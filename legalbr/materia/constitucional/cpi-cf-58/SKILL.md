# Comissão Parlamentar de Inquérito (CPI)

## Base normativa

| | Conteúdo |
|---|---|
| **CF 58 §3** | Criação pela **CD + SF** (CN), em conjunto (CPMI) ou separadamente |
| Requerimento | **1/3 dos membros** |
| Objeto | **Fato DETERMINADO** |
| Prazo | **Certo** |
| Poderes | **De investigação próprios das autoridades judiciais** |
| Encaminhamento | Ao **MP** (in fine) |
| **Lei 1.579/1952** (+ Lei 13.367/2016) | Procedimento + poderes + limites |

## Poderes da CPI

| | Conteúdo |
|---|---|
| Convocar testemunhas/investigados | Condução coercitiva fundamentada |
| **Quebra de sigilo BANCÁRIO + FISCAL + DADOS TELEFÔNICOS** (registros, não conteúdo) | Decisão **colegiada e fundamentada** |
| Requisição de documentos | Sim |
| Inspeções/perícias | Sim |
| Convocar autoridades públicas | Inclusive **Ministros de Estado** |
| Convocar PR | **NÃO**: o Presidente da República não pode ser convocado por CPI (CF 50, que alcança só Ministros e titulares de órgãos subordinados; STF ADPF 848 MC-Ref, 2021); a vedação estende-se, por simetria, a Governadores; admite-se **convite** para comparecimento voluntário |

## Limites: RESERVA DE JURISDIÇÃO (STF MS 23.452 + 23.964)

CPI **NÃO PODE**:

| | Conteúdo |
|---|---|
| **Prisão preventiva** | Somente flagrante (CF 5 LXI) |
| **Busca e apreensão DOMICILIAR** | CF 5 XI, reserva jurisdicional |
| **Interceptação TELEFÔNICA** | CF 5 XII + Lei 9.296/96, reserva absoluta |
| Indisponibilidade de bens | Não |
| Medidas cautelares patrimoniais | Não |
| Proibir exercício profissional | Não |
| Restringir direitos fundamentais | Não |

## CPI PODE (com fundamentação)

| | Conteúdo |
|---|---|
| Quebra de sigilo bancário | Decisão colegiada fundamentada |
| Quebra de sigilo fiscal | Comunicação BACEN/RFB |
| Quebra de **dados telefônicos** (registros) | **NÃO conteúdo** |
| Dever de preservar sigilo das informações coletadas | Sim |

## Direitos do investigado/testemunha

| | Conteúdo |
|---|---|
| **Direito ao SILÊNCIO** (CF 5 LXIII) | STF HC 79.244 + HC 100.341 + HC 169.706 |
| **Assistência de advogado** | Lei 8.906 art. 7 + STF HC 88.015, comunicação reservada |
| **Acesso aos autos** já documentados | **SV 14 STF** |
| Vedação a perguntas capciosas + ameaças + coação | Sim |
| Não autoincriminação | Sim |

## Controle judicial

Atos da CPI sujeitam-se ao **STF** (autoridade coatora = Mesa/Presidente da CPI federal; competência originária do STF, CF 102 I "d" e "i"):

| Instrumento | Conteúdo |
|---|---|
| **MS** | Contra atos lesivos (quebra sem fundamentação + indeferimento de prova) |
| **HC** | Direito ao silêncio + liberdade + advogado |
| **Reclamação** (CPC 988) | Usurpação de competência ou descumprimento de SV |

## Relatório final

| | Conteúdo |
|---|---|
| Aprovação | Maioria |
| Encaminhamento | MP + autoridades competentes |
| **NÃO produz coisa julgada** | |
| Apenas **indiciamentos políticos** | Sujeitos a apuração penal/cível autônoma |

## Fato determinado + desdobramentos

| | Conteúdo |
|---|---|
| **Vedada CPI genérica** | "Pesca probatória" inadmissível |
| **Desdobramentos conexos** | Admitida a ampliação para fatos conexos supervenientes, mediante aditamento do requerimento; o fato determinado e o direito da minoria à investigação são tutelados pelo STF (MS 26.441, CPI do Apagão Aéreo) |
| Lei 14.197/2021 | Crimes contra Estado Democrático podem ser objeto de CPI |

## Simetria (Estados + DF + Municípios)

CF 58 §3 aplica-se por **simetria** às Assembleias Legislativas (STF ADI 3.619). Câmaras municipais podem instaurar CPI no âmbito da competência fiscalizatória local, observados os **mesmos limites** (reserva de jurisdição); poderes que dependem de previsão em lei federal têm alcance controvertido na esfera municipal.

## Convocação de Ministros

| | Conteúdo |
|---|---|
| Ministros de Estado | CPI **pode** convocar (CF 50 + Lei 1.579) |
| **PR** | **NÃO pode ser convocado** (CF 50 + ADPF 848 MC-Ref); Governadores idem, por simetria; cabível apenas **convite** voluntário |
| Comparecimento | Respeitado, podem responder |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Criação | 1/3 + fato determinado + prazo certo |
| Quebra sigilo bancário/fiscal/dados telefônicos | **OK** com fundamentação colegiada |
| Conteúdo de comunicações | **VEDADO** (só com autorização judicial) |
| Prisão preventiva | **VEDADA** (só flagrante) |
| Busca domiciliar | **VEDADA** sem autorização judicial |
| Investigado | Direito ao silêncio + advogado + SV 14 |
| Relatório | MP + indiciamentos políticos |
| Ato lesivo | MS/HC/Reclamação ao STF |

## Erros a evitar

- A CPI não decreta prisão preventiva nem busca domiciliar (reserva de jurisdição).
- A interceptação telefônica é vedada à CPI (CF 5 XII + Lei 9.296/96).
- O direito ao silêncio e a assistência de advogado são assegurados (CF 5 LXIII + SV 14).
- A CPI sem fato determinado ou sem 1/3 de assinaturas é nula.
- A quebra de sigilo sem fundamentação colegiada é anulável (MS 23.452).
- Os registros telefônicos (permitidos) não se confundem com o conteúdo das comunicações (vedado).
- A convocação do Presidente da República por CPI não é admitida; a de Governadores também não, por simetria (CF 50 + ADPF 848 MC-Ref).
- O relatório não é condenatório: veicula indiciamentos políticos.
- A simetria estadual e municipal observa os mesmos limites (reserva de jurisdição).
- A comunicação reservada entre advogado e cliente é assegurada no depoimento.

# Liberdade Religiosa + Reunião

## CF 5 VI: INVIOLABILIDADE

| | Conteúdo |
|---|---|
| Conteúdo | Liberdade de **CONSCIÊNCIA + CRENÇA + culto + livre exercício** |
| Proteção | **LOCAIS de CULTO + suas LITURGIAS** |

## CF 5 VII: assistência religiosa

| | Conteúdo |
|---|---|
| Conteúdo | Prestação de **assistência religiosa nas entidades CIVIS e MILITARES** de internação coletiva |
| Exemplos | Presídios + hospitais + quartéis |
| **Lei 9.982/2000** | Regulamenta |

## CF 5 VIII: escusa de consciência

| | Conteúdo |
|---|---|
| Regra | Ninguém será **PRIVADO de direitos por motivo de crença/convicção filosófica/política** |
| **Exceção** | **EXIMIR-SE de OBRIGAÇÃO LEGAL** a todos imposta E **RECUSAR-SE a cumprir PRESTAÇÃO ALTERNATIVA** fixada em lei |
| **CF 143 §1** | **Serviço alternativo ao MILITAR** obrigatório (Lei 8.239/1991) |

## CF 19 I: ESTADO LAICO

| | Conteúdo |
|---|---|
| Vedações | União + Estados + DF + Municípios |
| Conteúdo | Estabelecer cultos + subvencioná-los + embaraçá-los + manter relações de dependência/aliança |
| Exceção | **COLABORAÇÃO de INTERESSE PÚBLICO** |

| | Conteúdo |
|---|---|
| LAICIDADE | ≠ **laicismo** |

## STF ADI 4.439 (Rel. p/ acórdão Min. Alexandre de Moraes, 27/09/2017, 6x5)

| | Conteúdo |
|---|---|
| Tese | **CONSTITUCIONALIDADE do ENSINO RELIGIOSO CONFESSIONAL** nas escolas públicas |
| **CF 210 §1** | **FACULTATIVO** + horários normais |
| Razão | Prevalece **neutralidade do Estado** sem laicismo militante |

## Concordata Brasil-Santa Sé (Dec. 7.107/2010)

| | Conteúdo |
|---|---|
| Status | Vigente; o ensino religioso nela previsto foi validado, em interpretação conforme, na ADI 4.439 |

## Lei 6.802/1980: feriado de N. Sra. Aparecida (12/10)

| | Conteúdo |
|---|---|
| Jurisprudência STF | Feriados religiosos tradicionais são admitidos sem afronta à laicidade |

## STF RE 494.601 (2019): SACRIFÍCIO ANIMAL

| | Conteúdo |
|---|---|
| Tese | **CONSTITUCIONAL** sacrifício animal em cultos **afro-brasileiros** |
| Caráter | Repercussão geral |

## CF 5 XVI: DIREITO DE REUNIÃO

| | Conteúdo |
|---|---|
| Conteúdo | Todos podem reunir-se **PACIFICAMENTE + SEM ARMAS** |
| Local | Aberto ao público |
| **NÃO exige** | Autorização |
| **Exige** | **PRÉVIO AVISO** à autoridade competente |
| Restrição | NÃO frustrar outra reunião anteriormente convocada para o mesmo local |

## STF ADPF 187 (Rel. Min. Celso de Mello, 15/06/2011): "MARCHA DA MACONHA"

| | Conteúdo |
|---|---|
| Tese | Interpretação CONFORME ao **CP 287**: descriminaliza a manifestação pública pela LEGALIZAÇÃO |
| **ADI 4.274** | Reforçou |

## CF 5 XVII-XIX: ASSOCIAÇÃO

| Inc. | Conteúdo |
|---|---|
| **XVII** | **Liberdade de associação** para fins lícitos |
| **XVIII** | **Independe de autorização** |
| **XIX** | **Dissolução** só por decisão judicial **transitada em julgado**; suspensão por decisão judicial |

## Distinções essenciais

| | Liberdade religiosa | Liberdade de associação |
|---|---|---|
| Base | CF 5 VI | CF 5 XVII-XIX |
| Proteção | Crença + culto + assistência | Fins lícitos |

| | Laicidade | Laicismo |
|---|---|---|
| Significado | Neutralidade + separação | Hostilidade ao religioso |
| BR | **Laicidade** (não laicismo) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Crença/culto | **Protegido** (CF 5 VI) |
| Assistência religiosa em presídio | **CF 5 VII** + Lei 9.982 |
| Escusa de consciência ao serviço militar | **CF 143 §1** + serviço alternativo |
| Ensino religioso na escola pública | **CONFESSIONAL constitucional** (ADI 4.439), facultativo |
| Sacrifício animal afro | **CONSTITUCIONAL** (RE 494.601) |
| Feriado religioso (Aparecida) | Constitucional |
| Manifestação pacífica + prévio aviso | **Cabível** |
| Marcha da Maconha | **Permitida** (ADPF 187) |
| Reunião com armas | **Vedada** (CF 5 XVI: sem armas) |
| Dissolução de associação | **Só com trânsito** em julgado (XIX) |
| Promoção de violência | Reunião **não pacífica**: vedada |

## Erros a evitar

- O Estado é laico, não laicista militante (neutralidade, não hostilidade).
- O ensino religioso confessional é constitucional (ADI 4.439).
- O sacrifício animal em cultos afro-brasileiros é constitucional, não crime (RE 494.601).
- A reunião pacífica é direito constitucional, não ato proibido (CF 5 XVI).
- A reunião independe de autorização, exigido apenas o prévio aviso (CF 5 XVI).
- A assistência religiosa nas entidades civis e militares é assegurada (CF 5 VII).
- A escusa de consciência depende de prestação alternativa fixada em lei (CF 5 VIII + 143 §1).
- A dissolução de associação exige decisão judicial transitada em julgado (CF 5 XIX).
- A subvenção a culto específico viola a laicidade (CF 19 I).
- A reunião com armas é vedada (CF 5 XVI).
- A marcha pela legalização não configura o CP 287 (ADPF 187).

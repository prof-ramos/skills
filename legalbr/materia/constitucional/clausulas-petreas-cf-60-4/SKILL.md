# Cláusulas Pétreas

## CF 60 §4: VEDAÇÕES MATERIAIS

| Inc. | Conteúdo |
|---|---|
| **I** | **FORMA FEDERATIVA** de Estado |
| **II** | **VOTO DIRETO, SECRETO, UNIVERSAL E PERIÓDICO** |
| **III** | **SEPARAÇÃO DOS PODERES** |
| **IV** | **DIREITOS E GARANTIAS INDIVIDUAIS** |

| | Conteúdo |
|---|---|
| **"Tendente a abolir"** | Protege o **NÚCLEO ESSENCIAL**, não a literalidade |
| ADI 2.024 + ADI 939 | Admite **reforma que aperfeiçoe**; veda **esvaziamento** direto ou oblíquo |

## CF 60 §§1-3+5: LIMITES FORMAIS

| § | Conteúdo |
|---|---|
| **§1** | **Iniciativa**: 1/3 Câmara + 1/3 Senado + PR + **mais da metade das ALs** com maioria relativa |
| **§2** | **2 turnos** em cada Casa + **3/5 dos votos** |
| **§3** | Promulgação pelas Mesas com número de ordem |
| **§5** | Matéria **REJEITADA** não pode na **mesma sessão legislativa** |

## CF 60 §1: LIMITES CIRCUNSTANCIAIS

| | Conteúdo |
|---|---|
| Vedação | Emendar na vigência de: **intervenção federal + estado de defesa + estado de sítio** |
| Caráter | **ABSOLUTO** enquanto perdurar a anormalidade |

## Limites materiais IMPLÍCITOS

| | Conteúdo |
|---|---|
| (a) | **Titularidade** do poder constituinte originário |
| (b) | **Próprio art. 60** |
| (c) | Proibição do retrocesso quanto a direitos sociais: construção doutrinária, invocada pontualmente pelo STF em searas específicas (ex.: ambiental, ADIs 4.901-4.903, contra lei), sem tese consolidada que a erija a limite autônomo de PEC |

## STF ADI 939 (IPMF): DIREITOS ESPALHADOS

| | Conteúdo |
|---|---|
| Tese | **Direitos individuais ESPALHADOS pela CF** (fora do art. 5) **SÃO cláusulas pétreas** |
| Exemplo | **Anterioridade tributária** (CF 150 III "b") |
| Imunidades recíprocas | Cláusula pétrea (federalismo) |

## Casos paradigmáticos

| | Conteúdo |
|---|---|
| **ADI 939** | EC 3/93 inconstitucional (viola anterioridade + imunidades) |
| **ADI 3.685** | **Verticalização**: anterioridade eleitoral (CF 16) é cláusula pétrea |
| **EC 132/2023** (reforma tributária) | Em controle no STF, sem declaração de inconstitucionalidade do núcleo |
| **EC 103/2019** (Previdência) | Idem |
| Reforma Trabalhista (Lei, não EC) | STF reputou compatível |

## CF 34 VII: PRINCÍPIOS SENSÍVEIS (≠ PÉTREAS)

| Alínea | Princípio |
|---|---|
| **a** | Forma republicana + sistema representativo + regime democrático |
| **b** | Direitos da pessoa humana |
| **c** | Autonomia municipal |
| **d** | Prestação de contas |
| **e** | Aplicação mínima ensino + saúde |

| | Conteúdo |
|---|---|
| Função | Autorizam **INTERVENÇÃO FEDERAL**, não controle de PEC |
| **ATENÇÃO** | **NÃO confundir** com cláusulas pétreas (CF 60 §4) |

## Controle de PEC

| | Conteúdo |
|---|---|
| **MS por parlamentar** (MS 20.257 + MS 32.033) | **Direito subjetivo ao devido processo legislativo**: controle **PREVENTIVO**, admitido contra PEC tendente a abolir cláusula pétrea e contra violação das normas constitucionais do processo legislativo; legitimidade **exclusiva do parlamentar** |
| Após promulgação | **ADI / ADC / ADPF** |

## Poder constituinte

| | Originário | Derivado |
|---|---|---|
| Limites jurídicos | **Ilimitado** | **Limitado** |
| Tipos | Inicial + autônomo | **Formal + material + circunstancial + temporal** |
| Espécies | (não há) | **Reformador** (EC) + **decorrente** (CE) |

## Distinção pétreas × princípios sensíveis × limites formais

| | Cláusulas pétreas | Princípios sensíveis | Limites formais |
|---|---|---|---|
| Local | CF 60 §4 | CF 34 VII | CF 60 §§1-3+5 |
| Função | Veda PEC | Autoriza intervenção | Disciplina procedimento |
| Controle | ADI/MS parlamentar | ADI Interventiva | MS parlamentar |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| PEC abole voto direto | **Inconstitucional** (CF 60 §4 II) |
| PEC restringe direito individual | Análise de **núcleo essencial** |
| PEC durante intervenção federal | **Inconstitucional** (CF 60 §1) |
| EC aprovada com 2/5 dos votos | **Inconstitucional** (formal) |
| Estado descumpre saúde mínima | **Intervenção federal** (CF 34 VII e) |
| Parlamentar quer impedir PEC | **MS prévio** (MS 20.257 + MS 32.033) |
| Anterioridade tributária | **Cláusula pétrea** (ADI 939) |
| Anterioridade eleitoral | **Cláusula pétrea** (ADI 3.685) |
| Reforma social | Aferir preservação do **núcleo essencial** (CF 60 §4 IV) |

## Erros a evitar

- Os limites formais (procedimento) não se confundem com os materiais (conteúdo).
- A petreidade alcança o núcleo essencial do direito fundamental, não toda a sua extensão.
- Os limites circunstanciais (intervenção, defesa, sítio) também obstam a reforma (CF 60 §1).
- As cláusulas pétreas (CF 60 §4) não se confundem com os princípios sensíveis (CF 34 VII).
- A proteção dos direitos sociais em face de PEC é aferida pelo núcleo essencial (CF 60 §4 IV); a proibição do retrocesso como limite autônomo é construção doutrinária sem tese consolidada.
- A CF 60 §5 (sessão legislativa) não se confunde com a CF 67 (PL por maioria absoluta).
- A CF 34 VII autoriza intervenção federal, não veda PEC.
- O MS preventivo do parlamentar é admitido para controle do devido processo legislativo (MS 20.257 + MS 32.033), com legitimidade exclusiva do parlamentar.
- O poder constituinte derivado é limitado, não ilimitado.
- A proibição do retrocesso pressupõe aferição do núcleo do direito.
- A ADI 939 alcança direitos individuais espalhados fora do art. 5.

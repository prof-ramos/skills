# ADI + ADC

## Fundamento

| | Conteúdo |
|---|---|
| **CF 102 I "a"** | Competência originária do **STF** para ADI/ADC |
| **CF 103** | Legitimados ativos |
| **Lei 9.868/1999** | Disciplina o processo |

## CF 103: legitimação ativa

| Inc. | Legitimado |
|---|---|
| I | Presidente da República |
| II | **Mesa do Senado** |
| III | Mesa da Câmara |
| IV | **Mesa de AL** ou Câmara Distrital |
| V | **Governador** ou DF |
| VI | **PGR** |
| VII | Conselho Federal da **OAB** |
| VIII | **Partido político** com representação no CN |
| IX | **Confederação sindical** ou entidade de classe nacional |

## Pertinência temática

| | Conteúdo |
|---|---|
| **UNIVERSAIS** | **NÃO exige**: I, II, III, VI, VII, VIII |
| **ESPECIAIS** | **EXIGE pertinência temática**: IV, V, IX |
| Conceito | **Nexo objetivo** entre o ato impugnado e a finalidade institucional |

## Rito da Lei 9.868/1999

| Art. | Conteúdo |
|---|---|
| **3** | Petição inicial: dispositivo + fundamentos + pedido |
| **4** | Não conhecimento por **inépcia** |
| **5** | **NÃO admite DESISTÊNCIA** |
| **6** | **Informações** do órgão emanador |
| **7** | **AGU** defende o ato (curador da presunção de constitucionalidade) |
| **8** | **PGR** opina |
| **9** | Relator + audiência pública |
| **10** | **CAUTELAR**: maioria absoluta; **EX NUNC (regra)**; ex tunc só excepcional |
| **12** | Julgamento direto |

## Quóruns

| | Conteúdo |
|---|---|
| **Presença** (art. 22) | **8 MINISTROS** |
| **Decisão** (art. 23) | **MAIORIA ABSOLUTA (6 VOTOS)** |
| **Modulação** (art. 27) | **2/3 (8 VOTOS)** |

## Art. 27: MODULAÇÃO DE EFEITOS

| | Conteúdo |
|---|---|
| Quórum | **2/3** dos ministros (8 votos) |
| Fundamento | **SEGURANÇA JURÍDICA** OU **EXCEPCIONAL INTERESSE SOCIAL** |
| Aplicação | Comum em **matéria tributária** (ex.: modulação na "tese do século", RE 574.706, Tema 69 RG, ICMS na base de PIS/COFINS) |

## Art. 28: EFEITOS

| | Conteúdo |
|---|---|
| **Eficácia** | **ERGA OMNES** |
| **Vinculação** | **VINCULANTE** (CF 102 §2: todos os órgãos + administração) |
| **Temporal** | **EX TUNC** (regra) |
| Modulação | Pode alterar para *ex nunc* ou *pro futuro* |

## Art. 26: IRRECORRIBILIDADE

| | Conteúdo |
|---|---|
| Regra | **IRRECORRÍVEL** |
| Salvo | **Embargos de declaração** |

## ADC: Ação Declaratória de Constitucionalidade

| | Conteúdo |
|---|---|
| Função | **INVERTE a presunção**: declara o ato constitucional |
| **Pressuposto** (art. 13) | **CONTROVÉRSIA JUDICIAL RELEVANTE** |
| Subsidiariedade | **NÃO é subsidiária da ADI**: ações de sinal trocado |
| Caráter ambivalente | **Fungibilidade** ADI ↔ ADC (STF) |
| Legitimação | Mesma da ADI (CF 103, após EC 45/2004) |

## Amicus curiae (art. 7 §2 + CPC 138)

| | Conteúdo |
|---|---|
| Admissibilidade | **AMPLIADA** pelo CPC/2015 (art. 138) |
| Função | Pluralização do debate constitucional |
| Requisitos | Representatividade do postulante + relevância da matéria |

## Distinções essenciais

| | ADI | ADC |
|---|---|---|
| Função | Declara INCONSTITUCIONALIDADE | Declara CONSTITUCIONALIDADE |
| Pressuposto | Inconstitucionalidade do ato | Controvérsia judicial relevante |
| Defesa | AGU defende | AGU defende |
| Efeitos | Erga omnes + vinculante | Idem |

| | Concentrado (STF) | Difuso |
|---|---|---|
| Competência | STF (ADI/ADC/ADPF/ADO) | **Qualquer juiz** |
| Eficácia | Erga omnes | *Inter partes* (salvo CF 52 X) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Lei federal/estadual posterior à CF | **ADI** |
| Lei pré-CF/88 | **ADPF** (recepção) |
| Confirmar constitucionalidade + controvérsia | **ADC** |
| Universal autor | **Sem** pertinência |
| Especial autor | **EXIGE** pertinência |
| Cautelar | Maioria absoluta; **ex nunc regra** |
| Decisão de mérito | 6 votos + ex tunc |
| Modulação | **2/3 (8 votos)** |
| Desistência | **Vedada** |

## Erros a evitar

- A decisão concentrada produz eficácia erga omnes e vinculante, não coisa julgada *inter partes* de sentença comum (CF 102 §2; art. 28).
- A pertinência temática não se exige dos legitimados universais (CF 103 I, II, III, VI, VII, VIII).
- A ADC não é subsidiária da ADI: são ações de sinal trocado (caráter ambivalente).
- A cautelar tem eficácia *ex nunc* como regra (art. 10).
- A modulação exige quórum qualificado de 2/3, equivalente a 8 votos (art. 27).
- A desistência é vedada (art. 5).
- A AGU é curadora da presunção de constitucionalidade, não parte adversa (art. 7).
- A decisão vincula o Executivo e o Judiciário, mas não o Legislativo (CF 102 §2).
- A ADI não alcança leis pré-CF/88: cabe ADPF (recepção).
- A modulação pressupõe segurança jurídica ou excepcional interesse social (art. 27).
- A ADC exige controvérsia judicial relevante (art. 13).

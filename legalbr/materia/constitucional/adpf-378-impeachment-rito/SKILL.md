# ADPF 378: Rito do Impeachment

## Identificação

| | Conteúdo |
|---|---|
| Ação | **ADPF 378** |
| Autor | **PCdoB** |
| Relator | Min. Edson Fachin |
| Redator acórdão | Min. **Roberto Barroso** |
| Julgamento | **17/12/2015** |
| Contexto | Impeachment Dilma Rousseff (2015–2016) |

## Tese estruturante

Atualização interpretativa da Lei 1.079/1950 à CF/88, com fixação de **rito constitucional** do impeachment do Presidente da República.

## Câmara dos Deputados: fase de admissibilidade

| Etapa | Regra |
|---|---|
| **Recebimento da denúncia** | Competência **PRIVATIVA** do Presidente da Câmara |
| Defesa prévia | **DEVE ser oportunizada** antes do juízo de admissibilidade |
| Quórum | **2/3** (342 votos), CF 51 I |
| Votação | **NOMINAL + ABERTA** (vedado voto secreto) |
| Efeito | Juízo **POLÍTICO** de admissibilidade; o afastamento do cargo decorre da instauração pelo Senado |

## Comissão Especial: composição

| | Conteúdo |
|---|---|
| Indicação | **Líderes partidários** dos partidos/blocos (CF 58) |
| Candidatura avulsa | **VEDADA** (ADPF 378, por 7x4): não cabe chapa avulsa escolhida pelo plenário à revelia dos líderes |
| Voto na escolha | **ABERTO** (ADPF 378): voto secreto é incompatível com a CF |
| Composição | Proporcional + reflexo dos blocos parlamentares |

## Senado Federal: fase processante

| Etapa | Regra |
|---|---|
| **Recebimento** | Senado faz **NOVO JUÍZO DE ADMISSIBILIDADE** (não vinculado pela Câmara) |
| Maioria | **MAIORIA SIMPLES** para instauração |
| Afastamento | Automático com a instauração, até **180 DIAS** |
| Instrução | Senado conduz |
| Julgamento | Presidido pelo **PRESIDENTE DO STF** |
| Condenação | **2/3 (54 votos)** |
| Penas | **Perda do cargo + INABILITAÇÃO 8 anos** para função pública |

## Hipóteses

| | Conteúdo |
|---|---|
| **Crime comum** | STF (CF 102 I "b"), com autorização da Câmara por 2/3 |
| **Crime de responsabilidade** | **Lei 1.079/1950** + rito ADPF 378 |
| Distinção | Político ≠ Penal: sanção é perda do cargo + inabilitação |

## Crimes de responsabilidade: base normativa

| | Conteúdo |
|---|---|
| **CF 85** | Define hipóteses |
| **Lei 1.079/1950** | Tipifica + disciplina o processo |
| **EC 23/1999** | Alterou competências (arts. 52, 102 e 105 da CF) |

## Erros do rito anterior corrigidos

| Prática anterior | ADPF 378 corrigiu |
|---|---|
| Voto secreto na escolha da comissão | **VEDADO**: voto aberto |
| Voto secreto no plenário | **VEDADO**: votação aberta/nominal |
| Candidatura/chapa avulsa na comissão | **VEDADA**: indicação pelos líderes (CF 58) |
| Senado vinculado à Câmara | Senado faz **NOVO JUÍZO** |

## Distinções essenciais

| | ADPF 378 (Dilma) | Caso Collor (MS 21.564, 1992) |
|---|---|---|
| Rito | Detalhamento | Primeiro precedente |
| Defesa prévia | Confirmou exigibilidade | Já reconhecida |
| Voto aberto | Confirmou | Não enfrentado |

| | Câmara | Senado |
|---|---|---|
| Função | Autorização (2/3) | Processo e julgamento |
| Natureza | Juízo político | Juízo político-jurídico |
| Quórum | 2/3 (342) | 2/3 (54) |

## Precedentes do rito

| | Conteúdo |
|---|---|
| **MS 21.564** | Caso Collor (rito de 1992) |
| **ADPF 378** | Rito Dilma (2015) |
| Afastamento | Limitado a 180 dias (CF 86 §2) |
| Governadores | Fundamentos análogos; a definição dos crimes de responsabilidade e as normas de processo e julgamento são competência legislativa privativa da União (**SV 46**) |

## Renúncia x prosseguimento

| | Conteúdo |
|---|---|
| Renúncia antes do julgamento | **EXTINGUE** quanto à perda do cargo |
| **Inabilitação** | Tese: PROSSEGUE (Collor: STF reconheceu) |
| Tese contrária | Renúncia extinguiria também a inabilitação (rejeitada pelo STF no caso Collor) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Recebimento da denúncia | **Presidente da Câmara** privativamente |
| Defesa prévia | **OBRIGATÓRIA** antes do juízo |
| Votação Câmara | **2/3 + aberta + nominal** |
| Comissão especial | Indicação pelos **líderes** + voto **ABERTO** (chapa avulsa vedada) |
| Recebimento no Senado | **MAIORIA SIMPLES** + novo juízo |
| Afastamento | Até **180 DIAS** |
| Presidência do julgamento Senado | **Presidente do STF** |
| Condenação | **2/3 (54 votos)** |
| Pena | Perda do cargo + **inabilitação 8 anos** |
| Crime comum × responsabilidade | STF (102 I "b") × Senado (Lei 1.079) |

## Erros a evitar

- O Senado não é vinculado à Câmara: faz NOVO juízo de admissibilidade.
- O voto no plenário da Câmara em juízo de admissibilidade é aberto (voto secreto é vedado).
- A ausência de defesa prévia gera nulidade.
- O recebimento compete ao Presidente da Câmara, não a órgão diverso.
- A autorização da Câmara exige quórum de 2/3, não de maioria simples.
- A renúncia não extingue a inabilitação (caso Collor, STF).
- O afastamento é AUTOMÁTICO com a instauração no Senado.
- O prazo de afastamento é limitado a 180 DIAS.
- O crime de responsabilidade (Senado) não se confunde com o crime comum (STF, CF 102 I "b").
- A inabilitação é autônoma, não acessória dependente da pena principal (caso Collor).

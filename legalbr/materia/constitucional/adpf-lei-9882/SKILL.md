# ADPF

## Fundamento

| | Conteúdo |
|---|---|
| **CF 102 §1** | Prevê a ADPF |
| **Lei 9.882/1999** | Regulamenta; constitucionalidade declarada pelo STF |
| Competência | Originária do **STF** |

## Lei 9.882 art. 1: OBJETO

### Caput: ADPF AUTÔNOMA
| | Conteúdo |
|---|---|
| Hipótese | Evitar/reparar **lesão a PRECEITO FUNDAMENTAL** decorrente de ato do Poder Público |
| Preceitos | **Cláusulas pétreas** (CF 60 §4) + **princípios sensíveis** (CF 34 VII) + **direitos fundamentais** (Título II) + **princípios estruturantes** (Estado Democrático + separação dos Poderes + federalismo) |

### Par. único: ADPF INCIDENTAL / POR EQUIPARAÇÃO
| Inc. | Hipótese |
|---|---|
| **I** | **Ato concreto** da União + Estados + DF + Municípios (inclusive **atos não normativos** + decisões judiciais transitadas) |
| **II** | **Controvérsia constitucional relevante** sobre **lei/ato PRÉ-CONSTITUCIONAL** (recepção) |

## Art. 2: legitimação

| | Conteúdo |
|---|---|
| Legitimados | **Mesmos da ADI** (CF 103) |
| Pertinência temática | Para **especiais** |

## Art. 4 §1: SUBSIDIARIEDADE

| | Conteúdo |
|---|---|
| Regra | **NÃO CABE** se houver **outro meio EFICAZ** de sanar a lesividade |
| **STF (ADPF 33, 76, 388)** | **Subsidiariedade FLEXIBILIZADA / RELATIVIZADA** |
| "Eficaz" | **Capaz de gerar PROTEÇÃO com mesma INTENSIDADE + IMEDIATIDADE + AMPLITUDE GERAL** |
| Alternativa abstrata | (ex.: ações individuais) **NÃO afasta** ADPF |
| **Fungibilidade ADI ↔ ADPF** (ADPF 72-QO) | Aplicável |

## Procedimento

| Art. | Conteúdo |
|---|---|
| 3 | Petição inicial: preceito violado + ato + prova + pedido |
| **5** | **LIMINAR**: maioria absoluta (6 votos), salvo recesso/urgência monocrática |
| 6 | Oitiva obrigatória de **AGU + PGR** |
| **8** | Quórum de presença de **2/3 (8 ministros)** para a decisão + **INTERPRETAÇÃO CONFORME** + nulidade parcial sem redução de texto |
| 10 | Comunicação a autoridades/tribunais |
| **11** | **ERGA OMNES + VINCULANTE + EX TUNC** (regra); admite **MODULAÇÃO** por 2/3 (subsidiariamente Lei 9.868 art. 27) |
| **12** | **IRRECORRÍVEL**: apenas ED |

## Cabimento residual (≠ ADI)

| | ADI | ADPF |
|---|---|---|
| Lei pré-CF/88 | NÃO cabe | **Cabe** |
| Lei municipal | Estadual cabe na Constituição estadual | **Cabe** |
| Ato concreto | Não | **Cabe** |
| Decisão judicial transitada | Não | **Cabe** |
| Omissão | NÃO (cabe ADO) | NÃO (cabe ADO) |

## Distinções essenciais

| | ADI (qualquer dispositivo) | ADPF (preceito fundamental) |
|---|---|---|
| Objeto | Lei posterior à CF | Preceitos fundamentais (núcleo material) |
| Subsidiariedade | NÃO | **SIM** (flexibilizada) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Lei pré-CF/88 violando preceito | **ADPF** par. único II |
| Lei municipal | **ADPF** |
| Ato concreto lesivo | **ADPF** par. único I |
| Decisão transitada | **ADPF** |
| Lei posterior à CF | **ADI** (regra) |
| Sem outro meio eficaz | **ADPF** |
| Liminar | Maioria absoluta (6 votos) |
| Mérito | Erga omnes + vinculante + ex tunc (presentes 8 ministros) |
| Modulação | 2/3 |
| ADPF 132 | União homoafetiva |
| ADPF 347 | Estado de coisas inconstitucional |
| ADPF 442 | Pendente (aborto até 12 semanas) |

## Erros a evitar

- A ADPF tutela preceito fundamental, não qualquer dispositivo da CF (objeto distinto da ADI).
- A subsidiariedade é flexibilizada pelo STF, não rígida (ADPF 33).
- A omissão legislativa desafia ADO, não ADPF.
- A lei posterior à CF, em regra, desafia ADI (ADPF é residual).
- A fungibilidade ADI ↔ ADPF é admitida pelo STF (ADPF 72-QO).
- O caput (ato pós-CF lesivo) não se confunde com o parágrafo único (lei pré-CF e ato concreto).
- A liminar exige maioria absoluta (6 votos, art. 5); os 2/3 (8 ministros) do art. 8 são quórum de presença para a decisão.
- A modulação aplica-se subsidiariamente pela Lei 9.868 art. 27.
- O ato com recurso pendente não comporta ADPF (subsidiariedade).
- A ADPF 442 segue pendente de julgamento definitivo.
- A alternativa meramente abstrata não afasta a subsidiariedade da ADPF.
- A decisão judicial transitada em julgado pode ser objeto de ADPF (par. único I).

# Poder Judiciário + STF + STJ + CNJ

## Bases legais

- **CF 92-126** + **EC 45/2004** (Reforma + CNJ);
- **EC 80/2014** (Defensoria); **EC 74/2013**;
- **LOMAN LC 35/1979**;
- Resoluções CNJ.

## Estrutura (CF 92)

| | Órgão |
|---|---|
| I | STF |
| I-A | **CNJ** |
| II | STJ |
| II-A | TRFs + JF |
| III | TST + TRTs + JT |
| IV | TSE + TREs + JE |
| V | STM + JM |
| VI | TJs + JE estadual |

## Garantias da magistratura (CF 95)

| | Conteúdo |
|---|---|
| **Vitaliciedade** | 2 anos de exercício; só perde por sentença |
| **Inamovibilidade** | Salvo interesse público (CNJ/tribunal maioria absoluta) |
| **Irredutibilidade** | Nominal |

### Vedações (95 par. único)
- I outro cargo (exceto magistério);
- II custas/participação;
- III partidária;
- IV auxílios/contribuições;
- V **quarentena 3 anos**.

## Ingresso e promoção

- **Concurso público** (93 I) + 3 anos atividade jurídica;
- **Quinto constitucional** (94): 1/5 nos TJ/TRF (e TST/TRT); no STJ, o terço (CF 104): sêxtupla (OAB/MP) → tríplice → Executivo;
- Promoção alternada antiguidade × merecimento.

## STF (CF 101-103)

| | Conteúdo |
|---|---|
| **11 ministros** | Brasileiros **natos** (12 §3 IV) |
| Idade | 35-65 anos |
| Requisitos | Notável saber + reputação ilibada |
| Nomeação | Presidente + Senado (maioria absoluta) |
| Caso recente | Rejeição da indicação de Jorge Messias pelo Senado em 29/04/2026 (42×34, voto secreto): primeira rejeição de indicado ao STF sob a CF/88 |

### Competência

| | Conteúdo |
|---|---|
| **Originária** (102 I) | Pres/Vice/Ministros; ADI/ADC/ADPF/ADO; extradição; HC autoridades |
| Recursal | RE (com RG); RO (102 II) |
| Sumular | SV (103-A) |

## CNJ (CF 103-B + EC 45/2004)

| | Conteúdo |
|---|---|
| Membros | **15** (presidido pelo **Presidente do STF**, CF 103-B §1) |
| Mandato | 2 anos + 1 recondução |
| Funções (§4) | Correição + reclamações + PAD + remoção + representação MP |
| **DDH** | Lei 15.434/2026 cria, no âmbito do CNJ, o Departamento de Monitoramento e Fiscalização das Decisões dos Sistemas Internacionais de Direitos Humanos |
| **Não exerce** | Jurisdição |

## STJ (CF 104-105)

| | Conteúdo |
|---|---|
| **33 ministros** | 35-65 anos |
| Composição | 1/3 TRF + 1/3 TJ + 1/3 (advogados+MP) |
| Função | Uniformizador legislação federal infraconstitucional |
| Recursos | REsp (105 III); RO (105 II) |
| **Filtro de relevância** | EC 125/2022, regulamentado pela **Lei 15.484/2026** (novo CPC 1.035-A; DOU 04/08/2026, vigência 03/09/2026): tópico específico de relevância exigível em REsp contra acórdão publicado a partir de 03/09/2026 |
| IDC (109 §5) | Federalização crimes DH |

## Justiça Federal (CF 106-110)

- **6 TRFs** (incl. **TRF6/BH** instalado 19/08/2022);
- Discussões TRF7;
- Competência (109): U/autarquias; crimes federais; **V-A IDC DH**; HC/MS federal.

## Justiça do Trabalho (CF 111-117)

- TST + 24 TRTs + Varas;
- EC 24/1999 extinguiu representação classista;
- EC 45 ampliou (114);

### Teses do STF com impacto na competência

| | Conteúdo |
|---|---|
| **Tema 725** (RE 958.252 + ADPF 324) | Terceirização lícita em qualquer atividade, inclusive atividade-fim, mantida a responsabilidade subsidiária da contratante |
| Tema 550 (RE 606.003) | Relação entre representante e representada comerciais (Lei 4.886/65): competência da Justiça Comum |
| **Tema 1.389** (ARE 1.532.603, rel. Min. Gilmar Mendes) | **Pejotização**: pendente de tese (julgamento de mérito suspenso por pedido de vista em dez/2025); a suspensão nacional de abr/2025 foi flexibilizada em 18/06/2026 (processos prosseguem no 1º grau e nos TRTs; sobrestamento mantido a partir da fase recursal pós-TRT) |

## Justiça Eleitoral (CF 118-121)
TSE (7 membros: 3 STF + 2 STJ + 2 advogados) + TREs + Juízes + Juntas.

## Justiça Militar (CF 122-125)

| | Conteúdo |
|---|---|
| **Federal** | STM (15: 10 militares + 5 civis); crimes militares FFAA |
| **Estadual** | TJM (SP/MG/RS) ou Câmaras; Lei 13.491/2017 ampliou; EC 45 retirou ações disciplinares |

## Justiça Estadual (125-126)

TJ + juízes; competência **residual**.

## Responsabilidade do Estado (CF 5 LXXV)

| | Conteúdo |
|---|---|
| Erro judiciário + prisão além do tempo | Responsabilidade **objetiva** do Estado (CF 5 LXXV + CF 37 §6; STF RE 505.393/PE, 1ª Turma, 2007: a indenização por erro judiciário penal independe de dolo ou culpa do magistrado) |
| Regressiva contra juiz | Só dolo/culpa (CF 37 §6) |

## EC 45/2004: Reforma

- CNJ;
- **SV** + **RG**;
- **IDC** DH;
- **Quarentena** 3 anos;
- Razoável duração do processo;
- Ampliação JT (114).

## Erros a evitar

- A terceirização é lícita em qualquer atividade, inclusive na atividade-fim, mantida a responsabilidade subsidiária da contratante (Tema 725).
- A vitaliciedade não é imediata: forma-se após 2 anos de exercício.
- O quinto constitucional integra a composição dos tribunais (CF 94).
- Os ministros do STF são brasileiros natos (12 §3 IV).
- O CNJ não exerce jurisdição.
- O filtro de relevância do REsp foi regulamentado pela Lei 15.484/2026 (CPC 1.035-A), com vigência em 03/09/2026 e exigência restrita a recursos contra acórdãos publicados a partir dessa data; antes disso, não é requisito de admissibilidade.
- A representação classista foi extinta (EC 24/99).
- A relação entre representante e representada comerciais é da Justiça Comum, não da trabalhista (Tema 550).
- A Defensoria tem autonomia (EC 80/2014).
- A competência criminal militar estadual não alcança ato administrativo (EC 45).

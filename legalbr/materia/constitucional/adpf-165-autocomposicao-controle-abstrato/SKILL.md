# ADPF 165: Autocomposição em Controle Abstrato

## Identificação

| | Conteúdo |
|---|---|
| Ação | **ADPF 165** (ajuizada pela CONSIF em 2009) |
| Autor | **CONSIF (Confederação Nacional do Sistema Financeiro)** |
| Homologação do acordo | **16/02/2018** (Min. Ricardo Lewandowski); aditivo em 2020 para Collor I |
| Julgamento de mérito | **23/05/2025**, rel. Min. **Cristiano Zanin** (por maioria): Plenário declarou **constitucionais** os planos Bresser, Verão, Collor I e Collor II e prorrogou o prazo de adesão ao acordo por **24 meses**, contados da publicação da ata (03/06/2025) |
| Efeitos do mérito | Adesão ao acordo tornou-se a **via para o ressarcimento**; preservada a coisa julgada (sem rescisória ou inexigibilidade fundadas na constitucionalidade dos planos); eficácia erga omnes e vinculante |
| Objeto | Planos econômicos (1986–1991): expurgos inflacionários em poupança |
| Tema correlato | **Tema 264 STF** (RE 591.797/RE 626.307), com repercussão geral reconhecida e **sem tese de mérito fixada** |

## Tese estruturante

| | Conteúdo |
|---|---|
| Resultado | **HOMOLOGAÇÃO DE ACORDO** em controle abstrato |
| Tese | Controle concentrado admite **AUTOCOMPOSIÇÃO** com eficácia **erga omnes** |
| Base | Lei 9.882/1999 + aplicação subsidiária da **Lei 13.140/2015** + CPC |
| Função | **Conciliação como instrumento processual constitucional** |

| | Conteúdo |
|---|---|
| Partes | CONSIF + bancos + IDEC + DPU + AGU |

## Marco histórico

| | Conteúdo |
|---|---|
| Antes | STF resistia à autocomposição em controle abstrato |
| **ADPF 165 (homologação em 2018; mérito em 2025)** | **VIRADA**: admite expressamente o acordo coletivo em sede de controle concentrado |
| Justificativa | Segurança jurídica + razoável duração do processo + eficiência |

## Diálogo com Tema 264 STF

| | Conteúdo |
|---|---|
| Tema 264 | Repercussão geral sobre expurgos em poupança (RE 591.797 + RE 626.307); **sem tese de mérito fixada** |
| ADPF 165 | Acordo coletivo de soluções práticas |
| Suspensão | Processos individuais sobrestados; solução prática canalizada para a adesão ao acordo |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| ADPF com viabilidade de acordo | **Autocomposição cabível** (ADPF 165) |
| Direitos individuais homogêneos | Acordo coletivo |
| Adesão | Voluntária (sistema de inscrição) |
| Eficácia | **Erga omnes** + adesão para recebimento |
| Norma penal | **Acordo VEDADO** quanto a tipos |
| Direitos indisponíveis | Acordo VEDADO |
| Processos individuais | **Suspensos** (Tema 264, sobrestamento) |
| Homologação | Pelo **Plenário do STF** |
| Modulação | Compatível com autocomposição |
| Aplicação subsidiária | CPC + Lei 13.140/2015 |

## Erros a evitar

- O controle abstrato admite autocomposição (ADPF 165), não é incompatível com ela.
- O acordo coletivo não alcança direitos indisponíveis (vedado).
- A vinculação erga omnes depende de homologação plenária do STF.
- O Tema 264 (suspensão dos processos) e o acordo coletivo são complementares, não se confundem; o Tema 264 permanece sem tese de mérito fixada.
- A adesão é voluntária, com caráter de transação, não obrigatória.
- A representatividade adequada das partes negociadoras é requisito da autocomposição.
- A Lei 13.140 incide com adaptação ao processo objetivo.
- A homologação não é mera chancela: o STF examina a compatibilidade material.
- O acordo em ADPF é admissível: a tese constitucional pode permanecer com solução consensual sobre efeitos práticos.
- A autocomposição não alcança norma penal (princípio da reserva legal).

# ADO + ADC + ADI Interventiva

## ADO: Ação Direta de Inconstitucionalidade por OMISSÃO

### Base
| | Conteúdo |
|---|---|
| **CF 103 §2** | Omissão de medida tornando efetiva norma constitucional |
| **Lei 12.063/2009** | Incluiu arts. **12-A a 12-H** na Lei 9.868 |
| Legitimados | Mesmos da ADI (CF 103 I-IX) |

### Pressupostos
| | Conteúdo |
|---|---|
| (i) | Norma constitucional de **EFICÁCIA LIMITADA** |
| (ii) | Decurso de **prazo razoável** caracterizando silêncio inconstitucional |
| (iii) | **Inércia do órgão competente** |
| Modalidades | **TOTAL** (silêncio absoluto) OU **PARCIAL** (insuficiência: ADI-MC 1.439) |

### Procedimento
| | Conteúdo |
|---|---|
| **AGU** | Manifestação **facultativa**: o relator **poderá** solicitá-la (Lei 9.868 art. 12-E §2, incluído pela Lei 12.063/2009), pois não há ato a defender |
| **PGR** | **SEMPRE INTERVÉM** |

### Efeitos
| | Conteúdo |
|---|---|
| Eficácia | **ERGA OMNES + VINCULANTE** |
| Temporal | **EX NUNC** (regra: mera declaração da mora) |
| **Órgão ADMINISTRATIVO** | Prazo de **30 DIAS** (12-H §1), prorrogável excepcionalmente |
| **Órgão LEGISLATIVO** | **Apenas DAR CIÊNCIA**, sem prazo coercitivo (**separação dos Poderes**); admite-se a fixação de **parâmetro temporal razoável**, sem sanção (ADI 3.682: 18 meses para a LC do CF 18 §4) |
| STF | **NÃO cria norma substitutiva** |

### Precedentes ADO
| | Conteúdo |
|---|---|
| **ADO 26** (2019) | **Homotransfobia = racismo** por interpretação conforme até lei específica (rel. Celso de Mello) |
| **ADO 25** (30/11/2016) | Omissão do Congresso em editar a LC que compensa os Estados pelas perdas de ICMS nas exportações (Lei Kandir + EC 42/2003); fixado prazo para legislar e, na ausência, arbitragem pelo TCU (depois LC 176/2020) |
| **ADI 3.682** (rel. Min. Gilmar Mendes, 09/05/2007) | ADI por omissão: mora do Congresso na LC do CF 18 §4 (criação de municípios); reconhecida a "inertia deliberandi" como omissão e fixado parâmetro temporal razoável de 18 meses |

| | Conteúdo |
|---|---|

## ADC: Ação Declaratória de Constitucionalidade

| | Conteúdo |
|---|---|
| Origem | **EC 3/93** + **EC 45/2004** (ampliou legitimação) |
| Base | Lei 9.868 arts. **13-19** |
| Função | **Inverte a presunção**: cessa a relativa, gera certeza |
| Pressuposto **específico** (art. 14 III) | **CONTROVÉRSIA JUDICIAL RELEVANTE**: divergência concreta nos tribunais |
| Cabimento | **NÃO contra ato pré-CF** (cabe ADPF: recepção) |
| Legitimação | Equiparada à ADI (CF 103) |
| Efeitos | **ERGA OMNES + VINCULANTE** (CF 102 §2) |

## ADI INTERVENTIVA: CF 36 III

| | Conteúdo |
|---|---|
| Função | **Pressuposto da INTERVENÇÃO FEDERAL** por violação aos princípios sensíveis |
| **Legitimado EXCLUSIVO** | **PGR** |
| Competência | **STF processa** (Lei **12.562/2011**) |
| Precedente | **IF 5.179/DF** (caso do DF, rel. Min. Cezar Peluso, 30/06/2010): pedido julgado **improcedente**; a intervenção é medida extrema e excepcional, incabível quando a ordem já foi restabelecida por providências eficazes das autoridades |
| Procedência | Presidente expede **decreto interventivo**: ato **VINCULADO** + **dispensa controle do CN** (CF 36 §3) |

## Distinções essenciais

| | ADO | ADC | ADI Interventiva |
|---|---|---|---|
| Função | Omissão | Constitucionalidade | Intervenção federal |
| Legitimação | CF 103 | CF 103 | **PGR exclusivo** |
| Efeito | Ciência/prazo 30d | Erga omnes + vinculante | Decreto interventivo |

| | ADO (abstrato) | MI (concreto) |
|---|---|---|
| Interesse | Geral | Individual |
| Procedimento | Lei 9.868 (12-A) | Lei 13.300 |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Omissão legislativa (norma eficácia limitada) | **ADO** |
| Direito subjetivo obstado | **MI** |
| Omissão administrativa | **ADO** + prazo 30d |
| Confirmar constitucionalidade + controvérsia | **ADC** |
| Lei pré-CF | **ADPF** (não ADC) |
| Violação a princípio sensível (CF 34 VII) | **ADI Interventiva** (PGR) |
| Homotransfobia | **ADO 26** |
| Compensação Lei Kandir aos Estados | **ADO 25** |
| Greve do servidor | **MI** + aplicação analógica Lei 7.783 |

## Erros a evitar

- A ADO é controle abstrato e o MI é controle concreto: são instrumentos distintos.
- O prazo coercitivo não se impõe ao Legislativo (separação dos Poderes); admite-se apenas parâmetro temporal razoável (ADI 3.682).
- A ADO cabe apenas contra omissão relativa a norma de eficácia limitada, não plena ou contida.
- A ADC exige controvérsia judicial relevante (art. 14 III).
- A ADI Interventiva limita-se aos princípios sensíveis taxativos (CF 34 VII).
- A legitimação na interventiva é exclusiva do PGR (CF 36 III).
- O prazo de 30 dias aplica-se ao órgão administrativo, não ao Legislativo (12-H §1).
- A omissão de ato administrativo concreto não desafia ADO: cabe ADPF.
- O MI produz efeitos ultra partes após a Lei 13.300/2016 (art. 9 §1).
- Os princípios sensíveis (CF 34 VII) não se confundem com as cláusulas pétreas (CF 60 §4).
- O decreto interventivo é ato vinculado, não discricionário (CF 36 §3).

# Direitos Políticos

## Soberania popular (CF 14)

| | Conteúdo |
|---|---|
| **CF 14** | Sufrágio **universal + voto direto + secreto + periódico** + valor igual para todos |
| **Cláusula pétrea** | CF 60 §4 II |
| Mecanismos diretos | **I — plebiscito** (consulta ANTES do ato); **II — referendo** (DEPOIS); **III — iniciativa popular** |
| **Iniciativa popular** (CF 61 §2) | **1% eleitorado nacional + 5 estados + 0,3%** em cada |
| Regulamentação | **Lei 9.709/1998** |

## Alistamento (CF 14 §1-2)

| Faixa | Conteúdo |
|---|---|
| **18-70 anos alfabetizados** | **OBRIGATÓRIO** |
| **16-18 + > 70 + analfabetos** | **FACULTATIVO** |
| **Estrangeiros + conscritos** | **VEDADO** (§2) |

## Inelegibilidades (CF 14)

| | Conteúdo |
|---|---|
| **§5** | **Reeleição**: PR + GO + Pref **UMA vez** para período subsequente |
| **§7 — reflexa** | Cônjuge + parentes até 2º grau no território |
| **SV 18 STF** | Dissolução conjugal **NO CURSO** do mandato **NÃO afasta** inelegibilidade (exceção: morte) |
| Desincompatibilização | **6 meses** antes |
| **§8** | Militar com < 10 anos: **afastar-se**; ≥ 10 anos: agregação |
| **§9** | Base da **LC 64/1990** + **LC 135/2010 (Ficha Limpa)** + **LC 219/2025** (contagem da condenação colegiada) |

## Perda/suspensão (CF 15 — VEDADA cassação)

| Inc. | Hipótese |
|---|---|
| **I** | **Perda da nacionalidade** (perda definitiva) |
| **II** | Incapacidade civil absoluta (suspensão) |
| **III** | **Condenação criminal TRANSITADA EM JULGADO**, enquanto durarem os efeitos — **Tema 370 STF** (AUTOAPLICÁVEL — vale para pena restritiva + privativa + sursis) |
| IV | Recusa de obrigação alternativa (CF 5 VIII) |
| V | **Improbidade administrativa** (CF 37 §4) |

## CF 16 + CF 17

| Art. | Conteúdo |
|---|---|
| **CF 16** | **Anterioridade eleitoral** — **1 ano** (cláusula pétrea — ADI 3.685); NÃO se aplica a EC originária |
| **CF 17** | **Partidos políticos**: livre criação + caráter nacional + prestação de contas à JE + funcionamento parlamentar — **Lei 9.096/1995** |

## Jurisprudência-chave STF

| | Conteúdo |
|---|---|
| **ADC 29/30 + ADI 4.578** (2012) | Ficha Limpa **constitucional** — condenação por **órgão COLEGIADO** basta (não viola presunção de inocência — natureza não penal) |
| **Tema 370** (RE 601.182) | Suspensão CF 15 III **AUTOAPLICÁVEL** |
| **Tema 1.199** | Irretroatividade do dolo na nova Lei de Improbidade (Lei 14.230/2021); norma benéfica retroage; prescrição intercorrente |
| **ADI 6.530** | Financiamento de campanha — **FEFC constitucional**; vedação a empresas mantida |
| **SV 18** | Inelegibilidade reflexa persiste após divórcio durante mandato |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Consulta antes da edição | **Plebiscito** |
| Consulta após edição | **Referendo** |
| 1% eleitorado + projetos | **Iniciativa popular** |
| Condenação colegiada (Ficha Limpa) | **Inelegível** 8 anos (sem necessidade de trânsito) |
| Condenação para suspensão CF 15 III | **Exige trânsito** |
| Divórcio durante mandato | **Mantém reflexa** (SV 18) |
| Morte do cônjuge | Afasta reflexa (SV 18 exceção) |
| Norma eleitoral < 1 ano da eleição | **Não aplicável** (CF 16) |
| Improbidade dolosa | Suspensão CF 15 V |

## Erros a evitar

- **Aplicar CF 15 III sem trânsito** em julgado — Ficha Limpa basta colegiada mas suspensão **exige trânsito**;
- **Confundir plebiscito (ANTES) × referendo (DEPOIS)**;
- Aplicar **CF 16 a EC originária** ou interpretativa;
- **Negar Ficha Limpa por condenação colegiada** alegando presunção de inocência (ADC 29/30 rejeitou);
- Aplicar **SV 18 a viuvez** (não se aplica);
- Ignorar prazo de **8 anos** a partir da condenação colegiada (LC 219/2025);
- **Confundir cassação** (vedada CF 15 caput) com perda/suspensão;
- Tratar alistamento de **estrangeiros/conscritos** como possível;
- Não aplicar **iniciativa popular** sem aferir os percentuais (1% + 5 estados + 0,3%);
- Considerar **militar < 10 anos** elegível sem afastamento.

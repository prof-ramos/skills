# Modulação de Efeitos das Decisões do STF

## Marco normativo

| | Conteúdo |
|---|---|
| **CF art. 102** | Competência do STF |
| **CF art. 103** | Legitimados ADI/ADC |
| **Lei 9.868/1999 art. 27** | Modulação em ADI/ADC |
| **Lei 9.882/1999 art. 11** | Modulação em ADPF |
| **CPC art. 927 §3** | Modulação em decisões com efeito vinculante |
| **CPC art. 535 §5-§8** | Inexigibilidade do título por norma declarada inconstitucional (constitucionalidade do mecanismo: Tema 360 STF) |
| **CPC art. 966 V** | Rescisória por norma inconstitucional |
| **Tema 733 STF (RE 730.462)** | Efeitos sobre coisa julgada |
| **Temas 881 + 885 STF** | Coisa julgada tributária |
| **Lei 13.655/2018 (LINDB 20-30)** | Decisões com consequências práticas |

## Conceito

| | Conteúdo |
|---|---|
| **Modulação de efeitos** | Restrição temporal ou material da declaração de inconstitucionalidade |
| **Função**: equilibrar nulidade (regra) com segurança jurídica |
| **Cabimento**: ADI + ADC + ADPF + RE com repercussão geral |
| **Quorum qualificado**: 2/3 dos ministros (8 dos 11), Lei 9.868 art. 27 |
| **Aplicação por simetria**: STJ + TJ em controle difuso |

## Lei 9.868 art. 27 (ADI/ADC)

```
Art. 27 - Ao declarar a inconstitucionalidade de lei ou ato
normativo, e tendo em vista razões de segurança jurídica ou de
excepcional interesse social, poderá o Supremo Tribunal Federal,
por maioria de dois terços de seus membros, restringir os
efeitos daquela declaração ou decidir que ela só tenha eficácia
a partir de seu trânsito em julgado ou de outro momento que
venha a ser fixado.
```

| | Conteúdo |
|---|---|
| **Quorum**: 2/3 (8 ministros) |
| **Fundamentos**: |
|   - **Segurança jurídica** |
|   - **Excepcional interesse social** |
| **Modalidades**: |
|   - **Eficácia ex nunc** (a partir do trânsito) |
|   - **Pro futuro** (a partir de data futura) |
|   - **Marco intermediário** (data específica) |

## Lei 9.882 art. 11 (ADPF)

```
Art. 11 - Ao declarar a inconstitucionalidade de lei ou ato
normativo, no processo de arguição de descumprimento de preceito
fundamental, e tendo em vista razões de segurança jurídica ou
de excepcional interesse social, poderá o Supremo Tribunal
Federal, por maioria de dois terços de seus membros, restringir
os efeitos daquela declaração ou decidir que ela só tenha
eficácia a partir de seu trânsito em julgado ou de outro
momento que venha a ser fixado.
```

| | Conteúdo |
|---|---|
| **Aplicação em ADPF** | Idêntica à ADI |
| **Quorum**: 2/3 |
| **Fundamentos**: segurança jurídica + interesse social |

## CPC art. 927 §3: controle difuso

| | Conteúdo |
|---|---|
| **Modulação em decisões com efeito vinculante** (ações repetitivas, IRDR, RE/REsp repetitivo) |
| **Quorum**: maioria absoluta do colegiado |
| **Aplicação**: STJ + TJ + outros tribunais |
| **Fundamento**: segurança jurídica + interesse social |

## Tema 733 STF (RE 730.462): efeitos sobre coisa julgada

| | Conteúdo |
|---|---|
| **Tese** | A decisão do STF que declara a constitucionalidade ou a inconstitucionalidade de preceito normativo não produz a automática reforma ou rescisão das decisões anteriores em sentido diverso: exige recurso próprio ou ação rescisória, observado o prazo decadencial |
| **Cabe rescisória** (CPC 966 V), no prazo decadencial de 2 anos (CPC 975); na hipótese do CPC 535 §8, o termo inicial conta do trânsito em julgado da decisão do STF |
| **Efeitos**: |
|   - **Para o futuro**: imediata aplicação |
|   - **Para o passado** com coisa julgada: exige rescisória |
| **Modulação**: STF pode estabelecer efeitos diferenciados |
| **Aplicação prática**: muito comum em direito tributário |

## Temas 881 + 885 STF: coisa julgada tributária

| | Conteúdo |
|---|---|
| **Temas 881 (RE 949.297) + 885 (RE 955.227)**: tese conjunta sobre os limites da coisa julgada nas relações tributárias de trato sucessivo |
| **Decisões em ação direta ou em repercussão geral**: interrompem automaticamente os efeitos temporais das decisões transitadas em julgado nas relações tributárias de trato sucessivo |
| **Decisões em controle incidental anteriores ao regime de repercussão geral**: NÃO impactam automaticamente a coisa julgada |
| **Observância**: irretroatividade + anterioridade anual + noventena/anterioridade nonagesimal, conforme a natureza do tributo |
| **Temas 733 + 881-885**: aplicam-se conjuntamente |

## Quem pode pedir modulação

| | Conteúdo |
|---|---|
| **Legitimados ativos** da ADI (CF 103) |
| **Amicus curiae** (CPC 138), em manifestações |
| **AGU**, em curadoria da norma (CF 103 §3) |
| **PGE / PGM**, em ADIs estaduais e municipais |
| **MP**, em sua atuação |
| **Particulares**, por intervenção anômala (em RE) ou amicus curiae |
| **STF**: pode modular de ofício |

## Procedimento

| Fase | Conteúdo |
|---|---|
| **Petição inicial** | Pedido de modulação fundamentado |
| **Manifestações**: AGU + PGR + amicus |
| **Análise pelo relator** | Sugere modulação ao Plenário |
| **Votação**: quorum qualificado (2/3) |
| **Acórdão**: define a modulação aplicável |
| **Embargos de declaração**: cabíveis para esclarecer modulação |
| **Modulação posterior**: cabe modulação suplementar (incomum) |

## Fundamentos da modulação

### Segurança jurídica

| | Conteúdo |
|---|---|
| **Estabilidade das relações jurídicas** | Constituídas sob a norma declarada inconstitucional |
| **Proteção da confiança legítima**: contribuintes / administrados que agiram conforme a lei |
| **Boa-fé**: aplicação imediata pode prejudicar quem agiu conforme a norma |
| **STF**: tem aplicado em inúmeros casos |

### Excepcional interesse social

| | Conteúdo |
|---|---|
| **Impactos econômicos massivos** | Repercussão sobre o orçamento público |
| **Continuidade de serviços públicos** |
| **Função social**: proteção de direitos coletivos |
| **STF**: tem aplicado quando o impacto é expressivo |

## Casos paradigmáticos

### ICMS-Difal (Tema 1.093 STF)

| | Conteúdo |
|---|---|
| **Decisão** (RE 1.287.019 + ADI 5.469, 24/02/2021): a cobrança do Difal do ICMS (EC 87/2015) pressupõe lei complementar com normas gerais |
| **Modulação**: efeitos a partir de 2022 (exercício seguinte ao julgamento), ressalvadas as ações judiciais ajuizadas até 24/02/2021 |
| **Tributos cobrados antes**: mantidos |
| **Desdobramento**: editada a LC 190/2022; nas ADIs 7.066, 7.070 e 7.078 (29/11/2023), o STF assentou que a LC 190/2022 observa apenas a anterioridade nonagesimal (cobrança a partir de 90 dias de sua publicação, em 2022) |

| | Conteúdo |

## Redação

- Articular segurança jurídica + interesse social com dados concretos.
- Indicar impactos fiscais + sociais + setoriais.
- Citar Temas + dispositivos legais com precisão.

## Erros a evitar

- A regra é a nulidade ex tunc, ressalvada a modulação cabível.
- A coisa julgada não é automaticamente desconstituída pela decisão do STF (Tema 733).
- Os Temas 881-885 observam a irretroatividade e a anterioridade tributária (anual e nonagesimal, conforme o tributo).
- Nos Temas 881-885, só as decisões em ação direta ou em repercussão geral interrompem automaticamente os efeitos da coisa julgada de trato sucessivo; as decisões incidentais anteriores ao regime de RG não.
- A modulação não se confunde com a mutação constitucional.
- O pedido de modulação exige fundamento concreto, mesmo quando formulado por particular.
- A modulação pressupõe fundamentação em segurança jurídica ou excepcional interesse social.
- A modulação exige quórum qualificado de 2/3 em ADI/ADC/ADPF.
- As consequências práticas observam a LINDB 20-30.
- A modulação é faculdade do STF, não decisão obrigatória.
- A modulação em causas de impacto massivo exige análise concreta.
- A rescisória observa o prazo de 2 anos (CPC 975).
- A modulação opera, em regra, para frente, salvo fundamento específico.
- A inexigibilidade superveniente segue o CPC 535 §5-§8.
- A modulação tributária observa a anterioridade.
- O Tema 1.245 STJ admite rescisória apenas para adequar julgados anteriores a 13.05.2021 à modulação do Tema 69.
- A modulação no controle difuso segue o CPC 927 §3.
- O efeito vinculante (CPC 927) não se confunde com a modulação.
- A modulação é decisão judicial, não administrativa.

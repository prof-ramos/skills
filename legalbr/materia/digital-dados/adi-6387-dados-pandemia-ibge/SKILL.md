# ADI 6387: Dados Pandemia / IBGE

## Identificação

| | Conteúdo |
|---|---|
| Ações | **ADI 6387 + 6388 + 6389 + 6390 + 6393** |
| Autores | PT + PSB + PSDB + outros |
| Relatora | Min. **Rosa Weber** |
| Cautelar | Deferida em 24/04/2020; referendada pelo Plenário em **07/05/2020** |
| Desfecho | Ações julgadas **prejudicadas** em 17/11/2020 (perda superveniente de objeto) |
| Objeto | MP 954/2020 |

## Tese estruturante

| | Conteúdo |
|---|---|
| Resultado | Cautelar suspendendo a MP 954/2020 deferida (24/04/2020) e referendada pelo Plenário (07/05/2020); a MP caducou sem conversão e as ADIs 6387, 6388, 6389, 6390 e 6393 foram julgadas **prejudicadas** por perda superveniente de objeto (17/11/2020), sem resolução de mérito |
| Legado | A fundamentação da cautelar (proteção de dados como direito fundamental autônomo) permaneceu como marco e foi positivada pela EC 115/2022 (CF 5 LXXIX) |
| Tese | **Proteção de dados pessoais** é direito fundamental |
| Base | CF 5 X (intimidade) + XII (sigilo) + dignidade |
| Princípios | Finalidade + necessidade + proporcionalidade + transparência |

## MP 954/2020

| | Conteúdo |
|---|---|
| Conteúdo | Obrigava operadoras de telecom a fornecer **nome + telefone + endereço** ao IBGE para pesquisas durante pandemia |
| Vício | Ausência de base legal específica + falta de proporcionalidade + ausência de finalidade clara |
| **Eficácia** | Suspensa em cautelar, depois caducada |

## EC 115/2022

| | Conteúdo |
|---|---|
| Inseriu | **CF 5 LXXIX**: direito à proteção dos dados pessoais, inclusive nos meios digitais |
| Inseriu | **CF 21 XXVI**: competência da União sobre proteção de dados |
| Status | Eleva LGPD à dignidade constitucional |

## Princípios da proteção de dados

| | Conteúdo |
|---|---|
| **Finalidade** | Propósito legítimo + específico |
| **Necessidade** | Mínimo necessário |
| **Proporcionalidade** | Adequação + necessidade + proporcionalidade |
| **Transparência** | Informação ao titular |
| **Segurança** | Proteção técnica + organizacional |
| **Autodeterminação informativa** | Controle sobre os próprios dados |

## LGPD (Lei 13.709/2018)

| | Conteúdo |
|---|---|
| Vigência | Setembro/2020 |
| **ANPD** | Autoridade Nacional de Proteção de Dados |
| **Sanções** | Até 2% do faturamento + multa |
| **Bases legais** | LGPD art. 7 + 11 |
| Diálogo | ADI 6387 antecipou a tese |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Compartilhamento de dados sem base legal | **Vedado** (ADI 6387) |
| Proteção de dados como direito fundamental | **Sim** (CF 5 LXXIX) |
| Pandemia | Não autoriza coleta indiscriminada |
| LGPD + ANPD | Aplicáveis |
| Anonimização | Atenuante (LGPD) |
| Compartilhamento via Decreto | Insuficiente |
| Dados sensíveis | LGPD art. 11 (proteção reforçada) |
| Crianças | Consentimento dos pais (LGPD 14) |
| Direito de acesso | Garantido (LGPD 18) |
| Indenização | Cabível (LGPD 42) |

## Erros a evitar

- Compartilhar dados pessoais sem base legal específica;
- Tratar proteção de dados como direito infraconstitucional (CF 5 LXXIX);
- Aplicar emergência sanitária como autorização ampla;
- Ignorar princípios da proporcionalidade + necessidade;
- Confundir anonimização com proteção total;
- Esquecer ANPD como autoridade;
- Aplicar consentimento sem informação adequada.

# RIPD: Relatório de Impacto à Proteção de Dados

## Marco legal

- **Lei 13.709/2018 (LGPD)**: art. **38** + 5 XVII + 10 §3 + 32;
- **ANPD Resolução CD/ANPD 23/2024** (Agenda Regulatória 2025-2026, alterada pela Res. CD/ANPD 31/2025: RIPD entre os temas prioritários; ainda **sem regulamento específico** de RIPD até 2026);
- **ANPD Guia Modelo RIPD** (2023);
- **GDPR art. 35** (DPIA, referência internacional);
- **Resolução CD/ANPD 2/2022** (pequeno porte);
- Recomendações ENISA + WP29 (mantidas pelo EDPB).

## Conceito (LGPD art. 5 XVII)

> "Relatório de Impacto à Proteção de Dados Pessoais: documentação do controlador que contém a descrição dos processos de tratamento de dados pessoais que podem gerar **riscos às liberdades civis e aos direitos fundamentais**, bem como medidas, salvaguardas e mecanismos de mitigação de risco."

## Quando é necessário (art. 38 + ANPD)

| | Conteúdo |
|---|---|
| **ANPD pode requisitar** | LGPD art. 38 caput |
| **Boa prática** | Em operações de **alto risco** |
| **Operações sensíveis** | Dados pessoais sensíveis (art. 11) em larga escala |
| **Decisões automatizadas** | Com efeitos significativos (art. 20) |
| **Monitoramento sistemático** | De pessoas |
| **Vigilância pública** | Espaços públicos |
| **Crianças/adolescentes** | LGPD art. 14 + ECA |
| **Transferência internacional** | Para país sem nível adequado |
| **Novas tecnologias** | IA, biometria, geolocalização contínua |

## Conteúdo mínimo (LGPD art. 38)

| | Conteúdo |
|---|---|
| **a)** | **Descrição** dos tipos de dados pessoais coletados |
| **b)** | **Metodologia** utilizada para tratamento + garantia da segurança |
| **c)** | **Análise** do controlador sobre medidas + salvaguardas + mecanismos de mitigação |

## Estrutura recomendada pela ANPD

| Seção | Conteúdo |
|---|---|

| **3. Análise da necessidade + proporcionalidade** | Justificativa |
| **4. Identificação de riscos** | Para titulares + organização |
| **5. Avaliação de probabilidade × impacto** | Matriz de risco |
| **6. Medidas mitigadoras** | Técnicas + organizacionais |
| **7. Consultas** | Encarregado + áreas envolvidas + (eventualmente) titulares |
| **8. Conclusão** | Decisão sobre prosseguimento |
| **9. Revisões** | Periódicas + após mudanças |

## Erros a evitar

- Tratar RIPD como **opcional sempre**: é obrigatório em alto risco;
- Esquecer **categorias especiais** (LGPD 11), sempre exigem RIPD em larga escala;
- Aplicar RIPD **genérico** sem especificidade ao tratamento;
- Não **documentar** medidas mitigadoras adotadas;
- Esquecer **revisão periódica** + após mudanças;
- Confundir RIPD com **inventário de dados** (escopos distintos);
- Não envolver **encarregado** na elaboração;
- Ignorar **direitos do titular** (LGPD 18) no diagnóstico;
- Aplicar **GDPR DPIA** literalmente sem adequação brasileira;
- Esquecer **transferência internacional** (LGPD 33-36);
- Não consultar **áreas internas** + (eventualmente) titulares;
- Não atualizar após **incidente** ou nova tecnologia (IA).

# Assinatura Eletrônica + Digital

## Marco legal

- **Lei 14.063/2020** (23/09/2020);
- **MP 2.200-2/2001** (ICP-Brasil);
- **Decreto 10.543/2020** (regulamento);
- **CC 219** (presunção de declaração);
- **Lei 11.419/2006** (processo eletrônico);
- **Lei 14.382/2022** (SERP);
- **Reso CFM 2.314/2022** (telemedicina + ICP-Brasil);
- LGPD (proteção de dados biométricos).

## Conceito (Lei 14.063 art. 3)

| | Conteúdo |
|---|---|
| **Assinatura eletrônica** | Confirma autoria + integridade de documento eletrônico |
| **ICP-Brasil** | Infraestrutura de Chaves Públicas |
| **AC (Autoridade Certificadora)** | Emite certificados |
| **Token + cartão + nuvem** | Suportes |

## Três níveis (Lei 14.063 art. 4)

### Simples

| | Conteúdo |
|---|---|
| **Identificação** | Por meio convencionado |
| **Aceita** | Por acordo das partes |
| **Exemplos** | E-mail + login + senha + biometria não-certificada |
| **Aplicação** | Atos de baixo impacto |
| **Validade** | Entre as partes |

### Avançada

| | Conteúdo |
|---|---|
| **Certificado não-ICP** | Mas com integridade comprovada |
| **Critérios** | Vinculação ao signatário + capacidade de detectar alterações |
| **Aceitação** | Conforme convenção das partes ou normas |
| **Exemplos** | DocuSign + Clicksign + outras plataformas |
| **gov.br** | Assinatura avançada via gov.br |

### Qualificada (ICP-Brasil)

| | Conteúdo |
|---|---|
| **Certificado ICP-Brasil** | Emitido por AC credenciada |
| **Presunção** | Autenticidade + integridade (MP 2.200-2 art. 10 §1) |
| **Validade plena** | Equivale à manuscrita |
| **Suporte** | Token + cartão + nuvem |
| **AC raiz** | ITI |
| **Aplicação** | Atos mais sensíveis |

## ICP-Brasil (MP 2.200-2)

| | Conteúdo |
|---|---|
| **Estrutura** | Hierarquia de ACs |
| **AC Raiz** | Instituto Nacional de Tecnologia da Informação (ITI) |
| **AC nível 1** | Bancos + cartórios + entidades |
| **AC nível 2** | Geralmente nível operacional |
| **Comitê Gestor** | Define normas |
| **Tipos de certificado** | A1, A3, e-CPF, e-CNPJ |

## Tipos de certificado ICP-Brasil

| Tipo | Conteúdo |
|---|---|
| **A1** | Software (em arquivo): 1 ano |
| **A3** | Hardware (token, cartão): 3 anos |
| **A4, S1-S4** | Outros tipos específicos |
| **e-CPF** | PF |
| **e-CNPJ** | PJ |
| **NF-e + outros** | Específicos |

## Aplicação (Lei 14.063 art. 5)

| Cenário | Nível mínimo |
|---|---|
| **Interação com Poder Público (impacto baixo)** | Simples ou avançada |
| **Interação com Poder Público (impacto médio)** | Avançada |
| **Interação de impacto alto** | **Qualificada** |
| **Prescrição médica controlada** | Qualificada (Reso CFM) |
| **PJ + atos formais** | Avançada ou qualificada |

## Erros a evitar

- Confundir **simples** (sem certificado) com **qualificada** (ICP-Brasil);
- Aceitar **assinatura simples** em atos de impacto alto (Lei 14.063 art. 5);
- Esquecer **gov.br como avançada** (não qualificada);
- Aplicar **assinatura escaneada** como digital (não tem força);
- Confundir **MP 2.200-2** (ICP-Brasil) com **Lei 14.063** (classifica os tipos);
- Não verificar **validade do certificado** (expiração);
- Esquecer **LGPD** + dado biométrico (categoria sensível);
- Aplicar **eIDAS UE** literalmente no Brasil (regimes próprios);
- Não documentar **convenção das partes** em avançada;
- Confundir certificado A1 (software) com A3 (hardware);
- Esquecer Reso CFM 2.314 (telemedicina exige ICP-Brasil para prescrição);
- Aplicar **gov.br** em atos que exigem ICP-Brasil qualificada.

# ANPD: Natureza e Autonomia (LGPD)

## Identificação

| | Conteúdo |
|---|---|
| Tema | Estrutura e autonomia da ANPD |
| Marco normativo | LGPD (Lei 13.709/2018) + Lei 13.853/2019 + Lei 14.460/2022 + EC 115/2022 |
| Controle concentrado em dados | ADIs 6387 a 6393 (MP 954/2020, cautelar referendada); ADI 6649 e ADPF 695 (Decreto 10.046/2019) |

## ANPD: natureza atual

| | Conteúdo |
|---|---|
| **Lei 14.460/2022** | Transformou em **AUTARQUIA DE NATUREZA ESPECIAL** |
| **Independência** | Funcional + técnica + decisória + administrativa |
| Mandatos | Conselho diretor com mandatos fixos |
| Vinculação | Presidência (autonomia preservada) |

## Estrutura da ANPD

| | Conteúdo |
|---|---|
| **Conselho Diretor** | 5 membros + mandatos |
| **CNPD** | Conselho Nacional de Proteção de Dados (multissetorial) |
| **Procuradoria** | Especializada |
| **Carreiras** | Servidores próprios |

## LGPD: pilares

| | Conteúdo |
|---|---|
| **Bases legais** | LGPD art. 7 + 11 (sensíveis) |
| **Princípios** | LGPD art. 6 |
| **Direitos** | LGPD art. 18 |
| **Sanções** | Até 2% do faturamento + multa diária |
| **DPO** | Encarregado obrigatório |
| **RIPD** | Relatório de Impacto |

## EC 115/2022

| | Conteúdo |
|---|---|
| **CF 5 LXXIX** | Direito à proteção de dados |
| **CF 21 XXVI** | Competência exclusiva da União |
| Status | Eleva proteção a direito fundamental |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Tratamento de dados | LGPD + ANPD |
| Violação | Sanção administrativa + civil + penal (em hipóteses) |
| Encarregado | Obrigatório (LGPD 41) |
| Transferência internacional | LGPD 33-36 |
| Dados sensíveis | LGPD 11 (base reforçada) |
| Crianças | Consentimento parental (LGPD 14) |
| Direito de acesso/portabilidade | LGPD 18 |
| Anonimização | LGPD 12 |
| **ANPD** | Autarquia especial (Lei 14.460) |

## Independência da ANPD

| | Conteúdo |
|---|---|
| Decisões técnicas | Sem ingerência política |
| Sanções | Aplicação autônoma |
| Padrões internacionais | Adequação |
| **EDPB + GDPR (UE)** | Diálogo regulatório |
| **Convenção 108+ Conselho da Europa** | Brasil em adesão |

## Erros a evitar

- Tratar ANPD como vinculada hierarquicamente à Presidência (Lei 14.460);
- Aplicar LGPD sem o filtro constitucional da EC 115;
- Ignorar bases legais específicas (LGPD 7 + 11);
- Esquecer obrigação de **encarregado** (LGPD 41);
- Tratar anonimização como proteção total;
- Aplicar sanção sem **due process**;
- Confundir LGPD com Marco Civil (Lei 12.965/2014).

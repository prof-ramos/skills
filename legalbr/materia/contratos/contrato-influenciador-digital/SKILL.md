# Contrato com Influenciador Digital

## Base legal

| Diploma | Conteúdo |
|---|---|
| **CC 20** | Direito de imagem: uso requer autorização específica |
| **CC 421-A + 422** | Liberdade contratual + boa-fé |
| **CDC 36-38** | Publicidade: identificação e veracidade (relação anunciante x consumidor) |
| **Código CONAR + Guia de Publicidade por Influenciadores (2021/atualizado 2024)** | Autorregulação publicitária: identificação (#publi) |
| **Lei 9.610/98** | Direito autoral sobre conteúdo produzido |
| **LGPD** | Dados de seguidores e métricas |
| **Marco Civil** | Lei 12.965/14 |
| **CDC 7 §ú + 18 + 25 §1** | Responsabilidade solidária dos integrantes da cadeia de fornecimento (anunciante e influenciador) por publicidade enganosa |
| Res. ANS / ANVISA / BACEN | Setores regulados (saúde, financeiro) |

## Tipologia

| Tipo | Característica |
|---|---|
| **Publipost único** | Uma peça (story, reel, post) |
| **Campanha** | Pacote de peças com cronograma |
| **Embaixador** | Vínculo de longo prazo + exclusividade |
| **Affiliate** | Comissão por venda |
| **Co-criação** | Produto/coleção em conjunto |
| **Live commerce** | Transmissão ao vivo com vendas |

## Estrutura mínima

| Bloco | Conteúdo |
|---|---|
| Partes | Anunciante + Influenciador (PF ou PJ) + agência (se houver) |
| Briefing | Anexo técnico com diretrizes |
| Entregáveis | Tipo, quantidade, plataforma, datas |
| **Identificação publicitária** | #publi + tag de parceria + diretrizes CONAR |
| Direito de imagem | Cessão + escopo + prazo + território |
| Direito autoral sobre conteúdo | Cessão / licença / coautoria |
| **Métricas** | KPIs, relatórios, validação |
| Exclusividade | Categoria + prazo |
| Takedown / aprovação prévia | Direito do anunciante |
| Conduta / morality clause | Hipóteses de rescisão |
| Pagamento | Datas + condicionantes |
| Indenidade | Por violação de imagem/PI |
| LGPD | Tratamento de dados de público |

## Cláusulas obrigatórias

| # | Cláusula | Norma |
|---|---|---|
| 1 | **Entregáveis detalhados** (formato, plataforma, duração, hashtags) | Briefing anexo |
| 2 | **Identificação publicitária obrigatória** (#publi / "Parceria paga com…") | CONAR + CDC 36 |
| 3 | **Diretrizes de mensagem** + vedação de claims não comprovados | CDC 37 + CONAR |
| 4 | **Direito de imagem** com escopo (mídias, prazo, território) | CC 20 |
| 5 | **Direito autoral** sobre o conteúdo (licença ou cessão) | Lei 9.610 art. 49 |
| 6 | **Métricas** (alcance, impressões, engajamento) + auditoria | Relatórios oficiais |
| 7 | **Exclusividade** (categoria de produto + prazo) | Boa-fé |
| 8 | **Aprovação prévia** ou **takedown** em até X horas | Indenidade |
| 9 | **Pagamento** vinculado à entrega + métricas mínimas | Condicionamento |
| 10 | **Indenidade** por violação de PI ou ofensa | Risco reputacional |
| 11 | **Conduta**: moral / crise / repúdio | Rescisão |
| 12 | **LGPD**: dados de público | Co-controle ou separação |
| 13 | Confidencialidade do briefing | CC 422 |

## Identificação publicitária: CONAR

| Diretriz | Conteúdo |
|---|---|
| **Princípio** | Toda publicação patrocinada deve ser **identificável** como tal pelo consumidor médio |
| Tags aceitas | #publi, #publicidade, #ad, "Parceria paga com @marca" |
| Ferramenta nativa | "Conteúdo de marca" / "Branded content" do Instagram, TikTok, YouTube |
| Vedações | Esconder hashtag em meio a outras; usar #parceria isolado |
| Stories | Identificação **no início** + mantida durante |
| Vídeos longos | Identificação visível **na descrição** + verbal |
| Setores regulados | Acréscimo das regras ANVISA, ANS, BACEN, CVM, CFM (saúde, financeiro, jurídico) |

> **Cadeia de fornecimento (CDC 7 §ú, 18, 25 §1)**: anunciante e influenciador podem **responder solidariamente** por dano ao consumidor decorrente de publicidade enganosa quando o influenciador integra a cadeia de fornecimento (STJ, REsp 1.840.239, 4ª Turma, 2021).

## Direito de imagem (CC 20)

| Aspecto | Conteúdo |
|---|---|
| Natureza | Direito da personalidade: autorização **específica** |
| Forma | Escrita + escopo definido |
| **Escopo** | Mídias permitidas, plataforma, prazo, território, finalidade |
| Prazo | Definido (1 ano comum; perpétuo somente se altíssima contraprestação) |
| Vedações | Modificações que ofendam honra (CC 20 + CF 5 X) |
| **Imagem de menores** | Exige autorização dos pais ou responsáveis + observância do ECA |
| Reuso | Sempre exige novo termo se fora do escopo |

## Direito autoral sobre conteúdo

| Modelo | Conteúdo |
|---|---|
| **Licença não exclusiva** | Influenciador mantém titularidade, anunciante usa nas mídias autorizadas |
| **Licença exclusiva** | Anunciante uso exclusivo no escopo |
| **Cessão integral** | Total transferência: caro |
| **Coautoria** | Em co-criação |
| Direitos morais | Inalienáveis (Lei 9.610 art. 27): citar autor |

## Métricas e entregáveis

| Métrica | Definição |
|---|---|
| **Alcance** | Pessoas únicas que viram |
| **Impressões** | Visualizações totais |
| **Engajamento** | Curtidas + comentários + compartilhamentos / alcance |
| **CPV / CPE** | Custo por view / engajamento |
| **Cliques** / link em bio | Direcionamento |
| **Conversão** | Vendas atribuídas (UTM, cupom) |

> Exigir **relatório oficial** da plataforma (printscreen do dashboard): vedar dados auto-declarados.

## Cláusulas acidentais

| Cláusula | Função |
|---|---|
| **Exclusividade de categoria** | 30-90 dias após última peça |
| **Right of first refusal** | Próxima campanha |
| **Morality clause** | Rescisão por conduta: exemplos objetivos |
| **Recall** | Direito de remoção em crise |
| **Whitelisting / dark posts** | Anunciante impulsiona o conteúdo do influenciador |
| **Cap de comentários negativos** | Falsa: vedar |
| **Cláusula penal** por descumprimento de identificação | Útil: riscos CONAR |
| **Insurance** | E&O para grandes contratos |

## LGPD

| Item | Regra |
|---|---|
| Dados de seguidores | Anunciante e influenciador podem ser **co-controladores** |
| Sorteios / promoções | Coleta direta exige base legal + Decreto 70.951/72 |
| Métricas agregadas | Permitidas |
| Comentários / DMs | Não compartilhar sem base legal |

## Setores regulados: alertas

| Setor | Norma |
|---|---|
| Saúde | ANVISA RDC 96/2008 + CFM Res. 1.974/11 (médicos) |
| Financeiro / investimentos | **Res. CVM 20/2021** (analista de valores mobiliários) + orientação CVM: divulgação profissional e remunerada de análise exige credenciamento |
| Bebidas alcoólicas | Lei 9.294/96 |
| Tabaco | Vedada (CF 220 §4) |
| Apostas | Lei 14.790/23 (bets): restrições |
| Crianças / adolescentes | CONAR + Res. CONANDA 163/2014: vedação de publicidade dirigida |

## Roteiro de redação

1. **Briefing anexo** com peças, datas, plataformas, hashtags;
2. **Identificação publicitária** obrigatória + diretrizes CONAR + multa por descumprimento;
3. **Direito de imagem** com escopo (mídias, prazo, território);
4. **Direito autoral**: licença ou cessão com prazo;
5. **Métricas mínimas** + relatórios oficiais;
6. **Exclusividade de categoria** com prazo razoável;
7. **Aprovação prévia** + takedown em até 24h;
8. **Morality clause** objetiva;
9. **Pagamento** condicionado à entrega + métricas;
10. **Indenidade** + LGPD + setor regulado se aplicável.

## Erros a evitar

- Não exigir **#publi** ou tag de parceria (CONAR + CDC 36: anunciante responde);
- Cessão de imagem **perpétua** com pagamento único (desproporcional);
- Esquecer **escopo** (mídias, prazo, território): autorização vira controversa;
- Métricas **autodeclaradas** sem relatório oficial;
- Exclusividade **vaga** ou geográfica indefinida;
- Sem **aprovação prévia** em setor regulado (ANVISA, CVM);
- Esquecer **moralidade** com critério objetivo;
- Tratar influencer como **fornecedor** sem indenidade própria;
- Não regular **takedown** em crise;
- Pagar **antes da entrega** sem condicionantes;
- Esquecer **LGPD** em sorteios/coletas;
- Publicidade infantil dirigida a crianças (CONANDA 163);
- Influenciador de investimento atuando como analista **sem credenciamento CVM** (Res. CVM 20/2021);
- Confundir licença autoral com cessão (Lei 9.610: interpretação restritiva);
- Não prever **solidariedade** ou indenidade reversa (cadeia de fornecimento: CDC 7 §ú, 18, 25 §1).

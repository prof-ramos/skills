# Penhor - Instrumento

## Base legal

| Norma | Conteúdo |
|---|---|
| **CC 1.419-1.430** | Disposições gerais: direitos reais de garantia |
| **CC 1.431-1.472** | Penhor (convencional, legal, rural, industrial/mercantil, de direitos, de títulos, de veículos) |
| **CC 1.428** | **Vedada cláusula comissória** (pacto que autoriza o credor a ficar com a coisa em caso de inadimplemento) |
| **DL 167/67** | Cédula de Crédito Rural (CCR/penhor rural) |
| **DL 413/69** | Cédula de Crédito Industrial |
| **Lei 6.840/80** | Cédula de Crédito Comercial |
| **Lei 10.931/04** | CCB + integração de garantias |
| **Lei 6.015/73 art. 127** | Registro no RTD |
| **Lei 14.711/23** | Marco Legal das Garantias: extensão a algumas modalidades |

## Natureza

| | Conteúdo |
|---|---|
| Definição | Direito real de garantia sobre **bem móvel** alheio para garantia de obrigação |
| Acessório | Segue a sorte da obrigação principal (CC 1.420) |
| Indivisível | Recai sobre a totalidade da coisa (CC 1.421) |
| Sequela | Acompanha a coisa em poder de terceiro (CC 1.422) |
| Preferência | Credor pignoratício prefere quirografários (CC 1.422) |
| Modalidades | Convencional, legal, rural (agrícola/pecuário), industrial, mercantil, de direitos, de títulos de crédito, de veículos |

## Modalidades

| Modalidade | Conteúdo |
|---|---|
| **Convencional** (CC 1.431) | Tradição ao credor; pertence ao regime geral |
| **Legal** (CC 1.467) | Hospedeiro sobre bagagem; dono do prédio rústico/urbano sobre coisas do locatário etc. |
| **Rural agrícola** (CC 1.442) | Sobre safras pendentes ou em vias de formação; tradição ficta |
| **Rural pecuário** (CC 1.444) | Sobre animais que se destinem à indústria pastoril |
| **Industrial** (CC 1.447) | Sobre máquinas, equipamentos, instalações; tradição ficta |
| **Mercantil** (CC 1.447) | Sobre mercadorias do estoque; tradição ficta |
| **De direitos** (CC 1.451) | Suscetível de cessão (créditos, ações etc.) |
| **De títulos de crédito** (CC 1.458) | Endosso pignoratício |
| **De veículos** (CC 1.461) | Específico: distingue-se da AF |

## Requisitos formais

| Modalidade | Forma |
|---|---|
| **Convencional comum** | Instrumento escrito + **tradição** ao credor ou a terceiro depositário (CC 1.431) |
| **Rural / industrial / mercantil** | Instrumento público ou particular + **registro no CRI do imóvel** onde se situam (CC 1.438) **ou no CRTD** quando bem móvel comum |
| **De direitos** | Escrito + **notificação ao devedor** do crédito empenhado (CC 1.453) |
| **De títulos de crédito** | **Endosso pignoratício** (CC 1.458 + LUG 19/20) |
| **De veículos** | Instrumento escrito + **registro no Detran** (CC 1.462) + seguro obrigatório (CC 1.463) |

> Sem tradição ou registro conforme modalidade → **penhor não nasce** como direito real (apenas crédito pessoal).

## Cláusulas essenciais

| Cláusula | Conteúdo |
|---|---|
| **Identificação das partes** | Devedor pignoratício + credor pignoratício |
| **Dívida garantida** | Origem + valor + prazo + juros + encargos |
| **Bem empenhado** | Descrição detalhada (espécie, quantidade, qualidade, marcas, números, localização) |
| **Depósito** | Quem fica com a posse: credor, devedor (rural/industrial/mercantil) ou terceiro |
| **Valor estimado** | Para fins de excussão e preferência |
| **Conservação** | Dever do depositário (CC 1.435) |
| **Vencimento antecipado** | CC 333 + deterioração; falta de reforço da garantia |
| **Excussão** | Forma de venda em caso de inadimplemento: judicial ou autorizada extrajudicial nos casos da lei |
| **Cláusula expressa de vedação ao pacto comissório** | Reforço do CC 1.428 |
| **Seguro** | Recomendado; obrigatório no penhor de veículos (CC 1.463) |
| **Cláusula de substituição/reforço** | Permite trocar bem deteriorado |
| **Cessão de crédito + penhor** | Acompanha o crédito (CC 287) |

## Penhor com tradição × tradição ficta

| | Conteúdo |
|---|---|
| **Tradição efetiva** (regra) | Bem é entregue ao credor: caracteriza o penhor comum |
| **Tradição ficta** (rural, industrial, mercantil) | Bem permanece com o devedor como **depositário**: cláusula expressa + registro |
| Sanção pela disposição indevida | Devedor-depositário que dispuser do bem responde civil e criminalmente (CP 168: apropriação indébita), vedada a prisão civil (SV 25 STF) |

## Penhor rural (CC 1.438-1.446 + DL 167/67)

| | Conteúdo |
|---|---|
| **Agrícola** | Safras (CC 1.442): máquinas, frutos pendentes, lenha, madeiras |
| **Pecuário** | Animais (CC 1.444): identificação por marcas/brincos |
| **Forma** | Cédula de Crédito Rural (CCR) ou instrumento com registro |
| **Registro** | CRI da localização do imóvel onde se encontra o bem (Lei 6.015 art. 167 I 9) |
| **Prazo** | Agrícola: até 3 anos prorrogáveis (CC 1.439); pecuário: até 4 anos prorrogáveis |
| **Excussão** | Judicial (CC 1.435 IV + CPC) ou extrajudicial (DL 167/67) via cédula |

## Penhor industrial e mercantil (CC 1.447-1.450)

| | Conteúdo |
|---|---|
| Objeto | Máquinas, aparelhos, materiais, instrumentos, instalações + mercadorias do estoque |
| Forma | Instrumento + **registro CRI da localização do estabelecimento** ou CRTD |
| Posse | Permanece com o devedor (depositário) |
| Substituição | Cláusula pode autorizar substituição automática do estoque |
| Cédula | Cédula de Crédito Industrial (DL 413/69) ou Comercial (Lei 6.840/80) |

## Penhor de direitos (CC 1.451-1.460)

| | Conteúdo |
|---|---|
| Objeto | Crédito suscetível de cessão (CC 1.451) |
| Forma | Instrumento escrito + **notificação ao devedor** do crédito empenhado (CC 1.453) |
| Cobrança | Credor pignoratício cobra diretamente o devedor do crédito (CC 1.455-1.456) |
| Quitação | Devedor do crédito empenhado paga ao credor pignoratício para se liberar |
| Endosso pignoratício | Para títulos cambiais (CC 1.458) |
| Penhor de ações | Forma do art. 39 LSA: averbação no livro de ações |
| Penhor de aplicações financeiras | Penhor sobre conta investimento: possível com aviso à IF |

## Penhor de veículos (CC 1.461-1.466)

| | Conteúdo |
|---|---|
| Objeto | Veículos automotores |
| Forma | Escritura pública ou particular + **registro no Detran** + averbação no CRTD |
| Posse | Permanece com o devedor (CC 1.461) |
| Seguro | Obrigatório contra furto, avaria etc. (CC 1.463) |
| Prazo | 2 anos prorrogáveis (CC 1.466) |
| Vencimento antecipado | Alienação do veículo sem anuência (CC 1.465) |

> Atenção: a AF de veículo (DL 911/69) é mais usada na prática que o penhor: penhor mantém a propriedade no devedor; AF transfere propriedade resolúvel ao credor.

## Vedação à cláusula comissória (CC 1.428)

| | Conteúdo |
|---|---|
| Regra | É **NULA** a cláusula que autoriza o credor a ficar com o bem em caso de inadimplemento |
| Razão | Evita enriquecimento sem causa + força equilíbrio entre dívida e valor do bem |
| Alternativa | Dação em pagamento **após o vencimento** (CC 356-357) é válida: é negócio autônomo |
| Jurisprudência | STJ reafirma a nulidade do pacto comissório (CC 1.428) |

## Excussão e venda

| Hipótese | Conteúdo |
|---|---|
| **Convencional** | Ação de execução por quantia certa (CPC 824): penhora recai prioritariamente sobre o bem empenhado |
| **Cédula rural / industrial / comercial** | Execução por título extrajudicial: bem empenhado responde primeiro |
| **Penhor de direitos** | Credor cobra diretamente o devedor do crédito |
| **Adjudicação** | Cabível pelo valor da avaliação |

## Extinção (CC 1.436)

| Inc. | Hipótese |
|---|---|
| I | Extinção da obrigação principal |
| II | Perecimento da coisa |
| III | Renúncia do credor |
| IV | Confusão (credor adquire o bem) |
| V | Adjudicação judicial, remição ou venda da coisa empenhada |

## Súmulas / Temas relevantes

| | Conteúdo |
|---|---|
| **CC 1.428** | Vedação ao pacto comissório (cláusula nula) |
| **Súm. 308 STJ** | Refere-se à hipoteca de incorporação; não se aplica ao penhor |
| Tradição ficta | Tradição ficta + registro são pressupostos das modalidades especiais |
| **Súm. 286 STJ** | Renegociação não impede a revisão de cláusulas anteriores |

## Roteiro prático

1. **Definir modalidade** (convencional, rural, industrial, mercantil, de direitos, de veículos): cada uma com requisito formal próprio.
2. **Descrever o bem** com identificação precisa (números de série, marcas, localização, quantidade, peso).
3. **Definir depósito**: quem retém a posse (regra comum: credor; rural/industrial/mercantil: devedor como depositário).
4. **Estipular dívida** + critério de excussão.
5. **Cláusula expressa de vedação ao pacto comissório** (reforço do CC 1.428).
6. **Cláusula de conservação / reforço / substituição**.
7. **Promover tradição efetiva** (convencional) ou **registro CRI/CRTD/Detran** (modalidades especiais).
8. **Notificar o devedor** do crédito quando penhor de direitos (CC 1.453).
9. **Considerar emissão de Cédula** (CCR, CCI, CCC, CCB): facilita execução.
10. **Cláusula de vencimento antecipado** + cross default.

## Erros a evitar

- Inserir **cláusula comissória** (CC 1.428: NULA);
- Constituir penhor rural/industrial **sem registro CRI**: não nasce direito real;
- Constituir penhor convencional sem **tradição** efetiva ao credor ou depositário;
- Pretender penhor sobre **imóvel**: incabível (hipoteca, AF ou anticrese);
- Ignorar **notificação ao devedor** do crédito no penhor de direitos (CC 1.453): sem ela, devedor paga ao cedente e libera-se;
- Esquecer **seguro** no penhor de veículos (CC 1.463);
- Confundir **penhor de veículo** com **AF de veículo**: regimes distintos (penhor mantém propriedade no devedor);
- Não obter **vênia conjugal** quando aplicável (penhor de bens da meação);
- Estipular prazos **superiores** aos legais sem prorrogação formal (rural 3-4 anos);
- Esquecer **endosso pignoratício** em títulos de crédito (CC 1.458);
- Não averbar **registro no CRTD** quando exigido: perde oponibilidade contra terceiros;
- Pretender **excussão extrajudicial** fora dos casos da lei (cédula rural/industrial/comercial);
- Tratar **bem fungível** (dinheiro, grãos a granel sem identificação) sob penhor: exige individualização;
- Não atualizar **registro** quando há substituição do estoque (mercantil).

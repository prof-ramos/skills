## Tema 698 STF: intervenção em omissão

| | Conteúdo |
|---|---|
| **Tese**: o Poder Judiciário, em situação excepcional, pode determinar a realização de políticas públicas previstas na Constituição quando configurada **omissão grave** ou **ineficiência crônica** da Administração |
| **Limites**: não substitui o gestor; controla legalidade + razoabilidade + minimalidade |
| **Princípios**: subsidiariedade + reserva do possível + mínimo existencial |
| **Aplicação**: saúde + educação + segurança + sistema penitenciário |

## ADPF 347 STF: estado de coisas inconstitucional

| | Conteúdo |
|---|---|
| **Caso paradigma**: sistema penitenciário |
| **Tese**: quando há violação **generalizada e sistemática** de direitos fundamentais + falência estrutural + necessidade de intervenção judicial estrutural |
| **Características**: |
|   - **Violação massiva** dos direitos |
|   - **Inércia** dos poderes |
|   - **Necessidade de medidas complexas + integradas** |
| **Decisão**: medidas estruturais, diálogo institucional + plano de ação |

## ADPF 854 + processo estrutural

| | Conteúdo |
|---|---|
| **Conceito**: processo que visa **reestruturar instituições** ou políticas para sanar lesão crônica |
| **Não é caso individual + clássico**: visa transformações estruturais |
| **Características**: |
|   - Pluralidade de partes |
|   - Decisão flexível + revisável |
|   - Monitoramento contínuo |
|   - Diálogo institucional |
| **Aplicação**: presídios + favelas + sistema de saúde + educação |
| **CPC 139 e 489**: fundamentação |

## Reserva do possível + mínimo existencial

### Reserva do possível

| | Conteúdo |
|---|---|
| **Conceito**: limitação **fática** (recursos finitos) + **jurídica** (legalidade orçamentária) |
| **CF 167**: vedações orçamentárias |
| **Pré-requisitos**: previsão na LDO + LOA |
| **Limite**: não pode ser invocada para frustrar o **mínimo existencial** |
| **ADPF 45**: construção jurisprudencial inicial |

### Mínimo existencial

| | Conteúdo |
|---|---|
| **Núcleo dos direitos fundamentais** | Resistente à reserva do possível |
| **Conceito**: condições mínimas para vida digna |
| **Compreende**: vida + saúde básica + educação fundamental + moradia + segurança alimentar |
| **STF**: tem reconhecido como núcleo irredutível |
| **Saúde**: mínimo existencial alcança medicamentos básicos + tratamentos essenciais |

## Tema 793 STF: solidariedade SUS

| | Conteúdo |
|---|---|
| **Tese**: os entes da federação, em decorrência da competência comum, são **solidariamente** responsáveis nas demandas prestacionais de saúde; compete à autoridade judicial direcionar o cumprimento conforme as regras de repartição de competências e determinar o ressarcimento a quem suportou o ônus financeiro |
| **Efeito**: o autor pode acionar qualquer ente; o cumprimento é direcionado ao ente competente, com ressarcimento |
| **Lei 8.080**: aplicação |
| **Limites**: não significa que qualquer pedido será atendido; análise concreta |

## Tema 6 STF + Tema 106 STJ: medicamentos individuais

### Tema 6 STF (medicamentos não incorporados, tese atual)

| | Conteúdo |
|---|---|
| **Regra** | A ausência de inclusão do medicamento nas listas do SUS (RENAME, RESME, REMUME) **impede, como regra geral, o fornecimento por decisão judicial**, independentemente do custo |
| **Exceção (requisitos cumulativos, ônus do autor)** | (a) negativa de fornecimento na via administrativa; (b) ilegalidade da não incorporação pela Conitec, ausência de pedido de incorporação ou mora na apreciação; (c) impossibilidade de substituição por medicamento das listas/PCDT; (d) eficácia e segurança respaldadas por evidências de alto nível (ensaios randomizados e revisão sistemática/meta-análise); (e) imprescindibilidade clínica comprovada por laudo fundamentado; (f) incapacidade financeira |
| **Deveres do juízo** | Analisar o ato da Conitec/negativa administrativa sem incursão no mérito; consultar o **NATJUS** (não decidir só com laudo do autor); em caso de deferimento, oficiar para avaliação de incorporação (sob pena de nulidade, CPC 489 §1 V-VI + 927 III) |
| **Embargos de declaração (2025)** | Não conhecidos, com esclarecimentos: **sem modulação** (tese aplicável aos processos em curso); a exigência de evidências de alto nível vale também para **doenças raras e oncológicas**; critérios consolidados nas **SV 60 e 61** |

### Tema 106 STJ

| | Conteúdo |
|---|---|
| **Tese**: medicamentos não incorporados exigem, cumulativamente: |
|   - Laudo médico fundamentado do médico assistente comprovando imprescindibilidade e ineficácia dos fornecidos pelo SUS |
|   - Incapacidade financeira de arcar com o custo |
|   - Registro na ANVISA |

## Tema 1.234 STF: medicamentos fora do SUS

| | Conteúdo |
|---|---|
| **Competência**: demandas de medicamentos não incorporados e oncológicos com registro na ANVISA tramitam na **Justiça Federal** quando o custo anual (PMVG/CMED) for igual ou superior a **210 salários mínimos**; efeitos de competência para ações ajuizadas após 19/09/2024 |
| **Custeio**: integral pela **União** nas ações federais; ressarcimento parcial pela União nas ações da Justiça Estadual (inclusive quanto a oncológicos), conforme as faixas da tese |
| **Tese alterada em 19/02/2026**: ajuste homologado pelo STF a partir de acordo na Comissão Intergestores Tripartite sobre a assistência farmacêutica oncológica |
| **Nulidade**: decisão que não analisar o ato da Conitec/negativa administrativa |
| **Bloqueio judicial de verbas**: excepcional |

## Tema 548 STF: educação infantil

| | Conteúdo |
|---|---|
| **Tese**: a educação básica em todas as suas fases (educação infantil, ensino fundamental e médio) é **direito fundamental** assegurado por normas de eficácia plena, exigível inclusive em juízo |
| **Direito subjetivo** | Pode ser exigido em juízo (creche e pré-escola, CF 208 IV) |
| **Cumprimento**: multa cominatória + medidas atípicas (CPC 139 IV) |

## Erros a evitar

- **Substituir o gestor** sem análise de capacidade + alternativas (Tema 698);
- **Concessão de medicamento individual** sem cumprir os requisitos cumulativos do Tema 6 STF (seis, alíneas a-f) e do Tema 106 STJ (três);
- **Decidir sem dialogar com a Administração**: ferindo princípio de cooperação;
- **Esquecer LINDB 20-30** ao decidir consequências práticas;
- **Aplicar reserva do possível** contra mínimo existencial;
- **Afastar mínimo existencial** sem análise concreta;
- **Concessão de bloqueio universal** sem análise de impacto sistêmico (Tema 1.234);
- **Tratar SUS como obrigado individualmente** sem analisar solidariedade (Tema 793);
- **Afastar o ressarcimento ao SUS pelas operadoras de planos de saúde** (constitucional, Tema 345 STF);
- **Aplicar Tema 698** indiscriminadamente: exige ausência ou deficiência grave do serviço;
- **Afastar separação de poderes** como princípio dirigente;
- **Admitir tutela contra Fazenda** vedada pela Lei 8.437 + 9.494;
- **Esquecer ADPF 347** ao tratar de violação massiva sistêmica;
- **Tratar processo estrutural** como caso individual (ADPF 854);
- **Desconsiderar capacidade orçamentária** (LRF art. 17);
- **Esquecer Tema 366 STF**: na omissão, a responsabilidade exige violação de dever jurídico específico de agir;
- **Admitir pedido de medicamento sem registro ANVISA** (Tema 6);
- **Concessão de vaga creche/pré-escola** sem análise concreta (Tema 548, análise);
- **Esquecer CONITEC** como instância técnica prévia;
- **Tratar princípios constitucionais** como cláusulas pétreas inflexíveis sem ponderação.

# Convênios e Transferências Voluntárias

## Marco normativo

| | Conteúdo |
|---|---|
| **CF 167 X + LRF 25** | Transferência voluntária: pressupostos |
| **Lei 14.133/2021 art. 184** | As disposições da Lei de Licitações aplicam-se, no que couber e na ausência de norma específica, aos convênios, acordos e ajustes |
| **Lei 8.666/93 art. 116** | Regime histórico dos convênios; a Lei 8.666 foi **REVOGADA** pela Lei 14.133/2021 (aplicável só a instrumentos celebrados sob sua vigência) |
| **Dec. 11.531/2023** | **Substituiu** Dec. 6.170/2007: novo regime federal |
| **Lei 13.019/2014 (MROSC)** | OSCs (regime autônomo) |
| **LC 101/2000 art. 25** | Pressupostos das transferências voluntárias |

## Transferência voluntária (LRF art. 25)

| | Conteúdo |
|---|---|
| Conceito | Entrega de recursos a outro ente federativo, **a título de cooperação**, sem decorrência de dispositivo constitucional/legal |
| **Pressupostos** | Existência de dotação + comprovação da regularidade do ente recebedor (CAUC) + cumprimento da LRF |
| **Vedações** | Para pagamento de pessoal ativo + inativo + serviço da dívida |
| **Áreas exigidas em LDO** | Educação + saúde + assistência |

## Conceito de convênio

| | Conteúdo |
|---|---|
| Natureza | Instrumento de **cooperação** entre Adm + ente público + OSC sem fins lucrativos para realização de objetivo de interesse comum |
| Distinção do contrato | **Sem interesses opostos** + sem fim lucrativo + sem remuneração |
| **Não é contrato** | Embora siga regime análogo (STF) |

## Espécies de instrumentos

| Espécie | Conteúdo |
|---|---|
| **Convênio** (Dec. 11.531) | Entre União + ente federativo + entidade privada **sem fins lucrativos** |
| **Contrato de repasse** (Dec. 11.531) | Operacionalizado por **agente financeiro oficial** (CEF/BB) |
| **Acordo de cooperação técnica / de adesão** (Dec. 11.531) | Parcerias **sem** transferência de recursos |
| **Termo de execução descentralizada (TED)** | Entre órgãos/entidades federais (intra-Administração; Dec. 10.426/2020) |
| **Termo de fomento/colaboração** | Quando OSC (Lei 13.019, regime próprio) |

## Plataforma Transferegov (antiga +Brasil/SICONV)

| | Conteúdo |
|---|---|
| Sistema | Federal, de gestão eletrônica |
| Função | Cadastro + plano de trabalho + execução + prestação de contas |
| **Obrigatoriedade** | Para todas as transferências federais voluntárias |
| Acesso | gov.br |

## Pressupostos para celebração

| Requisito | Conteúdo |
|---|---|
| **CAUC** | Cadastro de exigências para transferências voluntárias: regularidade fiscal + previdenciária + trabalhista + FGTS |
| **PCA** | Plano de Contratações Anual (Lei 14.133 art. 12) |
| **Dotação orçamentária** | Imprescindível |
| **Contrapartida** | Mínima por porte do ente (estados/municípios) |
| Habilitação | Documentação completa |

## Plano de trabalho (Dec. 11.531 art. 7)

| Item | Conteúdo |
|---|---|
| Identificação do objeto | Obrigatória |
| Metas + indicadores | Quantitativos + qualitativos |
| **Cronograma** físico-financeiro | Obrigatório |
| **Plano de aplicação** | Detalhado |
| Etapas + fases | Cronograma de desembolso |
| **Justificativa** | Necessidade + viabilidade |

## Contrapartida (Dec. 11.531 art. 9)

| | Conteúdo |
|---|---|
| Cálculo | Sobre o **valor total do objeto**; se financeira, depositada na conta específica conforme o cronograma de desembolso |
| **Percentuais** | Os mínimos, máximos e condições são os da **LDO vigente à época da celebração** (art. 9 §2), escalonados pelo porte e situação do ente |
| **Dispensa/redução** | Nas hipóteses autorizadas pela LDO |

## Execução

| | Conteúdo |
|---|---|
| **Conta bancária específica** | Obrigatória (Banco do Brasil ou CEF) |
| **Aplicação financeira** | Rendimentos compõem o convênio |
| **Aquisições** | Mediante regime análogo à Lei 14.133 |
| **Movimentação** | Por meio eletrônico; bloqueio do que não estiver no plano |

## Prestação de contas (Dec. 11.531 arts. 20-21)

| Fase | Conteúdo |
|---|---|
| Início | Concomitante à liberação da **primeira parcela** (art. 20) |
| **Final** | Até **60 dias** do término da vigência ou da consecução do objeto (art. 20 §2); saldos devolvidos em 30 dias |
| Conteúdo | Relatório de cumprimento + execução financeira + extratos + comprovantes |
| **Aprovação** | Total + parcial com ressalva + reprovação |
| **Reprovação** | Devolução + TCE + responsabilização |

## Tomada de Contas Especial (TCE)

| | Conteúdo |
|---|---|
| Fundamento | Lei 8.443/92 + IN TCU 71/2012 |
| Cabimento | Dano ao erário + não prestação de contas + irregularidade insanável |
| Procedimento | Apuração administrativa + envio ao TCU |
| **Decisão** | Julgamento de **contas** + débito + multa |
| **Tema 666 STF** | É prescritível a ação de reparação de danos à Fazenda Pública decorrente de ilícito civil (RE 669.069) |

## Sanções

| | Conteúdo |
|---|---|
| Suspensão | Imediata em caso de irregularidade |
| **Rescisão** | Por inexecução + irregularidade insanável |
| Restituição | Valores não comprovados + glosa |
| **CADIN** | Inscrição em caso de inadimplemento |
| **Sancionamento** Lei 14.133 art. 156 | Por extensão analógica |

## Diferenças com MROSC (Lei 13.019)

| Aspecto | Convênio (Dec. 11.531) | OSC (MROSC) |
|---|---|---|
| Partes | Adm + Adm; Adm + entidade sem fins lucrativos | Adm + OSC |
| Instrumento | Convênio + TED + contrato de repasse | Termo colaboração/fomento/cooperação |
| Chamamento | Para entidades sem fins lucrativos, regulamento próprio | **Obrigatório** salvo art. 30/31 |
| Plataforma | Transferegov | Transferegov |
| Vedação | Pessoal | Pessoal |

## Diferenças com PPP / contratos

| Aspecto | Convênio | Contrato |
|---|---|---|
| Interesses | Comuns | Opostos |
| Lucratividade | Sem | Pode haver |
| Remuneração | Sem | Com |
| Regime | Lei 14.133 art. 184 (no que couber) + Dec. 11.531 | Lei 14.133 |

## Erros a evitar

- Aplicar regime de **contrato administrativo** integralmente ao convênio (regime autônomo; Lei 14.133 art. 184 só no que couber);
- Admitir convênio **sem CAUC** (LRF 25);
- Permitir **gasto com pessoal ativo/inativo** com recursos do convênio (vedado);
- Tratar contratado da OSC como **vínculo público direto** (Súm. 331 TST);
- Não exigir **contrapartida** (dispensa requer LDO);
- Permitir convênio **sem plano de trabalho** detalhado;
- Aprovar prestação de contas **sem comprovação documental**;
- Tratar como imprescritível a **reparação de dano por ilícito civil contra a Fazenda** (Tema 666 STF: prescritível; Tema 897 STF: imprescritível apenas o ressarcimento por ato **doloso** de improbidade);
- Afastar **TCE** em ausência de prestação de contas (cabível);
- Confundir convênio com termo de colaboração (MROSC: regime distinto);
- Tratar TED como convênio externo (é intra-administração);
- Admitir contrato de repasse sem **agente financeiro oficial**;
- Permitir aquisições sem regulamento próprio + princípios CF 37;
- Não inscrever inadimplente no **CADIN** (Lei 10.522);
- Permitir movimentação fora da **conta específica** (vedada);
- Esquecer **suspensão** automática em caso de irregularidade.

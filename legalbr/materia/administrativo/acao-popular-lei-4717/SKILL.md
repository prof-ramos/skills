# Ação Popular (Lei 4.717/1965)

## Marco normativo

| | Conteúdo |
|---|---|
| **CF 5 LXXIII** | Direito fundamental do cidadão |
| **Lei 4.717/1965** | Lei da ação popular |
| **CF 129 III** | Atribuição do MP |
| **Lei 7.347/1985** | ACP (distinção) |
| **Lei 8.429/1992 + 14.230/2021** | Improbidade (institutos distintos, mas conexos) |

## Conceito (CF 5 LXXIII)

| | Conteúdo |
|---|---|
| Cabimento | Anular ato lesivo a **patrimônio público** + **moralidade administrativa** + **meio ambiente** + **patrimônio histórico e cultural** |
| Sujeito ativo | **Cidadão** (eleitor em pleno gozo dos direitos políticos) |
| Objeto | Tutela de **direitos difusos** + interesse público |
| Sujeito passivo | Adm + agentes + beneficiários do ato |

## Legitimidade ativa

| | Conteúdo |
|---|---|
| **Cidadão brasileiro** | Eleitor com **título de eleitor** + gozo dos direitos políticos |
| **Estrangeiro** | **Não legitimado** (STF) |
| Pessoa jurídica | **Não legitimada** (Súm. 365 STF) |
| **MP** | **Não autor**: atua como custos legis + pode assumir o polo ativo em caso de desistência (art. 9) |
| Adolescente 16+ | Se tiver título de eleitor, é legitimado |

## Legitimidade passiva (art. 6)

| | Conteúdo |
|---|---|
| **Ente público** | Que praticou o ato |
| **Autoridade + servidor** | Responsável |
| **Beneficiários** | Particulares que se beneficiaram |
| **Litisconsórcio passivo necessário** | (art. 6) |
| MP | Custos legis |

## Pressupostos do ato impugnável

| | Conteúdo |
|---|---|
| Ato | Comissivo ou omissivo |
| **Ilegalidade** | (objetiva: viola norma) |
| **Lesividade** | (real, presumida, ou potencial) |
| **Patrimônio amplo** (CF + art. 1 §1) | Bens + direitos + valores **econômicos + morais + ambientais + culturais** |

## Vícios do ato (art. 2)

| Inc. | Vício |
|---|---|
| **a** | **Incompetência** |
| **b** | **Vício de forma** |
| **c** | **Ilegalidade do objeto** |
| **d** | **Inexistência dos motivos** |
| **e** | **Desvio de finalidade** |

## Lesividade

| Tipo | Conteúdo |
|---|---|
| **Real** | Dano comprovado |
| **Presumida** | Decorrente da ilegalidade (art. 2 §p ún) |
| **Moral/imaterial** | Patrimônio ético: lesão à moralidade administrativa (CF 5 LXXIII) |
| **Ambiental** | Patrimônio difuso |

## Procedimento (Lei 4.717)

| Fase | Conteúdo |
|---|---|
| **Citação** | Adm + autoridade + beneficiários |
| **Resposta** | 20 dias |
| **Justificativa adequada** (art. 6 §3) | Adm pode atuar ao lado do autor se conveniente ao interesse público |
| **Audiência preliminar** | (art. 7) |
| **Instrução** + sentença | Rito ordinário com adaptações da Lei 4.717 |
| **MP** | Apura ainda que autor desista |

## Liminar (art. 5 §4)

| | Conteúdo |
|---|---|
| Cabível | Para suspender ato ilegal |
| Pressupostos | Plausibilidade + risco |
| Lei 8.437 | Vedações se contra Fazenda |
| Suspensão | Ao Presidente do Tribunal |

## Sentença + efeitos

| | Conteúdo |
|---|---|
| **Anulação** do ato | Efeito **ex tunc** |
| **Condenação** dos responsáveis | Solidária |
| **Reparação do dano** | Em favor da PJ lesada |
| **Sentença de procedência** | **Erga omnes** |
| **Sentença de improcedência** | Erga omnes **salvo** improcedência por insuficiência de prova (CF 5 LXXIII + art. 18) |

## Reexame necessário (art. 19)

| | Conteúdo |
|---|---|
| Sentença de **improcedência ou de carência** | Sujeita ao duplo grau **obrigatório** |
| **Procedência** | Em regra apelação |
| Inversão CPC 496 | **Não se aplica** o limite por valor |

## Prescrição (art. 21)

| | Conteúdo |
|---|---|
| Pretensão de anular | **5 anos** |
| Marco | Da publicação ou ciência |
| **Ressarcimento** | **Imprescritível em atos dolosos** (Tema 897 STF) |
| **Tema 666 STF** | É prescritível a ação de reparação de danos à Fazenda Pública decorrente de ilícito civil |

## Custas + ônus (CF 5 LXXIII + art. 5 §3)

| | Conteúdo |
|---|---|
| Autor de boa-fé | **Isento** de custas + sucumbência |
| Má-fé | **10x as custas** + sucumbência (art. 13) |
| **Honorários** | Cabem aos vencidos quando autor vencer |

| Aspecto | Popular | ACP |
|---|---|---|
| Legitimado | Cidadão | MP + Adm + DP + associações + entes |

| Objeto | Anulação de ato + ressarcimento | Tutela coletiva ampla |
| Pretensão | Desfazimento + indenização | Obrigação + indenização + tutela específica |
| **Coexistência** | Sim (instrumentos complementares) |

## Ação popular x Improbidade

| Aspecto | Popular | Improbidade |
|---|---|---|
| Legitimado autor | **Cidadão** | **MP + ente lesado** (ADIs 7.042/7.043) |
| Lei | 4.717 | 8.429 + 14.230 |
| Sanção | Anulação + ressarcimento | Sanções do art. 12 |
| Elemento subjetivo | **Ilegalidade objetiva** (não exige dolo) | **Dolo** (Tema 1.199 STF; exigência validada nas ADIs 7.156/7.236) |
| Prescrição | 5 anos (art. 21) | 8 anos (Lei 8.429 art. 23); prescrição intercorrente de **8 anos** mantida pelo STF (ADIs 7.156/7.236: invalidada a redução para 4 anos) |
| Foro | Sem prerrogativa | Sem prerrogativa (STF Pet 3.240 AgR) |

## Foro e competência

| | Conteúdo |
|---|---|
| **Local do ato** | Regra |
| **Ente atingido** | Determina ramo (federal/estadual) |
| **Foro privilegiado** | **NÃO há**: julga o juízo de 1º grau; o STF firmou na Pet 3.240 AgR (improbidade) que o foro penal por prerrogativa não se estende a ações civis |
| **STF Pet 3.211 QO** | Exceção construída para ação de improbidade contra Ministro do próprio STF (não é regra da ação popular) |

| | Conteúdo |
|---|---|

## Erros a evitar

- Admitir PJ ou MP como **autor** (vedado, Súm. 365 + art. 1);
- Exigir **dolo** do agente (requisito próprio da improbidade; a ação popular exige **ilegalidade objetiva**);
- Aplicar **prescrição decenal** ao ressarcimento (Tema 897: imprescritível só com dolo);
- Afastar a **lesividade presumida** em ato ilegal (art. 2 §p ún);
- Aplicar custas/sucumbência ao autor de **boa-fé** (CF 5 LXXIII);
- Aplicar **foro privilegiado** (Pet 3.240);
- Recusar legitimidade do **estrangeiro** sem reconhecer ressalva;
- Atribuir efeito **inter partes** à sentença de procedência (é erga omnes);
- Não realizar **reexame necessário** em improcedência;
- Tratar ato omissivo como **não cabível** (cabe: interpretação consolidada);
- Afastar a **liminar** sem analisar a plausibilidade real;
- Esquecer **MP** como assumidor do polo em desistência (art. 9);
- Esquecer **litisconsórcio passivo** dos beneficiários;
- Aplicar **Súm. 105 STJ** (sem honorários em MS) à ação popular (são distintas);
- Considerar **conexão automática** com improbidade (institutos distintos).

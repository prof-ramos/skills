## CCAF: Câmara de Conciliação e Arbitragem da AGU

### Conceito + finalidade

| | Conteúdo |
|---|---|
| **Vinculada à AGU** | Instituída por ato administrativo + Lei 9.469 art. 4 |
| **Função** | Solução consensual de conflitos entre **órgãos da União** ou entre **União e outros entes** |
| **Não é arbitragem privada** | Procedimento administrativo cooperativo |
| **Eficácia**: termo de acordo é **título executivo extrajudicial** (Lei 9.469 art. 4 §6) |
| **Composição** | Membros AGU + representantes dos órgãos em conflito |

### Quando atuar

| Situação | CCAF cabível? |
|---|---|
| **Conflito entre Ministérios** sobre competência | SIM |
| **Conflito entre União e autarquia federal** | SIM |
| **Conflito entre União e Estado** (repasses, ICMS, FPE) | SIM |
| **Conflito entre União e Município** (repasses) | SIM |
| **Conflito entre Estados** | Em análise, a depender do tema |
| **Particular contra União** | NÃO: vai para vias judiciais ou outras (transação tributária, Lei 13.988) |
| **Conflito interno do mesmo órgão** | NÃO: solução hierárquica |

### Procedimento

| Fase | Conteúdo |
|---|---|
| **Provocação** | Por qualquer das partes ou pelo AGU |
| **Admissão**: avaliação preliminar pela CCAF |
| **Instrução**: documentos + manifestações |
| **Sessão de conciliação**: presencial ou virtual |
| **Termo de acordo**: assinado pelas partes |
| **Eficácia**: imediata após homologação interna |
| **Descumprimento**: execução pelo CPC 784 III (título executivo extrajudicial) |
| **Prazo razoável**: prazos internos definidos pela CCAF |

### Câmaras estaduais e municipais

| | Conteúdo |
|---|---|
| **Câmaras estaduais**: criadas por lei ou regulamento local em diversos Estados |
| **Câmaras municipais**: instituídas por legislação local em várias capitais |
| **Funcionamento**: análogo à CCAF |
| **Eficácia**: termo de acordo é título executivo |
| **Iniciativa**: por requerimento + iniciativa da própria Adm |

### Hipóteses cabíveis

| | Conteúdo |
|---|---|
| **Conflitos entre órgãos públicos**: comum |
| **Particular x Adm**: cabível em hipóteses específicas (Lei 13.140 art. 35) |
| **Direitos transigíveis**: passíveis |
| **Direitos indisponíveis**: vedada (regra geral) |
| **Conflitos contratuais**: cabíveis (Lei 14.133 art. 151) |

## Lei 9.307/1996 + Lei 13.129/2015: arbitragem na Adm

### Marco geral

| | Conteúdo |
|---|---|
| **Lei 9.307**: arbitragem em geral |
| **Lei 13.129/2015**: Lei 9.307 art. 1 §1, admite arbitragem com Adm pública |
| **Condições**: |
|   - **Direitos patrimoniais disponíveis** |
|   - **Arbitragem de direito** (não de equidade) |
|   - **Publicidade** (princípio da publicidade administrativa) |
| **Cabível**: contratos administrativos + concessões + PPPs + acordos |
| **Lei 14.133 art. 151**: arbitragem em contratos administrativos |

### Diferenças mediação x arbitragem x conciliação

| | Mediação | Arbitragem | Conciliação |
|---|---|---|---|
| **Decisão** | Pelas partes | Pelo árbitro | Pelas partes (com auxílio) |
| **Resultado** | Acordo | Sentença arbitral | Acordo |
| **Imposição coercitiva** | Não há | Imperativa | Não há |
| **Impugnação** | Regras gerais de invalidade dos negócios jurídicos | Ação de nulidade em hipóteses legais (Lei 9.307) | Regras gerais de invalidade dos negócios jurídicos |

## Lei 13.988/2020: transação tributária

| | Conteúdo |
|---|---|
| **Tipo de câmara**: específica para conflitos tributários federais |
| **PGFN como condutora** |
| **Modalidades**: adesão + individual + por proposta |
| **Descontos**: até 65% do valor total, em regra (art. 11 §2, redação da Lei 14.375); até 70% para pessoa natural, ME e EPP (art. 11 §3) |
| **Prazo**: até 120 meses, em regra; até 145 meses para pessoa natural, ME e EPP |
| **Lei 14.375/2022**: ampliou benefícios e hipóteses |
| **Não confundir com CCAF**: foco é particular x Fazenda, não interfederativo |

## Eficácia do termo de acordo

| | Conteúdo |
|---|---|
| **Título executivo extrajudicial** (CPC 784 III + Lei 9.469 art. 4 §6) |
| **Vincula as partes** | Eficácia normativa |
| **Descumprimento**: execução direta + multa cominatória (CPC 537) |
| **Homologação judicial**: opcional (CPC 515 III, torna título judicial) |
| **Não cabe rescisão por mero arrependimento**: cabe ação anulatória em hipóteses gerais |

## Tipos de conflitos típicos

### 1. Repartição de receitas (CF 158-159)

- FPE + FPM + IPI exportação + Lei Kandir (ADO 25).
- Discussão sobre cálculo + repasse.
- CCAF intervém + acordo possível.

### 2. Competências administrativas

- Sobreposição de funções entre órgãos.
- Conflitos de atribuição entre autarquias.
- Solução por pacto interno.

### 3. Contratos administrativos (Lei 14.133 art. 151)

- Reequilíbrio econômico-financeiro.
- Aditivos contratuais.
- Acordos sobre execução.

### 4. Concessões + PPPs (Lei 8.987 + Lei 11.079)

- Reajuste + revisão tarifária.
- Inadimplemento + caducidade.
- Cláusula arbitral comum.

### 5. ICMS (entre Estados + Estados x União)

- Lei Kandir.
- Difal (Tema 1.093 STF).
- Convênios CONFAZ.

## Erros a evitar

- **Afastar a CCAF** em causas envolvendo conflito interfederativo (Lei 9.469 art. 4);
- **Tratar mediação como obrigatória** em causas com particular (cabível mas voluntária);
- **Admitir acordo** sobre direitos indisponíveis (vedado, Lei 13.140 + CC 841);
- **Tratar termo de acordo** como sem força executiva (CPC 784 III);
- **Confundir transação tributária (Lei 13.988)** com CCAF (institutos distintos);
- **Afastar arbitragem com Adm** (Lei 9.307 art. 1 §1 + Lei 14.133 art. 151);
- **Admitir arbitragem de equidade** com Adm (apenas de direito);
- **Permitir transação sem fundamentação** (LRF art. 17 + LINDB);
- **Esquecer publicidade** (LAI + transparência administrativa);
- **Ignorar controle externo (TCU + TC)** + interno (CGU);
- **Admitir acordo fraudulento** sem analisar improbidade (Lei 8.429);
- **Homologar acordo** sem análise de legalidade (CPC 515 III);
- **Tratar a CCAF como sempre facultativa**: há hipóteses obrigatórias por regulamento interno;
- **Esquecer Lei 13.140 art. 38**: controle interno;
- **Considerar acordo como imutável** sem hipótese de revisão (CC 478);
- **Admitir prazo aberto** para cumprimento (sem termo);
- **Tratar arbitragem como excluindo o Judiciário** em todas as fases (cabe controle de nulidade);
- **Afastar valor probatório** do termo de acordo;
- **Aplicar limites de transação** da Lei 13.988 a conflito interfederativo (institutos distintos).

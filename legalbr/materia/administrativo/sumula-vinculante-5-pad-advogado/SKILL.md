# Súmula Vinculante 5, Defesa Técnica em PAD

## Texto integral

> "A falta de defesa técnica por advogado no processo administrativo disciplinar **não ofende a Constituição**."

## Marco normativo

| | Conteúdo |
|---|---|
| **CF 5 LV** | Contraditório + ampla defesa |
| **CF 133** | Indispensabilidade do advogado **à administração da justiça** |
| **Lei 8.112/1990 art. 156 §2** | Servidor pode constituir advogado em PAD |
| **Lei 8.906/1994 art. 1 III** | Atividade privativa do advogado |
| **STF SV 5** | Editada em 07/05/2008, em sessão plenária |
| **STJ Súm. 343** (cancelada) | Era exigência de defesa técnica |

## Contexto histórico

| | Conteúdo |
|---|---|
| Antes da SV 5 | Súm. 343 STJ exigia defesa técnica obrigatória em PAD |
| **STF reverteu** | Em 2008 com SV 5 |
| **Súm. 343 STJ** | **Cancelada** |

## Distinção: defesa técnica obrigatória x facultativa

| Tipo de processo | Defesa técnica |
|---|---|
| **Processo penal** | Obrigatória (CF 5 LXII + LXIII) |
| **PAD** | **Facultativa** (SV 5) |
| **Civil** | Obrigatória (CPC + CF 133) |
| **Tributário administrativo** | Facultativa |
| **CADE** | Facultativa |
| **TCU/TCE** | Facultativa (mas recomendada) |

## Ampla defesa em PAD (não dispensada)

| | Conteúdo |
|---|---|
| **Direito de** | Apresentar provas + contraditar provas + arrolar testemunhas + produzir provas + ser ouvido + recorrer |
| **Direito a** | Acesso aos autos (SV 14) + assistência técnica facultativa |
| **Autodefesa** | Pode ser exercida pelo próprio servidor |
| **Defensor dativo** | Quando servidor não constitui advogado (Lei 8.112 art. 164 §2) |

## Lei 8.112 art. 164 §2 (defensor dativo)

| | Conteúdo |
|---|---|
| Cabimento | Servidor revel + ausência de advogado constituído |
| Função | Apresentar defesa escrita + acompanhar |
| Indicação | Pela Administração |
| **Atenção** | STJ exige que a defesa pelo dativo seja efetiva, não meramente formal: defesa simulada equipara-se a ausência |

## Entendimento consolidado

| | Conteúdo |
|---|---|
| **STF SV 5** | Vinculante: falta de defesa técnica por advogado em PAD não ofende a CF |
| **Ausência de advogado** | Não anula o PAD quando assegurada a oportunidade efetiva de defesa |
| **Qualidade da defesa** | A faculdade não dispensa o contraditório e a ampla defesa reais (CF 5 LV) |
| **CGU** | Recomenda assistência técnica em casos complexos |

## Garantias que **permanecem** indispensáveis

| | Conteúdo |
|---|---|
| **Contraditório real** | Mais que formal |
| **Acesso aos autos** | SV 14 |
| **Direito de manifestação** | Em cada fase |
| **Direito à prova** | Pertinente e adequada |
| **Direito ao recurso** | Administrativo |
| **Comunicação clara** | Acusações + provas |
| **Decisão fundamentada** | CF 93 IX (aplicação extensiva) |

## Quando defesa técnica é praticamente exigível

| Hipótese | Análise |
|---|---|
| Demissão | Recomendada |
| Improbidade discutida no PAD | Recomendada |
| Servidor analfabeto + dificuldade real | Recomendável (acesso à justiça, CF 5 LXXIV) |
| Demissão (art. 132) | Mesmo na pena vinculada, exige defesa efetiva, não meramente formal |
| Oportunidade de defesa | A ausência de advogado pode ser saneada se houve oportunidade efetiva de defesa |

## Diferenças PAD x processo penal

| | PAD | Penal |
|---|---|---|
| Sanção máxima | Demissão | Privação de liberdade |
| Defesa técnica | Facultativa (SV 5) | Obrigatória (CF 5 LXIII) |
| **Padrão probatório** | Maioria simples + dúvida em favor do servidor | Prova além de dúvida razoável |
| **Princípios** | Devido processo (CF 5 LV) | Devido processo penal (CF 5 LIV-LXIII) |
| **Recurso** | Administrativo | Apelação + RE |

## Defensoria Pública

| | Conteúdo |
|---|---|
| **LC 80/1994** | A Defensoria pode prestar assistência ao servidor hipossuficiente |
| **Lei 13.460/2017** | Carta de direitos do usuário de serviços públicos |
| Faculdade | A assistência técnica é facultativa (SV 5), mas pode ser garantida ao hipossuficiente |

## Improbidade x PAD

| | Conteúdo |
|---|---|
| Improbidade (defesa técnica) | **Obrigatória** (ação judicial) |
| PAD por mesmo fato | Defesa técnica facultativa |
| **Independência das instâncias** | Sanções administrativa + cível + penal (Lei 8.112 art. 125) |
| Cumulação | Não configura bis in idem (instâncias autônomas) |

## CGU + Estado da arte 2024-2026

| | Conteúdo |
|---|---|
| **CGU** | Orientações de procedimento + recomendação de garantia de defesa real |
| **Sistema CGU-PAD** | Acompanhamento |
| **PAD eletrônico** | Lei 14.129/2021 (Governo Digital) |
| **SV 5** | Reafirmada de forma reiterada pelo STF |
| Avaliação | A defesa deve ser apreciada em sua substância, não apenas na forma |

## Erros a evitar

- Anulação de **PAD sem advogado** de modo automático (SV 5, facultativa);
- Aplicar **Súm. 343 STJ** (cancelada pela SV 5);
- Tratar PAD como processo **penal** (regimes distintos);
- Suprimir **defensor dativo** ao servidor revel (Lei 8.112 art. 164 §2);
- Recusar **acesso aos autos** sob alegação de sigilo (SV 14);
- Aplicar **SV 5** sem analisar **qualidade efetiva** da defesa (jurisprudência STJ);
- Não fundamentar decisão final (CF 93 IX por extensão);
- Aplicar **demissão** sem contraditório real;
- Afastar a Defensoria ao servidor hipossuficiente que a solicite (LC 80/1994);
- Tratar autodefesa como **bastante** sem ofertar prazo razoável;
- Confundir **SV 5** com **SV 14** (institutos complementares);
- Aplicar **prescrição penal** ao PAD (regimes distintos);
- Suprimir **recurso administrativo** + revisão (Lei 8.112 + 9.784);
- Tratar PAD eletrônico como dispensa do **devido processo** (deve assegurar);
- Admitir **prejuízo presumido** por ausência de advogado (exige demonstração).

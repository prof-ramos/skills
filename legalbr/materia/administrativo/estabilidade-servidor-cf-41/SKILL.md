# Estabilidade do Servidor (CF 41)

## Marco normativo

| | Conteúdo |
|---|---|
| **CF 41** (redação EC 19/1998) | Estabilidade após 3 anos + avaliação especial |
| **CF 19 ADCT** | Estabilidade extraordinária aos servidores sem concurso (CF/88) |
| **Súm. 21 STF** | Funcionário em estágio probatório não pode ser exonerado nem demitido sem inquérito ou sem as formalidades legais de apuração de sua capacidade |
| **Súm. 22 STF** | O estágio probatório não protege o funcionário contra a extinção do cargo |
| **Lei 8.112/1990 arts. 20-22** | Procedimento federal |
| **EC 103/2019** | Implicações previdenciárias |

## Conceito

| | Conteúdo |
|---|---|
| Estabilidade | Garantia constitucional do servidor efetivo após período probatório |
| **Não confunde** com | **Vitaliciedade** (magistratura/MP/TC: perda apenas por sentença) |
| Espécie | Direito **público subjetivo** |
| Titular | Apenas servidor de cargo **efetivo** (concursado) |

## Pressupostos (CF 41 caput)

| | Conteúdo |
|---|---|
| **Cargo efetivo** | Concursado (CF 37 II) |
| **Tempo de serviço** | **3 anos** (EC 19) |
| **Avaliação especial** | Por comissão constituída para esse fim (CF 41 §4) |
| Aprovação no estágio probatório | Pressuposto formal |

## Hipóteses de perda do cargo (CF 41 §1)

| Inc. | Hipótese |
|---|---|
| **I** | **Sentença judicial transitada** em julgado |
| **II** | **PAD** com **ampla defesa** + ato fundamentado |
| **III** | **Insuficiência de desempenho** apurada em procedimento periódico (LC ainda **não editada**) |
| **CF 169** | **Excesso de despesa pessoal** (LRF), após adoção de outras medidas |

## Estabilidade extraordinária (CF 19 ADCT)

| | Conteúdo |
|---|---|
| Beneficiário | Servidor da Adm direta + autárquica + fundacional + EP + SEM em **05/10/1988** com **5 anos contínuos** de serviço |
| Sem concurso | Beneficia quem ingressou irregularmente |
| **NÃO** efetiva | Apenas estabiliza no **serviço** (não no cargo) |
| **Provimento efetivo** | Só por concurso público (CF 37 II), conforme STF/STJ |
| **Aproveitamento** | Permitido se houver lei do ente concedendo |

## Estabilidade no cargo x no serviço (CF 19 ADCT, STF/STJ)

| | Conteúdo |
|---|---|
| **No cargo** | CF 41: exige concurso + 3 anos + avaliação |
| **No serviço** | CF 19 ADCT: não vincula a cargo específico |
| **STF/STJ** | Servidor estável pela CF 19 ADCT **não tem direito** a efetividade, ingresso em quadro efetivo ou reenquadramento em PCCR de efetivos sem aprovação em concurso |
| Consequência | A CF 19 ADCT garante apenas permanência no serviço, não o provimento de cargo efetivo |

## Servidor temporário e estabilidade

| | Conteúdo |
|---|---|
| Lei 8.745 + CF 37 IX | Contratação por **prazo determinado**, sem estabilidade |
| Tempo de serviço acumulado | Não confere estabilidade |
| Demissão sem causa | Permitida (não há vínculo estável) |
| Reconhecimento de vínculo permanente | **Vedado**: exige concurso (Tema 308 STF) |

## Estágio probatório (Lei 8.112 art. 20)

| | Conteúdo |
|---|---|
| Duração | **36 meses** (alinhada com CF 41 EC 19) |
| Avaliação | Comissão constituída: assiduidade, disciplina, capacidade, responsabilidade, produtividade |
| **Critérios objetivos** | Exigência STJ |
| **Inabilitação** | **Exoneração** (não demissão) + contraditório |
| Estável anterior | **Recondução** ao cargo de origem (art. 29 I) |

## Perda por insuficiência de desempenho (CF 41 §1 III)

| | Conteúdo |
|---|---|
| Lei complementar | **Pendente** desde EC 19/1998 |
| Aplicabilidade | **Norma de eficácia limitada**: só após LC |
| Reforma Administrativa | A PEC 32/2020 não avançou; em 2025 tramitou nova proposta (PEC 38/2025), também retirada de pauta. **Sem alteração vigente** ao regime do art. 41 |
| Avaliações periódicas | Permitidas para gestão (não para demissão sem LC) |

## Perda por excesso de despesa (CF 169 §4)

| | Conteúdo |
|---|---|
| Lei 9.801/1999 | Disciplina exoneração de estáveis por excesso de despesa |
| Pressuposto | Esgotamento das demais medidas (cargos em comissão + servidores não estáveis) |
| Indenização | 1 mês de remuneração por ano de serviço |
| **Vedação** de criação | 4 anos para criar cargo equivalente |

| Hipótese | Conteúdo |
|---|---|
| Crime contra administração pública | Inc. I |
| Abandono de cargo (>30 dias) | Inc. II |
| Inassiduidade habitual | Inc. III |
| Improbidade administrativa | Inc. IV |
| Incontinência pública + conduta escandalosa | Inc. V |
| Insubordinação grave | Inc. VI |
| Ofensa física | Inc. VII |
| Aplicação irregular de dinheiro público | Inc. VIII |
| Revelação de segredo | Inc. IX |
| Lesão aos cofres + dilapidação | Inc. X |
| Corrupção | Inc. XI |
| **Acumulação ilegal** | Inc. XII |
| **Transgressão dos incisos do art. 117** | Inc. XIII |

## Demissão vinculada (Súm. 650 STJ)

| | Conteúdo |
|---|---|
| **Súm. 650 STJ** | A autoridade administrativa **não dispõe de discricionariedade** para aplicar pena diversa de demissão quando caracterizadas as hipóteses do art. 132 da Lei 8.112/1990 |
| Discricionariedade | **Inexiste**: a autoridade não pode aplicar pena mais branda |
| Aprovação | 1ª Seção, 22/09/2021 |
| Controle judicial | Restrito à legalidade + proporcionalidade dosimétrica + due process |

## Cargo em comissão x estabilidade

| | Conteúdo |
|---|---|
| Servidor comissionado | **Sem estabilidade**: exonerável **ad nutum** |
| Servidor efetivo **investido** em comissão | Mantém estabilidade no cargo efetivo |
| **CF 37 II e V** | Cargo em comissão: **livre nomeação e exoneração** |
| **Cassação** da comissão | Não afeta cargo efetivo subjacente |

## Empregado público (CLT) e estabilidade

| | Conteúdo |
|---|---|
| **STF Tema 1.022 (RE 688.267)** | Empregado de EP/SEM **NÃO** tem estabilidade do art. 41 (mas a dispensa exige motivação) |
| Garantia | Apenas em concurso (CF 37 II); dispensa motivada |
| **Súm. 390 TST** | Estabilidade do art. 41 **não** se aplica a empregado público de SEM |
| EP/SEM prestadora de serviço público | Dispensa motivada (Tema 131 STF, ECT; OJ 247 II SDI-1 TST): exige justificativa |

## Erros a evitar

- Aplicar prazo de **2 anos** para estabilidade (EC 19/1998: 3 anos);
- Estender estabilidade a **cargo em comissão** (vedado);
- Estender estabilidade a **temporário** (vedado);
- Aplicar **CF 19 ADCT** para **ingresso em cargo efetivo** ou reenquadramento em PCCR sem concurso (STF/STJ);
- Admitir perda por **insuficiência de desempenho** sem LC (norma de eficácia limitada);
- Aplicar demissão **discricionária** (Súm. 650 STJ: vinculada);
- Confundir **estabilidade** com **vitaliciedade**;
- Aplicar CF 41 a empregado público (Tema 1.022);
- Tratar como adquirida a estabilidade **antes** da avaliação especial (CF 41 §4);
- Afastar a **recondução** do estável inabilitado em probatório (art. 29 I);
- Aplicar perda por **excesso de despesa** sem esgotar outras medidas (CF 169);
- Afastar a estabilidade extraordinária da **CF 19 ADCT** quando preenchidos requisitos;
- Tratar empregado público de **EP/SEM exploradora de atividade econômica** como apto à estabilidade (Tema 1.022);
- Aplicar **vitaliciedade do magistrado** ao servidor comum (institutos distintos);
- Aplicar CF 41 a **funcionário público comissionado político** (CF 37 II e V: exonerável).

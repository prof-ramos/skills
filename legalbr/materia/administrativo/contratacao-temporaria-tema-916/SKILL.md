# Contratação Temporária em Desconformidade

## Base normativa

| | Conteúdo |
|---|---|
| **CF 37 IX** | Lei estabelecerá os casos de contratação por **tempo determinado** para atender a **necessidade temporária de excepcional interesse público** |
| **CF 37 II** | Concurso público em regra |
| **Lei 8.745/93** | Contratação temporária federal |
| **Súm. 363 TST** | Contratação sem concurso (nula): saldo de salário + FGTS apenas |

## STF Tema 916 (RE 765.320)

| | Conteúdo |
|---|---|
| Fixada | **16/09/2016** |
| **Tese (essência)** | A **contratação temporária** em **desconformidade** com os requisitos do art. 37 IX CF (necessidade temporária + excepcional interesse público + prazo determinado) é **NULA**. Apenas saldo de salário + FGTS são devidos. Mesma lógica da Súm. 363 TST |

## Requisitos válidos (CF 37 IX)

| Requisito | Conteúdo |
|---|---|
| **Necessidade temporária** | Não permanente; com prazo limitado |
| **Excepcional interesse público** | Justificado em ato administrativo |
| **Previsão em lei** específica | Lei federal/estadual/municipal regulamentadora |
| **Prazo determinado** | Limitado + prorrogação justificada |
| **Sem prorrogações sucessivas** | Configura desvirtuamento |

## Aplicação prática

| Hipótese | Saída |
|---|---|
| Contrato temporário renovado por 10 anos consecutivos | **NULO** (Tema 916): apenas saldo + FGTS |
| Contrato sem previsão em lei local | **NULO** (CF 37 IX) |
| Contrato para função permanente (não excepcional) | **NULO** |
| Contrato regular (atende CF 37 IX) | Cabível com direitos respectivos |
| Servidor temporário com 5 anos + reconhecimento de vínculo estatutário | **NÃO cabe** (CF 37 II exige concurso) |
| FGTS de período em contrato nulo | **Devido** (Súm. 363 TST + Tema 916) |
| Verbas trabalhistas integrais (férias + 13º) | **NÃO devidas** em contrato nulo (Tema 916) |

## Direitos do servidor temporário **regular** vs **nulo**

| Verba | Contrato regular | Contrato nulo (Tema 916) |
|---|---|---|
| Saldo de salário | **Devido** | **Devido** |
| FGTS | Devido (se previsto) | **Devido** (Súm. 363 TST) |
| Férias + 13º | Devidos (CF 7) | **NÃO devidos** |
| Verbas rescisórias | Devidas conforme lei | NÃO devidas |
| Reintegração | Cabível (Tema 1.022 em estatais) | NÃO cabível |
| Estabilidade | Não há | Não há |

## Casos correlatos

| | Conteúdo |
|---|---|
| **Tema 916 STF** | Contrato temporário irregular |
| **Tema 1.022 STF** | Empregado estatal: dispensa motivada |
| **Tema 1.143 STF** | Servidor celetista x Poder Público |
| **Tema 1.150 STF** | Reintegração aposentado RGPS |
| **Súm. 363 TST** | Contrato nulo: saldo + FGTS |
| **CF 37 II + IX** | Concurso + contratação temporária |
| **Lei 8.745/93** | Federal |

## Erros a evitar

- Reconhecer **vínculo estatutário** em contrato temporário (CF 37 II exige concurso);
- Pagar verbas trabalhistas integrais em contrato nulo (Tema 916: apenas saldo + FGTS);
- Em contrato regular (atende CF 37 IX), negar verbas próprias do regime;
- Em renovação sucessiva sem justificativa, considerar o contrato regular (cabe desvirtuamento);
- Aplicar Tema 916 a **terceirizado** (regime CLT puro: cabe verificação Tema 246/725);
- Em servidor temporário com Lei 8.745 vigente, aplicar Tema 916 sem analisar regularidade.

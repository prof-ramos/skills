# Acumulação de Cargos Públicos (CF 37 XVI-XVII)

## Marco constitucional

| Inc. | Conteúdo |
|---|---|
| **XVI** | Vedada acumulação remunerada; **exceções taxativas** (compatibilidade de horários) |
| **a** | Dois cargos de **professor** |
| **b** | Um cargo de **professor** + outro **técnico ou científico** |
| **c** | Dois cargos/empregos **privativos de profissionais de saúde com profissões regulamentadas** |
| **XVII** | Vedação **estendida** a empregos + funções + autarquias + fundações + EP/SEM + subsidiárias + controladas direta/indiretamente |
| **§10** | Vedada percepção simultânea de **proventos** com remuneração de cargo, salvo cargos acumuláveis na ativa + comissão/eletivo |

## Cargo técnico ou científico (XVI b)

| | Conteúdo |
|---|---|
| Conceito | Cargo cujo exercício **requer conhecimento especializado** + formação superior/técnica |
| Não basta | Mera nomenclatura: exige **substância técnica/científica** |
| **STF e STJ** | Excluem cargos **meramente burocráticos** (auxiliar administrativo, assistente em geral) |
| **STJ** | Cargo técnico = exige formação técnica de nível médio ou superior com conhecimento especializado |

## Cargos de saúde (XVI c)

| | Conteúdo |
|---|---|
| Profissões | **Regulamentadas em lei** (médico, enfermeiro, odontólogo, farmacêutico, fisioterapeuta, psicólogo, biomédico; assistente social quando na área de saúde) |
| Não basta | Estar lotado em órgão de saúde: exige **profissão regulamentada de saúde** |
| **AGU Parecer GMF-4 (2017)** | Lista referencial das profissões abrangidas |

## Compatibilidade de horários (Tema 1.081 STF)

| | Conteúdo |
|---|---|
| **Tese (literal)** | "As hipóteses excepcionais autorizadoras de acumulação de cargos públicos previstas na Constituição Federal sujeitam-se, unicamente, a existência de compatibilidade de horários, verificada no caso concreto, ainda que haja norma infraconstitucional que limite a jornada semanal" |
| Consequência | Limite fixo (ex.: 60h semanais) não pode, por si só, impedir a acumulação: a aferição é **caso a caso** |
| Critérios práticos | Jornadas (manhã/tarde/noite) + intervalos de descanso/deslocamento + qualidade do serviço |
| Demissão por mera extrapolação de limite fixo | Sem prova de incompatibilidade concreta, tende à **reintegração** |

> Não há **teto fixo** de horas: exige-se **avaliação concreta** da compatibilidade.

## Teto remuneratório (Tema 377 + Tema 384 STF)

| Tema | Conteúdo |
|---|---|
| **Tema 377** (RE 612.975) | Nas hipóteses constitucionalmente autorizadas de acumulação, o teto do art. 37 XI incide **sobre cada vínculo isoladamente**, e **não sobre a soma** das remunerações |
| **Tema 384** | Tema correlato sobre a incidência do teto na acumulação de cargos |
| Aposentado + ativo | Cada vínculo respeita o teto **isoladamente** (acumulação lícita) |
| **Acumulação inconstitucional** | Não há proteção: cessa o vínculo ilícito |

## Aposentadoria + cargo ativo

| Hipótese | Permitido? |
|---|---|
| Aposentado em cargo do XVI + nomeado em outro **acumulável** (CF 37 §10) | **Sim** |
| Aposentado em cargo **não acumulável** + nomeado em ativa | **Não**, exceto cargo eletivo + comissão + hipóteses acumuláveis |
| Dupla aposentadoria | Permitida se ambos os cargos eram **acumuláveis** na ativa |
| **Proventos + proventos** | Permitida (não é remuneração) |

## Procedimento de apuração

| | Conteúdo |
|---|---|
| Detecção | **CGU/AGU/SIAPE-Cruzamento** + denúncia |
| **Notificação** | Servidor **opta** por um vínculo em **10 dias** (Lei 8.112 art. 133 §5) |
| Opção | Cessa o outro vínculo + **boa-fé** preserva proventos do período |
| Recusa de opção | **Demissão** + **destituição** ou rito sumário (Lei 8.112 art. 133) |
| **Má-fé** | Exige **devolução** dos valores recebidos no cargo ilicitamente acumulado |
| **STF e STJ** | **Boa-fé** dispensa devolução se servidor declarou e foi nomeado pela Administração |

## Estatais (XVII)

| | Conteúdo |
|---|---|
| Abrangência | EP + SEM + subsidiárias + controladas |
| **Empregado celetista** | Sujeito à mesma vedação (Lei 8.112 não se aplica diretamente, mas a regra constitucional sim) |
| **OS/OSCIP** | Não há vedação **se não houver vínculo público**; mas o servidor que atua em OS contratada pelo seu próprio ente caracteriza desvio |

## Jurisprudência consolidada

| | Conteúdo |
|---|---|
| **STJ** | Não basta a nomenclatura "técnico": exige conteúdo técnico/científico real |
| **STF e STJ** | Acumulação ilícita não gera direito adquirido; demissão é ato vinculado |
| **Tema 1.081 STF** | Compatibilidade de horários verificada no caso concreto, ainda que norma infraconstitucional limite a jornada |
| **CF 37 §10** | Vedada a percepção simultânea de proventos + remuneração, ressalvadas as hipóteses do XVI, os cargos eletivos e os em comissão |
| **STJ (boa-fé)** | Reposição ao erário só com má-fé comprovada (boa-fé objetiva) |
| **CF 37 XVI "c"** | Cargo de saúde exige profissão regulamentada; não basta a lotação em órgão de saúde |

## Acumulação x extensão

| Hipótese | Permitido? |
|---|---|
| Cargo público + advocacia privada | Vedada para AGU/PFN/PGE; permitida ao demais salvo conflito |
| Cargo + magistério particular | **Permitido** se compatível |
| Magistério + atividade política | Suspende o magistério (CF 38) |
| Magistratura + magistério | Permitido (CF 95 §p ún I) |
| MP + magistério | Permitido (CF 128 §5 II d) |
| **2 cargos + bolsa de pesquisa** | Bolsa **não é remuneração**: permitido |
| **Cargo + função de confiança comissionada** | Vedado salvo magistério/eletivo |

## Erros a evitar

- Aplicar **limite fixo de 60h** após Tema 1.081 STF (inconstitucional);
- Exigir **devolução** sem prova de **má-fé** (jurisprudência consolida boa-fé);
- Tratar **cargo burocrático** como técnico/científico só pela nomenclatura;
- Permitir acumulação de cargo de saúde **sem profissão regulamentada**;
- Aplicar teto **único** sobre a soma em acumulação **lícita** (Tema 377/384: teto incide por vínculo isolado);
- Confundir **proventos + remuneração** (vedada salvo cargos acumuláveis ativos) com **proventos + proventos** (permitida);
- Aplicar demissão sem oportunizar **opção** (Lei 8.112 art. 133 §5);
- Considerar **bolsa de pesquisa** como vínculo (não é);
- **Reintegração** de servidor demitido por mera ultrapassagem horária sem análise concreta de prejuízo;
- Não estender a vedação às **estatais** (XVII);
- Não considerar **boa-fé** com nomeação válida da Administração;
- Suprimir contraditório/ampla defesa no procedimento de acumulação (CF 5 LV);
- **Cumular cargo** + função de confiança/cargo em comissão fora do magistério/eletivo;
- Admitir acumulação de **3 cargos** (sempre **dois**).

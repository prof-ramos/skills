# Lei das Estatais

## Lei 13.303/2016

| | Conteúdo |
|---|---|
| Função | Regulamenta **CF 173** |
| Conteúdo | **Estatuto Jurídico** das EP + SEM + subsidiárias |
| Aplicação | **União + Estados + DF + Municípios** |
| Inclui | Exploradoras de atividade econômica + prestadoras de serviço público |
| Origem | Profissionalização pós-Lava-Jato |

## ESTRUTURA + GOVERNANÇA

| | Conteúdo |
|---|---|
| **Conselho de ADMINISTRAÇÃO** | **Mínimo 7 membros** + **25% INDEPENDENTES** |
| **Diretoria EXECUTIVA** | Sim |
| **Comitê de Auditoria Estatutário** | Sim |
| **Área de COMPLIANCE** | Sim |
| **Código de conduta** | Sim |
| **Programa de INTEGRIDADE** | Obrigatório (art. 9) |

## Art. 17 §2 (vedações)

| | Conteúdo |
|---|---|
| Vedações | **INDICAÇÕES POLÍTICO-PARTIDÁRIAS** para diretoria + conselho |
| Impedidos | **Ministros + Secretários + dirigentes SINDICAIS + dirigentes de PARTIDO** |
| **Constitucionalidade** | Incisos I e II do §2 do art. 17 declarados **constitucionais** no mérito (STF, Plenário, ADI 7.331, j. 05/2024); preservadas, por boa-fé e continuidade do serviço público, as indicações realizadas antes ou durante a vigência da liminar de 16/03/2023 que havia suspendido as restrições |

## STF ADI 5.624 (Min. Ricardo Lewandowski, 06/06/2019)

| | Conteúdo |
|---|---|
| (i) | **Alienação do controle de MATRIZ** exige **AUTORIZAÇÃO LEGISLATIVA específica + LICITAÇÃO** |
| (ii) | **DISPENSADAS exigências para SUBSIDIÁRIAS E CONTROLADAS** (usada nas privatizações posteriores) |
| (iii) | As vedações do art. 17 (indicações político-partidárias) não foram suspensas nesta cautelar; posteriormente, liminar na ADI 7.331 as suspendeu de 16/03/2023 até o julgamento de mérito, que as declarou constitucionais (STF, Plenário, ADI 7.331, j. 05/2024) |

## Licitações próprias (arts. 28-49)

| | Conteúdo |
|---|---|
| Substituiu | A antiga Lei 8.666/1993 (hoje revogada; a norma geral atual é a Lei 14.133/2021) |
| Convive com | **Lei 14.133/2021** (Lei de Licitações e Contratos Administrativos), aplicável subsidiariamente |
| Modalidades | **Concorrência + diálogo competitivo + leilão + pregão** |
| **Contratação direta** | Somente nas hipóteses legais de dispensa e inexigibilidade |

## Contratos próprios (arts. 68-84)

| | Conteúdo |
|---|---|
| **MATRIZ DE RISCO** | Sim |
| Regime | Próprio |

## Lei 14.182/2021 (Eletrobras)

| | Conteúdo |
|---|---|
| Tese | **Viabilizou privatização** |
| Mecanismo | **Limitação de voto a 10%** + poderes especiais à União (**golden share**) |
| **ADIs 6.929, 6.932 e 7.033** | Sem liminar (rito do art. 12 da Lei 9.868); a desestatização prosseguiu |
| **ADI 7.385** (voting cap de 10%) | Encerrada por **acordo homologado pelo STF** (participação da União nos conselhos preservada em troca da manutenção do limite de voto) |

## Petrobras

| | Conteúdo |
|---|---|
| Status | Debates em ADIs |
| Temas | Política de preços + governança pós-Lava-Jato |

## Distinções essenciais

| | EP | SEM |
|---|---|---|
| Capital | **100% público** | **Misto** (público + privado) |
| Forma | Qualquer | **S.A.** |
| Exemplos | CEF + Correios + BNDES | Petrobras + Banco do Brasil |

| | Lei 13.303 | Lei 14.133 |
|---|---|---|
| Aplicação | EP + SEM | Adm direta + autarquias + fundações |
| Convivência | Subsidiária |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Privatização da matriz | **Lei + licitação** (ADI 5.624) |
| Privatização de subsidiária | **Dispensa autorização legislativa** específica |
| Indicação de Ministro para Conselho | **VEDADA** (art. 17 §2) |
| Licitação | **Lei 13.303 arts. 28-49** |
| Aplicação supletiva | **Lei 14.133/2021** |
| Programa de integridade | **Obrigatório** |
| Conselho com 5 membros | **Insuficiente** (mínimo 7) |
| Golden share | **Eletrobras + ADI 5.624** |
| EP/SEM delegatária de serviço público essencial, sem lucro a acionista privado nem risco concorrencial | **Imunidade recíproca** (Tema 1.140 STF), independentemente de cobrança de tarifa |

## Erros a evitar

- **Aplicar Lei 8.666/1993 às ESTATAIS** (lei revogada; regime próprio da Lei 13.303 com aplicação subsidiária da Lei 14.133/2021);
- **Permitir privatização da MATRIZ sem lei autorizativa** (ADI 5.624);
- Aceitar **indicação política** (art. 17 §2);
- Aplicar **CF 173** sem combinar com Lei 13.303;
- **Confundir EP com SEM** (capital);
- Permitir **Conselho sem 25% independentes**;
- Aceitar **subsidiária com mesmas exigências da matriz** (ADI 5.624);
- Não aplicar **Lei 14.133 supletivamente**;
- Aplicar **golden share como veto absoluto** (limitações);
- Afastar **controle do TCU** sobre as estatais;
- Permitir **contratos sem matriz de risco** (arts. 68+).

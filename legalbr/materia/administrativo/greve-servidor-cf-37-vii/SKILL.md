# Greve do Servidor Público

## CF 37 VII (redação EC 19/1998)

| | Conteúdo |
|---|---|
| Tese | Servidor público civil tem **direito de greve** |
| Limite | "Será exercido nos termos e nos limites definidos em **LEI ESPECÍFICA**" |
| Natureza | **Norma de EFICÁCIA LIMITADA** |
| Mora | Congresso **INERTE**: não há lei |

| | Conteúdo |
|---|---|
| Texto original | Exigia "lei COMPLEMENTAR" |
| EC 19/1998 | Reduziu para **LEI ESPECÍFICA** |

## STF MIs 670/ES + 708/DF + 712/PA (25/10/2007)

| | Conteúdo |
|---|---|
| **MI 670/ES** | Rel. Min. Maurício Corrêa, red. p/ acórdão Min. Gilmar Mendes |
| **MI 708/DF** | Rel. Min. Gilmar Mendes |
| **MI 712/PA** | Rel. Min. Eros Grau |
| Posição | **CONCRETISTA GERAL** com **eficácia ERGA OMNES** |
| Tese | **APLICAÇÃO ANALÓGICA da Lei 7.783/1989** (Lei de Greve do setor privado), **no que couber + adaptada** |
| Vigência | Até edição de **lei específica** |
| Importância | Virada do **NÃO CONCRETISTA (MI 107)** para o **CONCRETISTA GERAL** |

## STF Tema 531 (RE 693.456, Min. Dias Toffoli)

| | Conteúdo |
|---|---|
| Tese | Administração Pública **DEVE proceder ao DESCONTO dos DIAS de PARALISAÇÃO** |
| Razão | **Suspensão do vínculo funcional** |
| Salvo | Conduta ilícita do Poder Público OU **acordo de COMPENSAÇÃO** |

## STF Tema 541 (ARE 654.432)

| | Conteúdo |
|---|---|
| **Tese I** | O exercício do direito de greve, **sob qualquer forma ou modalidade, é VEDADO** aos policiais civis e a **todos os servidores públicos que atuem diretamente na área de segurança pública** |
| **Tese II** | É **OBRIGATÓRIA a participação do Poder Público em MEDIAÇÃO** instaurada pelos órgãos classistas das carreiras de segurança pública (CPC art. 165), para vocalização dos interesses da categoria |

## COMPETÊNCIA para julgar greve

| | Conteúdo |
|---|---|
| Servidor **ESTATUTÁRIO** | **Justiça Comum** (Federal ou Estadual), ADI 3.395 + MI 670 |
| Servidor **CELETISTA** | **JT** |

## VEDAÇÕES ABSOLUTAS

### Policiais militares e civis (carreiras de segurança pública armadas)
| | Conteúdo |
|---|---|
| **Tema 541 (ARE 654.432)** | **VEDADA greve** a policiais civis e a todos os servidores que atuem diretamente na segurança pública |
| Razão | **Essencialidade do serviço + estrutura hierárquico-disciplinar** |
| Contrapartida | **Mediação obrigatória** com participação do Poder Público (Tema 541, tese II) |

### Forças Armadas
| | Conteúdo |
|---|---|
| **CF 142 §3 IV** | **Proibição EXPRESSA de SINDICALIZAÇÃO e GREVE** |

## Lei 13.300/2016: Lei do MI

| | Conteúdo |
|---|---|
| Conteúdo | Consolidou regime processual da injunção |
| **Corrente** | **CONCRETISTA** |
| **Art. 8** | Fixar **prazo ao impetrado** + ultrapassado → estabelecer **condições do exercício** do direito |

## Lei 7.783/1989: aplicação analógica

| | Conteúdo |
|---|---|
| **Atividades essenciais** | Servidores em **percentual mínimo de continuidade** do serviço (art. 11) |
| **Aviso prévio** | **72 HORAS (essenciais) OU 48 HORAS (gerais)** |
| Procedimento | Comunicação + tentativa de negociação |

## Distinções essenciais

| | Servidor civil | PM/PC armados | FFAA |
|---|---|---|---|
| Greve | **Permitida** (analogia 7.783) | **VEDADA** (Tema 541) | **VEDADA** (CF 142 §3 IV) |

| | Lei 7.783 (privado) | Aplicação ao público |
|---|---|---|
| Aviso prévio | 48-72h | Idem |
| Essenciais | % mínimo | Idem |

| | MI 107 (não concretista) | MIs 670+ (concretista) |
|---|---|---|
| Posição | Apenas declara mora | **Aplica lei análoga** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Servidor civil em greve | **Lei 7.783 aplicação analógica** (MIs 670+) |
| Dias parados | **DESCONTO** (Tema 531) |
| Acordo de compensação | Afasta desconto |
| PM em greve | **VEDADA** (Tema 541 + regime militar estadual, CF 42) |
| FFAA em greve | **VEDADA** (CF 142 §3 IV) |
| Sem aviso prévio | Atos atípicos |
| Servidor em essencial | **% mínimo** mantido |
| Estatuto da carreira → essencial | Aplicação rigorosa |
| Foro | **Justiça COMUM** se estatutário |

## Erros a evitar

- **Aplicar MI 107 (não concretista)** ignorando MIs 670/708/712 (CONCRETISTA);
- **Permitir GREVE de PM/PC** (Tema 541 veda);
- Permitir **greve de FFAA** (CF 142 §3 IV: vedada);
- **Não DESCONTAR dias parados** (Tema 531: DEVE);
- Aplicar **Lei 7.783 sem analogia adaptada** ao público;
- Tratar **direito de greve como autoaplicável** (eficácia limitada);
- Submeter **greve de estatutário à JT** (Justiça Comum, ADI 3.395);
- Não exigir **aviso prévio + % essenciais** (Lei 7.783 analogia);
- Aceitar **EC 19 mantendo lei complementar** (reduziu a específica);
- Afastar a **eficácia erga omnes** dos MIs (concretista geral);
- Aplicar **Lei 13.300 sem corrente concretista** (art. 8).

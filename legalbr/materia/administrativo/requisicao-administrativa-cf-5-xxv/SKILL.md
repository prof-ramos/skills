# Requisição Administrativa

## Marco normativo

| | Conteúdo |
|---|---|
| **CF 5 XXV** | Núcleo constitucional |
| **CF 22 III** | União legisla sobre requisições civis/militares |
| **DL 4.812/1942** | Requisições militares e civis em estado de guerra |
| **Lei 8.080/1990 art. 15 XIII** | Requisição em saúde |
| **Lei 12.340/2010** | Defesa Civil |
| **Lei 13.979/2020** | COVID; interpretada conforme a ADI 6.341 |
| **Lei 14.133/2021 art. 75 V** | Dispensa de licitação em caso de calamidade |

## Texto da CF 5 XXV

> "No caso de **iminente perigo público**, a autoridade competente poderá usar de propriedade particular, **assegurada ao proprietário indenização ulterior**, se houver dano."

## Conceito

| | Conteúdo |
|---|---|
| Natureza | **Intervenção estatal** na propriedade ou serviço de particular |
| Pressuposto | **Iminente perigo público** ou interesse coletivo urgente |
| **Caráter transitório** | Sim (dura enquanto persistir o perigo) |
| Indenização | **Ulterior** + condicionada a **dano** |
| Sujeito ativo | **Autoridade competente** |

## Espécies

| Critério | Espécies |
|---|---|
| **Civil/militar** | Civil (em geral); militar (estado de guerra) |
| **Bens móveis** | Veículos + alimentos + medicamentos |
| **Bens imóveis** | Hospitais + casas (calamidade) |
| **Serviços** | Profissionais (médicos, técnicos) |
| **Híbrida** | Conjunto |

## Pressupostos

| | Conteúdo |
|---|---|
| **Iminente perigo público** | Risco real + atual + sério |
| **Necessidade** | Não existe meio alternativo razoável |
| **Proporcionalidade** | Adequada ao perigo |
| **Excepcionalidade** | Caráter de exceção |
| **Formalidade** | Ato fundamentado |

## Procedimento

| Fase | Conteúdo |
|---|---|
| **1. Caracterização** | Da emergência |
| **2. Ato administrativo** | Fundamentado |
| **3. Execução** | Imediata |
| **4. Notificação** | Posterior ao proprietário |
| **5. Cessação** | Quando termina o perigo |
| **6. Indenização** | Se houver dano comprovado |

## Distinção dos demais instrumentos

| | Requisição | Servidão | Limitação | Desapropriação |
|---|---|---|---|---|
| Caráter | **Transitória** | Permanente | Permanente | Definitiva |
| Pressuposto | **Iminente perigo** | Utilidade | Interesse geral | Necessidade/utilidade pública/interesse social |
| Indenização | Ulterior + se houver dano | Sim | Não (em regra) | **Prévia** + justa |
| Direito real | Não | **Sim** | Não | Aquisição |
| **Domínio** | Mantém-se | Mantém-se | Mantém-se | Transfere |

## Lei 8.080/1990 (SUS) art. 15 XIII + 24

| | Conteúdo |
|---|---|
| Requisição em saúde | Permitida em emergência sanitária |
| Sujeitos | Bens + serviços de hospitais privados |
| **Limite federativo** | A requisição alcança bens e serviços **privados**, mas não pode recair sobre bens e/ou serviços **públicos de outro ente federativo** (STF, Plenário, ADI 3.454, j. 20/06/2022, interpretação conforme ao art. 15 XIII da Lei 8.080/1990), ressalvadas as requisições pela União em estado de defesa e estado de sítio (CF 136 §1º II e 139 VII) |
| **Indenização** | Conforme legislação |
| **STF ADI 6.341** | Reafirma competência concorrente dos entes em saúde |

## Lei 13.979/2020 (COVID-19)

| | Conteúdo |
|---|---|
| Requisição de bens/serviços | Permitida |
| **STF ADI 6.341** | Estados/DF/Municípios também podem requisitar; afasta a exclusividade federal |
| **Decreto + Lei** | Procedimento simplificado |
| **Indenização ulterior** | Garantida |

## Requisição militar (DL 4.812/1942)

| | Conteúdo |
|---|---|
| Pressuposto | **Estado de guerra** ou comoção interna |
| Sujeitos | Forças Armadas |
| **CF 22 III** | Competência da União |
| Indenização | Conforme lei especial |

## Indenização

| | Conteúdo |
|---|---|
| Critério | **Dano efetivo** |
| Pagamento | **Ulterior** (não prévio) |
| **Justa + atualizada** | Sim |
| **Boa-fé** | Da Administração no uso |
| **Devolução do bem** | Quando móvel + íntegro |
| **Juros + correção** | Sobre o valor do dano, da data do prejuízo |

## Limites constitucionais

| | Conteúdo |
|---|---|
| **Necessidade real** | Exige fato concreto |
| **Proporcionalidade** | Aferida concretamente |
| **Controle judicial** | Cabe MS + ACP |
| **Abuso de poder** | Ato nulo + responsabilidade |

## Cessação

| | Conteúdo |
|---|---|
| Fim da emergência | Encerra a requisição |
| **Devolução** | Imediata |
| **Indenização** | Avaliada posteriormente |

## STF ADI 6.341 (COVID-19)

| Item | Tese |
|---|---|
| 1 | Competência **concorrente** dos entes federativos para medidas sanitárias |
| 2 | Estados, DF e Municípios podem **requisitar bens** em emergências |
| 3 | União não exclui a atuação local |
| 4 | Limites pela CF + razoabilidade |

## Jurisprudência (STF/STJ)

| | Conteúdo |
|---|---|
| **STF MS 25.295** | Requisição como ato discricionário fundamentado |
| **Jurisprudência STJ** | Indenização integral pelo dano efetivo + cessação imediata após o fim do perigo |
| **STF ACO 3.463 / ADPF 672** | Limites à requisição entre entes federativos (leitos, insumos) na pandemia; entendimento consolidado em controle abstrato: a vedação é **geral**, não limitada a bens já afetados a serviço essencial nem ao contexto pandêmico (STF, Plenário, ADI 3.454, j. 20/06/2022) |

## Erros a evitar

- Confundir **requisição** com **servidão** ou **desapropriação**;
- Exigir indenização **prévia** (a regra é ulterior se houver dano);
- Permitir requisição **sem iminente perigo** comprovado (abuso);
- Aplicar requisição **permanente** (é transitória);
- Afastar competência de **Estado/Município** em saúde (ADI 6.341);
- Admitir requisição sobre **bens ou serviços públicos de outro ente federativo** (vedada; STF, Plenário, ADI 3.454, j. 20/06/2022), salvo requisição pela União em estado de defesa/sítio;
- Concessão de indenização sem **prova de dano**;
- Esquecer **devolução** do bem móvel após cessação;
- Tratar requisição como **desapropriação simplificada**;
- Não exigir **motivação** fundamentada do ato;
- Permitir requisição **abusiva** sem proporcionalidade;
- Afastar **MS** como via de controle (cabe);
- Confundir **requisição civil** com **militar** (regimes próprios);
- Permitir requisição **sem indenização** quando há dano (CF 5 XXV);
- Aplicar **prazo prescricional** à devolução (deve ser imediata);
- Esquecer competência **concorrente** da União/Estados/Municípios em saúde + defesa civil;
- Tratar requisição de **serviços profissionais** (médicos) como ilegal sem analisar emergência.

# Lei de Acesso à Informação (LAI)

## Marco normativo

| | Conteúdo |
|---|---|
| **CF 5 XIV, XXXIII, XXXIV** | Direito à informação |
| **CF 37 §3 II** | Acesso a registros administrativos |
| **CF 216 §2** | Documentos públicos |
| **Lei 12.527/2011** | LAI (vigência 16/05/2012) |
| **Dec. 7.724/2012** | Regulamenta no Executivo federal |
| **Lei 13.460/2017** | Direitos do usuário de serviços públicos (complementar) |
| **LGPD (Lei 13.709/2018)** | Articulada com a LAI |
| **Dec. 11.529/2023** | Regime federal de integridade e transparência |

## Princípios (art. 3)

| | Conteúdo |
|---|---|
| **Publicidade** | Regra geral |
| **Sigilo** | Exceção |
| Divulgação | Independente de solicitação |
| Linguagem | Clara + acessível |
| **Fomento** | Cultura de transparência |
| **Gratuidade** | Em regra |

## Sujeitos passivos (art. 1)

| | Conteúdo |
|---|---|
| Adm direta + indireta | Todos os Poderes |
| **Empresas públicas e SEM** | Sim |
| **TC + MP + Defensoria** | Sim |
| **Entidades sem fins lucrativos** que recebam recursos públicos | Sim (no que couber, art. 2) |
| **OSC + OS + OSCIP** | Sim quanto a recursos públicos recebidos |

## Sujeito ativo

| | Conteúdo |
|---|---|
| **Qualquer pessoa** | Física ou jurídica |
| Nacional ou estrangeira | Sim |
| **Sem necessidade de motivação** (art. 10 §3) | Vedada exigência |
| Identificação | Permitida apenas para fins de resposta |

## Transparência ATIVA (art. 8)

| | Conteúdo |
|---|---|
| Obrigatória | Independente de solicitação |
| **Sítio na internet** | Obrigatório (entes > 10.000 habitantes, art. 8 §4) |
| Conteúdo mínimo | Estrutura organizacional + endereços + telefones + competências + repasses + execução orçamentária + licitações + contratos + dados gerais para acompanhamento de programas |
| **Dados abertos** | Formato aberto + estruturado |
| **Atualização** | Permanente |

## Transparência PASSIVA (arts. 10-14)

| | Conteúdo |
|---|---|
| Pedido | Qualquer interessado |
| **Identificação mínima** | Nome + documento + especificação |
| **Resposta** | **Imediata** se disponível ou **20 dias** (prorrogáveis por **10**) |
| Forma | Eletrônica (regra) |
| **Gratuita** | Salvo custo de reprodução |
| **Indeferimento** | Fundamentado |

## Classificação do sigilo (art. 24)

| Grau | Prazo máximo |
|---|---|
| **Ultrassecreta** | **25 anos** (renovável uma vez) |
| **Secreta** | **15 anos** |
| **Reservada** | **5 anos** |

## Competência para classificar (art. 27)

| Grau | Autoridade |
|---|---|
| **Ultrassecreta** | Presidente + Vice + Ministros + Comandantes Forças Armadas + Chefes Missões |
| **Secreta** | Mesmos + Titulares de autarquias/fundações/EP/SEM |
| **Reservada** | DAS 101.5 ou superiores |

## Pressupostos para sigilo (art. 23)

| Inc. | Hipóteses |
|---|---|
| **I** | Pôr em risco **defesa + soberania nacional** + integridade territorial |
| **II** | Prejudicar relações internacionais |
| **III** | Pôr em risco **vida + segurança da população** |
| **IV** | Pôr em risco **segurança das instituições** |
| **V** | Pôr em risco **operações estratégicas das Forças Armadas** |
| **VI** | Prejudicar pesquisas científicas/tecnológicas estratégicas |
| **VII** | Pôr em risco a **segurança de autoridades** + seus familiares |
| **VIII** | Comprometer atividades de **inteligência** + investigação |

> Lista taxativa: autoridade **não pode classificar** fora dessas hipóteses.

## Informações pessoais (art. 31)

| | Conteúdo |
|---|---|
| Sigilo | **100 anos** (regra geral) |
| Acesso restrito | Próprio titular + agentes públicos legalmente autorizados |
| **LGPD** | Convergência com regime de dados pessoais |
| **Servidor público** | Remuneração + dados funcionais são **públicos** (STF SS 3.902/AgR) |

## Procedimento e recursos (arts. 15-20)

| Fase | Conteúdo |
|---|---|
| 1ª instância | Servidor responsável pela informação |
| 2ª instância | Autoridade hierarquicamente superior (**10 dias** para recurso) |
| 3ª instância (federal) | **CGU**: última instância administrativa |
| 4ª instância (federal) | **CMRI** (Comissão Mista de Reavaliação de Informações), para classificação |
| **Mandado de segurança** | Via judicial (prazo 120 dias) |

| | Servidor |
|---|---|

## Informação ambiental (Tema IAC 13 STJ)

| | Conteúdo |
|---|---|
| Base | Lei 10.650/2003 art. 2 + LAI art. 8 + Lei 6.938/1981 art. 9 |
| **Tríplice acesso** | Transparência **ativa** (dever de publicar na internet os documentos ambientais não sigilosos) + **passiva** (direito de requerer informação específica não publicada) + **reativa** (direito de requerer a produção de informação inexistente) |
| **Presunção** | Presume-se a obrigação estatal de transparência, cabendo à Administração justificar o descumprimento (sem discricionariedade), sempre sob controle judicial |
| Registro imobiliário | Admite-se a averbação facultativa de informações ambientais de interesse público na matrícula do imóvel; o MP pode requisitar a averbação diretamente ao oficial de registro |
| Âncora | STJ, 1ª Seção, REsp 1.857.098/MS (Tema IAC 13), j. 11/05/2022 |

## Erros a evitar

- Recusar pedido por **falta de motivação** (vedada exigência, art. 10 §3);
- Aplicar sigilo **fora das hipóteses** do art. 23 (rol taxativo);
- Exceder prazo de **20 dias** + 10 prorrogação sem justificativa;
- Autorizar **prorrogação indefinida** do ultrassecreto (apenas **1 renovação** de 25 anos);
- Tratar **vencimentos de servidores** como sigilosos (Tema 483 STF);
- Não admitir **MS** contra recusa indevida (cabível);
- Afastar o acesso a **dados pessoais do próprio titular** (LGPD art. 18 + LAI 31);
- Exigir **autenticação cartorária** do solicitante (Lei 13.726 desburocratização);
- Cobrar pelo **acesso à informação** (gratuito salvo reprodução);
- Permitir **classificação por autoridade incompetente** (art. 27);
- Aplicar **sanções administrativas** ao servidor sem PAD com contraditório;
- Admitir pedido **genérico ou desproporcional** sem especificação (Dec. 7.724 art. 13);
- Afastar o acesso do próprio titular a dado sigiloso por **100 anos** (LAI 31 §1 I);
- Ignorar o fluxo recursal administrativo (autoridade superior + **CGU** + CMRI, arts. 15-16);
- Aplicar LAI a entidade privada **sem recursos públicos**;
- Não exigir resposta **fundamentada** ao indeferimento.

# Programa de Parcerias de Investimentos (PPI), Lei 13.334/2016

## Marco normativo

| | Conteúdo |
|---|---|
| **Lei 13.334/2016** | Cria o PPI |
| **Dec. 11.412/2023** | Dispõe sobre o Conselho do PPI (órgão de assessoramento imediato ao Presidente da República) |
| **Lei 11.079/2004** | PPP |
| **Lei 8.987/1995** | Concessões |
| **Lei 9.491/1997** | PND |
| **Lei 14.133/2021** | Licitações |

## Objetivos (art. 1)

| Inc. | Objetivo |
|---|---|
| **I** | Ampliar oportunidades de investimento em infraestrutura |
| **II** | Garantir expansão + qualidade da infraestrutura |
| **III** | Promover ampla competição |
| **IV** | Assegurar estabilidade + segurança jurídica |
| **V** | Fortalecer o papel regulador do Estado |
| **VI** | Apoiar entes subnacionais |

## Conceito de PPI

| | Conteúdo |
|---|---|
| Natureza | Programa federal de coordenação |
| Função | Catalisar PPPs + concessões + privatizações + parcerias |
| **Não cria** novo instrumento jurídico | Articula os já existentes |
| **Sujeitos** | União + Estados (por adesão) |

## Estrutura

| Órgão | Função |
|---|---|
| **Conselho do PPI** | Aprova qualificação + diretrizes; composto por Ministros + setoriais |
| **Secretaria do PPI** | Função executiva; vinculação ministerial variável conforme a organização do Executivo |
| **BNDES** | Apoio técnico + gestor |
| **EPL** (Empresa de Planejamento e Logística) | Estudos |
| **Banco do Brasil + CEF** | Operações financeiras |

## Qualificação de projetos

| Etapa | Conteúdo |
|---|---|
| **1. Indicação** | Pelo Ministério setorial |
| **2. Análise** | Pela Secretaria do PPI |
| **3. Aprovação** | Pelo Conselho do PPI |
| **4. Decreto presidencial** | Qualifica o empreendimento |
| **5. Tramitação prioritária** | Em todos os órgãos federais |

## Vantagens da qualificação

| | Conteúdo |
|---|---|
| **Apoio técnico** | EPL + BNDES + consultorias |
| **Tramitação prioritária** | Em órgãos e agências federais (licenciamento, regulação) |
| **Financiamento incentivado** | Acesso a debêntures incentivadas/de infraestrutura (Lei 12.431/2011 + Lei 14.801/2024) e FIP-IE, com benefícios tributários |
| **Acesso a recursos** | FGP + outros fundos |
| **Visibilidade política** | Atrai investidores |
| **Roadshows** | Internacionais |

## Setores prioritários

| Setor | Conteúdo |
|---|---|
| **Logística** | Rodovias + ferrovias + portos + hidrovias + aeroportos |
| **Energia** | Geração + transmissão + petróleo + gás |
| **Saneamento** | Lei 14.026 |
| **Telecomunicações** | Lei 9.472 + faixas 5G |
| **Segurança pública** | Excepcional |
| **Saúde + educação** | Em casos específicos |

## Procedimento de licitação

| | Conteúdo |
|---|---|
| **Concessão comum** | Lei 8.987 |
| **PPP** | Lei 11.079 |
| **Privatização** | Lei 9.491 |
| **Diálogo competitivo** | Lei 14.133 (em projetos complexos) |
| **Audiência pública** | Obrigatória |
| **Consulta pública** sobre edital | Mín. 30 dias |

## Coordenação federativa

| | Conteúdo |
|---|---|

## Erros a evitar

- Tratar PPI como **lei especial** que afaste 8.987/11.079/9.491 (apenas **coordena**);
- Permitir qualificação **sem aprovação** do Conselho;
- Admitir projeto qualificado **sem audiência pública** + estudos prévios;
- Confundir PPI com **PND** (institutos distintos);
- Aplicar PPI a entes **sem adesão** formal;
- Tratar **tramitação prioritária** como dispensa do controle ambiental/regulatório;
- Confundir os benefícios tributários das **debêntures incentivadas/de infraestrutura** (Lei 12.431/2011 + Lei 14.801/2024) com isenções genéricas;
- Não exigir **transparência** dos dados no painel PPI;
- Aplicar Lei 14.133 sem subsidiariedade às concessões/PPPs;
- Admitir **vinculação automática** de garantias sem análise de capacidade fiscal (LRF);
- Permitir **alienação** de bens fora do PND;
- Tratar Conselho do PPI como **órgão deliberativo definitivo** sem ratificação ministerial;
- Afastar **dispute board** ou arbitragem em projetos do PPI (Lei 14.133 art. 151-154);
- Admitir **step-in** sem cláusula contratual + anuência;
- Aplicar **prescrição quinquenal** a obrigações de continuidade;
- Tratar PPI como **ato de mero gabinete** sem fundamentação técnica.

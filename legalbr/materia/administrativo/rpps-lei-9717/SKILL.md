# Regime Próprio de Previdência Social (RPPS)

## Marco normativo

| | Conteúdo |
|---|---|
| **CF 40** (redação EC 103) | RPPS: princípios contributivo + solidário + equilíbrio financeiro/atuarial |
| **Lei 9.717/1998** | Normas gerais de organização do RPPS |
| **Lei 10.887/2004** | Cálculo + contribuição |
| **EC 103/2019** | Reforma estrutural |
| **EC 20/1998, 41/2003, 47/2005** | Antecessoras (regras de transição) |
| **Portaria MTP 1.467/2022** | Procedimentos atualizados |
| **Lei 12.618/2012** | **Funpresp** (previdência complementar federal) |

## Características (CF 40 + Lei 9.717)

| | Conteúdo |
|---|---|
| Filiação | **Servidor efetivo** (CF 37 II): apenas titulares de cargo efetivo |
| **Compulsória** | Sim |
| Caráter | **Contributivo + solidário** |
| Equilíbrio | **Financeiro + atuarial** (CF 40) |
| Vedação | **Não inclui** comissionados puros + temporários + empregados públicos (RGPS) |

## Filiados (CF 40 §13)

| Sujeito | Regime |
|---|---|
| Servidor efetivo | **RPPS** |
| **Comissionado** (sem cargo efetivo) | **RGPS** |
| **Temporário** Lei 8.745 | **RGPS** |
| **Empregado público** (CLT) | **RGPS** |
| **Detentor de mandato eletivo** | **RGPS** |
| **Magistrado/MP** | **RPPS** (sujeito ao CF 40) |

## Custeio (CF 40 §1 + Lei 9.717 art. 2 + Lei 10.887)

| | Conteúdo |
|---|---|
| **Tripartite** | Ente + servidor ativo + servidor inativo + pensionista (sobre o que excede teto RGPS) |
| **Alíquota mínima servidor** | **14%** (EC 103); pode ser progressiva por faixas |
| **Alíquota patronal** | Não inferior à do servidor e conforme necessidade atuarial (Lei 9.717 art. 2: até o dobro da contribuição do segurado) |
| **Contribuição extraordinária** | CF 149 §1-B (EC 103): para equacionar déficit, com prazo determinado |
| **Inativos/pensionistas** | Contribuem sobre o que **excede teto RGPS** (ADI 3.105) |

### Alíquotas progressivas pós-EC 103 (servidor federal)

| Faixa de salário-contribuição | Alíquota |
|---|---|
| Até 1 salário-mínimo | **7,5%** |
| Faixas intermediárias | 9% / 12% / 14% / 14,5% / 16,5% / 19% |
| Faixa superior | **22%** |

Os valores em reais de cada faixa são os do art. 11 da EC 103/2019, reajustados anualmente pelos mesmos índices do RGPS; citar sempre a tabela vigente no ano de referência.

## Vedações e sanções (Lei 9.717 arts. 5 e 7)

| Base | Conteúdo |
|---|---|
| **Art. 5 caput** | RPPS **não pode conceder benefícios distintos** dos previstos no RGPS (Lei 8.213/91), salvo disposição em contrário da própria CF |
| **Art. 5 par. único** | Vedada a concessão de **aposentadoria especial** (CF 40 §4) até que lei complementar discipline a matéria (lacuna suprida, no que couber, pela **SV 33**) |
| **Art. 7** | Descumprimento da lei: **suspensão das transferências voluntárias** da União, impedimento de convênios/avais/subvenções e suspensão de empréstimos por instituições financeiras federais |

## Segregação de massas

| | Conteúdo |
|---|---|
| Conceito | Separação da massa segurada em **plano financeiro** (regime de repartição) e **plano previdenciário** (regime de capitalização) |
| Aplicação | Para **garantir solvência** atuarial |
| Portaria MTP 1.467 | Disciplina operacional |
| **Plano financeiro** | Para servidores antigos: cobertura pelo ente |
| **Plano previdenciário** | Para servidores novos: capitalização de contribuições |

## Equilíbrio financeiro e atuarial (CF 40)

| | Conteúdo |
|---|---|
| **Cálculo atuarial** | Obrigatório (DRAA, Demonstrativo de Resultado da Avaliação Atuarial) |
| **Déficit atuarial** | Exige plano de equacionamento (até 35 anos) |
| **Insuficiência financeira** | Adimplemento pelo Tesouro (ente) |
| **Contribuição extraordinária** | Adicional aos contribuintes |

## CRP: Certificado de Regularidade Previdenciária

| | Conteúdo |
|---|---|
| Fundamento | Lei 9.717 art. 7 + Portaria MTP 1.467 |
| Função | Atesta cumprimento dos critérios; exigido para acessar transferências federais voluntárias |
| **Validade** | 180 dias |
| Renovação | Avaliação dos critérios atuariais + governança |

## Pró-Gestão RPPS

| | Conteúdo |
|---|---|
| Programa | **Adesão facultativa** dos entes |
| Níveis | I a IV: escalas de aprimoramento da governança |
| Acreditação | ISO 9001 + critérios da Portaria |
| **Vantagens** | Acesso a alíquotas patronais reduzidas + maior limite de aplicação |
| Atualização | Versão **3.0** vigente (2024) |

## Investimentos (Res. CMN 4.963/2021)

| | Conteúdo |
|---|---|
| Segmentos | Renda fixa + variável + estruturados + exterior + imobiliário + empréstimos consignados |
| **Limites por segmento** | Definidos por Res. CMN |
| **Pró-Gestão** | Aumenta limites em segmentos de risco |
| **Conflito de interesses** | Vedado uso dos recursos em operações com gestores/dirigentes |

## Funpresp (Lei 12.618/2012)

| | Conteúdo |
|---|---|
| **Funpresp-Exe** | Servidores Executivo + autarquias + fundações |
| **Funpresp-Jud** | Servidores Judiciário + MP |
| **Adesão** | **Automática** para ingresso após 04/02/2013 (Funpresp-Exe) |
| **ADI 5.502 STF** (sessão virtual encerrada em 09/06/2026) | **Constitucional** a inscrição automática de novos servidores federais na previdência complementar, preservado o direito de cancelamento (opt-out) com **restituição integral** das contribuições |
| Patrocínio | 7,5% paritário + voluntário até 8,5% |
| Plano | **Contribuição definida** (CD) |

## Benefícios (CF 40 + Lei 10.887)

| Benefício | Conteúdo |
|---|---|
| Aposentadoria por incapacidade permanente | Junta médica oficial |
| Aposentadoria compulsória | **75 anos** (LC 152) |
| Aposentadoria voluntária | 65H/62M + 25 anos contribuição + 10 SP + 5 cargo |
| Pensão por morte | Cota familiar 50% + 10% por dependente |
| **Rol limitado (EC 103 art. 9 §§2-3)** | O RPPS paga apenas **aposentadorias e pensão por morte**; incapacidade temporária, salário-maternidade, salário-família e auxílio-reclusão correm à conta do tesouro do ente, pelo RGPS ou por norma própria |

## Estado da arte 2026

| | Conteúdo |
|---|---|
| Adesão Pró-Gestão | Crescente, por incentivos econômicos |
| **EC 103** | Aplicada parcialmente nos Estados/Municípios (regras de benefício dependem de reforma local; alíquota mínima e vedações são nacionais) |
| Alíquotas extraordinárias | Admitidas pela EC 103 (CF 149 §1-B) para equacionar déficit, por prazo determinado |
| Equilíbrio atuarial | Princípio expresso da CF 40 (caráter contributivo e solidário) |
| Reforma administrativa | A PEC 32/2020 não avançou; em 2025 tramitou nova proposta (PEC 38/2025), também retirada de pauta. **Sem alteração vigente** ao RPPS |

## Erros a evitar

- Tratar **temporário** ou **comissionado puro** como filiado ao RPPS (CF 40 §13: RGPS);
- Admitir benefício distinto dos do RGPS no RPPS (Lei 9.717 art. 5);
- Admitir **estabilidade financeira sem cálculo atuarial** (CF 40);
- Aplicar alíquota inferior a **14%** (EC 103);
- Não exigir **CRP** para transferências voluntárias (Lei 9.717 art. 7);
- Permitir **investimento** fora dos limites da Res. CMN 4.963;
- Esquecer contribuição de **inativos/pensionistas** sobre o que excede teto RGPS;
- Confundir RPPS com **Funpresp** (RPPS é o regime; Funpresp é a previdência complementar);
- Tratar empregado público de **EP/SEM** como filiado ao RPPS (RGPS);
- Aplicar EC 103 a entes **sem EC local** correspondente (princípio federativo);
- Não distinguir **plano financeiro** (repartição) de **plano previdenciário** (capitalização);
- Aplicar regra de transição **errada** ao caso concreto (verificar ingresso + condições);
- Esquecer **direito adquirido** quando preenchidos requisitos antes da EC 103;
- Ignorar **Pró-Gestão** como prêmio para alíquotas reduzidas;
- Admitir benefício **sem fonte de custeio** (CF 195 §5: viola equilíbrio).

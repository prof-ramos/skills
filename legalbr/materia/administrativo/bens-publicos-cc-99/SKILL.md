# Bens Públicos

## CC 98: definição

| | Conteúdo |
|---|---|
| Tese | Bens **DE DOMÍNIO NACIONAL** pertencentes às PJ de **DIREITO PÚBLICO interno** |

## CC 99: CLASSIFICAÇÃO TRIPARTITE

| Inc. | Categoria |
|---|---|
| **I** | **USO COMUM DO POVO**: mares + rios + estradas + ruas + praças (uso geral + gratuito ou retribuído) |
| **II** | **USO ESPECIAL**: edifícios + terrenos para **serviço/estabelecimento** da Adm direta + autárquica (**AFETADOS**) |
| **III** | **DOMINICAIS**: patrimônio das PJ de direito público, **objeto de direito pessoal ou real** (desafetados) |

| | Conteúdo |
|---|---|
| **Par. único** | Bens de PJ de direito público com **ESTRUTURA DE DIREITO PRIVADO** = **dominicais**, salvo lei em contrário |

## CC 100-101: INALIENABILIDADE RELATIVA

| Art. | Conteúdo |
|---|---|
| **100** | **Uso comum + uso especial** = **INALIENÁVEIS enquanto conservarem qualificação** (afetação) |
| **101** | **DOMINICAIS** podem ser alienados observadas exigências legais |

## CC 102: IMPRESCRITIBILIDADE

| | Conteúdo |
|---|---|
| Tese | Bens públicos **NÃO sujeitos a USUCAPIÃO** |
| Confirmações | **CF 183 §3 + 191 par. único + Súm. 340 STF** |

## CC 103: uso comum

| | Conteúdo |
|---|---|
| Modo | **Gratuito OU retribuído** |

## IMPENHORABILIDADE

| | Conteúdo |
|---|---|
| Base | **CF 100**: **regime de PRECATÓRIOS** |
| Decorrência | Bens públicos são **IMPENHORÁVEIS + não onerabilidade** |

## CF 20: bens da UNIÃO

| | Conteúdo |
|---|---|
| Lista | **Terrenos de marinha + mar territorial + plataforma continental + recursos naturais da plataforma e ZEE + ilhas oceânicas e costeiras** (exceto sedes de Municípios) + **terras indígenas** + **recursos minerais + potenciais de energia hidráulica + cavidades naturais subterrâneas** etc. |

## CF 26: bens dos ESTADOS

| | Conteúdo |
|---|---|
| Lista | **Águas superficiais ou subterrâneas + fluentes + emergentes + em depósito** + **ilhas fluviais e lacustres** não pertencentes à União + **terras devolutas** não compreendidas entre as da União |

## Lei 9.636/1998: TERRENOS DE MARINHA

| | Conteúdo |
|---|---|

| **Lei 13.465/2017** | Permite remição do aforamento e alienação de terrenos da União (extinção gradual da enfiteuse em áreas urbanas) |

## Lei 14.133/2021: alienação de dominicais

| | Conteúdo |

| Dispensa | Doação a outro ente + permuta + investidura + venda a outro ente + alienação em procedimento judicial + dação em pagamento |

## Distinções essenciais

| | Uso comum | Uso especial | Dominicais |
|---|---|---|---|
| Afetação | Sim (público em geral) | Sim (serviço público) | **NÃO** (desafetados) |
| Alienabilidade | NÃO | NÃO | **SIM** (com requisitos) |
| Exemplos | Ruas + praças | Edifícios públicos | Imóveis vagos |

| | Bens públicos | Bens privados |
|---|---|---|
| Usucapião | **NÃO admite** (Súm. 340) | Admite |
| Impenhorabilidade | **Sim** | Apenas hipóteses específicas |

| | União (CF 20) | Estados (CF 26) |
|---|---|---|
| Recursos minerais | **União** | NÃO |
| Águas subterrâneas | NÃO | **Estados** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Praça pública | **Uso comum**: inalienável |
| Edifício do MJ | **Uso especial**: inalienável |
| Imóvel vazio do município | **Dominical**: alienável c/ requisitos |
| Usucapião contra ente público | **NÃO admite** (Súm. 340) |
| Penhora de bens públicos | **VEDADA** (precatório CF 100) |
| Alienação de imóvel | **Autorização legislativa** + **leilão** (Lei 14.133) |
| Terreno de marinha | **Lei 9.636** |
| ZEE + plataforma continental | **Bens da União** |
| Lago entre Estados | Conforme natureza |

## Erros a evitar

- **Admitir USUCAPIÃO contra ente PÚBLICO** (Súm. 340 + CC 102 vedam);
- Permitir **ALIENAÇÃO de USO COMUM** com afetação (CC 100);
- Aplicar **regime privado** a bem de uso especial;
- **Penhora de bem público** (vedada, precatório CF 100);
- Permitir **alienação de DOMINICAL sem requisitos** (Lei 14.133 art. 76);
- Aplicar **CC 99 sem CF 20/26** (titularidade);
- Tratar **terras devolutas** como União automaticamente (CF 26);
- Admitir **tributação INTER-ENTES** (CF 150 VI "a");
- Tratar a enfiteuse de **terrenos de marinha** como extinta (persiste sob lei especial: CC 2.038 §2 + Lei 9.636; a Lei 13.465/2017 apenas permite a remição do aforamento em certas áreas);
- Aplicar **CF 150 VI "a"** a entidade privada;
- Aplicar **CC 102 a empresa pública concorrencial** com prudência (regime distinto).

# Tomada de Contas Especial (TCE)

## Marco normativo

| | Conteúdo |
|---|---|
| **CF 71 II** | Julgamento de contas pelo TCU |
| **Lei 8.443/1992 arts. 8 + 16** | TCE federal |
| **IN TCU 98/2024** | Procedimento vigente (instauração, organização e envio ao TCU); **revogou a IN TCU 71/2012** |
| IN TCU 71/2012 | Norma anterior (referência histórica) |
| **Lei 4.320/1964 art. 84** | Tomada de contas (geral) |
| **Lei 10.180/2001** | Sistema de Contabilidade Federal |
| **Lei 14.133/2021** | Apuração de irregularidades contratuais (a Lei 8.666/1993 foi revogada e só se aplica, historicamente, a contratos por ela regidos) |
| **Lei 13.460 + 12.527** | Acesso e transparência |

## Conceito

| | Conteúdo |
|---|---|
| TCE | Procedimento administrativo específico para **apurar dano ao erário** + identificar **responsáveis** + obter **ressarcimento** |
| **Distinção** | Não se confunde com **PAD** (disciplinar) nem com **TCA** (tomada de contas anual) |
| **Natureza** | **Administrativa** com remessa ao TC |

## Cabimento (IN TCU 98/2024 + Lei 8.443 art. 8)

| Hipótese | Conteúdo |
|---|---|
| **I** | Omissão na prestação de contas |
| **II** | Dano ao erário |
| **III** | Irregularidade insanável que gere dano |
| **IV** | Não comprovação da aplicação de recursos repassados |
| **V** | Desvio de recursos |
| **VI** | Desfalque + apropriação indébita |
| **VII** | Prática de ato ilegal/ilegítimo/antieconômico que cause dano |

## Pré-TCE: diligências preliminares (IN TCU 98/2024)

| | Conteúdo |
|---|---|
| Pressuposto | Tentar **sanear** antes da TCE |
| Notificação | Para apresentar documentação ou ressarcir |
| **Prazo** | Conforme orientação interna |
| **Limite de valor (IN TCU 98/2024)** | Dispensa de instauração para débito inferior a **R$ 120 mil**; no somatório de débitos de um mesmo responsável consideram-se valores a partir de R$ 20 mil |

## Procedimento

| Fase | Conteúdo |
|---|---|
| **1. Instauração** | Por autoridade competente (gestor + controle interno) |
| **2. Comissão** | Constituição da equipe |
| **3. Apuração dos fatos** | Coleta de provas |
| **4. Quantificação do dano** | Valor + atualização + juros + correção |
| **5. Identificação dos responsáveis** | Solidários + subsidiários |
| **6. Citação dos responsáveis** | Apresentação de defesa + recolhimento |
| **7. Relatório** | Conclusivo |
| **8. Envio ao TCU** | Para julgamento |

## Quantificação do dano

| | Conteúdo |
|---|---|
| Critério | **Real** + apurado em valores atualizados |
| Correção | IPCA + Selic |
| **Juros** | A partir do evento danoso |
| **Acréscimos** | Conforme lei |

## Citação dos responsáveis

| | Conteúdo |
|---|---|
| Garantias | Contraditório + ampla defesa |
| Forma | Edital + AR + ciência |
| Prazo | Em regra 15-30 dias (variável conforme TCU) |
| **Solidariedade** | Entre gestor + agente + beneficiário |

## Decisão do TCU (Lei 8.443 art. 16)

| Decisão | Conteúdo |
|---|---|
| **Regulares** | Sem dano |
| **Irregulares** | Com débito + multa + sanção |
| **Iliquidáveis** | Quando não se pode apurar valor |
| **Sancionatória** | Inidoneidade + inabilitação |

## Sanções (Lei 8.443 arts. 57-58)

| | Conteúdo |
|---|---|
| Multa | Até **100% do dano** (Lei 8.443 art. 57) + multa administrativa do art. 58, em valor atualizado por ato do TCU |
| Débito | Restituição + correção + juros |
| **Inidoneidade** | Até **5 anos** para licitar |
| **Inabilitação** | Até **8 anos** para função pública |
| Comunicação | MP (improbidade + penal) |

## Execução do débito

| | Conteúdo |
|---|---|
| Título | **Acórdão TCU** = título executivo extrajudicial |
| **Execução** | Pela AGU (Lei 8.443 art. 28) |
| Foro | Justiça Federal (servidor federal) |
| **Inscrição em dívida ativa** | Possível |
| **Tema 899 STF (RE 636.886)** | Tese: "é prescritível a pretensão de ressarcimento ao erário fundada em decisão de Tribunal de Contas" (Plenário, rel. Min. Alexandre de Moraes, j. 20/04/2020); execução sujeita a prazo **quinquenal**, pelo regime da execução fiscal (art. 174 CTN + Lei 6.830/1980), inclusive prescrição intercorrente |
| **STF Tema 897 (RE 852.475)** | **Imprescritível** apenas o ressarcimento fundado em ato **doloso** tipificado na Lei de Improbidade |

## Articulação com improbidade (Lei 8.429 + 14.230)

| | Conteúdo |
|---|---|
| TCE + ACP improbidade | Procedimentos **independentes** |
| **Independência das instâncias** | Não há bis in idem (sanções administrativa, civil e penal de naturezas diversas) |
| **MP** | Comunicado de ofício pelo TCU |
| **Tema 897** | Dolo é pressuposto da imprescritibilidade |
| **STF ADIs 7.156/7.236 (2026)** | Validados o dolo e o rol taxativo da Lei 14.230; prescrição intercorrente da ação de improbidade mantida em **8 anos** (invalidada a redução para 4); teto de 20 anos de tramitação total |

## TCE + Lei Anticorrupção (12.846)

| | Conteúdo |
|---|---|
| Pessoa jurídica | Sujeita à TCE quando responsável por dano |
| **PAR** | Procedimento próprio + paralelo |
| **Acordo de leniência** | Pode incluir compromissos de ressarcimento |

## TCE x PAD (institutos distintos)

| | TCE | PAD |
|---|---|---|
| Finalidade | Ressarcir dano | Punir disciplinar |
| Competência final | TCU | Adm |
| Sanção | Débito + multa + inidoneidade | Advertência → demissão |
| Sujeito | Qualquer responsável | Servidor |
| **Conjugação** | Podem coexistir |

## TCE em casos especiais

| | Conteúdo |
|---|---|
| **Convênio** | TCE quando há dano em recursos repassados |
| **Chefe do Executivo (convênios)** | Em TCE por irregularidades no cumprimento de convênios interfederativos de repasse de verbas, o Tribunal de Contas pode condenar administrativamente (débito + multa) chefes do Executivo municipal, estadual ou distrital, quando identificada responsabilidade pessoal, **sem** necessidade de posterior julgamento ou aprovação pelo Legislativo (Tema 1.287 STF, ARE 1.436.197, Plenário, j. 12/2023); hipótese distinta do julgamento das contas anuais de governo, que cabe ao Legislativo |
| **Contrato administrativo** | TCE quando inexecução causou dano |
| **OS/OSCIP/MROSC** | TCE em recursos descentralizados |
| **Estatal** | Submetida a TCU se há recursos federais |

## Dispensa de TCE (IN TCU 98/2024)

| | Conteúdo |
|---|---|
| Valor | Débito inferior a **R$ 120 mil** (IN TCU 98/2024; o piso anterior da IN 71/2012 era R$ 100 mil) |
| **Pressuposto** | Salvo determinação em contrário do TCU; medidas administrativas de ressarcimento continuam devidas |
| **Reposição administrativa** | Substitui a instauração formal quando eficaz |

## Atualizações 2024-2026

| | Conteúdo |
|---|---|
| **IN TCU 98/2024** | Novo regime da TCE: dispensa abaixo de R$ 120 mil, arquivamento por prescrição na fase interna e abertura à consensualidade |
| **Portaria CGU 1.531/2021** | Orientações da CGU para a fase interna da TCE nos órgãos federais |
| **Resoluções TCU 344/2022 + 367/2024** | Regime de prescrição no controle externo pós-Tema 899 (Lei 9.873/1999): quinquenal para as pretensões punitiva e de ressarcimento + intercorrente de 3 anos; a Resolução 367/2024 estendeu a aferição da prescrição inclusive a acórdãos já em cobrança executiva (limitada a 5 anos do trânsito em julgado e vedada quando a prescrição já foi apreciada em recurso) e tornou personalíssima a interrupção (só atinge o destinatário da citação/notificação) |
| **CGU + AGU + TCU** | Atuação integrada |

## Erros a evitar

- Tratar como imprescritível a cobrança fundada em acórdão do TC sem ato doloso de improbidade (Tema 899 STF: prescritível, prazo quinquenal);
- Citar o **Tema 1.183/STJ** como precedente sobre prescrição da execução de acórdão de Tribunal de Contas: o tema trata, na verdade, da natureza (propter rem ou pessoal) do débito de rateio de despesas de associação de moradores em loteamento, para fins de penhora de bem de família (REsps 1.995.213/SP e 2.023.451/SP, 2ª Seção, ainda em julgamento), matéria estranha à TCE; o precedente correto é o **Tema 899 STF** (RE 636.886);
- Considerar **imprescritibilidade** sem prova de **dolo** (Tema 897);
- Confundir TCE com **PAD** (institutos distintos);
- Admitir TCE **sem contraditório** (CF 5 LV);
- Admitir cobrança sem **acórdão TCU** transitado;
- Não realizar **diligência preliminar** antes de instaurar TCE (IN TCU 98/2024);
- Tratar **TCE + ACP** como bis in idem (independência das instâncias: sanções de naturezas diversas);
- Aplicar **TCE + PAD** alternativamente (são complementares);
- Esquecer **AGU** como legitimada para execução (art. 28 Lei 8.443);
- Não atualizar valor com **IPCA + Selic** + juros desde o evento;
- Admitir solidariedade **sem nexo** (responsabilidade restrita ao quinhão);
- Suprimir **defesa por escrito** na fase de citação;
- Não comunicar MP em indícios de improbidade/crime;
- Aplicar **dispensa** de TCE fora das hipóteses da IN TCU 98/2024 ou com indício de má-fé;
- Considerar OS/OSCIP **isentas** de TCE (são submetidas);
- Exigir julgamento ou aprovação pelo Legislativo para condenação de chefe do Executivo pelo Tribunal de Contas em TCE de convênios interfederativos com responsabilidade pessoal (Tema 1.287 STF: condenação administrativa direta).

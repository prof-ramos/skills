# Convalidação de Atos Administrativos

## Marco normativo

| | Conteúdo |
|---|---|
| **CF 37** | LIMPE |
| **Lei 9.784/1999 art. 55** | Convalidação |
| **Súm. 473 STF** | Autotutela |
| **LINDB arts. 20-30** (Lei 13.655/18) | Consequencialismo |
| **Art. 54 Lei 9.784** | Decadência quinquenal |

## Texto do art. 55

> "Em decisão na qual se evidencie não acarretarem **lesão ao interesse público** nem prejuízo a terceiros, os atos que apresentarem **defeitos sanáveis** poderão ser convalidados pela própria Administração."

## Pressupostos

| | Conteúdo |
|---|---|
| **Defeito sanável** | Não atinge núcleo essencial |
| **Sem lesão ao interesse público** | Avaliação concreta |
| **Sem prejuízo a terceiros** | Boa-fé preservada |
| **Decisão fundamentada** | Da Administração |
| **Forma** | Por ato superveniente |

## Espécies de convalidação

| Espécie | Conteúdo |
|---|---|
| **Ratificação** | Autoridade competente reedita o ato com seu poder de decisão |
| **Reforma** | Suprime parte viciada + mantém parte sã |
| **Conversão** | Transforma o ato em outro válido (ex: revogação por anulação) |
| **Confirmação** | Mero reconhecimento da validade |

## Vícios sanáveis x insanáveis

| Elemento | Sanável? |
|---|---|
| **Competência** | **Sim** se hierárquica + competência de mesma categoria |
| **Forma** | **Sim** em vícios não essenciais |
| **Finalidade** | **Não** (desvio é insanável) |
| **Motivo** | **Não** se inexistente ou falso |
| **Objeto** | **Não** se ilícito |

## Convalidação x ratificação

| | Conteúdo |
|---|---|
| Ratificação | Espécie de convalidação |
| Conteúdo | Confirmação por autoridade competente |
| **Hierarquia** | Autoridade superior ratifica ato de inferior incompetente |

## Convalidação x revogação x anulação

| Instituto | Causa | Efeitos |
|---|---|---|
| **Convalidação** | Vício sanável | **Ex tunc** do ato original |
| **Revogação** | Conveniência | Ex nunc |
| **Anulação** | Ilegalidade insanável | Ex tunc + desfaz efeitos |

## Decadência (art. 54) + convalidação

| | Conteúdo |
|---|---|
| 5 anos | Para anular ato favorável |
| **Decorrido prazo** | Ato é **estabilizado** (não mais anulável, salvo má-fé) |
| **Má-fé** | Afasta a decadência |
| **Tema 138 STF** | Anulação que afeta interesses individuais exige prévio contraditório |

## Exemplos práticos

| Situação | Convalidação |
|---|---|
| Ato assinado por autoridade incompetente em razão da hierarquia | Ratificação por superior |
| Ato com forma simplificada | Reforma para forma adequada |
| Ato com data incorreta | Confirmação |
| Concessão de licença com vício de procedimento + boa-fé do beneficiário | Confirmação após 5 anos |
| Nomeação por autoridade incompetente | Ratificação se requisitos materiais atendidos |

## Hipóteses de **não** convalidação

| | Conteúdo |
|---|---|
| **Desvio de finalidade** | Insanável |
| **Objeto ilícito** | Insanável |
| **Motivo falso/inexistente** | Insanável |
| **Competência em razão da matéria** | Insanável |
| **Lesão ao interesse público** | Veda convalidação |
| **Prejuízo a terceiros** | Veda |

## Estabilização x convalidação

| | Conteúdo |
|---|---|
| **Estabilização** | Efeitos do tempo (decadência art. 54) |
| **Convalidação** | Ato positivo da Adm sanando vício |
| Coexistência | A estabilização pode ser pressuposto + a convalidação a institucionaliza |

## LINDB art. 24

> "A revisão, nas esferas administrativa, controladora ou judicial, quanto à validade de ato, contrato, ajuste, processo ou norma administrativa cuja produção já se houver completado **levará em conta as orientações gerais da época**..."

| | Conteúdo |
|---|---|
| Sentido | Adm tem que considerar **boa-fé** + interpretação da época |
| **Reforço da convalidação** | Vícios sanáveis avaliados conforme as orientações gerais da época |
| Segurança jurídica | Estabilização dos atos consolidados |

| | Conteúdo |

## Erros a evitar

- Convalidar ato com **vício insanável** (motivo + finalidade + objeto);
- Aplicar convalidação **com prejuízo** a terceiros (vedada);
- Considerar **revogação** como convalidação (institutos distintos);
- Aplicar efeitos **ex nunc** à convalidação (é ex tunc);
- Esquecer **decisão fundamentada** da Administração;
- Convalidar **competência em razão da matéria** (vedada);
- Tratar **estabilização por decadência** como sinônimo de convalidação (institutos próximos mas distintos);
- Convalidar com **má-fé** do beneficiário (impede a estabilização e a convalidação);
- Aplicar convalidação a ato **inexistente** (sem suporte);
- Não exigir **autoridade competente** na ratificação;
- Esquecer **LINDB 24** em casos de orientações novas;
- Considerar a convalidação **automática** após 5 anos (a decadência opera; a convalidação requer ato);
- Permitir Judiciário substituir a Adm na convalidação (regra);
- Esquecer **terceiros de boa-fé** + **direitos adquiridos**;
- Tratar **conversão** como anulação (instituto próprio);
- Permitir convalidação **sem motivação**.

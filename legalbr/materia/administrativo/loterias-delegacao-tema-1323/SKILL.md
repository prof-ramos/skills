# Exploração de Loterias por Agentes Privados

## Base normativa

| | Conteúdo |
|---|---|
| **CF 22 XX** | Compete privativamente à **União** legislar sobre **sistemas de sorteios** |
| **CF 175** | Concessão/permissão de serviço público mediante **licitação** |
| **DL 6.259/44** + DL 204/67 | Regime de loterias federais |
| **Lei 13.756/2018** | Loteria federal + apostas de quota fixa (LotEx) |
| **Lei 14.790/2023** | Apostas de quota fixa (bets): regulamentação + tributação |
| **ADPF 492 + 493** | STF reconheceu que **loterias estaduais** podem ser exploradas pelos próprios estados |
| **Lei 8.987/95** | Lei das Concessões |

## STF Tema 1.323 (RE 1.498.128)

| | Conteúdo |
|---|---|
| Fixada | **28/09/2024** (Plenário Virtual, repercussão geral com reafirmação de jurisprudência; trânsito em julgado em 09/10/2024) |
| **Tese** | "A execução do serviço público de loteria por agentes privados depende de delegação estatal precedida de licitação" |
| Consequência | **Vedada** a exploração por particular sem regular delegação |

## ADPF 492 + 493: loterias estaduais

| | Conteúdo |
|---|---|
| Tese | Estados-membros podem **explorar loterias** (próprias) sob a competência estadual |
| Limite | Loterias **NÃO podem fugir do regime de exploração estatal direta ou via delegação licitada** |

## Distinções

| Hipótese | Saída |
|---|---|
| Estado explora loteria estadual diretamente | **Cabível** (ADPF 492/493) |
| Estado delega loteria estadual a agente privado | **Cabível com licitação** (Tema 1.323) |
| Agente privado opera loteria sem delegação | **Vedado** (Tema 1.323) |
| União opera loteria federal (Caixa) | Cabível diretamente |
| Particular operando jogo de azar sem regulamentação | Crime de contravenção (LCP) + ilícito civil |
| Apostas de quota fixa (bets) sem licença pela SPA/MF | Operação irregular (Lei 14.790/23) |
| Bingo eletrônico em casa noturna | Verificar enquadramento legal (em regra, vedado) |
| Loteria filantrópica autorizada | Regime próprio (autorização específica) |

## Lei 14.790/2023 (apostas de quota fixa: "bets")

| | Conteúdo |
|---|---|
| **Bets** | Apostas de quota fixa: o jogador conhece a chance e o prêmio antes |
| **Autorização** | Pela Secretaria de Prêmios e Apostas (SPA) do Ministério da Fazenda |
| **Outorga** | R$ 30 milhões + 5 anos prorrogáveis |
| **Tributação** | Apostadores: 15% sobre prêmios + operadoras: 12% da receita |
| **Limites** | Verificação biométrica + faixa etária 18+ + autoexclusão + responsabilidade social |
| **Vedações** | Crédito + cartão de crédito + alguns formatos de divulgação |
| **Fiscalização** | SPA + outras agências |

## Aplicação prática

| Hipótese | Saída |
|---|---|
| Estado realiza licitação para concessão de loteria | **Cabível** (Tema 1.323) |
| Município pretende criar loteria municipal | **Inviável** (CF 22 XX: competência federal) |
| Casa de apostas online sem autorização SPA | **Operação ilegal** |
| Empresa estrangeira com licença em outro país opera no Brasil | Precisa de autorização brasileira (Lei 14.790) |
| Bingos eletrônicos em estabelecimento privado | Em regra, vedados (DL 3.688/41 art. 50) |
| Apostas em jogos de cassino físico | Pendente regulamentação |
| Apostas esportivas reguladas pela Lei 14.790 | **Cabíveis** com licença |
| Concurso de prognósticos (loterias federais) | Operadas pela Caixa |

| | Conteúdo |

## Erros a evitar

- A exploração de **loteria por privado** exige **delegação licitada** (Tema 1.323);
- O Estado tem competência para explorar **loterias próprias** (ADPF 492/493);
- O **Município** não pode criar loteria municipal (CF 22 XX: competência federal);
- As **apostas de quota fixa** (bets: Lei 14.790) não se confundem com **loterias** tradicionais;
- A casa de apostas **sem licença SPA** não é "atividade econômica livre" (regulação específica);
- As **rifas filantrópicas** com autorização específica têm regime próprio (fora do Tema 1.323);
- O bingo eletrônico privado não se autoriza por decreto estadual (regime federal: CF 22 XX);
- As apostas esportivas reguladas não exigem **adicional** de licença estadual (regime federal nacional);
- A contratação com casa de apostas estrangeira sem autorização é vedada;
- A contravenção do jogo (LCP 50) é tipo vigente;
- A fraude em apostas é estelionato (CP 171), fora do Tema 1.323;
- O concurso de prognóstico operado por OSCIP sujeita-se ao seu regime específico;
- A tributação das **bets** é prevista expressamente (Lei 14.790);
- O sorteio promocional comercial autorizado pela CAIXA tem regime distinto (Lei 13.756 + Portaria SPA), fora do Tema 1.323.

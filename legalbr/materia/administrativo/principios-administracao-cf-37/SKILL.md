## Súmula Vinculante 13: NEPOTISMO

| | Conteúdo |
|---|---|
| Veda | Nomeação de **cônjuge + companheiro + parente até 3º grau** (linha reta + colateral + afinidade) |
| Da autoridade | Nomeante OU servidor em **direção + chefia + assessoramento** |
| Para | **Cargo em comissão + função de confiança + função gratificada** |
| Alcance | Qualquer Poder/ente |
| Inclui | **NEPOTISMO CRUZADO** (designações recíprocas) |
| **Exceção clássica** | **Cargos POLÍTICOS** (Ministros + Secretários estaduais/municipais) |

## STF Tema 1.000 (RE 1.133.118): estado atual

| | Conteúdo |
|---|---|
| Objeto | Aplicação da vedação ao nepotismo aos **cargos políticos** de alto escalão |
| Estado | Julgamento **SUSPENSO** por pedido de vista em **15/04/2026**, **sem tese fixada**; tendência de estender a vedação, com exceções motivadas (ex.: inexistência de terceiros aptos) |
| Cargos eletivos | **NÃO se aplica** SV 13 |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Nomeação de cônjuge para cargo em comissão | **VEDADA** (SV 13) |
| Nomeação para Ministério | Exceção tradicional (cargo político), mas pendente o Tema 1.000 |
| Nepotismo cruzado | **VEDADO** (SV 13) |
| Cargo eletivo | **NÃO se aplica** SV 13 |
| Publicidade pessoal | **VEDADA** (CF 37 §1) |
| Improbidade culposa pré-Lei 14.230 com trânsito | **MANTIDA** |
| Improbidade culposa SEM trânsito | **EXTINÇÃO** (Tema 1.199) |
| Servidor passa em concurso + 3 anos | **Estabilidade** (CF 41) |
| Dano a particular por agente | **Resp. OBJETIVA** (CF 37 §6) |
| Acima do teto | Limitado ao subsídio Ministro STF |

## Erros a evitar

- **Aplicar SV 13 a CARGO ELETIVO** (não se aplica);
- **Confundir legalidade administrativa com PRIVADA**;
- Tratar **moralidade** como mera ética **não vinculante**;
- Ignorar **controvérsia atual** sobre cargos políticos (Tema 1.000 pendente);
- Aplicar **Lei 14.230/2021 retroativamente** com trânsito em julgado (Tema 1.199 veda);
- Afastar **transparência tributária** pós-EC 132/2023;
- **Admitir publicidade PESSOAL** de servidor (CF 37 §1);
- Aplicar **responsabilidade subjetiva** ao Estado por ato comissivo (objetiva, CF 37 §6);
- Não respeitar **teto remuneratório** desembargadores;
- Aplicar SV 13 sem caracterizar **direção/chefia/assessoramento** do nomeante;
- Aplicar **nepotismo a parente além do 3º grau** (limite da SV 13).

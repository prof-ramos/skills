# Tribunal de Contas da União (TCU)

## Marco normativo

| | Conteúdo |
|---|---|
| **CF 70-75** | Controle externo + TCU |
| **Lei 8.443/1992** | Lei orgânica do TCU |
| **Regimento Interno** | Resolução TCU 246/2011 (atualizada) |
| **Lei 13.655/2018 (LINDB)** | Decisões com consequências práticas |
| **Lei 14.230/2021 (LIA)** | Articulação com improbidade |
| **EC 113/2021** | EC dos precatórios: repercussões no controle |

## Natureza jurídica

| | Conteúdo |
|---|---|
| Órgão | **Auxiliar do Poder Legislativo** (CF 71), **não subordinado** |
| Função | Predominantemente **administrativa** |
| **Decisões** | Atos administrativos, sem coisa julgada material |
| **Autonomia** | Funcional + administrativa + financeira |
| Composição | **9 ministros** (CF 73): 3 indicados pelo Presidente + 6 pelo Congresso |

## Competências (CF 71)

| Inc. | Conteúdo |
|---|---|
| **I** | **Apreciar contas do Presidente** (parecer prévio) |
| **II** | **Julgar contas** dos administradores + responsáveis por dinheiros + ente que receba transferência |
| **III** | **Apreciar** legalidade de atos de **admissão de pessoal** + **concessão de aposentadorias/pensões** (não inclui nomeações de comissão) |
| **IV** | Realizar **inspeções e auditorias** por iniciativa própria ou da CD/SF |
| **V** | Fiscalizar contas nacionais de **empresas supranacionais** |
| **VI** | Fiscalizar **aplicação** de recursos federais transferidos a Estado/DF/Município |
| **VII** | Prestar **informações** ao Congresso |
| **VIII** | Aplicar **sanções** |
| **IX** | Assinalar **prazo** para correção |
| **X** | **Sustar** ato (não contrato) |
| **XI** | Representar ao Poder competente |

## Diferenças contas Presidente x contas administradores

| | Presidente | Administradores |
|---|---|---|
| **Função** | Parecer **prévio** | **Julga** |
| Decisão final | Congresso (CD + SF) | TCU |
| Recurso | Político | Administrativo + judicial (Súm. 347 STF) |

## Julgamento de contas (Lei 8.443 art. 1 I)

| Decisão | Conteúdo |
|---|---|
| **Regulares** | Sem ressalvas |
| **Regulares com ressalvas** | Pequenas irregularidades sem dano |
| **Irregulares** | Dano + omissão + ato ilegítimo + ato antieconômico |

## Sanções (Lei 8.443 art. 16)

| Sanção | Limite |
|---|---|
| **Multa** | Até **100% do dano** (art. 57) + multa administrativa do art. 58, em valor atualizado por ato normativo do TCU |
| **Débito** | Restituição do dano (acrescido de juros + correção) |
| **Inidoneidade** | Para licitar com a Adm Pública por até **5 anos** |
| **Inabilitação** | Para função pública por até **8 anos** |
| **Bloqueio** de bens | Cautelar |
| **Sustação** do ato | Quando ilegal |
| **Recomendações** + alertas | Não vinculantes |

## Tomada de Contas Especial (Lei 8.443 art. 8 + IN TCU 71/2012)

| | Conteúdo |
|---|---|
| Cabimento | Dano ao erário + omissão de prestar contas + irregularidade insanável |
| Fases | Apuração + quantificação + procedimento administrativo + envio ao TCU |
| Decisão | Julgamento com débito + multa |
| **Tema 899 STF** | É prescritível a pretensão de ressarcimento ao erário fundada em decisão de Tribunal de Contas (aplica-se prazo quinquenal) |
| **STF Tema 897** | Imprescritíveis apenas as ações de ressarcimento fundadas em ato **doloso** tipificado na Lei de Improbidade |
| **Execução** | Pelo ente lesado (AGU): título executivo extrajudicial |

## Apreciação de atos de pessoal (CF 71 III)

| | Conteúdo |
|---|---|
| Abrange | Admissão por concurso + aposentadorias + reformas + pensões |
| Não abrange | Cargo em comissão + função de confiança |
| **Natureza** | **Ato complexo** (STF MS 24.268): só se aperfeiçoa com registro |
| **Prazo para julgamento** | **5 anos** para o TC julgar a legalidade do ato de concessão inicial de aposentadoria, reforma ou pensão, contados da chegada do processo à Corte de Contas (Tema 445 STF) |
| **Súm. Vinc. 3** | Contraditório e ampla defesa asseguradas quando a decisão puder anular ou revogar ato que beneficie o interessado, **excetuada** a apreciação da legalidade do ato de concessão inicial de aposentadoria, reforma e pensão |

## Contraditório (Súm. Vinc. 3 + Tema 445 STF)

| | Conteúdo |
|---|---|
| Regra | Contraditório **obrigatório** quando a decisão puder anular/revogar ato que beneficie o interessado (SV 3) |
| Exceção | Apreciação da legalidade da **concessão inicial** de aposentadoria, reforma e pensão (SV 3, parte final) |
| **Prazo de 5 anos** | Esgotado o prazo do Tema 445 STF sem julgamento, o TC não pode mais rever a concessão inicial |
| Defesa | Por escrito + sustentação oral (se permitido) |
| **Inversão de ônus** | Adm prova |

## Sustação de contratos (CF 71 X + §1-2)

| | Conteúdo |
|---|---|
| TCU **NÃO susta** contratos diretamente | Apenas atos |
| **Congresso Nacional** | Susta contrato (CF 71 §1) |
| Se Congresso não decidir em **90 dias** | TCU pode determinar medidas |
| **Cautelar** | TCU pode determinar suspensão **provisória** de contrato em casos urgentes (STF MS 24.510) |

## Recursos administrativos (Lei 8.443 arts. 32-35)

| Recurso | Conteúdo |
|---|---|
| **Pedido de reexame** | Apreciação de atos sujeitos a registro |
| **Recurso de reconsideração** | Acórdão em processo de contas (15 dias) |
| **Embargos de declaração** | 10 dias |
| **Agravo** | Decisão monocrática |
| **Revisão** | Em hipóteses específicas |

## Controle judicial (CF 5 XXXV + Súm. 347 STF)

| | Conteúdo |
|---|---|

| **MS** | Cabe contra decisões do TCU (CF 102 I d) |
| **Foro do MS** | **STF** quando contra TCU plenário |

## Erros a evitar

- Tratar decisão do TCU como **coisa julgada** material (é ato administrativo);
- Negar **contraditório** quando a decisão puder anular ato que beneficie o interessado (SV 3);
- Admitir **sustação direta de contrato pelo TCU** (compete ao Congresso, CF 71 §1);
- Tratar como imprescritível a cobrança fundada em acórdão do TC sem ato doloso de improbidade (Tema 899 STF: prescritível, prazo quinquenal);
- Afastar **imprescritibilidade** em ato doloso comprovado (Tema 897);
- Tratar TCU como **órgão subordinado ao Legislativo** (auxilia, sem subordinação);
- Ignorar o **prazo de 5 anos** do Tema 445 STF para o julgamento da legalidade da concessão inicial;
- Esquecer aplicação da Súm. 347 em controle de constitucionalidade pelo TCU;
- Afastar **MS** contra ato do TCU plenário ao STF (CF 102 I d);
- Confundir contas do **Presidente** (parecer prévio) com contas dos **administradores** (julgamento);
- Aplicar **inabilitação** acima de **8 anos** (limite legal);
- Tratar débito como **prescrito** sem analisar marco;
- Não admitir cautelar do TCU (admissível);
- Confundir TCE com PAD;
- Não aplicar LINDB (arts. 20-26) nas decisões do TCU.

# Agências Reguladoras

## Lei 13.848/2019 (lei geral)

| | Conteúdo |
|---|---|
| Natureza | **AUTARQUIA EM REGIME ESPECIAL** |
| Autonomia | **Administrativa + funcional + decisória + financeira** |
| Subordinação hierárquica | **AUSENTE** |

## Mandatos dos diretores

| | Conteúdo |
|---|---|
| **Duração** | **5 ANOS** (alterado pela Lei 13.848; antes, 4) |
| **Não coincidentes** | Sim |
| Recondução | **VEDADA** (regra); exceção do art. 5 §7 da Lei 9.986/2000 para quem cumpriu mandato-tampão remanescente ≤ 2 anos |
| **Sabatina** | **SENADO FEDERAL** (CF 52 III "f") |
| **QUARENTENA** | **6 MESES** pós-mandato + remuneração compensatória |

## Instrumentos da Lei 13.848

| | Conteúdo |
|---|---|
| **AGENDA REGULATÓRIA** | Anual |
| **AIR** (Análise de Impacto Regulatório) | **OBRIGATÓRIA** (Lei 13.848 art. 6), com hipóteses de dispensa (Dec. 10.411/2020 art. 4) |
| **Audiências + consultas públicas** | Para atos normativos |
| **Conselhos consultivos** | Sim |
| **Prestação de contas** | TCU + Congresso |

| | Conteúdo |
|---|---|
| Caso | ANVISA / aditivos do cigarro |

| | Conteúdo |
|---|---|
| **Lei 9.472 art. 19 XIX** | A Anatel exerce controle, prevenção e repressão de infrações à ordem econômica nas telecomunicações, **ressalvadas as competências do CADE** |
| **Lei 13.848 art. 25** | Cooperação + atuação conjunta entre agência e CADE |

## Lei 13.460/2017 (usuário de serviços públicos)

| | Conteúdo |
|---|---|
| Tese | Direitos dos **USUÁRIOS de serviços públicos** |
| Exige | **Ouvidorias + cartas de serviço** |

## Controle judicial: deferência técnica

| | Conteúdo |
|---|---|
| Regra | **CONTROLE MITIGADO** (deferência técnica) |
| Sindicabilidade | **PLENA** quanto a **motivação + devido processo regulatório + proporcionalidade** |
| Sancionamento | **Lei 9.784/1999 supletivamente** |

## Distinções essenciais

| | Agência reguladora | Autarquia comum |
|---|---|---|
| Regime | **ESPECIAL** | Comum |
| Mandato | **5a + sabatina + quarentena** | Sem |
| Autonomia | **Plena (4 dimensões)** | Limitada |

| | Agência | CADE |
|---|---|---|
| Foco | Setor regulado | **Concorrência GERAL** |
| Prevalência em concorrência | NÃO (CADE prevalece) | Sim |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Telecomunicações | **ANATEL** |
| Saúde suplementar | **ANS** |
| Cigarro/aditivos | **ANVISA** (ADI 4.874) |
| Conduta anticompetitiva em telecom | Competências do **CADE ressalvadas** (Lei 9.472 art. 19 XIX) + cooperação (Lei 13.848 art. 25) |
| Sancionamento por agência | **Devido processo + proporcionalidade** |
| Norma regulatória sem AIR (exigida e não dispensada) | **Irregularidade procedimental** (Lei 13.848 art. 6 + Dec. 10.411/2020 arts. 3-4): repercussão sobre a validade aferida no caso concreto; o Dec. 10.411 art. 21 dispõe que a inobservância não acarreta, por si, a invalidade da norma |
| Diretor pós-mandato + atividade no setor | **Quarentena 6m** |
| Mandato com recondução | **VEDADA** |
| Audiência pública | **Obrigatória** para normas |
| Usuário de serviço | **Lei 13.460/2017** |
| Controle judicial | **Restrito a legalidade + motivação** |

## Erros a evitar

- **Substituir MÉRITO TÉCNICO** da agência (deferência);
- **Permitir RECONDUÇÃO** de diretor (vedada);
- Tratar a ausência de AIR, quando exigida e não dispensada (Lei 13.848 art. 6 + Dec. 10.411/2020 arts. 3-4), como **nulidade automática**: é irregularidade procedimental cuja repercussão sobre a validade se afere no caso concreto (Dec. 10.411 art. 21);
- Aplicar **subordinação hierárquica** (autonomia plena);
- Afastar **quarentena de 6m** ao diretor;
- Permitir **CADE não atuar em concorrência setorial** (prevalência);
- Tratar **deslegalização como genérica** (ADI 4.874: com limites);
- Aplicar **Lei 9.784 sem supletividade** (Lei 13.848 prevalece);
- Permitir **norma sem audiência pública** quando exigida;
- Confundir **autarquia comum com agência** (regime distinto);
- Permitir **sabatina por outra Casa** (é Senado, CF 52 III "f").

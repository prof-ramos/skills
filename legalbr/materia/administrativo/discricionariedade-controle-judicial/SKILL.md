# Discricionariedade Administrativa e Controle Judicial

## Marco normativo

| | Conteúdo |
|---|---|
| **CF 5 XXXV** | Inafastabilidade |
| **CF 37** | LIMPE |

| **CPC art. 489** | Fundamentação |
| **STF Tema 698** | Controle judicial |

## Conceitos

| | Conteúdo |
|---|---|
| **Vinculação** | Lei prevê integralmente o ato + sem margem |
| **Discricionariedade** | Lei concede **margem** de escolha quanto a **conveniência + oportunidade + conteúdo** |
| **Conceito jurídico indeterminado** | Termo aberto na norma; não é discricionariedade pura |
| **Mérito administrativo** | Zona de decisão **dentro** dos limites legais |

## Elementos do ato (Lei 4.717 art. 2)

| Elemento | Vinculado/Discricionário |
|---|---|
| **Competência** | **Vinculado** |
| **Forma** | **Vinculado** (em regra) |
| **Finalidade** | **Vinculado** (interesse público) |
| **Motivo** | Vinculado quanto à existência; discricionário quanto à valoração (em parte) |
| **Objeto** | **Discricionário** (em ato discricionário) |

## Mérito administrativo x Controle Judicial

| | Conteúdo |
|---|---|
| **Mérito** | Núcleo da discricionariedade: **conveniência + oportunidade** |
| **Vedação clássica** | O Judiciário não substitui o juízo de conveniência e oportunidade da Administração |
| **Controle possível** | Legalidade, motivação, razoabilidade e proporcionalidade do ato |
| Limite | A revisão do mérito é excepcional (violação a direitos fundamentais ou desvio) |

## Princípios de controle (jurisprudência consolidada)

| Princípio | Conteúdo |
|---|---|
| **Legalidade** | Inerente |
| **Motivação** | Razões expressas (Lei 9.784 art. 50) |
| **Razoabilidade** | Adequação entre meios e fins |
| **Proporcionalidade** | Adequação + necessidade + proporcionalidade em sentido estrito |
| **Impessoalidade** | Decisão sem favoritismos |
| **Moralidade** | Aderência ética |
| **Eficiência** | Resultado adequado |
| **Consequencialismo** | LINDB 20 |

## Teoria dos motivos determinantes

| | Conteúdo |
|---|---|
| Conceito | Quando a Adm motiva, vincula-se à motivação; se os motivos são falsos, o ato é nulo |
| Aplicação | Exoneração ad nutum de cargo em comissão dispensa motivação; se motivada, vincula-se aos motivos declarados |
| **Jurisprudência STF/STJ** | Exoneração ad nutum independe de motivação; declarada, incide a teoria dos motivos determinantes |
| Crítica | Hoje, motivação é regra (Lei 9.784) |

## Controle de políticas públicas (ADPF 45 + Tema 698)

| | Conteúdo |
|---|---|
| **Reserva do possível** | Limite: capacidade orçamentária |
| **Mínimo existencial** | Núcleo intangível |
| **Tema 698 STF** | Intervenção judicial não viola separação de poderes em caso de ausência ou deficiência grave do serviço; sem substituição do mérito |
| **Bloqueio de verbas** | Medida excepcional, sujeita à proporcionalidade |

| Art. | Conteúdo |
|---|---|

## Erros a evitar

- **Substituir** o mérito administrativo sem fundamento (vedado em regra);
- Não exigir **motivação** (Lei 9.784 art. 50);
- Tratar o controle do mérito como ilimitado: ele é excepcional (legalidade/motivação/proporcionalidade);
- Recusar controle de **proporcionalidade** em ato discricionário;
- Esquecer **consequencialismo** (LINDB 20);
- Não aplicar regime de **transição** em nova interpretação (LINDB 23);
- Responsabilizar agente por **divergência razoável** (LINDB 28);
- Aplicar a **reserva do possível** para negar o mínimo existencial;
- Tratar **conceito jurídico indeterminado** como mérito puro;
- Afastar controle de **falsidade dos motivos**;
- Aplicar revogação a ato vinculado (Súm. 473);
- Anulação de ato sem considerar **consequências** (LINDB 21);
- Tratar ato discricionário como **insuscetível** de controle judicial (CF 5 XXXV);
- Considerar **motivação posterior** como suficiente (CF 93 IX por extensão);
- Confundir desvio de **finalidade** (interesse público) com desvio de **objeto** (conteúdo);
- Não fundamentar concretamente a decisão (CPC 489);
- Aplicar consequencialismo como **renúncia** ao controle de legalidade.

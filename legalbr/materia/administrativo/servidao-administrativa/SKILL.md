# Servidão Administrativa

## Marco normativo

| | Conteúdo |
|---|---|
| **CF 5 XXII-XXV** | Propriedade + intervenções |
| **CF 175** | Serviços públicos |
| **DL 3.365/1941 art. 40** | Servidão por decreto |
| **CC arts. 1.378-1.389** | Servidão (regime civil aplicável subsidiariamente) |
| **Lei 8.987/1995** | Concessionárias podem instituir |
| **Lei 9.074/1995** | Setor elétrico |
| **Lei 12.351/2010** | Regime do pré-sal (partilha de produção) |
| **Lei Geral das Antenas (Lei 13.116/2015)** | Telecomunicações |

## Conceito

| | Conteúdo |
|---|---|
| Natureza | **Direito real público** sobre imóvel privado |
| Finalidade | **Utilidade pública** |
| **Ônus** | Suportar atividade da Administração (ou concessionária) |
| Sujeito ativo | **Adm direta + indireta + concessionárias autorizadas** |
| Sujeito passivo | **Proprietário** do imóvel serviente |

## Características

| | Conteúdo |
|---|---|
| **Mantém o domínio** | Proprietário continua dono |
| **Restrição parcial** | Não esvazia totalmente |
| **Caráter perpétuo** | Em regra |
| **Indenização** | Pelo **dano efetivo** (não pela propriedade) |
| **Registro** | Cartório de Registro de Imóveis: caráter erga omnes |

## Espécies (DL 3.365 art. 40)

| Modalidade | Conteúdo |
|---|---|
| **Por acordo** | Convenção entre Adm + proprietário (escritura pública) |
| **Por sentença** | Após processo expropriatório (servidão) |
| **Por decreto + registro** | Quando há autorização legislativa específica (setoriais) |

## Procedimento

| Fase | Conteúdo |
|---|---|
| 1. **Declaração de utilidade pública** | Por decreto |
| 2. **Tentativa de acordo** | Negociação |
| 3. **Ajuizamento** | Caso não haja acordo (rito do DL 3.365) |
| 4. **Imissão na posse** | Mediante depósito prévio |
| 5. **Avaliação** | Pelo perito |
| 6. **Sentença** | Constitui a servidão |
| 7. **Registro** | No CRI |

## Indenização

| | Conteúdo |
|---|---|
| Critério | **Dano efetivo** + desvalorização |
| **Não inclui** | Valor do domínio (mantém-se com o proprietário) |
| Cálculo | Diferença entre valor do imóvel **antes + depois** |
| Pagamento | Prévio + justo + em dinheiro |
| **Súm. 56 STJ** | Juros compensatórios devidos pela limitação de uso da propriedade na servidão administrativa |

## Servidão x desapropriação

| | Servidão | Desapropriação |
|---|---|---|
| Transfere domínio | **Não** | Sim |
| Indenização | Dano efetivo | Valor venal/mercado |
| Caráter | Ônus real | Aquisição |
| Reversibilidade | Permanece com o particular | Adquirida pela Adm |
| Procedimento | DL 3.365 art. 40 | DL 3.365 + CC |

## Servidão x limitação administrativa

| | Servidão | Limitação |
|---|---|---|
| Caráter | **Específica** (imóvel determinado) | **Geral** (universal) |
| Indenização | Sim | **Não** (em regra) |
| Direito real | **Sim** (registro) | Não |
| Forma | Acordo + sentença + decreto | Lei + ato administrativo |

## Servidão x requisição

| | Servidão | Requisição |
|---|---|---|
| Caráter | **Permanente** | **Transitória** |
| Pressuposto | Utilidade pública | **Emergência** (CF 5 XXV) |
| Indenização | Antes (em regra) | Posterior se houver dano |
| Direito real | Sim | Não |

## Erros a evitar

- Confundir servidão (não transfere domínio) com **desapropriação**;
- Tratar servidão como **gratuita** (exige indenização do dano efetivo);
- Afastar a indenização sob argumento de manutenção do domínio (pode haver desvalorização indenizável);
- Aplicar a regra da **desapropriação** (valor venal) à servidão (dano efetivo);
- Permitir servidão **por mero ato administrativo** sem registro ou sentença (não é eficaz erga omnes);
- Confundir **servidão** (específica) com **limitação** (geral);
- Aplicar **regime civil** integralmente (servidão administrativa tem regime próprio);
- Tratar a servidão como **transitória** (é permanente em regra);
- Atribuir à servidão eficácia **inter partes** sem registro;
- Aplicar **prescrição quinquenal** à servidão em si (é direito real; prescreve apenas a pretensão indenizatória);
- Esquecer **juros compensatórios + moratórios** (Súm. 56 + 70 STJ);
- Admitir servidão em favor de **particular** sem delegação legal (utilidade pública);
- Não permitir **ação possessória** ao titular da servidão (cabe);
- Confundir **cessação** com mera inatividade (não basta);
- Aplicar servidão a **bem público** dominante (não cabe: bens públicos têm regime próprio);
- Tratar como regra geral o desconto de IPTU sobre a área de servidão: a repercussão na base de cálculo (valor venal, CTN 33) depende da legislação municipal e da avaliação concreta do imóvel.

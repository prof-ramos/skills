# Tombamento (DL 25/1937)

## Marco normativo

| | Conteúdo |
|---|---|
| **CF 216 §1** | Tombamento como instrumento |
| **DL 25/1937** | Lei do Tombamento |
| **CF 23 III-IV** | Competência comum |
| **CF 24 VII-VIII** | Competência concorrente |
| **Lei 3.924/1961** | Patrimônio arqueológico |
| **Lei 11.483/2007** | Patrimônio ferroviário (extinta RFFSA); atribuições ao IPHAN |
| **CPC/2015 art. 1.072, I** | Revogou o art. 22 do DL 25/37 (direito de preferência) |

## Conceito

| | Conteúdo |
|---|---|
| Natureza | Instrumento de proteção do **patrimônio cultural** |
| Sujeito ativo | União (IPHAN) + Estados (IEPHA, CONDEPHAAT) + Municípios |
| **Não transfere** o domínio | Mantém-se com o particular |
| **Caráter** | Limitação (provisório) que evolui para servidão (definitivo) |
| **Registro** | No Livro do Tombo |

## Espécies (DL 25 arts. 6-9)

| Espécie | Conteúdo |
|---|---|
| **Voluntário** | Iniciativa do **proprietário** + concordância da entidade |
| **Compulsório** | Por ato da Adm + resistência do particular |
| **De ofício** | Bens públicos: o órgão inscreve diretamente |
| **Provisório** | Limitação, durante o processo (DL 25 art. 10) |
| **Definitivo** | Servidão, após inscrição no Livro |

## Procedimento (DL 25 arts. 8-9)

| Fase | Conteúdo |
|---|---|
| **1. Manifestação inicial** | Pelo IPHAN ou proprietário |
| **2. Notificação do proprietário** | Pessoal |
| **3. Impugnação** | 15 dias |
| **4. Parecer do IPHAN** | Técnico |
| **5. Decisão** | Pelo Presidente do IPHAN |
| **6. Inscrição** | No Livro do Tombo |
| **7. Recurso ao Ministro** (Cultura) | 30 dias |

## Livros do Tombo (DL 25 art. 4)

| Livro | Conteúdo |
|---|---|
| **I** | Arqueológico, Etnográfico e Paisagístico |
| **II** | Histórico |
| **III** | Belas Artes |
| **IV** | Artes Aplicadas |

## Efeitos do tombamento (DL 25 arts. 11-17)

| | Conteúdo |
|---|---|
| **Vedação de alteração + demolição** | Sem autorização |
| **Conservação** | Ônus do proprietário (admite custeio pelo Estado em estado crítico) |
| **Autorização para reformas** | IPHAN/órgão competente |
| **Saída do país** | Vedada |
| **Direito de preferência** (DL 25 art. 22) | **REVOGADO** pelo CPC/2015 (Lei 13.105 art. 1.072, I); não mais exigível |
| **Vizinhança** (art. 18) | Vizinho não pode fazer obra que prejudique visibilidade do bem |

## Direito de preferência (DL 25 art. 22): REVOGADO

| | Conteúdo |
|---|---|
| **Status** | **REVOGADO** pelo art. 1.072, I, do CPC/2015 (Lei 13.105/2015) |
| **Antes da revogação** | União, Estado e Município tinham preferência, nessa ordem, na alienação onerosa de bem tombado |
| **Atualmente** | Proprietário pode alienar livremente o bem tombado, sem dever de oferecê-lo previamente ao Poder Público |
| **Permanece** | Demais restrições do tombamento (vedação de alteração/demolição, autorização para reformas, proibição de saída do país) |

## Tombamento de bens públicos

| | Conteúdo |
|---|---|
| Possível | Sim, entre entes diversos (competência comum de proteção, CF 23 III-IV) |
| **De ofício** | Pela Administração proprietária ou pelo órgão de proteção competente (DL 25 art. 5) |
| **Tombamento entre entes** | Tema controvertido na jurisprudência; a proteção do patrimônio cultural é competência comum, mas o tombamento de bem de outro ente exige cautela e fundamentação específica |

## Indenização

| | Conteúdo |
|---|---|
| **Regra** | **Não há** indenização (carga geral) |
| **STF (jurisprudência)** | Indenização apenas em caso de **dano específico** comprovado |
| **Esvaziamento econômico** | Configura desapropriação indireta: indenizável |
| **Restauro + manutenção** | Encargo do particular (admite-se auxílio público) |

## Tombamento provisório x definitivo

| | Provisório | Definitivo |
|---|---|---|
| Caráter | **Limitação** | **Servidão (registrada)** |
| Eficácia | Após notificação | Após inscrição |
| Efeitos | Mesmos do definitivo (DL 25 art. 10) | Permanentes |

| Transfere domínio | **Não** | Sim |

## Tombamento ambiental + paisagístico

| | Conteúdo |
|---|---|
| CF 216 + Lei 6.938 | Coexistem |

| **APA + UC** (Lei 9.985) | Regime próprio + pode coexistir |

## Cancelamento do tombamento (DL 25 art. 19)

| | Conteúdo |
|---|---|
| Possível | Por ato motivado da Adm |
| **Procedimento** | Idêntico ao tombamento (rito inverso) |
| **Motivação** | Exige-se motivação técnica robusta |
| **Causa** | Perda do valor cultural ou descaracterização irreversível |

## Tombamento de bens móveis

| | Conteúdo |
|---|---|
| Cabível | Sim |
| Exemplos | Obras de arte + documentos + utensílios |

## Patrimônio Imaterial (Dec. 3.551/2000)

| | Conteúdo |
|---|---|

## Erros a evitar

- Admitir **indenização** automática em tombamento (regra: não há, salvo dano específico comprovado);
- Confundir tombamento (não transfere) com desapropriação;
- Exigir **direito de preferência** do art. 22 do DL 25/37 (REVOGADO pelo CPC/2015 art. 1.072, I);
- Tratar tombamento como **propriedade pública**;
- Admitir alteração **sem autorização** do IPHAN/órgão competente;
- Aplicar **prazo decadencial** ao tombamento (não há);
- Considerar tombamento **provisório** sem efeitos (tem mesmos do definitivo, art. 10);
- Afastar conservação **ônus do particular** com auxílio público em estado crítico;
- Tratar **tombamento entre entes** como automaticamente válido ou inválido (tema controvertido; exige fundamentação específica);
- Aplicar **tombamento sem motivação técnica** (vício insanável);
- Recusar **MS** contra ato do IPHAN (cabível);
- Confundir patrimônio **material** com **imaterial** (regimes próprios);
- Tratar UC ambiental como tombamento (institutos próprios);
- Admitir saída de bem tombado **do país** sem autorização (sanção criminal);
- Não aplicar **vizinhança** (art. 18), obra que prejudique visibilidade;
- Admitir cancelamento sem **motivação** robusta + procedimento.

# Consórcios Públicos (Lei 11.107/2005)

## Marco normativo

| | Conteúdo |
|---|---|
| **CF 241** (EC 19/1998) | Gestão associativa entre entes |
| **Lei 11.107/2005** | Lei nacional |
| **Dec. 6.017/2007** | Regulamento federal |
| **Lei 14.026/2020** | Marco do saneamento (consórcios privilegiados) |
| **Lei 13.822/2019** | Estabeleceu o regime **CLT** para empregados de consórcio público (de direito público ou privado) |
| **Lei 13.821/2019** | Reduziu exigências (fiscais/tributárias/previdenciárias) para convênios da União com consórcios |

## Conceito

| | Conteúdo |
|---|---|
| Definição | Pessoa jurídica formada **exclusivamente por entes federativos** (União/Estados/DF/Municípios) |
| Forma | Associação pública (PJ direito **público**) ou PJ direito **privado** sem fins lucrativos |
| **Finalidade** | Gestão associativa de serviços + atividades + bens |
| Base | **Federalismo cooperativo** (CF 18) |

## Natureza jurídica

| Modalidade | Conteúdo |
|---|---|
| **Associação pública** | Adquire personalidade jurídica de **direito público** com a vigência das leis de ratificação; integra a **administração indireta** dos entes consorciados (CF 37 XIX) |
| **PJ direito privado** | Atende às normas civis + regras de direito público quanto a licitação + contabilidade + pessoal |

## Constituição (arts. 3-6)

| Etapa | Conteúdo |
|---|---|
| **1. Protocolo de intenções** | Subscrito pelos chefes do Executivo dos entes |
| **2. Ratificação** | Mediante **lei** de cada ente |
| **3. Contrato de consórcio** | Após ratificação |
| **4. Estatuto** | Regulamentação operacional |

## Cláusulas obrigatórias do protocolo de intenções (art. 4)

| Inc. | Conteúdo |
|---|---|
| **I** | Denominação + finalidade + prazo + sede |
| **II** | Identificação dos entes consorciados |
| **III** | Indicação da área de atuação |
| **IV** | Previsão de associação pública ou PJ direito privado |
| **V** | Critérios para representação na assembleia geral |
| **VI** | Forma de eleição do representante legal (presidente, necessariamente Chefe do Executivo de um dos entes) |
| **VII** | Direito de cada um dos entes consorciados em **se retirar** + **exclusão** |
| **VIII** | Forma de aprovação de contas, prestação de contas e liquidação |
| **IX** | Foro (residência da sede) |
| **X** | **Aporte de bens, recursos, pessoal** + critérios |
| **XI** | Autorização para licitar e contratar |
| **XII** | Limites do contrato de rateio |
| **XIII** | Direito do consórcio a tarifas e outras espécies de preços |

## Contrato de rateio (art. 8)

| | Conteúdo |
|---|---|
| Conceito | Instrumento pelo qual os entes **fornecem recursos financeiros** ao consórcio |
| **Anual** | **Formalmente renovado** a cada exercício |
| LRF | Despesa de **caráter continuado**: exige inclusão na LDO/LOA |
| Sanção por inadimplemento | Exclusão do ente do consórcio (após procedimento) |
| **Pressuposto** | Dotação orçamentária prévia |

## Contrato de programa (art. 13)

| | Conteúdo |
|---|---|
| Conceito | Instrumento pelo qual o consorciado **executa obrigações** previstas no protocolo (ou se obriga a executar) |
| Cabimento | Prestação de serviços + transferência de pessoal + uso compartilhado de bens |
| **Sem licitação** (Lei 14.133 art. 75 XI) | Permite contratação direta de consórcio público pelos entes consorciados para a celebração de contrato de programa |
| **Saneamento** | Lei 14.026/2020: restringiu o uso direto sem prévia regulação |
| **Continuidade** | Permanece mesmo com saída do consorciado |

## Vantagens

| | Conteúdo |
|---|---|
| Ganhos de escala | Compras conjuntas |
| Especialização técnica | Sim |
| Compartilhamento de bens + pessoal | Sim |
| **Custeio compartilhado** | Rateio entre os entes |
| **Acesso a transferências federais** | Voluntárias e obrigatórias |
| **Imunidade recíproca** | CF 150 VI a, quando associação pública |

## Pessoal

| | Conteúdo |
|---|---|
| **Regime** | **CLT** (regra): Lei 11.107 art. 6 §2 + Lei 13.822/2019 |
| Concurso público | **Obrigatório** (CF 37 II) |
| **Cessão** | Permitida dos entes consorciados (art. 4 IX h) |
| Remuneração | Conforme plano de cargos do consórcio + observa teto |

## Regime de licitação

| | Conteúdo |
|---|---|
| **Associação pública** | Lei 14.133 (regime de Administração indireta) |
| **PJ direito privado** | Lei 14.133 (regime análogo) |
| **Limites diferenciados** (Lei 14.133 art. 75 §2) | Os limites de dispensa por valor (art. 75 I e II) são **dobrados** para compras/obras/serviços contratados por consórcio público (e por autarquia/fundação qualificada como agência executiva) |
| **Contratação direta entre consorciados e consórcio** (Lei 14.133 art. 75 XI) | Permitida (contrato de programa) |

## Regime de contas e controle

| | Conteúdo |
|---|---|
| Contabilidade própria | Conforme Lei 4.320/64 |
| **TCE/TCU** | Controle externo conforme natureza do recurso |
| **Prestação de contas** | A cada ente conforme repasse |
| LRF | Aplicação integral |

## Saída e exclusão (art. 11)

| | Conteúdo |
|---|---|
| **Saída** | Voluntária: exige lei específica |
| **Exclusão** | Por inadimplemento: observa contraditório |
| Efeitos | Recuperação de bens + assunção de obrigações |
| **Continuidade** dos contratos | Em regra mantida pelos remanescentes |

## Saneamento (Lei 14.026/2020)

| | Conteúdo |
|---|---|
| Consórcios | Forma **prioritária** de prestação regionalizada |
| **URE** (Unidade Regional de Saneamento) | Quando inexistente consórcio |
| **Regulação** | ANA dispõe normas de referência (Lei 14.026 art. 4-A) |
| **Reflexos** | Universalização até **2033** (incentivo a consórcios) |

## Jurisprudência (STF/STJ)

| | Conteúdo |
|---|---|
| **Fundamento constitucional** | CF 241 (EC 19/1998): gestão associada de serviços públicos por consórcios e convênios de cooperação |
| **Associação pública** | Integra a Adm indireta (CF 37 XIX + Lei 11.107 art. 6 §1): natureza autárquica interfederativa, com imunidade recíproca (CF 150 VI a e §2) |
| **Tarifas e preços públicos** | O consórcio pode ser autorizado a arrecadar tarifas e outros preços públicos pelos serviços que prestar (Lei 11.107 art. 2 §2 + art. 4 XIII) |

## Estado da arte 2024-2026

| | Conteúdo |
|---|---|
| Saúde | Consórcios intermunicipais de saúde (uso disseminado) |
| Saneamento | Marco Legal 14.026: consolidação |
| Resíduos sólidos | Lei 12.305: incentivo |

## Erros a evitar

- Tratar consórcio como mero **convênio** (Lei 11.107 é regime autônomo);
- Permitir admissão por **PJ não pública** (entes federativos apenas);
- Admitir consórcio **sem ratificação por lei** (art. 5);
- Confundir **contrato de rateio** (custeio) com **contrato de programa** (execução);
- Permitir contrato de rateio **plurianual** sem previsão expressa do protocolo;
- Não aplicar **LRF** ao consórcio;
- Permitir contratação de pessoal **fora do regime CLT** (regra) sem fundamento legal;
- Tratar associação pública como **direito privado** (é direito público + Adm indireta);
- Afastar **imunidade recíproca** à associação pública (CF 150 VI a e §2: natureza autárquica);
- Aplicar **Lei 14.133** ao protocolo de intenções (instrumento próprio);
- Permitir **saída** sem lei do ente (art. 11);
- Permitir contrato de programa **sem objeto definido** (art. 13);
- Esquecer **limites dobrados** de dispensa de licitação por valor para consórcios (Lei 14.133 art. 75 §2);
- Admitir **inadimplemento sem exclusão** + procedimento (art. 8 §5);
- Aplicar **Lei do Voluntariado** a empregado do consórcio (vínculo formal);
- Admitir **contratação direta** entre ente e consórcio sem previsão expressa (art. 75 XI: contrato de programa);
- Aplicar Lei 14.026 a serviço **fora do saneamento** (regime saneamento específico).

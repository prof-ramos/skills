# OSCIPs (Lei 9.790/1999)

## Marco normativo

| | Conteúdo |
|---|---|
| **Lei 9.790/1999** | Lei das OSCIPs |
| **Dec. 3.100/1999** | Regulamento |
| **CF 5 XVII-XX** | Liberdade associativa |
| **Lei 13.019/2014 (MROSC)** | Coexistência |

## Conceito

| | Conteúdo |
|---|---|
| Natureza | Pessoa jurídica de **direito privado sem fins lucrativos** |
| Qualificação | **Vinculada**: Ministério da Justiça (deferida se preenchidos requisitos) |
| **Áreas (art. 3)** | 12 finalidades, sociais e públicas |
| Instrumento | **Termo de parceria** (Lei 9.790 art. 9) |

## Áreas (art. 3: 12 finalidades)

| Inc. | Finalidade |
|---|---|
| **I** | Promoção da assistência social |
| **II** | Promoção da cultura, defesa e conservação do patrimônio histórico/artístico |
| **III** | Promoção gratuita da educação |
| **IV** | Promoção gratuita da saúde |
| **V** | Promoção da segurança alimentar e nutricional |
| **VI** | Defesa, preservação e conservação do meio ambiente + desenvolvimento sustentável |
| **VII** | Promoção do voluntariado |
| **VIII** | Promoção do desenvolvimento econômico e social + combate à pobreza |
| **IX** | Experimentação não lucrativa de novos modelos sócio-produtivos + sistemas alternativos de produção, comércio, emprego e crédito |
| **X** | Promoção de direitos estabelecidos + construção de novos direitos + assessoria jurídica gratuita |
| **XI** | Promoção da ética + paz + cidadania + DH + democracia + outros valores universais |
| **XII** | Estudos + pesquisas + desenvolvimento de tecnologias alternativas |

## Entidades **vedadas** (art. 2)

| | Conteúdo |
|---|---|
| Sociedades comerciais | Sim |
| Sindicatos + associações de classe + entidades religiosas | Sim |
| Instituições hospitalares **não filantrópicas** | Sim |
| Partidos políticos | Sim |
| Cooperativas | Sim |
| OS já qualificada (Lei 9.637) | Sim |
| Entidades de benefício mútuo a determinada categoria | Sim |
| Fundações públicas | Sim |
| Fundações instituídas por OS, sindicatos, etc. | Sim |
| Organizações creditícias vinculadas ao Sistema Financeiro | Sim |

## Requisitos para qualificação (art. 4)

| | Conteúdo |
|---|---|
| Objetivos compatíveis | Com art. 3 |
| Estatuto com cláusulas obrigatórias | Princípios: observância LIMPE + universalidade serviços + publicidade + transparência + impessoalidade |
| Conselho fiscal | **Obrigatório** |
| Vedação de **distribuição** de bens/lucros | Sim |
| Destinação de patrimônio em extinção | A outra OSCIP ou entidade pública |
| **Prestação de contas** | Conforme princípios contábeis |
| **Auditoria independente** | Para movimentações > limite (Dec. 3.100) |

## Termo de parceria (art. 9-11)

| | Conteúdo |
|---|---|
| Conceito | Instrumento jurídico que disciplina a parceria com a Adm |
| **Plano de trabalho** | Obrigatório |
| Metas + indicadores | Obrigatórios |
| Prazo | Definido conforme objeto |
| **Consulta** ao Conselho de Política Pública correspondente | Obrigatória se houver |
| **Concurso de projetos** | Obrigatório na esfera federal (Dec. 3.100/99 art. 23, redação do Dec. 7.568/2011), com exceções fundamentadas do art. 23 §2 |

## Seleção impessoal (CF 37 + Dec. 7.568/2011; ADI 1.923 por analogia)

| Ponto | Conteúdo |
|---|---|
| Impessoalidade | A seleção da OSCIP parceira deve ser objetiva e impessoal (CF 37 caput) |
| Concurso de projetos | Obrigatório por força do Dec. 7.568/2011 (art. 23 do Dec. 3.100); a ADI 1.923 tratou da Lei 9.637 (OS) e reforça, por analogia, a exigência de seleção objetiva e impessoal (CF 37) |
| Aquisições da OSCIP | Devem seguir **regulamento próprio** + princípios CF 37 |
| Seleção de pessoal | Objetiva |

## Diferenças OSCIP x OS

| Aspecto | OS (9.637) | OSCIP (9.790) |
|---|---|---|
| Instrumento | **Contrato de gestão** | **Termo de parceria** |
| Áreas | 6 (restritas) | **12** (amplas) |
| Qualificação | **Discricionária** | **Vinculada** |
| Conselho | Composição mista | **Conselho fiscal** próprio |
| Cessão de servidor | **Sim** | **Não** (Lei 9.790 não autoriza) |
| Bens públicos | Permissão | Não há regime específico |

## Diferenças OSCIP x OSC (MROSC)

| Aspecto | OSCIP | OSC (MROSC) |
|---|---|---|
| Lei | 9.790/1999 | 13.019/2014 |
| Instrumento | Termo de parceria | Termo de colaboração/fomento/cooperação |
| Qualificação | **Sim** (MJ) | **Não** |
| Instituto | Anterior | Mais recente, mais detalhado |
| **Convivência** | Sim: entidade pode ser qualificada e celebrar parcerias por ambas as leis |
| Tendência atual | Crescimento do **MROSC** como regime principal |

## Aquisições pela OSCIP

| | Conteúdo |
|---|---|
| Regulamento próprio | Obrigatório |
| Conteúdo | Princípios da CF 37 |
| Cotação prévia | Mínima: 3 propostas |
| **Jurisprudência do TCU** | Paradigmas sobre prestação de contas e seleção em termos de parceria |
| **Vedação** | Subcontratação para empresa cujo dirigente seja agente público parente |

## Prestação de contas (arts. 11-12)

| | Conteúdo |
|---|---|
| Periódica | Conforme cronograma |
| Final | Após encerramento |
| **Auditoria independente** | Obrigatória se valores movimentados > limite (Dec. 3.100) |
| **Publicação** | Sítio oficial + jornais |
| Não aprovação | Devolução + TCE + sanções |

## Sanções (art. 13)

| | Conteúdo |
|---|---|
| Causa | Descumprimento + irregularidade financeira + uso desviado |
| **Procedimento** | Administrativo + contraditório |
| **Perda da qualificação** | Pelo Ministério da Justiça |
| **Penal** | Crimes contra a Administração + improbidade |
| **Suspensão** | Decretação cautelar dos bens (medida judicial) |

## Estado da arte 2024-2026

| | Conteúdo |
|---|---|
| Tendência | Migração para **MROSC** (13.019) |
| **OSCIPs ativas** | ~3.000 no Brasil (cadastro MJ) |
| **Chamamento/seleção objetiva** | Exigência decorrente da impessoalidade (CF 37) e do Dec. 3.100 art. 23 (red. Dec. 7.568/2011); a ADI 1.923 (Lei 9.637/OS) aplica-se por analogia |
| **TCU** | Diretrizes para aquisições com recursos do termo de parceria (seleção objetiva e comprovação de preços) |
| **Lei 14.133/2021** | Não traz dispensa específica para o terceiro setor; o termo de parceria da OSCIP segue regime próprio (Lei 9.790 + Dec. 3.100), com chamamento/concurso de projetos |

## Erros a evitar

- Tratar OSCIP como **OS** ou vice-versa (institutos distintos);
- Considerar qualificação como OSCIP **discricionária** (é vinculada se requisitos preenchidos);
- Aceitar **sindicato, partido, cooperativa** como OSCIP (vedadas, art. 2);
- Aplicar Lei 9.790 a entidade não enquadrada em uma das **12 finalidades**;
- Permitir termo de parceria **sem plano de trabalho** + metas;
- Aceitar contratações pela OSCIP **sem regulamento próprio**;
- Tratar **cessão de servidor** como permitida em OSCIP (vedada; só em OS);
- Aplicar **Lei 14.133** integralmente ao termo de parceria (regime autônomo);
- Permitir **auditoria independente facultativa** em movimentação acima do limite;
- Confundir **conselho fiscal** (OSCIP) com **conselho misto de gestão** (OS);
- Atribuir à **ADI 1.923** (que julgou a Lei 9.637/OS) tese específica sobre OSCIP: a obrigatoriedade do concurso de projetos na esfera federal decorre do Dec. 3.100 art. 23 (red. Dec. 7.568/2011), e a seleção objetiva/impessoal decorre do CF 37;
- Considerar **doação direta** sem termo de parceria (vedada salvo Lei 13.019 cooperação);
- Tratar OSCIP como Adm indireta (é privada);
- Não aplicar **devolução + TCE** em irregularidades graves;
- Permitir **acumulação** OS + OSCIP simultânea (vedada, art. 2 §1).

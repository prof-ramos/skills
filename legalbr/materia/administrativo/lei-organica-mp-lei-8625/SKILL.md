# Lei Orgânica do MP

## CF 127: natureza institucional

| | Conteúdo |
|---|---|
| Definição | Instituição **PERMANENTE + ESSENCIAL** à função jurisdicional |
| Função | Defesa da **ordem jurídica + regime democrático + interesses sociais e individuais indisponíveis** |

## Estrutura

| MP | Base | Conteúdo |
|---|---|---|
| **MPU** | **LC 75/1993** | **MPF + MPT + MPM + MPDFT** |
| **MPs Estaduais** | **Lei 8.625/1993** | Lei Orgânica Nacional |
| Cada MP estadual | Edita | Lei complementar própria |

## CF 127 §1: PRINCÍPIOS

| | Conteúdo |
|---|---|
| **UNIDADE** | Cada MP é **UM SÓ ÓRGÃO** sob direção do PGJ/PGR |
| **INDIVISIBILIDADE** | Membros podem ser **SUBSTITUÍDOS** uns pelos outros |
| **INDEPENDÊNCIA FUNCIONAL** | Cada membro age conforme **convicção jurídica**, **SEM subordinação hierárquica funcional** |

## CF 127 §§ 2-3: AUTONOMIA

| | Conteúdo |
|---|---|
| Funcional | Atuação independente |
| **Administrativa** | Gestão própria |
| **Financeira** | **Iniciativa de proposta orçamentária** + proposição de criação/extinção de cargos |

## CF 129: FUNÇÕES INSTITUCIONAIS

| Inc. | Conteúdo |
|---|---|
| **I** | **Promover privativamente a AÇÃO PENAL PÚBLICA** |
| **II** | Zelar pelo efetivo respeito dos Poderes Públicos aos direitos assegurados |
| **III** | **Promover INQUÉRITO CIVIL + ACP** para proteção do patrimônio público/social/meio ambiente/interesses difusos e coletivos |
| **IV** | **Ajuizar ADI/ADC** |
| **V** | Defender direitos das **populações indígenas** |
| **VI** | **Expedir notificações + requisitar informações/documentos** |
| **VII** | **CONTROLE EXTERNO da atividade POLICIAL** |
| **VIII** | Requisitar diligências investigatórias + instaurar inquérito policial |
| **IX** | Outras funções compatíveis |

## CF 128 §5: GARANTIAS + VEDAÇÕES

### Garantias (I)
| | Conteúdo |
|---|---|
| **Vitaliciedade** | Após **2 ANOS** de exercício |
| **Inamovibilidade** | Idem magistratura |
| **Irredutibilidade** | De subsídios |
| **Regime remuneratório** | Equiparado ao da magistratura (CF 129 §4); sujeição ao teto do CF 37 XI e vedação à criação/expansão de verbas por atos infralegais; conjunto das verbas indenizatórias limitado a 35% do subsídio (Temas 976 e 966 STF, 2026, mantidos nos embargos de declaração; auxílio-saúde por reembolso de despesas comprovadas fora do cômputo) |

### Vedações (II)
| | Conteúdo |
|---|---|
| **Advocacia** | Vedada |
| **Outra função pública** | Salvo **magistério** |
| **Honorários/custas** | Vedados |
| **Atividade político-partidária** | Vedada |
| **QUARENTENA de 3 ANOS** | Para advocacia no juízo ou tribunal do qual se afastou (**EC 45/2004**, CF 128 §6) |

## CNMP: CF 130-A (EC 45/2004)

| | Conteúdo |
|---|---|
| Composição | **14 MEMBROS** |
| Função | **CONTROLE ADMINISTRATIVO + DISCIPLINAR** dos MPs |

## ANPP: Lei 13.964/2019 (Pacote Anticrime)

### CPP art. 28-A
| | Conteúdo |
|---|---|
| Instrumento | **Consensualidade penal** |
| Cabimento | Crimes **sem violência/grave ameaça** + pena mínima **inferior a 4 ANOS** |
| Mediante | **Confissão + cumprimento de condições** |

### Retroatividade (Tema 1.098 STJ)
| | Conteúdo |
|---|---|
| **Natureza híbrida** | Norma processual + material (extinção da punibilidade): aplica-se a **retroatividade da norma penal benéfica** (CF 5 XL) |
| **Alcance** | ANPP cabível em processos em andamento quando da entrada em vigor da Lei 13.964/2019, mesmo sem confissão prévia, desde que requerido **antes do trânsito em julgado** |
| **Processos em curso em 18/09/2024** (data do julgamento do HC 185.913/DF pelo Plenário do STF) | Se o ANPP era cabível e não foi oferecido nem justificada a recusa, o MP deve se manifestar motivadamente na primeira oportunidade (de ofício, a pedido da defesa ou por provocação do juiz) |
| **Casos iniciados a partir de 18/09/2024** | ANPP celebrável antes do recebimento da denúncia, ressalvada proposta no curso da ação, se for o caso |

### Confissão (Tema 1.303 STJ)
| | Conteúdo |
|---|---|
| **Tese** | A confissão na fase de inquérito **não é exigência** do CPP 28-A: é inválida a negativa de proposta baseada em sua ausência |
| **Formalização** | Pode ocorrer no momento da assinatura do acordo, perante o próprio MP, com defesa técnica |

## Carreira

| | Conteúdo |
|---|---|
| Ingresso | **Concurso público** de provas e títulos |
| **3 anos** | Atividade jurídica (CF 129 §3) |
| Vitaliciedade | **2 anos** de estágio probatório |
| Aposentadoria compulsória | **75 anos** (LC 152/2015) |

## Distinções essenciais

| | MPU (LC 75/93) | MPs Estaduais (Lei 8.625/93) |
|---|---|---|
| Composição | MPF + MPT + MPM + MPDFT | Cada Estado |
| Chefia | PGR | PGJ |

| | MP (CF 127) | Defensoria (CF 134) |
|---|---|---|
| Função | **Ordem jurídica + sociais + INDISPONÍVEIS** | **Necessitados** |
| Atuação | Geral | Hipossuficientes |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| AP pública | **Privativa do MP** (CF 129 I) |
| ACP | **MP legitimado** (CF 129 III) |
| Membro do MP age fora da convicção | Viola **independência funcional** |
| Substituição entre membros | **OK** (indivisibilidade) |
| Outra função pública | **Vedada** (salvo magistério) |
| Advocacia pós-afastamento | **3 ANOS de quarentena** no juízo de origem |
| ANPP retroativo | **Tema 1.098 STJ**: cabível sem trânsito em julgado |
| Recusa de ANPP por falta de confissão no IP | **Inválida** (Tema 1.303 STJ) |
| MP vencido em ação civil | **Não é condenado** a despesas processuais e honorários de sucumbência; perícia que requerer é custeada por dotações do próprio MP, observado o CPC 91 (Tema 1.382 STF) |
| Controle externo da polícia | **CF 129 VII** |
| Disciplina interna | **CNMP** (CF 130-A) |

## Erros a evitar

- **Afastar a PRIVATIVIDADE do MP** na AP pública (CF 129 I);
- Aplicar a **independência funcional como hierarquia** invertida (cada membro decide);
- Permitir **outra função** ao membro do MP (vedado salvo magistério);
- **Confundir vitaliciedade** com estabilidade comum (perda do cargo só por sentença judicial transitada em julgado);
- Tratar o **CNMP como ente jurisdicional** (é administrativo/disciplinar);
- Afastar a **retroatividade do ANPP** em processo sem trânsito em julgado (Tema 1.098 STJ);
- Exigir **confissão prévia no inquérito** para a proposta de ANPP (Tema 1.303 STJ);
- Aplicar **quarentena menor** que 3 anos (EC 45);
- Permitir **atividade político-partidária** (vedada);
- Aplicar a **Lei 8.625 ao MPU** (é a LC 75/1993);
- Não considerar a **autonomia administrativa + financeira** (CF 127 §§);
- Ignorar o **controle externo da polícia** (CF 129 VII).

## Conceito

| | Conteúdo |
|---|---|
| Desestatização | Transferência do **controle estatal** para o setor privado |
| Modos | Alienação + abertura de capital + permuta + arrendamento + concessão |
| **Fundamentos** | Subsidiariedade do Estado + eficiência + livre iniciativa |

## Objetivos (art. 1)

| Inc. | Objetivo |
|---|---|
| **I** | Reordenar a posição estratégica do Estado na economia |
| **II** | Contribuir para a reestruturação econômica do setor público |
| **III** | Permitir a retomada de investimentos pela iniciativa privada |
| **IV** | Contribuir para a reestruturação econômica do setor privado |
| **V** | Permitir o desenvolvimento tecnológico |
| **VI** | Concentrar atividades estatais em ações + atividades necessárias |

| | Conteúdo |
|---|---|

## Erros a evitar

- Considerar privatização sem **autorização legislativa** quando exigida (CF 37 XIX);
- Aplicar Lei 14.133 a desestatização **sem subsidiariedade** (Lei 9.491 é especial);
- Tratar **golden share** como ilegal: tem base na Lei 6.404 art. 17 §7 + Lei 9.491 art. 8;
- Confundir privatização (transferência controle) com **concessão** (não transfere);
- Aplicar privatização a **monopólio União** (CF 177);
- Admitir **dispensa** de licitação fora das hipóteses da Lei 9.491;
- Considerar privatização como ato discricionário **sem fundamentação técnica** + estudos;
- Afastar **audiência pública** em projeto relevante;
- Tratar **CND** como facultativo (decisão vinculante);
- Permitir privatização **sem plano de empregos**;
- Admitir venda **abaixo do preço mínimo** (vedada, leilão competitivo);
- Confundir **abertura de capital** com **alienação de controle**;
- Não exigir aprovação **TCU + CGU** preventiva;
- Aplicar Lei 13.303 fora do regime das estatais (Lei 9.491 é regime de privatização);
- Tratar **Eletrobras** como totalmente privatizada (mantém golden share);
- Permitir desfazimento do PND **sem nova lei** (princípio da legalidade).

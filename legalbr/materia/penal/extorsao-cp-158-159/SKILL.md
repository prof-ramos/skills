# Extorsão + Extorsão Mediante Sequestro

## CP 158: Extorsão (caput)

| | Conteúdo |
|---|---|
| Conduta | **Constranger** alguém mediante **violência/grave ameaça** com intuito de **obter para si/outrem indevida vantagem econômica** |
| **Pena** | **Recl. 4-10 + multa** |
| Natureza | **Crime FORMAL**: consuma-se com o constrangimento, independentemente da obtenção da vantagem (Súm. 96 STJ) |

## Distinção crítica CP 158 × CP 157 (roubo)

| | Extorsão (158) | Roubo (157) |
|---|---|---|
| Vítima | **COLABORA** com a entrega | NÃO colabora |
| Subtração | Agente recebe | Agente **subtrai** diretamente |
| Erro recorrente | Aplicar 158 quando há subtração direta (é 157) | Aplicar 157 quando há colaboração coercida (é 158) |

## §1: Aumento (1/3 a 1/2)

| | Conteúdo |
|---|---|
| Hipótese | Cometido por **2+ pessoas** OU com **emprego de arma** |
| **STJ** | Majorante de arma **dispensa** apreensão e perícia quando o emprego é comprovado por outros meios idôneos (palavra da vítima, testemunhal, vídeo); questão afetada ao Tema 1.407 STJ (pendente) |
| **Arma de brinquedo** | **NÃO majora** (a Súm. 174 STJ, que admitia, foi **cancelada**; entendimento atual: simulacro não incide na majorante) |
| Concurso de agentes | Dispensa identificação de todos |

## §2: Extorsão com violência, qualificada pelo resultado

O CP 158 §2 remete ao regime do roubo qualificado pelo resultado (CP 157 §3):

| Resultado | Pena |
|---|---|
| Lesão grave | **7-18** anos |
| **MORTE** | **20-30** anos |

> Hediondez: o rol da Lei 8.072 art. 1 III (red. Lei 13.964/2019) alcança a **extorsão qualificada pela restrição da liberdade da vítima, lesão ou morte (art. 158, §3º)**; a extorsão do caput/§2 sem restrição de liberdade não consta expressamente do inciso.

## §3: Sequestro relâmpago (Lei 11.923/2009)

| | Conteúdo |
|---|---|
| Conduta | Restrição da liberdade da vítima como **condição NECESSÁRIA à obtenção da vantagem** |
| **Pena** | **Recl. 6-12 + multa** |
| Qualificadoras | Lesão grave (**16-24**); morte (**24-30**) |
| **HEDIONDO** | Lei 8.072 art. 1 III (red. Lei 13.964/2019), inclusive com lesão ou morte |
| Cumulação majorantes §1 | **STJ**: incidem cumulativamente sobre o §3 |

## CP 159: Extorsão mediante sequestro

| | Conteúdo |
|---|---|
| Conduta | **Sequestrar pessoa** com fim de obter qualquer vantagem como **condição/preço do resgate** |
| **Pena** | **Recl. 8-15** |
| §1, qualificadoras | Duração > 24h + vítima < 18 ou > 60 + **bando**: **12-20** |
| §2, lesão grave | **16-24** |
| §3, MORTE | **24-30** |
| **HEDIONDO em todas as modalidades** | Lei 8.072 art. 1 IV |

## CP 159 §4: Delação eficaz

| | Conteúdo |
|---|---|
| Hipótese | **Concorrente** que denuncia + facilita libertação |
| Benefício | **Redução de 1/3 a 2/3** |
| Aplicação | Concurso com **Lei 12.850/2013** (colaboração premiada) |
| **STJ** | Admite delação em **qualquer crime em concurso de agentes** (não apenas ORCRIM) |

## Consumação e competência (STJ Súm. 96)

> "O crime de extorsão consuma-se independentemente da obtenção da vantagem indevida." (Súm. 96 STJ)

Consequência: o foro é o do **local do constrangimento** (momento consumativo), independentemente de onde a vantagem seria obtida; define a competência em casos interestaduais.

## Lei 12.694/2012 + Lei 13.964/2019

| | Conteúdo |
|---|---|
| Lei 12.694 | Colegiado de juízes em crimes de organização criminosa |
| Lei 13.964 (Anticrime) | Progressão diferenciada para hediondos com morte (**50% primário / 70% reincidente**, com LC vedado), para fatos até 24/03/2026; a Lei 15.358/2026 elevou para **75/85%** a partir de 25/03/2026 |

## Distinção CP 158 §3 × CP 159

| | CP 158 §3 (sequestro relâmpago) | CP 159 (extorsão mediante sequestro) |
|---|---|---|
| Privação | **Necessária à vantagem** (condição) | Fim do resgate |
| Pena | 6-12 | 8-15 |
| Duração típica | Curta | Prolongada |
| Hediondez | Sim | Sim |

## Síntese operacional

| Hipótese | Tipo |
|---|---|
| Constrangimento + vítima colabora | **CP 158** |
| Subtração direta com violência | **CP 157** (roubo) |
| Constrangimento + 2 pessoas/arma | CP 158 §1 |
| Constrangimento com violência + morte | CP 158 §2 (pena de 20-30) |
| Privação curta + obter vantagem | **CP 158 §3** (sequestro relâmpago, hediondo) |
| Sequestro + fim de resgate | **CP 159** (sempre hediondo) |
| Concorrente denuncia | CP 159 §4: redução 1/3 a 2/3 |
| Constrangimento em SP + entrega em RJ | **SP** (Súm. 96) |

## Erros a evitar

- **Confundir 158 com 157** (subtração × colaboração coercida);
- Omitir aplicação de **hediondez ao §3 do 158** mesmo sem resultado morte;
- **Ignorar CP 159 §4** (delação eficaz) quando cabível;
- Deixar de cumular **§1 (arma/concurso) com o §3** por suposto bis in idem (NÃO há: institutos distintos);
- Aplicar **arma de brinquedo** como majorante (Súm. 174 STJ cancelada);
- Não considerar **Súm. 96 STJ** para definir competência;
- Aplicar **progressão antiga** (1/6) em hediondo com morte (50/70% no Anticrime; 75/85% após a Lei 15.358/2026);
- Tratar **§3 do 158 como não hediondo** (Lei 13.964 incluiu);
- Exigir **apreensão/perícia da arma** quando o emprego está provado por outros meios idôneos (STJ);
- Aplicar **CP 159 sem fim específico de resgate** (descaracteriza; o caso é 148 ou 158).

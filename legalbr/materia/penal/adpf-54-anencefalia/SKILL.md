# ADPF 54: Anencefalia

## Identificação

| | Conteúdo |
|---|---|
| Ação | **ADPF 54** |
| Autor | **CNTS (Confederação Nacional dos Trabalhadores na Saúde)** |
| Relator | Min. **Marco Aurélio** |
| Julgamento | **12/04/2012** |
| Placar | **8×2** (procedente) |
| Vencidos | Mins. Ricardo Lewandowski + Cezar Peluso |

## Tese estruturante

| | Conteúdo |
|---|---|
| Resultado | **PROCEDENTE**: interrupção de gestação de **anencéfalo NÃO é crime** |
| Técnica | **Interpretação conforme** dos arts. 124, 126 e 128 do CP |
| Expressão | **"Antecipação TERAPÊUTICA do parto"** (não "aborto") |
| Fundamento | Dignidade + autonomia + saúde da gestante |

## Anencefalia: conceito

| | Conteúdo |
|---|---|
| Definição | **Ausência total** de cérebro + calota craniana |
| Viabilidade | **NULA**: incompatível com vida extrauterina |
| Diagnóstico | Por **ULTRASSONOGRAFIA** ou ressonância |
| Confirmação | Dois médicos independentes (Res. CFM 1.989/2012) |

## Fundamentos constitucionais

| Art. | Conteúdo |
|---|---|
| **CF 1 III** | Dignidade da pessoa humana |
| **CF 5 caput** | Vida + liberdade + autonomia |
| **CF 5 II** | Legalidade |
| **CF 5 X** | Intimidade + privacidade |
| **CF 6** | Saúde |
| **CF 196** | Saúde como direito de todos |

## CP: hipóteses de aborto não punível

| Art. | Hipótese |
|---|---|
| **CP 128 I** | Aborto **NECESSÁRIO** (risco à vida da gestante) |
| **CP 128 II** | Aborto **SENTIMENTAL** (gravidez de estupro, consentimento da gestante ou representante) |
| **ADPF 54** | **Anencefalia** (acrescentada por interpretação conforme) |

## Resolução CFM 1.989/2012

| | Conteúdo |
|---|---|
| Função | Disciplina médica do procedimento |
| Diagnóstico | **Dois médicos** independentes |
| Termo | **Consentimento informado** da gestante |
| Documentação | Em prontuário |
| Notificação | Não exige autorização judicial |

## Procedimento da gestante

| Etapa | Conteúdo |
|---|---|
| 1. **Diagnóstico** | Ultrassonografia + 2 médicos |
| 2. **Informação** | Médica + jurídica |
| 3. **Consentimento** | Livre + informado + escrito |
| 4. **Antecipação** | Em hospital, SUS ou privado |
| 5. **Notificação** | Estatística (SUS) |

## Distinções essenciais

| | Aborto criminoso | Antecipação terapêutica (anencefalia) |
|---|---|---|
| Sujeito passivo | Feto viável | Feto inviável (anencéfalo) |
| Vida em formação | Sim | Não (incompatível) |
| Tipicidade | Crime CP 124 | **NÃO é crime** (ADPF 54) |
| Autorização judicial | Não se cogita | **Desnecessária** |

| | Aborto necessário | Sentimental | Anencefalia |
|---|---|---|---|
| Base | CP 128 I | CP 128 II | ADPF 54 |
| Pressuposto | Risco materno | Estupro | Anencefalia diagnosticada |
| Autorização | Médica | Médica | Médica |

## ADPF 442: Aborto até 12 semanas (pendente)

| | Conteúdo |
|---|---|
| Autor | PSOL |
| Pedido | Descriminalização até **12 semanas** |
| Status | **Em julgamento** |
| Diálogo com ADPF 54 | Pedido mais amplo que a ADPF 54: descriminalização até 12 semanas, sem restrição a anomalia fetal (julgamento pendente) |

## ADPF 1.141: Resolução CFM 2.378/2024 (assistolia fetal)

| | Conteúdo |
|---|---|
| Tema | Resolução do CFM que vedou a **assistolia fetal** na interrupção de gestação acima de 22 semanas decorrente de estupro |
| Liminar | Min. Alexandre de Moraes (2024) **suspendeu** a resolução e os processos contra médicos fundados nela (indícios de abuso do poder regulamentar) |
| Status | Mérito pendente de julgamento pelo Plenário |
| Diálogo | Limites da regulamentação ética à execução do aborto legal |

## Outras malformações graves

| | Conteúdo |
|---|---|
| ADPF 54 | Restrita a **ANENCEFALIA** |
| Demais | **Caso a caso**; autorização judicial pode ser necessária |
| Critério | Inviabilidade comparável à anencefalia |
| Jurisprudência | Tribunais têm estendido a outras malformações letais |

## Direitos da gestante

| | Conteúdo |
|---|---|
| **Autonomia** | Decidir ou prosseguir com gestação |
| **Sigilo** | Atendimento sigiloso |
| **SUS** | Procedimento obrigatório |
| **Assistência psicossocial** | Direito |
| **Não criminalização** | Garantida (ADPF 54) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Anencefalia diagnosticada | **Antecipação terapêutica**: não é crime |
| Autorização judicial | **DESNECESSÁRIA** (Res. CFM 1.989) |
| Diagnóstico | **2 médicos** independentes |
| Recusa do hospital | Ofende SUS + CFM |
| Outras malformações graves | Caso a caso; eventualmente autorização |
| Estupro | CP 128 II |
| Risco à vida da gestante | CP 128 I |
| Aborto até 12 sem | ADPF 442 (pendente) |
| Atendimento SUS | **Obrigatório** |
| Notificação | Estatística (não comunica polícia) |

## Erros a evitar

- Aplicar **CP 124** a antecipação de **anencéfalo** (ADPF 54, interpretação conforme);
- Exigir **autorização judicial** para antecipação (desnecessária, Res. CFM 1.989);
- Tratar a antecipação como **"aborto"** (a denominação correta é antecipação terapêutica);
- Negar atendimento no **SUS** (descumpre dever; pode gerar improbidade);
- Aplicar ADPF 54 a **OUTRAS malformações** sem juízo casuístico (não é automático);
- Exigir **único médico** para diagnóstico (Res. CFM exige 2);
- Comunicar a **polícia** (não há crime; sigilo);
- Confundir antecipação com **eutanásia** (são institutos distintos);
- Aplicar CP 128 sem o **consentimento** da gestante (ofende autonomia);
- Tratar ADPF 442 como **decidida** (ainda pendente).

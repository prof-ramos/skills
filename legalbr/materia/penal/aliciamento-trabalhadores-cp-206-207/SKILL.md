# Aliciamento de Trabalhadores

## Bem jurídico tutelado

| | Conteúdo |
|---|---|
| Bem jurídico | **ORGANIZAÇÃO DO TRABALHO** (titularidade COLETIVA) |
| Localização | Título IV CP: Crimes contra a Organização do Trabalho |

## CP 206: ALICIAMENTO PARA EMIGRAÇÃO

| | Conteúdo |
|---|---|
| Conduta | **Recrutar trabalhadores mediante FRAUDE** para levá-los a **TERRITÓRIO ESTRANGEIRO** |
| Pena | **Det. 1-3 anos + multa** |
| Natureza | Crime **formal** + **doloso** |

## CP 207: ALICIAMENTO INTERNO (entre localidades do Brasil)

| | Conteúdo |
|---|---|
| Caput | Aliciamento entre **localidades do TERRITÓRIO NACIONAL** |
| Pena | **Det. 1-3 anos + multa** |

### CP 207 §1: MAJORANTES (1/6 a 1/3), Lei 9.777/1998
| | Conteúdo |
|---|---|
| **(a)** | **FRAUDE** |
| **(b)** | **COBRANÇA de qualquer importância** do trabalhador |
| **(c)** | **AUSÊNCIA de garantia de RETORNO** ao local de origem |

### CP 207 §2: sem retorno
| | Conteúdo |
|---|---|
| Conduta | **Deixar de ASSEGURAR O RETORNO** |
| Pena | **Det. 6m-1a** |

## Lei 13.344/2016: Lei de Tráfico de Pessoas

| | Conteúdo |
|---|---|
| Alterou | **CP 207** |
| Introduziu | **CP 149-A** (tráfico de pessoas) |

## DISTINÇÃO CRÍTICA: tripartição

| | CP 149 | CP 149-A | CP 206-207 |
|---|---|---|---|
| Conduta | **Reduzir a CONDIÇÃO ANÁLOGA À de ESCRAVO** | **TRAFICAR** (8 verbos + 5 meios + 5 finalidades) | **ALICIAR** simples (emigração ou interno) |
| Coerção | Sim (degradante basta) | **Meio coercitivo + finalidade típica** | Pode ser por **fraude** apenas |
| Pena | Recl. 2-8a | Recl. 4-8a | Det. 1-3a |
| Finalidade específica | Submeter | Órgãos + escravo + degradante + adoção + sexual | Não exige |

## Ação penal

| | Conteúdo |
|---|---|
| Modalidade | **PÚBLICA INCONDICIONADA** |

## COMPETÊNCIA: JF (com ressalva)

| | Conteúdo |
|---|---|
| **CF 109 VI** | Crimes contra a **organização do trabalho** → **Justiça Federal** **quando atingido o interesse coletivo** (sistema de órgãos e instituições do trabalho) |
| **STF RE 398.041** | Reduzir a condição análoga à de escravo (CP 149) é crime contra a organização do trabalho → **Justiça Federal** (única exceção em que basta vítima individual) |
| Aliciamento puro (CP 206-207) | Competência **definida caso a caso**: vai à JF se houver lesão a interesse coletivo/sistema do trabalho; do contrário pode ser estadual (verificar a hipótese concreta) |
| Justiça do Trabalho | **NÃO** tem jurisdição criminal (ADI 3.684); jamais julga esses crimes |
| Concurso com CP 149 | Atrai a JF |

## Concurso entre tipos

| | Conteúdo |
|---|---|
| Aliciamento + escravo | **Concurso MATERIAL** ou **consunção** (caso a caso) |
| Aliciamento + tráfico | Mesmo |

## Lei 15.455/2026 (proteção do trabalhador resgatado)

| | Conteúdo |
|---|---|
| Objeto | Medidas de proteção e acolhimento de trabalhadoras e trabalhadores **resgatados de condição análoga à de escravo**, inclusive no ambiente doméstico (conforme ementa) |
| Reflexo | Reforça a rede protetiva nos casos em que o aliciamento evolui para o **CP 149** |

## Lei 14.811/2024 (Henry Borel)

| | Conteúdo |
|---|---|
| Hediondez | Tráfico de criança/adolescente (CP 149-A) |
| Aliciamento de criança | Pode atrair hediondez se conduta migrar para 149/149-A |

## Distinções essenciais

| | CP 206 | CP 207 |
|---|---|---|
| Destino | **ESTRANGEIRO** | **Interno** (entre localidades BR) |
| Meio | Fraude | Aliciamento (com majorantes se fraude/cobrança) |

| | Aliciamento (206-207) | Tráfico (149-A) |
|---|---|---|
| Finalidade típica | NÃO exige | **EXIGE** (rol taxativo) |
| Pena | Det. 1-3a | Recl. 4-8a |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Recrutar para trabalhar no exterior | **CP 206** (fraude) |
| Recrutar internamente | **CP 207** |
| Com fraude/cobrança/sem retorno | **+ 1/6 a 1/3** (§1) |
| Sem retorno consumado | **§2** (det. 6m-1a) |
| + condições degradantes | **CP 149** |
| + meios coercitivos + finalidade típica | **CP 149-A** |
| Competência | **JF** se atingido interesse coletivo (CF 109 VI; RE 398.041 p/ CP 149); caso a caso no aliciamento puro |
| Aliciamento + escravo | **Concurso ou consunção** + JF |

## Erros a evitar

- **Tratar aliciamento como competência da Justiça do Trabalho** (vedado: JT NÃO tem jurisdição criminal, ADI 3.684);
- **Confundir CP 206 (emigração) com CP 207 (interno)**;
- Aplicar **Lei 9.777/1998 sem majorantes** quando há fraude/cobrança/sem retorno;
- **Capitular CP 207 sem analisar §1 e §2**;
- Tratar aliciamento como **tráfico de pessoas** sem finalidade típica (149-A);
- Ignorar **concurso com CP 149** quando há trabalho escravo;
- Aplicar AP **PRIVADA** ou condicionada (é incondicionada);
- Fixar competência **sem aferir lesão a interesse coletivo** (a JF nos crimes contra a organização do trabalho exige, em regra, ofensa ao interesse coletivo; só o CP 149 dispensa, RE 398.041);
- Não aplicar **Lei 13.344** alterações no CP 207;
- Confundir bem jurídico **(coletivo) com individual**;
- Aplicar **hediondez ao aliciamento puro** (só CP 149-A com vítima menor).

# ADPF 187: Marcha da Maconha

## Tese estruturante

| | Conteúdo |
|---|---|
| Resultado | **PROCEDENTE**: Marcha da Maconha **NÃO configura crime** |
| Técnica | **Interpretação conforme** do CP 287 (apologia ao crime) |
| Tese | Defesa do **DEBATE PÚBLICO** sobre descriminalização ≠ apologia |
| Fundamento | Liberdade de **reunião + expressão** |

## CP 287: apologia ao crime

| | Conteúdo |
|---|---|
| Texto | "Fazer, publicamente, apologia de fato criminoso ou de autor de crime" |
| Pena | Detenção, 3-6 meses, ou multa |
| Pós-ADPF 187 | **Não se aplica** a defesa de descriminalização |

## Reunião pacífica (CF 5 XVI)

| | Conteúdo |
|---|---|
| **Pacífica** | Sem violência |
| **Sem armas** | Físicas ou de fogo |
| **Locais abertos** | Públicos |
| **Aviso prévio** | À autoridade, para coordenar logística + segurança |
| **Independe de autorização** | Direito constitucional autoaplicável |
| Possibilidade de frustração de outra | Vedado prejudicar reunião anterior no mesmo local |

## Distinções essenciais

| | Apologia a crime | Defesa de descriminalização |
|---|---|---|
| Objeto | Crime concreto + autor | Política pública + mudança legislativa |
| Tipicidade | CP 287 | **Atípica** (ADPF 187) |
| Liberdade | Não protegida | **Protegida** (CF 5 IV + XVI) |
| Exemplo | "Roubar é legal" | "Devemos descriminalizar o porte" |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Marcha pacífica por descriminalização | **Atípica**: CP 287 não aplicável (ADPF 187) |
| Reunião sem aviso prévio mas pacífica | Direito constitucional; não obstada |
| Marcha com violência | Sanção penal proporcional |
| Reunião que prejudica outra anterior | Avaliação caso a caso (CF 5 XVI) |
| Apologia a crime concreto | CP 287 pode ser aplicado |
| Discurso de ódio (racismo, LGBTfobia) | Não protegido (HC 82.424 + ADO 26) |
| Censura prévia | **Vedada** (CF 5 IX + 220) |
| Responsabilização | **A posteriori** |
| Internet | Aplicação análoga (Tema 987 STF) |
| Plataformas + manifestações virtuais | Compatíveis com a tese |

## Limites do direito de reunião

| | Conteúdo |
|---|---|
| Aviso prévio | Logística, não autorização |
| Pacífica + sem armas | Requisito |
| Locais abertos | Públicos |
| Não frustrar outra | Coordenação |
| **Não impedir circulação total** | Conciliação |
| **Conteúdo** | Imune; censura vedada |

## Erros a evitar

- Aplicar **CP 287** a defesa de descriminalização (ADPF 187: interpretação conforme);
- Negar **autorização** ou exigi-la para reuniões pacíficas (CF 5 XVI: independe);
- Confundir **defesa política** com **incitação a crime concreto**;
- Aplicar **censura prévia** a marchas/manifestações (vedada, CF 220);
- Tratar **apologia ao crime** como sinônimo de **opinião contrária à lei** (não é);
- Aplicar HC 82.424 (Ellwanger) **fora do contexto**: não engloba debate sobre políticas;
- Considerar manifestação automaticamente **ilegal** por causar transtorno (conciliação);
- Exigir **conteúdo prévio** para autorização (vedado);
- Considerar **reunião virtual** como não protegida (a tese é extensível);
- Aplicar **dispersão** sem justificativa concreta (proporcionalidade).

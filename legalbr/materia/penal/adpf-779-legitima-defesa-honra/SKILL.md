## Tese estruturante

| | Conteúdo |

| Vedação | Aos sujeitos do processo (defesa + MP + juiz + jurados) |
| Sanção | **NULIDADE ABSOLUTA** do julgamento |

## Conteúdo da tese vedada

| | Conteúdo |
|---|---|
| Origem | Atenuante/excludente histórica ("marido traído" como vítima) |
| Conteúdo | "**Homicídio justificado pela traição/honra**" |
| Status | **NÃO CONSTITUI** legítima defesa (CP 25); afronta direitos fundamentais |

## CP 25: Legítima defesa

| | Conteúdo |
|---|---|
| Texto | Entende-se em legítima defesa quem, usando moderadamente dos meios necessários, repele injusta agressão, atual ou iminente, a direito seu ou de outrem |
| Pressupostos | Agressão **injusta + atual ou iminente** + meios moderados + direito próprio ou de outrem |
| **Honra "atingida"** | **NÃO é agressão atual/iminente**: fato consumado é vingança, não defesa |
| Pós-ADPF 779 | Vedação expressa quanto à honra |

## Vedações da ADPF 779

| Sujeito | Vedação |
|---|---|
| **Defesa** | Não pode invocar tese |
| **MP** | Não pode admitir/aceitar |
| **Juiz togado** | Não pode admitir tese |
| **Jurados** | Não devem considerar |
| **Quesitação** | **Vedada** redação que sugira a tese |

| | Conteúdo |
|---|---|
| Hipótese | Tese invocada/aceita no julgamento |
| Efeito | **NULIDADE ABSOLUTA** + novo julgamento |

## Procedimento do júri pós-ADPF 779

| Etapa | Cuidado |
|---|---|
| **Pronúncia** (CPP 413) | Evitar fundamentar com honra |
| **Debates** | Juiz **DEVE intervir** se tese for invocada |
| **Quesitação** | Não pode submeter tese de honra ao Conselho |
| **Sentença** | Não pode acolher absolvição com fundamento em honra |
| **Recurso** | Apelação por nulidade (CPP 593 III "a") |

## Decisão dos jurados

| | Conteúdo |
|---|---|
| **Quesito do CPP 483 III** | "O jurado absolve o acusado?" |
| Pós-ADPF 779 | Jurados não podem absolver com **base exclusiva** na honra |
| Verificação | Discursos da defesa + quesitação |

## Distinções

| | Pré-ADPF 779 | Pós (2021) |
|---|---|---|
| Tese da honra | Frequente | **Vedada** |
| Nulidade | Discutida | **Absoluta** |
| Quesitação | Permitia | **Vedada** |
| Soberania | Argumento de blindagem | Não blinda inconstitucionalidade |

| | Legítima defesa (CP 25) | "Defesa da honra" |
|---|---|---|
| Agressão | Injusta + atual/iminente | Inexistente |
| Resposta | Proporcional | Desproporcional |
| Validade | Constitucional | **Inconstitucional** (ADPF 779) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Tese de honra invocada | **NULIDADE ABSOLUTA** |
| Quesitação que sugira tese | **VEDADA** |
| Absolvição com base em honra | **Nula**: novo julgamento |
| Defesa que use tese | Juiz deve intervir + censurar |
| Recurso por nulidade | **Apelação** (CPP 593 III "a") |
| Feminicídio | **CP 121-A** (crime autônomo, Lei 14.994/2024) + Lei 8.072 |
| Compatibilidade com Júri | Tese é vedada; não imuniza pelo sigilo |
| Honra como argumento atenuante | Inadmissível |
| Provocação injusta | **CP 65 III "c"**: atenuante (mas não exclui dolo) |
| Honra real (CP 138) | É **proteção da reputação**; não justifica violência |

## Erros a evitar

- Aceitar **tese da honra** no júri (ADPF 779: vedada);
- Permitir **quesitação** com tese vedada (vedada);
- Confundir CP 25 (legítima defesa) com **"defesa da honra"** (não há agressão atual);
- Tratar **soberania dos veredictos** como blindagem contra nulidade (ADPF 779);
- Considerar a tese **legítima quando o autor é mulher** (vedada em qualquer hipótese);
- Aplicar a tese disfarçada como **emoção/passional** (vedação substancial);
- Considerar a tese válida em **violência psicológica** prévia (não é defesa atual);
- Invocar apenas a **cautelar de 2021** e ignorar o **mérito da ADPF 779** (julgado em 01/08/2023, por unanimidade);
- Tratar o feminicídio como **homicídio simples** (é crime autônomo, CP 121-A, hediondo);
- Capitular o feminicídio como **CP 121 §2 VI** (a qualificadora foi substituída pelo tipo autônomo CP 121-A, Lei 14.994/2024);
- Negar **nulidade absoluta** sob argumento de não-prejuízo (a tese é insanável).

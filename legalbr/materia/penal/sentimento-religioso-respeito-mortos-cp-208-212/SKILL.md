# Sentimento Religioso + Respeito aos Mortos

## Estrutura

| Art. | Tipo | Pena |
|---|---|---|
| **CP 208** | **Ultraje a culto** (escárnio + perturbação + vilipêndio de objeto) | **Det. 1m-1ano** ou multa (+ 1/3 com violência) |
| **CP 209** | Impedir/perturbar **cerimônia funerária** | Det. 1m-1ano (+ 1/3 com violência) |
| **CP 210** | **Violação de sepultura/urna** | **Recl. 1-3** + multa |
| **CP 211** | **Destruir/subtrair/ocultar cadáver** | **Recl. 1-3** + multa |
| **CP 212** | **Vilipêndio a cadáver/cinzas** | **Det. 1-3** + multa |

## CP 208: ULTRAJE a culto

| | Conteúdo |
|---|---|
| Condutas | **Escarnecer** publicamente por crença/função religiosa **OU** **impedir/perturbar** cerimônia/culto **OU** **vilipendiar** publicamente ato ou objeto de culto |
| Bem jurídico | **Sentimento religioso** + liberdade de crença (CF 5 VI + VIII) |
| Sujeito passivo | **Coletivo** (comunidade religiosa) |
| Crime | **Comum + doloso** |
| Aumento 1/3 | **Violência** empregada |
| Concurso material | Lesão corporal + ultraje em violência intensa |

## CP 208 × intolerância religiosa (Lei 7.716/89)

| | CP 208 | Lei 7.716 art. 20 (racismo) |
|---|---|---|
| Pena | Det. **1m-1ano** | **Recl. 2-5** + multa |
| Bem jurídico | Sentimento religioso | **Dignidade** + igualdade |
| Conduta | Escarnecer/perturbar/vilipendiar | **Praticar/induzir/incitar** discriminação/preconceito |
| Aplicação | Conduta **isolada** sem incitação a discriminação | Discriminação **estrutural/sistemática** |
| **Lex specialis** | | **Prevalece** quando configurada discriminação religiosa qualificada (Lei 14.532/2023: equiparação ao racismo) |

### STJ: distinção (REsp 1.620.039 + reiterados)
Quando há **intolerância** religiosa qualificada (incita ódio) ⇒ **Lei 7.716** (com Lei 14.532/2023: imprescritibilidade + inafiançabilidade). O CP 208 reserva-se ao **escárnio isolado** sem incitação.

## CP 209: impedimento/perturbação de cerimônia funerária

| | Conteúdo |
|---|---|
| Conduta | **Impedir/perturbar** enterro/cerimônia funerária |
| Bem jurídico | Sentimento religioso + respeito ao morto |
| Pena | Det. 1m-1ano + multa |
| Aumento 1/3 | Violência |
| Lugar | Velório + sepultamento + cremação + cortejo |

## CP 210: violação de sepultura

| | Conteúdo |
|---|---|
| Conduta | **Violar OU profanar** sepultura, urna funerária, mausoléu |
| Pena | **Recl. 1-3** + multa |
| Bem jurídico | Respeito ao morto + tranquilidade do local |
| **Furto + violação** | **Concurso material** (CP 155 + CP 210), STJ |
| Tentativa | Admite |

## CP 211: destruir/subtrair/ocultar cadáver

| | Conteúdo |
|---|---|
| Condutas | **Destruir + subtrair + ocultar** cadáver OU parte |
| Pena | **Recl. 1-3** + multa |
| **Sujeito ativo** | Inclusive o **autor do homicídio** (concurso material com CP 121) |
| Bem jurídico | Respeito + interesse da justiça (não confundir com CP 347, fraude processual) |
| Tentativa | Admite |

### STJ: concurso CP 121 + 211
Quem mata + oculta o cadáver responde **em concurso material**: o CP 211 NÃO é consumido pelo homicídio (post factum punível).

## CP 212: vilipêndio a cadáver

| | Conteúdo |
|---|---|
| Conduta | **VILIPENDIAR** (desprezo, ultraje, profanação) cadáver OU **CINZAS** |
| Pena | **Det. 1-3** + multa |
| Bem jurídico | Respeito ao morto + dignidade *post mortem* |
| Modalidades | Atos físicos + atos simbólicos (zombaria filmada, publicação humilhante) |
| Dolo | **Específico** (vilipendiar) |

### Vilipêndio digital
Filmagens + publicações ofensivas de cadáver em redes sociais → **CP 212** + **concurso** eventual com **CP 153** (divulgação de segredo) + **LGPD** quando dados sensíveis.

## Lei 14.532/2023: racismo religioso

| | Conteúdo |
|---|---|
| Inseriu na Lei 7.716 | **Equiparação** entre intolerância religiosa + racismo |
| Efeito | **IMPRESCRITÍVEL** + **INAFIANÇÁVEL** (CF 5 XLII) |
| Lex specialis | Afasta o CP 208 quando configurar discriminação religiosa qualificada |

## Distinções essenciais

| | CP 208 | CP 209 |
|---|---|---|
| Objeto | **CULTO RELIGIOSO** | **CERIMÔNIA FUNERÁRIA** |
| Bem | Sentimento religioso | Respeito ao morto |

| | CP 210 | CP 211 |
|---|---|---|
| Objeto | **SEPULTURA** | **CADÁVER** |
| Verbo | Violar/profanar | Destruir/subtrair/ocultar |

| | CP 211 | CP 212 |
|---|---|---|
| Conduta | **Subtrair/destruir/ocultar** | **VILIPENDIAR** (desprezar/ultrajar) |
| Posse | **Subtração** sem necessária ofensa | Sem necessidade de subtrair |
| Pena | Reclusão | Detenção |

## Ação penal

| | Conteúdo |
|---|---|
| CP 208-212 | **Pública INCONDICIONADA** |
| CP 208 (controvérsia antiga) | Hoje pacificada como **incondicionada** (não é crime contra a honra) |

## Competência

| | Conteúdo |
|---|---|
| Regra | **Justiça Estadual** |
| Crimes de **menor potencial ofensivo** | CP 208 + 209 (det. ≤ 2 anos) → **JECRIM** + ANPP |
| Sursis processual | Possível |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Vandalizar terreiro de candomblé | **Lei 7.716/89 art. 20** (com Lei 14.532): lex specialis |
| Zombar publicamente de fé em cerimônia | **CP 208** (escárnio + perturbação) |
| Atrapalhar enterro com agressão | **CP 209** + 1/3 + lesão corporal (concurso) |
| Quebrar lápides + furtar urna | **CP 210** + CP 155 (concurso material) |
| Matar + esquartejar + ocultar | **CP 121** + **CP 211** (concurso material) |
| Filmar cadáver + publicar zombando | **CP 212** + eventual concurso |
| Pichar igreja | **CP 208** (vilipêndio de objeto) + CP 163 (dano) |
| Profanar urna + dispersar cinzas | **CP 212** (cinzas) |
| Conduta isolada de escárnio | **CP 208** (não é racismo se não for sistêmico) |

## Erros a evitar

- **Aplicar CP 208 a intolerância qualificada** (deve ser Lei 7.716 + Lei 14.532: racismo religioso, imprescritível);
- **Reconhecer CP 211 consumido pelo homicídio** (STJ: concurso material, post factum punível);
- Confundir **CP 210** (sepultura) com **CP 212** (vilipêndio de cadáver);
- Tratar **CP 208** como crime de honra (não é: bem jurídico diverso);
- Não reconhecer concurso CP 210 + CP 155 (furto de bens da sepultura);
- Aplicar competência **federal** sem bem da União;
- Esquecer **JECRIM/ANPP** quando a pena máxima ≤ 2 anos;
- Tratar **vilipêndio digital** como atípico (CP 212 abarca atos simbólicos);
- Confundir CP 211 (ocultação de cadáver) com **CP 347** (fraude processual): bens jurídicos distintos;
- Aplicar a Lei 14.532/2023 retroativamente a fato anterior (CF 5 XL).

# Reabilitação Criminal

## CP 93: CONCEITO

| | Conteúdo |
|---|---|
| Natureza | **Declaração judicial** |
| Alcance | **QUAISQUER PENAS** impostas |
| Efeitos | Restaura direitos + assegura **SIGILO** dos registros (FAA, não eliminação) |
| ≠ extinção da punibilidade | **"Descanso penal"**: suspende condicionalmente os efeitos secundários (CP 92) |

## CP 94: REQUISITOS (Lei 7.209/1984)

| Inc. | Conteúdo |
|---|---|
| **I** | **2 ANOS** após cumprimento/extinção (incluído **sursis** + **livramento condicional**) |
| **II** | **Domicílio no BRASIL** no período |
| **III** | **Bom comportamento PÚBLICO E PRIVADO** efetivo e constante |
| **IV** | **Reparação do DANO** OU prova de **impossibilidade** |
| **V** | **Cumprimento da pena PECUNIÁRIA** |

### STJ REsp 2.059.742-RS (5ª Turma, julg. 28/11/2023, Inf. 797)
| | Conteúdo |
|---|---|
| ANPP | O fato de o ANPP não gerar reincidência nem maus antecedentes **NÃO implica reconhecimento de bom comportamento público e privado** (CP 94 II) para a reabilitação |
| Exige | Conduta ética cotidiana comprovada ("bom comportamento" é conceito mais amplo que "antecedentes") |

## CP 95: REVOGAÇÃO

| | Conteúdo |
|---|---|
| Hipótese | Condenação **irrecorrível posterior** à PPL OU multa |
| Não cabe | Se aplicada apenas **PRD** |

## Reincidência × reabilitação (distinção de prazos)

### Distinção crucial
| | Reabilitação propriamente dita | Período depurador da reincidência |
|---|---|---|
| Base | **CP 94 I** | **CP 64 I** |
| Prazo | **2 ANOS** | **5 ANOS** (quinquênio) |
| Conta-se | Pós-cumprimento/extinção | Pós-cumprimento/extinção da pena |

## EFEITOS DA REABILITAÇÃO

| | Conteúdo |
|---|---|
| Sigilo | **Sim** (não eliminação) |
| Suspensão dos efeitos secundários | **CP 92** |
| **NÃO atinge** | **CONFISCO** de instrumentos do crime + **REPARAÇÃO do dano** + **MULTA** + **incapacidades civis** |
| **NÃO afasta** | **REINCIDÊNCIA** dentro do quinquênio (CP 64 I) |

## CP 64 I: PERÍODO DEPURADOR

| | Conteúdo |
|---|---|
| Prazo | **5 ANOS** entre cumprimento e novo crime |
| Após 5 anos | **NÃO há REINCIDÊNCIA** |
| Maus antecedentes | **CONTROVERTIDO** |

## STF Tema 150 (RE 593.818)

| | Conteúdo |
|---|---|
| Tese (redação alterada no RE 593.818 ED, julg. 25/04/2023) | O prazo quinquenal do CP 64 I **NÃO se aplica** ao reconhecimento dos **maus antecedentes** |
| Aplicação | O julgador pode, **fundamentada e eventualmente, NÃO exasperar** a pena-base quando as condenações pretéritas forem desimportantes ou demasiadamente distanciadas no tempo (CP 59) |

## STJ: "Direito ao esquecimento dos antecedentes"

| | Conteúdo |
|---|---|
| Tese | Parte da jurisprudência do STJ defende o **esquecimento dos antecedentes** após longo período de vida sem novas condenações |
| Divergência STF × STJ | Persiste: verificar o entendimento atual aplicável |
| STF | Admite uso pós-quinquênio (mediante fundamentação) |
| STJ | Tende ao **esquecimento DECENAL** |

## JECrim (Lei 9.099/95)

| | Conteúdo |
|---|---|
| Suspensão condicional do processo (art. 89) | **NÃO gera reabilitação**: inexiste condenação a reabilitar |

## Distinções essenciais

| | CP 64 I (reincidência) | CP 93-94 (reabilitação) |
|---|---|---|
| Prazo | **5 anos** (período depurador) | **2 anos** (após cumprimento) |
| Função | Apaga reincidência | Sigilo + descanso |
| Maus antecedentes | Pode subsistir (STF Tema 150) | Sigilo |

| | Reabilitação | Extinção da punibilidade |
|---|---|---|
| Conteúdo | Sigilo + suspensão | **Apaga** crime |
| Pena já cumprida | Pode reabilitar | Já extinta pelo cumprimento |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| 2 anos pós-cumprimento + requisitos | **Reabilitação** (CP 94) |
| Condenação posterior à PPL irrecorrível | **Revoga** (CP 95) |
| 5 anos pós-cumprimento | **Sem reincidência** (CP 64 I) |
| Uso de antecedente pós-quinquênio | **Admitido com fundamentação** (STF Tema 150) |
| Esquecimento dos antecedentes | Parte da jurisprudência do STJ admite após longo período |
| ANPP cumprido | **NÃO gera bom comportamento** (STJ 2024) |
| Sursis cumprido | Conta para os 2 anos |
| PRD apenas | **NÃO admite revogação** (CP 95) |
| Suspensão condicional do processo | **NÃO há condenação** a reabilitar |
| Cancelamento de registros | Após o cumprimento/extinção (CP 64 I + CP 93) |

## Erros a evitar

- **Confundir REABILITAÇÃO (CP 93/94: 2 anos) com PERÍODO DEPURADOR da reincidência (CP 64 I: 5 anos)**;
- **Aplicar REINCIDÊNCIA após o QUINQUÊNIO** (CP 64 I veda);
- **Ignorar Tema 150 STF** e admitir maus antecedentes ETERNOS sem fundamentação;
- Tratar **reabilitação como APAGAMENTO** (é apenas **SIGILO**);
- Aplicar **prazo de 2 anos para reincidência** (é 5);
- Considerar **ANPP como bom comportamento** automático (STJ veda);
- Aplicar **suspensão condicional do processo** como gerando reabilitação;
- Atingir **confisco/reparação/multa** pela reabilitação (não atinge);
- Revogação da reabilitação por **PRD posterior** (CP 95 exige PPL/multa);
- **Negar reabilitação** quando irreparável dano sem analisar **impossibilidade** (CP 94 IV);
- Esquecer da divergência **STF × STJ** sobre o esquecimento dos antecedentes.

# Tráfico de Pessoas (CP 149-A)

## Tipo penal (Lei 13.344/2016)

| | Conteúdo |
|---|---|
| Núcleos alternativos | **Agenciar + aliciar + recrutar + transportar + transferir + comprar + alojar + acolher** |
| Meios | **Grave ameaça + violência + coação + fraude + abuso** |
| **Pena** | **Recl. 4-8 + multa** |
| Natureza | **Crime formal**: consuma-se com a prática de qualquer núcleo, dispensando exploração efetiva |

## Finalidades EXAUSTIVAS (incs. I a V)

| Inc. | Finalidade |
|---|---|
| **I** | **Remoção de órgãos/tecidos** |
| **II** | **Trabalho forçado/escravidão** |
| **III** | Qualquer outro tipo de **servidão** |
| **IV** | **Adoção ilegal** |
| **V** | **Exploração sexual** |

## §1: causas de aumento (1/3 a 1/2)

| | Conteúdo |
|---|---|
| I | **Funcionário público** no exercício |
| **II** | Vítima **criança/adolescente** + **> 60 anos** + **PCD** |
| III | Agente **ascendente/descendente/cônjuge/companheiro/irmão/tutor/curador/preposto** |
| IV | Vítima **retirada do território nacional** |

## §2: causa de diminuição (1/3 a 2/3)

| | Conteúdo |
|---|---|
| Hipótese | **Primário** + **NÃO integrante de ORCRIM** |
| Vedada | Combinação de leis para retroatividade (STJ) |

## Hediondez: Lei 14.811/2024

| | Conteúdo |
|---|---|
| Incluiu | Lei 8.072 art. 1 XII: tráfico de pessoas (149-A caput, incisos I-V, e §1 II) **contra criança/adolescente** |
| Vínculo | À **qualidade da vítima** |
| Vigência | Imediata (**12/01/2024**) |
| Irretroatividade | *Lex gravior* |

## Distinção CP 149 × CP 149-A (STJ)

| | CP 149 (redução à escravidão) | CP 149-A (tráfico de pessoas) |
|---|---|---|
| Pena | Recl. **2-8** | Recl. **4-8** |
| Natureza | **Crime-FIM** (submissão concreta) | **Crime de TENDÊNCIA** (conduta-meio com finalidade) |
| Elementos | Trabalho forçado + jornada exaustiva + condições degradantes + restrição de locomoção | Aliciamento + transporte + acolhimento etc. |
| Liberdade | Necessária restrição? | NÃO (STJ: o 149 independe de restrição) |
| Concurso material | Possível com 149-A (aliciamento + efetiva submissão) |

## Síntese operacional

| Hipótese | Tipo |
|---|---|
| Aliciamento para exploração sexual no exterior | **CP 149-A** + §1 IV |
| Vítima menor + tráfico | **CP 149-A + HEDIONDO** (Lei 14.811) |
| Submissão concreta a trabalho forçado | **CP 149** |
| Aliciamento + submissão efetiva | **Concurso material** 149-A + 149 |
| Funcionário público no exercício | **§1 I** (+1/3 a 1/2) |
| Primário + sem ORCRIM | **§2** (-1/3 a 2/3) |
| Aliciamento para órgãos | CP 149-A I |
| Adoção ilegal | CP 149-A IV |

## Concursos

| | Conteúdo |
|---|---|
| Tráfico + submissão | Concurso material |
| Tráfico + crimes sexuais | Concurso material/formal |
| Tráfico + ORCRIM | Concurso material |

## Erros a evitar

- **Confundir CP 149 (submissão)** com **CP 149-A (conduta-meio com finalidade)**;
- **Omitir hediondez** da Lei 14.811/2024 quando vítima menor;
- Aplicar **§2** a integrante de ORCRIM;
- **Combinar leis** para retroatividade benéfica (vedado);
- Exigir **restrição de liberdade** para CP 149 (STJ: independe);
- Não aplicar **§1 II** quando vítima criança/idoso/PCD;
- Aplicar Lei 14.811 **retroativamente** (*lex gravior*, vedado);
- Confundir tráfico com **CP 148** (sequestro/cárcere privado);
- Negar concurso material entre **149 + 149-A** quando há aliciamento + submissão;
- Aplicar a Convenção de Palermo como **revogando** a lei interna (complementa).

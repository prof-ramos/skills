# Crimes contra Pessoa com Deficiência (LBI)

## Lei 13.146/2015: fundamentos

| | Conteúdo |
|---|---|
| Vigência | **02/01/2016** |
| Internacionalização | Implementa **Convenção ONU PcD** (Decreto 6.949/2009, status **constitucional** CF 5 §3) |
| **Pessoa com deficiência** | Art. 2: impedimento de longo prazo **físico/mental/intelectual/sensorial** que, em interação com **barreiras**, obstrui participação plena |
| Modelo | **Social** (não meramente médico) |
| Acessibilidade | Direito assegurado (art. 53) |

## Quadro de crimes (Título II)

| Art. | Crime | Pena |
|---|---|---|
| **88** | **DISCRIMINAÇÃO** (praticar/induzir/incitar) por deficiência | Recl. **1-3** + multa |
| **88 §1** | Vítima **sob cuidado** do agente | + 1/3 |
| **88 §2** | Crime por **meio comunicação social/publicação** | Recl. **2-5** + multa |
| **89** | **APROPRIAR-SE OU DESVIAR** bens/proventos/pensão/benefícios/remuneração de PcD | Recl. **1-4** + multa |
| **89 §u** | Agente **tutor/curador/síndico/inventariante/depositário/profissional** | + 1/3 |
| **90** | **ABANDONAR** PcD em hospital/casa de saúde/abrigo OU **não prover** necessidades básicas | Recl. **6m-3a** + multa |
| **91** | **RETER OU UTILIZAR** cartão magnético/eletrônico/documento de PcD destinado a benefícios/operações financeiras | Det. **6m-2a** + multa |

## Ação penal

| | Conteúdo |
|---|---|
| Todos | **Pública INCONDICIONADA** (regra geral, sem ressalva específica) |
| Sem renúncia | Vítima vulnerável + interesse público |

## Conceito de "PcD" para fins penais (LBI art. 2)

| | Conteúdo |
|---|---|
| **Física** | Alteração completa ou parcial de membros |
| **Sensorial** | Auditiva, visual, da fala |
| **Mental/intelectual** | TDAH/autismo/Down/transtorno desenvolvimento |
| **Psicossocial** | Esquizofrenia + bipolaridade + outros |
| **Avaliação** | **Multidisciplinar** + biopsicossocial (art. 2 §1) |
| Documentação | LAUDO + perícia |

## STJ: pontos aplicados

| | Conteúdo |
|---|---|
| **STJ (2021)** | Postagem **piada/zombaria PcD** em rede social = crime **LBI 88 §2** (publicação em meio de comunicação) |
| **STJ (apropriação)** | Filhos que se apropriam de aposentadoria por invalidez do pai PcD = **LBI 89** (lex specialis sobre CP 168) |
| Bem do tutor | Tutor que retém pensão da curatela = **LBI 89 §u** + 1/3 |
| Ação | **Pública incondicionada** mesmo em apropriação |

## Distinções com tipos próximos

| | LBI 88 | Lei 7.716 art. 20 |
|---|---|---|
| Núcleo | Discriminação por **deficiência** | Discriminação **racial/cor/etnia/religião** |
| Lex specialis | **Prevalece** para PcD | Para racismo |
| Pena | 1-3 (+ §§) | 1-3 (+ §§) |
| Imprescritibilidade | NÃO (LBI) | **SIM** (CF 5 XLII) |
| Ação | Pública incondicionada | Pública incondicionada |

| | LBI 89 | Lei 10.741 art. 102 (idoso) |
|---|---|---|
| Vítima | PcD | **Idoso ≥ 60** |
| Pena | Recl. **1-4** | Recl. 1-4 |
| Cumulação | Idoso **+** PcD ⇒ **concurso formal** ou aplicação da **mais gravosa** com agravantes |

| | LBI 89 | CP 168 (apropriação indébita) |
|---|---|---|
| Vítima | **PcD** | Genérica |
| Lex specialis | **Prevalece** | Subsidiária |

| | LBI 90 | CP 133 (abandono incapaz) |
|---|---|---|
| Vítima | **PcD** | Pessoa sob guarda/vigilância |
| Pena | Recl. **6m-3a** | Det. 6m-3a (caput) |
| Lex specialis | **Prevalece** quando PcD | Genérica |

## Concurso de leis especiais

| Cenário | Saída |
|---|---|
| Vítima é **idosa + PcD** | **Concurso aparente**: aplica-se a mais grave OU agravantes em concurso formal (caso a caso) |
| **Lei 13.431/2017** (criança/adolescente vítima de violência) | Concorre com LBI quando criança com deficiência |
| Lei **11.340** Maria da Penha | Concorre quando mulher PcD |
| Maus-tratos a cão-guia/animal de assistência | Lei 9.605 art. 32; eventual discriminação ao usuário → LBI 88 |

## Bis in idem: agravante CP 61 II "h"

| | Conteúdo |
|---|---|
| **CP 61 II "h"** | Crime contra **enfermo** + **deficiente** + idoso; **VEDADO** bis in idem se elementar do tipo |
| Aplicação | Em crime comum (homicídio + lesão) **contra PcD**: aplica agravante |
| Cumulação | Tipos específicos da LBI **NÃO cumulam** com a agravante (condição já considerada na pena) |

## CF 5 §3 + Convenção ONU PcD

| | Conteúdo |
|---|---|
| Decreto 6.949/2009 | Convenção ONU com status de **EMENDA CONSTITUCIONAL** |
| Interpretação | Crimes da LBI devem ser interpretados em **conformidade com a Convenção** |
| Acesso à justiça | Adaptado (LBI art. 79) |
| **Tema 1.096 STF (RE 918.315/DF)** | Enfermidade ou doença mental, ainda que estabelecida curatela, não configura, por si, elemento suficiente para afastar o discernimento da PcD para os atos da vida civil |

## Procedimento + competência

| | Conteúdo |
|---|---|
| **Justiça Estadual** | Regra |
| **Federal** | Quando benefício for INSS/Federal |
| Pena máx ≤ 2 (regra da Lei 9.099) | JECRIM; sursis processual quando pena mínima ≤ 1 (não há vedação expressa na LBI) |
| ANPP | Cabível nos tipos com pena mínima < 4 (CPP 28-A), com confissão e reparação |
| Pena máx > 4 (LBI 88 §2) | Rito ordinário |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Postar piada sobre PcD em rede social | **LBI 88 §2** (mídia): recl. 2-5 |
| Tutor desvia BPC do tutelado | **LBI 89 §u** + 1/3: recl. 1-4 + aumento |
| Filho retém cartão do INSS do pai cego | **LBI 91**: det. 6m-2 |
| Abandonar PcD em ILPI | **LBI 90**: recl. 6m-3a |
| Recusar emprego por deficiência | **LBI 88**: recl. 1-3 + multa |
| Discriminação em estabelecimento | **LBI 88** (não confundir com Lei 7.716: específica) |
| Vítima é **idosa PcD** | Concurso formal entre Lei 10.741 + LBI |
| Vítima é **criança PcD** | Lei 13.431 + LBI + ECA |
| Insultar pessoa por deficiência | **LBI 88** (não é injúria racial: bem distinto) |
| Apropriação de benefício previdenciário | Análise **CP 168 vs. LBI 89**: LBI prevalece quando vítima PcD |

## Erros a evitar

- **Aplicar CP 168** quando há **LBI 89** (lex specialis para PcD);
- Aplicar **Lei 7.716** a discriminação por deficiência (deve ser **LBI 88**);
- Tratar crime da LBI como imprescritível (a imprescritibilidade da CF 5 XLII alcança o racismo da Lei 7.716; a LBI é **prescritível**: distinção crítica);
- Conceder transação/sursis processual fora das balizas da Lei 9.099 (pena máx ≤ 2 / mínima ≤ 1);
- Ignorar **causas de aumento §1/§u/§2** específicas;
- Aplicar **CP 61 II "h"** **cumulando** com tipo da LBI (condição já considerada);
- Tratar **Convenção ONU** como soft law: tem status **constitucional** (CF 5 §3);
- Não cumular **LBI + Lei 10.741** quando vítima é idosa PcD (concurso formal, bens diversos);
- Aplicar **CP 168 + LBI 89** cumulativamente (consunção pela específica);
- Desconsiderar a **avaliação biopsicossocial** da deficiência (LBI 2 §1);
- Aplicar **ANPP** quando pena mínima ≥ 4 (CPP 28-A: vedado).

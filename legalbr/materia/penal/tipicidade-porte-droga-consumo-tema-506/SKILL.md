# Tipicidade do Porte de Droga para Consumo

## Base normativa

| | Conteúdo |
|---|---|
| **Lei 11.343/06 art. 28** | Quem **adquirir, guardar, transportar OU trouxer consigo** drogas para **consumo pessoal**: advertência + serviços à comunidade + comparecimento (sem prisão) |
| **CF 5 X** | Intimidade + vida privada |
| **CF 5 XLVI** | Individualização da pena |
| **Lei 11.343 art. 28 §1** | Quem cultivar, plantar, colher para consumo |
| **Lei 11.343 art. 28 §2** | Critérios: natureza + quantidade da substância + local + circunstâncias |

## STF Tema 506 (RE 635.659)

| | Conteúdo |
|---|---|
| Fixada | **26/06/2024** |
| **Tese (essência)** | **DESCRIMINALIZAÇÃO** do porte de **cannabis para consumo pessoal**: não comete infração penal, sem prejuízo da **ilicitude extrapenal** (apreensão + advertência art. 28 I + medida educativa art. 28 III, aplicadas em procedimento de natureza **não penal**) |
| **Presunção de usuário** | Até **40 gramas** de cannabis OU **6 plantas-fêmeas**, até que o Congresso legisle (item 4 da tese) |
| **Presunção RELATIVA** | Cabe flagrante por **tráfico mesmo abaixo de 40g** quando presentes elementos de mercancia (acondicionamento, variedade, balança, registros comerciais), com justificativa minudente do delegado, vedados critérios subjetivos arbitrários (itens 5-6); acima dos limites, o juiz ainda pode reconhecer a condição de usuário com prova suficiente (item 8) |

## Limites quantitativos

| Substância | Limite | Saída |
|---|---|---|
| **Maconha** | Até **40g** OU **6 plantas-fêmeas** | **Presunção (relativa) de uso pessoal**: sem infração penal, mas ilícito administrativo |
| **Maconha** acima de 40g/6 plantas | Análise para **tráfico** (não automática; juiz pode reconhecer usuário com prova suficiente, item 8 da tese) |
| **Cocaína / outras drogas** | Tema 506 NÃO se aplica diretamente: regime do art. 28 mantido |
| **Cultivo doméstico** maconha | Até 6 plantas: lícito penal |

## Aplicação prática

| Hipótese | Saída |
|---|---|
| Apreensão de 30g maconha + sem indícios de tráfico | **Não criminal** (Tema 506); Juizado Especial Criminal aplica medidas do art. 28 I/III sem efeitos penais, até regulamento do CNJ |
| Apreensão de 35g + 3 plantas | **Não criminal** (ambos abaixo do limite) |
| Apreensão de 50g | Cabe análise: indícios de tráfico vs uso |
| Apreensão de 200g | Presunção de tráfico (regra Lei 11.343) |
| Cocaína em qualquer quantidade para uso | Tema 506 NÃO se aplica diretamente: Lei 11.343 art. 28 mantém |
| Porte em estabelecimento prisional | Análise específica (LEP) |
| Adolescente: ato infracional análogo | Cabe ECA |
| Conduzir veículo sob efeito | Crime do CTB |

## Casos correlatos

| | Conteúdo |
|---|---|
| **Tema 506 STF** | Descriminalização do porte de maconha para consumo pessoal |
| **SV 63** | O tráfico privilegiado (Lei 11.343 art. 33 §4) **não é hediondo**: afastam-se os parâmetros mais rigorosos de progressão e livramento |
| **Tema 1.400 STF** | É constitucional a concessão de **indulto** a condenado por tráfico privilegiado, pois o crime não tem natureza hedionda |
| Porte de munição | Crime de perigo abstrato: em regra **não** admite insignificância (STJ) |
| **Lei 11.343/06** | Drogas |
| Tráfico internacional pelo correio | A **Súm. 528 STJ foi CANCELADA** (2022); fixa-se a competência no **local de destino** da droga (quando conhecido o endereço) |

## Erros a evitar

- Aplicar tipo penal de **uso** a quantidades acima dos limites Tema 506 (cabe análise tráfico);
- Aplicar Tema 506 a **outras substâncias** (cocaína etc.: regime art. 28);
- Em **cultivo doméstico** acima de 6 plantas: aplicar Tema 506 (cabe verificação);
- Tratar como tráfico **automaticamente** quantidades acima dos limites (cabe contexto);
- Em pequena quantidade com **vínculos a organização criminosa**: aplicar Tema 506 (cabe Lei 12.850);
- Em **ato infracional** de adolescente, aplicar Tema 506 sem analisar ECA + medidas socioeducativas.

# Conflito Aparente de Normas Penais

## Aparente × Real

| | Conteúdo |
|---|---|
| **Aparente** | Várias normas parecem incidir, mas apenas UMA efetivamente regula o fato, afastando as demais por critérios lógico-valorativos |
| **Real** | Concurso de crimes (CP 69-71): fatos autônomos + aplicação cumulativa |

## Princípios solucionadores

Quatro critérios consolidados na aplicação da norma penal: **especialidade, subsidiariedade, consunção** e **alternatividade**. A alternatividade tem alcance restrito (tipos mistos alternativos) e é, por parte da jurisprudência, tratada como conflito intranormativo.

## 1. ESPECIALIDADE (*lex specialis derogat generali*)

| | Conteúdo |
|---|---|
| Critério | **Lógico-abstrato** |
| Conteúdo | Norma especial contém **TODOS os elementos da geral + PLUS** (elementos especializantes) |
| Resolução | **EM ABSTRATO**, independentemente do caso |
| **Exemplos** | Infanticídio (CP 123) afasta homicídio (CP 121); feminicídio (CP 121-A); peculato afasta furto quando praticado por funcionário público |

## 2. SUBSIDIARIEDADE (*lex primaria derogat subsidiariae*)

| Modalidade | Conteúdo |
|---|---|
| **Critério** | **Concreto**: a norma subsidiária funciona como "soldado de reserva" (aplica-se apenas se não incidir a primária) |
| **Expressa** | O tipo declara: "**se o fato não constitui crime mais grave**" (CP 132 + 238 + 239 + 307) |
| **Tácita** | Inferida da estrutura: dano (CP 163) cede ao furto qualificado pela destruição (CP 155 §4 I); constrangimento ilegal cede à extorsão |

## 3. CONSUNÇÃO (*lex consumens derogat consumptae*)

Crime-fim absorve crime-meio quando este se exaure naquele.

| Hipótese | Conteúdo |
|---|---|
| **(i) Crime progressivo** | Lesão necessária ao homicídio |
| **(ii) Progressão criminosa** | Mudança de dolo: o agente lesiona, depois decide matar; responde só pelo mais grave |
| **(iii) Antefato impunível** | Porte de arma absorvido pelo homicídio quando único nexo |
| **(iv) Post factum impunível** | Venda da res furtiva pelo próprio autor |

### STJ + STF
| | Conteúdo |
|---|---|
| **Súm. 17 STJ** | **Falso exaurido no estelionato** é absorvido (sem potencialidade lesiva remanescente) |
| **STF/STJ** | Consunção exige **potencialidade lesiva esgotada**: se o falso conserva eficácia além do estelionato, há **concurso** |
| Uso doc falso × comércio ilegal de arma | Consunção pelo crime-fim quando o falso é **meio necessário** sem potencialidade lesiva autônoma |

## 4. ALTERNATIVIDADE

| | Conteúdo |
|---|---|
| Aplicação | Dentro do **MESMO tipo** de ação múltipla/conteúdo variado |
| Exemplos | CP 33 Lei de Drogas + CP 213 Estupro |
| Efeito | Prática de vários núcleos no mesmo contexto fático = **crime ÚNICO** |
| Observação | Parte da jurisprudência **NÃO** a trata como verdadeiro conflito de normas (é fenômeno intranormativo) |

## Crime progressivo × Progressão criminosa

| | Crime progressivo | Progressão criminosa |
|---|---|---|
| Dolo | **Único** | **Renovado** |
| Conduta | Mesmo crime + diversas intensidades | Mudança de propósito |
| Exemplo | Lesão → morte (mesmo dolo) | Lesão → decide matar |
| Resultado | Responde pelo mais grave | Responde pelo mais grave |

## Antefato × Post factum impunível

| | Conteúdo |
|---|---|
| **Antefato** | Crime anterior absorvido pelo posterior (porte para homicídio) |
| **Post factum** | Crime posterior absorvido pelo anterior (venda da coisa furtada pelo próprio agente) |

## Síntese operacional

| Hipótese | Princípio |
|---|---|
| Infanticídio × homicídio | **Especialidade** (123 afasta 121) |
| Peculato × furto (funcionário público) | Especialidade |
| Tipo com "se não for crime mais grave" | **Subsidiariedade expressa** |
| Dano × furto qualificado | **Subsidiariedade tácita** |
| Falso exaurido em estelionato | **Consunção** (Súm. 17) |
| Falso com potencial autônomo | **Concurso** (potencialidade lesiva remanescente) |
| Lesão progressiva → morte (dolo único) | **Crime progressivo** |
| Lesão + decisão posterior de matar | **Progressão criminosa** |
| Porte de arma como meio para homicídio | **Antefato impunível** |
| Venda da res furtiva pelo próprio | **Post factum impunível** |
| Múltiplos núcleos no tráfico | **Alternatividade** (crime único) |

## Erros a evitar

- Aplicar **concurso material onde cabe consunção** (falso exaurido, Súm. 17);
- **Ignorar especialidade** do feminicídio/infanticídio;
- **Confundir crime progressivo (dolo único) com progressão criminosa (dolo renovado)**;
- **Absorver crime-meio que conserva lesividade autônoma** (há concurso quando o falso conserva eficácia além do estelionato);
- Tratar **alternatividade como conflito internormativo** (é intranormativo);
- Aplicar **consunção sem nexo de necessariedade** entre meio/fim;
- Não distinguir **antefato × post factum impunível**;
- Aplicar **especialidade in concreto** (é abstrato);
- Não reconhecer **subsidiariedade expressa** quando há cláusula expressa no tipo;
- **Cumular** múltiplos núcleos do mesmo tipo no mesmo contexto (alternatividade).

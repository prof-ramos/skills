# Associação Criminosa × Organização Criminosa

## CP 288: Associação Criminosa

| | Conteúdo |
|---|---|
| Conduta | **Associarem-se 3 ou mais** pessoas para fim específico de cometer crimes |
| **Pena** | **Recl. 1-3 anos** |
| **Par. único** | Aumento até a **metade** se associação **armada** OU **criança/adolescente** participa |

## Lei 12.850/2013 art. 1 §1: Organização Criminosa

| | Conteúdo |
|---|---|
| Definição | Associação de **4 ou mais pessoas** + **estruturalmente ordenada** + caracterizada pela **divisão de tarefas** (ainda que informalmente) + estabilidade + objetivo de **vantagem direta/indireta** |
| Mediante | Prática de infrações com pena máx. **> 4 anos** OU caráter **transnacional** |
| **Pena** (art. 2) | **Recl. 3-8 anos + multa** |

## Distinções nucleares

| | CP 288 | Lei 12.850 |
|---|---|---|
| Número mínimo | **3** | **4** |
| Estrutura | **Dispensa** | **Exige** (hierarquia + divisão) |
| Finalidade | Crimes em geral | Infrações com pena > 4 anos OU transnacionais + vantagem |
| Estabilidade | Exige | **Reclama permanência estrutural** |
| Pena | 1-3 anos | 3-8 anos |

## CP 288-A: Milícia privada (lex specialis)

| | Conteúdo |
|---|---|
| Conduta | Constituir + organizar + integrar + manter + custear **organização paramilitar + milícia particular + grupo + esquadrão** com finalidade de praticar crimes |
| **Pena** | **Recl. 4-8 anos** |
| Relação | **Lex specialis** frente ao CP 288 |

## Associação para o tráfico: Lei 11.343 art. 35

| | Conteúdo |
|---|---|
| Conduta | **3 ou mais** pessoas + reiteradamente ou não + para fim de praticar **tráfico** (arts. 33 caput/§1 e 34) |
| **Pena** | **Recl. 3-10 anos + multa** |
| **Especialidade** | **AFASTA CP 288** quando a finalidade é tráfico (jurisprudência pacífica do STJ) |

## Lei Anticrime (13.964/2019)

| | Conteúdo |
|---|---|
| **Art. 4 Lei 12.850** | **Colaboração premiada**: natureza de **negócio jurídico processual** (STF HC 127.483) |
| Homologação | Sob controle de **regularidade + voluntariedade + legalidade** |
| Corroboração externa | **Necessária** |
| **STF Toffoli** (2024-2026) | Controle de cláusulas atípicas + vedação de renúncia ao silêncio sem assistência técnica |

## Causas de aumento (Lei 12.850 art. 2 §§ 2-4)

| | Conteúdo |
|---|---|
| **Metade** | Arma de fogo |
| **1/6 a 2/3** | Criança/adolescente + funcionário público (aproveitando-se da função) + produto para outro país + conexão com outra organização autônoma |

## Hediondez

| | Conteúdo |
|---|---|
| CP 288 | **NÃO hediondo** |
| Lei 12.850 | **NÃO hediondo automático** |
| **Lei 13.964/2019** | Incluiu **comando de organização criminosa estruturada para crime hediondo** no rol (Lei 8.072 art. 1 par. único V) |

## Natureza + consumação

| | Conteúdo |
|---|---|
| Crime | **FORMAL + permanente** |
| Consumação | Com a **estabilidade do vínculo**, independentemente da prática de crime-fim |
| **Súm. 711 STF** | Lei penal mais grave vigente durante a permanência incide |

## Jurisprudência consolidada

| | Conteúdo |
|---|---|
| **STJ** | Vínculo **eventual/esporádico NÃO configura**: exige-se **animus associativo ESTÁVEL** |
| **STF AP 470 + INQ 4.781** | Estabilidade aferida por **divisão de tarefas + hierarquia + durabilidade + logística** |
| **STJ** | Concurso entre CP 288 e crimes-fim é **MATERIAL** (CP 69), não consunção |
| **STF** | Distinção entre **coautoria eventual (CP 29)** e **associação (CP 288)**: necessidade de prévio ajuste com estabilidade |

## Lei 14.197/2021: crimes contra Estado Democrático

Criou tipos contra Estado Democrático (Tít. XII CP); associação para esses fins pode configurar **CP 359-L** (organização para abolir Estado de Direito).

## Lei 12.694/2012: juízo colegiado

Permite **3 juízes** em processos sobre organizações criminosas (proteção do magistrado). NÃO cria tipo penal (processual).

## Lei 15.358/2026 (Lei Raul Jungmann): Marco Legal do Combate ao Crime Organizado

| | Conteúdo |
|---|---|
| Novos tipos | **Domínio social estruturado** e **favorecimento ao domínio social estruturado** (conforme ementa da lei) |
| Execução penal | Elevou frações de progressão dos hediondos (LEP 112: 70/75/80/85%) e previu 75% com vedação de livramento para quem exerce **comando de organização criminosa ultraviolenta** estruturada para hediondos (LEP 112 VI "b") |
| CP 147-C | Ameaça em contexto de domínio social estruturado: recl. 1-3 anos |
| Vigência | 25/03/2026; frações mais gravosas não retroagem |

## Síntese operacional

| Hipótese | Tipo |
|---|---|
| 3+ pessoas + crime em geral + vínculo estável | **CP 288** |
| 3+ pessoas + finalidade tráfico | **Lei 11.343 art. 35** (especialidade) |
| 4+ pessoas + estrutura + hierarquia + divisão + vantagem | **Lei 12.850** |
| Milícia paramilitar | **CP 288-A** |
| Vínculo eventual | **Não configura**: coautoria (CP 29) |
| Crimes-fim praticados | **Concurso material** (CP 69) |
| Associação + crime hediondo + comando | **Hediondez** (Lei 8.072 par. único V) |

## Erros a evitar

- Aplicar **Lei 12.850 sem provar estrutura ordenada + divisão de tarefas** (o STJ anula a condenação);
- Capitular **CP 288 em vínculo eventual** (confunde com coautoria CP 29);
- **Ignorar especialidade do art. 35 Lei 11.343** quando finalidade é tráfico (bis in idem);
- Não reconhecer **concurso material** entre associação e crimes-fim (autônoma);
- Aplicar **majorante de arma do CP 288 par. único cumulativamente** com majorante de arma do crime-fim (bis in idem se mesma arma);
- **Confundir CP 288-A (milícia)** com Lei 12.850 (milícia tem tipo próprio mais grave);
- Computar **inimputável** para fechar o número mínimo sem aplicar majorante (CP 288 par. único + Lei 12.850 §4 II);
- **Homologação de colaboração premiada** sem corroboração externa (STF Pet 7.074);
- Aplicar **hediondez automática** à Lei 12.850 (só com comando para crime hediondo);
- Esquecer **Súm. 711 STF** em crime permanente.

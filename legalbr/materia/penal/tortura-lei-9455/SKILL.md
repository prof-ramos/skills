# Crime de Tortura

## Estrutura típica (Lei 9.455/1997 art. 1)

### Inciso I: tortura-prova/coação/discriminatória
| | Conteúdo |
|---|---|
| Conduta | **Constranger** com **violência ou grave ameaça** + causar sofrimento físico/mental |
| Finalidade específica | (a) Obter informação/declaração/confissão; (b) provocar ação/omissão criminosa; (c) **discriminação racial/religiosa** |
| Sujeito ativo | **Comum** |

### Inciso II: tortura-castigo
| | Conteúdo |
|---|---|
| Conduta | Submeter pessoa **sob guarda + poder + autoridade** a intenso sofrimento físico/mental como **castigo pessoal** OU **medida preventiva** |
| Sujeito ativo | **Crime PRÓPRIO**: STJ exige vínculo jurídico prévio de guarda/poder/autoridade; ausente, desclassifica para lesão/maus-tratos |

### §1
Submeter **preso** OU pessoa **sujeita a medida de segurança** a sofrimento físico/mental por ato não previsto em lei (pena equiparada: 2 a 8 anos).

## Penas + qualificadoras

| | Conteúdo |
|---|---|
| **§2, pena base** | **Recl. 2-8 + multa** |
| **§3, lesão grave** | **Recl. 4-10** |
| **§3, resultado MORTE** | **Recl. 8-16** (preterdolo: dolo na tortura + culpa no resultado) |

## Aumentos (§4: 1/6 a 1/3)

| | Conteúdo |
|---|---|
| (i) | **Agente público** |
| (ii) | Vítima **criança + gestante + PCD + maior de 60** |
| (iii) | Mediante **sequestro** |

## Efeitos da condenação (§5)

| | Conteúdo |
|---|---|
| **Perda do cargo** | **Automática** |
| **Inabilitação** | Pelo **DOBRO** do prazo da pena |

## §6 + §7

| | Conteúdo |
|---|---|
| **§6** | **Inafiançável + insuscetível de graça/anistia** (CF 5 XLIII) |
| **§7** | **Regime inicial FECHADO**: o **STF (HC 111.840, Pleno, 27/06/2012)** declarou **INCONSTITUCIONAL** a obrigatoriedade (viola a individualização da pena, CF 5 XLVI); o juiz aplica o CP 33 fundamentadamente |

## Equiparação a hediondo + progressão

| | Conteúdo |
|---|---|
| CF 5 XLIII + Lei 8.072/90 | **Equipara a hediondo** |
| **Anticrime** (Lei 13.964/2019) | Migrou progressão para LEP 112 |
| **Lei 15.358/2026** (vigente 25/03/2026) | Elevou as frações (*novatio in pejus*: só para fatos a partir de 25/03/2026) |
| Primário sem morte | **40%** (fato até 24/03/2026) / **70%** (a partir de 25/03/2026) |
| Primário com morte | **50%** / **75%** |
| Reincidente específico sem morte | **60%** / **80%** |
| Reincidente específico com morte | **70%** / **85%** |
| **STJ Tema 1.084** | Retroatividade do patamar do art. 112, V (fração de primário) ao apenado por hediondo/equiparado sem morte que não seja reincidente específico |

## Convenção ONU contra a Tortura (Dec. 40/1991)

| | Conteúdo |
|---|---|
| Definição | Tortura: finalidade + agente estatal/aquiescência |
| Exigência | Tipificação interna + jurisdição universal |
| Lei 9.455/97 | **Ampliou o tipo**: NÃO exige agente público (salvo §4 majorante) |

## Tortura × maus-tratos (CP 136)

| | Tortura | Maus-tratos |
|---|---|---|
| **Intensidade** | Dano efetivo + sofrimento intenso | Perigo concreto |
| **Dolo** | Vontade de impingir padecimento desnecessário | Excesso no *animus corrigendi* |
| **STJ** | Tortura-castigo **dispensa deleite/gozo**: basta intenção de causar sofrimento desvinculado de fim educativo | Não se aplica |

## Concurso com homicídio

| | Conteúdo |
|---|---|
| **Tortura qualificada pela morte (§3)** | **Preterdolosa** (dolo só de torturar): **CONSOME homicídio culposo** (consunção) |
| **Homicídio qualificado por tortura (CP 121 §2 III)** | **Dolo de matar** + tortura como meio cruel; STJ exige "processo cruel" prolongado |

## Atualizações legislativas

| | Conteúdo |
|---|---|
| **Lei 14.245/2021** (Mariana Ferrer) | Vedações a humilhação em audiência aplicam-se a vítimas de tortura |
| **Lei 14.811/2024** | Ampliou o rol de hediondos com crimes graves contra crianças e adolescentes (proteção reforçada da vítima menor) |
| **Lei 13.964/2019** | Não modificou substancialmente o tipo |
| **Súm. 711 STF** | Lei penal mais grave aplica-se a crime permanente/continuado iniciado antes; relevante para tortura prolongada |

## STJ: agravantes do CP em tortura

O crime de tortura pode receber **agravante do CP** quando praticado **contra descendente** (CP 61 II "e"), conforme jurisprudência do STJ.

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Constranger com violência para obter confissão | **Art. 1, I, "a"** |
| Castigo a filho sob guarda | **Art. 1, II** (crime próprio) |
| Resultado morte preterdoloso | **§3: 8-16** + consome homicídio culposo |
| Agente policial torturando | **§4 (i)**: +1/6 a 1/3 + **perda do cargo** (§5) |
| Tortura prolongada + lei nova | Lei mais grave aplica-se (Súm. 711 STF) |
| Regime inicial fechado obrigatório | **Inconstitucional** (HC 111.840) |
| Reincidente genérico, hediondo sem morte | Fração de **primário** (STJ Tema 1.084): 40% até 24/03/2026 ou 70% a partir de 25/03/2026 |
| Tortura × maus-tratos | Intensidade + dolo |
| Sem vínculo de guarda no inciso II | **Desclassificar** para lesão/maus-tratos |

## Erros a evitar

- **Condenação por tortura sem finalidade específica**, sem (a)/(b)/(c) do inciso I, ou sem castigo/prevenção do inciso II (descabe);
- **Confundir com maus-tratos**: exigir prova do *animus* de causar sofrimento (não apenas excesso disciplinar);
- **Fixação de regime inicial fechado de ofício** com base no §7 (inconstitucional, HC 111.840); deve fundamentar pelo CP 33;
- **Omitir perda do cargo (§5)**, efeito automático da condenação;
- Aplicar a fração de **reincidente específico** a reincidente genérico em tortura sem morte (STJ Tema 1.084: usa-se a fração de primário);
- Aplicar frações de hediondo **sem aferir a data do fato** (Lei 15.358/2026 elevou para 70/75/80/85% apenas a partir de 25/03/2026);
- **Cumular** tortura qualificada pela morte com homicídio (viola consunção: preterdolo);
- Aplicar **tortura-castigo (II) sem vínculo de guarda/poder** (crime próprio);
- **Ignorar §4** quando agente é policial/servidor (majorante obrigatória);
- Admitir **graça/anistia** em tortura (CF 5 XLIII, vedados);
- Aplicar **prescrição** sem considerar pena máxima (16 anos para §3 morte: PPP 20 anos).

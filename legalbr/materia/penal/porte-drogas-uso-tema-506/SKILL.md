# Porte de Drogas para Uso Pessoal (Tema 506 STF)

## Acórdão paradigma

| | Conteúdo |
|---|---|
| Caso | **RE 635.659/SP** |
| Relator | **Min. Gilmar Mendes** |
| Julgamento | **26/06/2024** (Pleno) |
| Acórdão | Publicado **27/09/2024** |

## Teses fixadas (8 teses)

| | Conteúdo |
|---|---|
| **1** | Não comete **infração penal** quem adquire, guarda, tem em depósito, transporta ou traz consigo, para **consumo pessoal**, **cannabis sativa**, sem prejuízo da **ilicitude extrapenal** |
| **2** | Sanções dos incisos I e III do art. 28 (advertência, medida educativa) aplicadas em procedimento **não penal** |
| **3** | Presume-se **usuário** quem porta até **40 g** OU **6 plantas-fêmeas** (presunção **relativa**) |
| **4** | Presunção não impede a **prisão em flagrante por tráfico** com elementos de mercancia |
| **5** | NÃO afeta **outras drogas** |
| **6** | Aplica-se aos processos em **andamento e em execução** |
| **7** | Cumprimento de sanções pretéritas **não obstaculiza** nova caracterização como usuário |
| **8** | Comunicação ao Congresso |

## Modulação

| | Conteúdo |
|---|---|
| Eficácia | **Prospectiva** + aplicação aos processos em curso e execução |
| Apreensão da droga | **Mantida** |
| Sanções **não penais** | Mantidas (advertência, curso) |
| **Não há abolitio criminis** para tráfico | Sim |

## Limite quantitativo

| | Conteúdo |
|---|---|
| **40 g** de cannabis sativa | **Presunção relativa** de uso |
| **6 plantas-fêmeas** | Idem |
| Autoridade policial | Pode afastar com elementos de **mercancia** |

| Antecedentes | **Não gera** |
| Reincidência | **Não gera** |

## Distinguishing

| Hipótese | Saída |
|---|---|
| **Outras drogas** (cocaína, ecstasy) | **NÃO descriminalizadas** |
| Quantidade **> 40 g** | Presunção de **tráfico** |
| Elementos de **mercancia** | Tráfico mesmo abaixo de 40 g |
| **Tráfico privilegiado** (art. 33 §4) | Regime próprio |
| Cultivo comercial / transporte interestadual | Não legalizado |

## Erros a evitar

- Estender a descriminalização a **outras drogas**;
- Tratar o **limite de 40 g** como absoluto (é relativo);
- Manter **antecedentes criminais** por porte para uso (impróprio);
- Confundir com **legalização** (não houve);
- Não aplicar a tese a **processos em andamento e execução**;
- Ignorar a competência do **JECrim** para o procedimento administrativizado;
- Aplicar **reincidência** decorrente de art. 28 anterior a crime subsequente.

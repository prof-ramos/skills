# Erro de Tipo e Erro de Proibição

## CP 20: ERRO DE TIPO

| | Conteúdo |
|---|---|
| Caput | Erro sobre **ELEMENTOS DO TIPO OBJETIVO**: exclui o DOLO |
| Escusável (invencível) | **Exclui DOLO + CULPA** → ATIPICIDADE |
| Inescusável (vencível) | **Exclui DOLO** + permite CULPA (se crime admite modalidade culposa) |

## CP 20 §1: DESCRIMINANTES PUTATIVAS

| | Conteúdo |
|---|---|
| Hipótese | Erro sobre causa de exclusão da ilicitude (LD + EN + EC + estrito cumprimento) |
| **Teoria adotada (majoritária)** | **TEORIA LIMITADA DA CULPABILIDADE** (Exposição de Motivos 19 CP) |
| Erro sobre **PRESSUPOSTOS FÁTICOS** | Trata-se como **erro de tipo permissivo**: exclui o dolo; inescusável → **CULPA IMPRÓPRIA** |
| Erro sobre **EXISTÊNCIA/LIMITES** da causa | **ERRO DE PROIBIÇÃO INDIRETO** (CP 21) |
| Teoria extremada (minoritária) | Tudo como erro de proibição |

## CP 20 §2 e §3

| § | Conteúdo |
|---|---|
| **§2** | Erro determinado por **terceiro**: responde quem provocou (autoria mediata) |
| **§3** | **Error in persona**: irrelevante; consideram-se as condições da **vítima VISADA** (ficção jurídica) |

## CP 21: ERRO DE PROIBIÇÃO

| | Conteúdo |
|---|---|
| Objeto | **Ilicitude da conduta** (sabe o que faz; crê permitido) |
| Conhecimento da lei | Presunção *iuris tantum* |
| Relevância | **POTENCIAL** consciência da ilicitude (teoria normativa pura) |
| **Escusável (invencível)** | **ISENTA DE PENA** (inexigibilidade do potencial conhecimento) |
| **Inescusável (vencível)** | **REDUÇÃO OBRIGATÓRIA de 1/6 a 1/3** (direito subjetivo do réu, STJ); quantum fundamentado |

## CP 73: ABERRATIO ICTUS

| | Conteúdo |
|---|---|
| Hipótese | Erro na **EXECUÇÃO**: resultado em pessoa **diversa** (mesma espécie) |
| Tratamento | Aplica-se o **CP 20 §3**: considera-se a vítima **VIRTUAL** |
| Resultado duplo | **Concurso FORMAL** |

## CP 74: ABERRATIO CRIMINIS

| | Conteúdo |
|---|---|
| Hipótese | Erro com resultado de **natureza DIVERSA** (visou pessoa, atingiu coisa) |
| Tratamento | Responde por **CULPA** pelo resultado obtido (se previsto) |
| Resultado duplo | Concurso formal |

## Distinção CRÍTICA

| | Erro de Tipo (CP 20) | Erro de Proibição (CP 21) |
|---|---|---|
| Objeto | **Elementos do TIPO objetivo** | **ILICITUDE** da conduta |
| Escusável | **ATIPICIDADE** (exclui dolo + culpa) | **ISENTA DE PENA** |
| Inescusável | **CULPA** (se admitida) | **REDUÇÃO 1/6 a 1/3** |
| Erro recorrente | **Confundir** ambos | |

## CP 73 × CP 74

| | Aberratio ictus (73) | Aberratio criminis (74) |
|---|---|---|
| Resultado | Mesma espécie | Espécie diversa |
| Exemplo | A atira em B, acerta C | A atira em B, quebra vidro |
| Tratamento | Considera vítima virtual | Culpa pelo resultado |
| Concurso | Formal duplo | Formal |

## Jurisprudência (até maio/2026)

| | Conteúdo |
|---|---|
| STF/STJ | **Escusabilidade exige ANÁLISE CONCRETA** das circunstâncias pessoais (escolaridade + contexto cultural + acesso à informação); não basta presunção |
| STJ, VD | Descumprimento de **medida protetiva** com ciência formal **afasta** o erro de proibição |
| Normas penais em branco | Admite erro de proibição quando **complemento normativo de difícil acesso ao leigo** |
| STF, bagatela aduaneira | Reconhecido erro de proibição em contextos específicos |
| STF, porte de arma em zona rural/indígenas | Erro de proibição cabível |

## Modalidades

| | Conteúdo |
|---|---|
| Erro **ESSENCIAL** | Sobre elemento essencial do tipo → **EXCLUI DOLO** |
| Erro **ACIDENTAL** | Sobre circunstância → **NÃO EXCLUI** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Erro sobre **fato** | **CP 20** |
| Erro sobre **ilicitude** | **CP 21** |
| Erro escusável de tipo | **ATIPICIDADE** |
| Erro inescusável de tipo | **CULPA** (se admite) |
| Erro escusável de proibição | **ISENÇÃO** (exclui culpabilidade) |
| Erro inescusável de proibição | **Redução 1/6 a 1/3 OBRIGATÓRIA** |
| LD putativa (pressuposto fático) | **CP 20 §1**: erro de tipo permissivo |
| LD putativa (existência/limite) | **CP 21**: erro de proibição indireto |
| Erro na execução (pessoa diversa) | **CP 73**: vítima virtual |
| Erro com resultado diverso | **CP 74**: culpa |
| Erro determinado por 3º | **CP 20 §2**: autoria mediata |

## Erros a evitar

- **Confundir erro de tipo (CP 20)** com **erro de proibição (CP 21)** (objetos distintos);
- **Tratar redução do CP 21 inescusável como facultativa** (é OBRIGATÓRIA);
- Aplicar **Súm. 17 STJ** (absorção) onde cabe erro de tipo;
- **Confundir aberratio ictus (CP 73, mesma espécie) com aberratio criminis (CP 74, espécie diversa)**;
- Tratar **descriminante putativa FÁTICA** como erro de proibição (o Brasil adota a teoria LIMITADA: é erro de tipo permissivo);
- **Ignorar culpa IMPRÓPRIA** nas descriminantes putativas vencíveis;
- Negar **erro de proibição em norma penal em branco** complexa;
- Aceitar **presunção pura** de conhecimento da lei (exige análise concreta);
- Aplicar **error in persona** considerando a vítima ATINGIDA (o CP 20 §3 considera a VISADA);
- Confundir **erro escusável** com **causa de inexigibilidade genérica**;
- Não distinguir **erro ESSENCIAL** (exclui dolo) de **ACIDENTAL** (irrelevante).

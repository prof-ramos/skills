# Genocídio

## Lei 2.889/1956: texto

| Art. | Conteúdo | Pena |
|---|---|---|
| **1 "a"** | **Matar** membros do grupo | Pena CP **121 §2** (recl. 12-30) |
| **1 "b"** | **Causar lesão grave** à integridade física/mental | Pena CP **129 §2** (recl. 2-8) |
| **1 "c"** | Submeter a **condições** de existência **capazes de destruir** total/parcialmente | Pena CP **270** (recl. 10-15) |
| **1 "d"** | Adotar **medidas para impedir nascimentos** no grupo | Pena CP **125** (aborto sem consentimento, recl. 3-10) |
| **1 "e"** | Efetuar **transferência forçada de crianças** | Penas do CP **148**, conforme o caso: caput recl. 1-3; §1 IV recl. 2-5 (vítima menor de 18); §2 recl. 2-8 (grave sofrimento) |
| **2** | **ASSOCIAÇÃO** de **mais de 3 pessoas** (mínimo 4) para genocídio | **Metade** das do art. 1 |
| **3** | **INCITAÇÃO** direta e pública ao genocídio | **Metade** das do art. 1 |
| **3 §1** | Incitação **pelos meios de comunicação** | Em **dobro** |
| **4** | Pena maior + agravante CP 61 (organizador/cabeça) | + 1/3 |
| **5** | Tentativa | CP 14 II (1/3 a 2/3) |
| **6** | Crimes praticados por funcionário público | Inaplicável CP 327 (não funcionário) |

## Elementos do tipo

| | Conteúdo |
|---|---|
| **Especial dolo** | Intenção **ESPECÍFICA** de **destruir, total ou parcialmente, GRUPO** identificável (nacional/étnico/racial/religioso) |
| Grupo | **Coletivo identificável**: não basta morte de várias pessoas |
| Não exige | Êxito na destruição: basta a **intenção + uma das condutas típicas** |
| Bem jurídico | **Existência do grupo** + dignidade humana coletiva |
| Crime | **Múltiplo** (cada ato pode constituir genocídio se houver dolus specialis) |

## Caráter hediondo + prescrição

| | Conteúdo |
|---|---|
| **Lei 8.072 art. 1 par. único** | Tentado **OU** consumado = **HEDIONDO** |
| **CF 5 XLIII + Lei 8.072 art. 2 I** | Hediondo: insuscetível de **anistia, graça e indulto** |
| Prescrição | **Sem regra expressa de imprescritibilidade**: STF Ext 1.362 (Pleno, 2016) exige lei interna e nega eficácia à Convenção de 1968 (não aderida pelo BR) e ao jus cogens; a corrente que estende o CF 5 XLII (racismo, HC 82.424) ao genocídio étnico-racial é tese em debate, sem decisão específica do STF |
| **CF 5 XLII** | Racismo imprescritível + inafiançável; há corrente que enquadra o genocídio étnico-racial no conceito amplo de racismo (HC 82.424), sem tese específica |
| Hediondez progressão | LEP 112 + Anticrime |

## Caso HAXIMU (RE 351.487/RR, STF Pleno 03/08/2006)

| | Conteúdo |
|---|---|
| Caso | Massacre **1993** de 12 Yanomami por garimpeiros em **Roraima** |
| Tese fixada | **Competência da JUSTIÇA FEDERAL** (CF 109 V: disputa por terras indígenas + tratado internacional) |
| Genocídio + homicídios | **CONCURSO MATERIAL** (CP 69): Lei 2.889 + CP 121 §2 |
| Bem jurídico distinto | Genocídio protege **grupo** e homicídio protege **vida individual**: não há consunção |
| Relator | Min. Cezar Peluso |
| Sentença | 19-20 anos (garimpeiros condenados pela Justiça Federal de Boa Vista) |

## STF: competência

| | Conteúdo |
|---|---|
| **Justiça FEDERAL** | **REGRA** (RE 351.487: terras indígenas + tratado + grupo) |
| CF 109 V | Crimes previstos em **tratado internacional** (Convenção 1948) |
| Conexão | Mesmo crime conexo segue Federal |
| Crime militar | TPI militar **não cobre** genocídio civil; vide CPM |

## Estatuto de Roma (TPI): Decreto 4.388/2002

| | Conteúdo |
|---|---|
| **Genocídio** (art. 6 ER) | Definição idêntica à Convenção 1948 |
| Crimes contra humanidade (art. 7) | Distintos de genocídio (sem dolus specialis sobre grupo) |
| Crimes de guerra (art. 8) | Genocídio em conflito armado |
| **Princípio da complementaridade** | TPI atua **subsidiariamente** quando Estado não puder/quiser punir |
| **CF 5 §4** | Sujeição do BR à jurisdição do TPI |
| Pena | Até **30 anos** OU prisão perpétua (caso de "extrema gravidade") |
| Aplicabilidade BR | TPI complementar: punição prioritária pelo BR |

## Distinções essenciais

| | Genocídio (Lei 2.889) | Crime contra humanidade (Estatuto Roma art. 7) |
|---|---|---|
| Dolus specialis | **EXIGIDO** (destruir grupo) | Não exige (basta ataque sistemático) |
| Vítima | **Grupo** identificável | **População civil** geral |
| Tipos | 5 condutas (a-e) | 11 condutas (assassinato, exterminação, escravidão, deportação, tortura, agressão sexual, perseguição, apartheid, desaparecimento forçado) |

| | Genocídio | Homicídio (CP 121) |
|---|---|---|
| Bem jurídico | **Grupo** | Vida individual |
| Concurso | **Material** (não há consunção, Caso Haximu) | |

| | Genocídio | Lei 7.716 racismo |
|---|---|---|
| Conduta | **Destruir grupo** | Discriminar pessoa |
| Bem jurídico | Existência coletiva | Dignidade + igualdade |
| Concurso | Possível concurso material | |

| | Genocídio | Lei 13.260 antiterrorismo |
|---|---|---|
| Dolus | Destruir grupo | Atemorizar população/governo (motivos políticos/ideológicos/religiosos/sociais) |
| Grupo-alvo | Étnico/nacional/racial/religioso | Indeterminado |

## Tipos análogos

| | Conteúdo |
|---|---|
| **Limpeza étnica** | Pode configurar Lei 2.889 quando há dolo específico, ou crime contra humanidade |
| **Apartheid** | Considerado **crime contra humanidade** (Estatuto Roma) |
| **Genocídio cultural** | Não tipificado expressamente; STJ/STF debatem em casos indígenas |
| **Femícidio em massa** | NÃO é genocídio (não há grupo nacional/étnico/racial/religioso) |

## Ação penal + processo

| | Conteúdo |
|---|---|
| Ação | **Pública INCONDICIONADA** |
| Foro | **Justiça Federal** (Caso Haximu) |
| Competência originária | **Tribunal do Júri** quando "matar" (Lei 2.889 art. 1 "a" + CP 121: bem jurídico vida) |
| Prescrição | Segue o **CP 109** pela jurisprudência dominante (STF Ext 1.362: imprescritibilidade depende de lei interna); corrente minoritária sustenta imprescritibilidade por jus cogens (voto do rel. Min. Fachin na Ext 1.362, não prevaleceu) |
| Anistia/graça/indulto | **VEDADOS**: CF 5 XLIII + Lei 8.072 art. 2 I (hediondez) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Matar indígenas em garimpo ilegal | **Lei 2.889 art. 1 "a"** + CP 121 §2 (concurso material); federal + júri |
| Causar lesões graves em grupo étnico | **Lei 2.889 art. 1 "b"** |
| Submeter aldeia a fome/sede sistemática | **Lei 2.889 art. 1 "c"** |
| Esterilização forçada de povo | **Lei 2.889 art. 1 "d"** |
| Transferir crianças indígenas para "cultura ocidental" | **Lei 2.889 art. 1 "e"** |
| Associação criminosa para genocídio | **Lei 2.889 art. 2** |
| Discurso público de incitação | **Lei 2.889 art. 3**; pela mídia (§1) dobra |
| Massacre racial sem destruir grupo | **CP 121** (vários): não é genocídio (sem dolus specialis) |
| Crime contra humanidade sem grupo identificável | TPI (art. 7), não Lei 2.889 |
| Estado-membro ou organização | TPI complementar se omissão BR |

## Erros a evitar

- **Reconhecer genocídio sem DOLUS SPECIALIS** (destruir grupo identificável);
- Tratar **homicídio múltiplo** como genocídio sem grupo nacional/étnico/racial/religioso;
- Aplicar **consunção** entre Lei 2.889 e CP 121 (Caso Haximu: concurso material);
- **Submissão à Justiça Estadual** (deve ser **Federal**, Caso Haximu, RE 351.487);
- Aplicar **anistia/graça/indulto** (vedados: CF 5 XLIII + Lei 8.072 art. 2 I);
- **Esquecer Tribunal do Júri** quando art. 1 "a" + CP 121 (crime doloso contra vida);
- Aplicar **Estatuto de Roma diretamente** (TPI é complementar: BR julga prioritariamente);
- Confundir **genocídio** (grupo) com **crime contra humanidade** (população);
- Tratar **violência política** como genocídio (sem grupo elementar);
- Aplicar Lei mais grave **retroativamente** (CF 5 XL);
- Não cumular com **agravante CP 61 II "h"** (idoso/criança vítima) quando não houver bis in idem.

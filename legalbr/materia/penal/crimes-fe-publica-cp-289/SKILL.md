# Crimes contra a Fé Pública

## I. Moeda falsa e equiparados (CP 289-292)

### CP 289
| | Conteúdo |
|---|---|
| **Caput** | Fabricar + alterar + importar + exportar + vender + trocar + ceder + guardar moeda falsa: **recl. 3-12 + multa** |
| **§1** | Guarda + aquisição + recebimento + introdução + transporte |
| **§2** | Restituição à circulação após receber de boa-fé: **det. 6m-2a + multa** (privilegiada) |
| **§3** | Funcionário público: agravamento específico |

### Demais
| | Conteúdo |
|---|---|
| **CP 290** | Moeda inutilizada/recolhida: det. 1-4 |
| **CP 291-292** | Petrechos + emissão sem causa legal |

### Competência
| | Conteúdo |
|---|---|
| Regra | **Justiça Federal** (CF 109 IV: interesse da União emissora) |
| **STJ Súm. 73** | Papel-moeda **GROSSEIRAMENTE falsificado** = **estelionato** (CP 171), **Justiça Estadual** (sem *imitatio veri*) |

## II. Falsificação material × ideológica

| | Conteúdo |
|---|---|
| **Material** (CP 296-298) | Altera/cria fisicamente o documento (forma) |
| **Ideológica** (CP 299) | Insere conteúdo falso em documento materialmente verdadeiro |

### CP 297: Documento PÚBLICO
| | Conteúdo |
|---|---|
| Conduta | **FALSIFICAR** (no todo ou em parte) OU **ALTERAR** documento público verdadeiro |
| Pena | **Recl. 2-6 + multa** |
| §1 | Aumento de **1/6** se funcionário público que se prevalece do cargo |
| **§2, EQUIPARAÇÕES** | Documento emanado de entidade paraestatal, títulos ao portador/transmissíveis por endosso, ações de sociedade comercial, livros mercantis e testamento particular |
| **§3 (Lei 9.983/2000)** | Inserção de declaração falsa em **CTPS e documentos previdenciários** equipara-se à falsificação de documento público; competência: **Justiça Estadual** quando a falsa anotação na CTPS é atribuída a empresa privada (**Súm. 62 STJ**) |
| **§4** | Omitir, em livro/documento tributário/previdenciário, declaração que deveria constar; **STJ exige DOLO de falso + potencialidade lesiva** à fé pública |

### CP 298: Documento PARTICULAR
| | Conteúdo |
|---|---|
| Conduta | Falsificar (no todo/parte) ou alterar |
| Pena | **Recl. 1-5 + multa** |
| **Par. único** (Lei 12.737/2012) | Equipara **cartão de crédito/débito** a documento particular |

### CP 299: Falsidade ideológica
| | Conteúdo |
|---|---|
| Conduta 1 | **Omitir**, em documento público ou particular, declaração que dele devia constar |
| Conduta 2 | **Inserir** ou fazer inserir declaração **FALSA ou DIVERSA** da que devia ser escrita |
| **Fim específico** | **PREJUDICAR direito + CRIAR obrigação + ALTERAR a VERDADE** sobre fato juridicamente relevante |
| Pena | **Recl. 1-5** (público) OU **det. 1-3** (particular) + multa |
| **Par. único** | **+ 1/3** se agente é funcionário público + documento público |
| Natureza | **FORMAL**: consuma com inserção/omissão, **independentemente de prejuízo efetivo** |
| Atipicidade | Ausência de **fim específico**: atípico |

### CP 299: STJ 2025, verificação obrigatória pela Administração

| | Conteúdo |
|---|---|
| Tese | Declarações sujeitas à **verificação OBRIGATÓRIA** pela Administração (ex.: hipossuficiência para gratuidade) **NÃO configuram CP 299** |
| Razão | Presunção é **RELATIVA**: a verdade pode ser apurada pelo órgão |

### CP 304: USO DE DOCUMENTO FALSO

| | Conteúdo |
|---|---|
| Pena | Mesma dos arts. **297-299** |
| Natureza | **FORMAL**: consuma com o **uso** |
| **STJ** | Se o **PRÓPRIO falsário usa**: **CRIME ÚNICO** (uso é mero **exaurimento** da falsificação) |
| **Súm. 546 STJ** | Competência para julgar USO de documento falso: **órgão A QUE APRESENTADO** (independe da entidade emissora) |
| Lei 14.155/2021 | Aplicável a documentos digitais |

### FALSIDADE GROSSEIRA (STF)

| | Conteúdo |
|---|---|
| Tese | Falsificação **perceptível *ictu oculi*** (a olho nu) por homem médio: **CRIME IMPOSSÍVEL** (CP 17) |
| Razão | **Ineficácia ABSOLUTA do meio** |
| **STJ** | Se a constatação **EXIGE PERÍCIA**: NÃO há crime impossível |
| CNH/identidade falsa em blitz | **Tipicidade plena** (não é grosseira) |

### CP 307 × uso de documento de identidade alheio

| | Conteúdo |
|---|---|
| **Apresentação de documento de identidade ALHEIO** | **NÃO** configura CP 307 (falsa identidade); enquadra-se no **CP 308** (uso de documento de identidade alheia) ou **CP 304**, conforme o caso |
| **STJ 17/06/2025** | Falsa identidade é crime **FORMAL**: consuma com fornecer dado incorreto |

### Tema 933 STJ: descaminho

| | Conteúdo |
|---|---|
| Tese | "Quando o falso se exaure no descaminho, sem mais potencialidade lesiva, é por este absorvido, como crime-fim, condição que não se altera por ser menor a pena a este cominada." |
| Critério | Falsidade exaure-se INTEGRALMENTE no descaminho + sem aptidão lesiva autônoma residual à fé pública |
| Crítica | Relativiza o critério da gravidade abstrata |

### Cadeia de Custódia (CPP 158-A-F + Lei 13.964/2019)

| | Conteúdo |
|---|---|
| Aplicação | Documentos físicos apreendidos |
| Quebra | **Inadmissibilidade probatória** (com prejuízo concreto) |
| Perícia grafotécnica | Exige **preservação documentada** |

## III. Classificação de documentos

| Documento | Natureza | Tipo |
|---|---|---|
| CNH + RG + CPF + passaporte + diploma público + certidão nascimento | **Público** | CP 297 |
| Contratos privados + declarações + recibos | **Particular** | CP 298 |
| Cartão de crédito/débito | Equiparado a particular | CP 298 par. único |
| Declaração de IR | Pública | CP 299; quando o falso se exaure no crime tributário/descaminho, é por ele absorvido (lógica da Súm. 17 e do Tema 933 STJ) |

## IV. Uso + supressão + falsa identidade

| Art. | Conteúdo | Pena |
|---|---|---|
| **CP 304** | **Uso de documento falso**: consumação independe de proveito | Pena da falsificação |
| CP 305 | Supressão | Recl. 2-6 |
| **CP 307** | **Falsa identidade** | Det. 3m-1a + multa |
| CP 308 | Uso de identidade alheia | Det. 4m-2a |
| **CP 311** | **Adulteração de sinal identificador veicular** | **Recl. 3-6 + multa** |

### Lei 14.562/2023: ampliação do CP 311
Ampliou drasticamente as condutas:
- **Adquirir + receber + transportar + ocultar + desmontar + vender** veículo com sinal adulterado;
- **Dolo eventual** admitido.

## V. Consunção: conflitos aparentes

| | Conteúdo |
|---|---|
| **STJ Súm. 17** | "Quando o falso se exaure no estelionato, sem mais potencialidade lesiva, é por este absorvido" |
| Critério decisivo | **Potencialidade lesiva remanescente** |
| Documento reutilizável | Concurso material |
| Exaurido na fraude | Absorção |
| **STJ (5ª T., 2024)** | Na relação meio/fim, **uso de documento falso (fim)** prevalece sobre a **falsidade ideológica (meio)**, NÃO o contrário |
| **STJ Súm. 522** | Atribuir-se **falsa identidade perante autoridade policial é TÍPICA**, ainda que em alegada autodefesa (na linha do STF RE 640.139, RG: direito ao silêncio não abrange identificação) |

## VII. Súm. 73 STJ + crime impossível

| | Conteúdo |
|---|---|
| **Súm. 73 STJ** | Moeda **grosseiramente falsificada** = **estelionato** (CP 171), JE |
| **CP 17** | Crime impossível por absoluta ineficácia |
| Distinção | Súm. 73 mantém **estelionato** (tipo diverso); CP 17 = atipicidade total |

## Síntese da tipificação

| Hipótese | Saída |
|---|---|
| Moeda falsa de qualidade | **CP 289** + **JF** |
| Moeda **grosseira** | **CP 171** + **JE** (Súm. 73) |
| Documento público falsificado materialmente | CP 297 |
| Documento particular falsificado materialmente | CP 298 |
| Documento verdadeiro com conteúdo falso | CP 299 (ideológica) |
| Uso de documento falso pelo falsário | Crime único (consunção, STJ) |
| Falso usado para estelionato + exaurido | **CP 171** (absorve, Súm. 17) |
| Falsa identidade perante autoridade policial | **CP 307** típico (Súm. 522) |
| Adulteração veicular + receber/desmontar/vender | **CP 311** (Lei 14.562) |
| Declaração de IR falsa + crime tributário | **Crime tributário absorve** (Tema 933) |
| Cartão de crédito falsificado | **CP 298 par. único** |

## Erros a evitar

- Aplicar **concurso material** onde cabe **Súm. 17** STJ: verificar se o falso tem potencial lesivo autônomo;
- Ignorar **Súm. 73 STJ** em falsificação grosseira de moeda: desclassificar para CP 171 + JE;
- **Admitir autodefesa** em CP 307 perante autoridade policial, Súm. 522 STJ é taxativa;
- **Confundir CP 297 com CP 298**: decide a natureza do documento (público × particular), não quem o portava;
- **Aplicar CP 297 em documento estritamente privado** (é CP 298);
- **Aplicar CP 298 em CTPS** (é CP 297 §3, red. Lei 9.983/2000; competência JE se atribuída a empresa privada, Súm. 62 STJ);
- **Admitir falsidade GROSSEIRA quando exigiu PERÍCIA** (não é crime impossível, STJ);
- **Inverter a consunção** (STJ) absorvendo o uso de documento falso pela falsidade ideológica: é o oposto, o uso (crime-fim) absorve a falsidade ideológica (crime-meio);
- Tipificar **CP 299** quando há rasura física (rasura = 297/298 material; conteúdo mentiroso em documento autêntico = 299);
- **Imputar CP 299 SEM demonstrar o fim específico** de prejudicar (atípico);
- Capitular **CP 299 em declaração de hipossuficiência** (STJ: verificação obrigatória torna atípico);
- **Desconsiderar §3 do CP 297** (Lei 9.983/2000) em fraudes previdenciárias;
- **Ignorar dolo específico no §4 do CP 297** (omissão objetiva insuficiente);
- Confundir competência da **Súm. 546** (órgão DESTINATÁRIO, não emissor);
- Aplicar **CP 307 a apresentação de documento de identidade alheio** (o caso é CP 308/304);
- Aplicar **CP 304 em concurso material** quando o próprio falsário usa (crime único, STJ);
- Tratar o **CP 299 como material** (exigindo prejuízo): é **formal**;
- Afastar consunção por **pena maior do crime-meio** (STJ admite);
- Aplicar **CP 311 caput** sem atentar para a **Lei 14.562/2023** (receptação dolosa eventual de veículo adulterado é típica);
- Não absorver **falso por descaminho** quando exaurido (Tema 933 STJ);
- Reconhecer **crime impossível** em falso grosseiro de documento (CP 17) confundindo com Súm. 73 (que tipifica estelionato);
- Não aplicar **Lei 14.155/2021** a documentos digitais falsos.

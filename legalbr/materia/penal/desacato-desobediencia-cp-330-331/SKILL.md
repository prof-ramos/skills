# Desacato + Desobediência

## CP 330: DESOBEDIÊNCIA

| | Conteúdo |
|---|---|
| Conduta | **Desobedecer ORDEM LEGAL** de funcionário público |
| Pena | **Det. 15d-6m + multa** |
| Bem jurídico | Regular funcionamento administrativo |

### STJ: requisitos
| | Conteúdo |
|---|---|
| (i) | Ordem **CONCRETA + INDIVIDUALIZADA** com destinatário determinado (NUNCA comando genérico previsto em lei) |
| (ii) | **CIÊNCIA INEQUÍVOCA** do destinatário (notificação pessoal) |
| (iii) | **AUSÊNCIA de SANÇÃO administrativa/civil específica** cominada em lei |
| **STJ (jurisprudência consolidada)** | A desobediência exige a inexistência de sanção administrativa/civil específica para o descumprimento, salvo ressalva legal expressa de cumulação com a sanção penal |

### Aplicação
| | Conteúdo |
|---|---|
| Aplica-se a | Desobediência à **ordem de parada policial** |
| **NÃO se aplica** a | **Mera infração administrativa** |

## CP 331: DESACATO

| | Conteúdo |
|---|---|
| Conduta | **DESACATAR funcionário público** no exercício/em razão da função |
| Pena | **Det. 6m-2a OU multa** |
| Conduta exigida | **HUMILHAR ou DESAFIAR**: *animus* efetivo de afrontar |
| Crítica educada + questionamento | **NÃO configura** |

## CADH + CIDH

| | Conteúdo |
|---|---|
| **CADH art. 13** | Liberdade de expressão |
| **CIDH Relatório Anual 1994** (Cap. V) | Leis de desacato são **INCOMPATÍVEIS com a Convenção** (silenciam opiniões impopulares) |
| 25+ países da OEA | **Já descriminalizaram** |

## STF ADPF 496 (Rel. Min. Barroso, 22/06/2020)

| | Conteúdo |
|---|---|
| Autora | Conselho Federal **OAB** |
| Votação | **9 x 2** pela constitucionalidade (vencidos Fachin + Rosa Weber) |
| Tese | CP 331 **RECEPCIONADO pela CF/88** |

### 4 critérios restritivos (Barroso)
| Inc. | Critério |
|---|---|
| (i) | Presença do funcionário |
| (ii) | Relação com a função |
| (iii) | **Perturbação EFETIVA do serviço** |
| (iv) | **Tolerância a excessos de INDIGNAÇÃO** |

| | Conteúdo |
|---|---|
| 2026 | Posição mantida; aplicação **RESTRITIVA** |

## STJ: HC 379.269/MS (3ª Seção, 24/05/2017)

| | Conteúdo |
|---|---|
| **5ª Turma 2016** | Havia declarado **INCONVENCIONALIDADE** |
| **3ª Seção 2017** | **REVERTEU** (HC 379.269/MS) |
| Tese | Duplo controle: desacato **COMPATÍVEL com CADH 13** (pune EXCESSOS, não a crítica) |
| 2026 | Mantida |

## CP 329: RESISTÊNCIA

| | Conteúdo |
|---|---|
| Conduta | **Opor-se à execução de ATO LEGAL mediante VIOLÊNCIA ou AMEAÇA** |
| Sujeito passivo | Funcionário público |
| Pena | **Det. 2m-2a** |
| **§1** | Forma qualificada: **det. 1-3 anos** se o ato, em razão da resistência, não se executa |
| §2 | Sem prejuízo das penas pela violência (**concurso material**) |
| Natureza | **FORMAL** + bem jurídico = funcionamento da Administração |
| ANPP | **NÃO admite** (envolve violência/ameaça) |
| Ato manifestamente ILEGAL | **AFASTA** o crime |
| **Resistência PASSIVA** (deitar/agarrar-se, sem violência ou ameaça) | **ATÍPICA** (STJ) |

## Distinções essenciais

| | Desobediência | Desacato | Resistência |
|---|---|---|---|
| Conduta | Não cumprir ordem | Humilhar | **Violência/ameaça** |
| Subsidiariedade | Sim (jurisprudência STJ) | Não | Não |
| ANPP | Pode (pena baixa) | Pode | NÃO |
| Ato ilegal | Afasta | Afasta | Afasta |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Não para na blitz | **Desobediência** (CP 330) |
| Há sanção administrativa específica | **Atípica** (jurisprudência STJ) |
| Xingar policial em serviço | **Desacato** (CP 331), observados os critérios da ADPF 496 |
| Mera crítica educada | **ATÍPICA** |
| Empurrar policial | **Resistência** (CP 329) |
| Resistência passiva | **Atípica** (STJ 2024) |
| Lesão grave ao policial | **CP 329 §1** + concurso material |
| Ato manifestamente ilegal | **AFASTA** todos |
| Ofensa fora da função | **CP 138-140** (honra) |
| CADH × CP 331 | **Compatível** (HC 379.269/MS) |
| 4 critérios Barroso | Aplicação restritiva |

## Erros a evitar

- **Aplicar DESACATO a CRÍTICA OU MERO QUESTIONAMENTO** (exige humilhação concreta);
- **Confundir DESOBEDIÊNCIA (ordem concreta) com mera INFRAÇÃO ADMINISTRATIVA** (jurisprudência STJ);
- **Ignorar CADH** + HC 379.269/MS STJ + ADPF 496;
- **Admitir resistência PASSIVA** como crime (é atípica: exige violência ou ameaça, STJ);
- Aplicar **desobediência genérica** a comando legal (exige ordem CONCRETA);
- Aplicar **CP 329 §2 isoladamente** sem concurso material (regra);
- Tratar **excesso de indignação** como desacato (critério da ADPF 496: tolerar);
- Não exigir **perturbação EFETIVA** do serviço (critério Barroso);
- Confundir desacato com **resistência** (humilhação × violência);
- **Afastar ANPP a desobediência** com pena máx 6m;
- Aplicar **ato manifestamente ilegal** como objeto de resistência (afasta).

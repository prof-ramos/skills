# Lenocínio e Exploração Sexual

## Estrutura

| Art. | Crime | Pena |
|---|---|---|
| **CP 227** | **Mediação** para servir à lascívia de outrem | Recl. **1-3** (multa cumulativa só no §3, fim de lucro) |
| **CP 228** | **Favorecimento** da prostituição/exploração sexual | Recl. **2-5** + multa |
| **CP 229** | **Casa** de prostituição/exploração sexual | Recl. **2-5** + multa |
| **CP 230** | **Rufianismo** | Recl. **1-4** + multa |
| **CP 231** | (REVOGADO) Tráfico internacional | Vide **CP 149-A** |
| **CP 231-A** | (REVOGADO) Tráfico interno | Vide **CP 149-A** |
| **CP 218-B** | Favorecimento + vulnerável (14-18) | Recl. **7-16** + multa (Lei 15.280/2025) + **HEDIONDO** |

## CP 227: mediação para servir à lascívia de outrem

| | Conteúdo |
|---|---|
| Verbo | **INDUZIR** alguém a satisfazer a lascívia de outrem |
| Bem jurídico | Dignidade sexual + liberdade |
| Pena | Recl. **1-3** |
| **§1 qualificadora** | Vítima **maior de 14 e menor de 18** OU agente ascendente/descendente/cônjuge ou companheiro/irmão/tutor/curador ou pessoa a quem a vítima esteja confiada para educação, tratamento ou guarda: recl. **2-5** |
| **§2** | Crime cometido com **violência/grave ameaça/fraude**: recl. **2-8**, além da pena correspondente à violência |
| **§3** | Se cometido com **fim de lucro**, aplica-se **também multa** (não é causa de aumento) |

## CP 228: favorecimento da prostituição/exploração sexual

| | Conteúdo |
|---|---|
| Verbos | **Induzir** + **atrair** + **facilitar** + **impedir/dificultar abandono** |
| Objeto | **Prostituição** OU outra **exploração sexual** |
| Pena | Recl. **2-5** + multa |
| **§1** | Agente **ascendente, padrasto, madrasta, irmão, enteado, cônjuge, companheiro, tutor, curador, preceptor ou empregador** da vítima, ou quem assumiu obrigação de cuidado/proteção/vigilância: recl. **3-8** |
| **§2 qualificadora** | **Violência/grave ameaça/fraude**: recl. **4-10**, além da pena correspondente à violência |
| Lei 12.015/2009 | Reformou o tipo: substituiu "lenocínio" por **"favorecimento"** |

## CP 229: casa de prostituição

| | Conteúdo |
|---|---|
| Verbo | **MANTER** estabelecimento (por conta própria ou de terceiro) |
| Bem jurídico | Dignidade sexual |
| Pena | Recl. **2-5** + multa |
| Tipo penal | **EXIGE EXPLORAÇÃO SEXUAL** (Lei 12.015: não basta a mera prostituição); irrelevante o intuito de lucro ou a mediação direta do proprietário/gerente |
| Lugar | Casa + apartamento + boate + clube + bordel + sauna + motel + similar |
| **STJ REsp 1.683.375/SP (Inf. 631, 6ª T, 2018)** | Após a Lei 12.015/2009, o tipo exige **exploração sexual** (violação à dignidade/liberdade sexual); manter local de prostituição sem exploração é **atípico** |
| Atipicidade | **Local que apenas hospeda profissionais sem exploração**: STJ admite atipia |

## CP 230: RUFIANISMO

| | Conteúdo |
|---|---|
| Verbo | **TIRAR PROVEITO** da prostituição alheia (participar diretamente dos lucros OU fazer-se sustentar) |
| Núcleo | Parasitismo econômico sobre quem se prostitui |
| Pena | Recl. **1-4** + multa |
| **§1 qualificadora** | Vítima **maior de 14 e menor de 18** OU crime cometido por ascendente, padrasto, madrasta, irmão, enteado, cônjuge, companheiro, tutor, curador, preceptor ou empregador, ou por quem assumiu obrigação de cuidado/proteção/vigilância: recl. **3-6** + multa |
| **§2 qualificadora** | **Violência, grave ameaça, fraude ou outro meio que impeça/dificulte a livre manifestação da vontade**: recl. **2-8**, sem prejuízo da pena correspondente à violência |
| Modalidades | **Ativo** (partilha lucros) × **passivo** (vive às custas) |
| Habitualidade | **EXIGE** (crime habitual), STJ |

## CP 218-B: favorecimento + vulneráveis (14-18)

| | Conteúdo |
|---|---|
| Verbo | **Submeter, induzir, atrair** à prostituição/exploração sexual |
| Vítima | **Menor de 18** OU quem, por enfermidade/deficiência mental, não tem discernimento |
| Pena | Recl. **7-16** + multa (Lei 15.280/2025; o §1 foi revogado) |
| **§2** | Incorre nas mesmas penas: **I** quem pratica conjunção carnal/ato libidinoso com menor 14-18 na situação do caput (cliente); **II** proprietário/gerente/responsável pelo local |
| **§3** | Efeito obrigatório da condenação no §2 II: **cassação da licença** de localização e funcionamento |
| Habitualidade | **NÃO se exige**: crime **INSTANTÂNEO**, consumado com a obtenção da anuência da vítima para práticas sexuais mediante oferta de dinheiro ou vantagem, ainda que o ato libidinoso não ocorra (STJ, 6ª Turma, j. 09/2022, aplicando o EREsp 1.530.637/SP, 3ª Seção, j. 03/2021, que também dispensa a figura do intermediador: o próprio cliente que oferece a vantagem responde) |
| **HEDIONDO** | Lei 8.072 art. 1 VIII (incluído pela Lei 12.978/2014) |
| Súm. 593 STJ | Estupro de vulnerável configura-se com ato sexual contra menor de 14, irrelevantes consentimento, experiência anterior ou namoro (vide [[estupro-crimes-sexuais]]) |

## CP 231 + 231-A: REVOGADOS (Lei 13.344/2016)

| | Conteúdo |
|---|---|
| Antes | Tráfico internacional/interno para prostituição |
| Depois | **CP 149-A**: tráfico de pessoas (genérico); vide [[trafico-pessoas-cp-149-a]] |
| Migração | Núcleos típicos do tráfico para exploração sexual passaram ao CP 149-A |
| Lei 13.344/2016 | Implementa o **Protocolo de Palermo** |

## Coexistência dos tipos (STJ)

| Tipos | Conteúdo |
|---|---|
| CP 228 + 229 + 230 | **COEXISTEM** e podem ser **autonomamente punidos** (STJ) |
| CP 229 + 230 | Manter casa + tirar proveito = **concurso material** |
| CP 228 + CP 218-B | Vulnerável → **lex specialis** (CP 218-B prevalece) |
| Atos sexuais com vulnerável + favorecimento | **Concurso** CP 217-A + 218-B |

## Bem jurídico e debate constitucional

| | Conteúdo |
|---|---|
| Prostituição **adulta voluntária** | **NÃO é crime** no BR |
| Bem jurídico | **Dignidade sexual** + proteção contra **exploração** |
| Crime existe quando | **Terceiro** explora: mediador + favorecedor + rufião + dono de casa |
| **STF** | Debate sobre revisão à luz da autodeterminação, não pacificado |

| | Conteúdo |
|---|---|
| Regra | **Justiça Estadual** |

| Lei 13.344 (tráfico) | Federal quando internacional |

## Distinções essenciais

| | CP 227 | CP 228 |
|---|---|---|
| Núcleo | **Mediar** para satisfação da lascívia (1 vez ou pontual) | **Manter** sistema de prostituição (continuado) |
| Vítima | Pessoa específica | Indeterminada/coletiva |

| | CP 228 | CP 229 |
|---|---|---|
| Núcleo | **Favorecer** prostituição (dinâmica) | **Manter LOCAL** de exploração |
| Verbo | Induzir/atrair/facilitar | **Manter** |
| Local | Não exige | **Estabelecimento** |

| | CP 230 | CP 228 |
|---|---|---|
| Núcleo | **Lucrar** da prostituição (parasitismo) | **Favorecer** a dinâmica |
| Crime | **Habitual** | Eventual |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Mediador esporádico | **CP 227** |
| Cafetão organizado | **CP 228** + às vezes 230 |
| Dono de boate exploratória | **CP 229** + possíveis 228/230 |
| Marido vive da prostituição da esposa | **CP 230** |
| Aliciamento de menor 16 + prostituição | **CP 218-B** (HEDIONDO) |
| Tráfico internacional para prostituição | **CP 149-A** + Lei 13.344: competência **federal** |
| Profissionais alugando quarto sem exploração | Caso a caso: **atípico** (STJ admite) |
| Cliente paga vulnerável de 16 | **CP 218-B §2 I** (cliente responde) |
| Casa + ganhar dinheiro + ciência | **CP 229** (habitual + exploração + ciência) |

## Erros a evitar

- **Tratar a prostituição em si como crime** (não é; só a exploração);
- Aplicar CP 229 sem **EXPLORAÇÃO SEXUAL** (Lei 12.015: o tipo exige);
- Aplicar CP 231/231-A (REVOGADOS): usar **CP 149-A**;
- Ignorar **CP 218-B** quando a vítima tem 14-18 (lex specialis + hediondo);
- Aplicar CP 227 a relação **continuada** (deve ser CP 228);
- Reconhecer CP 230 **sem habitualidade** (crime habitual exige);
- Transportar a exigência de **habitualidade** dos CP 229/230 para o **CP 218-B** (crime instantâneo, sem habitualidade);
- Confundir CP 229 (manter local) com CP 230 (parasitismo);
- Tratar o **§3 do CP 227 como causa de aumento**: o fim de lucro acarreta apenas a aplicação cumulativa de multa;
- Confundir o §1 do CP 228 (vínculo de autoridade/cuidado, 3-8) com hipótese de lucro;
- Tratar a competência como **federal** quando a exploração é **doméstica**;
- Reconhecer concurso entre CP 218-B + CP 217-A na mesma conjunção carnal (consunção pelo mais grave);
- Aplicar lei nova **gravosa retroativamente**;
- Aplicar CP 227 a vulnerável (deve ser CP 218-B).

# Tentativa e Arrependimento

## CP 14: consumação × tentativa

| Inc. | Conteúdo |
|---|---|
| **I (Consumado)** | **Realizados TODOS os elementos** do tipo |
| **II (Tentado)** | **Iniciada execução** + não consumado por **circunstâncias ALHEIAS À VONTADE** |
| Par. único | **Redução 1/3 a 2/3**, critério: **iter criminis percorrido** (STJ: objetivo, não culpabilidade) |

## Classificação da tentativa

| | Conteúdo |
|---|---|
| **PERFEITA / ACABADA** | **Esgotada execução**, resultado não consumado |
| **IMPERFEITA / INACABADA** | Execução **interrompida** por terceiro |
| **BRANCA / INCRUENTA** | Vítima **não atingida** |
| **CRUENTA** | Vítima **atingida** mas não morre |

## CP 15: DESISTÊNCIA VOLUNTÁRIA + ARREPENDIMENTO EFICAZ

| | Desistência | Arrependimento eficaz |
|---|---|---|
| Hipótese | Agente **DESISTE** durante execução (não esgotada) | Esgotada execução, **IMPEDE o resultado** |
| Fórmula | Desistência: "**posso, mas não quero**"; tentativa: "quero, mas não posso" | (idem, após esgotar a execução) |
| Efeito | Responde **só pelos atos JÁ praticados** | Mesmo |
| Apelido | **"Ponte de ouro"** | "Ponte de ouro" |
| Natureza | **Causa de exclusão da TIPICIDADE da tentativa** (majoritária) | Idem |
| Requisito | **VOLUNTARIEDADE** (≠ espontaneidade): basta não ser coagido | Idem |
| Resultado | Se **INEFICAZ**, responde pelo CONSUMADO | Idem |

## CP 16: ARREPENDIMENTO POSTERIOR

| Req. | Conteúdo |
|---|---|
| **(i)** | Crime **SEM violência/grave ameaça à PESSOA** (violência contra coisa admite, ex.: furto qualificado) |
| **(ii)** | **REPARAÇÃO INTEGRAL** do dano OU restituição (STJ exige integralidade) |
| **(iii)** | Até o **RECEBIMENTO da denúncia/queixa** |
| **(iv)** | **VOLUNTARIEDADE** |
| Redução | **1/3 a 2/3**; a fração é fixada pela **presteza (celeridade) e voluntariedade** da reparação: quanto mais próxima do fato e mais espontânea, maior a redução (STJ) |

### STJ (REsp 1.187.976)

| | Conteúdo |
|---|---|
| Natureza | **OBJETIVA** |
| Efeito | **COMUNICA-SE aos COAUTORES/partícipes** (CP 30) |

## CP 17: CRIME IMPOSSÍVEL

| | Conteúdo |
|---|---|
| Hipótese | **Ineficácia ABSOLUTA do meio** OU **impropriedade ABSOLUTA do objeto** |
| Teoria adotada | **OBJETIVA TEMPERADA** |
| Relativa | **NÃO** é crime impossível: tentativa punível |
| Efeito | **FATO ATÍPICO**, não há tentativa |

## Súmulas

| | Conteúdo |
|---|---|
| **Súm. 145 STF** | Não há crime quando a **preparação do FLAGRANTE** pela polícia torna **impossível** a consumação |
| **Súm. 567 STJ** | Vigilância eletrônica em estabelecimento **por si só NÃO torna o furto impossível** (ineficácia relativa) |
| **Súm. 554 STF** | O pagamento de **cheque sem fundos APÓS o recebimento da denúncia NÃO obsta** o prosseguimento da AP (a contrario: pago antes, obsta, tratamento *sui generis* do estelionato CP 171 §2 VI) |

## Crimes que NÃO admitem tentativa

| | Conteúdo |
|---|---|
| **Culposos** | Salvo **culpa imprópria** (erro vencível equiparado a doloso) |
| **Contravenções** | LCP 4: não puníveis tentadas |
| **Habituais próprios** | Não admitem |
| **Omissivos próprios** | Não admitem |
| **Unissubsistentes** | 1 ato (calúnia verbal) |
| **Preterdolosos** | Resultado culposo não admite "tentar" |
| Formais + mera conduta | **Controvertido**: admite-se quando plurissubsistente |

## Distinções essenciais

| | CP 15 (eficaz) | CP 16 (posterior) |
|---|---|---|
| Momento | **ANTES da consumação** | **APÓS consumação** |
| Crimes | Quaisquer | **SEM violência** |
| Efeito | Atos praticados | Redução 1/3-2/3 |
| Reparação | Não exige | **EXIGE integral** |
| Limite temporal | Antes do resultado | Até **recebimento da denúncia** |

| | Tentativa | Crime impossível |
|---|---|---|
| Ineficácia/impropriedade | **Relativa** | **Absoluta** |
| Punibilidade | **Sim** (com redução) | **Atípico** |

## Nomenclatura

CP 15 é a **"ponte de ouro"** (evita a consumação); CP 16 é a **"ponte de prata"** (reduz a pena após a consumação).

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Inicia execução + interrompido | **Tentativa** (CP 14 II), redução 1/3-2/3 |
| Desistiu voluntariamente | **CP 15**: só atos praticados |
| Esgotou execução + impediu resultado | **CP 15** (eficaz) |
| Esgotou + tentativa de impedir **ineficaz** | Responde pelo **consumado** |
| Crime sem violência + reparou antes da denúncia | **CP 16**: redução 1/3-2/3 |
| Roubo + reparou | **NÃO se aplica CP 16** (violência): atenuante CP 65 III "b" |
| Furto em loja com câmeras | **Tentativa** (Súm. 567: não impossível) |
| Flagrante preparado | **Crime impossível** (Súm. 145) |
| Tentativa em culposo | **NÃO admite** (salvo culpa imprópria) |
| Tentativa em contravenção | **NÃO admite** (LCP 4) |
| Coautor repara (CP 16) | **Comunica** aos demais (STJ, REsp 1.187.976) |

## Erros a evitar

- **Aplicar CP 16 a crime VIOLENTO** (roubo + extorsão + latrocínio: vedado);
- Reconhecer **desistência voluntária** quando houve **impedimento externo** (é tentativa);
- **Confundir tentativa imperfeita** (interrompida) **com crime impossível** (atípico);
- **Exigir espontaneidade** quando a lei pede apenas **voluntariedade**;
- Reduzir tentativa pela **culpabilidade** (critério é o **iter percorrido**);
- Não comunicar CP 16 aos **coautores** (STJ, REsp 1.187.976: comunica);
- Aplicar **Súm. 567** invertida (vigilância NÃO torna impossível);
- Tratar **flagrante esperado** como impossível (é tentativa);
- Aplicar tentativa a **contravenção** (LCP 4 veda);
- Aplicar tentativa a **culposo** (salvo culpa imprópria);
- Considerar reparação **parcial** suficiente para CP 16 (STJ exige integral).

# Invasão de Domicílio (CP 150)

## Tipo objetivo (caput)

| | Conteúdo |
|---|---|
| Conduta | **Entrar OU permanecer**, clandestina ou astuciosamente OU contra vontade expressa/tácita, em casa alheia ou dependências |
| **Pena** | **Det. 1-3 meses** OU multa |
| Natureza | **Subsidiário + formal + comum + mera conduta** |
| STJ 2025 | Irrelevantes a finalidade do agente e o resultado naturalístico; configura mesmo em gabinete de Delegado (compartimento não aberto ao público, §4 III) |

## §1: qualificadora (det. 6m-2a + multa)

| Hipótese | |
|---|---|
| **Noite** | |
| **Lugar ermo** | |
| **Violência** | |
| **Arma** | STJ: porte ostensivo basta |
| **2+ pessoas** | |

## §2: causa de aumento (+1/3)

Funcionário público **fora das formalidades legais** OU com **abuso do poder**; pode concorrer com **abuso de autoridade** (Lei 13.869/19).

## §3: excludentes + CF 5 XI

| | Conteúdo |
|---|---|
| **Dia + ordem judicial** | I |
| **Qualquer hora** | II: **flagrante + desastre + socorro** |
| "Noite" | Critério misto (psicológico/cronológico, **18h-6h** como referência) |

## §4: conceito de "casa"

| Inc. | Conteúdo |
|---|---|
| I | **Compartimento habitado** |
| II | Aposento de habitação coletiva |
| III | Local de profissão **não aberto ao público** |

| STF/STJ | Estende |
|---|---|
| Escritórios de advocacia | Sim (CF 5 XI + EOAB art. 7 II, Lei 8.906/94) |
| Quartos de hotel | Sim |
| Motorhome | Sim (em parte) |
| **Automóvel comum** | **NÃO** é casa |

## Tema 280 STF (RE 603.616)

| | Conteúdo |
|---|---|
| Tese | A entrada forçada em domicílio sem mandado judicial só é lícita, mesmo em período noturno, quando amparada em **FUNDADAS RAZÕES**, devidamente justificadas *a posteriori*, que indiquem situação de flagrante delito dentro da casa |
| Falta | **NULIDADE das provas** + responsabilidade disciplinar, civil e penal do agente |
| **Endurecimento 2024-2026** | STJ exige **REGISTRO AUDIOVISUAL** |
| Insuficientes | Mera "denúncia anônima" + "atitude suspeita" + "odor de maconha" exalando da residência (STJ 2023-2025: cheiro no suspeito autoriza busca pessoal, não a entrada na casa) |

## Tema 1.208 STF (RE 1.368.160, pendente)

| | Conteúdo |
|---|---|
| Objeto | Pressupostos de validade do **consentimento do morador** para busca e apreensão domiciliar (CF 5 XI); mérito pendente de julgamento |
| Diretriz STJ atual | Consentimento **livre + informado + documentado (preferencialmente vídeo/áudio)** |
| Ônus | Do **Estado** |

## Concursos

| | Conteúdo |
|---|---|
| Furto/roubo (subtração posterior) | **Coexiste** |

| **Esbulho possessório** (CP 161 §1 II) | Conflito |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Entrar contra a vontade | **CP 150 caput** |
| À noite com arma | §1 qualificada |
| Policial sem mandado durante o dia | Excludente (§3 I) se houver ordem |
| Flagrante delito | Excludente (§3 II) |
| Busca sem fundadas razões | **Nulidade** (Tema 280) |
| Consentimento sem registro | Suspeito (Tema 1.208 pendente; diretriz STJ) |
| Escritório de advocacia | "Casa" (§4 III) |
| Automóvel comum | NÃO é casa |

## Erros a evitar

- Aplicar **fora das excludentes do §3** (dia/ordem judicial + flagrante/socorro/desastre);
- **Equiparar "denúncia anônima" a fundada razão** (Tema 280 não admite);
- **Confundir casa com via pública** ou área comum de condomínio;
- Aceitar **consentimento sem registro audiovisual** (diretriz STJ; Tema 1.208 STF pendente);
- Tratar **automóvel como casa** (não é);
- Aplicar **CP 150 caput** quando há **lex specialis** (esbulho possessório CP 161);
- **Permitir mero "odor"** como fundada razão (STJ, jurisprudência consolidada);
- Não aplicar o §2 (aumento 1/3) a **funcionário público** sem formalidades;
- Admitir JECrim nas formas dos **§§ 1-2** (cabível apenas no caput);
- Aplicar **excludentes do §3** sem demonstração concreta.

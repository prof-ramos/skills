# Lei Antiterrorismo

## Marco legal

| | Conteúdo |
|---|---|
| **Lei 13.260/2016** | Regulamenta **CF 5 XLIII** (terrorismo **inafiançável + insuscetível de graça/anistia**) |
| Atende | Convenção Interamericana contra o Terrorismo (Dec. 5.639/2005) + Convenção Internacional para Supressão do Financiamento (Dec. 5.640/2005) |

## Art. 2: CONCEITO

| | Conteúdo |
|---|---|
| Conduta | Prática por **um ou mais indivíduos** |
| **Motivação** | **XENOFOBIA + DISCRIMINAÇÃO + preconceito de RAÇA + COR + ETNIA + RELIGIÃO** |
| Finalidade | Provocar **TERROR SOCIAL OU GENERALIZADO** + expor a perigo pessoa/patrimônio/paz pública/incolumidade |

## Art. 2 §1: 5 ATOS TÍPICOS

| Inc. | Conduta |
|---|---|
| **I** | Usar/ameaçar usar **EXPLOSIVOS + GASES TÓXICOS + AGENTES QUÍMICOS/BIOLÓGICOS/NUCLEARES** |
| **II** | **Atentar contra VIDA/INTEGRIDADE FÍSICA** |
| **III** | **APODERAR-SE ou controlar MEIOS DE TRANSPORTE COLETIVO** |
| **IV** | **SABOTAGEM ou atentado contra SERVIÇOS ESSENCIAIS** |
| **V** | **Atentar contra CHEFES DE ESTADO + autoridades** |

### Pena
| | Conteúdo |
|---|---|
| Reclusão | **12 a 30 anos + multa** |

## Tipos derivados

| Art. | Conduta | Pena |
|---|---|---|
| **3** | **Formação de grupo TERRORISTA** | 5-8 anos |
| 5 | Atos preparatórios | Pena do crime consumado diminuída de 1/4 a 1/2 |
| **6** | **FINANCIAMENTO** | **15-30 anos** |

## §2: EXCLUSÕES EXPRESSAS

| | Conteúdo |
|---|---|
| **EXCLUI** | **Manifestações POLÍTICAS + movimentos SOCIAIS + sindicais + RELIGIOSOS + CLASSISTAS + categoria profissional** dirigidas por propósitos sociais/reivindicatórios |
| Importância | **PROTEÇÃO da liberdade de expressão/manifestação** (CF 5 IV + XVI) |

## HEDIONDOS

| | Conteúdo |
|---|---|
| Status | **HEDIONDO** (Lei 8.072/1990 alterada) |
| Regime | Mais gravoso |
| Vedação | Graça + anistia (CF 5 XLIII) |

## COMPETÊNCIA

| | Conteúdo |
|---|---|
| **JUSTIÇA FEDERAL** | **CF 109 IV** (crimes em detrimento da União) + **CF 109 V** (crimes previstos em tratado) |

## Conjuntura: atos de 8 de janeiro de 2023

| | Conteúdo |
|---|---|
| STF (Inq. 4.879 + correlatos) | **NÃO aplicou** a Lei 13.260 |
| Capitulação | **Lei 14.197/2021**: **CRIMES CONTRA O ESTADO DEMOCRÁTICO DE DIREITO** (CP arts. 359-L a 359-T) |
| Razão | Falta de elementos típicos da Lei 13.260 (motivação política não basta: exige preconceito) |

## Lei 14.197/2021: Crimes contra o Estado Democrático

| Art. CP | Crime |
|---|---|
| **359-L** | Abolição violenta do Estado Democrático de Direito |
| **359-M** | Golpe de Estado |
| 359-N | Interrupção do processo eleitoral (violação do sistema eletrônico de votação) |
| **359-P** | Violência política |
| 359-R | Sabotagem |
| 359-T | Cláusula de não incriminação (manifestação crítica/jornalística/política não é crime) |

> Atenção: os arts. **359-O** (comunicação enganosa em massa) e **359-S** (atentado a direito de manifestação) foram **VETADOS** e não integram o Código Penal.

| | Conteúdo |
|---|---|
| Revogação | **LSN** (Lei 7.170/1983) |

## PL 83/2023 (Sen. Alessandro Vieira)

| | Conteúdo |
|---|---|
| Propõe | Incluir **MOTIVAÇÃO POLÍTICA** como elemento típico do terrorismo |
| Altera | Competência |

## STF: interpretação restritiva

| | Conteúdo |
|---|---|
| Vandalismo isolado | **NÃO É terrorismo** |
| Manifestação política | **NÃO É terrorismo** (§2 exclui) |
| Necessidade de motivação típica | **Discriminatória** específica |

## Distinções essenciais

| | Terrorismo (Lei 13.260) | Crime Estado Democrático (Lei 14.197) |
|---|---|---|
| Motivação | **Preconceito** (raça/etnia/religião) + xenofobia | **Atentar contra Estado** |
| Fundamento | Convenções internacionais | CF + soberania interna |
| Exclusão | Movimentos sociais | Manifestação/jornalismo (359-T) |
| Aplicação 8/1 | NÃO aplicado | Aplicado |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Bomba motivada por xenofobia | **Lei 13.260** |
| Ataque por preconceito religioso | **Lei 13.260** |
| Movimento sindical com vandalismo | **NÃO é terrorismo** (§2) |
| Manifestação política | **NÃO é terrorismo** |
| Ataque a instituições democráticas | **Lei 14.197** (CP 359-L+) |
| Financiamento de terrorismo | **Art. 6** (recl. 15-30a) |
| Formação de grupo terrorista | **Art. 3** |
| Vandalismo isolado | Crimes comuns |
| Competência | **JF** (CF 109 IV/V) |

## Erros a evitar

- **Aplicar Lei 13.260 a movimentos SOCIAIS/SINDICAIS/POLÍTICOS** (§2 EXCLUI);
- **Aplicar Lei 13.260 a atos de 8/1/2023** (STF capitulou em Lei 14.197);
- **Aplicar competência ESTADUAL** (terrorismo é JF, CF 109 IV/V);
- Tratar **VANDALISMO ISOLADO como terrorismo** (STF rejeita);
- Aceitar **motivação genérica** (exige preconceito típico);
- Aplicar **Lei 14.197 e Lei 13.260 cumulativamente** sem distinção dos elementos típicos;
- Conceder **graça/anistia** a terrorismo (CF 5 XLIII veda);
- Admitir **FIANÇA** (inafiançável);
- Tratar como **hediondez apenas no nome** (são consequências processuais);
- Aplicar **financiamento** com pena menor (15-30a, específica);
- Aplicar LSN (revogada pela Lei 14.197).

# Concurso de Pessoas

## CP 29 caput: TEORIA MONISTA TEMPERADA

| | Conteúdo |
|---|---|
| Regra | Quem concorre **PARA O CRIME** incide nas penas, na **MEDIDA DE SUA CULPABILIDADE** |
| Teoria | **MONISTA / UNITÁRIA TEMPERADA** (todos respondem pelo MESMO crime) |
| Mitigação | §§ 1 e 2: distinção entre autor e partícipe |
| Exceção pluralística | CP 124/126 (aborto); CP 317/333 (corrupção): tipos distintos |

## CP 29 §1: PARTICIPAÇÃO DE MENOR IMPORTÂNCIA

| | Conteúdo |
|---|---|
| Aplicação | Apenas a **PARTÍCIPE** (não a coautor) |
| Redução | **1/6 a 1/3** |
| Hipótese | Induzimento, instigação, auxílio secundário |

## CP 29 §2: COOPERAÇÃO DOLOSAMENTE DISTINTA

| | Conteúdo |
|---|---|
| Hipótese | Agente quis participar de crime **menos grave** |
| Efeito | Responde pelo crime que **QUIS** + aumento **até METADE** se resultado mais grave for **PREVISÍVEL** |
| Exemplo | A combina roubo, B mata → A responde por roubo (com aumento se previsível); B por latrocínio |

## CP 30: COMUNICABILIDADE

| | Conteúdo |
|---|---|
| **ELEMENTARES do tipo** (objetivas + subjetivas) | **COMUNICAM** entre concorrentes (que delas tenham ciência) |
| **CIRCUNSTÂNCIAS PESSOAIS** (subjetivas) | **NÃO COMUNICAM**, salvo elementares do tipo |
| Exemplo | Condição de **funcionário público** no peculato é **elementar** → comunica-se ao extraneus ciente |
| Exemplo de não comunicação | **Reincidência** (subjetiva) não se comunica |

## CP 31: participação INFRUTÍFERA

| | Conteúdo |
|---|---|
| Hipótese | Ajuste + determinação + instigação + auxílio + crime **NÃO TENTADO** |
| Efeito | **IMPUNÍVEIS** |
| Exceção | **Crime autônomo** (CP 286, incitação ao crime) |

## Requisitos cumulativos do concurso

| Req. | Conteúdo |
|---|---|
| **a** | **Pluralidade** de agentes E condutas |
| **b** | **Relevância causal** das condutas |
| **c** | **LIAME SUBJETIVO** (vínculo psicológico); sua ausência configura **autoria colateral** |
| **d** | **Identidade** da infração penal |

## Espécies de concorrência

| | Conceito |
|---|---|
| **Autor** | Quem tem o **DOMÍNIO DO FATO** (controle finalístico da conduta) |
| **Coautor** | **Divisão funcional** de tarefas |
| **Partícipe** | **Induz/instiga/auxilia** sem realizar o núcleo |
| **Autor MEDIATO** | Utiliza terceiro como **INSTRUMENTO** (inimputável/coagido/em erro) |

## Teorias

| Teoria | Conteúdo |
|---|---|
| **Monista pura** | Todos = autor |
| **Monista temperada** (BR, CP 29 caput + §§) | Admite distinção |
| Dualista | Distingue autor/partícipe |
| **Pluralística** | Cada qual responde por crime distinto (exceção) |

## Jurisprudência STF/STJ

| | Conteúdo |
|---|---|
| **STF AP 470 (Mensalão)** | **Consagrou** domínio do fato no Brasil |
| **STF** | Domínio do fato **NÃO opera como PRESUNÇÃO**: exige **indícios CONCRETOS** de controle finalístico (sob pena de responsabilidade objetiva) |
| **STJ** | A teoria do domínio do fato **não autoriza**, isoladamente, imputar crime pela simples posição hierárquica (ex.: sócio/administrador); exige descrição concreta do nexo causal entre conduta e resultado |

## Autoria colateral × concurso

| | Concurso | Autoria colateral |
|---|---|---|
| Liame subjetivo | **EXISTE** | **NÃO EXISTE** |
| Tratamento | Monista (mesmo crime) | Cada um responde por seu ato |

## Aplicações típicas

| Hipótese | Saída |
|---|---|
| A e B planejam furto | **Coautoria** (29 caput) |
| C apenas informa local | **Partícipe** (29 §1: pode reduzir 1/6 a 1/3) |
| A combina roubo, B mata | **Cooperação distinta** (29 §2): A por roubo + aumento se previsível |
| Funcionário público + extraneus em peculato | **Comunica** (CP 30) |
| Determinação a crime + não tentado | **IMPUNÍVEL** (CP 31) |
| Mandante sem domínio | NÃO basta posição hierárquica (STF) |

## Síntese operacional

| Hipótese | Solução |
|---|---|
| Pluralidade + liame + crime único | **Concurso** (29 caput) |
| Sem liame subjetivo | **Autoria colateral** |
| Participação acessória | **Menor importância** (1/6-1/3) |
| Crime mais grave previsível | **Aumento até metade** (29 §2) |
| Crime mais grave imprevisível | Responde só pelo que quis |
| Elementar (ex. funcionário) | **Comunica-se ao extraneus** |
| Reincidência | **Não se comunica** |
| Crime não tentado | **Impunível** (31) |

## Erros a evitar

- **Tratar partícipe como coautor** sem distinção funcional;
- **Comunicar circunstância pessoal** não elementar (viola CP 30);
- **Aplicar domínio do fato como PRESUNÇÃO** decorrente do cargo (vedado, STF/STJ);
- Tratar **acordo + crime não tentado** como punível (CP 31: impunível);
- Aplicar **aumento de previsibilidade automaticamente** (exige análise concreta);
- **Confundir autoria colateral com concurso** (na autoria colateral falta o liame);
- Aplicar **CP 29 §1 a coautor** (é só para partícipe);
- Tratar **autor mediato como partícipe** (responde como autor);
- Negar aplicação de **§2 ao previsível** apenas pela combinação inicial;
- Aplicar **AP 470 como autorização para presunções de autoria** (a jurisprudência posterior limitou);
- Não reconhecer **teoria pluralística** em CP 124/126 e 317/333.

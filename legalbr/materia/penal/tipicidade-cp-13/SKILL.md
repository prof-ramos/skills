# Tipicidade Penal

## CP 13 caput: NEXO CAUSAL

| | Conteúdo |
|---|---|
| Teoria | **CONDITIO SINE QUA NON** (Equivalência dos Antecedentes Causais) |
| Fórmula | "Causa é ação ou omissão **sem a qual** o resultado **não teria ocorrido**" |
| Procedimento | **Eliminação hipotética** dos antecedentes (suprime-se mentalmente a conduta; se o resultado desaparece, há nexo) |

## CP 13 §1: SUPERVENIÊNCIA CAUSAL

| | Conteúdo |
|---|---|
| **IMPREVISÍVEL** | **ROMPE o nexo**: agente responde só pelos atos praticados |
| **STJ** | Complicações **decorrentes diretamente da lesão** inicial (ex.: infecção hospitalar da ferida) **NÃO ROMPEM** o nexo |

## CP 13 §2: CRIMES OMISSIVOS IMPRÓPRIOS (GARANTE)

| Hipótese | Conteúdo |
|---|---|
| **a** | **DEVER LEGAL** de evitar (garante legal) |
| **b** | **ASSUNÇÃO** da responsabilidade (garante contratual) |
| **c** | **INGERÊNCIA**: comportamento anterior **CRIOU o RISCO** |

### Jurisprudência
| | Conteúdo |
|---|---|
| **STJ HC 603.195-PR** (5ª T., julg. 06/10/2020, Inf. 681) | A **irmã da vítima** de estupro de vulnerável responde por omissão imprópria **se assumiu o papel de garantidora** (alíneas "b" e "c") |
| Limite do mesmo julgado | O **mero parentesco entre irmãos NÃO gera** posição de garante (alínea "a" restrita ao dever legal, ex.: poder familiar); a responsabilização exige assunção fática ou ingerência |

## TEORIAS sobre nexo causal

| Teoria | Conteúdo |
|---|---|
| **Conditio sine qua non** | **Adotada no BR** (CP 13) |
| Causalidade adequada | Não adotada como regra geral |
| **Imputação objetiva** | Critério complementar, aplicado pelo STJ e STF para filtrar resultados não-imputáveis ao agente |

## IMPUTAÇÃO OBJETIVA: 3 FILTROS

| Filtro | Conteúdo |
|---|---|
| **1** | **CRIAÇÃO de RISCO PROIBIDO** |
| **2** | **REALIZAÇÃO** do risco **no RESULTADO** |
| **3** | **ÂMBITO de PROTEÇÃO da norma** |

| | Conteúdo |
|---|---|
| STF/STJ | Aplicando em **crimes culposos de trânsito + condutas neutras + omissão** |
| Diminuição de risco já existente | **Afasta** imputação |

## CP 18: DOLO + CULPA

| Inc. | Conteúdo |
|---|---|
| **I (DOLO)** | Consciência + vontade |
| Espécies | **Direto + EVENTUAL** (assumiu o risco) |
| **II (CULPA)** | Negligência + imprudência + imperícia |
| Espécies | **Consciente + inconsciente** |
| **Par. único** | Crime **EXCLUSIVAMENTE DOLOSO** salvo previsão expressa |

### Crimes preterdolosos
| | Conteúdo |
|---|---|
| Estrutura | **Dolo no antecedente + culpa no resultado** |
| Exemplos | Lesão corporal seguida de morte (CP 129 §3) |

## STJ: DOLO EVENTUAL × CULPA CONSCIENTE (trânsito)

| | Conteúdo |
|---|---|
| **REsp 1.689.173-SC** (6ª T., julg. 21/11/2017, Inf. 623; reiterado) | A embriaguez do condutor, **por si só, não basta** para afirmar dolo eventual: exige **demonstração da assunção do risco** por circunstâncias que excedam a violação do dever de cuidado (racha, contramão, velocidade extrema) |
| Pronúncia | Funciona como **filtro**: não pode basear-se em **PRESUNÇÃO** de dolo eventual; cabe ao juiz da 1ª fase do Júri examinar o elemento subjetivo |
| Caso paradigma | Morte no trânsito com motorista embriagada **desclassificada** para homicídio culposo (CTB 302) |

## CP 19: RESULTADO

| | Conteúdo |
|---|---|
| Tese | Pelo resultado que agrava a pena, responde-se **só com DOLO ou CULPA** |
| Veda | Responsabilidade objetiva |

## TIPICIDADE FORMAL × MATERIAL

| | Formal | Material |
|---|---|---|
| Conteúdo | **Adequação ao tipo** | **Lesão ao bem jurídico** |
| Afastada por | (não se afasta por esses institutos) | **Insignificância (STF HC 84.412)** + adequação social |

### STF HC 84.412: vetores cumulativos MARI
Aplicação à tipicidade material (já abordado em [[principios-penais-cp-1]]).

## CRIMES OMISSIVOS

| | Próprios | Impróprios |
|---|---|---|
| Dever | **GENÉRICO** (CP 135, omissão de socorro) | **ESPECÍFICO** de garante (CP 13 §2) |
| Resultado | Não exige | **EXIGE** + nexo |

## CRIMES de RESULTADO × MERA CONDUTA

| | Resultado | Mera conduta |
|---|---|---|
| Modificação | **Sim** (homicídio) | NÃO (porte de arma) |

## CRIMES de PERIGO

| | Concreto | Abstrato |
|---|---|---|
| Prova | **Exigida** | **Presunção legal** |
| STF | Admite ambos; abstrato em porte de arma etc. |

## Lei 13.964 (Anticrime)

| | Conteúdo |
|---|---|
| Ampliou | Hediondos (roubo com restrição + furto com explosivo) |
| Inseriu | CP 25 par. único (legítima defesa do agente de segurança contra agressão a refém) |
| Pena máxima | **40 anos** (CP 75) |

## Distinções essenciais

| | Dolo eventual | Culpa consciente |
|---|---|---|
| Vontade | **Assume o risco** | Acredita poder evitar |
| Critério STJ | Exige **prova da assunção** | Presunção de dolo vedada |

| | Tipo objetivo | Tipo subjetivo |
|---|---|---|
| Conteúdo | Conduta + resultado + nexo | **Dolo OU culpa** |

| | Próprio | Impróprio |
|---|---|---|
| Tipo | Tipificação independente | **Equiparação ao comissivo** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Ação A → resultado X | Nexo se A é conditio (eliminação hipotética) |
| Superveniência imprevisível | **ROMPE** nexo (§1) |
| Complicações da lesão inicial | **NÃO rompem** (STJ) |
| Mãe não impede crime contra filho | **CP 13 §2 "a"**: garante legal |
| Babá contratada | **CP 13 §2 "b"**: assunção |
| Quem criou risco | **CP 13 §2 "c"**: ingerência |
| Crime exclusivamente doloso | **Sem culpa** (par. único) |
| Embriaguez ao volante + morte | Sem prova de assunção: **CULPA CONSCIENTE** |
| Roubo + morte | **Latrocínio** (CP 157 §3 II) |
| Insignificância | **Tipicidade material afastada** |
| Conduta socialmente adequada | **Atípica materialmente** |

## Erros a evitar

- **Confundir teoria do RESULTADO (não adotada) com CONDITIO SINE QUA NON**;
- **Aplicar dolo eventual a CULPA CONSCIENTE** sem prova da assunção;
- **Ignorar tipicidade MATERIAL** (insignificância afasta tipicidade, NÃO culpabilidade);
- Confundir **omissão própria (CP 135) com IMPRÓPRIA (CP 13 §2)**;
- Punir agente por **resultado SEM dolo ou culpa** (CP 19 veda);
- Tratar **garante por ingerência** como responsabilidade objetiva;
- **Pronúncia ao Júri por dolo eventual presumido** (STJ, REsp 1.689.173-SC);
- Aplicar **imputação objetiva** sem analisar **âmbito de proteção** da norma;
- Confundir **dolo eventual com culpa consciente** sem fundamentação;
- Não exigir **prova de risco proibido** em imputação objetiva;
- Aplicar **causalidade adequada** (não adotada no BR).

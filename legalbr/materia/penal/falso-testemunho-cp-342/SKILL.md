# Falso Testemunho e Falsa Perícia

## Tipo (CP 342)

| | Conteúdo |
|---|---|
| Núcleo | **Fazer afirmação falsa, negar ou calar a verdade** |
| Sujeito ativo | **Testemunha, perito, contador, tradutor, intérprete** |
| Sede | Processo judicial, **inquérito policial**, processo **administrativo** ou em **juízo arbitral** + CPI |
| Pena | **Recl. 2-4 + multa** |
| Bem jurídico | Administração da Justiça (verdade dos fatos) |

## §1 (causa de aumento de 1/6 a 1/3)

Crime cometido com **fim de obter prova destinada a produzir efeito em processo penal** OU em processo civil que tenha por parte a **administração pública direta/indireta**.

## §2: retratação extintiva da punibilidade

| | Conteúdo |
|---|---|
| Condição | **Antes da sentença** no processo onde o falso testemunho foi prestado |
| Forma | Retratação espontânea + comunicação ao juízo |
| Efeito | **Extinção da punibilidade** |
| Sentença final | Marco: após, não há mais retratação extintiva (STJ HC 218.844) |

## Sujeito ativo: quem PODE/NÃO PODE

| | Pode? |
|---|---|
| Testemunha **compromissada** | **Sim** |
| Testemunha **sem compromisso** (parente, criança) | **Controvertido**: corrente majoritária no STJ admite (basta dever de verdade); minoritária nega |
| **Perito** | Sim |
| **Réu** (interrogatório) | **NÃO**: direito ao silêncio + não-autoincriminação (HC 75.257 STF) |
| Vítima/ofendido | **NÃO** (não é testemunha, CPP 201); pode ser denunciada por outros tipos |
| Investigado/indiciado | NÃO |
| Advogado da parte | NÃO (não é testemunha) |
| Assistente técnico | Controvertido: STJ admite (equiparado a perito) |

## §1: relevância

| Cenário | Aumento |
|---|---|
| Falso testemunho em ação penal | **Aplica-se §1** (finalidade de prova penal) |
| Falso testemunho em ação contra a Fazenda (execução fiscal, MS) | **Aplica-se §1** (parte é Adm. Pública) |
| Ação cível entre particulares | **NÃO se aplica §1**; pena base |

## Crime formal × tentativa

| | Conteúdo |
|---|---|
| Natureza | **Crime formal**: consuma com a afirmação falsa |
| Tentativa | **Inviável** (formal), posição majoritária no STJ |
| Quem nega/cala | Equiparado à afirmação falsa |

## §2: retratação, particularidades

| | Conteúdo |
|---|---|
| Quem | O próprio autor do falso testemunho (não basta arrependimento de terceiros) |
| Forma | Por escrito ou em audiência; ato formal |
| Marco | **Sentença de 1º grau** do processo onde foi prestado o falso |
| **STJ** | Retratação após sentença é **inútil**: não extingue |
| **Comunicabilidade** | Não; aproveita só ao próprio agente |

## Distinções

| Crime | Conduta |
|---|---|
| **CP 342** | Testemunha **mente** sob compromisso |
| **CP 341** | Auto-acusação falsa (chamar-se de autor) |
| **CP 340** | Comunicação falsa de crime à autoridade |
| **CP 339** | Denunciação caluniosa (imputar crime a quem sabe inocente) |
| **CP 343** | **Corromper** testemunha/perito para dizer falso |

## CP 343: corrupção ativa de testemunha

| | Conteúdo |
|---|---|
| Núcleo | Dar/oferecer/prometer dinheiro ou qualquer outra vantagem a testemunha/perito/contador/tradutor/intérprete para fazer falsa afirmação |
| Pena | **Recl. 3-4 + multa** |
| Causa de aumento (par. único) | Se cometido com fim de obter prova em processo penal/processo contra Adm.: aumento 1/6-1/3 |

## Concurso

| Cenário | Saída |
|---|---|
| Testemunha mente + parte oferece dinheiro | CP 342 (testemunha) + CP 343 (oferente), em concurso material |
| Falso testemunho + denunciação caluniosa | Pode haver concurso material (núcleos distintos) |
| Falso testemunho em vários processos | **Continuado** se conexão + mesmo agente |
| Falso testemunho + obstrução de justiça (Lei 12.850 art. 2 §1) | Concurso material |

## Procedimento

| | Conteúdo |
|---|---|
| Ação penal | **Pública incondicionada** |
| Início | Geralmente após **expedição de ofício** pelo juízo onde se deu o falso |
| Suspensão | Pode aguardar julgamento do processo principal (jurisprudência) |
| Competência | Local onde se deu o testemunho |
| Rito | Sumário/ordinário conforme pena |

## STJ: posições consolidadas

| Tema | Conteúdo |
|---|---|
| Testemunha sem compromisso | Corrente majoritária admite tipicidade (basta dever de dizer a verdade) |
| Réu como testemunha | **Inviável**: direito ao silêncio |
| Retratação por escrito após sentença | **Ineficaz** |
| Vítima em interrogatório | **Não** é sujeito ativo |
| Perito do juízo + assistente técnico | Ambos podem responder |

## Erros a evitar

- Recebimento de denúncia contra **réu** que mentiu em interrogatório: direito ao silêncio + não-autoincriminação;
- Recebimento de denúncia contra **vítima**: não é testemunha (CPP 201);
- Aplicar **§1** em ação cível entre particulares: só processo penal ou contra a Adm. Pública;
- Recusar retratação **espontânea** antes de sentença (§2): extingue punibilidade;
- Admitir retratação **após sentença**: STJ pacificou a ineficácia;
- Tipificar mentira em **conversa informal** com policial: exige sede formal (inquérito, processo);
- Confundir CP 342 com CP 343: o primeiro é de quem mente, o segundo de quem corrompe;
- Aplicar CP 339 (denunciação) quando há **só falsa narrativa** sem imputação criminosa;
- Não considerar concurso material com **obstrução de justiça** (Lei 12.850);
- Esquecer **causa de aumento §1** em processo penal (aumento 1/6-1/3).

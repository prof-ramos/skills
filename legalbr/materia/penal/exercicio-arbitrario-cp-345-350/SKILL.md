# Exercício Arbitrário das Próprias Razões e Tipos Correlatos

## CP 345: Exercício arbitrário das próprias razões

| | Conteúdo |
|---|---|
| Núcleo | Fazer **justiça pelas próprias mãos**, satisfazendo pretensão **legítima** sem recorrer à autoridade |
| Pena | **Det. 15 dias-1 mês** OU multa, **além da pena correspondente à violência** |
| **Par. único** | Ação **privada** se cometido **sem violência** |
| Sujeito ativo | Quem tem (ou crê ter) direito |
| Bem jurídico | Administração da Justiça (monopólio estatal) |
| **Elemento essencial** | Pretensão **legítima**; se ilegítima, é outro crime (extorsão, roubo) |

### Modalidades

| Cenário | Saída |
|---|---|
| Credor que invade casa do devedor e leva TV | **CP 345** (com violência); pode cumular com lesão se houver |
| Locador que muda fechadura para expulsar inquilino inadimplente | CP 345 + CP 150 (invasão domicílio) eventualmente |
| Particular que prende ladrão flagrante e o leva à delegacia | **Atípico**: flagrante autorizado (CPP 301) |
| Tomar bens em pagamento de dívida | CP 345 (autotutela vedada) |
| Reaver bem furtado em flagrante perseguição | Atípico (CPP 301) |

## CP 346: Subtração ou dano de coisa própria em poder de outrem

| | Conteúdo |
|---|---|
| Núcleo | Tirar/inutilizar/deteriorar coisa **própria** que está em **poder de terceiro** por determinação judicial OU em virtude de contrato |
| Pena | **Det. 6 meses-2 anos + multa** |
| Bem jurídico | Posse legítima de terceiro + administração da justiça |
| Sujeito ativo | **Próprio dono** |
| Exemplo | Tomar carro alienado em poder do banco; subtrair bem penhorado |

### Distinções

| Cenário | Tipo |
|---|---|
| Devedor retira veículo alienado fiduciariamente | **CP 346** + eventual DL 911/69 (fraude alienação fiduciária) |
| Possuidor tira bem penhorado em sua casa | CP 346 + desobediência |
| Vender coisa empenhada | CP 346 + estelionato (171 §2 III) |

## CP 348: Favorecimento pessoal

| | Conteúdo |
|---|---|
| Núcleo | **Auxiliar** autor de crime **a que é cominada pena de RECLUSÃO** a **subtrair-se** à ação da autoridade |
| Pena | **Det. 1-6 meses + multa** |
| **§1** | Se ao crime (antecedente) **não é cominada pena de reclusão**: det. 15 dias a 3 meses + multa |
| **§2** | Escusa absolutória: **ascendente/descendente/cônjuge/irmão** fica isento de pena |
| Bem jurídico | Administração da Justiça |

### Características

- Não inclui **co-autoria** prévia (só pós-fato);
- Não inclui **manutenção** material (esconder produto = CP 349);
- Crime **subsidiário**: cede ao concurso de pessoas se o ajuste é anterior.

## CP 349: Favorecimento real

| | Conteúdo |
|---|---|
| Núcleo | **Prestar auxílio** destinado a tornar **seguro o proveito do crime** (alimentação, abrigo, esconder bens) |
| Pena | **Det. 1-6 meses + multa** |
| Distinção com receptação (CP 180) | Receptação tem **fim de lucro** próprio; favorecimento real é apenas auxílio para garantir proveito a terceiro |

### Conduta típica

| Cenário | Tipo |
|---|---|
| Esconder objeto furtado para favorecer o ladrão | **CP 349** |
| Comprar objeto furtado sabendo origem ilícita | **CP 180** (receptação) |
| Receber bem furtado sem onerosidade, para favorecer | **CP 349** |
| Adquirir/transportar com finalidade comercial | **CP 180 §1** (qualificada) |

## CP 349-A: Ingresso de aparelho celular em estabelecimento prisional (Lei 12.012/2009)

| | Conteúdo |
|---|---|
| Núcleo | Ingressar/manter/possibilitar a entrada de **aparelho telefônico/de rádio/similar** em estabelecimento prisional |
| Pena | **Det. 3 meses-1 ano** |
| Sujeito ativo | Comum (visitantes, agentes, advogados, presos) |

## CP 350: Exercício arbitrário ou abuso de poder

| | Conteúdo |
|---|---|
| Histórico | Conduta de funcionário público que **prendia ou recolhia** alguém à prisão sem flagrante/ordem |
| Posição prevalecente | **Revogado tacitamente** pela Lei 13.869/2019 (arts. 9-12): o abuso de autoridade absorveu a conduta |
| Posição residual | Há quem sustente sobrevivência parcial em hipóteses não cobertas pela Lei 13.869, mas STJ tende à revogação tácita |
| Aplicação prática | Hoje aplica-se **Lei 13.869 art. 9** (decretar prisão fora hipóteses legais) |

## Ação penal: quadro

| Tipo | Ação |
|---|---|
| CP 345 caput (sem violência) | **Privada** |
| CP 345 caput (com violência) | **Pública incondicionada** |
| CP 346 | Pública incondicionada |
| CP 348 | Pública incondicionada |
| CP 349 | Pública incondicionada |
| CP 349-A | Pública incondicionada |
| CP 350 | (Se mantido) pública incondicionada |

## Escusas absolutórias (CP 348 §2)

| Parente | Isento? |
|---|---|
| Cônjuge | **Sim** |
| Ascendente/descendente | **Sim** |
| Irmão | **Sim** |
| União estável | Equiparado a cônjuge (jurisprudência prevalecente) |
| Tio/primo | **Não** isento: responde |

## Erros a evitar

- Recebimento de **denúncia** em CP 345 sem violência (ação **privada**);
- Confundir CP 345 (pretensão legítima) com **extorsão** (CP 158: pretensão ilegítima);
- Aplicar CP 346 a **terceiro**: sujeito ativo é o **próprio dono**;
- Confundir CP 348 (favorecimento pessoal) com CP 349 (real);
- Não aplicar **escusa absolutória** do CP 348 §2 a familiares próximos;
- Aplicar CP 350 (revogação tácita prevalece) em vez de Lei 13.869 art. 9;
- Confundir CP 349 com **receptação** (CP 180: fim de lucro);
- Recebimento de denúncia por **CP 348** quando há concurso prévio (coautoria), tipos excludentes;
- Não aplicar **CP 349-A** em apreensão de celular em presídio (tipo específico);
- Tratar **autotutela legítima** (flagrante CPP 301, desforço imediato CC 1.210) como CP 345 (atípica).

# Incitação ao Crime + Apologia

## CP 286: INCITAÇÃO ao crime

| | Conteúdo |
|---|---|
| Verbo | **INCITAR** (publicamente) |
| Núcleo | Estímulo a **CRIME DETERMINADO + FUTURO** |
| Destinatários | **NÚMERO INDETERMINADO** de pessoas |
| Pena | **Detenção 3-6 meses OU multa** |
| Natureza | **Perigo abstrato** + crime formal |
| Consumação | **Independe** de efetiva prática do crime incitado |
| Elemento normativo | **Publicidade** (presencial OU **redes sociais**, STF/STJ reiterado) |
| Bem jurídico | Paz pública + ordem |

### Requisitos cumulativos
| | Conteúdo |
|---|---|
| (i) | **Conduta dolosa** + consciência da publicidade |
| (ii) | Estímulo a **CRIME** (não contravenção; controvérsia, com corrente no STJ admitindo ampliação) |
| (iii) | Crime **determinado** (não bastam frases vagas) |
| (iv) | Crime **futuro** (não consumado) |

## CP 287: APOLOGIA de crime ou criminoso

| | Conteúdo |
|---|---|
| Verbo | **FAZER apologia** (publicamente) |
| Núcleo | Elogio/exaltação de **CRIME PRETÉRITO** OU **AUTOR** |
| Pena | **Detenção 3-6 meses OU multa** |
| Bem jurídico | Paz pública |
| Diferença essencial × CP 286 | **Apologia = pretérito** (passado) / **Incitação = futuro** |

## ADPF 187 (STF, 2011)

| | Conteúdo |
|---|---|
| Caso | Marcha da Maconha: debate público sobre descriminalização |
| Decisão | **Tipos CP 286 + 287 devem ser interpretados conforme a CF**: NÃO criminalizam **debate público** sobre descriminalização |
| Núcleo | **Liberdade de expressão** (CF 5 IV + IX) + reunião (XVI) |
| Limite | Apologia que **incite efetivamente** + perigo concreto à paz pública |

## Comparativo

| | CP 286 INCITAÇÃO | CP 287 APOLOGIA |
|---|---|---|
| Tempo do crime | **Futuro** | **Pretérito** |
| Verbo | Incitar | Fazer apologia |
| Destinatários | Indeterminado | Indeterminado |
| Tipo | Estímulo direto | Elogio/exaltação |
| Pena | 3-6m det/multa | 3-6m det/multa |
| ADPF 187 | Não criminaliza debate público | Idem |

## Distinção com tipos especiais

| Hipótese | Tipo aplicável |
|---|---|
| Incitação ao **TERRORISMO** | **Lei 13.260/2016 art. 5 III** (lex specialis) |
| Integrar/constituir **organizações criminosas ou paramilitares** | **CP 288 + 288-A** (mais graves), vide [[associacao-criminosa-cp-288]] |
| Incitação a **discriminação racial** | **Lei 7.716/89 art. 20** (racismo) |
| Incitação ao **suicídio/automutilação** | **CP 122** (induzimento) |
| Crimes contra o **Estado Democrático** | **Lei 14.197/21** (CP 359-L a 359-T: abolição + golpe) |
| Ameaça no contexto de facção | **CP 147-C** (Lei 15.358/2026, marco legal do combate ao crime organizado) |

## Lei 14.197/2021 (Estado Democrático)

| | Conteúdo |
|---|---|
| **CP 359-L** | Tentativa de abolição do Estado Democrático: recl. 4-8 |
| **CP 359-M** | Golpe de Estado: recl. 4-12 |
| Atos 8/1/2023 | Enquadramento típico: vide [[crimes-estado-democratico-lei-14197]] |
| Apologia pós-atos | CP 287 + 359-L (concurso aparente: consunção pela norma específica) |
| **Lei 15.402/2026** | Acrescentou CP 359-M-A (concurso formal próprio obrigatório entre crimes do capítulo no mesmo contexto) e CP 359-M-B (redução de 1/3 a 2/3 quando praticados em contexto de multidão, salvo liderança/financiamento) |

## Internet + redes sociais

| Tese | Conteúdo |
|---|---|
| Publicidade configurada | **REsp 1.788.687/MS** + AgRg HC 825.034: publicação aberta atende |
| Stories/grupos fechados | Caso a caso: exige **alcance público** |
| **Tema 987 STF** | Responsabilidade civil de provedores por conteúdo de terceiros (art. 19 MCI parcialmente inconstitucional); tese ajustada em ED julgados em 17/06/2026, com trânsito em julgado (responsabilidade solidária no regime do art. 21 MCI; presunção relativa de culpa em anúncios/impulsionamentos pagos); vide Marco Civil |
| Reedição/compartilhamento | Pode configurar **autoria** ou participação |

## Súmula importante

| | Conteúdo |
|---|---|
| Súm. 711 STF | A **lei penal mais grave** aplica-se ao crime **permanente/continuado** se vigente antes da cessação (relevante para apologia online prolongada) |

## Consumação + tentativa

| | Conteúdo |
|---|---|
| Consumação | **Ato de incitação/apologia** publicamente: crime FORMAL |
| Tentativa | **Admitida** por corrente minoritária (escrito pronto não publicado, interceptado antes) |
| Crime instantâneo | Salvo apologia continuada na internet (permanente) |

## Competência

| | Conteúdo |
|---|---|
| Regra | **Justiça Estadual** |
| Federal | Quando atinge **bem da União** (CF 109 IV) OU **transnacional** |
| 8 jan/2023 | **STF** (competência originária + foro por prerrogativa) |
| Conexão | Pode acompanhar crime federal conexo |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Discurso público "vamos invadir o STF" | **CP 286** + concurso CP 359-L/M |
| Postagem "Comando Vermelho é a salvação" | **CP 287** (apologia) |
| Marcha de descriminalização | **ATÍPICO** (ADPF 187) |
| Cartaz "Vamos linchar o estuprador X" | **CP 286** (incitação) |
| Stories elogiando assassino do dia | **CP 287** + análise de publicidade |
| Incitação ao terrorismo | **Lei 13.260 art. 5 III** (lex specialis) |
| Discurso racista incitando agressão | **Lei 7.716/89** (lex specialis) |
| Grupo fechado WhatsApp restrito | **Atípico** (sem publicidade) |
| Incitação a contravenção | Controvérsia (corrente no STJ admite) |
| Tentativa de publicação interceptada | **Tentativa** (posição minoritária) |

## Erros a evitar

- Criminalizar **DEBATE PÚBLICO** sobre descriminalização (ADPF 187);
- Aplicar **CP 286 a frases VAGAS** sem crime determinado;
- Confundir **incitação** (futuro) com **apologia** (pretérito);
- Aplicar CP 286/287 quando há **tipo específico** (terrorismo Lei 13.260 + racismo Lei 7.716 + golpe Lei 14.197);
- Ignorar **publicidade** como elementar (grupo fechado restrito ⇒ atípico);
- Desconsiderar **liberdade de expressão** (CF 5 IV) no juízo de tipicidade;
- **Cumular** CP 287 com o crime apologiado pelo próprio autor (consunção);
- Tratar **stories temporários** automaticamente como públicos (caso a caso);
- Aplicar lei nova mais gravosa **retroativamente** (CF 5 XL), salvo Súm. 711 (permanente/continuado);
- Confundir CP 286 com **CP 122** (induzimento ao suicídio, específico);
- Esquecer a **competência do STF** em atos contra o Estado Democrático com prerrogativa.

# Crimes contra a Administração por Particular

## CP 328: USURPAÇÃO DE FUNÇÃO PÚBLICA

| | Conteúdo |
|---|---|
| Conduta | Exercer função pública **sem investidura legítima** |
| Natureza | **FORMAL + instantâneo**: consuma com o **primeiro ato** de exercício |
| Sujeito ativo | Particular ou funcionário de órgão diverso (**extraneus**) |
| Pena (caput) | **Det. 3m-2a + multa** |
| **§1 QUALIFICADA** | **Vantagem ILÍCITA**: **recl. 2-5a + multa** |
| **STJ** | Vantagem econômica **INDIRETA basta** para a forma qualificada |

| | Conteúdo |
|---|---|
| Erro recorrente | Afastar a tipicidade por **ausência de prejuízo concreto** (crime formal: dispensa resultado) |

## CP 329: RESISTÊNCIA

| | Conteúdo |
|---|---|
| Conduta | Opor-se à execução de **ATO LEGAL** mediante **violência OU ameaça** contra funcionário competente (ou auxiliar) |
| Pena | **Det. 2m-2a** |
| **§1** | Se ato **NÃO se executa** em razão da resistência: **det. 1-3a** |
| **§2** | **Concurso MATERIAL OBRIGATÓRIO** com penas pela violência (lesão/homicídio) |
| Natureza | **FORMAL**: consuma com a oposição, ainda que o ato se execute |
| Bem jurídico | Funcionamento da Adm + integridade do agente |

| | Conteúdo |
|---|---|
| **STF/STJ** | Oposição a **ATO ILEGAL** afasta a tipicidade (não há dever de obediência a ato ilegal) |
| **STJ** | **Resistência PASSIVA** (deitar/agarrar-se, sem violência ou ameaça) é **ATÍPICA** |

## CP 332: TRÁFICO DE INFLUÊNCIA

| | Conteúdo |
|---|---|
| Conduta | **Solicitar/exigir/cobrar/obter vantagem** a pretexto de **INFLUENCIAR funcionário público** |
| Pena | **Recl. 2-5 anos + multa** |
| **§1** | Aumento de **METADE** se o agente **alega ou insinua** que a vantagem é também **destinada ao funcionário** |
| Influência | **NÃO precisa ser REAL**: basta a ALEGAÇÃO |

### CP 342: FALSO TESTEMUNHO / PERÍCIA
| | Conteúdo |
|---|---|
| Conduta | Fazer afirmação falsa + negar a verdade + calar |
| Sujeitos | **Testemunha + perito + tradutor + intérprete** (Lei 10.268/2001) |
| Pena | **Recl. 2-4 anos + multa** |
| **§1 (causa de AUMENTO)** | Penas **aumentam-se de 1/6 a 1/3** se praticado mediante suborno ou com o fim de obter prova destinada a produzir efeito em processo penal, ou em processo civil em que for parte entidade da administração pública direta ou indireta (Lei 10.268/2001) |
| **§2** | **RETRATAÇÃO antes da sentença** do processo onde ocorreu o falso: **EXTINGUE** a punibilidade |

### CP 343: CORRUPÇÃO DE TESTEMUNHA
| | Conteúdo |
|---|---|
| Conduta | **Oferecer/prometer vantagem** a testemunha/perito |
| Pena | **Recl. 3-4 anos + multa** |

### CP 344: COAÇÃO NO CURSO DO PROCESSO
| | Conteúdo |
|---|---|
| Conduta | **Violência ou GRAVE AMEAÇA** para favorecer interesse próprio em processo |
| Pena | **Recl. 1-4 anos + multa** + concurso com pena da violência |

### CP 345: EXERCÍCIO ARBITRÁRIO DAS PRÓPRIAS RAZÕES
| | Conteúdo |
|---|---|
| Conduta | **Fazer JUSTIÇA pelas PRÓPRIAS MÃOS** |
| Pena | **Det. 15d-1m OU multa** |
| AP | **PRIVADA** salvo se houver **violência** (pública incondicionada) |

## Súmulas + jurisprudência

| | Conteúdo |
|---|---|
| **STJ (jurisprudência)** | Desobediência (CP 330) exige inexistência de sanção administrativa/civil específica para o descumprimento, salvo ressalva legal de cumulação |
| Competência (resistência contra PM) | Em regra **Justiça comum estadual** (resistência é crime comum); a Justiça Militar só atrai se configurado crime militar (CPM art. 9, Lei 13.491/2017); analisar o caso concreto |
| Extraterritorialidade | Crimes contra a Adm. Pública brasileira praticados no exterior sujeitam-se à lei brasileira (CP 7º, I, "c") |
| Lei 13.964/2019 | Não alterou tipos 328-345 |

## Distinções essenciais

| | Resistência | Desacato | Desobediência |
|---|---|---|---|
| Meio | **Violência/ameaça** | Humilhação verbal | Não cumprir ordem |
| §2 concurso | Sim | Não | Não |
| Subsidiariedade | Não | Não | **Sim** (STJ) |

| | CP 342 (falso testemunho) | CP 343 (corrupção) |
|---|---|---|
| Sujeito | **Testemunha/perito** | **Quem oferece** |
| Retratação | **§2 extingue** | Não há |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Falso médico atende | **CP 328** |
| Falso médico + vantagem | **§1** (recl. 2-5a) |
| Empurra policial | **CP 329** |
| Resistência passiva | **Atípica** (STJ 2024) |
| Lesão grave + resistência | **CP 329 §1** + concurso material |
| Promete pagar testemunha | **CP 343** |
| Testemunha mente em audiência | **CP 342** |
| Retratação antes da sentença do processo onde ocorreu o falso | **EXTINGUE** (§2) |
| Vende influência a 3º | **CP 332** |
| Diz que repassará a funcionário | **§1** + metade |
| Atira a outrem para receber dívida | **CP 345** |
| Sem violência (ex. arbitrário) | **AP PRIVADA** |
| Resistência contra PM (policiamento civil) | **Justiça comum estadual**, salvo crime militar (CPM art. 9) |

## Erros a evitar

- **Aplicar DESOBEDIÊNCIA onde há sanção administrativa específica** (jurisprudência STJ);
- **Confundir RESISTÊNCIA (violência/ameaça) com DESACATO (humilhação)**;
- **Tratar USURPAÇÃO como crime de RESULTADO** (é formal);
- **Ignorar §2 do CP 329** (concurso material **OBRIGATÓRIO**);
- **Desconhecer RETRATAÇÃO** do CP 342 §2 (extingue a punibilidade se anterior à sentença do processo onde ocorreu o falso);
- Admitir **resistência PASSIVA** como crime (é atípica: exige violência ou ameaça);
- Aplicar **AP pública ao CP 345 sem violência** (é privada);
- Tratar **tráfico de influência sem ALEGAÇÃO** (basta alegação; não exige influência real);
- Atribuir automaticamente à Justiça Militar a resistência contra PM em policiamento civil (em regra é Justiça comum estadual; analisar CPM art. 9/Lei 13.491/2017);
- Não aplicar **CP 7º, I, "c"** em crimes contra a Adm. brasileira praticados no exterior.

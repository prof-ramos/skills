# Crimes Cibernéticos

- **Lei 12.737/2012** (Carolina Dieckmann);
- **Lei 14.155/2021** (penas mais severas);
- **CP 154-A** (invasão de dispositivo);
- **CP 155 §4-B** (furto eletrônico qualificado);
- **CP 171 §2-A** (fraude eletrônica);
- **Decreto 11.491/2023** (Convenção de Budapeste);
- **ECA 240-241** (pornografia infantil);
- **Marco Civil da Internet** (Lei 12.965);

## CP 154-A — invasão de dispositivo informático

### Antes (Lei 12.737 original)

| | Conteúdo |
|---|---|
| **Conduta** | Invasão de dispositivo informático **mediante violação indevida de mecanismo de segurança** |
| **Pena** | Detenção 3 meses-1 ano + multa |

### Após Lei 14.155/2021

| | Conteúdo |
|---|---|
| **Caput** | "Invadir dispositivo informático de uso alheio (...)" — sem necessidade de violar mecanismo de segurança |
| **Pena** | **Reclusão 1-4 anos** + multa |
| **§3** (qualificadora) | Obter conteúdo privado, segredo comercial, controle remoto, etc. |
| **Pena §3** | **Reclusão 2-5 anos** + multa |
| **§4** | Aumento de 1/3 a 2/3 se prejuízo econômico |
| **§5** | Aumento de 1/3 a metade se contra Presidente, governador, prefeito, etc. |

## CP 155 §4-B — furto qualificado eletrônico (Lei 14.155)

| | Conteúdo |
|---|---|
| **Conduta** | Furto **mediante fraude por meio de dispositivo eletrônico** (com ou sem violação de mecanismo de segurança) |
| **Pena** | **Reclusão 4-8 anos** + multa |
| **§4-C** | Aumento 1/3-2/3 se cometido contra idoso/vulnerável + de outras agravantes |
| **Aplicação** | Phishing + boleto fraudulento + Pix fraudulento |

## CP 171 §2-A — fraude eletrônica (Lei 14.155)

| | Conteúdo |
|---|---|
| **Conduta** | Estelionato **mediante fraude eletrônica** |
| **Pena** | **Reclusão 4-8 anos** + multa |
| **§2-B** | Aumento 1/3-2/3 — vulnerável + servidor + via servidor estrangeiro |
| **Aplicação** | Golpe do WhatsApp + clonagem + falso parente |

### Diferença furto eletrônico × estelionato eletrônico

| | Furto (155 §4-B) | Estelionato (171 §2-A) |
|---|---|---|
| **Conduta** | Subtrai sem consentimento | Vítima entrega por fraude |
| **Aplicação** | Hack + acesso direto | Engenharia social + erro |
| **Pena** | 4-8 anos | 4-8 anos |
| **Ônus** | Cibercrime puro | Mais comum em golpes |

## Erros a evitar

- Aplicar **Lei 12.737 original** sem ver Lei 14.155 (penas aumentadas);
- Esquecer **furto eletrônico qualificado** (155 §4-B) — confunde com estelionato;
- Confundir CP 154-A (**invasão**) com CP 155 §4-B (**furto eletrônico**);
- Exigir violação de **mecanismo de segurança** (Lei 14.155 removeu);
- Tratar crimes contra **vulneráveis** sem aplicar aumento;
- Esquecer **Conv. Budapeste** + cooperação;
- Não considerar **Marco Civil** + provedores;
- Esquecer **cadeia de custódia** (CPP 158-A);
- Aplicar **competência estadual** em crime transnacional (JF);
- Não notificar provedores **antes** de ações judiciais (Marco Civil + Tema 987);
- Confundir **fraude eletrônica** (171 §2-A) com **furto eletrônico** (155 §4-B);
- Esquecer **LGPD** + responsabilidade dos provedores em vazamentos.

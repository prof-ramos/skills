# Corrupção Passiva + Ativa

## CP 317: Corrupção PASSIVA

| | Conteúdo |
|---|---|
| Conduta | Funcionário público **solicitar + receber + aceitar promessa** de vantagem indevida, direta ou indiretamente, em razão da função (mesmo antes de assumi-la ou fora dela) |
| **Pena** | **Recl. 2-12 + multa** (Lei 10.763/2003) |
| **§1** | Aumento de **1/3** se retarda + omite + pratica ato infringindo dever funcional (qualificadora-exauriente) |
| **§2** | **Privilegiada**: pratica/retarda/omite ato com infração de dever, cedendo a pedido/influência de outrem; **det. 3m-1a ou multa** |

## CP 333: Corrupção ATIVA

| | Conteúdo |
|---|---|
| Conduta | **Oferecer + prometer** vantagem indevida a funcionário público para determinar prática + omissão + retardamento de ato de ofício |
| **Pena** | **Recl. 2-12 + multa** |
| **Par. único** | Aumento de **1/3** se em consequência o funcionário retarda + omite + pratica |

## CP 327: funcionário público

| | Conteúdo |
|---|---|
| Caput | Conceito amplo: inclui equiparados (paraestatais + EP + SEM + prestadoras de serviço típico) |
| **§2** | **Aumento de 1/3** para cargo em **comissão + direção + assessoramento** (chefia) |

## Crimes correlatos

| | Conteúdo |
|---|---|
| **CP 332** | Tráfico de influência: recl. 2-5 + multa |
| **CP 337-B/C/D** | Corrupção ATIVA em transação comercial **internacional** (Lei 10.467/2002, OCDE) |
| CP 350 | Exercício arbitrário das próprias razões |

## Jurisprudência consolidada

| | Conteúdo |
|---|---|
| **STF AP 470 (Mensalão)** | Paradigma: flexibilizou "ato de ofício"; corrupção ativa e passiva são **AUTÔNOMAS e INDEPENDENTES**, sem bilateralidade processual obrigatória |
| **Crime FORMAL** | Consuma-se com solicitação (passiva) OU oferta/promessa (ativa), independentemente de recebimento ou prática do ato |
| **Bilateralidade apenas fático-jurídica** | Não processual; nas modalidades "receber/aceitar" há bilateralidade lógica |
| **Súm. 599 STJ** | Insignificância **NÃO se aplica** a crimes contra Administração Pública |
| **Particular como coautor** (CP 30) | Qualidade de funcionário = **elementar** que se comunica |
| Concurso | **Material com peculato (CP 312)** + admitido com **lavagem (Lei 9.613)** |

## Atualizações 2024-2026

| | Conteúdo |
|---|---|

## Distinções críticas

| | Conteúdo |
|---|---|
| **Corrupção × Concussão (CP 316)** | Concussão **EXIGE** com abuso/temor reverencial; corrupção **SOLICITA** sem coação |
| **Corrupção × Prevaricação (CP 319)** | Prevaricação retarda/omite por **sentimento pessoal** (sem vantagem); corrupção pressupõe vantagem indevida |
| **Corrupção × Tráfico de influência (CP 332)** | Influência refere-se a particular que se apresenta como tendo influência sobre funcionário |

## Prescrição

| | Conteúdo |
|---|---|
| Pena máxima | **12 anos** |
| **PPP** | **16 anos** (CP 109 I) |

## Síntese operacional

| Hipótese | Tipo |
|---|---|
| Funcionário solicita propina | **CP 317 caput** |
| Particular oferece propina | **CP 333 caput** |
| Funcionário retarda em razão da vantagem | **CP 317 §1** (+1/3) |
| Funcionário cede a pedido | **CP 317 §2** (privilegiada) |
| Funcionário com poder de chefia | **+1/3** (CP 327 §2) |
| Corrupção em transação internacional | **CP 337-B** |
| Particular como coautor passiva | **CP 30**: responde |
| Insignificância | **VEDADA** (Súm. 599) |
| Bilateralidade processual | **Não exigida** (AP 470) |
| Crime formal | Consuma-se com solicitação/oferta |
| Concurso com peculato | **Material** |
| Concurso com lavagem | Admitido |

## Erros a evitar

- **Exigir bilateralidade rígida**: tipos autônomos (AP 470);
- **Afastar coautoria de particular** (CP 30, elementar comunica);
- **Aplicar insignificância**: vedada (Súm. 599);
- **Confundir com concussão** (concussão exige coação);
- **Exigir ato de ofício consumado** (crime formal);
- Esquecer **aumento do §1** (317) e **par. único** (333) quando há exaurimento;
- **Não aplicar CP 327 §2** em cargo de chefia (+1/3);
- **Confundir com prevaricação** quando há vantagem;
- Aplicar **Lei 14.230** automaticamente para extinguir punibilidade penal (esferas autônomas);
- Não considerar **compliance** como atenuante (Dec. 11.129/2022);
- Admitir revisão de **colaboração premiada** sem fundamentação (STF Toffoli 2024-2026).

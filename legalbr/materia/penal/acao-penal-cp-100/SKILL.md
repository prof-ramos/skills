# Ação Penal

## CP 100: espécies

| § | Conteúdo |
|---|---|
| **§1** | **PÚBLICA**: regra (MP) |
| **§2** | **PRIVADA**: quando lei expressa |
| **§3** | **PRIVADA SUBSIDIÁRIA**: inércia do MP |
| **§4** | Preserva titularidade do MP na subsidiária |

## AP PÚBLICA INCONDICIONADA

| | Conteúdo |
|---|---|
| Regra | Geral do sistema |
| Iniciativa | **EXCLUSIVA do MP** (CF 129 I) |
| Princípios | **Oficialidade + obrigatoriedade + indisponibilidade + indivisibilidade + intranscendência** |

## AP PÚBLICA CONDICIONADA

| | Conteúdo |
|---|---|
| Subordinada | **Representação do ofendido** OU **requisição do MJ** |
| **Prazo decadencial** | **6 MESES** do conhecimento da autoria (CP 103 + CPP 38) |
| **EXCEÇÃO (Lei 15.438/2026)** | Crimes praticados no âmbito de **violência doméstica e familiar contra a mulher**: prazo decadencial de **12 MESES** para queixa ou representação (CP 103 parágrafo único, Lei 11.340 art. 16-A e CPP 38 §2) |

### Hipóteses atuais
| | Conteúdo |
|---|---|
| **Ameaça** (CP 147) | Condicionada |
| **Estelionato** (CP 171) | **Condicionada** (CP 171 §5, Lei 13.964/2019) para fatos **até 03/05/2026**; **INCONDICIONADA** para fatos **a partir de 04/05/2026** (Lei 15.397/2026 revogou o §5) |
| **Perseguição** (CP 147-A) | Condicionada (CP 147-A §3), **inclusive em violência doméstica** (entendimento prevalente no STJ, sem exceção legal); em VD contra mulher, a decadência é de **12 meses** (Lei 15.438/2026) |
| **Funcionário público** em razão das funções | Concorrente (Súm. 714 STF) |
| **Injúria racial** | **PÚBLICA INCONDICIONADA** (Lei 14.532/2023: migrou para a Lei 7.716 art. 2-A) |

## AP PRIVADA

| | Conteúdo |
|---|---|
| Hipóteses | Crimes contra **honra** (CP 145 regra) + induzimento a erro essencial (CP 236 par. único) + demais previstos em lei |
| Iniciativa | **OFENDIDO** via **queixa-crime** |
| Prazo decadencial | **6 MESES** (CPP 38); **12 MESES** em crimes de VD contra a mulher (Lei 15.438/2026) |
| Princípios | **Oportunidade + disponibilidade + indivisibilidade + intranscendência** |

## AP PRIVADA SUBSIDIÁRIA DA PÚBLICA

| | Conteúdo |
|---|---|
| Base | **CF 5 LIX** + **CP 100 §3** + **CPP 29** |
| Hipótese | MP **DEIXA ESCOAR o PRAZO** sem denunciar/arquivar/requisitar diligências |
| Prazo subsidiário | **6 MESES** |
| Poderes do MP | **Manter** poderes de **aditar + repudiar queixa + oferecer denúncia substitutiva + retomar titularidade** em caso de negligência do querelante |

## Pressupostos + condições

| | Conteúdo |
|---|---|
| Materialidade | Existência do fato |
| Indícios | De autoria |
| Tipicidade | Aparente |
| Não-extinção | Da punibilidade |
| Punibilidade | Abstrata |
| Condições | Genéricas e específicas (legitimidade + interesse + possibilidade jurídica + **JUSTA CAUSA**) |

## PERSONALIDADE: sucessão (CPP 31)

| | Conteúdo |
|---|---|
| AP privada | **NÃO se transmite** automaticamente |
| Morte do ofendido | **CADI**: Cônjuge + Ascendente + Descendente + Irmão (CPP 31) |

## RENÚNCIA × PERDÃO × PEREMPÇÃO

| | Renúncia (CPP 49) | Perdão (CPP 51-59) | Perempção (CPP 60) |
|---|---|---|---|
| Momento | **ANTES da queixa** | **APÓS oferecida** | Inércia processual |
| Natureza | **Unilateral** | **Bilateral** (exige aceitação) | Inércia |
| Prazo | | | **30 dias** sem promover andamento |

## RETRATAÇÃO DA REPRESENTAÇÃO

| | Conteúdo |
|---|---|
| Geral | Até **oferecimento da denúncia** (CPP 25) |
| **Lei Maria da Penha** (art. 16) | **Apenas perante o juiz**, em **audiência específica**, **antes do recebimento** |

## Súmulas

| | Conteúdo |
|---|---|
| **Súm. 714 STF** | **Funcionário público + crime contra HONRA** → **LEGITIMIDADE CONCORRENTE** (queixa OU representação) |
| **Súm. 608 STF** | Estupro com violência real → AP pública incondicionada; com a **Lei 13.718/2018**, todos os crimes contra a dignidade sexual passaram a ser de ação pública incondicionada (CP 225) |

## Lei 13.718/2018

| | Conteúdo |
|---|---|
| Crimes contra dignidade sexual (CP 225) | **AP PÚBLICA INCONDICIONADA** |
| Súm. 608 STF | Superada na parte que exigia representação |

## Distinções essenciais

| | Pública | Privada |
|---|---|---|
| Princípio | **Obrigatoriedade** | **Oportunidade** |
| Iniciativa | MP | Ofendido |
| Indisponibilidade | Sim | NÃO (perdão + perempção) |

| | Renúncia | Perdão |
|---|---|---|
| Quando | Antes queixa | Após oferecida |
| Natureza | Unilateral | Bilateral |

## Síntese operacional

| Hipótese | AP |
|---|---|
| Homicídio | **Pública incondicionada** |
| Estelionato (fato até 03/05/2026) | **Condicionada** (CP 171 §5, Lei 13.964) |
| Estelionato (fato a partir de 04/05/2026) | **Incondicionada** (Lei 15.397/2026 revogou o §5) |
| Ameaça | Condicionada |
| Injúria racial | **Incondicionada** (Lei 14.532) |
| Calúnia/difamação | Privada (regra) |
| Funcionário público + honra | **Concorrente** (Súm. 714) |
| Crime sexual | **Incondicionada** (Lei 13.718) |
| MP omisso no prazo | **Subsidiária** (CF 5 LIX) |
| Morte do ofendido | **CADI sucede** (CPP 31) |
| Inércia processual privada | **Perempção** (30d) |
| Perdão | Bilateral (após queixa) |
| Renúncia | Unilateral (antes da queixa) |

## Erros a evitar

- Aplicar prazo decadencial errado: regra de **6 MESES**, com exceção de **12 MESES** nos crimes de VD contra a mulher (Lei 15.438/2026, irretroativa para decadências já consumadas);
- **Confundir REPRESENTAÇÃO (condicionada) com QUEIXA (privada)**;
- **Aplicar SUBSIDIÁRIA SEM inércia comprovada** do MP (arquivamento fundamentado não autoriza);
- Tratar **injúria racial como AP privada/condicionada** (Lei 14.532 mudou para incondicionada);
- Tratar a **perseguição (CP 147-A) em VD como incondicionada**: a regra legal é a representação, sem exceção expressa (entendimento prevalente no STJ);
- Aplicar **CP 171 §5 retroativamente** a denúncias oferecidas antes do Pacote Anticrime (regime da Lei 13.964);
- Tratar estelionato como **condicionado** em fato **posterior a 04/05/2026** (Lei 15.397/2026 tornou incondicionado), ou aplicar a regra incondicionada **retroativamente** a fatos anteriores (norma mais gravosa);
- **Confundir renúncia com perdão** (unilateral × bilateral);
- Admitir **retratação em Maria da Penha** fora da audiência específica (art. 16 Lei 11.340);
- Aplicar **AP pública incondicionada** a crime contra dignidade sexual com vítima vulnerável onde lei exija outra forma;
- Tratar **CPP 31 (CADI)** como rol meramente exemplificativo;
- Não respeitar **legitimidade concorrente** (Súm. 714);
- Admitir **perempção sem inércia de 30d** (CPP 60).

# Abandono de Incapaz (CP 133)

## ATUALIZAÇÃO CRÍTICA: Lei 15.163/2025 (jul/2025)

Alterou substancialmente o tratamento penal:
- **Detenção passou a RECLUSÃO**;
- **Penas elevadas**.

## CP 133, nova redação (Lei 15.163/2025)

| | Conteúdo |
|---|---|
| Caput | **Abandonar pessoa sob cuidado + guarda + vigilância + autoridade**, incapaz de defender-se dos riscos resultantes do abandono |
| **Pena** | **RECLUSÃO 2-5 anos** (antes: det. 6m-3a) |
| **§1** | **Lesão grave**: recl. **3-7** (antes 1-5) |
| **§2** | **Morte**: recl. **8-14** (antes 4-12) |
| **§3, causas de aumento (1/3)** | I) lugar ermo; II) agente ascendente/descendente/cônjuge/irmão/tutor/curador da vítima; III) vítima **maior de 60 anos** (Lei 10.741/2003) |

## Crimes correlatos

### CP 134: Exposição/abandono de RECÉM-NASCIDO

| | Conteúdo |
|---|---|
| Finalidade | **Ocultar desonra própria** |
| Pena | Det. 6m-2a (com majoração preterdolosa pelo resultado) |
| Dolo | **DIRETO apenas**; NÃO admite eventual |
| Sujeito | **Próprio** (mãe/pai) |
| Aplicação atual | Pouquíssima; interpretação restritiva |

### CP 135: Omissão de socorro

| | Conteúdo |
|---|---|
| Conduta | **Genérica**, sem vínculo prévio com a vítima |
| Pena | Det. 1m-6m OU multa (aumentada de metade se resulta lesão grave; triplicada se resulta morte) |
| Caráter | **Subsidiária ao CP 133** |

### CP 136: Maus-tratos (Lei 15.163/2025 elevou)

| | Conteúdo |
|---|---|
| Caput | **Recl. 2-5** |
| Lesão grave | Recl. **3-7** |
| Morte | Recl. **8-14** |
| Finalidade especial | **Educação + ensino + tratamento + custódia** |
| §3 | Aumento de 1/3 se vítima menor de 14 anos |

## Distinções consolidadas (STJ)

| | CP 133 | CP 135 | CP 136 |
|---|---|---|---|
| Conduta | **Comissão** (afastamento físico) | **Omissão pura** | **Excesso ativo** na correção/cuidado |
| Vínculo | **Dever de garante** (cuidado/guarda/vigilância/autoridade, alternativos) | **Sem vínculo** | Mantém relação |
| Pena pós-Lei 15.163 | Recl. 2-5 (até 14 com morte) | Det. 1m-6m | Recl. 2-5 (até 14 com morte) |

| | Conteúdo |

| | Conteúdo |
|---|---|
| Renomeou | Lei 10.741/2003 |
| Art. 98 | Abandono próprio do estatuto |
| Relação | **COEXISTE** com CP 133 §3 (vítima > 60) |

## Lei 14.811/2024

| | Conteúdo |
|---|---|
| Hediondez | Ampliou o rol de hediondos para crimes graves contra menores (ex.: sequestro de menor) |
| Distinção | **NÃO se confunde** com CP 133 |

## Síntese operacional

| Hipótese | Tipo |
|---|---|
| Pai abandona filho incapaz | **CP 133** (recl. 2-5) |
| Idoso em ILPI sem assistência | **CP 133** (STJ: vínculo de fato) |
| Filho deixa pai > 60 em lugar ermo | CP 133 + §3 (aumento 1/3) |
| Lesão grave do abandonado | **CP 133 §1** (recl. 3-7) |
| Morte do abandonado | **CP 133 §2** (recl. 8-14) |
| Mãe abandona recém-nascido por desonra | **CP 134** |
| Transeunte vê acidente e não socorre | **CP 135** |
| Cuidador excede na disciplina | **CP 136** |
| Pessoa idosa abandonada | CP 133 + Lei 10.741 art. 98 (Estatuto da Pessoa Idosa): coexistem |

## Diferença entre tipos

| | CP 133 | CP 134 | CP 135 |
|---|---|---|---|
| Vínculo | **Sim** (dever de garante) | Mãe/pai | **Não** (genérico) |
| Vítima | Incapaz sob cuidado | **Recém-nascido** | Qualquer |
| Motivação | Indiferente | **Ocultar desonra** | Indiferente |

## Erros a evitar

- Aplicar **pena antiga de detenção** pós-Lei 15.163/2025 (agora é **reclusão**);
- **Confundir 133 (vínculo) com 135 (genérico)**;
- Usar **CP 134 fora da motivação típica** (ocultar desonra);
- **Ignorar §3** quando vítima é maior de 60 anos, lugar ermo ou agente é parente/tutor/curador;
- Afirmar que o §3 abrange criança/adolescente/PCD (as hipóteses legais são só as dos incisos I a III);
- Tratar como **perigo abstrato** (é concreto, STJ);
- Recusar **vínculo de fato** como suficiente (STJ, basta);
- Aplicar CP 133 quando há **lex specialis** (ex.: tráfico de pessoas/sequestro de menor);
- **Confundir 136 (maus-tratos) com 133** (abandono): no 136 a relação se mantém;
- Aplicar pena nova **retroativamente prejudicial** (Lei 15.163 é *lex gravior*);
- Não cumular **CP 133 + Estatuto da Pessoa Idosa** quando cabível.

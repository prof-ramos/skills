# Peculato

## CP 312: núcleos típicos

### Caput: apropriação
| | Conteúdo |
|---|---|
| Conduta | Funcionário público apropriar-se de dinheiro + valor + bem móvel **público OU particular** em razão do cargo |
| **Pena** | **Recl. 2-12 + multa** |
| Pressuposto | **Posse lícita prévia** invertida em domínio |
| Objeto | Pode ser **bem particular sob custódia da Administração** (dinheiro apreendido) |

### Caput: desvio
Dar destinação diversa em proveito próprio ou alheio. Diferencia-se da apropriação porque o agente **NÃO incorpora** o bem ao patrimônio; apenas o desloca finalisticamente.

### §1: peculato-furto
Funcionário **NÃO tem a posse**: subtrai (ou concorre) valendo-se do cargo. **Equiparado em pena** ao caput.

### §2: peculato culposo
| | Conteúdo |
|---|---|
| Conduta | Concorrer **culposamente** para crime de outrem |
| **Pena** | **Det. 3m-1a** |
| Exigência | **Negligência funcional** que viabilize o crime alheio (doloso) |

### §3: reparação no culposo (apenas)
| Momento | Efeito |
|---|---|
| **Antes do trânsito** | **EXTINGUE** a punibilidade |
| **Depois do trânsito** | **Reduz a pena pela metade** |
| Aplicação | **Somente ao culposo** |

## CP 313: peculato mediante erro de outrem

Apropriar-se de valor recebido por **erro de outrem** no exercício do cargo. **Recl. 1-4 + multa**.

**Diferença** com estelionato comum: o **erro é espontâneo** do particular, não induzido.

## CP 313-A/B (Lei 9.983/2000)

| Art. | Conduta | Pena |
|---|---|---|
| **313-A** | **Inserção de dados falsos** em sistema | Recl. 2-12 + multa |
| **313-B** | **Modificação ou alteração não autorizada** | Det. 3m-2a + multa |

## CP 327: funcionário público

| | Conteúdo |
|---|---|
| **Caput** | Quem exerce **cargo + emprego + função pública**, ainda que transitoriamente e sem remuneração |
| **§1** | **Equiparados**: empregados de entidade paraestatal + EP + SEM + concessionária/permissionária + quem trabalha para empresa contratada para atividade típica da Administração |
| **§2** | **Aumento de 1/3** se cargo em comissão + função de direção + assessoramento |

### Funcionário de fato
**STF HC 70.310** (linha mantida): admite; basta o exercício fático, dispensada investidura regular.

### Particular em coautoria
**CP 30**: a condição de funcionário é **ELEMENTAR do tipo** + comunica-se ao partícipe que dela tenha conhecimento (STF/STJ pacífico).

## Insignificância

| | Conteúdo |
|---|---|
| **Súm. 599 STJ** | Princípio da insignificância **NÃO se aplica** a crimes contra a Administração Pública |
| STF | Mitiga apenas excepcionalmente (HC 107.370 + HC 112.388): valor irrisório + ausência de reprovabilidade + contexto único |
| Regra prática | Insignificância **inaplicável** em peculato (Súm. 599 STJ) |

## Concursos

| | Conteúdo |
|---|---|
| **Peculato + corrupção passiva (CP 317)** | Crimes autônomos: concurso material (STF AP 470) |
| **Peculato + lavagem (Lei 9.613)** | Admitido: peculato como infração antecedente |
| **Improbidade × peculato** | Instâncias **autônomas** (penal, civil e administrativa), sem bis in idem (CP/Lei 8.429 c/ Lei 14.230) |

## Prescrição

| Tipo | PPP |
|---|---|
| Doloso (máximo 12 anos) | **16 anos** (CP 109 II) |
| Culposo (máximo 1 ano) | **4 anos** (CP 109 V) |

## Medidas patrimoniais

Cabem **sequestro + arresto + indisponibilidade** (CPP 125+ + Lei 9.613/98 art. 4).

Apreensão de valores + bloqueio via **SISBAJUD** são rotineiros.

## Síntese operacional

| Hipótese | Tipo |
|---|---|
| Funcionário apropria-se de dinheiro sob posse | **CP 312 caput** (apropriação) |
| Funcionário desvia para fim diverso | **CP 312 caput** (desvio) |
| Funcionário subtrai sem posse | **CP 312 §1** (furto) |
| Negligência viabiliza crime alheio | **CP 312 §2** (culposo) |
| Reparação culposa antes do trânsito | **Extinção** (§3) |
| Recebimento por erro espontâneo | **CP 313** |
| Inserção de dados falsos | **CP 313-A** |
| Alteração não autorizada | **CP 313-B** |
| Funcionário de fato | **Sujeito ativo** admitido |
| Particular em coautoria | **CP 30**: responde |
| Insignificância | **VEDADA** (Súm. 599) |
| Cargo de chefia | **+1/3** (CP 327 §2) |

## Erros a evitar

- **Aplicar insignificância** (viola Súm. 599 STJ);
- **Afastar peculato de funcionário de fato** (STF admite);
- **Recusar coautoria do particular** (CP 30: elementar comunicável);
- **Confundir apropriação × desvio**: apropriação = *animus domini*; desvio = destinação finalística diversa;
- **Desclassificar para estelionato comum** quando há erro espontâneo do particular perante funcionário (é CP 313);
- Aplicar o **§3 ao doloso** (extinção/redução só no culposo);
- Reconhecer **bis in idem com improbidade** (instâncias autônomas);
- Esquecer o **§2 do art. 327** (aumento de 1/3 para chefia/assessoramento);
- Aplicar o **§1 (peculato-furto)** sem demonstrar a inexistência de posse prévia;
- Não observar a **Lei 14.230/2021** em improbidade conexa.

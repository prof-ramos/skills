# Concurso de Crimes (CP 69-71)

## CP 69: concurso MATERIAL (real)

| | Conteúdo |
|---|---|
| Estrutura | **Pluralidade de condutas + pluralidade de crimes** (idênticos ou não) |
| Penas | **SOMAM** (cúmulo material) |
| Características | Autonomia fática entre as condutas |
| STJ | Admite **cúmulo material concomitante com continuidade** quando há blocos sem nexo de continuação |

## CP 70: concurso FORMAL (ideal)

| Modalidade | Conteúdo |
|---|---|
| **Próprio/perfeito** (caput) | **Uma só conduta + pluralidade de crimes** → pena mais grave + **aumento 1/6 a 1/2** |
| Cabimento STJ | Ambos culposos OU doloso+culposo |
| **Impróprio/imperfeito** (par. único) | **Desígnios AUTÔNOMOS** → soma (cúmulo material) |
| **CP 359-M-A** (Lei 15.402/2026) | Nos crimes contra o Estado Democrático de Direito do Cap. II do Título XII, inseridos no mesmo contexto, aplica-se **obrigatoriamente o concurso formal próprio** (CP 70, 1ª parte), **ainda que haja desígnio autônomo**, vedado o cúmulo material (CP 69 e CP 70, 2ª parte); o CP 359-M-B prevê redução de 1/3 a 2/3 quando praticados em contexto de multidão, salvo liderança/financiamento |
| **STJ AREsp 2.521.343** (5ª T 2024) | Desígnios autônomos abrangem **dolo direto E dolo eventual** |
| **STJ Tema 1.192** | Roubo mediante **uma única conduta e sem desígnios autônomos** contra o patrimônio de diferentes vítimas, ainda que da mesma família, configura **concurso formal** (CP 70), não crime único |

## CP 71: crime CONTINUADO

### Requisitos objetivos (caput)
| | Conteúdo |
|---|---|
| Pluralidade de condutas | |
| Crimes da **mesma espécie** | Mesmo bem jurídico + modo similar (não exige identidade típica) |
| **Tempo** | Até **30 dias** entre condutas (parâmetro flexibilizável) |
| **Lugar** | Comarcas próximas |
| Maneira de execução | Semelhante |

### Requisito subjetivo (teoria mista)
**Unidade de desígnios/plano prévio**: distingue-se da habitualidade (jogo do bicho + rufianismo).

### Aumento (Súm. 659 STJ)
**1/6 a 2/3** conforme o número de crimes:
| Crimes | Aumento |
|---|---|
| 2 | 1/6 |
| 3 | 1/5 |
| 4 | 1/4 |
| 5 | 1/3 |
| 6 | 1/2 |
| 7+ | **2/3** |

### Continuidade ESPECÍFICA (par. único)
| | Conteúdo |
|---|---|
| Hipótese | Crimes **dolosos** + vítimas **diferentes** + **violência ou grave ameaça** |
| Aumento | **Até o TRIPLO** (não 2/3) |
| Considerações | Culpabilidade + antecedentes + personalidade + motivos + circunstâncias |

## Súmulas-chave

| | Conteúdo |
|---|---|
| **Súm. 711 STF** | Lei penal mais grave aplica-se a crime continuado/permanente se vigente antes da cessação: não é retroatividade |
| **Súm. 497 STF** | Prescrição em crime continuado pela pena imposta na sentença, **SEM** o acréscimo da continuação |
| **Súm. 723 STF** | Não cabe sursis processual em continuado se a pena mínima da infração mais grave + 1/6 supera 1 ano |
| **Súm. 17 STJ** | Falso exaurido no estelionato é absorvido (**consunção**, não concurso) |
| **Súm. 81 STJ** | Não se concede fiança quando, em **concurso material**, a soma das penas mínimas cominadas for superior a 2 anos de reclusão |
| **STJ** | Não há continuidade entre **furto** e **roubo** (espécies diversas, ainda que do mesmo gênero) |
| **Tema 1.353 STJ** | É **inviável a continuidade delitiva** entre apropriação indébita previdenciária (**CP 168-A**) e sonegação de contribuição previdenciária (**CP 337-A**): espécies diversas com condutas típicas distintas, embora do mesmo gênero |

## Jurisprudência STF/STJ

| | Conteúdo |
|---|---|
| STJ | Flexibilizar os 30 dias em casos peculiares (atentados + situação carcerária) |
| STJ | **Modus operandi diverso** afasta continuidade (furto noturno + furto diurno com arrombamento = material) |
| STJ | Dosimetria base e continuidade podem valorar mesma circunstância sob aspectos distintos sem bis in idem |
| STJ | Continuidade específica em **estupro**: aplicável apenas quando violência **real** (não em violência presumida) |

## Casos práticos

| Hipótese | Concurso |
|---|---|
| Roubo + 3 vítimas em ato único | **Formal próprio** (1/6-1/2), Tema 1.192 |
| Estupro + 3 vítimas diferentes em contexto continuativo | **Continuidade específica** (até triplo) |
| 5 furtos em 20 dias com mesmo modo | **Continuidade simples** (1/3) |
| Estelionato em 3 ações distintas + 3 vítimas | **Material** (soma) |
| Falso + estelionato (exaurido) | **Consunção** (não concurso) |

## Concurso × concurso aparente de normas

| | Conteúdo |
|---|---|
| **Concurso de crimes** | Crimes autônomos |
| **Concurso aparente** | Uma única norma incide: especialidade + subsidiariedade + consunção |

## Alterações legislativas

- **Lei 13.964/2019**: NÃO alterou o CP 69-71;
- **Lei 15.402/2026**: criou regra especial de concurso para os crimes contra o Estado Democrático de Direito (CP 359-M-A e 359-M-B, ver acima).

## Síntese operacional

| Cenário | Saída |
|---|---|
| Uma conduta + múltiplos crimes (sem desígnio autônomo) | **Formal próprio** (1/6-1/2) |
| Uma conduta + múltiplos crimes (desígnio autônomo) | **Formal impróprio** (soma) |
| Múltiplas condutas + mesma espécie + tempo/lugar/maneira semelhantes | **Continuado** (1/6-2/3) |
| Continuado + violência/grave ameaça + vítimas diferentes | **Continuidade específica** (até triplo) |
| Múltiplas condutas + crimes autônomos | **Material** (soma) |
| Modus operandi diverso | Afasta continuidade |
| Violência presumida em estupro | NÃO específica (só real) |

## Erros a evitar

- Aplicar concurso **material** quando há uma só conduta sem desígnios autônomos (deveria ser formal, Tema 1.192);
- **Não aplicar par. único do CP 71** em crimes dolosos com violência/grave ameaça contra vítimas diferentes (estupro + latrocínio plural);
- Aumentar pena **além do triplo** na continuidade específica (limite máximo absoluto);
- **Confundir continuidade** (plano prévio) com **habitualidade** (modo de vida que o tipo exige);
- Aplicar **Súm. 711 retroativamente** sem analisar gravidade comparativa;
- **Não somar penas** no concurso formal **impróprio** (desígnios autônomos → cumula);
- Ignorar a **escala objetiva** STJ para fixação do aumento (motivar com número de crimes);
- Esquecer a **Súm. 497 STF**: a prescrição NÃO computa o acréscimo da continuação;
- Reconhecer continuidade entre **roubo e latrocínio** ou tipos com bens jurídicos distintos (afasta "mesma espécie");
- Aplicar **consunção como concurso** (falso × estelionato, Súm. 17);
- Tratar **desígnio autônomo** como restrito ao dolo direto (STJ: o eventual também);
- Reconhecer **continuidade entre CP 168-A e CP 337-A** (Tema 1.353 STJ veda);
- Aplicar cúmulo material a crimes do Cap. II do Título XII no mesmo contexto (CP 359-M-A impõe o concurso formal próprio, Lei 15.402/2026).

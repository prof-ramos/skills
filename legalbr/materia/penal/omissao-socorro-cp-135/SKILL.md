# Omissão de Socorro

## Tipo (CP 135 caput)

| | Conteúdo |
|---|---|
| Núcleos | **Deixar de prestar assistência** OU **não pedir socorro** à autoridade |
| Pena | **Det. 1-6 meses** OU multa |
| Natureza | **Omissivo próprio** (não exige resultado) |
| Bem jurídico | Vida + integridade |
| Sujeitos passivos | (a) Criança **abandonada ou extraviada**; (b) pessoa **inválida ou ferida** ao desamparo; (c) pessoa em **grave e iminente perigo** |
| Possibilidade | O caput exige "quando possível fazê-lo **sem risco pessoal**"; havendo risco, o dever residual é **pedir socorro** à autoridade |

## Pena majorada (parágrafo único)

| Resultado | Aumento |
|---|---|
| **Lesão corporal grave** | **Metade** |
| **Morte** | **Triplica** |

Resultado a título de culpa; se doloso, responde pelo resultado por omissão imprópria (CP 13 §2).

## CP 135-A (Lei 12.653/2012): condicionamento de atendimento

| | Conteúdo |
|---|---|
| Núcleo | **Exigir cheque-caução + nota promissória + qualquer garantia** + preenchimento prévio de formulários administrativos como condição para atendimento médico-hospitalar **emergencial** |
| Pena | **Det. 3 meses-1 ano + multa** |
| Aumento | **Até o dobro** se resulta lesão grave; **até o triplo** se resulta morte (par. único) |

## Sujeito ativo

| | Conteúdo |
|---|---|
| CP 135 | **Qualquer pessoa** (crime comum) |
| Profissional de saúde | O tipo permanece comum |
| Garantidor (CP 13 §2): médico de plantão, salva-vidas | **Omissão imprópria**: responde pelo resultado (homicídio/lesão), não por CP 135 |

## Distinção CP 135 × omissão imprópria (CP 13 §2)

| | CP 135 (próprio) | CP 13 §2 (impróprio) |
|---|---|---|
| Posição | Qualquer pessoa | **Garantidor** (lei + assunção + ingerência) |
| Resultado | **Não exige** | **Exige** + nexo de evitabilidade |
| Pena | Tipo autônomo | Crime do resultado (homicídio/lesão) |

## Possibilidade: circunstância elementar

| Cenário | Saída |
|---|---|
| Pessoa que não sabe nadar diante de afogamento | **Pedir socorro** (dever residual do caput), sem exposição a risco |
| Médico que recusa atender em PS | **Omissão imprópria** (CP 13 §2): responde pelo resultado |
| Motorista após atropelar | **CTB 305** (fugir do local) + omissão de socorro se cabível |
| Risco real para o socorrente | Excluída a tipicidade se **chamou** socorro |

## Distinção com CTB 304 e 305

| | CP 135 | CTB 304 | CTB 305 |
|---|---|---|---|
| Núcleo | Não socorrer | Não prestar pronto socorro à **vítima de acidente em que se envolveu** | **Fugir** do local para evitar responsabilidade |
| Sujeito | Qualquer | Motorista (mesmo não-culpado) | Motorista envolvido em acidente |
| Pena | Det. 1-6m | Det. 6m-1a + suspensão CNH | Det. 6m-1a + suspensão CNH |
| **STF Tema 907** (RE 971.959, 2018) | | | CTB 305 é **constitucional** (não infirma a não incriminação, garantido o direito ao silêncio) |

## CP 135-A: interpretação

| | Conteúdo |
|---|---|
| Aplicação | **Hospitais/clínicas/profissionais**, privados ou públicos |
| Caráter emergencial | Risco iminente à vida/saúde; não alcança atendimentos eletivos |
| Forma | Exigir cheque-caução/garantia, nota promissória, preenchimento de termo, depósito |
| Sujeito ativo | Médico + diretor administrativo + atendente (todos que exigem) |
| Lei 14.454/2022 | Não altera o tipo penal; refere-se a cobertura de planos |

## Ação penal

**Pública incondicionada** (CP 135 e CP 135-A).

## Erros a evitar

- Aplicar CP 135 a **garantidor** (médico de plantão + salva-vidas): caso de **omissão imprópria** (CP 13 §2);
- Exigir resultado para o CP 135: é **omissivo próprio**, basta a conduta omissiva;
- Não aplicar a majorante do par. único quando o resultado deriva da omissão (independe de dolo quanto ao resultado);
- Confundir **CP 135 × CTB 304/305**: o trânsito tem tipos específicos;
- Reconhecer atipicidade por "risco pessoal" sem analisar a **alternativa de pedir socorro**;
- Aplicar CP 135-A a atendimento **eletivo** (cirurgia agendada): exige caráter emergencial;
- Aplicar ao CP 135-A os aumentos do CP 135 (metade/triplo): no 135-A o aumento é **até o dobro/até o triplo**;
- Não responsabilizar **diretor administrativo** que orienta cobrança de caução (coautoria/mandante);
- Aplicar **insignificância**: bem jurídico vida/integridade não admite (jurisprudência);
- Punir como mera omissão de socorro quem **criou o perigo** (ingerência): omissão imprópria, responde pelo resultado.

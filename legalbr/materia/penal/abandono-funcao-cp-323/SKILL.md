# Abandono de Função e Tipos Funcionais Próximos

## CP 323: Abandono de função

| | Conteúdo |
|---|---|
| Núcleo | **Abandonar** cargo público, fora dos casos permitidos em lei |
| Pena | **Det. 15 dias-1 mês** OU multa |
| Sujeito ativo | **Funcionário público** (próprio) |
| Bem jurídico | Administração Pública (regular prestação) |
| Crime omissivo | Próprio |

### §1: Qualificada por resultado (prejuízo público)

Resultado: prejuízo público. Pena: **det. 3 meses-1 ano + multa**.

### §2: Em lugar compreendido na faixa de fronteira

**Det. 1-3 anos**.

### Caracterização

| Elemento | Conteúdo |
|---|---|
| **Abandono** | Cessação intencional + permanente (não basta atraso, falta isolada) |
| Sem motivo justo | Casos não permitidos em lei (licença, férias, situação de emergência) |
| Dolo | Saber que abandona indevidamente |
| Reiteração | Mero atraso/faltas isoladas: falta funcional (PAD), não crime |

## CP 324: Exercício funcional ilegalmente prolongado

| | Conteúdo |
|---|---|
| Núcleo | Continuar exercendo função pública depois de saber **oficialmente** que foi exonerado/removido/substituído/suspenso |
| Pena | **Det. 15 dias-1 mês** OU multa |
| Sujeito | Funcionário público |
| Bem jurídico | Administração + regularidade dos atos |

## CP 320: Condescendência criminosa

| | Conteúdo |
|---|---|
| Núcleo | **Deixar** o funcionário, por indulgência, de responsabilizar subordinado que cometeu infração no exercício do cargo OU, quando lhe falte competência, não levar o fato ao conhecimento da autoridade superior |
| Pena | **Det. 15 dias-1 mês** OU multa |
| Sujeito ativo | Funcionário público com **poder hierárquico** |
| Elemento subjetivo | **Indulgência**, não fim de favorecimento (ressalva prevaricação) |

### CP 320 × CP 319 (Prevaricação)

| | CP 319 (prevaricação) | CP 320 (condescendência) |
|---|---|---|
| Conduta | Retardar/deixar de praticar ato | Deixar de responsabilizar subordinado |
| Fim | **Satisfazer interesse/sentimento pessoal** | **Indulgência** (sem fim pessoal) |
| Pena | Det. 3m-1a + multa | Det. 15d-1m + multa |

## CP 321: Advocacia administrativa

| | Conteúdo |
|---|---|
| Núcleo | **Patrocinar**, direta/indiretamente, interesse privado perante a Administração, valendo-se da qualidade de funcionário |
| Pena | **Det. 1-3 meses + multa** |
| §1 | Se interesse **ilegítimo**: det. 3m-1a + multa |

## CP 322: Violência arbitrária

**Revogada** pela Lei 13.869/2019 (entendimento prevalecente): incidem agora os arts. 9 a 33 da Lei 13.869.

## CP 326: Violação de sigilo de proposta de concorrência

| | Conteúdo |
|---|---|
| Núcleo | Devassar sigilo de **proposta de concorrência pública** ou facilitar devassamento |
| Pena | **Det. 3m-1a + multa** |
| **Hoje** | Para licitações, a matéria é regida pelo **CP 337-M (Lei 14.133)** |
| Vigência | Discutível para licitações novas; Lei 14.133 art. 337-M é especial |

## CP 327: Conceito de funcionário público (essencial)

| | Conteúdo |
|---|---|
| **Próprio** | Quem exerce cargo, emprego ou função pública, ainda que transitoriamente ou sem remuneração |
| **§1 equiparado** | Quem exerce cargo/emprego/função em entidade paraestatal + empregado de empresa prestadora de serviço contratada/conveniada para execução de atividade típica da Adm |
| **§2 aumento** | Aumento 1/3 quando: ocupante de cargo em comissão OU função de direção/assessoramento de órgãos da Adm. direta + autarquia + FP + empresa pública + soc. economia mista |

## Bem jurídico comum

| Tipo | Bem |
|---|---|
| CP 312-327 | **Administração Pública** (probidade, regularidade, função) |
| CP 323 | Continuidade do serviço |
| CP 324 | Eficácia dos atos administrativos |
| CP 320 | Disciplina + hierarquia |
| CP 326 | Sigilo + igualdade na concorrência |

## Ação penal

Todos: **pública incondicionada**.

## Procedimento

| Tipo | Rito |
|---|---|
| CP 323 caput, 324, 320 (det. 15d-1m) | **JECRIM**: transação penal + ANPP |
| CP 323 §1 (det. 3m-1a), 326, 321 §1 | Sumário: ANPP + sursis processual |
| CP 323 §2 (det. 1-3) | Sumário/ordinário |

## ANPP

Todos cabíveis (pena mín. < 4).

## Concurso

| Cenário | Saída |
|---|---|
| Abandono + prejuízo material | §1 (qualificada); não cumula prejuízo como dano (CP 163) |
| Condescendência + prevaricação | **Tipos excludentes**: analisar fim (interesse pessoal = 319; indulgência = 320) |
| Abandono + crime cometido por terceiro (omissão garante) | CP 13 §2 + crime do resultado se garantidor |
| Exercício prolongado + atos viciados | Atos administrativos podem ser invalidados; resta crime do CP 324 |

## Súmulas e jurisprudência

| | Conteúdo |
|---|---|
| Conceito amplo funcionário (CP 327) | STJ aplica a contratados temporários, terceirizados em função pública, prestadores |
| Lei 13.869 + abuso autoridade | Aplica-se a fato concorrente com tipos do CP 312-327 (especialidade conforme caso) |
| **STF, crimes funcionais e particulares** | Não-funcionários respondem em concurso (CP 30): a elementar do tipo se comunica |

## Erros a evitar

- Confundir **prevaricação** (319, interesse pessoal) com **condescendência** (320, indulgência);
- Aplicar CP 323 a **mera falta isolada** ou **atraso**: exige cessação intencional permanente;
- Não aplicar **§2** (faixa de fronteira): pena 1-3 anos, mudança de procedimento;
- Considerar CP 322 (violência arbitrária) ainda vigente (prevalece: revogado pela Lei 13.869);
- Aplicar CP 326 a licitação atual: **CP 337-M (Lei 14.133)** é especial;
- Tratar terceirizado como atípico (CP 327 §1, equiparado);
- Aplicar aumento **§2 do 327** sem analisar cargo em comissão/direção;
- Não usar CP 13 §2 em concurso de abandono com crime de terceiro (garante);
- Recebimento de denúncia sem identificar quebra do **dever específico** do cargo;
- Considerar PAD (sanção administrativa) como bis in idem (esferas independentes).

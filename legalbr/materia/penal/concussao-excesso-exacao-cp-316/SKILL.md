# Concussão + Excesso de Exação

## CP 316 caput: CONCUSSÃO

| | Conteúdo |
|---|---|
| Conduta | **EXIGIR** para si ou outrem, direta ou indiretamente |
| Sujeito ativo | **FUNCIONÁRIO PÚBLICO** (CP 327): abrange estatutário + comissionado + contratado + equiparados |
| Tempo | "Ainda que **FORA da função** ou **ANTES de assumi-la**, mas em razão dela" |
| Objeto | **Vantagem INDEVIDA** |
| **Pena** | **RECLUSÃO 2-12 ANOS + multa** (**Lei 13.964/2019**; antes era 2-8 anos) |
| Vigência da nova pena | Fatos pós-**24/12/2019** |

### Características
| | Conteúdo |
|---|---|
| **Natureza** | **FORMAL**: consuma com a **EXIGÊNCIA** (recebimento é mero exaurimento) |
| Sentimento | ***Metus publicae potestatis***: vítima sente-se **INTIMIDADA/CONSTRANGIDA** |
| Modalidade | Direta + indireta |

## CP 316 §1: EXCESSO DE EXAÇÃO

| | Conteúdo |
|---|---|
| Hipótese 1 | **EXIGIR TRIBUTO/contribuição** que **sabe ou deveria saber indevido** |
| Hipótese 2 | Quando devido, empregar **meio VEXATÓRIO/gravoso** não autorizado |
| Pena | **Recl. 3-8a + multa** |
| Consumação | "Tributo indevido": **recebimento**; "meio vexatório": **cobrança** |
| **STJ 6ª T.** | Erro **ESCUSÁVEL de interpretação tributária NÃO configura** o crime: exige **DOLO** |

## CP 316 §2: DESVIO DE EXAÇÃO

| | Conteúdo |
|---|---|
| Conduta | Desviar em **proveito próprio/alheio** o que recebeu **indevidamente para recolher aos cofres públicos** |
| Pena | **Recl. 2-12a + multa** (redação originária; a Lei 13.964/2019 majorou apenas o caput) |

## Crime único (exigência + recebimento)

| | Conteúdo |
|---|---|
| Tese (STJ) | Concussão é **CRIME ÚNICO**: a exigência consuma o crime (formal) e o eventual recebimento é **mero exaurimento**, sem concurso de crimes |

## Distinções CRÍTICAS

| | CP 316 (concussão) | CP 317 (corrupção passiva) |
|---|---|---|
| Verbo | **EXIGIR** (imperativo + *metus*) | **SOLICITAR / receber / aceitar** |
| Iniciativa | Funcionário coage | Funcionário negocia |
| Intimidação | **EXIGE** | NÃO exige |
| Erro recorrente | **Confundir os dois** | Idem |

| | CP 316 (concussão) | CP 158 (extorsão) |
|---|---|---|
| Sujeito | Funcionário público | Crime **COMUM** |
| Em razão da função | **SIM** | NÃO |
| Violência/grave ameaça | **NÃO necessariamente** (*metus* da função) | **EXIGE** |

| | CP 316 (concussão) | CP 319 (prevaricação) |
|---|---|---|
| Vantagem | **Patrimonial** | Sentimento/interesse pessoal |
| Pena | Recl. 2-12a | Det. 3m-1a |

| | CP 316 §1 (exação) | CP 312 (peculato) |
|---|---|---|
| Objeto | **Tributo/contribuição** | Bem público em **POSSE** do funcionário |

## Diplomas correlatos

| | Conteúdo |
|---|---|
| **Lei 12.846/2013** (Anticorrupção) | Responsabilização **OBJETIVA** da PJ beneficiada |
| **Lei 14.230/2021** (LIA) | Concussão = **ato de improbidade** (art. 9 LIA); exige **DOLO ESPECÍFICO** após a reforma; ação civil independente da penal |
| Lei 13.964/2019 | Majorou a pena do CAPUT do art. 316 (2-8 para 2-12) |

## STF: AP 937

| | Conteúdo |
|---|---|
| Tese | Foro por prerrogativa **RESTRITO** a crimes praticados **NO EXERCÍCIO + EM RAZÃO da função** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Funcionário **EXIGE** propina | **Concussão** (316) |
| Funcionário **SOLICITA** propina | **Corrupção passiva** (317) |
| Particular violenta para obter | **Extorsão** (158) |
| Funcionário exige tributo indevido | **§1 Excesso de exação** |
| Cobra com meio vexatório | **§1 Excesso de exação** |
| Erro escusável de interpretação | **ATÍPICO** (STJ) |
| Desvia tributo arrecadado indevidamente | **§2 Desvio de exação** |
| Pena aplicada a fato pré-Lei 13.964 | **2-8a** (lex mitior; só o caput: o §2 sempre foi 2-12) |
| Pena para fato pós-24/12/2019 | **2-12a** |
| Recebimento da vantagem | **Mero exaurimento** (formal) |
| Crime único (exigência + recebimento) | Sim, sem concurso (STJ) |

## Erros a evitar

- **Confundir "EXIGIR" (concussão) com "SOLICITAR" (corrupção passiva)**;
- **Aplicar pena anterior à Lei 13.964/2019** (2-8a) em fatos pós-24/12/2019;
- **Capitular conduta de funcionário público como extorsão** (CP 158);
- **Afirmar consumação somente com recebimento** (é formal: consuma com exigência);
- Imputar **excesso de exação por mero erro interpretativo** tributário (exige dolo);
- Elevação de pena pela cobiça/"lucro fácil" na 1ª fase (**já é elementar do tipo**, STJ);
- Afastar **independência da ação civil de improbidade** (Lei 14.230);
- Aplicar **foro além do exercício** + razão da função (AP 937);
- Tratar **§2 (desvio de exação) como peculato** (objetos distintos);
- Não distinguir **caput (qualquer vantagem) de §1 (tributo)**;
- Admitir **mera insistência administrativa** como exigência (exige *metus*).

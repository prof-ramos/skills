# Imputabilidade Penal

## CP 26: INIMPUTABILIDADE

| | Conteúdo |
|---|---|
| **Caput** | **Doença mental** OU **desenvolvimento mental incompleto/retardado** |
| Requisito 1 (BIOLÓGICO) | Causa = doença/desenvolvimento |
| Requisito 2 (PSICOLÓGICO) | **Ao tempo da AÇÃO**, inteiramente incapaz de **entender ilícito** OU **determinar-se** |
| Sistema | **BIOPSICOLÓGICO** (Brasil) |
| Efeito | **ISENTO de pena** + **absolvição imprópria** + MS |
| **STJ** | Juiz **NÃO detém** conhecimento técnico: **laudo pericial OBRIGATÓRIO** |

## CP 26 par. único: SEMI-IMPUTABILIDADE

| | Conteúdo |
|---|---|
| Hipótese | **Não inteiramente incapaz** |
| Capacidade | **DIMINUÍDA** |
| Efeito | **Redução de 1/3 a 2/3** |
| Substituição | Pena reduzida OU **medida de segurança** (CP 98) |

## CP 27: MENORIDADE

| | Conteúdo |
|---|---|
| Critério | **BIOLÓGICO PURO** (apenas a idade) |
| Idade | **< 18 anos** = **INIMPUTÁVEL** |
| Aplicação | **ECA (Lei 8.069/90) + SINASE (Lei 12.594/2012)** |
| Medidas | **Socioeducativas** |
| PEC redução | **Pendente**: debate constitucional sobre a natureza de **cláusula pétrea** do CF 228 (garantia individual, CF 60 §4 IV) |

## CP 28: EMOÇÃO + PAIXÃO + EMBRIAGUEZ

| | Conteúdo |
|---|---|
| **§1** | **Embriaguez VOLUNTÁRIA NÃO exclui** imputabilidade (***actio libera in causa***) |
| §1 também | Premeditada **AGRAVA** (CP 61 II "l") |
| **§2** | **FORTUITA/ACIDENTAL completa** isenta de pena |
| §2 (incompleta) | Reduz **1/3 a 2/3** |

### Alcoolismo PATOLÓGICO + dependência química

| | Conteúdo |
|---|---|
| **STF/STJ** | Dependência química e embriaguez patológica, quando comprovadas por perícia, **equiparam-se a DOENÇA MENTAL**: caem no **CP 26**, NÃO no CP 28 |
| Erro recorrente | Tratar como mera embriaguez |

## SISTEMAS de aferição

| Sistema | Conteúdo |
|---|---|
| **BIOLÓGICO puro** | Apenas causa (não adotado, exceto **CP 27, menoridade**) |
| **PSICOLÓGICO puro** | Apenas efeito (não adotado) |
| **BIOPSICOLÓGICO** | Causa + efeito: **adotado no CP 26** |

## MEDIDA DE SEGURANÇA (CP 96-99)

| | Conteúdo |
|---|---|
| Sujeitos | **Inimputável** + **semi-imputável** (CP 98) |
| Espécies | **Internação** (reclusão) OU **tratamento ambulatorial** (detenção) |
| **Prazo** | **INDETERMINADO** até cessação da periculosidade |
| **Súm. 527 STJ** | **MÁXIMO = pena ABSTRATAMENTE COMINADA** ao delito |
| **CP 75** (Lei 13.964/2019) | **Teto de 40 anos** |
| LEP 175 | Exame de **cessação da periculosidade** |

## ABSOLVIÇÃO IMPRÓPRIA

| | Conteúdo |
|---|---|
| Base | **CPP 386 VI + par. único III** (impõe MS quando cabível) |
| Conteúdo | **Absolve + aplica MS** |
| Diferença | **Própria** (sem imposição de MS) × imprópria (absolve por inimputabilidade e aplica MS) |

## INCIDENTE DE INSANIDADE MENTAL (CPP 149-154)

| | Conteúdo |
|---|---|
| Iniciativa | De ofício OU a requerimento |
| Peritos | **Oficiais** |
| Suspende processo | **Sim** (salvo diligências urgentes) |
| **STJ Inf. 675** (REsp 1.802.845-RS) | Inimputabilidade + semi-imputabilidade exigem **prévia instauração do incidente** + exame médico-legal |
| Laudo | **Imprescindível**: juiz pode divergir **fundamentadamente** |

## PSICOPATIA

| | Conteúdo |
|---|---|
| STJ | Tende a reconhecer **semi-imputabilidade** quando laudo contundente aponta transtorno de personalidade antissocial |
| Tese alternativa | **Plena imputabilidade** quando preservadas consciência da ilicitude e capacidade de autodeterminação |
| Necessário | Avaliação **biopsicossocial** + laudo + análise caso a caso (não há regra rígida) |

## Distinções essenciais

| | CP 26 caput | CP 26 par. único |
|---|---|---|
| Capacidade | **INTEIRAMENTE incapaz** | **Não inteiramente** (diminuída) |
| Efeito | **Isenta** + MS | **Redução 1/3-2/3** OU MS |

| | Embriaguez voluntária | Embriaguez fortuita completa |
|---|---|---|
| Imputabilidade | **PRESERVADA** (actio libera in causa) | **Isenta** |

| | Alcoolismo crônico | Embriaguez |
|---|---|---|
| Local | **CP 26** (doença mental) | CP 28 |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Esquizofrenia + ato | **CP 26** + MS |
| Capacidade diminuída | **CP 26 par. único**: redução |
| Menor de 18 | **ECA**: medidas socioeducativas |
| Embriaguez voluntária | **CP 28 §1**: imputabilidade preservada |
| Embriaguez fortuita completa | **CP 28 §2**: isenta |
| Embriaguez fortuita incompleta | Redução 1/3-2/3 |
| Alcoolismo patológico | **CP 26** (STF/STJ) |
| Inimputável condenado | **Absolvição imprópria** + MS |
| MS sem prazo-teto | **Súm. 527 STJ** + CP 75 (40 anos) |
| Sem laudo | **Imprescindível** (Inf. 675) |
| Psicopatia | Caso a caso (STJ) |

## Erros a evitar

- **Tratar DEPENDÊNCIA QUÍMICA como mera embriaguez** (alcoolismo/dependência patológica = CP 26, STF/STJ);
- **Aplicar MS sem prazo-teto** (Súm. 527 STJ + CP 75 = 40 anos);
- **Ignorar absolvição imprópria** (CPP 386 VI + par. único III);
- **Dispensar incidente de insanidade** (Inf. 675 STJ);
- Aplicar **CP 26 caput sem analisar SEMI-imputabilidade**;
- Confundir **biológico (CP 27) com biopsicológico (CP 26)**;
- Tratar **embriaguez voluntária como excludente** (actio libera in causa);
- Aplicar **CP 28 §2 INCOMPLETA como isenção** (é só redução);
- Tratar **psicopatia automaticamente como semi-imputabilidade** (STJ: caso a caso);
- Decretação de MS **com prazo definido superior** ao máximo cominado (Súm. 527);
- Substituir pena por MS **a imputável** (vedado).

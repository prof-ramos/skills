# Prevaricação + Condescendência + Advocacia Administrativa

## CP 319: PREVARICAÇÃO

| | Conteúdo |
|---|---|
| **Conduta tríplice** | **Retardar** + **deixar de praticar** + **praticar contra disposição expressa de lei** ato de ofício |
| Elemento subjetivo | **Dolo + INTERESSE ou SENTIMENTO PESSOAL** (dolo específico) |
| Sujeito ativo | **FUNCIONÁRIO PÚBLICO** (CP 327) |
| Pena | **Det. 3m-1a + multa** |
| Natureza | **Próprio + formal + doloso**; admite forma omissiva |
| Bem jurídico | Administração pública |

### STF/STJ: dolo específico
| | Conteúdo |
|---|---|
| **STF AP 996** + **STJ HC 199.481** | Exigem **PROVA CONCRETA do elemento subjetivo especial**; mera ilegalidade objetiva **NÃO basta** |
| **STJ RHC 168.052** (2024) | Sentimento pessoal pode ser **afetivo + religioso + político + vingança**; deve ser **DEMONSTRADO na DENÚNCIA** sob pena de **INÉPCIA** |
| **STJ, jurisprudência reiterada** | Denúncia por prevaricação **deve descrever fato concreto** revelador do interesse/sentimento pessoal (sob pena de inépcia) |

## CP 319-A: PREVARICAÇÃO IMPRÓPRIA (Lei 11.466/2007)

| | Conteúdo |
|---|---|
| Conduta | Diretor de **PENITENCIÁRIA** / agente público que **deixa de cumprir o dever de VEDAR acesso a APARELHO TELEFÔNICO**, rádio ou similar |
| Pena | Det. 3m-1a |
| Natureza | **Norma penal em BRANCO** (complementada pela LEP) |
| **STJ REsp 1.945.928** | **NÃO se aplica a estabelecimentos não-penitenciários** (delegacias/cadeias, com divergência) |

## CP 320: CONDESCENDÊNCIA CRIMINOSA

| | Conteúdo |
|---|---|
| Conduta | **Superior hierárquico** deixa de responsabilizar **SUBORDINADO** que cometeu infração no exercício |
| Móvel | **INDULGÊNCIA** (não sentimento pessoal qualificado) |
| Alternativa | Quando incompetente, **não leva** o fato à autoridade competente |
| Pena | **Det. 15d-1m OU multa** |
| Subsidiariedade | À **prevaricação** (319), quando ausente sentimento pessoal qualificado |

## CP 321: ADVOCACIA ADMINISTRATIVA

| | Conteúdo |
|---|---|
| Conduta | **PATROCINAR INTERESSE PRIVADO** perante a administração, **valendo-se da qualidade de funcionário** |
| Sujeito | Funcionário público |
| Pena (forma simples) | **Det. 1-3m OU multa** |
| **Par. único (QUALIFICADA)** | Interesse **ILEGÍTIMO** → **det. 3m-1a + multa** |
| **STF Inq 4.506** | Exige **VÍNCULO FUNCIONAL EFETIVO** + **ATO DE PATROCÍNIO CONCRETO** (não mera influência) |
| Lei 14.133/2021 (Licitações) | Figura específica de **patrocínio de contratação indevida** (CP 337-G: recl. 6m-3a + multa) |

## Distinções essenciais

| | CP 319 (prevaricação) | CP 317 (corrupção passiva) | CP 316 (concussão) |
|---|---|---|---|
| Vantagem | **NÃO** recebe | **SOLICITA/recebe** | **EXIGE** |
| Móvel | Sentimento pessoal | Vantagem | Vantagem com *metus* |
| Pena | Det. 3m-1a | Recl. 2-12a | Recl. 2-12a |

| | CP 319 | CP 320 | CP 321 |
|---|---|---|---|
| Conduta | Retardar/omitir | Não responsabilizar subordinado | Patrocinar interesse privado |
| Móvel | Sentimento pessoal | **Indulgência** | Valer-se da função |

| | CP 321 | CP 332 (tráfico de influência) |
|---|---|---|
| Qualidade | **REAL** de funcionário | **Sem qualidade** funcional |
| Conduta | Patrocínio concreto | Solicita vantagem alegando influência |

## Lei 14.197/2021

| | Conteúdo |
|---|---|
| Revogou | Crimes da **LSN** |
| Instituiu | Crimes contra o **Estado Democrático** |
| Relação com CP 319-321 | **NÃO absorve**; pode haver concurso aparente em hipóteses específicas |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Servidor retarda ato por inimizade | **CP 319** (com prova concreta) |
| Mera ilegalidade objetiva | **ATÍPICO**: não basta (exige sentimento/interesse pessoal) |
| Diretor de penitenciária permite celular | **CP 319-A** |
| Cadeia pública (não-penitenciária) | Divergente: STJ tende à atipicidade |
| Chefe não pune subordinado por indulgência | **CP 320** |
| Servidor patrocina interesse privado perante a Adm | **CP 321** |
| Patrocínio de interesse ilegítimo | **CP 321 par. único** (qualificada) |
| Mera influência sem cargo | **CP 332** (tráfico de influência) |
| Servidor recebe propina | **CP 317** (não CP 319) |

## Erros a evitar

- **Capitular prevaricação SEM descrever o sentimento/interesse pessoal** (denúncia INEPTA: AP 996 STF / RHC 168.052 STJ);
- **Confundir CP 319 com CP 317** (presença/ausência de vantagem);
- **Estender CP 319-A a celulares FORA de penitenciária** (atipicidade, STJ);
- Imputar **CP 320 quando o caso é CP 319** (indulgência ≠ sentimento pessoal qualificado);
- Aplicar **CP 321 sem ATO CONCRETO de patrocínio** (mera influência é CP 332 ou atípica);
- Tratar **mera ilegalidade objetiva** como prevaricação (vedado);
- Aplicar **dolo presumido** em prevaricação (exige prova);
- Chamar de "§1" a forma qualificada do CP 321 (é **parágrafo único**);
- Aplicar **CP 320 sem hierarquia** (exige relação superior-subordinado);
- Declarar inépcia da **denúncia por prevaricação** apenas por dificuldade probatória (o elemento subjetivo admite demonstração por indícios).

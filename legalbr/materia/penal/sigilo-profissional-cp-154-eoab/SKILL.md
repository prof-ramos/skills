# Sigilo Profissional

## Base constitucional

| | Conteúdo |
|---|---|
| **CF 5 XIV** | Acesso à informação resguardado o **sigilo da fonte** |
| **CF 5 X** | **INVIOLABILIDADE da intimidade** |
| Função | Pilar da **relação fiduciária + direito de defesa** |

## CP 154: VIOLAÇÃO DE SEGREDO PROFISSIONAL

| | Conteúdo |
|---|---|
| Conduta | **Revelar segredo** de que se tem ciência em razão de função/ministério/ofício/profissão |
| Pena | **Det. 3 meses-1 ano** OU multa |
| **AP** | **PÚBLICA CONDICIONADA à REPRESENTAÇÃO** |

## ADVOGADO: EOAB Lei 8.906/1994

### Art. 7 II: INVIOLABILIDADE
| | Conteúdo |
|---|---|
| Conteúdo | Inviolabilidade do **ESCRITÓRIO + instrumentos de trabalho + correspondência ESCRITA + ELETRÔNICA + TELEFÔNICA + TELEMÁTICA** |
| Limite | Relacionadas ao **exercício da advocacia** |

### Art. 7 XIX
| | Conteúdo |
|---|---|
| Tese | Direito de **RECUSAR-SE a DEPOR** sobre fatos do cliente |

### Art. 34 VII
| | Conteúdo |
|---|---|
| Tese | **Infração ÉTICA**: violar segredo |

## STF ADI 1.127 (2006)

| | Conteúdo |
|---|---|
| Tese | **Constitucionalidade** da inviolabilidade |
| **Busca + apreensão** | Exige presença de **REPRESENTANTE da OAB** |
| **Exceção** | **PRÓPRIO ADVOGADO INVESTIGADO** com indícios de autoria |

## STJ: colaboração premiada de advogado contra cliente

| | Conteúdo |
|---|---|
| **RHC 164.616/GO** (5ª Turma, 2022) | **NULA** a colaboração premiada firmada por advogado contra o próprio cliente com base em fatos conhecidos no mandato; ilícitas as provas derivadas (EOAB art. 34 VII) |
| **RHC 179.805/PR** (6ª Turma, 21/05/2024) | **Mesmo o advogado investigado** não pode firmar colaboração premiada com violação do sigilo profissional |
| Exceção (5ª Turma, 2024-2025) | Relação advogado-cliente **comprovadamente SIMULADA** (simulação não se presume) |

## Distinções essenciais

| | Sigilo do advogado | Sigilo médico |
|---|---|---|
| Base | EOAB 7 II | CFM 2.217/2018 |
| Levantamento | ADI 1.127 + ordem judicial | Justa causa + dever legal |
| Cliente investigado | Mitigado se advogado também investigado | |

| | Dado pessoal comum | Sensível (saúde) |
|---|---|---|
| LGPD | Art. 7 | **Art. 11** (mais restrito) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Advogado convocado a depor | **RECUSA** (EOAB 7 XIX) |
| Busca em escritório | **Representante OAB obrigatório** (ADI 1.127) |
| Advogado investigado | Mitiga sigilo (ADI 1.127) |
| Médico em casos de violência doméstica | **Notifica** (Lei 11.340 art. 13) |
| Médico em casos de crimes contra menor | **Notifica** (ECA 245) |
| Psicólogo | Código CFP 010/2005 |
| Telemedicina | Lei 14.510/2022 |
| Dados de saúde | **Sensíveis** (LGPD 5 II) |
| Colaboração premiada de advogado | **INVÁLIDA** se violar sigilo |
| Ordem judicial não fundamentada | **Vedada** |

## Erros a evitar

- **Admitir BUSCA em ESCRITÓRIO sem REPRESENTANTE da OAB** (ADI 1.127);
- **Admitir colaboração de advogado violando sigilo** (STJ, RHC 164.616 e RHC 179.805);
- Não exigir **ordem judicial fundamentada** para quebra;
- Aplicar **comunicação obrigatória ao advogado** em defesa do cliente (vedado);
- Tratar **dados de saúde** como comuns (LGPD: sensíveis);
- Aplicar **CFM 1.605** (revogada; usar 2.217/2018);
- Admitir **interceptação genérica advogado-cliente** (vedado);
- Não notificar em **violência doméstica** (Lei 11.340 art. 13 obriga);
- Não notificar em **crime contra menor** (ECA 245);
- Aplicar **CP 154 com AP pública** (é condicionada);
- Afastar **inviolabilidade ELETRÔNICA** + **telemática** ao advogado (EOAB 7 II ampliou).

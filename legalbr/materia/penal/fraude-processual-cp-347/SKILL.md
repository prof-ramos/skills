# Fraude Processual

## Tipo (CP 347)

| | Conteúdo |
|---|---|
| Núcleo | **Inovar artificiosamente** o estado de **lugar, coisa ou pessoa** |
| Fim | Induzir a **erro juiz ou perito** |
| Sede | Processo civil/administrativo OU processo penal (par. único) |
| Pena base | **Det. 3 meses-2 anos + multa** |
| **Par. único** | Pena **dobrada** se destinada a produzir efeito em **processo penal**, ainda que não iniciado |
| Crime | **Formal**: basta a inovação com finalidade |
| Bem jurídico | Administração da Justiça (verdade processual) |

## Modalidades de inovação

| Tipo | Exemplo |
|---|---|
| **Lugar** | Alterar cena de crime; mudar marco divisório de imóvel; remover sinais de acidente |
| **Coisa** | Adulterar produto sob disputa; substituir peças; falsificar marcas |
| **Pessoa** | Maquiar lesão; ocultar cicatriz; mudar aparência para reconhecimento |

## Sujeito ativo

| | Conteúdo |
|---|---|
| Regra | **Qualquer pessoa** (crime comum) |
| Partes | Sim (autor, réu) |
| Terceiros | Sim, desde que com finalidade processual |
| Funcionário público que altera prova | CP 347 + eventual abuso de autoridade (Lei 13.869) ou fraude em concurso material |
| **Adv./perito** que altera prova | Sim; pode haver concurso com CP 342/CP 304 (uso documento falso) |

## Tipo subjetivo

| | Conteúdo |
|---|---|
| Dolo | **Direto**: vontade de iludir juiz/perito |
| Especial fim | **Sim** (induzir a erro), elementar do tipo |
| Tentativa | Discutível: crime formal admite poucos casos |
| Não exige | Resultado (engano efetivo); basta a inovação com fim |

## Par. único: duplicação no processo penal

| | Conteúdo |
|---|---|
| Aplicação | Quando a inovação **destina-se** a produzir efeito em processo penal |
| **Mesmo se** processo não iniciado | Sim, desde que a inovação tenha **finalidade penal** |
| Reflexo prático | Cena de crime alterada antes da chegada da polícia já é fraude processual com pena dobrada |
| Ratio | Maior gravidade: interferência na verdade penal |

## Distinções fundamentais

| Crime | Conduta |
|---|---|
| **CP 347** | Alterar **estado material** (lugar/coisa/pessoa) para enganar juiz/perito |
| **CP 342** | Mentir **oralmente** como testemunha/perito |
| **CP 339** | Imputar falsamente crime a inocente |
| **CP 340** | Comunicar crime falso à autoridade |
| **CP 343** | Corromper testemunha/perito |
| **CP 297-299** | Falsidades documentais |
| **CP 304** | Usar documento falso |

## Concurso

| Cenário | Saída |
|---|---|
| Inovação + uso de documento falso | Concurso material (bens distintos) |
| Inovação + falso testemunho do mesmo agente | Concurso material |
| Inovação + crime principal (homicídio) | Concurso material: fraude processual é autônoma |
| Inovação em cena + ocultação de cadáver (CP 211) | Concurso material |
| Inovação no inquérito + obstrução (Lei 12.850 art. 2 §1) | Concurso ou consunção (caso a caso) |

## Cadeia de custódia (CPP 158-A a 158-F, Lei 13.964/2019)

| | Conteúdo |
|---|---|
| Relação | Quebra dolosa da cadeia de custódia pode caracterizar CP 347 + nulidade probatória |
| Agente público que adultera | CP 347 + abuso autoridade + improbidade |
| Servidor que **omite** coleta | CP 319 (prevaricação) |

## Procedimento + ação penal

| | Conteúdo |
|---|---|
| Ação | **Pública incondicionada** |
| Procedimento caput | JECRIM (pena máx. 2a): admite **transação** + ANPP |
| Par. único | Pena máx. 4a: não JECRIM; cabe ANPP (mín. 6m) |
| Competência | Local da inovação |

## Casos típicos (jurisprudência)

| Cenário | Saída |
|---|---|
| Suspeito de acidente que move veículo da via para alegar embriaguez ulterior | CP 347 par. único (efeito penal) + CTB 305 |
| Empresa que altera maquinário antes da perícia trabalhista | CP 347 caput |
| Réu que altera evidência forense (substituir sangue) | CP 347 par. único + eventualmente CP 343 |
| Litigante civil que esconde documento em ação | **Atípico**: não é inovação material; pode ser litigância de má-fé (cível) |
| Falsificar nota fiscal | CP 297-299 + uso CP 304 (não 347) |
| Vítima de violência que **maquia** lesão para parecer mais grave | CP 347 par. único |

## Erros a evitar

- Não aplicar **par. único** (pena dobrada) quando há finalidade penal, mesmo sem ação iniciada;
- Reconhecer CP 347 em **ocultação documental** civil: exige alteração de estado material;
- Confundir com **falsificação documental** (CP 297-299): fraude processual é alteração de coisa/lugar/pessoa, não de documento;
- Admitir atipicidade porque juiz/perito **não foi enganado**: crime formal, não exige resultado;
- Omitir concurso material com **falsidade ideológica** ou **uso de documento falso**;
- Aplicar somente CP 347 quando há **falso testemunho** posterior (concurso material);
- Tratar litigância de má-fé como crime: é só ilícito civil (CPC 79-81);
- Afastar responsabilidade de **terceiro** (não-parte) que adultera cena para favorecer agente;
- Aplicar **insignificância**: incompatível com o bem jurídico administração da justiça;
- Esquecer que **inovação destinada à perícia administrativa** (não judicial) também tipifica o caput.

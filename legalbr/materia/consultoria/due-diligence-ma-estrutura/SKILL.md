# Due Diligence em M&A: Estrutura

## Tipos

| | Conteúdo |
|---|---|
| **Full DD** | Análise integral de todos os workstreams |
| **Red flag DD** | Apenas riscos materiais, relatório curto |
| **Confirmatory DD** | Pós-signing, confirmação de premissas |
| **Vendor DD (VDD)** | Vendedor contrata para apresentar a interessados |
| **Reverse DD** | Comprador analisa próprio target (preparação pré-IPO/listing) |
| **Top-up DD** | Atualização entre signing e closing |

## Planejamento

- **Mandato** com escopo + materialidade + prazos + entregáveis;
- **Engagement letter** com limitação de responsabilidade + reliance;
- **Kick-off** com cliente para mapear pontos comerciais sensíveis;
- **Request list** estruturada por workstream;
- **VDR** (Intralinks, Datasite, iDeals): indexação e log de acesso;
- **Q&A process** disciplinado (no contato direto com management sem trilha);
- **Sequencing**: legal + financial + commercial + tax + operational.

## Materialidade

| | Conteúdo |
|---|---|
| **Threshold quantitativo** | Geralmente 0,1% a 1% do EV ou ticket fixo |
| **Materialidade qualitativa** | Reputacional + criminal + regulatório (sem threshold) |
| **Aggregação** | Soma de exposições correlatas |
| **Stand-alone × deal-impact** | Material para target ou para deal |

## Workstreams

### Societário
- Constituição + alterações + atas;
- Estrutura de capital + cap table + opções/RSUs;
- Acordos de acionistas/quotistas;
- Side letters + MFN clauses;
- Aprovações societárias da operação;
- Compliance com LSA + RCVM (se cia. aberta).

### Contratos materiais
- Top 20-50 contratos por valor/criticidade;
- **Change of control clauses** (gatilhos);
- **MAC clauses**;
- Exclusividades + non-compete;
- Limites de responsabilidade;
- Prazos de vencimento + renovação automática;
- Foro/arbitragem.

### Trabalhista
- Quadro de pessoal + contratos atípicos (PJ, estágio, intermitente);
- ACT/CCT vigentes;
- Reclamações (pool + valor + provisão);
- eSocial + obrigações acessórias;
- PLR + stock options + bônus;
- Compliance NR + saúde ocupacional;
- Sucessão trabalhista (CLT 10 + 448).

### Tributário
- Federal/estadual/municipal: apuração + recolhimento dos últimos 5 anos;
- **CND + CNDT + FGTS**;
- Contencioso administrativo (CARF/TIT/CMT) + judicial;
- Benefícios fiscais (Lei do Bem, Rouanet, Sudene/Sudam);
- Transfer pricing (Lei 14.596/2023);
- ICMS-ST + crédito acumulado;
- Reforma tributária (EC 132 + LC 214, regras de transição).

### Imobiliário
- Matrículas + ônus + averbações;
- Locações + alvarás + habite-se;
- Regularização ambiental;
- ITBI + IPTU;
- Áreas em litígio.

### Ambiental
- Licenças (LP + LI + LO);
- Passivos (TAC, autos de infração);
- Áreas contaminadas (CETESB/IBAMA);
- Logística reversa (Lei 12.305/10);
- ESG + relatórios de sustentabilidade.

### Regulatório
- Setoriais (ANVISA, ANATEL, ANEEL, ANP, ANS, BACEN, CVM, SUSEP);
- Autorizações + concessões + permissões;
- Multas + advertências + interdições;
- Pipeline regulatório (consultas públicas).

### Contencioso
- Civil + trabalhista + tributário + criminal + administrativo + arbitral;
- Pool por jurisdição;
- Provisão contábil vs exposição real;
- Pareceres de êxito;
- Insurance recovery.

### IP / Tecnologia
- Marcas + patentes + softwares (registro INPI);
- Domínios + redes sociais;
- Licenças de terceiros;
- Open source compliance;
- Cessão de IP de funcionários (Lei 9.279 arts. 88-91 + Lei 9.609 art. 4 para software).

### LGPD / dados
- RIPD + ROPA;
- Encarregado (DPO) nomeado;
- Política de privacidade + termos de uso;
- Incidentes reportados;
- Transferências internacionais;
- Multas ANPD.

### Compliance / Anticorrupção
- Programa de integridade (Lei 12.846 + Dec. 11.129/22);
- DD de terceiros + agentes;
- Canal de denúncias + investigações;
- Acordos de leniência + TAC;
- **FCPA / UK Bribery** (se houver nexo);
- Sanções (OFAC, EU, ONU).

## Relatório

### Long form
- Descrição factual completa;
- Análise por workstream;
- Anexos com listas e cópias.

### Executive summary
- Top 10-20 issues;
- **Deal breakers** (red flags críticos);
- **Price adjustments** sugeridos;
- **Indemnification asks** específicos;
- **Conditions precedent** sugeridas;
- **Post-closing remediation**.

## Tradução para R&W e disclosure

- Achados materiais → **R&W específica** + indemnification;
- Achados conhecidos → **disclosure schedule** (vendedor qualifica R&W);
- **Anti-sandbagging × pro-sandbagging clauses** (conhecimento do comprador prejudica ou não a indenização?);
- **Special indemnities** para riscos identificados (uncapped/uncapped por basket);
- **Escrow / earn-out** para riscos contingentes;
- **W&I insurance** (RWI): cobertura específica.

## Sequencing

1. **Pré-LOI**: red flag DD inicial;
2. **Pós-LOI / pré-signing**: full DD + R&W draft;
3. **Signing**: bring-down opinion;
4. **Pré-closing**: top-up DD + cumprimento de CPs;
5. **Closing**: closing opinions;
6. **Pós-closing**: confirmatory DD + integration.

## Erros a evitar

- DD **sem materialidade definida** (gera relatório indiscriminado);
- Pular **change of control** em contratos materiais;
- Não checar **arquivamento na junta comercial** das alterações societárias recentes;
- Confiar em **CND federal** sem checar **municipal e estadual**;
- Não avaliar **contingente trabalhista oculto** (PJ + intermitente irregular);
- Ignorar **sucessão tributária** (CTN 132-133) em asset deal mal estruturado;
- Não pedir **certidões de protesto** + **tabelionato** + **trabalhista**;
- DD **ambiental sem ASTM Phase I** em ativos industriais;
- Não mapear **side letters e MFN clauses** ativáveis pela operação;
- Confiar em **representations** sem confirmatory DD;
- Relatório **sem tradução para R&W** (cliente não consegue agir);
- Não atualizar **bring-down** entre signing e closing;
- Esquecer **regulatory consents** que travam closing;
- DD de **compliance** apenas formal (procurar fatos via canal de denúncias + auditoria);
- Não considerar **W&I insurance** quando comprador vs PE fund alinhamento dificulta indemnification.

# Estatuto da Igualdade Racial

## Lei 12.288/2010

| | Conteúdo |
|---|---|
| Função | Garantir à **POPULAÇÃO NEGRA** igualdade de oportunidades + defesa de direitos |
| **Definição art. 1 §1 IV** | **AUTODECLARADOS pretos + pardos** |
| Estrutura | **SINAPIR** (Sistema Nacional de Promoção da Igualdade Racial) |

## Direitos transversais

| | Conteúdo |
|---|---|
| **Saúde** | **Política Nacional de Saúde Integral da População Negra** |
| **Educação** | Cultura + história afro-brasileira + africana (Lei 10.639/2003) |
| **Trabalho** | + acesso a oportunidades |
| **Acesso à justiça** | |
| **Cultura** | |
| **Esporte + lazer** | |
| **Liberdade religiosa** | Proteção dos cultos afro-brasileiros |
| **Terras quilombolas** | CF 68 ADCT + Dec. 4.887/2003 |

## Sistema de COTAS: educação

| | Conteúdo |
|---|---|
| **Lei 12.711/2012** | **50% das vagas** em UFs/IFs para egressos de escola pública (com sub-cotas PPI + PCD) |
| **Lei 14.723/2023** | Reduz **renda per capita a 1 SM** + inclui **QUILOMBOLAS** + revisão decenal + cotista concorre **PRIMEIRO** à ampla concorrência |

## Cotas em CONCURSOS

| | Conteúdo |
|---|---|
| **Lei 12.990/2014** | 20% em concursos federais (vigência decenal expirada em jun/2024) |
| **Lei 15.142/2025** (03/06/2025) | Substituiu a Lei 12.990; reserva **30%**: **25% pretos/pardos + 3% indígenas + 2% quilombolas**, a partir de 2 vagas |

## Jurisprudência STF

| | Conteúdo |
|---|---|
| **ADPF 186** (2012) | **UNB CONSTITUCIONAL**: igualdade material + reparação histórica |
| **ADC 41** (2017) | **Lei 12.990/2014 CONSTITUCIONAL** + heteroidentificação com contraditório + ampla defesa |
| **ADO 26 + MI 4.733** (2019) | **HOMOTRANSFOBIA = RACISMO** social (Lei 7.716/1989) até legislação específica |

## Controle judicial da heteroidentificação: Tema 1.420 STF

|---|---|

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Política para população negra | **Lei 12.288** + SINAPIR |
| Cotas em UFs | **Lei 12.711** + 14.723 |
| Cotas em concursos | **Lei 15.142/2025 (30%)** |
| Injúria racial | **Lei 7.716 art. 2-A**: imprescritível |
| Homotransfobia | **Racismo** (ADO 26) |
| Heteroidentificação | **Com contraditório** (ADC 41) |
| Heteroidentificação arbitrária | **Controle judicial** para garantir contraditório/ampla defesa (Tema 1.420 STF) |
| Quilombolas | **Inclui no Estatuto** |
| Diversidade no currículo | **Lei 10.639** + 11.645 |

## Erros a evitar

- **Aplicar CP 140 §3** à injúria racial pós-Lei 14.532 (migrou para Lei 7.716 art. 2-A);
- **Aceitar autodeclaração SEM heteroidentificação** quando exigida;
- Aplicar **20% em concursos federais** após a Lei 15.142/2025 (é 30%);
- Negar **homotransfobia como racismo** (ADO 26, até lei específica);
- Aplicar **prescrição à injúria racial** (imprescritível pós-Lei 14.532);
- Tratar **ADO 26 como precária** (vinculante até legislação);
- Confundir **PPI com PCD** (cotas distintas);
- Afastar de plano o **controle judicial** da heteroidentificação (cabe para garantir contraditório/ampla defesa, sem reexame do mérito, Tema 1.420 STF);
- Aplicar **Lei 12.288 sem SINAPIR**;
- Não aplicar **Lei 10.639** no currículo (obrigatório);
- Aceitar **cultos afro-brasileiros como ato discriminável** (vedado, RE 494.601).

# ADO 26 + MI 4733: Criminalização da LGBTfobia

## Identificação

| | Conteúdo |
|---|---|
| Ações | **ADO 26 + MI 4733** |
| Autores | PPS (ADO) + ABGLT (MI) |
| Relatores | Min. **Celso de Mello** (ADO) + Min. **Edson Fachin** (MI) |
| Julgamento | **13/06/2019** |
| Placar | **8×3** (procedente) |
| Vencidos | Mins. Marco Aurélio, Ricardo Lewandowski, Dias Toffoli |

## Tese estruturante

| | Conteúdo |
|---|---|
| Resultado | **PROCEDENTE**: mora inconstitucional do Congresso |
| Solução | Aplicação da **Lei 7.716/1989** (Racismo) por **INTERPRETAÇÃO CONFORME** |
| Equiparação | **LGBTfobia = RACISMO SOCIAL** |
| Eficácia | **Imediata** (sem necessidade de aguardar lei) |
| Limite | Até que o Congresso edite lei específica |

## Lei 7.716/1989: Racismo

| | Conteúdo |
|---|---|
| Função | Tipificou crimes resultantes de discriminação ou preconceito |
| Pena | 1-5 anos (variando por tipo) |
| **CF 5 XLII** | **Imprescritível + inafiançável** |
| Pós-ADO 26 | Aplica-se a discriminação por **orientação sexual + identidade de gênero** |

## CF 3 IV + CF 5 caput

| | Conteúdo |
|---|---|
| **CF 3 IV** | Promover o bem de todos **sem preconceito** de origem, raça, sexo, cor, idade ou **quaisquer outras formas de discriminação** |
| **CF 5 caput** | Igualdade |
| **CF 1 III** | Dignidade |

## ADO: Ação Direta de Inconstitucionalidade por Omissão

| | Conteúdo |
|---|---|
| Base | CF 103 §2 + **Lei 12.063/2009** |
| Função | Combate à **omissão legislativa inconstitucional** |
| Efeito | Notifica órgão omisso |
| **Adm.** | 30 dias para suprir |
| **Legislativo** | Ciência (sem prazo coercitivo) |
| **ADO 26** | Inovou: aplicação de **interpretação conforme** + criminalização imediata por equiparação |

## MI: Mandado de Injunção

| | Conteúdo |
|---|---|
| Base | **CF 5 LXXI** + **Lei 13.300/2016** |
| Função | Suprir omissão para exercício de direito constitucional |
| Efeito | **Concretista** (norma para o caso) |
| Diferença com ADO | MI é via individual/coletiva; ADO é abstrata |

## Equiparação a racismo

| | Conteúdo |
|---|---|
| Racismo **social** | Tese: não biológico, social-cultural |
| **HC 82.424** (Ellwanger, 2003) | Conceito de racismo amplo (antissemitismo) |
| **ADO 26** | Expande a "raça social" para incluir orientação + identidade de gênero |
| Crítica | Tipicidade penal x analogia in malam partem |
| Resposta STF | Não é analogia: é **interpretação conforme** da expressão "raça" |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Agressão por orientação/identidade | **Crime (Lei 7.716)** + ADO 26 |
| Prescrição | **NÃO HÁ** (CF 5 XLII) |
| Fiança | **NÃO CABÍVEL** |
| Discriminação trabalhista | **Crime** (Lei 7.716) + reparação trabalhista (CLT; Lei 9.029/1995) |
| Recusa atendimento por LGBTfobia | **Crime** (Lei 7.716) |
| Injúria por LGBTfobia | **Crime** equiparado ao racismo (Lei 14.532 + ADO 26) |
| LGBTfobia online | **Crime** + responsabilização de plataformas (Tema 987 STF: incitação à discriminação integra o rol do dever de cuidado) |
| Discurso de ódio LGBTfóbico | Não protegido pela liberdade de expressão (ADO 26 + HC 82.424) |
| Homofobia institucional | Reparação + responsabilidade do Estado |
| Concurso público + discriminação | Crime (Lei 7.716 art. 3, impedir acesso a cargo público, alcançado pela ADO 26); improbidade somente se configurada hipótese típica com dolo específico (Lei 8.429 art. 11 V, red. Lei 14.230/2021: frustrar, em ofensa à imparcialidade, o caráter concorrencial de concurso público) |

## Limites

| | Conteúdo |
|---|---|
| Imunidade religiosa | Não autoriza incitação ao ódio (limite) |
| Liberdade de expressão | Não protege LGBTfobia (HC 82.424 + ADO 26) |
| Espaço sagrado | Tutela própria + limites convencionais |

## Erros a evitar

- A LGBTfobia é conduta típica após a ADO 26 (Lei 7.716 aplica-se);
- O crime de LGBTfobia é **imprescritível** e **inafiançável** (equiparação a racismo, ADO 26);
- A equiparação não é analogia in malam partem, mas interpretação conforme (ADO 26);
- A **liberdade religiosa** não ampara a discriminação;
- A ADO 26 segue vigente, não havendo norma específica que a supere;
- A LGBTfobia praticada online também é alcançada (Lei 7.716; Tema 987 STF);
- A injúria por LGBTfobia não é mero CP 140 §3 prescritível (Lei 14.532 e ADO 26 equiparam a racismo);
- O **discurso religioso** não se confunde com **incitação ao ódio** (são distintos);
- A ADO 26 vincula o Judiciário e a Administração, não apenas o Legislativo (CF 102 §2).

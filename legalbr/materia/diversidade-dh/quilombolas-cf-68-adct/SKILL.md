# Quilombolas

## CF 68 ADCT: direito fundamental

| | Conteúdo |
|---|---|
| Tese | "Aos **remanescentes das comunidades dos quilombos** que estejam ocupando suas terras é reconhecida a **PROPRIEDADE DEFINITIVA**, devendo o Estado emitir-lhes os títulos respectivos" |
| Natureza | **EFICÁCIA PLENA + APLICAÇÃO IMEDIATA** |
| Procedimento administrativo | Necessário para **titulação** (não para reconhecimento do direito) |

## Decreto 4.887/2003: procedimento

| | Conteúdo |
|---|---|
| Competência | **INCRA**: identificação + reconhecimento + delimitação + demarcação + titulação |
| Critério | **AUTOATRIBUIÇÃO** (autoidentificação): antropologicamente válido |
| Base | **Convenção 169 OIT** veda critérios heterodefinidos |

## RTID: Relatório Técnico de Identificação e Delimitação

| | Conteúdo |
|---|---|
| Componentes | **Antropológico + fundiário + agronômico + ecológico + geográfico + socioeconômico + cartorial** |
| Audiência pública | Sim |
| Contraditório | Sim |
| Sobreposição com terras particulares | **INCRA DESAPROPRIA** por interesse social |

## STF ADI 3.239 (Min. Rosa Weber: 08/02/2018)

| | Conteúdo |
|---|---|
| Decisão | **IMPROCEDENTE a ação** |
| Tese | **Dec. 4.887/2003 INTEGRALMENTE CONSTITUCIONAL** |
| Validou | **(i) AUTOATRIBUIÇÃO; (ii) competência do INCRA; (iii) desapropriação como instrumento; (iv) propriedade COLETIVA (*pro indiviso*) + INALIENÁVEL + IMPRESCRITÍVEL + IMPENHORÁVEL** |

## Caráter da titulação

| | Conteúdo |
|---|---|
| Caráter | **REPARATÓRIO** + promoção de direitos fundamentais |
| **STJ (REsp 2.000.449-MT, 1ª Turma, j. 26/11/2024, Info 837)** | Reafirmou que **NÃO se aplicam aos quilombolas os prazos de CADUCIDADE** das desapropriações comuns (DL 3.365/1941) |

## Distinção com INDÍGENAS

| | Indígenas | Quilombolas |
|---|---|---|
| Titularidade | **UNIÃO** (CF 20 XI) | **COMUNIDADE** quilombola |
| Direito | **Usufruto exclusivo** (CF 231) | **PROPRIEDADE** (CF 68 ADCT) |
| Caráter | Originário | **Reparatório** |
| Critério | Etnologia | **Autoatribuição** |

## Cotas: inclusão de quilombolas

| | Conteúdo |
|---|---|
| **Educação (Lei 14.723/2023)** | Incluiu quilombolas como beneficiários das cotas no ensino federal (Lei 12.711/2012) |
| **Concursos federais (Lei 15.142/2025)** | Reserva de **30%** das vagas: 25% pretos/pardos + **2% quilombolas** + 3% indígenas |

|---|---|---|
| Base | CF 68 ADCT | CF 231 |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Comunidade reivindica terras | **Autoatribuição + INCRA** (Dec. 4.887) |
| Sobreposição com propriedade privada | **Desapropriação por interesse social** |
| Negativa heterodefinida | **Vedada** (autoatribuição: Conv. 169 OIT) |
| Alienação de terras quilombolas | **VEDADA** (ADI 3.239, inalienável) |
| Caducidade da desapropriação | **NÃO se aplica** (STJ, REsp 2.000.449-MT, Info 837) |
| Cotas | Educação (Lei 14.723); concursos federais 30% com 2% quilombolas (Lei 15.142/2025) |
| Conhecimentos tradicionais | Lei 13.123/2015 |
| Certidão de autorreconhecimento | **Fundação Palmares** (declaratória) |

## Erros a evitar

- **Negar AUTOATRIBUIÇÃO** (Conv. 169 OIT + ADI 3.239 validam);
- **Aplicar caducidade do DL 3.365/1941** a desapropriações quilombolas (STJ, REsp 2.000.449-MT, 1ª Turma, Info 837);
- Tratar **propriedade quilombola como individual** (é COLETIVA);
- Permitir **alienação** (vedado: inalienável);
- Aplicar **prescrição** (imprescritível);
- Tratar **titulação como ato constitutivo** (é declaratório do direito originário);
- **Confundir com indígenas** (regimes distintos);
- Aplicar critério **heterodefinido** (Conv. 169 + ADI 3.239 vedam);
- Não conceder **certidão da Fundação Palmares** (ato vinculado declaratório);
- Aplicar **lei pré-Dec. 4.887** (revogada substancialmente);
- Negar a inclusão de quilombolas nas cotas (educação: Lei 14.723; concursos federais: Lei 15.142/2025, 2% das vagas).

# Estatuto da Juventude

## Lei 12.852/2013

| | Conteúdo |
|---|---|
| Função | Dispõe sobre direitos dos **JOVENS** |
| **JOVEM** | **15-29 anos** |
| Estrutura | **SINAJUVE** (Sistema Nacional de Juventude) |

## Relação com ECA

| | Conteúdo |
|---|---|
| Adolescentes (15-18) | **ECA PRIORITARIAMENTE** + Estatuto **SUBSIDIARIAMENTE** (quando não conflitar com proteção integral) |
| Jovens 18-29 | Estatuto |

## Jurisprudência STF/STJ

| | Conteúdo |
|---|---|
| **Prioridade absoluta** | Estende-se a **jovens vulneráveis** |
| **Continuidade do dever de proteção** | Entre ECA e Estatuto da Juventude |
| Controvérsias | **Idade-limite** em concursos + benefícios previdenciários, pacificadas pela proporcionalidade |
| STJ | Admite **políticas afirmativas etárias** (cotas em habitacionais) quando legítimo o discrimen |

## CONJUVE: Conselho Nacional de Juventude

| | Conteúdo |
|---|---|
| Função | **Articulação + deliberação** sobre políticas |

## Distinções essenciais

| | ECA (8.069/1990) | Estatuto Juventude (12.852/2013) |
|---|---|---|
| Faixa | **0-18** | **15-29** |
| Sobreposição | **15-18** | |
| Aplicação | **Prioritária no ECA** | Subsidiária 15-18 + integral 18-29 |

| | Adolescente (ECA) | Jovem (Estatuto) |
|---|---|---|
| Limite superior | 18 anos | **29** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Pessoa 15-18a | **ECA prioritário** + Juventude subsidiária |
| Pessoa 18-29a | **Estatuto da Juventude** |
| Meia-entrada | **ID Jovem** + baixa renda |
| Participação política | **CONJUVE** |
| Acesso à educação EJA | **Direito** |
| Cotas etárias em programa | **Admitidas** quando legítimas (STJ) |
| Sucessão rural | **Lei 15.178/2025** |
| Gravidez adolescente | Lei 13.798/2019 |
| > 29 anos | NÃO se aplica Estatuto |
| ProJovem | Lei 11.692 |

## Erros a evitar

- **Aplicar Estatuto da Juventude PRIORITARIAMENTE a 15-18a** (ECA prevalece);
- Negar **meia-entrada** a jovem baixa renda (ID Jovem);
- Aplicar **idade-limite arbitrária** em concursos (proporcionalidade);
- Confundir **ECA com Estatuto** (faixas distintas);
- Aplicar a **> 29 anos**;
- Não respeitar **CONJUVE** como instância de participação;
- Ignorar **Lei 15.178/2025** + sucessão rural;
- Negar **continuidade da proteção** entre ECA e Juventude;
- Aplicar **políticas etárias sem discrimen legítimo** (STJ exige);
- Permitir **discriminação por idade** ao jovem em emprego (combate);
- Não aplicar **Lei 13.798** na escola sobre gravidez adolescente.

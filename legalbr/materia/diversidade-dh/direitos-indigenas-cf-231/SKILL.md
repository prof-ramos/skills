# Direitos Indígenas

## CF 231: direitos territoriais

| | Conteúdo |
|---|---|
| Caput | Reconhece **organização social + costumes + línguas + crenças + tradições** + **DIREITOS ORIGINÁRIOS** sobre terras tradicionalmente ocupadas |
| União | **Demarcar + proteger** |

## CF 231 §§

| § | Conteúdo |
|---|---|
| **§1** | **Terras TRADICIONALMENTE OCUPADAS**: habitadas em **caráter permanente** + utilizadas para atividades produtivas + imprescindíveis à preservação ambiental + necessárias à reprodução física e cultural |
| **§2** | **POSSE PERMANENTE + USUFRUTO EXCLUSIVO** das riquezas do solo + rios + lagos |
| **§3** | **Recursos HÍDRICOS energéticos + lavra MINERAL** → **autorização do CONGRESSO NACIONAL** + ouvidas comunidades + participação nos resultados |
| **§4** | **INALIENABILIDADE + INDISPONIBILIDADE + IMPRESCRITIBILIDADE** (tripla blindagem) |
| **§5** | **VEDADA REMOÇÃO** salvo **ad referendum do CN** (catástrofe/epidemia ou soberania) |
| **§6** | **NULOS** os atos sobre terras indígenas (ressalvada **indenização ao ocupante de BOA-FÉ**) |
| **ADCT 67** | Demarcação das terras indígenas (prazo originário de 5 anos da promulgação) |

## CF 232: legitimidade processual

| | Conteúdo |
|---|---|
| Legitimados | **Índios + suas comunidades + organizações** |
| **MP** | Atua em **TODOS os atos** |
| Competência | **CF 109 XI: Justiça FEDERAL** |

## STF Tema 1.031 (RE 1.017.365/SC: set/2023)

| | Conteúdo |
|---|---|
| Tese | **INCONSTITUCIONAL a tese do marco temporal** |
| Fundamento | Direitos territoriais indígenas são **originários**, independentes de ocupação na data da promulgação (05/10/1988) |
| Tese de repercussão geral | Fixada com diretrizes sobre demarcação, indenização de boa-fé e regularização |

## Lei 14.701/2023: reação legislativa

| | Conteúdo |
|---|---|
| Conteúdo | **Ressuscitou o marco temporal** |
| Vigência | 2023 |

## STF ADC 87 + ADIs 7.582/7.583/7.586 (Rel. Min. Gilmar Mendes)

| | Conteúdo |
|---|---|
| Julgamento | Concluído em **19/12/2025** (Plenário virtual); acórdão publicado em **18/03/2026** |
| Resultado | **Parcialmente procedentes** as ações |
| Reafirmação | **Inconstitucionais** o marco temporal e a exigência de renitente esbulho, tal como positivados na Lei 14.701/2023 |
| Demais dispositivos | A Corte **não declarou a integralidade da lei inconstitucional**; subsistem outros dispositivos não atingidos pela decisão |
| Observação | Decisão ainda **sujeita a recursos** na data de referência |

## Convenção 169 OIT (Dec. 5.051/2004 + Dec. 10.088/2019)

| | Conteúdo |
|---|---|
| Status | **SUPRALEGAL** |
| **CPLI** | **Consulta PRÉVIA + LIVRE + INFORMADA** aos povos afetados por medidas legislativas/administrativas |
| Aplicação | Obrigatória em demarcação + obras + projetos |

## Estatuto do Índio (Lei 6.001/1973)

| | Conteúdo |
|---|---|
| Status | **Formalmente vigente** |
| Substancialmente | **DESATUALIZADO** pela CF/88 + Convenção 169 |

## FUNAI

| | Conteúdo |
|---|---|
| Função | Executar política indigenista federal |
| Base | Dec. 1.775/1996 (rito demarcatório) |

## Princípios estruturais

| | Conteúdo |
|---|---|
| **Indigenato** | Direito **ORIGINÁRIO** sobre as terras (anterior ao Estado) |
| **Diversidade** | CF 215-216 |
| **Autodeterminação** | Convenção 169 OIT |
| **CPLI** | Consulta prévia + livre + informada |

## Rito demarcatório (Dec. 1.775/1996)

| Fase | Conteúdo |
|---|---|
| 1 | Estudo antropológico + ambiental |
| 2 | RCID: relatório circunstanciado |
| 3 | Manifestação dos interessados |
| 4 | Aprovação pela FUNAI |
| 5 | **Declaração** pelo MJSP (Portaria Declaratória) |
| 6 | Demarcação física |
| 7 | **HOMOLOGAÇÃO** pelo PR (decreto) |
| 8 | **Registro** no SPU + cartórios |

## Lei 14.701/2023: pontos declarados inconstitucionais (ADC 87 / ADIs)

| | Conteúdo |
|---|---|
| Marco temporal | **Inconstitucional** |
| Renitente esbulho (como requisito) | **Inconstitucional** |
| Demais dispositivos | Não integralmente invalidados; subsistem os não atingidos pela decisão |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Demarcação | **CF 231** + ADCT 67 + Dec. 1.775/1996 |
| Marco temporal invocado | **INCONSTITUCIONAL** (Tema 1.031) |
| Ocupação imemorial sem prova até 1988 | Demarcação **CABÍVEL** (direitos originários independem da data) |
| Comunidade expulsa antes de 1988 + retorno | Demarcação **CABÍVEL** (imemorialidade) |
| Ocupante de boa-fé em terra indígena | **Indenização** (CF 231 §6, ressalva) |
| Obra em terra indígena | **CPLI** + autorização CN se hídrica/mineral |
| Ato sobre terra indígena | **NULO** (§6) |
| Remoção | **VEDADA** salvo CN (§5) |
| Disputa sobre direitos indígenas (coletivos/territoriais) | **JF** (CF 109 XI) |
| Crime em que o indígena figura como autor ou vítima, sem disputa de direitos coletivos | **Justiça ESTADUAL** (Súm. 140 STJ) |
| Lei 14.701, marco temporal e renitente esbulho | **Inconstitucionais** (ADC 87 / ADIs, julg. 19/12/2025) |
| Litigância indígena | **Comunidades + MP + organizações** |
| Posse permanente | **Usufruto exclusivo** |
| Recursos hídricos | **Autorização CN** |

## Erros a evitar

- **Aplicar o marco temporal** (Tema 1.031, inconstitucional; reafirmado na ADC 87 / ADIs, julg. 19/12/2025);
- Aplicar o **marco temporal ou o renitente esbulho** com base na Lei 14.701/2023 (declarados inconstitucionais);
- **Ignorar CPLI** da Convenção 169 OIT (supralegal);
- Levar à Justiça Federal crime com indígena como autor ou vítima sem disputa sobre direitos coletivos (Súm. 140 STJ: "Compete à Justiça Comum Estadual processar e julgar crime em que o indígena figure como autor ou vítima"); a JF (CF 109 XI) só quando houver disputa sobre direitos indígenas;
- **Tratar Estatuto do Índio como vigente plenamente** (substancialmente desatualizado);
- Permitir **mineração sem autorização do CN** (CF 231 §3);
- Aceitar **alienação de terras indígenas** (§4, inalienável);
- Aplicar **prescrição** a terras indígenas (§4, imprescritível);
- Negar **legitimidade processual** às comunidades (CF 232);
- Ignorar **MP** em atos relativos a indígenas (CF 232);
- Aplicar **remoção** sem ad referendum CN (§5).

# Cotas Raciais

## Lei 12.711/2012: UNIVERSIDADES + IFs

| | Conteúdo |
|---|---|
| Aplicação | **Universidades federais + Institutos Federais** (técnico/médio) |
| Reserva inicial | **50% das vagas** para egressos de **escola pública** |
| Subdivisão | **50% desse contingente** para renda familiar per capita ≤ 1,5 SM |
| **PPI** | Percentual proporcional ao perfil étnico-racial estadual (IBGE), **pretos + pardos + indígenas** |

## Lei 13.409/2016

| | Conteúdo |
|---|---|
| Inclusão | **PCD** (PCD/2%-10% conforme perfil) |

## Lei 14.723/2023: REFORMA ESTRUTURAL

| | Conteúdo |
|---|---|
| Política | **PERMANENTE** (com revisão decenal: próxima em **2033**) |
| Incluiu | **QUILOMBOLAS** |
| Concorrência | Cotistas concorrem **PRIORITARIAMENTE à AMPLA CONCORRÊNCIA** |
| Ocupam vaga reservada | **APENAS se não classificados** na ampla |
| Corte de renda | **REDUZIDO para 1 SM per capita** |
| Aferição | **Autodeclaração** (Lei 12.711, art. 3º, redação da Lei 14.723); heteroidentificação complementar admitida conforme ADC 41 e regulamentação de cada instituição |

## Concursos federais: Lei 12.990/2014 → Lei 15.142/2025

### Lei 12.990/2014 (regime original)

| | Conteúdo |
|---|---|
| Reserva | **20% das vagas** em concursos federais |
| Alcance | Adm Direta + autarquias + fundações + EP + SEM da União |
| Autodeclarados | **Pretos OU pardos** |
| Vigência inicial | Decenal: **expirou em jun/2024** |
| **STF: ADI 7.654 MC-Ref (Min. Flávio Dino; cautelar mai/2024, referendada pelo Plenário em jun/2024)** | **Prorrogou** a vigência até deliberação legislativa |

### Lei 15.142/2025 (regime atual)

| | Conteúdo |
|---|---|
| **Sanção** | **Lei 15.142, de 03/06/2025** (publicada 04/06/2025), substituiu a Lei 12.990/2014 |
| Reserva total | **30% das vagas** |
| Distribuição | **25% pretos/pardos + 3% indígenas + 2% quilombolas** |
| Alcance | Adm Direta + autarquias + fundações + EP + SEM da União + processos seletivos simplificados |
| Aplicação mínima | Edital com **2 ou mais vagas** |
| Aferição | **Autodeclaração + comissão de heteroidentificação** (negros); indígenas/quilombolas comprovam vínculo com a comunidade |
| Fases | Reserva incide em **todas** as fases do certame |
| Vagas surgidas na validade | A cota **atinge** as vagas que surgirem durante a validade |
| Vedação | **Fracionamento** por especialização para burlar a reserva |
| Fraude na autodeclaração | **Exclusão + responsabilização** |

## Arredondamento

| | Conteúdo |
|---|---|
| Fração **≥ 0,5** | Arredonda **PARA CIMA** |
| Fração **< 0,5** | Arredonda para baixo |
| Mínimo de vagas | Lei 12.990/2014: **3 ou mais**; Lei 15.142/2025: **2 ou mais** |

## Jurisprudência STF

| | Conteúdo |
|---|---|
| **ADPF 186/2012** (Min. Lewandowski) | **UNB CONSTITUCIONAL**: igualdade material + reparação histórica |
| **ADC 41/DF** (Min. Roberto Barroso, **08/06/2017, UNÂNIME**) | **Lei 12.990/2014 CONSTITUCIONAL** (reserva 20% em concursos federais) + autodeclaração + critérios subsidiários de **heteroidentificação** com **dignidade da pessoa humana + contraditório/ampla defesa** |
| **RE 597.285, Tema 203** | Sistema de cotas em UFs **constitucional** |
| **ARE 1.553.243, Tema 1.420 STF** | O Judiciário **pode controlar** o ato da comissão de heteroidentificação para assegurar contraditório e ampla defesa, **não lhe cabendo reexaminar o mérito** (fenótipo) quando exigiria reanálise de fatos e provas |

## STJ: jurisprudência

| | Conteúdo |
|---|---|
| Heteroidentificação | É **legítima**, em conjunto com a autodeclaração, observados dignidade, contraditório e ampla defesa (alinhada à ADC 41) |
| Aferição por fenótipo | Pode levar à **exclusão da reserva** quando não confirmada a autodeclaração, respeitado o devido processo; o indeferimento, em regra, **não exclui da ampla concorrência** salvo indício de fraude/má-fé |

## Estrutura comparativa

| | Lei 12.711 (educação) | Concursos federais |
|---|---|---|
| Diploma | Lei 12.711/2012 + 14.723/2023 | Lei 12.990/2014 → **Lei 15.142/2025** |
| Reserva | 50% escola pública + PPI proporcional | **30%** (25% pretos/pardos + 3% indígenas + 2% quilombolas) |
| Critério | Socioeconômico + racial | **Étnico-racial** (negros, indígenas, quilombolas) |
| PCD | Lei 13.409 incluiu | Reserva própria de PCD (Lei 8.112/90 art. 5 §2) |

## Antes e depois Lei 14.723/2023

| | Antes | Pós-Lei 14.723 |
|---|---|---|
| Corte de renda | 1,5 SM | **1 SM** |
| Permanência | Decenal | **Permanente** |
| Quilombolas | Não incluídos | **Incluídos** |
| Concorrência | Em paralelo | **PRIMEIRO ampla** |

## Critério de heteroidentificação

| | Conteúdo |
|---|---|
| **Autodeclaração** | Primeira etapa |
| **Banca de aferição COLEGIADA** | Critérios fenotípicos (ADC 41) |
| Avaliação | **FENOTÍPICA** |
| Contraditório | + ampla defesa + dignidade (ADC 41) |
| Decisão por **APENAS UM MEMBRO** | **INVÁLIDA** (regra é colegiada) |
| Vinculação | Não basta autodeclaração formal |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Vaga em UF | **50% pública + PPI proporcional** (Lei 12.711 + 14.723) |
| Concurso federal | **30%** (25% pretos/pardos + 3% indígenas + 2% quilombolas), **Lei 15.142/2025** |
| Renda > 1 SM (educação) | NÃO entra cota socioeconômica (sub-cota de renda) |
| Quilombola | **Incluído** (educação: Lei 14.723; concursos: Lei 15.142) |
| Autodeclaração contestada | **Heteroidentificação** com contraditório |
| Cotista classificado na ampla | **Não ocupa vaga reservada** (Lei 14.723, na educação) |
| Heteroidentificação arbitrária | **Controle judicial** para garantir contraditório/ampla defesa (Tema 1.420 STF) |
| ADPF 186 | Mantida + ADC 41 reforça |
| Cota PCD | **Lei 13.409** (educação) + Lei 8.112/90 art. 5 §2 (concursos) |
| Concurso federal < mínimo legal | Cota **NÃO** se aplica (Lei 12.990: < 3 vagas; Lei 15.142: < 2 vagas) |
| Fração de vaga ≥ 0,5 | Arredonda **para cima** |
| Reserva e fases do certame | Incide em **todas** as fases + vagas surgidas na validade |
| Aferição por único membro | **Inválida** (banca colegiada: ADC 41) |

## Erros a evitar

- Aceitar autodeclaração sem o procedimento de confirmação complementar quando exigido (concursos federais: Lei 15.142/2025, art. 3º; educação: edital/regulamento institucional, admitido pela ADC 41);
- **Aplicar corte de renda de 1,5 SM** após a Lei 14.723 na educação (é **1 SM** na sub-cota de renda);
- Tratar a Lei 12.711 como **temporária** (Lei 14.723 a tornou permanente, com revisão decenal);
- **Negar quilombolas** como beneficiários (educação: Lei 14.723; concursos: Lei 15.142);
- Aplicar a **Lei 12.990 como se ainda vigente** após a Lei 15.142/2025 (a nova lei a substituiu, ampliando a reserva para 30%);
- Aplicar **20% em concursos federais** após a Lei 15.142/2025 (é **30%**: 25% pretos/pardos + 3% indígenas + 2% quilombolas);
- Permitir **cotista em vaga reservada quando classificado na ampla** (regra de concorrência na educação, Lei 14.723);
- **Confundir Lei 12.711 (educação) com a lei de concursos** (Lei 12.990 → Lei 15.142);
- Não assegurar **contraditório e ampla defesa** na heteroidentificação (ADC 41; Tema 1.420 STF);
- Afastar de plano o **controle judicial** da banca de heteroidentificação (cabe para garantir contraditório/ampla defesa, sem reexame do mérito, Tema 1.420 STF);
- Ignorar **ADPF 186** como leading case;
- Tratar **cotas como discriminação reversa** (STF afasta, igualdade material, ADPF 186 e ADC 41);
- Aplicar **arredondamento para baixo** quando a fração for ≥ 0,5;
- Aplicar a cota abaixo do **mínimo legal de vagas** (Lei 12.990: < 3; Lei 15.142: < 2);
- Restringir a reserva ao **edital inicial** (atinge vagas surgidas na validade);
- Excluir cotista por aferição com **apenas um membro** (banca colegiada, ADC 41);
- Aceitar **fracionamento por especialização** para burlar a reserva.

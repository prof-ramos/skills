# Estatuto da Pessoa Idosa

## Marco normativo

| | Conteúdo |
|---|---|
| **Lei 10.741/2003** | Estatuto original |
| **Lei 13.466/2017** | **Prioridade especial reforçada ≥ 80 anos** (art. 71 §5) |
| **Lei 14.423/2022** | **Renomeou "Estatuto da Pessoa Idosa"** + uniformizou terminologia |
| **Lei 8.842/1994** | Política Nacional do Idoso |
| **CF 229 + 230** | Dever da família/sociedade/Estado |
| Conteúdo material | Sem alteração pela Lei 14.423 |

## Conceito + base constitucional

| | Conteúdo |
|---|---|
| **Pessoa idosa** | **≥ 60 ANOS** (art. 1) |
| Regime | **PROTEÇÃO INTEGRAL** + **PRIORIDADE ABSOLUTA** |
| **CF 230** | Família/Estado/sociedade: proteção |

## Direitos fundamentais

| Art. | Direito |
|---|---|
| **8** | Vida |
| **15** | Saúde: **PRIORIDADE no SUS** |
| **11** | Alimentos |
| 20 | Cultura + lazer + esporte |
| 26 | Profissionalização |
| 24 | Educação |
| 37 | Habitação |
| **38** | **RESERVA 5% vagas** em estacionamentos + 3% em condomínios |
| **39** | **TRANSPORTE COLETIVO GRATUITO** (urbano e semiurbano) **≥ 65 anos** |

## Estatuto arts. 11-12: ALIMENTOS

| | Conteúdo |
|---|---|
| Caráter | **SOLIDÁRIO** entre filhos (diferente do CC clássico, divisível) |
| **DIREITO DE OPÇÃO** | **Pessoa idosa escolhe entre os alimentantes** |
| **Súm. 596 STJ** | Obrigação alimentar dos **avós**: complementar e subsidiária (só na impossibilidade total ou parcial dos pais) |

## Medidas de proteção (art. 43)

| | Conteúdo |
|---|---|
| Hipóteses | Ameaça ou violação por **ação/omissão** da sociedade + Estado + responsáveis legais + **própria conduta** |
| Medidas | Encaminhamento à família + abrigamento + tratamento especial |
| **Lei 8.842/94** | **Política Nacional do Idoso**: diretriz programática |

## Prisão domiciliar: CPP 318 I

| | Conteúdo |
|---|---|
| Preventiva → domiciliar | Para **maior de 80 anos** (CPP 318 I) ou **extremamente debilitado por doença grave** (CPP 318 II) |
| Jurisprudência | Leitura **humanitária** consolidada nos tribunais superiores |

## Tutela coletiva

- **MP** legitimado nato (art. 74);
- **ACP** (Lei 7.347/85), interesses difusos/coletivos/individuais homogêneos;
- Legitimação concorrente: MP + Defensoria + entes + OAB + associações.

## Lei 14.181/2021: superendividamento

- CDC arts. 54-A a 54-G + 104-A a 104-C;
- **Proteção reforçada** à pessoa idosa (vulnerabilidade etária + econômica);
- **Vedação ao assédio de consumo** (CDC 54-C IV);
- Repactuação judicial.

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Pessoa de 60 anos | Aplicação do Estatuto |
| Transporte gratuito | **≥ 65 anos** |
| Reserva de vagas estacionamento | **5%** |
| Alimentos | Solidários + opção pelo idoso |
| Crime contra idoso | **AP PÚBLICA INCONDICIONADA** |
| Apropriação de bens | **Art. 102 do Estatuto** (recl. 1-4a; tipo específico, não CP 168) |
| Discriminação | Art. 96 |
| Homicídio doloso > 60a | **CP 121 §4** + Estatuto |
| Pena máx 4a | Rito sumaríssimo **sem despenalizadores** (ADI 3.096) |
| Processo judicial | **Prioridade** (CPC 1.048) |

## Erros a evitar

- **Aplicar > 60 SEM causas de aumento específicas** (CP);
- **Negar AP PÚBLICA INCONDICIONADA** em crimes contra idoso (art. 95);
- Tratar **crimes idoso SEM prioridade** processual (CPC 1.048);
- Aplicar transporte gratuito a **idoso < 65** (é ≥ 65);
- Negar **direito de opção** alimentar à pessoa idosa (art. 12);
- Confundir **alimentos solidários (Estatuto) com divisíveis** (CC clássico);
- Aplicar BPC a **< 65 anos** (LOAS exige idade);
- Não considerar **prioridade > 80 anos** (mais ampla);
- Confundir o rito sumaríssimo do art. 94 com a aplicação de **institutos despenalizadores** (vedados, ADI 3.096);
- Negar **causa de aumento em estelionato (CP 171 §4)** contra idoso;
- Tratar **art. 102 Estatuto** como CP 168 comum (é tipo específico);
- Usar "idoso" pós-2022 (deve ser **pessoa idosa**: Lei 14.423);
- Aplicar transação penal/sursis processual a crimes do Estatuto (STF, ADI 3.096);
- Validar reajuste de plano de saúde por faixa etária **sem os requisitos do Tema 952 STJ** (previsão contratual + normas regulatórias + percentuais não desarrazoados);
- Recusar prisão domiciliar a maior de 80 anos sem análise (CPP 318 I);
- Esquecer **prioridade especial ≥ 80** (Lei 13.466/2017);
- Não convocar MP em ACP com idoso vulnerável.

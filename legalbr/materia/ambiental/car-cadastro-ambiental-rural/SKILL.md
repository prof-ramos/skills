# CAR: Cadastro Ambiental Rural

## Marco legal

- **Lei 12.651/2012** (Novo Código Florestal, arts. 29-30 + 59-60 PRA);
- **Decreto 7.830/2012** (regulamento original);
- **Decreto 8.235/2014** (PRA);
- **Lei 13.887/2019** (prorrogações de prazos);
- **Lei 14.595/2023** (prazos de inscrição no CAR para fins de adesão ao PRA);
- **Resolução CMN 5.193/2024** (CAR como condição para crédito rural);
- **STF ADC 42 + ADIs** (constitucionalidade);
- Resoluções específicas + Instruções Normativas MMA;
- Atualizações estaduais.

## Conceito (Lei 12.651 art. 29)

> "É criado o Cadastro Ambiental Rural - CAR, no âmbito do Sistema Nacional de Informação sobre Meio Ambiente - SINIMA, registro público eletrônico de âmbito nacional, **obrigatório para todos os imóveis rurais**, com a finalidade de integrar as informações ambientais (...)."

## Características

| | Conteúdo |
|---|---|
| **Eletrônico** | Sistema online (SICAR) |
| **Obrigatório** | Para **todos os imóveis rurais** |
| **Declaratório** | Não há análise prévia |
| **Permanente** | Sem prazo de validade |
| **Público** | Acesso via SICAR |
| **Sujeito a verificação** | Posterior do órgão ambiental |

| | Conteúdo |
|---|---|

| **Localização** | Geográfica (GPS) |

| **Reserva Legal** | Localização |

## Sanções por não inscrição

| | Conteúdo |
|---|---|
| **Advertência** | Inicial |
| **Multa** | Aplicável |
| **Vedação de crédito rural** | CAR registrado e não suspenso é condição para concessão (Res. CMN 5.193/2024, com exigências adicionais contra desmatamento a partir de 01/2026) |
| **Vedação de autorização ambiental** | Sem CAR |
| **Bloqueio de compra/venda** | Em algumas situações |
| **CCIR + ITR** | Cruzamento de dados |

## PRA: Programa de Regularização Ambiental

### Conceito (art. 59)

| | Conteúdo |
|---|---|
| **Programa** | Para regularizar **passivos ambientais** |
| **Foco** | Áreas consolidadas até 22/07/2008 |
| **Após** | Recomposição de APPs + Reservas Legais |
| **Adesão voluntária** | Mediante Termo de Compromisso |
| **Direito de adesão (Lei 14.595/2023)** | Condicionado à inscrição no CAR até 31/12/2023 (imóveis acima de 4 MF) ou até 31/12/2025 (até 4 MF e agricultura familiar); adesão em até 1 ano da notificação do órgão |

### Benefícios

| | Conteúdo |
|---|---|
| **Suspensão de sanções** | Durante cumprimento |
| **Extinção de punibilidade** | Em alguns casos |
| **Recomposição parcial** | Áreas consolidadas com escalonamento |
| **Acesso a crédito** | Mantido com adesão |
| **Pequena propriedade** | Tratamento favorecido |

### Áreas consolidadas (APP)

| Tipo | Recomposição |
|---|---|
| **Pequena propriedade (até 4 MF)** | 5-15m (recomposição reduzida) |
| **Imóvel 4-10 MF** | 8-15m |
| **Imóvel >10 MF** | 30-200m (depende do uso) |
| **Topo de morro + nascente** | Recomposição plena (com exceções) |

### Reserva Legal

| Bioma | Percentual |
|---|---|
| **Amazônia Legal** (floresta) | 80% |
| **Amazônia Legal** (cerrado) | 35% |
| **Amazônia Legal** (campos gerais) | 20% |
| **Cerrado** + outros biomas | 20% |
| **PRA** | Recomposição em até 20 anos |

## Erros a evitar

- Tratar **CAR como licença** (é declaratório);
- Esquecer **PRA** como instrumento de regularização;
- Aplicar **regras de RL antigas** sem ver Lei 12.651;
- Confundir **APP** com **Reserva Legal** (institutos distintos);
- Achar que **CAR garante regularidade** (validação posterior);
- Esquecer **marco temporal 22/07/2008** para áreas consolidadas;
- Tratar pequena propriedade igual a grande (PRA diferencia);
- Aplicar Lei 12.651 sem ver **STF ADC 42** (constitucionalidade);
- Esquecer **CRA** como mecanismo de compensação;
- Confundir **CAR (ambiental)** com **CCIR (INCRA)** + ITR (RFB);
- Aplicar PRA **sem adesão formal** ao Termo de Compromisso;
- Não considerar **bioma** + percentual de RL (varia).

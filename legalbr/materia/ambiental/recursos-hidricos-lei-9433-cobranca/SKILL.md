# Recursos Hídricos: Lei 9.433/97

## Marco legal

- **Lei 9.433/1997** (PNRH + SINGREH);
- **Lei 9.984/2000** (Agência Nacional de Águas, ANA);
- **Lei 14.026/2020** (Marco do Saneamento Básico);
- **CF 20 III + 26 I + 21 XIX** (domínio público);
- **Lei 11.445/2007** (Saneamento Básico);
- Resoluções CNRH (Conselho Nacional de Recursos Hídricos);
- Decretos regulamentadores;
- Pactos de bacias (CBH).

## Princípios (Lei 9.433 art. 1)

| | Conteúdo |
|---|---|
| **I** | Água é **bem de domínio público** |
| **II** | Recurso natural **limitado + dotado de valor econômico** |
| **III** | **Usos múltiplos**, não apenas energia |
| **IV** | Em escassez, prioridade do **consumo humano + dessedentação animal** |
| **V** | Gestão por **bacia hidrográfica** |
| **VI** | Gestão **descentralizada + participativa** |

## Domínio da água (CF + Lei 9.433)

| Categoria | Domínio |
|---|---|
| **Águas em corpos hídricos** | **Públicas** (CF 20 III + 26 I) |
| **Águas subterrâneas** | Estaduais (em geral) |
| **Águas marinhas** | Federais |
| **Águas particulares?** | **Não existem mais** (CC 1.230): todas são públicas |
| **Aquíferos transfronteiriços** | Cooperação internacional |

## Instrumentos da PNRH (Lei 9.433 art. 5)

| Instrumento | Conteúdo |
|---|---|
| **I. Planos** | Recursos Hídricos (por bacia, estado, nacional) |
| **II. Enquadramento** | Corpos d'água conforme uso preponderante |
| **III. Outorga** | Direitos de uso |
| **IV. Cobrança** | Pelo uso da água |
| **V. Compensação aos municípios** | Atingidos por áreas inundadas |
| **VI. Sistema de informações** | SNIRH |

## Outorga de direitos (Lei 9.433 art. 12)

### Quando é necessária

| | Conteúdo |
|---|---|
| **I** | Derivação/captação para consumo final |
| **II** | Extração de aquífero |
| **III** | Lançamento de esgotos/resíduos |
| **IV** | Aproveitamento hidrelétrico |
| **V** | Outros usos que alterem regime, quantidade ou qualidade |

### Dispensa

| | Conteúdo |
|---|---|
| **Acumulação + derivação** | Volumes considerados insignificantes |
| **Uso doméstico de pequenos núcleos** | Rurais |
| **Quem decide insignificância** | ANA/Órgão estadual |

### Características

| | Conteúdo |
|---|---|
| **Ato administrativo** | Discricionário |

| **Suspensão** | Em situações de escassez |

## Erros a evitar

- Tratar água como **bem privado** (CF 20 III: pública);
- Captar sem **outorga** quando obrigatória (Lei 9.433 art. 12);
- Esquecer **prioridade humana + dessedentação** em escassez;
- Confundir **cobrança** com **tributo** (preço público);
- Aplicar **PNRH** sem considerar **plano de bacia** (descentralização);
- Esquecer **ANA** como regulador (Lei 9.984);
- Achar que **águas subterrâneas** são federais (em geral estaduais);
- Confundir **CONAMA Reso 357** com Lei 9.433;
- Tratar **outorga** como permanente (35 anos máx);
- Esquecer **Lei 14.026** (Marco Saneamento) que alterou ANA;
- Aplicar regime sem consultar **CBHs**;
- Não considerar **responsabilidade civil ambiental** (Tema 707 + 999).

# PNMC: Política Nacional sobre Mudança do Clima

## Marco legal

- **Lei 12.187/2009** (PNMC);
- **Decreto 7.390/2010** (regulamento original);
- **Decreto 9.578/2018** (atualização);
- **Acordo de Paris** (Dec. 9.073/2017);
- **NDC Brasil 2024** (atualização);
- **Lei 15.042/2024** (SBCE, Sistema Brasileiro de Comércio de Emissões);
- **CF 225** (meio ambiente);
- **Lei 12.114/2009** (Fundo Clima);
- Convenção-Quadro das Nações Unidas (Dec. 2.652/1998).

## Princípios (Lei 12.187 art. 3)

| | Conteúdo |
|---|---|
| **Precaução** | Antes mesmo de certeza científica |
| **Prevenção** | Atuação preventiva |
| **Participação cidadã** | Sociedade civil + setor produtivo |
| **Desenvolvimento sustentável** | Conciliação |
| **Responsabilidades comuns** | Mas **diferenciadas** entre Estados |

## Objetivos (Lei 12.187 art. 4)

| | Conteúdo |
|---|---|
| **I** | Compatibilizar desenvolvimento socioeconômico com proteção climática |
| **II** | **Redução** das emissões antropogênicas |
| **III** | **Sumidouros** de gases: fortalecer |
| **IV** | Medidas de **adaptação** + redução de vulnerabilidades |
| **V** | Pesquisa científica + transferência de tecnologia |
| **VI** | Educação ambiental |

## Compromissos voluntários (Lei 12.187 art. 12)

### Original (até 2020, cumprido)

| | Conteúdo |
|---|---|
| **Redução** | 36,1% a 38,9% das emissões |
| **Base** | Projeção tendencial 2020 |
| **Cumprido** | Brasil atingiu metas (principalmente por redução do desmatamento) |

### NDC 2024 (Contribuição Nacionalmente Determinada, apresentada em 13/11/2024 na COP29)

| | Conteúdo |
|---|---|
| **Meta** | Redução **59-67%** das emissões líquidas até **2035** (teto de 0,85 a 1,05 GtCO2e) |
| **Base** | Emissões de 2005 |
| **NDC anterior 2020** | 50% redução até 2030 (substituída) |
| **Implementação** | Plano Clima + Planos Setoriais |
| **Compromisso internacional** | Acordo de Paris + COP |

## Erros a evitar

- Tratar PNMC como **mera declaração** (vinculante);
- Esquecer **NDC 2024** (59-67% até 2035), e não a NDC anterior;
- Aplicar princípio **poluidor-pagador** sem considerar **CF 225 + Lei 6.938**;
- Confundir **PNMC** (clima) com **PNMA** (meio ambiente geral);
- Aplicar regras do **Protocolo de Kyoto** após Acordo de Paris (transição);
- Esquecer **Lei 15.042/2024** (SBCE);
- Tratar **NDC** como meta interna (é internacional);
- Aplicar responsabilidade civil **subjetiva** em dano climático (é objetiva, com risco integral);
- Esquecer **Tema 999 STF** (imprescritibilidade);
- Não considerar **REDD+** em projetos florestais;
- Confundir **Plano Clima** com **Plano Setorial**;
- Desconsiderar **litígio climático** crescente como precedente.

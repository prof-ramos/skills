# ADI 6581 — Vacinação Infantil

## Identificação

| | Conteúdo |
|---|---|
| Ação | **ADI 6581** |
| Autor | **PTB** |
| Relator | Min. **Ricardo Lewandowski** |
| Julgamento | **17/12/2020** |
| Placar | **UNÂNIME** |

## Tese estruturante

| | Conteúdo |
|---|---|
| Resultado | Vacinação infantil é **obrigatória** |
| Recusa parental | **Negligência** (ECA 14 §1) |
| Sanções indiretas | Cabíveis (matrícula + Bolsa Família) |
| Vacinação forçada | **Vedada** |

## ECA — base normativa

| | Conteúdo |
|---|---|
| **Art. 14 §1** | É **obrigatória** a vacinação das crianças nos casos recomendados pelas autoridades sanitárias |
| **Art. 56 II** | Escola comunica não comparecimento + reiteradas faltas |
| **Art. 98 II** | Medidas de proteção pela omissão dos pais |
| **Art. 129 VI** | Obrigação de cuidados médicos imposta aos pais |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Recusa parental | **Negligência** (Conselho Tutelar) |
| Matrícula escolar | Comprovante exigível |
| Bolsa Família | Condicionalidade |
| PNI | Obrigatório |
| Vacina COVID infantil | Compatível (ADI 6581) |
| Vacinação forçada | Vedada |
| Sanção indireta | Permitida |
| Justa razão médica | Imuniza |
| Pais reincidentes | Suspensão do poder familiar possível |
| Direito à informação | Garantido |

## Diálogo com ADIs 6586/6587

| | Conteúdo |
|---|---|
| Adultos | ADI 6586/6587 — compulsoriedade indireta |
| Crianças | ADI 6581 — proteção integral + ECA |
| **Comum** | Vedação à vacinação forçada |

## Erros a evitar

- Tratar recusa parental como liberdade absoluta;
- Negar matrícula sem base normativa local;
- Aplicar vacinação forçada;
- Aceitar objeção religiosa como blindagem total;
- Confundir adultos com crianças (regimes próprios).

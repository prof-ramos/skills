# Internação Compulsória + Saúde Mental

## Lei 10.216/2001 — REFORMA PSIQUIÁTRICA

| | Conteúdo |
|---|---|
| Modelo | **SUBSTITUTIVO** ao manicomial |
| Atenção | **COMUNITÁRIA** |
| Art. 2 | Tratamento humanizado + meio menos invasivo + preferência por serviços comunitários |

## Art. 4 — INTERNAÇÃO como ÚLTIMO RECURSO

| | Conteúdo |
|---|---|
| Regra | **ESGOTAMENTO** das alternativas extra-hospitalares |
| **§1** | **Vedada para fins ASILARES** |
| **§2** | Sempre **terapêutica** |

## Art. 6 — 3 ESPÉCIES de INTERNAÇÃO

| Espécie | Conteúdo |
|---|---|
| **VOLUNTÁRIA** | Com **consentimento expresso** do paciente |
| **INVOLUNTÁRIA** | **SEM consentimento** — a pedido de terceiro (familiar/responsável); **comunicação ao MP em 72h** (art. 8 §1); MP **supervisiona**; alta a qualquer tempo |
| **COMPULSÓRIA** | Determinada pelo **JUIZ COMPETENTE** + **LAUDO MÉDICO CIRCUNSTANCIADO** (art. 9); perigo a si/outros; **prazo determinado + REAVALIAÇÃO PERIÓDICA** |

## Lei 13.840/2019 — DEPENDÊNCIA QUÍMICA

| | Conteúdo |
|---|---|
| Altera | Leis 11.343/2006 + 7.560/1986 |
| **Internação involuntária por dependência** | A pedido da **família** + autoridade **médica** competente |
| **SEM ordem judicial** específica | Até **90 DIAS** |
| Reconheceu | **Comunidades terapêuticas** como dispositivo |
| **STF ADI 6.121** | **Pendente** julgamento — tensão proteção × autonomia |

## RAPS — Rede de Atenção Psicossocial

| | Conteúdo |
|---|---|
| Base | **Portaria GM/MS 3.088/2011** |
| Componentes | **CAPS + CAPS AD** (álcool/drogas) + **CAPS i** (infantojuvenil) + **UA** (Unidades de Acolhimento) + **SRT** (Serviços Residenciais Terapêuticos) + atenção domiciliar |
| Modelo | **SUBSTITUTIVO** |

## Medida de Segurança (CP 26 + 96-99)

| | Conteúdo |
|---|---|
| Sujeitos | **Inimputável + semi-imputável** |
| Espécies | **Internação** (reclusão) OU **tratamento ambulatorial** (detenção) |
| **Súm. 527 STJ** | **Máximo = pena cominada** em abstrato |
| **STF Tema 1.061 + HC 107.432** | Diálogo com Lei 10.216 — preferência por ambulatorial + desinstitucionalização |
| **HC 116.000 STJ** | **Alcoolismo PATOLÓGICO** = hipótese de MS |

## ADPF 347 + audiência de custódia

| | Conteúdo |
|---|---|
| Verificação | **Saúde mental** na audiência |
| Impacto | Encaminhamento para tratamento em vez de cárcere |

## Procedimento da COMPULSÓRIA

| | Conteúdo |
|---|---|
| 1 | Petição (família + MP + Defensoria) |
| 2 | **Laudo médico circunstanciado** |
| 3 | **Oitiva do paciente** (se possível) |
| 4 | **Manifestação do MP** |
| 5 | **Decisão FUNDAMENTADA** |
| 6 | **Prazo determinado + REAVALIAÇÕES periódicas** |
| 7 | Alta condicionada a laudo |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Esgotada RAPS | **Internação** |
| Paciente consente | **Voluntária** |
| Família pede + sem consentimento | **Involuntária** — MP em 72h |
| Periculosidade + ordem judicial | **Compulsória** |
| Dependência química | **Lei 13.840** — até 90d + ADI 6.121 pendente |
| Inimputável | **MS** (CP 96-99) + Súm. 527 |
| Alcoolismo patológico | **CP 26** + MS |
| Sem laudo | **VEDADA** (AgInt 1.853.220) |
| Sem reavaliação | **Vedada** (Res. CNJ 487) |
| ILPI substituindo tratamento | **Vedado** |
| Diretiva antecipada | **Aplicar** (CFM 1.995/2012) |

## Erros a evitar

- A internação exige **laudo técnico circunstanciado**; sua falta a torna nula;
- A medida exige **reavaliação periódica** (Res. CNJ 487/2023);
- **Internação** e **curatela/interdição** são institutos distintos;
- A Lei 13.840 exige, cumulativamente, suporte da **família** e da autoridade médica;
- O **esgotamento da RAPS** é pressuposto (Lei 10.216 art. 4);
- O **prazo indeterminado** é vedado (Súm. 527 STJ + Res. CNJ 487);
- A LBI prioriza a tomada de decisão apoiada sobre a **curatela plena**;
- A Lei 10.216 não rege a **medida socioeducativa** (Lei 12.594, distinta);
- A internação pressupõe a **oitiva prévia** do paciente, quando possível;
- A involuntária exige comunicação ao **MP em 72h** (Lei 10.216 art. 8 §1º); sua falta gera nulidade;
- A **ILPI** não substitui o tratamento psiquiátrico.

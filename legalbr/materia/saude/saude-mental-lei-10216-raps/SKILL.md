# Saúde Mental — Lei 10.216 + RAPS

## Marco legal

- **Lei 10.216/2001** (Reforma Psiquiátrica — Paulo Delgado);
- **Lei 13.146/2015** (LBI — pessoa com deficiência);
- **Portaria GM/MS 3.088/2011** (RAPS);
- Portarias atualizadoras (2024-2025);
- **Lei 11.343/2006** (drogas);
- **Lei 13.840/2019** (SISNAD — internação por dependência);
- **CP 96-99** (medida de segurança);
- **Lei 13.105 (CPC)** + Lei 8.842/94 (idoso) — interdições;
- LGPD (dado sensível — saúde mental);
- ANS Resolução Normativa 539/2022 (saúde suplementar).

## Princípios (Lei 10.216 art. 2)

| | Conteúdo |
|---|---|
| **I** | Acesso ao **melhor tratamento** disponível no SUS |
| **II** | **Tratamento humano** + respeito + interesse exclusivo da pessoa |
| **III** | Proteção contra qualquer forma de **exploração** ou abuso |
| **IV** | Garantia do **sigilo** das informações |
| **V** | Direito ao consentimento prévio do tratamento |
| **VI** | **Comunicação livre** com profissionais |
| **VII** | Atendimento por equipe multiprofissional |
| **VIII** | Recuperação por inserção em **família + trabalho + comunidade** |
| **IX** | Tratamento em **ambiente terapêutico** menos invasivo |

## Modalidades de internação (art. 6 + 8 + 9)

| Modalidade | Conteúdo |
|---|---|
| **Voluntária** | Com consentimento expresso do paciente |
| **Involuntária** | A pedido de terceiros (familiar, médico) — **sem** consentimento — **MP avisado em 72h** |
| **Compulsória** | Determinada pelo **juiz** — apenas em casos extremos |

### Procedimento (art. 7-10)

| | Conteúdo |
|---|---|
| **Laudo médico** | Justifica + circunstancia |
| **Comunicação ao MP** | Em **72 horas** (involuntária) |
| **Familiar** | Dever de acompanhar |
| **Direito de visita** | Garantido |
| **Encerramento** | Médico decide na voluntária; MP fiscaliza involuntária |

## Direitos da pessoa com transtorno mental (art. 2)

Inclui acesso aos cuidados, tratamento humano, sigilo, recusa de tratamento experimental, visitação, comunicação com profissionais, opção pela alta etc.

## RAPS — Rede de Atenção Psicossocial

| Serviço | Conteúdo |
|---|---|
| **CAPS I** | Cidade até 70mil habitantes — atendimento adulto |
| **CAPS II** | 70-200mil — geral adulto |
| **CAPS III** | > 200mil — funcionamento 24h |
| **CAPSi** | Infanto-juvenil |
| **CAPS-AD** | Álcool e drogas |
| **CAPS-AD III** | AD 24h |
| **SRT** | Serviço Residencial Terapêutico — moradia |
| **Consultório na Rua** | Acesso à população em situação de rua |
| **UPA + UBS** | Atenção primária + emergência |
| **Leitos saúde mental** | Hospital geral (não-manicomial) |
| **Unidade de Acolhimento** | Tratamento de adultos AD |

### Portaria 3.088/2011 + atualizações

Cinco eixos:
1. Atenção primária à saúde;
2. Atenção psicossocial estratégica;
3. Atenção de urgência e emergência;
4. Atenção residencial de caráter transitório;
5. Atenção hospitalar.

## Tratamento + alta

| | Conteúdo |
|---|---|
| **Alta** | Por melhora clínica |
| **Voluntária** | Pode optar pela alta (salvo médico discordar com justificativa) |
| **Involuntária** | Médico decide com fundamentação + MP fiscaliza |
| **Compulsória** | Judicial — alta requer manifestação judicial |
| **Acompanhamento pós-alta** | RAPS — continuidade |

## Internação compulsória (judicial)

| | Conteúdo |
|---|---|
| **Cabimento** | Risco grave a si próprio ou a terceiros |
| **Procedimento** | Vara cível especializada (idoso, infância) — Lei 10.216 art. 9 |
| **Provas** | Laudo psiquiátrico + outros elementos |
| **Limites** | Tratamento, não punição |
| **Drogadição** | Lei 13.840/2019 — específica |
| **Adolescentes** | ECA + Lei 12.594 (SINASE) |

## Dependência química — Lei 13.840/2019

| | Conteúdo |
|---|---|
| Conceitos | Tratamento + acolhimento + redução de danos |
| **Internação involuntária por dependência** | Permitida por familiar + médico + MP avisado |
| **Comunidade terapêutica** | Modalidade prevista |
| Críticas | Vagas ainda predominantemente manicomiais |

## Medida de segurança (CP 96-99)

| | Conteúdo |
|---|---|
| **Inimputável** (CP 26) | Doença mental impede culpabilidade |
| **Semi-imputável** (CP 26 par.) | Capacidade reduzida — pena ou MS |
| **Medidas** | Internação em hospital de custódia ou tratamento ambulatorial |
| **Prazo** | **Indeterminado** (CP 97) — mas STF + STJ aplicam limite máximo (pena cominada) |
| **Cessação** | Periculosidade afastada — exame após 1-3 anos |
| Hospital de custódia | Está em **desativação** (reforma psiquiátrica) |

## Interdição + curatela (CC 1.767 + LBI)

| | Conteúdo |
|---|---|
| **Pré-LBI** | Quase total para PCD |
| **Pós-LBI (2015)** | Restringida a **atos patrimoniais** |
| Tomada de Decisão Apoiada | Alternativa menos restritiva |
| **Saúde mental** | Pessoa com transtorno é **capaz** em geral |
| Curatela | Excepcional + temporária |

## Erros a evitar

- Tratar internação **involuntária** como prisão (é proteção médica);
- Esquecer **MP em 72h** na involuntária (Lei 10.216 art. 8 §1);
- Aplicar internação como **regra** — é exceção (Lei 10.216 art. 4);
- Achar que **medida de segurança** é indeterminada (STF + STJ — limita ao máximo da pena cominada);
- Internar pessoa em **hospital psiquiátrico** ignorando RAPS;
- Esquecer **LBI** — PCD é **capaz** em regra (interdição restrita);
- Tratar **álcool/drogas** sem aplicar Lei 13.840 + redução de danos;
- Aplicar interdição **plena** (vedada — LBI);
- Quebrar sigilo de saúde mental sem **base legal** (LGPD + CEM 73);
- Negar **alta voluntária** sem fundamentação (Lei 10.216 art. 9);
- Aplicar internação compulsória sem **ordem judicial** (Lei 10.216 art. 9);
- Esquecer **continuidade do tratamento** em rescisão de plano (STJ Tema 1.082).

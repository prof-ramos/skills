# Uso Compassivo + Acesso Expandido

## Marco legal

- **RDC Anvisa 38/2013** (regulamenta os 3 programas);
- **Lei 14.874/2024** (pesquisa clínica com seres humanos: substituiu CNS 466/2012 em parte);
- **Reso CNS 466/2012** (vigente em pesquisa não-intervencional);
- **RDC Anvisa 9/2015** (boas práticas em pesquisa clínica);
- **Lei 6.360/76** (vigilância sanitária);
- **CFM 2.314/2022** (telemedicina);
- **STF Tema 500 + STF Tema 6 / SV 61** (judicialização);
- LGPD (dado sensível: pesquisa).

## Definições essenciais (RDC 38)

| Termo | Conteúdo |
|---|---|
| **Medicamento experimental** | Sem registro no Brasil + em pesquisa clínica |
| **Doença grave debilitante ou ameaçadora à vida** | Sem alternativa terapêutica satisfatória entre os registrados |
| **Patrocinador** | Empresa farmacêutica responsável pelo medicamento |
| **CEP** | Comitê de Ética em Pesquisa |
| **CONEP** | Comissão Nacional de Ética em Pesquisa |
| **Anvisa** | Autoriza programas e produtos |

## Três programas (RDC 38)

| Programa | Conteúdo | Beneficiário |
|---|---|---|
| **Acesso Expandido** | Programa para **grupo de pacientes** | Coletivo (múltiplos pacientes) |
| **Uso Compassivo** | **Individual** (um paciente) | Caso único, fora de pesquisa |
| **Pós-Estudo** | Continuação após término da pesquisa clínica | Quem participou da pesquisa |

### Acesso Expandido

| | Conteúdo |
|---|---|
| Objetivo | Disponibilizar a um **grupo** durante a fase de registro |
| Requisitos | Doença grave + sem alternativa + medicamento em estudo avançado (Fase III ou pós) |
| Autorização | Anvisa + CEP + CONEP |
| Duração | Até registro formal |
| Custo | **Gratuito** ao paciente |

### Uso Compassivo

| | Conteúdo |
|---|---|
| Objetivo | Acesso **individual** sob solicitação médica |
| **Diferença do AE** | Apenas um paciente, fora de protocolo coletivo |
| Requisitos | Doença grave + sem alternativa + parecer médico + consentimento informado |
| Autorização | Anvisa + CEP |
| Documentação | Parecer médico + TCLE + dossier do produto + comprometimento do patrocinador |
| **Patrocinador** | Pode aceitar ou não fornecer |

### Pós-Estudo

| | Conteúdo |
|---|---|
| Objetivo | Continuidade para participantes que **se beneficiaram** da pesquisa |
| Direito | Reconhecido pela Reso CNS 466/2012 + agora Lei 14.874/2024 |
| **Patrocinador** | **Obrigado** a fornecer enquanto houver benefício |
| Duração | Enquanto há benefício clínico (médico decide) |
| Custo | Gratuito |
| Limite | Até registro + comercialização ou enquanto benefício |

## Lei 14.874/2024: Pesquisas Clínicas

### Inovações

| | Conteúdo |
|---|---|
| **Marco legal** | Substituiu parte da Reso CNS 466/2012 em pesquisa intervencional |
| **Prazos** | Análise em **prazo definido** (90 dias para CEP + 30 para Anvisa); antes indefinido |
| **Sistema nacional** | Plataforma Brasil + IRB acelerados |
| **CONEP** | Atua nas pesquisas mais sensíveis |
| **Patrocinador estrangeiro** | Representante no Brasil |
| **Direitos do participante** | **Pós-estudo obrigatório** + indenização + sigilo |
| **Vigência** | 100% em 2025 |

### Limites éticos

| | Conteúdo |
|---|---|
| **Placebo** | Restrito quando há tratamento eficaz disponível |
| **Indenização** | Patrocinador responde por danos |
| **TCLE** | Específico para pesquisa |
| **Vulneráveis** | Cuidados especiais (criança, gestante, indígena) |

## Procedimento (RDC 38)

| Etapa | Conteúdo |
|---|---|
| 1. Solicitação | Pelo médico responsável + paciente |
| 2. **TCLE** | Termo de consentimento informado |
| 3. **Anvisa** | Análise técnica do dossier |
| 4. **CEP** | Avaliação ética |
| 5. **CONEP** | Casos específicos |
| 6. **Patrocinador** | Aceitar fornecer (uso compassivo individual) |
| 7. Autorização | Anvisa emite |
| 8. **Importação** | Conforme regras alfandegárias |
| 9. **Acompanhamento** | Relatórios + farmacovigilância |

## Responsabilidades

| Ator | Responsabilidade |
|---|---|
| **Médico** | Prescrição + acompanhamento + relatórios |
| **Paciente** | Consentimento + compromisso |
| **Patrocinador** | Fornecimento + segurança + farmacovigilância |
| **Anvisa** | Autorização + supervisão |
| **CEP/CONEP** | Análise ética |
| **Estabelecimento de saúde** | Estrutura adequada |

## Judicialização: fornecimento via SUS

### STF Tema 500 + STF Tema 6 / SV 61

| | Conteúdo |
|---|---|
| **Medicamento sem registro Anvisa** | **STF Tema 500 (RE 657.718)**: em regra **vedado**; ação contra a União; a vedação não alcança a hipótese de importação autorizada pela Anvisa (Tema 1.161) |
| **Exceção (Tema 500)** | Mora irrazoável da Anvisa + registro estrangeiro + ausência de substituto (salvo órfão de doença rara) |
| **Sem registro, com importação autorizada pela Anvisa** | **STF Tema 1.161 (RE 1.165.959, Plenário, j. 18/06/2021)**: cabe ao Estado fornecer, em termos excepcionais, desde que comprovadas (i) a incapacidade econômica do paciente, (ii) a imprescindibilidade clínica do tratamento e (iii) a impossibilidade de substituição por similar constante das listas oficiais de dispensação e dos protocolos do SUS |
| **STF Tema 6 (RE 566.471) / SV 61** | Requisitos cumulativos para o não incorporado registrado |
| **Tema 1.234 STF / SV 60** (2024) | Fluxos interfederativos + competência por valor + análise prévia administrativa |

### Critérios para deferimento

| | Conteúdo |
|---|---|
| **Registro Anvisa** | Em regra exigido |
| **Sem alternativa** | Comprovada |
| **Indicação** | Medicamente fundada |
| **Custo-efetividade** | Considerado |
| **Política pública** | Existência de programa SUS |
| Eficácia comprovada | Mesmo se não registrado (excepcional) |

## Distinção uso compassivo × off-label

| | Uso Compassivo | Off-label |
|---|---|---|
| **Registro Anvisa** | **Sem** registro | **Com** registro |
| **Indicação** | Investigacional | Indicação não aprovada |
| **Regulação** | RDC 38 | Sem regulamentação específica |
| **Médico** | Decisão fundamentada | Decisão fundamentada |
| **Responsabilidade** | Patrocinador + médico | Médico |
| **Cobertura ANS** | Específica via judicialização | Lei 14.454/2022 (rol exemplificativo) favorável |

## Off-label

| | Conteúdo |
|---|---|
| **Definição** | Uso fora da bula aprovada |
| **CFM** | Resoluções e pareceres admitem a prescrição off-label com fundamentação e responsabilidade do médico |
| **TCLE** | Recomendado |
| **Plano de saúde** | Cobertura ampliada (Lei 14.454/2022, rol exemplificativo), com indicação médica fundamentada |

| | Conteúdo |
|---|---|

## Erros a evitar

- Confundir **uso compassivo** (individual) com **acesso expandido** (grupo): RDC 38;
- Pedir fornecimento via SUS de medicamento **sem registro** sem aplicar **Tema 500 STF**;
- Negar fornecimento de medicamento sem registro mas com **importação autorizada pela Anvisa** sem examinar o **Tema 1.161 STF** (RE 1.165.959, Plenário, j. 18/06/2021);
- Esquecer **pós-estudo obrigatório** após pesquisa clínica (Lei 14.874);
- Tratar off-label como uso compassivo (com vs. sem registro);
- Aceitar **placebo** quando há tratamento eficaz disponível (Lei 14.874);
- Esquecer **TCLE** + CEP + CONEP;
- Não comunicar **eventos adversos** à Anvisa;
- Confundir CONEP (ética) com Anvisa (técnica);
- Ignorar **CONITEC** ao incorporar medicamento ao SUS;
- Esquecer responsabilidade do **patrocinador** (Lei 14.874 art. 9);
- Aplicar regras antigas da **Reso CNS 466/2012** em pesquisa intervencional (Lei 14.874 substituiu);
- Negar cobertura ANS sem aplicar a **Lei 14.454/2022** (rol exemplificativo).

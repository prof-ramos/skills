# Telemedicina

## Marco legal

- **Reso CFM 2.314/2022** (regulamentação permanente);
- **Lei 14.510/2022** (telessaúde permanente: altera a Lei 8.080; substituiu a revogada Lei 13.989/2020, do regime emergencial da pandemia);
- **Lei 12.842/2013** (Ato Médico);
- **CEM 2018 art. 37** (atendimento à distância);
- **LGPD** (Lei 13.709/2018): dado sensível art. 5 II + 11;
- **Lei 14.063/2020** (assinatura digital);
- **MP 2.200-2/2001** (ICP-Brasil);
- ANS Resolução Normativa 539/2022 (cobertura);
- Portarias MS específicas (Telessaúde SUS).

## Definição (CFM 2.314 art. 1)

> "Telemedicina é o exercício da medicina mediado por Tecnologias Digitais, de Informação e de Comunicação (TDICs), para fins de assistência, educação, pesquisa, prevenção de doenças e lesões, gestão e promoção de saúde."

## Sete modalidades

| Modalidade | Conteúdo |
|---|---|
| **Teleconsulta** | Consulta médica não presencial (médico ↔ paciente) |
| **Teleinterconsulta** | Médico ↔ médico (segunda opinião) |
| **Telediagnóstico** | Emissão de laudo/parecer com base em dados enviados (imagens, gráficos) |
| **Telecirurgia** | Cirurgia robótica à distância (raríssima, em desenvolvimento) |
| **Telemonitoramento / Televigilância** | Acompanhamento contínuo (sinais vitais, dados clínicos) |
| **Teletriagem** | Avaliação inicial à distância |
| **Teleconsultoria** | Apoio decisório entre profissionais ou instituições |

## Requisitos para o médico

| | Conteúdo |
|---|---|
| **Inscrição no CRM** | Da localidade onde **médico ou paciente** está |
| **Diploma + título** | Regularmente registrados |
| **Especialidade** | Se exigida pelo tipo de teleatendimento |
| **Educação continuada** | Recomendada |
| **Plataforma adequada** | Segurança + LGPD compliance |
| **Telemedicina inteligente** | Permitida com supervisão |

## Plataforma: requisitos técnicos

| | Conteúdo |
|---|---|
| **Segurança da informação** | Criptografia + controle de acesso |
| **LGPD** | Conformidade com bases legais e direitos do titular |
| **Gravação** | Permitida se houver consentimento |
| **Armazenamento** | Mesmas regras do prontuário (20 anos) |
| **Rastreabilidade** | Auditoria das interações |
| **Identificação** | Médico + paciente |
| **Pseudonimização** | Quando aplicável (pesquisa) |

## Erros a evitar

- Praticar telemedicina **sem inscrição no CRM** (Reso 2.314);
- Esquecer **TCLE específico** para telemedicina;
- Usar **assinatura comum** em prescrição (precisa **ICP-Brasil**, Lei 14.063);
- Tratar urgências graves por telemedicina **sem direcionar** ao presencial;
- Não armazenar **prontuário eletrônico** por 20 anos;
- Esquecer **LGPD** + bases legais + dado sensível (art. 11);
- Invocar a **Lei 13.989/2020** como fundamento atual: foi revogada; o regime vigente é o da Lei 14.510/2022 + Reso CFM 2.314;
- Operadora de plano **negar cobertura** de teleconsulta (RN ANS 539/2022);
- Não comunicar **vazamento** à ANPD;
- Permitir gravação **sem consentimento** do paciente;
- Confundir telemedicina (médico-paciente) com **telessaúde** (multiprofissional);
- Esquecer **CEM 73**: sigilo aplicado integralmente.

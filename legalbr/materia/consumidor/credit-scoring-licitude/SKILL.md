# Credit Scoring

## Marco legal

- **Lei 12.414/2011**: Cadastro Positivo;
- **LGPD** Lei 13.709/2018;
- **CDC arts. 43 + 6 III**;
- **STJ Tema 710** (REsp 1.419.697 / 1.457.199);
- **Súm. 550 STJ**.

## Conceito

Sistema que atribui **pontuação** ao consumidor com base em histórico de pagamentos, capacidade financeira, dívidas, prazo de relacionamento, etc., para avaliar **risco de crédito**.

## Súm. 550 STJ

> "A utilização de **escore de crédito**, **método estatístico de avaliação de risco** que não constitui banco de dados, **dispensa o consentimento** do consumidor, que terá o direito de solicitar **esclarecimentos** sobre as informações pessoais valoradas e as fontes dos dados considerados no respectivo cálculo."

## Tema 710 STJ (REsp 1.419.697 + 1.457.199, j. 2014)

> Síntese da tese: o "credit scoring" é método de avaliação do risco de concessão de crédito a partir de modelos estatísticos; essa prática comercial é **lícita**, autorizada pelo art. 5º, IV, e pelo art. 7º, I, da Lei 12.414/2011, observados os deveres de **transparência** e o respeito à **privacidade**, vedado o uso de dados sensíveis ou excessivos.

### Requisitos para licitude

| Requisito | Conteúdo |
|---|---|
| **Transparência** | Direito de saber dados + fontes + critérios gerais |
| **Não usar dados sensíveis** | Origem racial, religião, opinião política, saúde, vida sexual, filiação sindical |
| **Não discriminação** | Por idade, etnia, gênero, etc. |
| **Acesso ao consumidor** | Pode consultar sua pontuação |
| **Atualização** | Dados atualizados |
| **Finalidade lícita** | Avaliação de risco |

## Lei 12.414/2011: Cadastro Positivo

| | Conteúdo |
|---|---|
| LC 166/2019 | Alterou: adesão **automática** (opt-out) |
| Cadastro positivo | Histórico de pagamentos pontuais |
| Gestores | Bureaus (Serasa, Boa Vista, SCPC) |
| Consumidor | Pode optar por sair (opt-out) |
| Sigilo | Mantido |

## Diferença credit scoring × bancos de dados

| | Banco de dados (cadastro restritivo) | Credit scoring |
|---|---|---|
| Conteúdo | Dívidas, inadimplência | Pontuação estatística |
| Comunicação | Obrigatória (Súm. 359) | Não obrigatória (Súm. 550) |
| Acesso | Direito do consumidor | Direito do consumidor |
| Negativação | Sim | Não (mera pontuação) |
| Dano moral | In re ipsa em irregularidade | Apenas em abuso |

## Quando é abusivo

| Hipótese | Cabível dano moral |
|---|---|
| Uso de **dados sensíveis** | Sim |
| Pontuação **discriminatória** | Sim |
| Recusa de acesso aos critérios | Sim |
| Pontuação **manifestamente errada** | Sim |
| Dados não atualizados | Caso a caso |
| Mera baixa pontuação | Não (não é dano automaticamente) |

## Direito de informação (CDC 6 III + Súm. 550)

| | Conteúdo |
|---|---|
| Critérios gerais | Devem ser informados |
| Fontes específicas | Sim |
| Algoritmo detalhado | Pode ser segredo comercial; **critérios gerais**, porém, devem ser informados |
| Reclamação | Canal acessível |
| Retificação | Direito do consumidor |

## LGPD aplicada

| | Conteúdo |
|---|---|
| Base legal | Proteção do crédito e legítimo interesse (LGPD art. 7 IX e X + art. 10) |
| Dados sensíveis | Definidos no art. 5 II LGPD; uso no scoring é vedado (Tema 710) |
| Direito do titular | Acesso, retificação, exclusão, oposição (art. 18) |
| ANPD | Fiscaliza |
| Sanção | Multa LGPD |

## Cadastro positivo

| | Conteúdo |
|---|---|
| LC 166/2019 | Adesão automática (opt-out) |
| Saída | Comunicação ao bureau |
| Conteúdo | Pagamentos em dia |
| Benefício | Favorece tomadores com bom histórico |
| Compartilhamento | Entre bureaus + bancos (limitado) |

## Recusa de crédito baseada em scoring

- **Lícita** se score baixo;
- Mas operador deve poder **explicar** ao consumidor (mediante solicitação);
- Recusa sem explicação = vício de informação;
- Discriminação ilegal = dano moral.

## Dano moral

| Caso | Cabível |
|---|---|
| Pontuação derivada de **dados sensíveis** | In re ipsa |
| Discriminação manifesta | In re ipsa |
| Erro grosseiro em dados | Cabível |
| Recusa de acesso à informação | Cabível |
| Mera baixa pontuação | Não |

## Ações cabíveis

| Pedido | Fundamento |
|---|---|
| Exibição dos dados/critérios | CDC 6 III + LGPD |
| Retificação | LGPD art. 18 |
| Exclusão de dado sensível | LGPD art. 11 |
| Dano moral | CDC 6 VI + Tema 710 |
| Tutela antecipada | Acesso à informação |

## Cláusulas / práticas inválidas

- Recusar acesso aos critérios;
- Usar **CEP discriminador** sistemático;
- Pontuação por **raça, gênero, religião**;
- Negativa de crédito **sem justificativa**;
- Dados desatualizados sustentando pontuação atual.

## Provas

- Consulta ao score;
- Solicitação de explicação ao bureau;
- Recusa de crédito documentada;
- Documentos de pagamento pontual;
- Cartas de retificação.

## Cadastros restritivos × score: não confundir

- SPC / Serasa cadastro restritivo (CDC 43);
- Score Serasa (mero indicador);
- Súm. 385 STJ aplicável ao **cadastro restritivo**, não ao score isolado.

## Reclamação ANPD

- Em caso de violação LGPD;
- Pode resultar em sanção administrativa;
- Não exclui a via judicial.

## Erros a evitar

- Tratar scoring como **cadastro restritivo** (são institutos diferentes);
- Exigir **comunicação prévia** para abertura do score (Súm. 550 dispensa);
- Tratar **mera baixa pontuação** como dano moral;
- Desconsiderar acesso aos **critérios gerais** (Tema 710);
- Admitir uso de **dados sensíveis** (LGPD + Tema 710);
- Omissão de **dano moral** em discriminação manifesta;
- Aplicar **Súm. 385 STJ** ao score (é para cadastro restritivo);
- Desconsiderar inversão do ônus em quesitos de transparência;
- Admitir segredo comercial **absoluto** sobre todos os critérios;
- Não aplicar **LGPD**;
- Admitir recusa de crédito **sem explicação possível**;
- Aplicar prescrição **trienal** (CDC 27, 5 anos para fato do serviço).

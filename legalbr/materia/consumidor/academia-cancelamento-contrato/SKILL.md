# Academia e Cursos: Cancelamento e Multa

## Marco legal

- **CDC** Lei 8.078/1990, arts. 14, 30, 35, 39, 49, 51-52;
- **CC** arts. 421-424, 478;
- **Lei 9.870/1999** (cursos com mensalidade);
- **CONAR** (publicidade);
- **Estatuto da Pessoa Idosa + LBI**: proteções específicas.

## Cancelamento: direito potestativo

| | Conteúdo |
|---|---|
| Fundamento | CDC 51 II + boa-fé |
| Direito | A qualquer tempo |
| Sem motivação | Sim |
| Multa | Razoável (CDC 51 IV) |
| Restituição | Proporcional |
| Aviso prévio | Razoável (15-30 dias) |

## Multa de rescisão

| | Limite |
|---|---|
| Razoabilidade | Proporcional ao período remanescente, vedada vantagem exagerada (CDC 51 IV); redução equitativa se excessiva (CC 413) |
| **Vantagem exagerada** | Cláusula nula (CDC 51 IV) |
| Contratos anuais | Multa proporcional ao tempo restante |
| Bonificação por adesão (gratuita inicial) | Pode ser glosada |
| Mensalidade ainda em curso | Devida integral |
| Mensalidades futuras | Multa razoável + restituição |

## Restituição

| | Conteúdo |
|---|---|
| Valores pagos antecipadamente | Restituição **proporcional** |
| Restituição em parcela única | Súm. 543 STJ, por analogia |
| Dobra (CDC 42 par. único) | Em valores claramente indevidos |
| Atualização | Sim |

## Cláusulas inválidas

- "Multa de 50% sobre saldo";
- "Sem direito a cancelamento";
- "Mensalidade não restituível";
- "Vencimento antecipado integral em caso de desistência";
- Plano semestral/anual com multa desproporcional ao saldo remanescente (CDC 51 IV);
- Renúncia ao CDC 49;
- Foro abusivo.

## Direito de arrependimento (CDC 49)

| | Aplicável |
|---|---|
| Contratação **online** | Sim, 7 dias |
| Contratação **presencial** | Não |
| Aula experimental + adesão presencial | Não cabe arrependimento |
| Aula experimental + adesão online | Cabe |

## Publicidade vincula (CDC 30)

- "Adesão sem multa";
- "Aula grátis";
- "Pague 3 e leve 6";
- "Sem fidelidade";

Tudo que veiculado vincula. Cláusulas internas contraditórias = inválidas.

## Aulas com personal trainer

| | Conteúdo |
|---|---|
| Pacote de aulas | Aplica-se CDC |
| Não usufruídas | Restituição proporcional |
| Substituição por outro profissional | Caso a caso (vincula a oferta original) |
| Lesão durante aula | Responsabilidade objetiva (CDC 14) |

## Lesão / acidente em academia

| | Conteúdo |
|---|---|
| Responsabilidade | **Objetiva** (CDC 14) |
| Excludentes | Culpa exclusiva da vítima |
| Cláusula de não responsabilização | Nula (CDC 25 + 51 I) |
| Termo de responsabilidade | Não exime fornecedor |
| Equipamentos | Devem ser seguros (CDC 12) |
| Profissional desqualificado | Defeito do serviço |

## Fechamento abrupto

| Caso | Solução |
|---|---|
| Empresa fecha | Restituição integral |
| Mudança de endereço prejudicial | Resolução com restituição |
| Suspensão de modalidades | Restituição proporcional |
| Insolvência | Habilitação em recuperação/falência + ACP |

## Cláusula de fidelidade

| | Conteúdo |
|---|---|
| Admitida? | Sim, com razoabilidade |
| Multa por descumprimento | Proporcional |
| Mudança de cidade (consumidor) | Caso a caso (jurisprudência admite redução da multa) |
| Doença incapacitante | Justifica cancelamento sem multa |
| Gravidez | Justifica suspensão ou cancelamento |

## Plano anual com desconto

| | Conteúdo |
|---|---|
| Desconto pelo total | Pode ser glosado em cancelamento parcial |
| Cálculo proporcional | Mensalidade cheia × meses utilizados |
| Diferença | Devida pelo consumidor |
| Multa adicional | Razoável |

## Vendas casadas

- Material didático + matrícula;
- Personal trainer + plano;
- Avaliação física obrigatória paga;

Em geral **vedadas** (CDC 39 I).

## Suspensão (não cancelamento)

| | Conteúdo |
|---|---|
| Doença/lesão | Direito do consumidor |
| Comprovação médica | Necessária |
| Período | Razoável |
| Sem multa | Mera suspensão |
| Operadora deve oferecer | Em geral via canal |

## Dano moral

| Caso | Cabível |
|---|---|
| Cobrança vexatória | Sim |
| Negativação indevida | Presumido, in re ipsa (jurisprudência consolidada do STJ) |
| Fechamento abrupto sem comunicação | Caso a caso |
| Lesão em equipamento defeituoso | Cumula com material |
| Mero aborrecimento | Não |

## Resolução por defeito do serviço

| | Conteúdo |
|---|---|
| Aulas suspensas reiteradamente | Cabe rescisão sem multa |
| Equipamentos danificados | Idem |
| Professor sem qualificação | Idem |
| Ambiente inadequado | Idem |
| Mudança de unidade | Caso a caso |

## Idoso (Estatuto)

- Proteção reforçada;
- Vedada discriminação;
- Recusa de cancelamento: abusiva.

## Erros a evitar

- Admitir **multa rescisória abusiva** (CDC 51 IV);
- Desconsiderar **direito potestativo** de cancelamento;
- Não permitir **restituição proporcional**;
- Admitir cláusula que vede arrependimento online (CDC 49);
- Ausência de responsabilização da academia por **acidente** (CDC 14, objetiva);
- Validar **termo de responsabilidade** como excludente;
- Admitir vendas **casadas** (CDC 39 I);
- Aplicar prescrição **trienal** à reparação por acidente de consumo (o prazo é quinquenal, CDC 27);
- Desconsiderar **suspensão** por doença/gravidez;
- Admitir cláusula de **fidelidade** sem razoabilidade;
- Admitir fechamento sem **comunicação** ou ressarcimento;
- Admitir cobrança **vexatória** (CDC 42).

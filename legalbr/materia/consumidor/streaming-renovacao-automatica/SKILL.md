# Streaming e Assinaturas: Renovação Automática

## Marco legal

- **CDC** Lei 8.078/1990;
- **Dec. 7.962/2013**: e-commerce;
- **LGPD** Lei 13.709/2018;
- **MCI** Lei 12.965/2014.

## Contratação

| | Conteúdo |
|---|---|
| Expressa | Necessária (CDC 6 III + 39 III) |
| Período de teste | Permitido com clareza |
| Conversão automática | Exige aviso **claro** |
| Adesão | Em geral clickwrap (CDC 54) |
| Termos restritivos | Destaque (CDC 54 §4) |
| Múltiplos planos | Diferenciação clara |

## Renovação automática

| | Conteúdo |
|---|---|
| Permitida | Sim, com transparência |
| Aviso prévio | Com antecedência razoável e comunicação clara (CDC 6 III) |
| Opt-out facilitado | Mesmo canal de contratação |
| Sem aviso | Cobrança indevida → dobra (CDC 42 par. único; EAREsp 676.608 STJ) |
| Cobrança com aumento de preço | Exige comunicação prévia, clara e com antecedência razoável (CDC 6 III) |

## Cancelamento

| | Conteúdo |
|---|---|
| **Mesmo canal** | App, site, e-mail |
| Sem retenção forçada | Vedada |
| **Sem multa** (se não há fidelidade contratada) | Direito potestativo |
| Confirmação | Imediata |
| Período pago já corrido | Aproveitável até final |
| Pro rata se cabível | Conforme contrato |

## CDC 39 III: envio sem solicitação

> "Enviar ou entregar ao consumidor, **sem solicitação prévia**, qualquer produto, ou fornecer qualquer serviço."

- Venda casada;
- Assinatura imposta;
- Período de teste convertido sem clareza;
- Equipara-se a amostra grátis (CDC 39 par. único: não gera obrigação).

## Cobrança após cancelamento

| | Conteúdo |
|---|---|
| Cobrança indevida | Dobra objetiva (EAREsp 676.608 STJ, após 30/03/2021) |
| Banco/cartão deve estornar | Operadora pode contestar |
| Plataforma da loja (Apple/Google) | Responsável pelo recurso |
| Estorno por chargeback | Direito |
| Dano moral | Em casos qualificados (não em erro isolado) |

## Período de teste

| | Conteúdo |
|---|---|
| Gratuidade | Vincula (CDC 30) |
| Conversão | Comunicação clara + opt-out fácil |
| Cartão exigido | Permitido com aviso |
| Cancelamento durante teste | Direito sem custo |
| Cobrança automática após teste | Permitida se houve aviso claro |

## Assinaturas via loja de app (Apple, Google)

| | Conteúdo |
|---|---|
| Gestão | Pelo sistema da loja |
| Cancelamento | App Store / Google Play (não pela empresa) |
| Estorno | Política da loja |
| Solidariedade | Loja + provedor: cadeia de fornecimento (CDC 7 par. único + 25 §1) |
| Disputa | Possível via plataforma |

## Compartilhamento de senha

- Discussão atual: plataformas passaram a cobrar por usuário;
- Termos de uso restritivos;
- Análise CDC 51 IV (vantagem exagerada);
- Mudança unilateral de termos = abusiva (CDC 39 III).

## Mudança unilateral de termos

| | Conteúdo |
|---|---|
| Aceita | Apenas com **aceitação ativa** |
| Aceitação tácita | Vedada (CDC 39 III) |
| Comunicação prévia | Com antecedência razoável |
| Direito do consumidor | Cancelar sem multa se mudança substancial |

## Dados pessoais (LGPD)

| | Conteúdo |
|---|---|
| Coleta | Mínima (princípio da necessidade) |
| Consentimento | Granular |
| Compartilhamento | Controlado |
| Direito de exclusão | Sim |
| Marketing | Opt-in |

## Cobrança de tributos

- Taxas (anuidade etc.): análise específica;
- Streaming é tributado por **ISS** (LC 116/2003, item 1.09, incluído pela LC 157/2016), não por ICMS (ADI 5.659 e 5.958 do STF afastaram o ICMS sobre software/serviços digitais);
- Repasse de tributos ao consumidor deve constar com transparência.

## Cláusulas inválidas

- "Sem direito a cancelamento";
- "Cancelamento apenas via telefone em horário restrito";
- "Aceitação tácita de novos termos";
- "Multa de fidelidade abusiva";
- "Cobrança continuada após cancelamento";
- "Renovação sem aviso";
- "Aumento de preço sem aviso".

## Streaming x serviços essenciais

- Não é essencial (mas é direito básico CDC 6);
- Interrupção indevida → defeito do serviço;
- Em geral não cabe dano moral em corte isolado;
- Cobrança indevida → dobra.

## Dano moral

| Caso | Cabível |
|---|---|
| Cobrança após cancelamento prolongada | Conforme as circunstâncias |
| Bloqueio injustificado de conta | Conforme as circunstâncias |
| Mudança de plano sem aviso | Caso a caso |
| Negativação por dívida indevida | In re ipsa |
| Mero aborrecimento | Não |

## Clubes de vantagens (gym, café, etc.)

- Mesma proteção;
- Cancelamento direto;
- Vedação a opt-out dificultado;
- Devolução proporcional.

## Trial / freemium

- "Gratuito" → não pode virar pago sem aceitação;
- "Premium" → característica clara.

## Erros a evitar

- Aceitar **renovação** sem aviso prévio;
- Validar cancelamento **dificultado** (CDC 6 III);
- Não aplicar **dobra** em cobrança pós-cancelamento (EAREsp 676.608 STJ);
- Aceitar **mudança unilateral** de termos sem aceitação ativa;
- Admitir **fidelidade** sem destaque (CDC 54 §4);
- Validar **conversão automática** de teste sem aviso claro;
- Aceitar cláusula que vede cancelamento;
- Aplicar prescrição **trienal** (CDC 27: 5 anos; repetição de indébito contratual: 10 anos, CC 205, STJ);
- Recusar tutela antecipada em **bloqueio indevido** prolongado;
- Aceitar **dados** coletados sem consentimento granular;
- Admitir cobrança por compartilhamento **retroativa** sem aceitação;
- Tratar tal contrato como **paritário** (é adesão, CDC 54).

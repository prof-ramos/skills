# Não-cumulatividade

## Bases constitucionais

| | Conteúdo |
|---|---|
| **CF 155 §2 I** | **ICMS NÃO-CUMULATIVO**: sistema **DÉBITO/CRÉDITO** |
| **CF 155 §2 II "a"** | Isenção ou não-incidência, salvo determinação em contrário, **NÃO implica crédito** para as operações seguintes |
| **CF 153 §3 II** | **IPI** não-cumulativo |
| **CF 195 §12** | **PIS/COFINS** não-cumulativo (mitigado) |

| | Conteúdo |
|---|---|
| **LC 87/96** (Kandir) | Regula ICMS |
| **Leis 10.637/02 + 10.833/03** | PIS/COFINS não-cumulativo |
| **LC 24/1975** | Exige **CONVÊNIO UNÂNIME no CONFAZ** para isenções + incentivos |

| | Conteúdo |
|---|---|
| Tese | **INCONSTITUCIONAL** concessão sem **CONFAZ unânime** |

## SÚMULAS

### CF 155 §2 II "a" (entrada isenta)
| | Conteúdo |
|---|---|
| Regra | Entrada **ISENTA** ou não tributada **NÃO gera crédito**, salvo determinação em contrário da legislação |

### Súm. 509 STJ
| | Conteúdo |
|---|---|
| Tese | É lícito ao comerciante de **BOA-FÉ** aproveitar créditos de ICMS de **nota fiscal posteriormente declarada inidônea**, demonstrada a veracidade da compra e venda |

### Súm. 411 STJ
| | Conteúdo |
|---|---|
| Tese | É devida **correção monetária** ao creditamento do **IPI** quando há oposição ao aproveitamento por **resistência ilegítima do Fisco** |

## STF Tema 756 (RE 841.979, Plenário, rel. Min. Dias Toffoli, 2022)

| | Conteúdo |
|---|---|
| Tese (item I) | O **LEGISLADOR ORDINÁRIO** possui **AUTONOMIA** para disciplinar a não cumulatividade do art. 195 §12 CF (**PIS/COFINS**), respeitados os demais preceitos constitucionais, como a matriz constitucional das contribuições e os princípios da razoabilidade, isonomia, livre concorrência e proteção à confiança |
| Tese (item II) | É **INFRACONSTITUCIONAL** (sem repercussão geral) a discussão sobre a expressão **insumo** do art. 3º II das Leis 10.637/02 e 10.833/03: preservado o **REsp 1.221.170/PR** (STJ, **ESSENCIALIDADE + RELEVÂNCIA**) |

## STJ: crédito presumido de ICMS (EREsp 1.517.492)

| | Conteúdo |
|---|---|
| Tese | **CRÉDITOS PRESUMIDOS de ICMS EXCLUEM-SE** da base de **IRPJ/CSLL** |
| Razão | Inclusão violaria o **PACTO FEDERATIVO** (esvaziaria incentivo estadual) |

## STJ Tema 1.182

| | Conteúdo |
|---|---|
| Tese | **DEMAIS BENEFÍCIOS de ICMS** (redução base + alíquota + diferimento) **SÓ se EXCLUEM** se cumpridos **art. 30 da Lei 12.973/2014** + **art. 10 da LC 160/2017** |
| Superado | Parcialmente pela **Lei 14.789/2023** |

|---|---|
| Tese | **DIFAL/EC 87/2015** exige **LC** |

| | Conteúdo |

## Distinções essenciais

| | ICMS/IPI | PIS/COFINS |
|---|---|---|
| Não-cumulatividade | **PLENA** (CF) | **Mitigada** (CF 195 §12 + lei) |

| | Crédito presumido (EREsp 1.517.492) | Demais benefícios (Tema 1.182) |
|---|---|---|
| IRPJ/CSLL | **EXCLUI** automaticamente | **SÓ se cumprir** art. 30 |

| | Entrada isenta (CF 155 §2 II "a") | Boa-fé em nota inidônea (Súm. 509) |
|---|---|---|
| Crédito | **VEDADO** | **PROTEGIDO** |

| | Insumo | Despesa |
|---|---|---|
| Conceito | **Essencialidade + relevância** (REsp 1.221.170) | Não creditável |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| ICMS entrada isenta | **Sem crédito** (CF 155 §2 II "a") |
| Adquirente de boa-fé em nota declarada inidônea | **Protegido** (Súm. 509) |
| Crédito presumido ICMS | **Exclui IRPJ/CSLL** (EREsp 1.517.492) |
| Subvenção ICMS pós-Lei 14.789/2023 | Regime do **crédito fiscal** (Lei 14.789) |
| Concessão sem CONFAZ | **INCONSTITUCIONAL** (LC 24) |
| Insumo essencial | **CREDITÁVEL** (REsp 1.221.170) |
| Insumo não essencial nem relevante | **Não creditável** (REsp 1.221.170; matéria infraconstitucional, Tema 756 item II) |
| DIFAL pré-LC 190 | **VEDADO** (ADI 5.469) |
| Resistência fiscal + crédito escritural | **Correção** (Súm. 411) |
| ICMS monofásico combustíveis | **LC 192/2022** |

## Erros a evitar

- Admitir **crédito em entrada ISENTA** sem previsão legal (CF 155 §2 II "a");
- Negar o crédito ao **adquirente de BOA-FÉ** em nota posteriormente declarada inidônea (Súm. 509);
- Tributar **crédito presumido ICMS** no IRPJ/CSLL (EREsp 1.517.492 STJ);
- Excluir **demais benefícios** sem cumprir art. 30 (Tema 1.182);
- Admitir **incentivo sem CONFAZ** (LC 24, unânime);
- Aplicar **conceito restritivo de insumo** (Tema 756 + REsp 1.221.170);
- Aplicar **DIFAL pré-LC 190/2022** (ADI 5.469);
- Negar **correção monetária** do crédito de IPI ante resistência ilegítima do Fisco (Súm. 411);
- Tratar **PIS/COFINS** como não-cumulativo pleno (é mitigado);
- Confundir **ICMS** com **PIS/COFINS** (regimes distintos);
- Tratar o **conceito de insumo** de PIS/COFINS como questão constitucional (Tema 756, item II: matéria **infraconstitucional**, definida pelo STJ no REsp 1.221.170).

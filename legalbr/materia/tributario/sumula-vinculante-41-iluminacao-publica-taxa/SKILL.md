# Súmula Vinculante 41, Iluminação Pública não pode ser Taxa

## Texto integral

> "O **serviço de iluminação pública** **NÃO pode** ser **remunerado** mediante **TAXA**."

## Bases normativas

| | Conteúdo |
|---|---|
| **CF 145 II** | Taxa: serviço público **específico** + **divisível** (uti singuli) |
| **CF 149-A** | **COSIP** (Contribuição para o custeio da Iluminação Pública), competência **municipal/DF**, incluído pela **EC 39/2002** |
| **CTN art. 77 § único** | Veda taxa em serviço uti universi |
| **STF Súm. 670** | Antiga: "O serviço de iluminação pública não pode ser remunerado mediante taxa" |

## Precedente paradigma

| | Conteúdo |
|---|---|
| Caso | **RE 573.675/SC** |
| Relator | Min. **Ricardo Lewandowski** |
| Julgamento | **25/03/2009** (Plenário, Repercussão Geral) |
| **Tema RG** | **44** |
| Súm. 670 | Antecessora, aprovada em 2003 |
| Aprovação SV 41 | **11/03/2015** |
| Tese | Iluminação é uti universi (indivisível + não específica), incompatível com taxa; solução é COSIP (CF 149-A) |

## Núcleo

| | Conteúdo |
|---|---|
| Iluminação pública | Serviço **uti universi**, beneficia toda a coletividade |
| Inviabilidade de **divisão** | Não é possível mensurar quanto cada cidadão "consome" |
| Inviabilidade de **especificação** | Serviço prestado em **vias públicas**, não a usuários individualmente identificados |
| Por isso | **NÃO** se enquadra como taxa (CF 145 II) |
| Solução constitucional | **COSIP** (CF 149-A + EC 39/2002), contribuição **sui generis** |
| Modulação | Sem necessidade, Súm. 670 já era jurisprudência consolidada |

## COSIP (CF 149-A)

| | Conteúdo |
|---|---|
| Competência | **Municípios + DF** |
| Natureza | **Contribuição sui generis**, não é imposto nem taxa |
| Base | **Lei municipal** + opcional **cobrança na fatura de energia elétrica** (CF 149-A § único) |
| Fato gerador típico | Imóvel servido pela rede de iluminação pública |
| Critério de **graduação** | Geralmente **consumo de energia elétrica** (proxy do uso do imóvel) |
| **RE 573.675** | Validou COSIP, graduação por consumo de energia é constitucional |
| **Tema 696** (RE 666.404) | É **constitucional** destinar os recursos da COSIP também à **expansão e aprimoramento** da rede de iluminação |

## Aplicação prática

| Hipótese | Saída |
|---|---|
| Município institui **taxa** de iluminação pública | **INCONSTITUCIONAL** (SV 41) |
| Município institui **COSIP** com cobrança na fatura | **CONSTITUCIONAL** (CF 149-A) |
| COSIP **graduada por consumo** de energia | OK (RE 573.675) |
| COSIP **graduada por área do imóvel** | OK |
| COSIP custeando **expansão/aprimoramento** da rede | OK (Tema 696, RE 666.404) |
| **Taxa** rotulada como "iluminação" mas usada para outro fim | Análise da substância, se a destinação for iluminação, é inconstitucional |
| Município **utiliza COSIP** para **outras destinações** (caixa geral) | Inconstitucional, afetação obrigatória |

## Casos correlatos

| | Conteúdo |
|---|---|
| **RE 573.675** (Tema 44) | Paradigma da SV 41 e validou COSIP |
| **Súm. 670 STF** | Antecessora |
| **SV 19** | Coleta domiciliar de lixo OK (contraste, uti singuli) |
| **SV 29** | BC da taxa pode ter elemento de imposto (correlata na lógica de taxas) |
| **Tema 696 STF** (RE 666.404) | Destinação da COSIP à expansão/aprimoramento da rede, válida |
| **SV 41** | Vinculante: iluminação pública não pode ser taxa |

## Distinguishing

| Hipótese | Saída |
|---|---|
| Taxa de **coleta domiciliar de lixo** | OK (SV 19, uti singuli) |
| Taxa de **iluminação pública** | **VEDADA** (SV 41) |
| Taxa de **limpeza pública** (varrição) | **VEDADA** (uti universi) |
| Taxa de **segurança pública** | **VEDADA** (uti universi) |
| **COSIP** sobre iluminação pública | **OK** (CF 149-A) |
| **COSIP** com cobrança via fatura de energia | OK (CF 149-A § único) |
| COSIP que **abrange ampliação** + **manutenção** do sistema | OK (CF 149-A) |
| Taxa pretendida como "Taxa de Conservação de Iluminação" | Inconstitucional, substância é iluminação |
| **Contribuição de melhoria** sobre instalação de iluminação | Discutível, pressupõe valorização imobiliária (CF 145 III) |

## Erros a evitar

- Cobrar **taxa** de iluminação pública sob qualquer rótulo (SV 41 + Súm. 670);
- Considerar iluminação pública como **uti singuli** (é uti universi);
- Confundir SV 41 com **SV 19** (coleta domiciliar OK, iluminação vedada);
- Aceitar **lei municipal** que institua taxa de iluminação (inconstitucional);
- Tratar **COSIP** como **taxa** (institutos distintos);
- Aplicar **CTN 77** à COSIP (a COSIP é contribuição, não taxa);
- Impugnar a cobrança da COSIP **na fatura de energia** (CF 149-A § único a autoriza);
- Aplicar a **SV 41** à COSIP (a SV é sobre taxa, não atinge a contribuição);
- Cobrar COSIP **sem destinação** específica (afetação ao custeio da iluminação);
- Aplicar **COSIP só sobre consumidores cativos** ignorando livres (análise concreta, geralmente todos são alcançados);
- Ignorar que cabe **reclamação** ao STF por descumprimento da SV (CF 102 I "l" + 103-A §3);
- Tratar a SV 41 como mera repetição sem efeito (a SV 41 tem eficácia **vinculante**, diferentemente da Súm. 670);
- Conceder **isenção de COSIP** sem lei municipal específica;
- Aceitar lei municipal que crie **taxa rotulada de outra forma** mas com mesma BC do consumo energético (substância é iluminação);
- Aplicar a SV 41 a serviços diversos como **manutenção viária** ou **paisagismo** (escopo restrito à iluminação).

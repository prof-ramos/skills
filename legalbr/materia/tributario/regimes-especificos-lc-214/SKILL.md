# Regimes Específicos

## Base legal

| | Conteúdo |
|---|---|
| **CF 156-A §6 II** | Lista de setores com regime específico |
| **LC 214/2025, Título V** | Detalha os regimes específicos (capítulos por setor) |
| **Decreto 12.955/2026 + Resolução CGIBS 6/2026** | Regulamentos da CBS (DOU 30/04/2026) e do IBS detalham os regimes específicos (disposições comuns na Portaria Conjunta MF/CGIBS 7/2026) |
| Convivência | Coexistem com regimes diferenciados (reduções) e regime ordinário |

## 1. Combustíveis (LC 214, Título V, regime monofásico)

| | Conteúdo |
|---|---|
| Regime | **Monofásico ad rem** (R$ por litro/m³/kg) |
| Quem recolhe | **Refinaria/produtor/importador** (CG-IBS centraliza) |
| Crédito | **Pleno** ao adquirente para revenda (cadeia); vedado ao consumidor final |
| Distribuição | CG-IBS distribui ao **destino** (Estado/Município do consumo) |
| Convivência | Sem ICMS-Combustíveis (LC 192/22) a partir de 2033 |
| Fixação | Alíquotas ad rem uniformes nacionalmente |

## 2. Serviços financeiros + seguros + planos de saúde + previdência (LC 214, Título V)

| Subgrupo | Base de cálculo |
|---|---|
| Bancos / instituições financeiras | **Spread bancário + tarifas + comissões** (não margem bruta) |
| Seguros | **Prêmio líquido** (sinistros + resseguros excluídos parcialmente) |
| Planos de saúde | **Receita líquida** (sinistralidade considerada) |
| Previdência privada | **Diferença** entre contribuições e benefícios |
| Capitalização | Receita do título − provisões matemáticas |
| Fundos de investimento | Em regra **não são contribuintes**; há exceções expressas (ex.: FII/Fiagro fora das condições legais, fundos que liquidam antecipadamente recebíveis); administração/gestão de fundos é serviço financeiro tributado |

| | Alíquotas |
|---|---|
| IBS + CBS | Específicas do setor financeiro, definidas na LC 214 |
| Reduções | Algumas (planos de saúde: redução 60% por hibridismo serviço-saúde) |

## 3. Bens imóveis (LC 214, Título V)

| | Conteúdo |
|---|---|
| Operações abrangidas | Venda + locação + cessão + permuta + administração + incorporação |
| Base | **Valor da operação** com **redutor social** (valor fixo que protege a moradia popular) |
| Locação residencial | Alíquota reduzida + redutor de aluguel social |
| Locação comercial | Alíquota cheia (com possibilidade de cumulativo opcional) |
| Construção civil | Crédito + débito padrão |
| **Regime cumulativo opcional** | Para alguns segmentos (incorporadoras + locadoras): recolhe sobre a receita sem crédito, com alíquota menor |

| | Detalhe |
|---|---|
| ITBI | **Convive** (Município); IBS incide sobre a operação econômica |
| Imunidade na integralização (ITBI) | CF 156 §2 I; **não alcança** o valor dos bens que exceder o capital a ser integralizado (Tema 796 STF) |

## 4. Cooperativas (LC 214, Título V)

| | Conteúdo |
|---|---|
| Regime | **Favorecido** (CF 146 III "c") |
| Ato cooperativo | **NÃO incide** IBS+CBS (mantém Lei 5.764/71 art. 79) |
| Ato não-cooperativo (com terceiros) | Tributação normal |
| Crédito | Sobre insumos de operações tributadas |

## 5. Hotelaria + parques + restauração + agências + aviação regional + SAF (LC 214, Título V)

| Setor | Regime |
|---|---|
| Hotelaria | **Simplificado** sobre diárias + serviços agregados |
| Parques (temáticos/aquáticos) | Simplificado |
| **Bares + restaurantes** | Simplificado: receita bruta com alíquota reduzida (substitui o crédito amplo) |
| Agências de viagem | Sobre comissão/margem |
| **Aviação regional** | Regime específico (LC 214 arts. 284 e ss.): voos com origem/destino na Amazônia Legal ou em capitais regionais e centros regionais |
| **SAF (Sociedade Anônima do Futebol)** | Regime específico (Lei 14.193/2021) |

## 6. Loterias + apostas + concursos (LC 214, Título V)

| | Conteúdo |
|---|---|
| Base | **GGR** (Gross Gaming Revenue) = apostas − prêmios pagos |
| Alíquota | Específica (segue padrão internacional do setor) |
| Loterias federais (Caixa) | Regime próprio (mantém afetação a saúde/educação/esporte) |
| Apostas de quota fixa (Lei 14.790/23) | Convivência com tributação federal específica + IBS+CBS |

## 7. Operações com bens móveis usados (LC 214, Título V)

| | Conteúdo |
|---|---|
| Critério | Pessoa física vendedora não-contribuinte |
| Adquirente revendedor | Tributação pela **margem** (≠ valor total) |
| Exemplo | Concessionária de carros usados |

## 8. Serviços de comunicação (LC 214)

| | Conteúdo |
|---|---|
| Telecom | Regime ordinário com particularidades (apuração centralizada) |
| Streaming | Tributação normal |
| Radiodifusão livre | Imunidade preservada (CF 220) |

## 9. Transporte de carga + serviços portuários/aeroportuários

| | Conteúdo |
|---|---|
| Transporte de carga | **Regime ordinário** (a redução de 60% é só do transporte coletivo de passageiros); o transporte de carga **aéreo regional** tem regime específico (LC 214 art. 284) |
| Serviços portuários | Regime específico (consideração de "valor agregado") |

## 10. Energia elétrica + gás canalizado

| | Conteúdo |
|---|---|
| Distribuidoras/comercializadoras | Regime específico, com apuração mensal centralizada |
| **Residencial baixa renda** | **Cashback 100%** (CF 156-A §5 VIII) |

## Convivência com regimes diferenciados

| | Específico | Diferenciado |
|---|---|---|
| Definição | Regra de **apuração** ou base | Redução de **alíquota** |
| Combustíveis | **SIM** (monofásico) | **NÃO** (não há redução) |
| Planos de saúde | **SIM** (receita líquida) | **SIM** (redução 60% saúde); combinam-se |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Refinaria vendendo gasolina | **Monofásico ad rem** centralizado |
| Banco (tarifa e spread) | **Receita líquida** |
| Seguradora (prêmio) | Prêmio − sinistros excluídos parcialmente |
| Plano de saúde | Receita líquida + redução 60% |
| Incorporadora | Operação imobiliária + redutor social + opcional cumulativo |
| Locação residencial | Reduzida + redutor de aluguel social |
| Cooperativa (ato cooperativo) | **NÃO incide** |
| Restaurante | Simplificado sobre receita |
| SAF | Regime específico (Lei 14.193) |
| Loteria/aposta | **GGR** (apostas − prêmios) |
| Concessionária carros usados | Tributação pela **margem** |

## Erros a evitar

- Tributar combustíveis pela **regra geral** (é monofásico ad rem, LC 214 arts. 172 e ss.);
- Aplicar IBS+CBS a banco sobre **receita bruta** (a base é a receita dos serviços: spread + tarifas);
- Tributar **ato cooperativo** (não incide: Lei 5.764 art. 79 + LC 214);
- Aplicar redução 60% a **transporte de carga** (só transporte coletivo de **passageiros**);
- Ignorar que a imunidade do **ITBI na integralização** não alcança o valor que exceder o capital integralizado (Tema 796 STF);
- Tributar locação residencial **sem redutor social** (LC 214 prevê);
- Aplicar regime ordinário a **incorporadora** que optou pelo cumulativo;
- Tributar apostas sobre **receita bruta** (é GGR: apostas − prêmios);
- Tratar **SAF** como sociedade anônima comum (regime específico);
- O **cashback de 100%** alcança energia residencial baixa renda;
- Aplicar regime de **móveis usados** a contribuinte revendedor adquirindo de outro contribuinte (regra só quando PF vendedora);
- Aplicar **regime simplificado** de restaurante e exigir crédito amplo (o regime substitui, sem créditos);
- Tratar **fundo de investimento** como contribuinte em regra (só nas exceções expressas da LC 214);
- Tratar **radiodifusão livre** como tributável (imunidade CF 220);
- Não considerar a transição em 2026 (regimes ainda em teste: 0,1%/0,9%);
- Aplicar SISTEMA antigo (PIS/COFINS bancos = receita líquida + IOF seguros) sem ajustar para a nova mecânica (LC 214 redefine bases).

# Súmula Vinculante 29, Base de Cálculo de Taxa com Elementos de Imposto

## Texto integral

> "É **constitucional** a adoção, no cálculo do valor de **taxa**, de **um ou mais elementos** da base de cálculo própria de **determinado imposto**, desde que **NÃO haja integral identidade** entre uma base e outra."

## Bases normativas

| | Conteúdo |
|---|---|
| **CF 145 II** | Taxa por poder de polícia ou serviço específico e divisível |
| **CF 145 §2** | **Taxas NÃO poderão ter BC própria de impostos** |
| **CTN art. 77 § único** | Repete a vedação |
| **CTN art. 79** | Definição de serviço específico e divisível |
| **CF 5 LIV** | Razoabilidade/proporcionalidade do quantum tributário (devido processo substantivo) |

## Precedente paradigma

| | Conteúdo |
|---|---|
| Caso central | **RE 232.393/SP** |
| Relator | Min. **Carlos Velloso** |
| Julgamento | **12/08/1999** (Plenário) |
| ADI correlata | **ADI 2.551/MG** (Min. Celso de Mello) |
| Aprovação SV 29 | **03/02/2010** (DJe de 17/02/2010) |
| Tese | A vedação do art. 145 §2 alcança **identidade integral**, não veda **elementos** isolados |

## Núcleo

| | Conteúdo |
|---|---|
| Vedação **literal** | Taxa não pode ter BC própria de imposto |
| Interpretação **STF** | A vedação é **substancial**, não meramente formal, atinge **identidade integral** |
| **Admite** | Adoção de **um ou mais elementos** (área, valor venal parcial, faturamento parcial) |
| **Veda** | Cópia **integral** da BC do imposto |
| **Equivalência razoável** (ADI 2.551) | Valor da taxa deve guardar **proporcionalidade** com o **custo real** da atividade estatal |

## Aplicação prática

| Hipótese | Saída |
|---|---|
| Taxa de **lixo** calculada por **área do imóvel** (também usada no IPTU) | **OK** (elemento comum) |
| Taxa de lixo calculada por **valor venal** integral (BC própria do IPTU) | **INCONSTITUCIONAL** (identidade) |
| Taxa de **fiscalização** com base em **faturamento** parcial | OK (elemento) |
| Taxa de fiscalização = % do **faturamento bruto** (BC do ICMS/ISS) | **Discutível**, risco de identidade |
| **TCFA** (Ibama, Lei 10.165/2000), valor fixo conforme porte e potencial poluidor | OK (constitucional segundo a jurisprudência do STF) |
| Taxa judiciária **ad valorem sem teto** | **INCONSTITUCIONAL** (Súm. 667 STF), viola razoabilidade |
| Taxa judiciária **ad valorem com teto** | OK (razoável) |
| Taxa de polícia administrativa com base em **patrimônio** | Requer análise de identidade |

## Equivalência razoável (ADI 2.551)

| | Conteúdo |
|---|---|
| Princípio | Taxa não é mero rótulo, deve corresponder a **custo real** da atividade |
| Excesso | Valor desproporcional ao custo do serviço/polícia é **inconstitucional** |
| Fundamento | Razoabilidade (CF 5 LIV) + vedação do confisco (CF 150 IV) |

## Casos correlatos

| | Conteúdo |
|---|---|
| **RE 232.393** | Paradigma, taxa de lixo com elemento de IPTU |
| **ADI 2.551** | Equivalência razoável entre o valor da taxa e o custo da atuação estatal |
| **SV 19** | Taxa de coleta domiciliar OK |
| **SV 41** | Iluminação NÃO é taxa |
| **Súm. 667 STF** | Taxa judiciária ad valorem sem teto inconstitucional |
| **Tema 16 STF** | Taxa municipal de combate a incêndio (segurança pública): **inconstitucional**; taxas estaduais de bombeiros são constitucionais (Tema 1.282) |
| **ARE 990.094** | Reafirma SV 29 |
| **RE 554.951** | Taxa de fiscalização sanitária |

## Distinguishing

| Hipótese | Saída |
|---|---|
| Taxa lixo com **área + frequência da coleta** | OK (SV 29) |
| Taxa lixo com **valor venal** integral | **VEDADO** |
| Taxa polícia ambiental com **porte da empresa** | OK |
| Taxa polícia com **lucro líquido** integral (BC do IRPJ) | **VEDADO** |
| Taxa judiciária com **valor da causa** + teto razoável | OK |
| Taxa judiciária com **valor da causa** sem teto | **VEDADO** (Súm. 667) |
| Taxa de fiscalização **fixa por categoria** | OK |
| Taxa com BC = **faturamento** integral | **Risco de identidade com ICMS/ISS**, análise concreta |
| Taxa proporcional ao **número de funcionários** | Geralmente OK |
| Taxa de **incêndio** municipal | **INCONSTITUCIONAL** (Tema 16: segurança pública); a estadual de bombeiros é constitucional (Tema 1.282) |

## Erros a evitar

- Considerar **inconstitucional** qualquer taxa que use **algum elemento** comum a imposto (SV 29 permite);
- Aplicar **CF 145 §2** literalmente, sem distinguir **identidade** de **elemento**;
- Aceitar taxa com **identidade integral** sob argumento de "interesse arrecadatório";
- Ignorar a **equivalência razoável** (ADI 2.551), taxa deve corresponder ao custo;
- Tratar **TCFA** como inconstitucional (a jurisprudência do STF a valida);
- Aceitar taxa judiciária **ad valorem sem teto** (Súm. 667);
- Confundir taxa com **imposto** quando há proporcionalidade ao custo;
- Aplicar SV 29 a **preço público** ou **tarifa** (regime contratual, fora do escopo);
- Tratar a vedação do **art. 145 §2** como mera recomendação;
- Aplicar a SV 29 sem analisar **identidade substancial** entre BCs;
- Considerar BC de taxa **inconstitucional** sob argumento meramente terminológico;
- Invalidar **taxa de lixo** apenas por usar elemento da base de imposto (a SV 29 autoriza);
- Aplicar **SV 29** para validar taxa com **valor manifestamente excessivo** (princípio da equivalência razoável);
- Tratar elementos comuns como **bis in idem** (não há, institutos diversos);
- Aplicar **SV 29** apenas a impostos municipais (alcança todos os impostos, federais/estaduais/municipais).

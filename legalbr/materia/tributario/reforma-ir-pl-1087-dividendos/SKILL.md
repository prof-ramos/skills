# Reforma IR, Lei 15.270/2025 (ex-PL 1.087/2025)

## Marco legal

- **Lei 15.270/2025** (sancionada em 26/11/2025; efeitos a partir de 01/01/2026);
- **Lei 9.249/1995** (alterada);
- **Lei 9.250/1995** (alterada);
- **Lei 14.973/2024** (atualização patrimonial, interface);
- **Lei 14.754/2023** (offshores + trust);
- **EC 132 + LC 214/2025** (Reforma Tributária do consumo, paralela);
- **CTN** + **RIR/2018**.

## Histórico

| Período | Tratamento |
|---|---|
| **1923-1995** | Dividendos tributados |
| **Lei 9.249/1995** | **Isenção total** de dividendos |
| **Lei 15.270/2025** (ex-PL 1.087) | **Reintrodução parcial** da tributação |
| **Vigência** | A partir de **01/01/2026** |

## Duas medidas principais

### 1. Isenção IRPF (Lei 15.270/2025)

| Faixa de renda | Tratamento |
|---|---|
| **Até R$ 5.000/mês** | **Isenção total** (redução = imposto apurado) |
| **R$ 5.001 a R$ 7.350/mês** | **Redução decrescente** linear |
| **Acima R$ 7.350/mês** | Tabela progressiva tradicional |
| **Vigência** | **2026** |
| **Impacto social** | Inclusão de milhões |

### 2. Tributação de dividendos (Lei 15.270/2025)

| | Conteúdo |
|---|---|
| **IRRF (na fonte)** | **10%** |
| **Base** | Dividendos distribuídos no mês |
| **Limite de incidência** | Acima de **R$ 50.000/mês** por PJ pagadora a mesma PF |
| **Cumulativo no mês** | Distribuição agregada por PJ |
| **Vigência** | **2026** |
| **Aplica-se** | Dividendos pagos/creditados a partir de 01/01/2026 |

## Regra de transição (Lei 15.270/2025)

| | Conteúdo |
|---|---|
| **Lucros deliberados** até **31/12/2025** | **Isentos** (regime atual mantido) |
| **Pagamento** | Pode ocorrer 2026-2028 |
| **Documentação** | Ata + decisão societária |
| **Estímulo** | Antecipação de distribuição |
| **Holdings + PJ** | Atenção ao planejamento |

## IRPFM (Imposto de Renda da Pessoa Física Mínimo)

| | Conteúdo |
|---|---|
| **Nova categoria** | Tributação mínima anual (Lei 9.250 art. 16-A, incluído pela Lei 15.270/2025) |
| **Aplicação** | Soma de todos os rendimentos do ano-calendário **superior a R$ 600.000** |
| **Base** | Soma de rendimentos (tributados + isentos + exclusivos na fonte, com exclusões legais) |
| **Inclui** | Dividendos + ganhos de capital + outros |
| **Alíquota** | Cresce **linearmente de 0 a 10%** entre R$ 600 mil e R$ 1,2 milhão (fórmula: alíquota % = REND/60.000 - 10); **10%** para rendimentos ≥ R$ 1,2 milhão |
| **Vigência** | 2026 |

## Mecanismo do IRPFM

| Etapa | Conteúdo |
|---|---|
| 1. **Apurar todos os rendimentos** anuais | Incluindo isentos |
| 2. **Calcular IR efetivo** total pago | Tabela + retenção |
| 3. **Comparar com o mínimo** da faixa | Se efetivo < mínimo |
| 4. **Recolher diferença** | Anual |
| 5. **DIRPF** | Ajuste |

## Quem é afetado

| | Conteúdo |
|---|---|
| **Acionistas/cotistas PF** | Recebendo > R$ 50k/mês de dividendos |
| **Altas rendas** | Em geral (renda total > limite) |
| **Sócios de empresas profissionais** | Atenção |
| **Holdings familiares** | Atenção |
| **PF com PJ no exterior** | Lei 14.754 + Lei 15.270/2025 |

## Estrutura do IRRF dividendos

| | Conteúdo |
|---|---|
| **Mensal** | Retenção pela PJ pagadora |
| **Por PJ** | Cada empresa contabiliza separado |
| **Múltiplas PJs** | Soma com cuidado |
| **DARF** | Pela PJ pagadora |
| **Compensável** | Com IRPF ajuste anual |

## Exemplo prático

| | Valor |
|---|---|
| Distribuição mensal de PJ X para PF | R$ 80.000 |
| Limite isento | R$ 50.000 |
| Excesso | R$ 30.000 |
| **IRRF 10%** | R$ 3.000 |
| Líquido recebido | R$ 77.000 |
| (Pode ser compensado no IRPF anual) |

## Erros a evitar

- Tratar dividendos como **isentos** após 2026 (Lei 15.270/2025, tributados a 10% na fonte sobre o que excede R$ 50k/mês por PJ pagadora);
- Esquecer a **transição**: lucros deliberados até 31/12/2025 + pagos 2026-2028 ficam isentos;
- Confundir **IRRF dividendos** (10%) com **IRPFM** (mínimo anual para rendas > R$ 600 mil);
- Aplicar IRRF a distribuições **< R$ 50.000/mês** por PJ (não incide);
- Esquecer **soma por PJ** (não por PF total), múltiplas empresas contam separado;
- Aplicar **alíquota progressiva** sobre dividendos (é fixa 10% na fonte);
- Tratar a **Lei 15.270/2025** como mero projeto (já está sancionada e em vigor desde 01/01/2026);
- Confundir com a **Reforma Tributária do consumo** (EC 132, IBS/CBS);
- Aplicar a **isenção de R$ 5.000** sem observar a redução decrescente até R$ 7.350;
- Esquecer o **IRPFM** e a compatibilização com o IRPF tradicional.

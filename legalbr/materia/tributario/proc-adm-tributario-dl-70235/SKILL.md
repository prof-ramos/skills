# Processo Administrativo Tributário

## Marco legal

| | Conteúdo |
|---|---|
| **DL 70.235/1972** | PAF federal |
| **Lei 9.784/99** | **SUBSIDIÁRIA** |

## Estrutura bifásica

| | Conteúdo |
|---|---|
| **1ª instância** | **DRJ** (Delegacia da RFB de Julgamento) |
| **2ª instância** | **CARF** + **CSRF** (Câmara Superior, via recurso especial) |

### CARF
| | Conteúdo |
|---|---|
| Paridade | **Fazenda + contribuintes** |
| Recurso voluntário | **Contribuinte vencido** |
| Recurso de ofício | **Fazenda vencida (automático)** |

## Lançamento

| | Conteúdo |
|---|---|
| Início | **Auto de infração** |
| Fase litigiosa | **IMPUGNAÇÃO TEMPESTIVA** |
| Suspensão | **CTN 151 III** |
| Garantia | **Contraditório + ampla defesa** (CF 5 LV) |

## Vedações

| | Conteúdo |
|---|---|
| **SV 21 + Súm. 373 STJ** | **VEDA depósito/arrolamento prévios** como condição recursal |

## ATUALIZAÇÃO 2026: LC 227/2026 (art. 173)

| | Conteúdo |
|---|---|
| **Impugnação** | De 30 dias corridos para **20 DIAS ÚTEIS** (DL 70.235 art. 15, red. LC 227/2026) |
| **Recesso processual** | Suspensão dos prazos de **20/12 a 20/01**, sem sessões de julgamento no período (art. 5º-A) |
| **Prazo subsidiário** | **10 dias úteis** quando não houver prazo expresso (art. 5º-B) |
| **Contagem** | Dias corridos, salvo disposição em contrário; exclui-se o dia do início e inclui-se o do vencimento (art. 5º) |

## VOTO DE QUALIDADE

### Histórico
| Lei | Conteúdo |
|---|---|
| **Lei 13.988/2020** (art. 19-E) | **REVOGOU** voto qualidade: empate **PRÓ-CONTRIBUINTE** |
| **Lei 14.689/2023** | **RESTABELECEU** voto qualidade **PRÓ-FAZENDA** |

### Compensações (Lei 14.689)
| | Conteúdo |
|---|---|
| (i) | **AFASTAMENTO de MULTAS** (qualificada + mora) quando crédito mantido por voto qualidade |
| (ii) | **EXCLUSÃO de representação fiscal** para fins penais |
| (iii) | **PARCELAMENTO** em **12x sem juros** |
| (iv) | Utilização de **PREJUÍZO FISCAL/base negativa CSLL** |
| (v) | **LIMITAÇÃO** de honorários sucumbenciais |

### ADIs pendentes
| | Conteúdo |
|---|---|
| **ADI 7.548** (Partido Novo) | Contra os arts. 1º e 17, II, da **Lei 14.689/2023** (restabelecimento do voto de qualidade); rel. Min. Edson Fachin |
| **ADIs 7.347 (OAB) + 7.353 (PP/Republicanos)**, entre outras | Contra a **MP 1.160/2023** (que antecipara o restabelecimento); rel. Min. Dias Toffoli; tratativas de acordo institucional nos autos |
| Status | **SEM julgamento de mérito**; o voto de qualidade da Lei 14.689/2023 permanece aplicável |

## STF Tema 487

| | Conteúdo |
|---|---|
| Multa isolada **vinculada a tributo** | **MÁX 60%** (100% com agravantes) |
| Multa isolada **sem vínculo** | **MÁX 20%** (30% com agravantes) |

## STF Tema 863

| | Conteúdo |
|---|---|
| Multas **QUALIFICADAS** (fraude/sonegação/conluio) | **TETO 100%** |
| Reincidência | **150%** |

## Distinções essenciais

| | Pré-LC 227/2026 | Pós-2026 |
|---|---|---|
| Impugnação | 30 dias corridos | **20 dias úteis** |
| Recesso | NÃO | **20/12-20/01** |

| | Pré-Lei 14.689 | Pós-2023 |
|---|---|---|
| Empate | Pró-contribuinte | **Pró-Fazenda** |
| Multa | Cobrada | **Afastada** se mantido por voto |

| | Multa qualificada | Isolada |
|---|---|---|
| Teto STF | **100-150%** (Tema 863) | **60% (vinculada) / 20%** (Tema 487) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Impugnação tempestiva | **Suspende** (CTN 151 III) |
| Empate no CARF | **Voto qualidade pró-Fazenda** + multas afastadas |
| Multa isolada com vínculo | **MÁX 60%** (Tema 487) |
| Multa isolada sem vínculo | **MÁX 20%** |
| Multa qualificada | **100%** + reincidência 150% (Tema 863) |
| Depósito prévio para recurso | **VEDADO** (SV 21) |
| Prazo sem previsão expressa pós-LC 227 | **10 dias úteis** (art. 5º-B) |
| Recesso 20/12-20/01 | **Suspende prazo** |
| Multa de mora qualificada se empate | **Afastada** (Lei 14.689) |
| Crédito mantido em voto qualidade | **Sem representação penal** |

## Erros a evitar

- Exigir **depósito prévio** para impugnação/recurso adm (SV 21 + Súm. 373);
- Aplicar o **prazo de 30 dias** à impugnação pós-LC 227/2026 (é 20 dias úteis);
- Aplicar **prazo corrido** quando lei diz **úteis**;
- Cobrar o crédito durante o PAF (a exigibilidade fica **suspensa**: CTN 151 III);
- Aplicar **multa qualificada > 100%** salvo reincidência (Tema 863);
- Aplicar **multa isolada > 60% (vinculada) ou > 20% (sem vínculo)** (Tema 487);
- Tratar **Lei 14.689 sem aplicar afastamento de multas**;
- Aplicar **Lei 13.988 art. 19-E** como vigente (revogada);
- Admitir **representação penal** quando crédito mantido por voto qualidade;
- Aplicar **prazo CPC** ao PAF (especial);
- Ignorar a **CSRF** como instância de recurso especial para uniformização.

# FUNRURAL

## Base legal

| | Conteúdo |
|---|---|
| **CF 195 I "b"** | Contribuição patronal — sobre **receita ou faturamento** |
| **CF 195 §8** | Produtor rural em **regime de economia familiar** — facultativo |
| **Lei 8.212/1991 art. 25** | Contribuição rural — produtor rural PF + PJ |
| **Lei 8.540/1992** | Instituiu contribuição rural patronal |
| **Lei 9.528/1997** | Manteve contribuição PF rural |
| **Lei 10.256/2001** | Reinstituiu pós-EC 20/98 (corrigiu inconstitucionalidade) |
| **Lei 13.606/2018** | Reduziu alíquota PF — 1,2% (de 2,1%) |
| **MP 793/2017** + **Lei 13.606/18** | PERT-Rural + opção pela folha |

## Histórico jurisprudencial

| | Conteúdo |
|---|---|
| **Tema 281 STF — RE 363.852** (2010) | **INCONSTITUCIONAL** a contribuição PF da Lei 8.540/92 (e Lei 9.528) — base no faturamento sem previsão constitucional |
| **EC 20/1998** | Acrescentou "ou receita" ao CF 195 I |
| **Tema 669 STF — RE 596.177** (2011) | Confirmou inconstitucionalidade pré-EC 20 |
| **Tema 651 STF — RE 718.874** (2017) | **CONSTITUCIONAL** a contribuição PF pós-EC 20/98 + Lei 10.256/01 |
| **STJ Tema 1.052** | Aplicação operacional pós Tema 651 |

## Tema 651 STF — RE 718.874 (2017)

| | Conteúdo |
|---|---|
| Tese | "**Constitucional** a contribuição prevista no art. 25 da Lei 8.212/91 (redação Lei 10.256/01) **PARA O EMPREGADOR RURAL PESSOA FÍSICA**" |
| Razão | EC 20/98 incluiu "ou receita" → adequação constitucional |
| Aplicação | Contribuição **válida** a partir de 01/01/2002 (vigência Lei 10.256) |

## Alíquotas atuais

| Sujeito | Alíquota |
|---|---|
| **Produtor rural PF** | **1,2%** (Lei 13.606/18) + 0,1% (RAT) + 0,2% SENAR = **1,5%** |
| **Produtor rural PJ** | **1,7%** + 0,1% RAT + 0,25% SENAR = **2,05%** |
| **PJ rural com opção pela folha** | **20%** patronal + RAT + SENAR + terceiros (Lei 13.606/18) |
| Empregado rural | 8-14% (regime único trabalhador) |

## Opção pela folha (Lei 13.606/18)

| | Conteúdo |
|---|---|
| Pressuposto | **PJ rural** pode optar |
| Opção | Anual — declarada via GFIP/EFD-Reinf |
| Vantagem | Em empresas com baixa folha + alta receita → favorável manter na receita; ao contrário, opta folha |
| Irretratabilidade | Ano-calendário |

## Base de cálculo — comercialização

| | Conteúdo |
|---|---|
| Inclui | Receita bruta da comercialização da **produção rural** |
| Exclui | Produtos sem industrialização para terceiros — operações com PJ recolhem por substituição |
| Adquirente | **Adquirente PJ** pode ser **substituto tributário** (Lei 8.212 art. 30 IV) |
| PF para PF | Produtor recolhe diretamente |

| | Conteúdo |
|---|---|
| Período | Pré-Lei 10.256 (até 31/12/2001) |
| Modulação | Tema 281 STF — sem modulação geral |
| Repetição | 5 anos do pagamento (CTN 168) |
| Pós Tema 651 (2017) | Repetições anteriores podem ser **rescindidas** pela União (Tema 1.245 STJ) |

## SENAR (Sistema S Rural)

| | Conteúdo |
|---|---|
| **Lei 8.315/1991** | Cria o SENAR |
| Alíquota | 0,2% (PF) ou 0,25% (PJ) — incidente na mesma base da receita rural |
| Destinação | Educação + capacitação rural |

## Defesas + estratégias

| | Conteúdo |
|---|---|
| Restituição pré-Lei 10.256 | Cabível com modulação (Súm. 162 STJ) |
| Discussão pós-Tema 651 | Difícil — STF pacificou |
| Opção pela folha | Análise comparativa |
| Adquirente PJ retém | Verificar legitimidade do recolhimento |

## Síntese operacional

| Hipótese | Solução |
|---|---|
| Produtor rural PF 2026 | **1,5%** (1,2 + 0,1 RAT + 0,2 SENAR) sobre receita |
| Produtor rural PJ 2026 | **2,05%** sobre receita OU opção folha 20% + RAT + SENAR |
| Comercializa com PJ adquirente | Substituto tributário (Lei 8.212 art. 30) |
| Pagamento pré-2002 | **Inconstitucional** (Tema 281) — restituição |
| Pagamento pós-2002 | **Constitucional** (Tema 651) |
| Trabalhador rural | Mesmas alíquotas urbanas (8-14%) |
| Cooperativa rural | Regime específico |

## Distinções essenciais

| | Pré-Lei 10.256 | Pós-Lei 10.256 |
|---|---|---|
| Constitucional? | **NÃO** (Tema 281) | **SIM** (Tema 651) |
| Vigência | Lei 8.540/92 + 9.528/97 | 01/01/2002 |

| | Patronal urbana | FUNRURAL |
|---|---|---|
| Base | Folha 20% | Receita comercialização 1,5%/2,05% |
| Opção | Não há | PJ pode opção pela folha |

## Erros a evitar

- Tratar FUNRURAL como **inconstitucional** após Tema 651 (constitucional pós-2002);
- A restituição é cabível para período **anterior** a 2002 (Tema 281);
- Aplicar alíquota antiga 2,1% para PF (Lei 13.606 — reduzida para 1,2%);
- Esquecer adicionais **RAT 0,1% + SENAR 0,2%** (PF) ou 0,25% (PJ);
- Aplicar opção folha **a PF** (Lei 13.606 — só PJ);
- Tratar opção como **mensal** (anual);
- Não considerar **substituição** pelo adquirente PJ (Lei 8.212 art. 30 IV);
- Aplicar regime trabalhador rural diferente da contribuição rural patronal (institutos distintos);
- O Tema 651 vincula (RE com repercussão geral);
- Não aplicar **Tema 1.245 STJ** (rescisória da União para adequar julgados antigos);
- Tratar **cooperativa rural** como regime comum (regime próprio Lei 9.867);
- Esquecer SENAR + contribuição sindical (regimes distintos);
- Aplicar FUNRURAL a **economia familiar** (CF 195 §8 — facultativo);
- Confundir CNAE rural com PJ rural para opção folha;
- Considerar produtor rural PF como **MEI** (regras distintas).

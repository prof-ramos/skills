# Notificação do Lançamento Tributário

## Base legal

| | Conteúdo |
|---|---|
| **CTN 142** | Lançamento — constituição |
| **CTN 145** | Alteração do lançamento — só por impugnação, recurso ou iniciativa de ofício |
| **CTN 144** | Lei aplicável é a vigente à data do FG |
| **DL 70.235/1972** | Processo Administrativo Fiscal — disciplina notificação |
| **Lei 9.784/1999** | Lei do Processo Administrativo — supletiva |
| **DL 70.235 art. 23** | Modalidades de intimação |

## Efeitos da notificação

| | Conteúdo |
|---|---|
| **Constitui** o crédito | Definitivamente após esgotado prazo de impugnação |
| Inicia | **Prescrição** (CTN 174) |
| Inicia | **Prazo de impugnação** (em geral 30 dias federal — DL 70.235) |
| Encerra | Decadência (CTN 173) |
| Permite | Inscrição em DA + EF (após constituição definitiva) |

## CTN 145 — alteração do lançamento

| Inc. | Conteúdo |
|---|---|
| **I** | **Impugnação** do sujeito passivo |
| **II** | **Recurso de ofício** (reexame necessário em PAF) |
| **III** | Iniciativa de ofício da autoridade administrativa nos casos do **CTN 149** (erro, fraude, omissão, etc.) |

## Modalidades de intimação (DL 70.235 art. 23)

| | Conteúdo |
|---|---|
| **Pessoal** | Diretamente ao contribuinte ou representante |
| **Postal** com AR | Aviso de recebimento |
| **Edital** | Quando frustradas as anteriores |
| **Eletrônica** (DTE — Domicílio Tributário Eletrônico) | Lei 11.196/05 + DTE-RFB |

## Súm. 397 STJ

| | Conteúdo |
|---|---|
| Tese | "O **envio do CARNÊ** ao endereço do contribuinte configura a notificação do lançamento do **IPTU**" |
| Aplicação | Presunção iuris tantum — admite prova em contrário (Súm. 397 §) |
| Tributos análogos | IPTU + IPVA + taxas regulares — envio anual |

## Notificação eletrônica via DTE

| | Conteúdo |
|---|---|
| Base legal | A intimação por meio eletrônico (DTE — Domicílio Tributário Eletrônico) é válida quando o sujeito passivo está cadastrado (DL 70.235 art. 23 III + Lei 11.196/05) |
| Aplicação | RFB + alguns Estados/Municípios |
| **DTE-PF** (Lei 11.457/07) | Opcional para pessoas físicas; obrigatório em programas de transação |

## Notificação do IPTU e prescrição

| | Conteúdo |
|---|---|
| Regra | A notificação do lançamento do IPTU se dá pelo **envio do carnê** (Súm. 397 STJ); a prescrição corre a partir do dia seguinte ao vencimento (Tema 980 STJ) |

## Lançamento por homologação — peculiaridades

| | Conteúdo |
|---|---|
| **Auto-lançamento** | Contribuinte declara + paga antecipado (DCTF/GIA) |
| **Notificação posterior** | Quando Fisco discorda → autuação |
| **Constituição** | Via declaração (Súm. 436 STJ) ou autuação |

## Decadência × notificação

| | Conteúdo |
|---|---|
| Notificação dentro de **5 anos** (CTN 173) | Tempestiva |
| Notificação após decadência | **Sem efeito** (CTN 156 V) |
| Comprovação | Ônus do Fisco em prazo aberto |

## Prescrição × notificação

| | Conteúdo |
|---|---|
| Notificação **válida** | Inicia 5 anos para Fisco cobrar (CTN 174) |
| Notificação **nula** | Não inicia prescrição |
| Convalidação | Possível por novo lançamento (CTN 149) |

## Notificação por edital — requisitos

| | Conteúdo |
|---|---|
| Pressuposto | Tentativa pessoal + postal **frustrada** |
| Diligência | Mínima — registro de tentativas |
| Súm. 414 STJ | "A citação por edital na execução fiscal é cabível quando frustradas as demais modalidades" |
| Notificação por edital | Sem tentativa diligente prévia (pessoal/postal) é **nula** (DL 70.235 art. 23 + devido processo) |

## Defesas em caso de notificação inadequada

| | Conteúdo |
|---|---|
| Demonstrar não recebimento | Pode usar **MS** OU **exceção de pré-executividade** (Súm. 393) |
| Vício formal | Anula notificação → reinicia prazos |
| Vício material | NÃO reabre decadência (CTN 173 II — só formal) |

## Notificação válida — pressupostos

| | Conteúdo |
|---|---|
| Identificação do contribuinte | Dados corretos |
| Descrição do FG | Detalhada |
| Quantum | Valor + cálculo + atualização |
| Fundamentação legal | Norma aplicada |
| Prazo + meios de defesa | Indicado |
| Assinatura da autoridade competente | Necessária |

## Lei 14.689/2023 — voto de qualidade CARF

| | Conteúdo |
|---|---|
| Reflexo | Quando contribuinte perde por **voto de qualidade**, exclui-se mora + multa de mora — relevante na fase pós-notificação + impugnação |

## Síntese operacional

| Hipótese | Solução |
|---|---|
| IPTU 2026 — envio do carnê | Notificação **presumida** (Súm. 397) |
| Auto de infração federal | Notificação pessoal/AR/DTE |
| Contribuinte PJ | DTE válida (DL 70.235 art. 23 + Lei 11.196/05) |

| Vício material | NÃO renova prazo |

|---|---|---|

## Erros a evitar

- Considerar lançamento **constituído** sem notificação válida (sem ela não há);
- Aplicar prescrição **antes** da notificação (CTN 174 — só após constituição definitiva);
- Tratar **carnê devolvido** como notificação válida (presunção iuris tantum admite contrário);
- Aceitar notificação **por edital sem tentativa** prévia diligente (DL 70.235 art. 23 + devido processo);
- Aplicar **vício formal** como impeditivo permanente (CTN 173 II — renova 5 anos);
- Tratar vício **material** como reabrindo prazo (CTN 173 II — só formal);
- Considerar DTE **inválida** para PJ cadastrada (válida — DL 70.235 art. 23 + Lei 11.196/05);
- Aplicar Súm. 397 a tributo **sem envio anual** (regimes próprios);
- Não fundamentar notificação adequadamente (vicia);
- Notificar **representante sem poder** legítimo;
- Tratar como **regular** notificação após decadência;
- Acreditar que impugnação automaticamente **anula** lançamento (só decisão do PAF anula);
- Aplicar Lei 9.784 quando há DL 70.235 (especial prevalece);
- Considerar **DTE-PF** como obrigatória (em geral opcional, salvo em transação);
- Esquecer **Lei 14.689** + voto de qualidade favorável ao contribuinte.

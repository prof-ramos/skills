# Isenção e Anistia Tributária

## Base legal

| | Conteúdo |
|---|---|
| **CTN 175** | Exclusão do crédito tributário: **I: isenção; II: anistia** |
| **CTN 176-179** | Isenção: disciplina |
| **CTN 180-182** | Anistia: disciplina |
| **CF 150 §6** | Concessão de benefícios fiscais: **lei específica** + reserva |
| **LC 24/75** | ICMS: exige convênio CONFAZ unânime |
| **LC 160/2017** | Convalidou guerra fiscal até 08/08/2017 |

## Natureza das duas figuras

| | Isenção | Anistia |
|---|---|---|
| Atinge | **Tributo** | **Multa/infração** |
| FG | **Ocorre** (mas dispensa) | Infração ocorre (mas perdoa) |
| Norma | Lei (em regra ordinária) | Lei |
| Espécie | Exclusão (CTN 175 I) | Exclusão (CTN 175 II) |

## Isenção

### Conceito

| | Conteúdo |
|---|---|
| Conceito predominante | **Dispensa legal** do pagamento do tributo: o fato gerador ocorre, mas a lei retira a obrigatoriedade do pagamento (CTN 175 I) |
| Distinção crítica | Não confundir com **não-incidência** (FG não ocorre) nem com **imunidade** (vedação constitucional à instituição) |

### Espécies (CTN 176-177)

| | Conteúdo |
|---|---|
| **Subjetiva** | Em razão da pessoa (entidade beneficente, atividade) |
| **Objetiva** | Em razão do bem/operação (produto exportado) |
| **Geral** | Lei autoaplicável |
| **Individual/condicionada** | Despacho administrativo + requisitos |
| **Onerosa** | Em troca de contraprestação (investimento, prazo) |

### CTN 178: revogação

| | Conteúdo |
|---|---|
| Regra | Pode ser revogada por **lei** a qualquer tempo |
| **Exceção** | **Isenção ONEROSA + por prazo certo**: **IRREVOGÁVEL** durante o prazo (Súm. 544 STF + CTN 178) |
| Fundamento | Direito adquirido (CF 5 XXXVI) + segurança jurídica + boa-fé do contribuinte que cumpriu a contrapartida |

### Súm. 544 STF

| | Conteúdo |
|---|---|
| Tese | "Isenções tributárias **concedidas, sob condição onerosa, NÃO podem ser livremente suprimidas**" |
| Base legal | CTN 178 (isenção onerosa e por prazo certo) |

### CF 150 §6 + Lei específica

| | Conteúdo |
|---|---|
| Regra | "Qualquer **subsídio ou isenção, redução de base de cálculo, concessão de crédito presumido, anistia ou remissão** ... só poderá ser concedido mediante lei específica" |
| Razão | Transparência fiscal + controle da renúncia de receita |
| ICMS | LC 24/75 + convênio CONFAZ unânime |

## CTN 175: alcance da isenção

| | Conteúdo |
|---|---|
| Caput | A isenção **exclui** o crédito tributário; a operação não gera dever de pagamento |
| § | Salvo disposição em contrário, **NÃO se estende às taxas + contribuições** (interpretação restritiva, CTN 111 II) |

## Isenção heterônoma (CF 151 III)

| | Conteúdo |
|---|---|
| Regra | **VEDADA** a União conceder isenção de tributos estaduais/municipais (princípio federativo) |
| Exceção | Tratados internacionais: STF RE 229.096 (Pleno) admite (a União, no plano externo, atua como Estado Federal, não como ente federativo interno) |
| ISS exportação de serviços | LC 116 art. 2 I + CF 156 §3 II (autorizada por LC); não é heterônoma stricto sensu |

## Anistia (CTN 180-182)

### Conceito

| | Conteúdo |
|---|---|
| Definição | **Perdão de infrações** + sanções (multas), **anteriores** à concessão |
| Distinção | Remissão (CTN 172) atinge **crédito tributário** (tributo); anistia atinge **multa** |

### Espécies (CTN 181)

| | Conteúdo |
|---|---|
| **Geral** | Para todas as infrações |
| **Limitada** | Por **categoria** de infrações OU **região** OU **valor** OU **condição** (despacho) |

### CTN 180: vedações

| | Conteúdo |
|---|---|
| **I** | NÃO se aplica aos atos qualificados como **CRIMES** (sonegação fiscal, contrabando, descaminho) |
| **II** | NÃO se aplica salvo disposição em contrário aos atos praticados com **dolo, fraude ou simulação** |

### CTN 182: despacho individual

| | Conteúdo |
|---|---|
| Concedida em caráter individual | Mediante **despacho** da autoridade administrativa em requerimento do contribuinte |
| Comprovação | Documentos + atendimento aos requisitos |
| Revogação | Pelo descumprimento posterior |

## CF 150 §6: exigências comuns

| | Conteúdo |
|---|---|
| Lei específica | Para isenção/anistia/remissão/redução de base |
| Caráter geral | Vedação de tratamento desigual sem fundamento |
| Estimativa de impacto orçamentário | LC 101/00 (LRF) art. 14 |
| **ADCT 113** (EC 95/2016) | A ausência da **prévia estimativa de impacto orçamentário e financeiro** gera **INCONSTITUCIONALIDADE FORMAL** da lei concessiva do benefício; vincula **TODOS os entes**, inclusive estados e municípios (STF, Plenário, ADI 6.303, j. 03/2022; STF, Plenário, RE 1.343.429, j. 04/2024, isenção municipal de IPTU, com modulação ex nunc naquele caso) |

## ICMS: LC 24/75 + LC 160/17

| | Conteúdo |
|---|---|
| Regra | Isenção/incentivos de ICMS dependem de **convênio CONFAZ UNÂNIME** |
| Sem convênio | **INCONSTITUCIONAL** (LC 24/75 + ADIs guerra fiscal STF) |
| LC 160/17 | Convalidou benefícios concedidos sem convênio até **08/08/2017** (Conv. 190/17) |

## Distinções essenciais

| | Isenção | Anistia |
|---|---|---|
| Objeto | Tributo | Multa/infração |
| Momento | Fato gerador | Após infração |
| Vedação | Crimes/dolo (algumas) | Crimes + dolo (CTN 180) |

| | Isenção | Imunidade |
|---|---|---|
| Fonte | **Lei** | **Constituição** |
| Natureza | Dispensa | Não-competência |
| Revogação | Por lei (regra) | Cláusula pétrea (CF 60 §4) |

| | Isenção | Não-incidência |
|---|---|---|
| FG ocorre? | **SIM** | NÃO |

| | Anistia | Remissão |
|---|---|---|
| Atinge | Multa | **Tributo + multa** |
| Concessão | Lei | Lei (CTN 172) |

## Aplicação prática

| Hipótese | Solução |
|---|---|
| Empresa exportadora pede isenção do ICMS exportação | **Imune** (CF 155 §2 X "a"); não é isenção |
| Pedido de isenção do IPI ZFM | Isenção do DL 288 (objetiva) |
| Isenção onerosa por 10 anos com contrapartida | **Irrevogável** (Súm. 544) |
| Lei revoga isenção onerosa antes do prazo | **Inconstitucional** |
| Anistia para multas de mora até 2024 | Cabível, mas exige lei + LRF |
| Sonegação fiscal + anistia | **Vedada** (CTN 180 I) |
| Convênio CONFAZ não-unânime | **Inválido** (LC 24/75 + ADIs guerra fiscal STF) |
| União concede isenção de ICMS | **Vedado** (CF 151 III) |

## Erros a evitar

- Confundir **isenção** com **imunidade** (fonte + natureza distintas);
- Aplicar isenção a **infrações dolosas** (CTN 180 I/II);
- A **União não pode isentar tributos estaduais/municipais** (CF 151 III, isenção heterônoma vedada salvo tratado);
- Estender isenção a **taxas + contribuições** (CTN 175 §, restritiva);
- A isenção **onerosa por prazo certo** não é revogável (Súm. 544);
- O benefício de ICMS sem **convênio CONFAZ** é inconstitucional (LC 24/75 + ADIs guerra fiscal STF);
- Aplicar **anistia** a sonegação ou crimes (CTN 180 I);
- O benefício fiscal exige **lei específica** (CF 150 §6);
- Ignorar estimativa de **impacto LRF** (art. 14);
- Validar benefício fiscal concedido **sem a estimativa do ADCT 113** tratando-a como mera exigência da LRF (vício FORMAL de inconstitucionalidade: STF, ADI 6.303, j. 03/2022 + RE 1.343.429, j. 04/2024);
- Tratar isenção como **ato administrativo discricionário** (exige lei);
- Aplicar isenção a **multa de mora** (é anistia);
- Considerar isenção **autoaplicável** quando lei exigir requisitos (caso individual);
- Aceitar isenção pré-CF 1988 não recepcionada (cada caso);
- Aplicar **CTN 178** a isenção onerosa sem ponderar Súm. 544;
- Estender anistia a **período posterior** à lei (CTN 180: infrações anteriores à lei concessiva).

# ICMS-ST Fora da Base do PIS/COFINS

Antes de usar, ler o [protocolo LegalBR](../../../SKILL.md). Este arquivo não foi integralmente verificado; confirmar fundamentos em fontes oficiais.

## Base normativa

| | Conteúdo |
|---|---|
| **CF 195 I "b"** | PIS/COFINS sobre receita/faturamento |
| **LC 87/96 art. 6 + 7** | ICMS-ST |
| **Tema 69 STF** | ICMS próprio fora PIS/COFINS |
| **Parecer SEI 4.090/2024 PGFN** | Consolidou orientação |

## STJ Tema 1.125 (REsp 1.896.678 + 1.958.265)

| | Conteúdo |
|---|---|
| Fixada | **2023** (1ª Seção) |
| **Tese (essência)** | O **ICMS-ST NÃO INTEGRA** a base de cálculo de **PIS/COFINS** devida pelo contribuinte **SUBSTITUÍDO**, por mesma lógica do **Tema 69 STF**: o tributo não é receita do contribuinte (é repasse ao Estado) |
| **Modulação** | Efeitos a partir de **15/03/2017** (data do Tema 69), ressalvadas ações ajuizadas antes |

## Aplicação prática

| Hipótese | Saída |
|---|---|
| Empresa substituída recebe NF com ICMS-ST + sua venda subsequente | **Excluir ICMS-ST** da base PIS/COFINS (Tema 1.125) |
| Cobrança histórica antes de 15/03/2017 | **Modulação**: cabe restituição apenas para ações ajuizadas antes |
| Pós-modulação: pretensão restitutória | Cabível dentro do prazo quinquenal |
| Empresa Simples Nacional: aplicar Tema 1.125 | Regime próprio (LC 123) |
| Tema 69 STF + Tema 1.125 STJ + Tema 1.099 STF: aplicação conjunta | Cada um em sua hipótese |

## Distinções

| Hipótese | Inclui PIS/COFINS? |
|---|---|
| ICMS próprio (saída) | **NÃO** (Tema 69) |
| ICMS-ST destacado | **NÃO** (Tema 1.125 STJ) |
| ICMS-ST não destacado | **NÃO** (mesma lógica) |
| ISS na base PIS/COFINS | **Tema 118 STF PENDENTE** (RE 592.616, sem tese fixada) |

## Erros a evitar

- Incluir ICMS-ST na base PIS/COFINS do substituído (Tema 1.125 exclui);
- Aplicar Tema 1.125 retroativamente a coisa julgada sem verificar os Temas 881/885 STF;
- Confundir ICMS-ST (substituição) com ICMS próprio (saída);
- Em ações pré-Tema 1.125 ainda sem decisão: aplicar a tese sem analisar modulação;
- Em ações ajuizadas após 15/03/2017 mas antes do julgamento: cabe restituição com prescrição quinquenal.

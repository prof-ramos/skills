# Súmula Vinculante 19, Taxa de Coleta e Tratamento de Lixo

## Texto integral

> "A **taxa cobrada exclusivamente** em razão dos serviços públicos de **coleta, remoção e tratamento ou destinação de lixo** ou resíduos provenientes de imóveis, **não viola o artigo 145, II, da Constituição Federal**."

## Bases normativas

| | Conteúdo |
|---|---|
| **CF 145 II** | Taxa de **serviço público específico e divisível** (uti singuli) |
| **CTN art. 77** | Definição de taxa |
| **CTN art. 79** | **Específico**: destacável em unidades autônomas; **divisível**: suscetível de utilização separada |
| **CF 145 §2** | Veda BC própria de imposto (cf. SV 29, admite **elementos**) |
| **STF Súm. 595** | É inconstitucional taxa municipal de conservação de estradas com BC idêntica à do ITR (identidade de base de cálculo) |
| **STF Súm. 670** | Iluminação pública NÃO pode ser taxa |
| **STF SV 41** | Reafirma Súm. 670 (iluminação) |

## Precedente paradigma

| | Conteúdo |
|---|---|
| Caso | **RE 576.321/SP QO-RG** |
| Relator | Min. **Ricardo Lewandowski** |
| Julgamento | **04/12/2008** (Plenário, Repercussão Geral) |
| **Tema RG** | **146** |
| Aprovação SV 19 | **29/10/2009** |
| Tese | Coleta + remoção + tratamento + destinação de lixo de imóveis é serviço **específico + divisível** = taxa **constitucional** |

## Núcleo

| | Conteúdo |
|---|---|
| Serviço **específico** | Identificável por unidade autônoma (imóvel) |
| Serviço **divisível** | Mensurável por usuário (cada imóvel gera lixo identificável) |
| **Coleta DOMICILIAR** | **OK**, uti singuli |
| **Limpeza PÚBLICA** (varrição, capina, conservação de logradouros) | **VEDADA** taxa (uti universi) |
| Cobrança **exclusiva** | A taxa deve remunerar **apenas** o serviço de lixo (sem misturar com limpeza pública) |

## Aplicação prática

| Atividade | Taxa permitida? |
|---|---|
| **Coleta** de lixo nos imóveis | **SIM** |
| **Remoção** do lixo coletado | **SIM** |
| **Tratamento/destinação** (aterro, incineração, reciclagem) | **SIM** |
| **Varrição** de ruas | **NÃO** (uti universi) |
| **Capina/poda** de vias públicas | **NÃO** |
| **Conservação** de logradouros, praças | **NÃO** |
| Coleta misturada com limpeza pública (taxa única) | **INCONSTITUCIONAL** (descumpre "exclusivamente") |

## Base de cálculo: SV 29

| | Conteúdo |
|---|---|
| Vedação CF 145 §2 | Taxa NÃO pode ter BC **própria** de imposto |
| **SV 29** | Pode adotar **um ou mais elementos** da BC de imposto, desde que NÃO haja **integral identidade** |
| Caso clássico | Taxa de lixo com elemento "área do imóvel" (também usada no IPTU), **válida** se não for cópia integral da BC do IPTU |
| Inconstitucional | Taxa que use **valor venal** integral (BC própria do IPTU) |

## Casos correlatos

| | Conteúdo |
|---|---|
| **RE 576.321** (Tema 146) | Paradigma, coleta domiciliar OK |
| **STF Súm. 595** | Taxa de conservação de estradas com BC idêntica ao ITR: inconstitucional |
| **STF Súm. 670** | Iluminação ≠ taxa |
| **SV 41** | Reafirma Súm. 670 |
| **SV 29** | BC com elementos de imposto OK |
| **RE 232.393** | Caso precursor sobre BC de taxa de lixo |
| **Súm. 545 STF** | Distinção entre taxa (compulsória) e preço público/tarifa (facultativo) |

## Distinguishing

| Hipótese | Saída |
|---|---|
| Taxa de coleta **isolada** + outras cobranças autônomas | **CONSTITUCIONAL** |
| Taxa **única** misturando coleta + varrição | **INCONSTITUCIONAL** (descumpre "exclusivamente") |
| Coleta seletiva de recicláveis (porta a porta) | OK (uti singuli) |
| Coleta de **lixo hospitalar** (regime próprio) | OK como taxa específica |
| Taxa cobrada de imóvel **não edificado** (sem geração de lixo) | Discutível, exige análise de **utilização potencial** (CF 145 II) |
| Imóvel **fora da rota** de coleta | Cobrança **vedada** (sem utilização potencial real) |
| Taxa proporcional **à área** do imóvel | OK (SV 29, elemento, não identidade) |
| Taxa proporcional ao **valor venal** | **INCONSTITUCIONAL** (identidade com IPTU) |

## Erros a evitar

- Tratar **varrição/limpeza pública** como serviço específico e divisível (é **uti universi**, vedado);
- Cobrar **taxa única** misturando coleta domiciliar + limpeza pública (descumpre "exclusivamente");
- Aplicar **BC integral do IPTU** (valor venal) à taxa de lixo (CF 145 §2, SV 29);
- Invocar a **SV 41** (iluminação pública) para invalidar a taxa de coleta de lixo (institutos distintos);
- Considerar **coleta domiciliar** como uti universi (é uti singuli, SV 19);
- Aplicar **SV 19** à **iluminação** ou **segurança pública** (uti universi, vedadas);
- Cobrar de imóvel **fora da rota** de coleta (sem utilização potencial);
- Afastar a taxa porque o usuário **não produziu lixo no período** (CF 145 II permite **utilização potencial**);
- Considerar a taxa **tarifa** (Súm. 545 STF, taxa é tributo);
- Aplicar **regime contratual** (taxa é tributo, regime tributário);
- Cobrar **taxa de lixo industrial** sob regramento de lixo domiciliar (regime próprio);
- Afastar a SV 19 por **inviabilidade prática** de individualização (basta a divisibilidade conceitual);
- Tratar a SV 19 como **revogada** pela COSIP (institutos distintos);
- Aplicar **multa pelo não pagamento** da taxa sem fundamento legal específico;
- Misturar IPTU + taxa em **CDA única** sem discriminação dos valores (vício de origem).

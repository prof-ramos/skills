## Síntese operacional

| Hipótese | Saída |
|---|---|
| Depósito integral em dinheiro | **SUSPENDE** (Súm. 112) |
| Fiança bancária | **Garante mas NÃO suspende** (Tema 378 STJ) |
| Recurso administrativo | **Suspende** (III) |
| Depósito prévio para recurso | **VEDADO** (SV 21) |
| Liminar em MS | **Suspende** (IV) |
| Parcelamento | **Suspende** (VI) |
| Suspensão + lançamento | **Lança para evitar decadência** (suspensão não obsta o lançamento) |
| Alienação pós-inscrição | **Fraude presumida** (CTN 185 + Tema 290) |
| MS para declarar compensação | **OK** (Súm. 213) |
| MS para convalidar | **VEDADO** (Súm. 460) |
| Anulatória + depósito prévio | **VEDADO** (SV 28) |
| Falência | Tributário 3º (art. 83 III Lei 11.101) |

## Erros a evitar

- Aceitar **FIANÇA/SEGURO** como suspensão (Tema 378 STJ: só garantia);
- Aplicar **depósito parcial ou em bens** (Súm. 112: integral em dinheiro);
- Exigir **DEPÓSITO PRÉVIO** para recurso adm (SV 21 + Súm. 373);
- Exigir **DEPÓSITO PRÉVIO** para anulatória (SV 28);
- **NÃO LANÇAR** durante suspensão (a Fazenda deve lançar para prevenir a decadência);
- Exigir **PROVA de má-fé** para fraude CTN 185 (Tema 290: desnecessária);
- Aceitar **MS para CONVALIDAR** compensação (Súm. 460);
- O **MS para DECLARAR** compensação é cabível (Súm. 213);
- Aplicar hipóteses **ALÉM das 6** do CTN 151 (taxativas);
- O **PRIVILÉGIO** do crédito tributário na falência é assegurado (art. 83 III);
- Tratar **moratória individual** sem despacho (CTN 152 II).

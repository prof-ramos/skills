# Dívida Ativa + CDA

## CTN 201 + LEF 2

| | Conteúdo |
|---|---|
| Tese | **INSCRIÇÃO em DÍVIDA ATIVA**: ato administrativo de controle de legalidade |
| Confere | **EXEQUIBILIDADE** ao crédito |
| Pressuposto | **ESGOTADA a via administrativa** |

## CTN 202: REQUISITOS da CDA

| Inc. | Conteúdo |
|---|---|
| **I** | **Nome + domicílio** do devedor (e **co-responsáveis**) |
| **II** | **Valor originário + forma de cálculo** de juros/encargos |
| **III** | **Origem + natureza + fundamento legal** |
| **IV** | **Data da inscrição** |
| **V** | **Número do PROCESSO ADMINISTRATIVO** |
| **VI** | **CÓPIA da CDA anexa** |

## CTN 203: sanabilidade

| | Conteúdo |
|---|---|
| Tese | **OMISSÃO** de requisito é **CAUSA de NULIDADE** |
| Sanável | **Até a DECISÃO de 1ª INSTÂNCIA** |
| Mediante | **Substituição/emenda** da CDA |
| Efeito | **REABRE prazo de defesa** |

## Súm. 392 STJ + Tema 1.350 STJ

| | Conteúdo |
|---|---|
| Súm. 392 | **SUBSTITUIÇÃO** da CDA admitida até a sentença dos embargos, apenas por **ERRO MATERIAL/FORMAL** |
| Vedação | **TROCAR sujeito passivo** |
| Vício de lançamento | **INCABÍVEL** substituir CDA |
| **Tema 1.350 STJ** | "Não é possível à Fazenda Pública, ainda que antes da prolação da sentença de embargos, substituir ou emendar a CDA para **incluir, complementar ou modificar o fundamento legal** do crédito tributário" |

## Súm. 559 STJ

| | Conteúdo |
|---|---|
| Tese | **DISPENSA demonstrativo de cálculo** na inicial da EF |
| Fundamento | LEF 6 é **ESPECIAL** em face do CPC |

## CTN 204 + LEF 3

| | Conteúdo |
|---|---|
| Tese | **PRESUNÇÃO iuris tantum** de **CERTEZA + LIQUIDEZ** |
| Efeito | **INVERSÃO** do ônus probatório |

## Súm. 393 STJ

| | Conteúdo |
|---|---|
| Tese | **EXCEÇÃO de PRÉ-EXECUTIVIDADE** em matérias cognoscíveis de **OFÍCIO** + **sem dilação probatória** |
| Aplica | Prescrição + decadência + ilegitimidade + nulidade da CDA |

## Garantia dos embargos + citação por edital

| | Conteúdo |
|---|---|
| Embargos | **CONDICIONADOS à GARANTIA** (LEF 16 §1); efeito suspensivo exige garantia + fumus + periculum (Tema 526 STJ) |
| **Súm. 414 STJ** | A **citação por edital** na execução fiscal é cabível quando frustradas as demais modalidades |

### Tema 444 STJ
| | Conteúdo |
|---|---|

|---|---|

## Síntese operacional

| Hipótese | Saída |
|---|---|
| CDA sem fundamento legal | **Nula** (CTN 202) |
| Vício formal até 1ª instância | **SUBSTITUIR** (Súm. 392 + CTN 203) |
| Trocar SP da CDA | **VEDADO** |
| Inicial sem demonstrativo de cálculo | **OK** (Súm. 559) |
| Embargos sem garantia | **Não recebidos** (LEF 16 §1) |
| Exceção pré-executividade | **OK** se sem dilação (Súm. 393) |
| Suspensão da exigibilidade | **CPD-EN** (CTN 206) |
| CND para licitação trabalhista | **CNDT** (CLT 642-A) |
| Prescrição IPTU | **Dia seguinte vencimento** (Tema 980) |
| Redirecionamento sócio | **5a** (Tema 444) |
| Promitente comprador | Pode ser eleito contribuinte do IPTU (Tema 122 + Súm. 399) |

## Erros a evitar

- Admitir **CDA SEM requisitos** CTN 202;
- Admitir **substituição APÓS a sentença dos embargos** (Súm. 392) ou saneamento fora da hipótese do CTN 203;
- Admitir **TROCA de SP** na substituição (Súm. 392);
- Exigir **demonstrativo de cálculo** na inicial (Súm. 559 dispensa);
- Afastar **EPE** em matéria de ordem pública (Súm. 393);
- Admitir **embargos SEM GARANTIA** (LEF 16 §1);
- Afastar **presunção iuris tantum** da CDA (CTN 204 + LEF 3);
- Admitir **CND quando há débito** suspenso (é CPD-EN, CTN 206);
- Contar **prescrição da inscrição** (Tema 980, vencimento);
- Aplicar **substituição CDA** para vícios materiais de lançamento (Súm. 392);
- Afastar **CNDT** para licitações (Lei 14.133 + CLT 642-A);
- Admitir emenda da CDA para **alterar o fundamento legal** do crédito (Tema 1.350 STJ).

# ADO 25: Lei Kandir

## Identificação

| | Conteúdo |
|---|---|
| Ação | **ADO 25** |
| Autor | Governo do PA |
| Relator | Min. **Gilmar Mendes** |
| Julgamento | **30/11/2016** |
| Resultado | **Procedente**: mora reconhecida |

## Tese estruturante

| | Conteúdo |
|---|---|
| Resultado | Mora **inconstitucional** do Congresso |
| Base | **ADCT 91** + **CF 155 §2 X "a"** |
| Prazo fixado | **12 meses** ao Congresso |
| Solução | TCU + STF apontariam critérios na inércia |

## Lei Kandir (LC 87/1996)

| | Conteúdo |
|---|---|
| Função | Imunidade do ICMS sobre exportações (até produtos primários e semielaborados) |
| Repercussão | Estados exportadores perderam arrecadação |
| **ADCT 91** | Determinou compensação por critério a ser definido em LC |

## LC 176/2020

| | Conteúdo |
|---|---|
| Origem | Resposta à ADO 25 |
| Conteúdo | **Cronograma** de transferências até **2037** |
| Critérios | Repartição entre Estados exportadores |
| **EC 132/2023** (Reforma Tributária) | Articulação com novo regime |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Compensação Lei Kandir | LC 176/2020: até 2037 |
| Estados exportadores | Direito assegurado |
| Mora legislativa | Pode gerar nova ADO |
| Reforma Tributária EC 132 | Substitui ICMS por IBS/CBS |
| Transição | Cronograma específico |
| Tribunal de Contas da União | Acompanhamento |

## Erros a evitar

- Aplicar Lei Kandir sem compensação prevista (LC 176);
- Tratar a compensação como **liberalidade** (é direito constitucional);
- Confundir ADO com ADI;
- Esquecer EC 132 + transição.

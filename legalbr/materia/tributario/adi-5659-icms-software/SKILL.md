# ADI 5659 + ADI 1945: Software

## Identificação

| | Conteúdo |
|---|---|
| Ações | **ADI 5659 + ADI 1945** |
| Autores | CNS + ABES |
| Relator | Min. **Dias Toffoli** |
| Julgamento | **24/02/2021** |

## Tese estruturante

| | Conteúdo |
|---|---|
| Resultado | **ISS** incide sobre software (não ICMS) |
| Categoria | Padronizado + customizado + download + SaaS |
| Base | **LC 116/2003 item 1.05** |
| **Atividade-fim** | **Cessão de USO** ou licenciamento |

## Modulação (8 hipóteses)

| Hipótese | Efeito |
|---|---|
| Contribuintes que recolheram ISS | Não restituem ao adquirente |
| Contribuintes que recolheram ICMS | Direito à restituição |
| Sem recolhimento | ISS exigível |
| Estados | Sem cobrança retroativa |
| Municípios | Cobrança a partir da modulação |
| Outras combinações | Conforme regulamentação |

## Reforma Tributária EC 132/2023

| | Conteúdo |
|---|---|
| **IBS** | Substitui ICMS + ISS gradualmente |
| **CBS** | Substitui PIS/COFINS |
| Transição | Até 2033 |
| Software | Sujeito a IBS/CBS no novo regime |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Software (qualquer modalidade) | **ISS** (LC 116 item 1.05) |
| Cessão de uso | ISS |
| SaaS | ISS |
| Padronizado | ISS |
| Customizado | ISS |
| ICMS sobre software | **Vedado** |
| Pós-EC 132 | IBS + CBS (transição) |
| Bitributação | **Vedada** (prevalece o ISS) |

## Erros a evitar

- Cobrar ICMS sobre software (ADI 5659 vedou);
- Tratar SaaS como **circulação de mercadoria**;
- Aplicar regime distinto a padronizado x customizado (ambos = ISS);
- Esquecer modulação (não restituir do contribuinte de ISS);
- Aplicar transição EC 132 sem cronograma.

# Contribuição de Melhoria

## CF 145 III

| | Conteúdo |
|---|---|
| Competência | **COMUM** (U/E/M/DF) |
| Natureza | Tributo **VINCULADO** |
| Fundamento | **VEDAÇÃO ao ENRIQUECIMENTO SEM CAUSA** do particular |

## Marco legal

| | Conteúdo |
|---|---|
| **DL 195/1967** | Lei principal |
| **CTN 81-82** | Disciplina |

## FATOS GERADORES

| | Conteúdo |
|---|---|
| (1) | **OBRA PÚBLICA** |
| (2) | **VALORIZAÇÃO IMOBILIÁRIA** decorrente |

## DOIS LIMITES CUMULATIVOS

| | Conteúdo |
|---|---|
| **(a) INDIVIDUAL** | Quanto o **IMÓVEL ESPECÍFICO VALORIZOU** |
| **(b) TOTAL** | **CUSTO EFETIVO da OBRA**: não se pode arrecadar mais que o gasto |

## Jurisprudência do STF (RE 116.148/SP)

| | Conteúdo |
|---|---|
| Orientação | **FG é a VALORIZAÇÃO**, não a obra em si |
| Exige | **DEMONSTRAÇÃO CONCRETA** da valorização imobiliária |

## Procedimento (DL 195/1967)

| | Conteúdo |
|---|---|
| **EDITAL prévio** | Memorial descritivo + orçamento + delimitação da zona beneficiada + **fator de absorção** |
| Direito | **IMPUGNAÇÃO administrativa** |
| **LANÇAMENTO INDIVIDUALIZADO** | Após apuração |

## Hipóteses clássicas

| | Conteúdo |
|---|---|
| **PAVIMENTAÇÃO asfáltica** | **PRIMEIRA pavimentação** (RE 116.148) |
| **RECAPEAMENTO** | **NÃO gera**: é **MANUTENÇÃO** |
| **ALARGAMENTO** de vias | Sim |
| **SANEAMENTO** | Sim |

## Diferença para a TAXA

| | Taxa | CM |
|---|---|---|
| Remunera | **CUSTO** do serviço/polícia | Capta **VALORIZAÇÃO** |
| FG | Exercício/serviço | Valorização |

## Jurisprudência correlata

| | Conteúdo |
|---|---|
| **RE 116.148** | Primeira pavimentação asfáltica enseja CM; recapeamento (manutenção) não |
| Jurisprudência consolidada | O fato gerador é a **valorização** imobiliária comprovada, não a obra em si |

## Subutilização prática

| | Conteúdo |
|---|---|
| Tese | **Subutilizada** pelos entes federados |
| Razão | Complexidade procedimental (edital + individualização + prova) |
| Consequência | Litígios sobre **NULIDADE por AUSÊNCIA de DEMONSTRAÇÃO** do quantum valorizado |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Asfalto novo + valorização | **CM** (limites duplos) |
| Recapeamento | **NÃO incide** (manutenção) |
| Edital prévio | **EXIGIDO** (DL 195) |
| Sem demonstração concreta | **NULA** (exigência jurisprudencial) |
| Arrecadação > custo total | **VEDADO** (limite total) |
| Particular sem valorização | **Não contribui** |
| Iluminação pública nova | NÃO é CM (é COSIP/taxa) |
| Saneamento | OK |
| Alargamento de rua | OK |
| Lançamento individualizado | **EXIGIDO** |

## Erros a evitar

- Cobrar CM **sem DEMONSTRAÇÃO da VALORIZAÇÃO** (cobrança nula);
- Aplicar CM a **RECAPEAMENTO** (RE 116.148, manutenção);
- Cobrar **acima do custo total** da obra (vedado);
- Cobrar **acima da valorização individual** (limite duplo);
- Dispensar **edital prévio** (DL 195/1967);
- Tratar **fato gerador como a OBRA** (é a valorização);
- Lançamento **GENÉRICO** (exige individualização);
- Confundir CM com **TAXA** (regimes distintos);
- Aplicar CM **antes da conclusão** da obra (regra, exige consumação);
- Dispensar **CONTRADITÓRIO** ao contribuinte;
- Aplicar CM como **renda do Município** (vinculada à obra).

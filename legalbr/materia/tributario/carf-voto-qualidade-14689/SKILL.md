# CARF + Voto de Qualidade

## CARF

| | Conteúdo |
|---|---|
| Função | **Tribunal administrativo paritário** |
| Composição | **Paritária** entre Fazenda e contribuintes |
| Instância | **2ª** do PAF (recurso contra DRJ) |
| **CSRF** | Câmara Superior: recurso especial |

## Voto de qualidade: histórico

### Tradicional
| | Conteúdo |
|---|---|
| Tese | Exercido pelo **PRESIDENTE de TURMA** (sempre fazendista) |
| Em caso de | **EMPATE** |

### Lei 13.988/2020, art. 19-E (oriundo da MP 899/2019)
| | Conteúdo |
|---|---|
| Tese | **REVOGOU voto qualidade** |
| Empate | **PRÓ-CONTRIBUINTE** |
| **ADIs 6.399 + 6.403 STF** | Julgamento **não concluído** (suspenso por pedido de vista); o art. 19-E permaneceu aplicado enquanto vigente |

### Lei 14.689/2023: RESTABELECEU
| | Conteúdo |
|---|---|
| Tese | **VOLTOU voto qualidade PRÓ-FAZENDA** |

## Compensações Lei 14.689

| | Conteúdo |
|---|---|
| **(i)** | **AFASTAMENTO de MULTAS** (qualificada + mora) quando crédito mantido por voto qualidade |
| **(ii)** | **EXCLUSÃO** de representação fiscal para fins **PENAIS** |
| **(iii)** | **PARCELAMENTO** facilitado em **12x SEM JUROS** |
| **(iv)** | Utilização de **PREJUÍZO FISCAL + base negativa CSLL** |
| **(v)** | **LIMITAÇÃO** de honorários sucumbenciais |

## Distinções essenciais

| | Lei 13.988 (art. 19-E) | Lei 14.689 (2023) |
|---|---|---|
| Empate | **PRÓ-contribuinte** | **PRÓ-Fazenda** |
| Status | Revogada | **Vigente** (com ADIs) |
| Multas | Cobradas | **Afastadas** se mantido por voto |

| | Voto qualidade Fazenda | Sem voto qualidade |
|---|---|---|
| Multa qualificada | Cobrava 150% | **AFASTADA** (Lei 14.689) |
| Representação penal | Cabível | **EXCLUÍDA** |

| | CARF | DRJ |
|---|---|---|
| Composição | Paritária | RFB |
| Instância | 2ª | 1ª |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Empate no CARF 2026 | **Voto qualidade PRÓ-Fazenda** (Lei 14.689) |
| Crédito mantido por voto qualidade | **Multas AFASTADAS** + sem representação penal |
| Parcelamento 14.689 | **12x sem juros** |
| Reformatio in pejus | **VEDADA** (Súm. CARF 26) |
| Transação por adesão | **Lei 13.988 + Lei 14.375** + editais PGDAU |
| Descontos juros/multas | **Até 100%** (transação) |
| Multa qualificada em voto qualidade | **Afastada** |
| ADI 7.548 + ADIs 7.347/7.353 | **PENDENTES**; Lei 14.689 vigente |
| Aplicar Lei 13.988 art. 19-E | **REVOGADO** |
| Recurso especial CSRF | OK |

## Erros a evitar

- Aplicar **Lei 13.988 art. 19-E** como vigente (revogado por 14.689);
- Manter **multas** quando o crédito foi decidido por voto de qualidade (Lei 14.689 as afasta);
- Admitir **representação penal** quando crédito mantido por voto qualidade;
- Aplicar **reformatio in pejus** no CARF (Súm. CARF 26);
- Negar o **parcelamento em 12x sem juros** da Lei 14.689;
- Tratar a **ADI 7.548** ou as **ADIs 7.347/7.353** como julgadas (pendentes de mérito);
- Negar o **uso de prejuízo fiscal/base negativa de CSLL** previsto na Lei 14.689;
- Aplicar **honorários** sem limitação (Lei 14.689);
- Negar a **transação** mesmo com base legal (Lei 13.988 + Lei 14.375 + PGDAU);
- Confundir **CARF** com **DRJ** (instâncias distintas);
- Aplicar **empate como sempre pró-Fazenda** sem ressalvar período 13.988.

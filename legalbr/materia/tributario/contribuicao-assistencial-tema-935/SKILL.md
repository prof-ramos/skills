# Contribuição Assistencial (Tema 935 STF)

## Acórdão paradigma

| | Conteúdo |
|---|---|
| Caso | **ARE 1.018.459** |
| Relator | **Min. Gilmar Mendes** |
| Decisão original (não incide) | **23/02/2017** |
| Reviravolta (ED) | Julgamento finalizado em **12/09/2023** |
| ED de ajuste | 2024 (direito de oposição) |

## Tese atual (pós-2023)

> "É constitucional a instituição, por acordo ou convenção coletivos, de contribuições assistenciais a serem impostas a todos os empregados da categoria, ainda que não sindicalizados, desde que assegurado o direito de oposição."

## Bases normativas

| | Conteúdo |
|---|---|
| **CF 5 XX** | Liberdade associativa |
| **CF 8** | Liberdade sindical |
| **CF 7 XXVI** | Negociação coletiva |
| **CLT 545, 578-610** (Lei 13.467/17) | Reforma Trabalhista |
| Lei 13.467/17 (CLT 579) | Contribuição sindical com autorização expressa |

## Modulação

**Sem retroatividade**. Aplicação a partir da conclusão do julgamento dos ED (set/2023).

## Quatro tipos distintos

| Contribuição | Quem paga | Base |
|---|---|---|
| **Sindical** (CLT 578) | Quem **autorizar expressamente** | Reforma Trabalhista |
| **Confederativa** (CF 8 IV) | **Só filiados** | **SV 40** |
| **Assistencial** (Tema 935) | **Todos da categoria** com direito de oposição | ARE 1.018.459 |
| Mensalidade associativa | Só filiados | Estatuto |

## Requisitos para validade da assistencial

| | Conteúdo |
|---|---|
| **Previsão expressa** em CCT/ACT | Sim |
| **Direito de oposição** efetivo | Prévio, amplo, sem ônus |
| Valor | **Razoável** (não confiscatório) |
| Sindicato | Representatividade comprovada |
| Cobrança | **Não retroativa** |

## Direito de oposição

| | Conteúdo |
|---|---|
| Efetivo | Sim, exercível sem entraves burocráticos |
| Prévio | Antes da cobrança |
| Amplo | Não pode ser limitado a curto prazo |
| Sem ônus | Não exige filiação ou interferência |

## Distinguishing

| Hipótese | Saída |
|---|---|
| Contribuição **confederativa** | Só filiados (SV 40) |
| Contribuição **sindical** (CLT 578) | Autorização expressa (Lei 13.467) |
| **Cobrança retroativa** | Vedada |
| Categoria **sem CCT/ACT** válida | Descabe |
| Empregado com **oposição válida** | Não paga |
| Procedimento de oposição **burocrático** | Inválido |
| Valor **desproporcional** | Questionável |

## Erros a evitar

- Confundir assistencial com **confederativa** (SV 40) ou **sindical** (Lei 13.467);
- Admitir cobrança **retroativa** ao marco de set/2023;
- Validar procedimento de oposição **complexo** ou com prazo exíguo imposto pelo sindicato;
- Não verificar **cláusula expressa** em CCT/ACT válida;
- Aplicar valor desproporcional: examinar a razoabilidade e a compatibilidade com a capacidade econômica da categoria caso a caso (ED integrativos no ARE 1.018.459), pois a tese do Tema 935 não estabelece teto;
- Confundir Tema 935 com **Tema 1.046** (assuntos distintos);
- Tratar a **oposição como faculdade do sindicato** (é direito do empregado);
- Exigir **filiação** para fins de oposição.

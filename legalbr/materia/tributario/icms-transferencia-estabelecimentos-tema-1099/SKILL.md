# ICMS na Transferência entre Estabelecimentos (Tema 1.099 STF + ADC 49)

## Acórdãos paradigmas

| | Conteúdo |
|---|---|
| **Tema 1.099** | ARE 1.255.885, Min. Dias Toffoli, **14/08/2020** |
| **ADC 49** | Min. Edson Fachin, mérito **19/04/2023** |
| ED ADC 49 | **12/04/2024** (modulação refinada) |

## Tese fixada

> "**NÃO incide ICMS** no deslocamento de bens de um estabelecimento para outro do mesmo contribuinte localizados em estados distintos, visto **não haver transferência de titularidade** ou realização de **ato de mercancia**."

## Bases normativas

| | Conteúdo |
|---|---|
| **CF 155 II** | ICMS |
| **LC 87/96** arts. 11 §3 II e 12 I | **Declarados inconstitucionais** |
| **LC 204/2023** | Disciplina pós-ADC 49 |
| **Convênio ICMS 178/2023** | Tentou impor transferência obrigatória: judicializado |

## Modulação (ADC 49)

| | Conteúdo |
|---|---|
| Marco | **Exercício 2024** |
| Ressalvas | Ações **pendentes em 29/04/2021** (publicação ata mérito) |
| Aproveitamento de créditos | Mantido para quem se beneficiou da sistemática anterior |
| Estado sem disciplina | Contribuinte autorizado a transferir créditos **sem ônus** |

## Núcleo

| | Conteúdo |
|---|---|
| Fato gerador | **Ato de mercancia** entre titulares distintos |
| Mesmo CNPJ raiz | Circulação física **NÃO basta** |
| Créditos de origem | **Devem** ser transferidos ao destino (não acumular) |
| LC 204/23 | **Não incidência expressa** + transferência |

## Cotejo LC 204/23 x Convênio 178/23

| | LC 204/23 | Convênio 178/23 |
|---|---|---|
| Caráter | Lei | Ato Confaz |
| Transferência de créditos | **Faculdade** | **Obrigatória** (judicializado) |
| Status | Vigente | ADI 7.515 + outras |

## Operações distintas

| Hipótese | Saída |
|---|---|
| Transferência entre **PJs distintas** (mesmo grupo) | **Incide ICMS** |
| Mudança de titularidade | Tributada |
| Saída para **revenda direta** | Tributada |
| IPI/PIS/COFINS na saída | **Não afastados** |
| DIFAL / ICMS-ST em saída econômica | **Incidem** |

## Beneficiários de incentivos fiscais regionais

| | Conteúdo |
|---|---|
| Risco | **Glosa pelos Estados de destino** se a sistemática mudar |
| Necessidade | Acompanhamento da disciplina estadual pós-LC 204 |

## Distinguishing

| Hipótese | Saída |
|---|---|
| Transferência **PJs distintas** (mesmo grupo) | Incide |
| Mudança real de titularidade | Tributada |
| Operação com fim de revenda | Tributada |
| ICMS-ST + antecipação tributária | Incidem (circulação econômica) |

## Erros a evitar

- Confundir vedação à **incidência** com vedação à **transferência de créditos** (créditos devem ser transferidos);
- Não atentar ao marco da **modulação 2024** (quem não pagou antes não recupera; quem ajuizou **até 29/04/2021** sim);
- Confundir Tema 1.099 com discussão de **ICMS-ST** e antecipação tributária;
- Não considerar impacto sobre **incentivos fiscais regionais**;
- Aplicar a tese a transferências entre **PJs do mesmo grupo** (CNPJ raiz diverso): não se aplica;
- Tratar **Convênio 178/23** como obrigatório (há tese de inconstitucionalidade);
- Não acompanhar a evolução estadual da disciplina pós-LC 204/23.

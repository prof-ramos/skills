# Lucro Presumido + Arbitrado

## Marco legal

- **Lei 9.249/1995** (presunções);
- **Lei 9.430/1996** (apuração trimestral);
- **LC 224/2025** (acréscimo nas presunções);
- **RIR/2018** (regulamento atualizado);
- **IN RFB 1.700/2017** (operacional);
- **CTN** (regras gerais);
- **Lei 14.596/2023** (preços de transferência; aplicação restrita);
- **EC 132 + LC 214** (reforma tributária).

## Comparativo regimes de IRPJ

| Regime | Receita bruta limite |
|---|---|
| **Lucro real** | Sem limite (opcional ou obrigatório) |
| **Lucro presumido** | Até **R$ 78 milhões/ano** |
| **Lucro arbitrado** | Compulsório (contabilidade imprestável) |
| **Simples Nacional** (LC 123) | Até **R$ 4,8 milhões/ano** |
| **MEI** | Até R$ 81.000/ano |

## Lucro Presumido: características

| | Conteúdo |
|---|---|
| **Limite** | R$ 78 milhões/ano (receita bruta) |
| **Opção** | Voluntária (atende ao limite) |
| **Apuração** | **Trimestral** |
| **Sem contabilidade rígida** | Simplificado (mas IN obrigam) |
| **Base de cálculo** | **Presunção** sobre receita bruta |
| **Não exige escrituração contábil completa** | Mas é recomendada |

## Percentuais de presunção (Lei 9.249 art. 15)

### IRPJ: presunção sobre receita bruta

| Atividade | % |
|---|---|
| **Revenda de combustíveis derivados de petróleo, álcool etílico e gás natural** | **1,6%** |
| **Indústria + comércio em geral** | **8%** |
| **Construção civil (com fornecimento de materiais)** | 8% |
| **Transporte de cargas** | 8% |
| **Atividade rural** | 8% |
| **Transporte de passageiros** | **16%** |
| **Serviços hospitalares + outros específicos** | 8% |
| **Serviços em geral (intelectuais)** | **32%** |
| **Profissões regulamentadas** | 32% |
| **Locação de bens móveis** | 32% |

### CSLL: presunção

| Atividade | % |
|---|---|
| **Indústria + comércio + atividades específicas** | **12%** |
| **Serviços em geral** | **32%** |

## Alíquotas IRPJ + CSLL

| | Conteúdo |
|---|---|
| **IRPJ** | **15%** sobre a base presumida |
| **Adicional IRPJ** | 10% sobre lucro **> R$ 60.000/trimestre** (ou R$ 20.000/mês) |
| **CSLL** | **9%** sobre a base presumida (instituições financeiras têm alíquotas majoradas, mas são obrigadas ao lucro real) |
| **Carga total IRPJ + CSLL serviço 32%** | ~10.88% sobre receita bruta |

## LC 224/2025: alterações

| | Conteúdo |
|---|---|
| **Acréscimo de 10%** | Nos percentuais de presunção (art. 4 §4, VII) |
| **Aplicação** | Somente sobre a **parcela da receita bruta total que exceder R$ 5 milhões no ano-calendário** (art. 4 §5) |
| **Vigência** | Efeitos a partir de **01/01/2026** |
| **IRRF sobre JCP** | Elevado de 15% para **17,5%** (LC 224/2025 art. 8) |
| **Alcance** | Optantes do presumido com receita acima de R$ 5 milhões |

## Apuração trimestral

| | Conteúdo |
|---|---|
| **Períodos** | 1T (jan-mar), 2T (abr-jun), 3T (jul-set), 4T (out-dez) |
| **Pagamento** | Até último dia útil do mês subsequente ao trimestre |
| **Quota única ou parcelamento** | Em 3 parcelas mensais (com juros Selic) |
| **DARF** | Por trimestre |

## PIS + Cofins (regime cumulativo)

| | Conteúdo |
|---|---|
| **PIS cumulativo** | **0,65%** sobre faturamento |
| **Cofins cumulativo** | **3%** sobre faturamento |
| **Sem créditos** | Em regra |
| **Acumulação com IRPJ presumido** | Comum |
| **Reforma tributária** | Substituirá por CBS |

## Quando o lucro presumido não é vantagem

| | Conteúdo |
|---|---|
| **Margem real < presumida** | Pagaria mais |
| **Atividade de serviço com baixa margem** | Cuidado |
| **Despesas elevadas** | Lucro real pode ser melhor |
| **Início de atividade** | Análise |

## Distribuição de lucros

| | Conteúdo |
|---|---|
| **Isenção parcial** | Lei 9.249 art. 10 isentava integralmente; a **Lei 15.270/2025** passou a reter **IRRF 10%** sobre dividendos > R$ 50.000/mês por PJ pagadora (a partir de 01/01/2026) |
| **Pró-labore** | Sujeito a INSS + IRRF |
| **Limite isento** | Lucro contábil ou presumido (caso a caso) |
| **IRPFM** | Tributação mínima de altas rendas (Lei 15.270/2025) pode alcançar o sócio |

## Lucro Arbitrado (Lei 9.430 arts. 47-48)

### Hipóteses

| | Conteúdo |
|---|---|
| **I** | Não-cumprimento de obrigação acessória |
| **II** | Escrituração + documentação **imprestáveis** |
| **III** | Optante por lucro presumido fora dos requisitos |
| **IV** | Recusa a apresentar documentos à RFB |
| **V** | Lucro real obrigatório sem escrituração |
| **VI** | Fusão + cisão + incorporação sem balanço |
| **VII** | PJ tributada pelo lucro real com inicio de atividade no ano (em certas hipóteses) |

### Tributação

| | Conteúdo |
|---|---|
| **Percentuais** | Mesmos do presumido **acrescidos de 20%** (em alguns casos) |
| **Aplicação** | Sobre a receita bruta conhecida |
| **Receita desconhecida** | Sobre o ativo + outras bases (Lei 9.430 art. 51) |
| **Tendência** | Mais oneroso |
| **Não é escolha** | Compulsório |

## Quem é obrigado ao lucro real (não pode presumido)

| | Conteúdo |
|---|---|
| **Receita > R$ 78 milhões** | Obrigatório |
| **Bancos + financeiras + seguradoras** | Obrigatório |
| **Operações no exterior** (com algumas exceções) | Obrigatório |
| **Incentivos fiscais isentivos** | Em alguns casos |
| **Factoring** | Obrigatório |
| **Atividade imobiliária loteamento** | Obrigatório |

## Vantagens × desvantagens

### Vantagens do presumido

| | Conteúdo |
|---|---|
| **Simplificação** | Menos obrigações acessórias |
| **Previsibilidade** | Sabe quanto vai pagar |
| **Custo contábil** | Menor |
| **Distribuição de lucros** | Isenta na PJ; sócio PF sujeito a IRRF 10% sobre dividendos > R$ 50k/mês (Lei 15.270/2025, a partir de 2026) |
| **Atrativa para serviços** com alta margem | Sim |

### Desvantagens

| | Conteúdo |
|---|---|
| **PIS/Cofins cumulativo** | Sem créditos (lucro real é não-cumulativo) |
| **Sem dedução de despesas** | Base presumida independe do custo real |
| **LC 224/2025** | Aumento da presunção sobre a parcela da receita > R$ 5M |
| **Limite R$ 78M** | Restrito |
| **Margem real baixa** | Paga mais |

## Reforma tributária (EC 132 + LC 214)

| | Conteúdo |
|---|---|
| **IBS/CBS** | Substituem PIS/Cofins/ICMS/ISS (LC 214/2025, que também institui o Imposto Seletivo) |
| **IRPJ + CSLL** | Permanecem |
| **Lucro presumido** | Mantido (com alterações LC 224/2025) |
| **Distribuição de lucros** | **Lei 15.270/2025** já instituiu IRRF 10% sobre dividendos > R$ 50k/mês (vigência 2026) |
| **Transição 2026** | Alíquotas-teste de CBS 0,9% + IBS 0,1%, com recolhimento dispensado se cumpridas as obrigações acessórias (LC 214/2025 art. 348); o Ato Conjunto RFB/CGIBS 4/2026 escalona os DF-e desde 03/08/2026, com datas próprias em 01/10, **15/11 para os eventos mensais DeRE D-1101, D-1106, D-1121, D-2101, D-1198 e D-1199**, 01/12 e 01/01/2027 |
| **Regulamentação** | Decreto 12.955/2026 (Regulamento da CBS) + Resolução CGIBS 6/2026 (Regulamento do IBS); Comitê Gestor do IBS criado pela LC 227/2026 e instalado em fevereiro/2026 |
| **Simples Nacional** | Opção pelo modelo de recolhimento de IBS/CBS entre 01 e 30/09/2026, com efeitos a partir de janeiro/2027 |

O Ato Técnico Conjunto RFB/CGIBS 1/2026 alterou regras de validação para que NF-e, NFC-e, CT-e, CT-e OS, GTV-e, BP-e, NF3e e NFCom não sejam rejeitados pela ausência de campos de IBS/CBS. Essa suspensão técnica não revoga as datas do Ato Conjunto 4/2026 nem, por si só, satisfaz as obrigações acessórias exigidas pelo art. 348 da LC 214/2025.

## Aplicação prática

| Cenário | Regime ideal |
|---|---|
| **Comércio com receita R$ 5M + margem 15%** | Presumido ainda vantajoso |
| **Serviços com receita R$ 5M + margem 30%** | Presumido (com LC 224) |
| **Serviços com margem 50%+** | Provavelmente presumido |
| **Serviços com margem 10%** | Lucro real |
| **Indústria com baixa margem** | Lucro real |

## Erros a evitar

- Aplicar **lucro presumido** com receita > R$ 78M (obrigatoriedade real);
- Esquecer **acréscimo LC 224/2025** (10% para receita > 5M);
- Confundir **presumido** com **arbitrado** (regimes próprios);
- Aplicar percentuais sem **enquadrar atividade** (Lei 9.249 art. 15);
- Esquecer **adicional IRPJ** (10% sobre lucro > R$ 60k/trimestre);
- Aplicar PIS/Cofins **não-cumulativo** em presumido (cumulativo);
- Tratar **distribuição de lucros** sempre como isenta (limites);
- Aplicar regime sem ver **obrigações acessórias** (DCTF + ECF);
- Esquecer **operações no exterior** (em geral obrigam lucro real);
- Aplicar regime antigo após **reforma tributária**;
- Confundir com **Simples Nacional** (regime distinto);
- Não documentar receita bruta + opção pelo regime.

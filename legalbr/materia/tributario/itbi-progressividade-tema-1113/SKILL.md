# ITBI: Base de Cálculo (Tema 1.113 STJ)

## Base normativa

| | Conteúdo |
|---|---|
| **CF 156 II** | ITBI: transmissão **inter vivos** de bens imóveis + direitos reais (exceto garantia) |
| **CTN art. 35-42** | ITBI |
| **CTN art. 38** | Base de cálculo: valor venal dos bens ou direitos transmitidos |
| **CF 156 §1 II** | ITBI **progressivo** vedado (regime atual, antes EC 29 + jurisprudência) |
| **Súm. 656 STF** | ITBI progressivo vedado |

## STJ Tema 1.113 (REsp 1.937.821)

| | Conteúdo |
|---|---|
| Fixada | **24/02/2022** |
| **Tese 1** | A **base de cálculo** do ITBI é o **VALOR DECLARADO** pelo contribuinte na transação |
| **Tese 2** | NÃO se vincula automaticamente ao **valor venal do IPTU** |
| **Tese 3** | Município pode demonstrar que o valor declarado é **inferior ao de mercado** via procedimento administrativo |
| **Tese 4** | Não há "pauta" geral de valores para ITBI (cada imóvel é único) |

## Aplicação prática

| Hipótese | Saída |
|---|---|
| Contribuinte declara R$ 500k + IPTU diz R$ 300k | **ITBI sobre R$ 500k** (valor declarado) |
| Município lança ITBI sobre valor diverso | **Inadequado** (Tema 1.113): cabe demonstração de subvalor |
| Município alega pauta de valores | **Inviável**: cabe análise individual |
| Contribuinte declara abaixo do mercado | Cabe **autuação** com demonstração + recurso |
| Permuta de imóveis | Base sobre valor declarado de cada um |
| Doação onerosa | Análise: ITCMD vs ITBI |
| Cessão de direitos aquisitivos | ITBI sobre valor declarado |

## Casos correlatos

| | Conteúdo |
|---|---|
| **Tema 1.113 STJ** | Base ITBI valor declarado |
| **Súm. 656 STF** | ITBI progressivo vedado |
| **Súm. 540 STJ** | Não correlato direto |
| **CTN 38** | Base de cálculo |
| **Tema 1.084 STF** | IPTU sem planta genérica (correlato) |

## Erros a evitar

- Vincular ITBI ao **valor venal do IPTU** (Tema 1.113);
- Aceitar **pauta geral** de valores (Tema 1.113);
- Em subvalor declarado, exigir prova pelo contribuinte (cabe Município provar);
- Aplicar ITBI progressivo (Súm. 656 STF veda);
- Em **alienação fiduciária**, considerar transmissão imediata (ITBI ocorre na consolidação ou averbação);
- Em permuta sem valor: aplicar pauta sem análise individual;
- Em compromisso de compra e venda, exigir ITBI antes da escritura definitiva (cabe verificar regulamento municipal).

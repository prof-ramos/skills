# Substituição Tributária

## CF 150 §7 (EC 3/93)

| | Conteúdo |
|---|---|
| Tese | Autoriza lei a atribuir a **SUJEITO PASSIVO** a condição de **RESPONSÁVEL pelo PAGAMENTO** cujo FG deva ocorrer **POSTERIORMENTE** |
| Garantia | **IMEDIATA E PREFERENCIAL RESTITUIÇÃO** se FG presumido NÃO se realizar |

## LC 87/1996 (Lei Kandir)

| | Conteúdo |
|---|---|
| Disciplina | **ICMS-ST** |

## TRÊS modalidades

| | Conteúdo |
|---|---|
| **ANTECEDENTE/regressiva** | **DIFERIMENTO** — pagamento posterior por substituto à frente da cadeia |
| **CONCOMITANTE** | Simultânea ao FG |
| **SUBSEQUENTE/progressiva** | **ANTECIPADA** — mais difundida — cálculo por **MVA + PMPF** (CONFAZ) |

## STF Tema 201 (RE 593.849 — 2016) — OVERRULING

| | Conteúdo |
|---|---|
| Reverteu | **ADI 1.851/2002** (que negava restituição) |
| Tese | **Presunção do FG é IURIS TANTUM** |
| Restituição | **DEVIDA da DIFERENÇA** quando BC EFETIVA < PRESUMIDA |
| Razão | Enriquecimento sem causa + capacidade contributiva |

## Distinções essenciais

| | Antecedente | Subsequente |
|---|---|---|
| Quando | **Posterior** (diferimento) | **Antecipada** (FG futuro) |

| | ADI 1.851 (2002) | Tema 201 (2016) |
|---|---|---|
| Restituição | **Negava** | **PERMITE** |
| Status | Superada | Atual |

| | BC efetiva > presumida | Efetiva < presumida |
|---|---|---|
| Estado | Não cobra diferença | **Restitui** (Tema 201) |
| Tese | Aceita | Iuris tantum |

| | MVA | PMPF |
|---|---|---|
| Conteúdo | Margem agregada | Preço médio ponderado |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| ICMS-ST sobre cadeia | **LC 87/96** |
| FG presumido NÃO realizado | **Restituição** (CF 150 §7) |
| BC efetiva < presumida | **Restitui DIFERENÇA** (Tema 201) |
| BC efetiva > presumida | **Estado não cobra a mais** (Tema 201) |
| Aplicação pré-Tema 201 (2016) | ADI 1.851 (superada) |
| DIFAL e-commerce | **LC 190/2022** |
| Análise individual | **Dispensada** (Tema 700) |
| CONFAZ define MVA | OK |
| Diferimento (regressiva) | OK |
| Substituto na frente | **Antecedente** |

## Erros a evitar

- A **restituição** é devida quando a BC efetiva for inferior à presumida (Tema 201);
- Aplicar **ADI 1.851** como vigente (superada por Tema 201);
- Tratar **FG presumido como definitivo** (iuris tantum);
- Aplicar **DIFAL e-commerce** sem LC 190/2022;
- Exigir **análise individual** para ST uniforme (Tema 700 — dispensa);
- Admitir **substituição sem lei** (CF 150 §7, exige);
- A **restituição imediata e preferencial** é assegurada (CF 150 §7);
- Aplicar **MVA acima do real** sem ressalvar restituição;
- Tratar **antecedente** como antecipação (é diferimento);
- Confundir **substituição** com **responsabilidade comum** (CTN 128);
- Aplicar ST a cadeias sem **CONFAZ** (convênios + protocolos).

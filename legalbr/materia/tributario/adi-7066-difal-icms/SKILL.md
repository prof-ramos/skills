# ADIs 7066/7070/7078: DIFAL

## Identificação

| | Conteúdo |
|---|---|
| Ações | **ADIs 7066 + 7070 + 7078** |
| Autores | ABIMAQ + ABRAS + Governadores |
| Relator | Min. **Alexandre de Moraes** |
| Julgamento | **29/11/2023** |
| Objeto | LC 190/2022 (DIFAL) |

## Tese estruturante

| | Conteúdo |
|---|---|
| Resultado | LC 190/2022 **constitucional** quanto ao DIFAL |
| Anterioridade | **Nonagesimal** (90 dias): válida desde 05/04/2022 |
| Anterioridade anual | **NÃO incide**: não há criação ou majoração |
| Tema 1093 | Confirma EC 87/2015 |

## EC 87/2015 + Tema 1093

| | Conteúdo |
|---|---|
| **EC 87/2015** | Repartição do ICMS em operações interestaduais ao destino |
| **Tema 1093** (RE 1.287.019) | Necessidade de LC para regulamentação |
| **LC 190/2022** | Cumpriu exigência |

## Anterioridade

| | Conteúdo |
|---|---|
| **CF 150 III "b"** | Exercício seguinte |
| **CF 150 III "c"** | 90 dias |
| LC 190 publicada em 05/01/2022 | Aplicável a partir de **05/04/2022** |

## DIFAL: mecânica

| | Conteúdo |
|---|---|
| Operação interestadual | Não-contribuinte |
| Diferença entre alíquota interna do destino e interestadual | Devida ao Estado de **destino** |
| Comércio eletrônico | Principal hipótese |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| DIFAL exigido pré-05/04/2022 | **Indevido** |
| DIFAL pós-05/04/2022 | **Devido** |
| Falta de LC anterior | LC 190 supriu |
| Tema 1093 | Compatível |
| Repetição indébito | DIFAL exigido antes de 05/04/2022: cabível |

## Erros a evitar

- Cobrar DIFAL antes de 05/04/2022 (anterioridade nonagesimal);
- Tratar LC 190 como inconstitucional (validada por ADIs 7066/7070/7078);
- Aplicar anterioridade anual cumulativamente;
- Confundir DIFAL com ICMS-ST;
- Esquecer EC 87 + Tema 1093.

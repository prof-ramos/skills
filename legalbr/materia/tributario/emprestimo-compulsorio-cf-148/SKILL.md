# Empréstimo Compulsório

## CF 148

| | Conteúdo |
|---|---|
| Competência | **EXCLUSIVA DA UNIÃO** |
| Veículo | **LEI COMPLEMENTAR** (sempre) |

## DUAS HIPÓTESES (taxativas)

### Inc. I: calamidade/guerra
| | Conteúdo |
|---|---|
| Conteúdo | **DESPESAS EXTRAORDINÁRIAS** decorrentes de **CALAMIDADE PÚBLICA OU GUERRA EXTERNA** (ou iminência) |
| Anterioridade | **NÃO se sujeita** (anual + nonagesimal) |

### Inc. II: investimento
| | Conteúdo |
|---|---|
| Conteúdo | **INVESTIMENTO PÚBLICO de caráter URGENTE + RELEVANTE INTERESSE NACIONAL** |
| Anterioridade | **INTEGRAL** (anual + nonagesimal) |

## Características essenciais

| | Conteúdo |
|---|---|
| **RESTITUÍVEL** | Por natureza: a devolução integra o regime constitucional |
| **VINCULAÇÃO** | Arrecadação vinculada à **despesa que fundamentou** (CF 148 par. único) |
| Vedação | **Desvio de finalidade** |

## STF: DL 2.288/1986 (compulsório sobre veículos + combustíveis)

### RE 121.336
| | Conteúdo |
|---|---|
| Tese | **INCONSTITUCIONAL** |
| Razão | Devolução em **quotas do Fundo Nacional de Desenvolvimento** viola a **NATUREZA RESTITUÍVEL**: devia ser em **MOEDA** |

## Eletrobras (Lei 4.156/1962)

| | Conteúdo |
|---|---|
| Cobrança | Até **1993** |
| Consequência | Massivo contencioso de devolução |

### STJ Temas 65/66/67 (REsp 1.003.955 + 1.028.592, 2009)
| | Conteúdo |
|---|---|
| Tese | Quanto à correção monetária sobre o principal e juros remuneratórios dela decorrentes, a lesão ocorreu na **restituição a menor**, efetivada pela conversão dos créditos em ações; a **prescrição** conta das assembleias que homologaram cada conversão: **20/04/1988** (72ª AGE), **26/04/1990** (82ª AGE) e **30/06/2005** (143ª AGE) |
| Revisão | Os temas encontram-se em **revisão** no STJ ("tese após revisão: a definir"); acompanhar |

### Súm. 553 STJ
| | Conteúdo |
|---|---|
| Tese | Nos casos de empréstimo compulsório sobre energia elétrica, é competente a **Justiça estadual** para demanda proposta exclusivamente contra a Eletrobras (competência; requerida intervenção da União após a sentença, remessa ao TRF sem anulação) |

## Distinções essenciais

| | Inc. I (calamidade/guerra) | Inc. II (investimento) |
|---|---|---|
| Anterioridade | **NÃO** | **SIM** integral |
| Urgência | Imediata | Médio prazo |

| | Tributo | Empréstimo compulsório |
|---|---|---|
| Definitivo | Sim | **NÃO** (restituível) |
| LO | Possível | **LC obrigatória** |

| | Devolução em moeda | Em quotas/títulos |
|---|---|---|
| Constitucional | **SIM** (RE 121.336) | **NÃO** |

| | Prescrição Eletrobras | STJ (Temas 65/66/67) |
|---|---|---|
| Prazo | Quinquenal | Termo: assembleias de conversão (Temas 65/66/67) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| União + LC + guerra externa | **EC I** + sem anterioridade |
| União + LO + qualquer hipótese | **INCONSTITUCIONAL** (exige LC) |
| Investimento urgente | **EC II** + anterioridade integral |
| Devolução em quotas FND | **INCONSTITUCIONAL** (RE 121.336) |
| Eletrobras pendente | Prescrição contada das assembleias de conversão (Temas 65/66/67 STJ, em revisão) |
| Correção + juros da devolução | Temas 65/66/67 STJ (em revisão; "tese após revisão: a definir") |
| Desvio de finalidade | **VEDADO** (CF 148 par. único) |
| MP institui | **VEDADO** (CF 62 §1 III) |
| Estado institui | **VEDADO** (competência exclusiva União) |

## Erros a evitar

- Aceitar **LO** para empréstimo compulsório (CF 148: exige LC);
- Permitir **MP** (CF 62 §1 III veda);
- Aplicar a **Estados ou Municípios** (exclusiva da União);
- Aceitar **devolução em quotas/títulos não monetários** (RE 121.336);
- Permitir **desvio de finalidade** (CF 148 par. único);
- Aplicar **anterioridade ao inc. I** (calamidade/guerra dispensa);
- Não aplicar anterioridade ao **inc. II** (investimento exige);
- Ignorar o marco prescricional das assembleias de conversão (STJ Temas 65/66/67);
- Confundir a Súm. 553 STJ (competência da Justiça estadual contra a Eletrobras) com o mérito da correção/juros;
- Tratar como **definitivo** (é restituível);
- Aplicar hipóteses **ALÉM das taxativas** (ADI 924).

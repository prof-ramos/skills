# Lei 14.973/2024

## Marco legal

- **Lei 14.973/2024** (16/09/2024);
- **IN RFB 2.222/2024** (regulamento);
- **Lei 14.754/2023** (offshores + trust);
- **Lei 13.254/2016** (RERCT original);
- **Lei 9.250/1995** (IRPF);
- **Lei 9.249/1995** (IRPJ);
- **Decreto regulamentar** específico;
- **CTN + RIR/2018**.

## Duas medidas centrais

### 1. Atualização patrimonial de imóveis (arts. 6-13)

| | Conteúdo |
|---|---|
| **Aplicação** | PF + PJ residentes no Brasil |
| **Bens** | Imóveis no Brasil + exterior |
| **Valor declarado** | Atualizado ao valor de mercado em 31/12/2023 |
| **Tributação sobre diferença** | Específica |
| **Opcional** | Não obrigatório |
| **Prazo de opção** | **15/12/2024** |

### 2. RERCT-Geral (arts. 14-30)

| | Conteúdo |
|---|---|
| **Origem** | Continuação do RERCT (Lei 13.254/2016) |
| **Objetivo** | Regularização de bens não-declarados |
| **Bens** | Brasileiros + exterior |
| **Alíquota** | **15% IRPF + 100% multa** = 30% total |
| **Prazo** | 15/12/2024 (encerrado, mas legado relevante) |

## Atualização de imóveis: PF

| | Conteúdo |
|---|---|
| **Alíquota** | **4%** sobre a diferença |
| **Base** | Valor de mercado − custo declarado |
| **Pagamento** | Nos prazos e condições da Lei 14.973 + IN RFB 2.222/2024 |
| **Benefício** | Reduz IR sobre ganho de capital em venda futura |
| **Sem retroatividade** | Não afeta passado |

### Cálculo exemplo

| | Valor |
|---|---|
| Imóvel declarado a | R$ 200.000 |
| Valor de mercado 31/12/2023 | R$ 500.000 |
| Diferença | R$ 300.000 |
| **IRPF 4%** | R$ 12.000 |
| Após atualização | Novo custo base é R$ 500.000 |
| **Ganho de capital futuro** | Reduzido |

## Atualização de imóveis: PJ

| | Conteúdo |
|---|---|
| **IRPJ** | **6%** sobre diferença |
| **CSLL** | **4%** sobre diferença |
| **Total** | 10% sobre diferença |
| **Bens permanentes** | Aplicação |
| **Lucro real, presumido, arbitrado** | Aplicação |
| **Lucro real** | Beneficiamento de ativo imobilizado |

## Regra de "carência": venda nos 15 anos seguintes

| Período | Tratamento |
|---|---|
| **< 3 anos** | Ganho de capital = valor de venda - custo original (sem atualização) |
| **3-7 anos** | Reduções proporcionais |
| **7-15 anos** | Reduções maiores |
| **> 15 anos** | Custo atualizado é integralmente reconhecido |
| **Efeito** | Atualização útil só se manter por longo período |

| | Conteúdo |
|---|---|

| **Definitivo** | Tributação fechada |

## Erros a evitar

- Tratar **atualização patrimonial** como obrigatória (é opcional);
- Esquecer a regra de **carência**: venda em menos de 3 anos perde o benefício;
- Aderir ao RERCT com **bens de origem ilícita** (lavagem persiste);
- Confundir **RERCT** com **transação tributária** (institutos distintos);
- Não documentar **origem lícita** + comprovação;
- Aderir após **prazo** (15/12/2024 expirado);
- Aplicar atualização **sem ver Lei 14.754** (offshores);
- Esquecer **ITCMD futuro** sobre valor atualizado;
- Aplicar **alíquotas erradas** (4% PF / 10% PJ / 30% RERCT);
- Confundir com **Lei 13.254** (RERCT original, 2016);
- Não considerar **PJ + Lucro presumido** (pode beneficiar);
- Aceitar atualização sem **planejamento de longo prazo** (>15 anos).

# CIDE Combustíveis + ICMS Monofásico

## Marco constitucional (EC 33/2001)

| | Conteúdo |
|---|---|
| **CF 177 §4** | Autoriza União a instituir **CIDE** sobre **importação e comercialização** de petróleo + derivados + gás natural + álcool combustível + biodiesel |
| **CF 155 §2 XII "h" + §4** | Autoriza **ICMS MONOFÁSICO** sobre combustíveis (definidos em LC) |

## Lei 10.336/2001: CIDE-Combustíveis

| | Conteúdo |
|---|---|
| **FG** | **Importação OU comercialização interna** |
| **Contribuintes** | **Produtor + formulador + importador** |
| **Alíquotas** | **ESPECÍFICAS** (R$/m³) |
| **Alteração por DECRETO** | **Até o limite legal** (CF 177 §4 I "b") |
| **Anterioridade** | **EXCEÇÃO PARCIAL** à legalidade + anterioridade anual |
| **Noventena** | **OBSERVADA** |

## Destinação VINCULADA (CF 177 §4 II)

| | Conteúdo |
|---|---|
| Subsídios | A **preços + transporte** |
| Ambiental | **PROJETOS AMBIENTAIS** ligados à indústria do petróleo/gás |
| **INFRAESTRUTURA de TRANSPORTE** | |

## CIDE × PIS/COFINS

| | Conteúdo |
|---|---|
| Cumulação | **Pode cumular** com PIS/COFINS |
| Não-cumulação | **NÃO há regra de não-cumulação automática** entre elas |

## STF ADI 4.171 (Rel. Min. Ellen Gracie, redator p/ acórdão Min. Ricardo Lewandowski, j. 2015)

| | Conteúdo |
|---|---|
| Tese | **INCONSTITUCIONAIS** os §§10 e 11 da cláusula 21ª do **Convênio ICMS 110/2007 (CONFAZ)**, que exigiam **estorno do crédito de ICMS** relativo ao álcool misturado à gasolina em operações interestaduais (ofensa à legalidade + bitributação) |
| Reafirmou | Regime constitucional **CF 155 §2 X "b"**: imunidade nas interestaduais com combustíveis derivados de petróleo |

## STF: destinação da CIDE (ADI 3.970, j. 13/05/2022)

| | Conteúdo |
|---|---|
| Tese | Plenário (unânime, sessão virtual encerrada em 13/05/2022) **VALIDOU** os dispositivos das **Leis 10.336/2001 e 10.636/2002** que tratam da destinação dos recursos da CIDE-combustíveis |
| Afastou | Alegações de **tredestinação**: eventual desvio decorre de descumprimento da lei, não da interpretação dos dispositivos |
| Limite | Respeitado o **núcleo finalístico** do art. 177 §4 II (rol exaustivo, conforme ADI 2.925) |

## ICMS MONOFÁSICO (LC 192/2022)

| | Conteúdo |
|---|---|
| Regulamenta | Tributação **MONOFÁSICA** (uma única incidência na cadeia) |
| Aplicação | **Diesel + biodiesel + GLP** + posteriormente **gasolina/etanol** |
| **Convênio ICMS 199/2022** | + seguintes CONFAZ: fixam **alíquotas AD REM ESPECÍFICAS (R$/litro)** com **UNIFORMIDADE NACIONAL** |
| Estados | **NÃO podem majorar livremente**: alíquotas dependem de deliberação CONFAZ |

## LC 194/2022: essencialidade

| | Conteúdo |
|---|---|
| Tese | Classifica **combustíveis + energia elétrica + gás natural + comunicações + transporte coletivo** como **BENS ESSENCIAIS** |
| Vedação | **Alíquotas superiores às operações em geral** |
| Consonância | **STF Tema 745** (RE 714.139): observância da **SELETIVIDADE/ESSENCIALIDADE** no ICMS |

## STJ Tema 1.339 (j. 10/06/2026): PIS/Cofins monofásico do varejista

| | Conteúdo |
|---|---|
| Tese | O comerciante **VAREJISTA** de combustíveis, sujeito ao regime **MONOFÁSICO** de PIS/Pasep e COFINS, **não tem direito à obtenção nem à manutenção de créditos** vinculados à aquisição de combustíveis, mesmo após as LCs 192/2022 e 194/2022 e a MP 1.118/2022 |
| Anterioridade | **Sem ofensa à anterioridade nonagesimal**: não houve majoração indireta de tributos quanto ao varejista |
| Órgão | 1ª Seção, unânime (REsp 2.124.940 e outros) |

## STF: homologação de acordo (ADI 7.191 + ADPF 984)

| | Conteúdo |
|---|---|
| Tese | **HOMOLOGOU acordo de COMPENSAÇÃO de R$ 27 BILHÕES** entre União + Estados + DF pelas perdas decorrentes |

## Distinções essenciais

| | CIDE-combustíveis | ICMS-combustíveis |
|---|---|---|
| Ente | **União** | Estados |
| Sistema | Contribuição interventiva | **Monofásico (LC 192)** |
| Alteração | DECRETO até limite legal | CONFAZ |

| | Alíquota ad rem | Ad valorem |
|---|---|---|
| Forma | R$/litro | % sobre valor |
| ICMS monofásico | **ad rem** (Convênio 199) | Anterior |

| | Pré-LC 192/2022 | Pós (2022) |
|---|---|---|
| ICMS combustíveis | Plurifásico + estados livres | **Monofásico + CONFAZ** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Importação de petróleo | **CIDE + outros** |
| Comercialização gasolina | **ICMS monofásico** + Convênio 199 |
| Alíquota CIDE alterada por decreto | **Permitido** (até limite legal) |
| ICMS interestadual derivado de petróleo | **Imunidade** (CF 155 §2 X "b" + ADI 4.171) |
| Estado tenta majorar ICMS combustível | **Vedado** (LC 192 + CONFAZ) |
| Combustível como essencial | **LC 194** + Tema 745 |
| Estados pleiteiam compensação | **R$ 27 bi** (ADI 7.191) |
| CIDE + PIS/COFINS | **Cumuláveis** |
| Tredestinação alegada | STF rejeita (validou) |

## Erros a evitar

- **Admitir tredestinação** sem limite (STF, núcleo finalístico);
- Aplicar **anterioridade ao CIDE** (exceção parcial, só noventena);
- **Afastar créditos de ICMS** interestaduais (ADI 4.171);
- Aplicar **ICMS combustível plurifásico** após LC 192/2022;
- **Admitir alíquota acima** do Convênio CONFAZ (LC 192, uniforme);
- Tratar **combustível como NÃO essencial** (LC 194 + Tema 745);
- Aplicar **ICMS alíquota superior** a operações gerais em essenciais;
- Afastar **acordo de R$ 27 bi** (ADI 7.191);
- Confundir **CIDE com ICMS** (entes distintos);
- Aplicar alíquota **ad valorem** quando é **ad rem** (Convênio 199).

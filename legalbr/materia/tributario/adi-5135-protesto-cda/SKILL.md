## Tese estruturante

| | Conteúdo |
|---|---|
| Resultado | Lei 9.492/97 art. 1 § ún **constitucional** |
| Tese | Protesto é **meio extrajudicial legítimo** de cobrança |
| Princípios | Razoabilidade + proporcionalidade + eficiência |
| Não viola | Devido processo, contraditório, sanção política |

## Distinções

| | Protesto extrajudicial | Execução fiscal |
|---|---|---|
| Base | Lei 9.492/97 | LEF (Lei 6.830/80) |
| Custo | Baixo | Alto |
| Tempo | Rápido | Lento |
| Efeito | Negativação + induz pagamento | Penhora + expropriação |

## Garantias do devedor

| | Conteúdo |
|---|---|
| **Sustação por dúvida** | CPC + Lei 9.492 |
| **Defesa** | Vias próprias (exceção pré-executividade etc.) |
| **Direito de retirada** | Após pagamento (cancelamento) |
| **Negativação** | Pode ser revertida |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Protesto de CDA | **Cabível** (ADI 5135) |
| Sanção política | Não caracterizada |
| Devedor inscrito | Pode ser protestado |
| Defesa | Vias próprias |
| Cancelamento após pagamento | Direito |
| Concorrência com execução fiscal | Modalidades distintas |
| Limite (mínimo) | Razoabilidade do valor |

## Erros a evitar

- Considerar protesto de CDA inconstitucional (ADI 5135);
- Tratar como **sanção política** (não é);
- A defesa do devedor é assegurada;
- Aplicar custos abusivos;
- Manter protesto após pagamento.

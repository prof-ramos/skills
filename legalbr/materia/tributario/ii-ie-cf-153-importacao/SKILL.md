# Imposto de Importação + Exportação

## CF 153

| Inc. | Conteúdo |
|---|---|
| **I** | **Imposto de IMPORTAÇÃO** (União) |
| **II** | **Imposto de EXPORTAÇÃO** (União) |

## Natureza

| | Conteúdo |
|---|---|
| Função | **PREDOMINANTEMENTE EXTRAFISCAL** |
| Instrumento | Regulação do **comércio exterior** + proteção da indústria nacional |

## EXCEÇÕES constitucionais (CF 153 §1 + 150 §1)

| | Conteúdo |
|---|---|
| Alíquotas | **Alteráveis por ATO do PODER EXECUTIVO** (atendidas condições + limites legais) |
| **Anterioridade anual** | **NÃO se submete** |
| **Noventena** | **NÃO se submete** |
| Função | Instrumentos **ÁGEIS** de política econômica |

## STF RE 570.680 (Tema 53)

| | Conteúdo |
|---|---|
| Tese | "É compatível com a CF a norma infraconstitucional que atribui a **órgão integrante do Poder Executivo** da União a faculdade de **alterar as alíquotas do Imposto de Exportação**" (não é privativa do Presidente; alcança a CAMEX) |

## IMPOSTO DE IMPORTAÇÃO (DL 37/1966)

| | Conteúdo |
|---|---|
| **FG** | **Entrada de produto ESTRANGEIRO** no território nacional (consumação no **registro da DI**) |
| **BC** | **VALOR ADUANEIRO** (Acordo de Valoração Aduaneira, GATT/OMC) |
| **Alíquotas** | **TEC**, Tarifa Externa Comum do **Mercosul** (com listas de exceções) |

### DRAWBACK
| | Conteúdo |
|---|---|
| Conteúdo | **Regime aduaneiro especial** de **suspensão + isenção + restituição** |
| Aplicação | Insumos destinados à produção de **bens EXPORTADOS** |
| Base | **Lei 11.945/2009** |

## IMPOSTO DE EXPORTAÇÃO (DL 1.578/1977)

| | Conteúdo |
|---|---|
| **FG** | **Saída** de produto nacional/nacionalizado |
| **BC** | **Preço NORMAL DE VENDA** |
| Aplicação | **Poucos produtos** (couros + armas + cigarros para certos destinos) |

## Jurisprudência relevante

### STF ADPF 400 (reimportação de produto nacional)
| | Conteúdo |
|---|---|
| Julgamento | Improcedente, por **unanimidade** (sessão virtual encerrada em 20/03/2026, rel. Min. Nunes Marques) |
| Tese | **VALIDOU cobrança de II** sobre **PRODUTO NACIONAL/NACIONALIZADO** que, após exportação DEFINITIVA, **RETORNA** ao território nacional (nova entrada sob regime de importação; DL 37/1966 art. 1 §1 compatível com a CF) |
| Afastou | Alegação de bitributação; o relevante é a reentrada no país, não a origem da fabricação |
| Ressalva | Não alcança mercadoria **temporariamente** exportada (ex.: feiras) que retorna |

### Súmula 661 STF
| | Conteúdo |
|---|---|
| Tese | Na entrada de mercadoria importada do exterior, é **LEGÍTIMA a COBRANÇA do ICMS** por ocasião do **DESEMBARAÇO ADUANEIRO** |

### STF Tema 1 (RE 559.937)
| | Conteúdo |
|---|---|
| Tese | **INCONSTITUCIONAL** a parte do art. 7º, I, da Lei 10.865/2004 que acresce à base do **PIS/COFINS-Importação** o **ICMS** incidente no desembaraço aduaneiro + o valor das próprias contribuições |
| Base correta | **VALOR ADUANEIRO** (CF 149 §2 III "a") |
| Correção legal | **Lei 12.865/2013** |

## Distinções essenciais

| | II | IE |
|---|---|---|
| FG | **Entrada** | **Saída** |
| Aplicação | Vasta | **Restrita** (poucos produtos) |
| Função | Proteger indústria | Política exportadora |

| | Imposto importação | ICMS-importação |
|---|---|---|
| Ente | **União** | **Estado** |
| Cobrança | DI | **Desembaraço** (Súm. 661 STF) |

| | Anterioridade | II/IE/IPI/IOF |
|---|---|---|
| Aplicação | Geral | **EXCEÇÃO** (CF 150 §1) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Importação | **II + ICMS no desembaraço** (Súm. 661) |
| Alíquota II por decreto | **PERMITIDO** (CF 153 §1) |
| Sem anterioridade ao II | **OK** |
| Drawback para exportação | **Lei 11.945**: suspensão/isenção/restituição |
| Reimportação de produto nacional | **VALIDADA cobrança** (ADPF 400) |
| ICMS na base PIS/COFINS-Importação (redação original) | **INCONSTITUCIONAL** (Tema 1, RE 559.937) |
| Pós-Lei 12.865/2013 | Corrigida |
| CAMEX altera alíquota | **Possível** (RE 570.680) |

## Erros a evitar

- **Aplicar anterioridade ao II/IE** (são exceções, CF 150 §1);
- A **alteração por DECRETO** das alíquotas é admitida (CF 153 §1);
- Aceitar **competência exclusiva do PR** (RE 570.680: órgão do Executivo pode);
- **Cobrar ICMS antes do desembaraço** (Súm. 661: no desembaraço);
- Aplicar **Lei 10.865 com ICMS na base** do PIS/COFINS-Importação sem ressalvar Tema 1 (RE 559.937) + correção;
- O **drawback** é cabível nas hipóteses legais (Lei 11.945);
- Tratar reimportação de produto nacional como bitributação (ADPF 400: cobrança válida na reentrada definitiva);
- Aplicar **DL 1.578 a produtos não listados** (IE é restrito);
- Não aplicar **TEC do Mercosul** como alíquota padrão;
- Confundir **valor aduaneiro com valor da nota** (BC = valor aduaneiro).

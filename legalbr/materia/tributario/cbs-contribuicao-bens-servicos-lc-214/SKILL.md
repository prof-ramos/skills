# CBS, Contribuição sobre Bens e Serviços

## Base constitucional + legal

| | Conteúdo |
|---|---|
| **CF 195 V** | Competência da **União** (EC 132/2023) |
| **CF 156-A §1** | Princípios (não-cumulatividade plena + neutralidade + simplicidade + transparência) |
| **EC 132/2023** | Cria CBS + IBS + IS; extingue PIS/COFINS/IPI/ICMS/ISS |
| **LC 214/2025** | Regulamenta CBS + IBS (sancionada 16/01/2025) |
| **Decreto 12.955/2026** | **Regulamento da CBS** (DOU 30/04/2026); Livro I traz normas comuns CBS/IBS (incidência, imunidades, base de cálculo, destino, não cumulatividade, documentos fiscais e split payment) |
| **Portaria Conjunta MF/CGIBS 7/2026** | Formaliza as disposições comuns entre o Regulamento da CBS e o Regulamento do IBS (Resolução CGIBS 6/2026) |
| **Ato Conjunto RFB/CGIBS 1/2025** | Obrigações acessórias de IBS/CBS para 2026, com período de adaptação sem penalidades |
| **Ato Conjunto RFB/CGIBS 4/2026 + Ato Técnico Conjunto 1/2026** | Datas por DF-e e documentação técnica; ausência de rejeição por falta dos campos de IBS/CBS não elimina a obrigação jurídica aplicável |
| **CF ADCT 124-133** | Cronograma de transição |

## Natureza jurídica

| | Conteúdo |
|---|---|
| Espécie | **Contribuição social** (CF 149 + 195 V) |
| Sujeito ativo | **União** (arrecada + fiscaliza isoladamente) |
| Não-cumulatividade | **PLENA** (≠ PIS/COFINS atual) |
| Forma | **Por fora** (≠ ICMS por dentro) |
| Princípio | **Destino** (consumo) |

## Cronograma

| Ano | Evento |
|---|---|
| **2026** | Teste: alíquota CBS **0,9%** + IBS 0,1% (compensáveis com PIS/COFINS, art. 348 LC 214; dispensa de recolhimento se cumpridas as acessórias) |
| **2027** | **Extinção PIS/COFINS** + CBS **plena** + IS + IPI 0% (salvo ZFM) |
| 2028 | Avaliação |
| 2029-2032 | Coexistência com ICMS/ISS em redução |
| 2033 | Sistema pleno |

## Hipóteses de incidência (LC 214 art. 4)

| | Conteúdo |
|---|---|
| Regra | **Operações onerosas** com bens (materiais/imateriais/direitos) e serviços |
| Inclui | Locação + cessão + licenciamento + leasing + arrendamento + permuta |
| Importação | **CBS-Importação** substitui PIS/COFINS-Importação (Lei 10.865/04) |

## Não-incidência (LC 214 art. 6)

| | Conteúdo |
|---|---|
| **Exportações** | Imunes, com manutenção integral do crédito |
| Transferências mesmo titular | NÃO incide |
| Doações sem contraprestação | NÃO |
| Rendimentos do trabalho | NÃO (relação de emprego) |
| Dividendos + JCP | NÃO |

## Base de cálculo (LC 214 art. 12)

Valor da operação **POR FORA** (≠ ICMS atual). Excluídos: IPI (transição), descontos incondicionais, valores recebidos por terceiros.

## Alíquotas

| | Valor |
|---|---|
| **Teste 2026** | **0,9%** |
| **Plena (estimada)** | Definida em **lei ordinária federal**; referência projetada **8,8 a 9,3%** (CBS) |
| Reduzida (60%) | Regimes diferenciados (saúde + educação + transporte coletivo + agropecuária + insumos agrícolas + cesta básica reduzida + bens culturais) |
| Reduzida (30%) | Profissionais regulamentados |
| **Alíquota zero** | Cesta básica nacional + medicamentos selecionados + Prouni |

## Crédito amplo

| | Conteúdo |
|---|---|
| Princípio | **Crédito = toda CBS efetivamente recolhida** na etapa anterior |
| Inclui | **Bens de uso/consumo** (≠ regime atual) + ativo imobilizado + serviços + insumos |
| Vedação | Bens/serviços de **uso pessoal** + entradas isentas (regra geral) |
| **Split payment** | Crédito **vinculado ao pagamento efetivo** do fornecedor (LC 214 arts. 31-35 + 47) |
| Saldo credor | Ressarcimento com prazos acelerados na LC 214 (até **60 dias** em hipóteses qualificadas); os **240 meses** com IPCA valem para saldos credores de **ICMS** existentes ao final de 2032 (regra do ADCT, EC 132), não para a CBS |

## Split Payment (LC 214 arts. 31-35)

| | Conteúdo |
|---|---|
| Mecânica | Adquirente paga **CBS direto à União** no instante da liquidação financeira |
| Operador | **Sistema do CG-IBS/RFB** + meios de pagamento (cartões + PIX + boleto + transferência) |
| Modalidades | **Inteligente** (regra) + **Simplificado** (ainda em definição) |
| Operação | Documentação técnica da plataforma pública publicada pelo **Ato Conjunto RFB/CGIBS 2/2026**; operação prevista a partir do **2º semestre de 2027** |
| Efeito | **Reduz inadimplência** + acelera o crédito ao adquirente |

## Cashback (LC 214 arts. 112-124)

| | Conteúdo |
|---|---|
| Beneficiários | Famílias **inscritas no CadÚnico** com renda per capita ≤ 1/2 SM |
| Devolução CBS | **20%** (regra geral); **100%** nos itens essenciais (energia + água + esgoto + gás canalizado + GLP até 13kg + telecom) |
| Devolução IBS | **20%** (inclusive nos essenciais) |
| Operação | Crédito direto na conta + estorno na fatura |

## Regimes diferenciados (CF 156-A §6)

| Setor | Redução |
|---|---|
| Saúde + educação + transporte coletivo + agro/insumos agrícolas + bens culturais | **60%** |
| Profissionais regulamentados | **30%** |
| Hotelaria + parques + restauração + agências de viagem + aviação regional | Específicos LC 214 |
| **Cesta básica nacional** + medicamentos selecionados + Prouni | **Alíquota zero** |

## Regimes específicos (CF 156-A §6 II)

| | Conteúdo |
|---|---|
| Combustíveis | **Monofásico ad rem** |
| Serviços financeiros + seguros + planos de saúde + concursos | Regras próprias (margem) |
| Bens imóveis | Redutor social + regime cumulativo opcional |
| Cooperativas | Regime favorecido |
| Bares + restaurantes + hotelaria | Regime simplificado |
| Operações com **SAF** (sociedade anônima do futebol) | Específico |

## ZFM + áreas livres de comércio

| | Conteúdo |
|---|---|
| **CF 92-A ADCT** + **CF 92-B ADCT** | Manutenção até **2073** |
| Mecânica | **Crédito presumido de CBS** + alíquotas do IPI reduzidas a zero a partir de 2027, **exceto** produtos com industrialização incentivada na ZFM (EC 132) |
| LC 214 | Disciplina cálculo + escrituração |

## Imunidades preservadas (LC 214 art. 8)

- CF 150 VI todas as alíneas (recíproca + templos + entidades + livros + música BR);
- CF 195 §7, entidades beneficentes;
- **Exportações** (CF 156-A §1 III);
- Aposentadorias/pensões RGPS.

## Não cumulatividade

| | Conteúdo |
|---|---|
| Apuração | Mensal, crédito × débito |
| Jurisprudência restritiva do PIS/COFINS (créditos/insumos) | NÃO se transpõe: a CBS adota não-cumulatividade **constitucional plena** (CF 156-A §1, aplicável à CBS) |
| Apropriação | Imediata na **escrituração da operação** + condicionada ao **pagamento via split** |

## Simples Nacional + CBS

| | Conteúdo |
|---|---|
| Optante pelo regime único | Mantém alíquota efetiva (DAS) |
| **Opção pelo regime regular** de CBS/IBS | Permitida; gera crédito ao adquirente |

## Penalidades + obrigações acessórias

| | Conteúdo |
|---|---|
| Documento fiscal eletrônico | Padrão nacional com datas escalonadas pelo Ato Conjunto RFB/CGIBS 4/2026: marcos em **03/08/2026**, **01/10/2026**, **15/11/2026**, **01/12/2026** e **01/01/2027**, conforme o documento, operação e contribuinte |
| Declaração | Apuração/declaração unificada da CBS perante a RFB |
| **Multa por falta de destaque** | LC 214, multas escalonadas |

## ICMS + ISS: sobrevida

| | Conteúdo |
|---|---|
| 2026 | ICMS + ISS plenos (CBS/IBS em teste) |
| 2029-2032 | Redução escalonada **90/80/70/60%** ICMS/ISS, com aumento gradual do IBS |
| 2033 | **Extinção total** ICMS/ISS |

## Distinções essenciais

| | PIS/COFINS atual | CBS |
|---|---|---|
| Origem | Lei 10.637 + 10.833 | **EC 132 + LC 214** |
| Forma | Por dentro (cumulativo) e por fora (n-cumul.) | **POR FORA** (sempre) |
| Crédito | Restritivo (insumo Tema 779 STJ) | **PLENO** (uso/consumo + ativo) |
| Alíquota | 3,65% / 9,25% | ≈ **8,8-9,3%** (estimada) |
| Pagamento | Empresa | **Split payment** |

| | CBS | IBS |
|---|---|---|
| Ente | **União** | **Estados + Municípios (dual)** |
| Substitui | PIS+COFINS | ICMS+ISS |
| Arrecadação | RFB | **CG-IBS** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Empresa em 2026 | **Destaca CBS 0,9% + IBS 0,1%** em NF (acessórias); compensa com PIS/COFINS (art. 348) |
| Empresa em 2027 | **CBS plena**; PIS/COFINS extintos |
| Exportação | **Imune**, crédito mantido |
| Cesta básica nacional | **Alíquota zero** |
| Família CadÚnico baixa renda | **Cashback** (≥ 20%) |
| Energia residencial baixa renda | **Cashback 100%** |
| Profissional regulamentado | **Redução 30%** |
| Combustível | **Monofásico ad rem** |
| ZFM | **Crédito presumido** mantido até 2073 |
| Saldo credor de ICMS ao final de 2032 | Compensação com IBS em **240 parcelas mensais**, atualização pelo IPCA (ADCT, EC 132) |

## Erros a evitar

- Tratar CBS como **continuidade do PIS/COFINS**: a não-cumulatividade é **constitucional plena**, sem transpor a jurisprudência restritiva de créditos do regime antigo;
- Calcular CBS **por dentro** (PIS/COFINS antigo); é **por fora**;
- O crédito de **bens de uso/consumo** é admitido na CBS (LC 214);
- Ignorar as datas específicas do Ato Conjunto RFB/CGIBS 4/2026: NF-e, NFC-e, CT-e, CT-e OS, BP-e não semiurbano/não aéreo, MDF-e, GTV-e, NF3e, DC-e e NFS-e Via desde 03/08; NFCom, DIR e NFS-e em hipóteses gerais desde 01/10; eventos periódicos mensais da DeRE D-1101, D-1106, D-1121, D-2101, D-1198 e D-1199 desde **15/11/2026**; NFGas, NFAg, NF-e ABI e hipóteses especiais de NFS-e desde 01/12; Simples, monofásicos, Duimp e eventos residuais da DeRE desde 01/01/2027;
- Confundir a suspensão de rejeições técnicas do Ato Técnico Conjunto 1/2026 com dispensa da obrigação jurídica ou com cumprimento das condições do art. 348 da LC 214/2025;
- Confundir alíquota de **teste 0,9%** com plena (≈ 8,8-9,3%);
- Tratar **cashback** como receita tributável da família (não é);
- Aplicar **PIS/COFINS** a fatos geradores **pós-01/01/2027** (extintos);
- A **imunidade das exportações** é assegurada (CF 156-A §1 III);
- Aplicar regime ordinário a **profissional regulamentado** (redução 30%);
- Ignorar **split payment** ao planejar fluxo de caixa (CBS recolhida no instante do pagamento);
- O crédito **sem pagamento efetivo** do fornecedor não é admitido (split condicionado);
- Aplicar regime **cumulativo opcional** fora das hipóteses permitidas (imóveis, financeiros);
- Tratar **ZFM** como extinta pela Reforma (mantida até 2073 via crédito presumido, ADCT 92-A);
- Esquecer a **transição PIS/COFINS** em 2026 (compensáveis com CBS, art. 348 LC 214);
- Aplicar **alíquota cheia** a setores com regime diferenciado (redução de 60%: saúde/educação/transporte coletivo);
- Tratar **Simples** como obrigado ao regime regular (é opção do optante).

# Comitê Gestor do IBS (CG-IBS)

## Base constitucional + legal

| | Conteúdo |
|---|---|
| **CF 156-B** (EC 132/2023) | Cria o CG-IBS |
| **LC 227/2026** (ex-PLP 108/2024, sancionada 13/01/2026, DOU 14/01/2026) | Disciplina governança + processo administrativo do IBS + contencioso + distribuição + normas gerais de ITCMD |
| **CF 156-A §3** | Funções básicas |
| **LC 214/2025** | IBS/CBS regulamentados |
| **Resolução CGIBS 6/2026** (30/04/2026) | **Regulamento do IBS**, editado pelo CG-IBS |
| **Portaria Conjunta MF/CGIBS 7/2026** | Formaliza as disposições comuns entre o Regulamento da CBS (Decreto 12.955/2026) e o Regulamento do IBS |
| **Atos Conjuntos RFB/CGIBS 1/2025, 2/2026 e 4/2026** | Obrigações acessórias de 2026, documentação do split payment e cronograma escalonado dos DF-e entre 03/08/2026 e 01/01/2027 |
| **Ato Técnico Conjunto RFB/CGIBS 1/2026** | Aprova e ratifica documentação técnica; suspende rejeições pela ausência dos campos de IBS/CBS em documentos especificados, sem revogar a obrigação jurídica aplicável |

## Natureza jurídica

| | Conteúdo |
|---|---|
| Espécie | **Entidade pública sob regime especial**, sui generis |
| Autonomia | **Técnica + administrativa + orçamentária + financeira** (CF 156-B §1) |
| Não é | Autarquia federal nem entidade subordinada à União |
| Personalidade | Pública, com capacidade processual + administrativa |
| Foro | Justiça competente conforme a controvérsia (em regra **estadual ou federal**) |

## Composição (CF 156-B + LC 227/2026)

| | Conteúdo |
|---|---|
| **27 Estados + DF** | 1 representante cada (eleitos pelos secretários estaduais de fazenda) |
| **27 Municípios** | 14 representantes eleitos com votos de igual valor para cada Município + 13 eleitos com votos ponderados pelas respectivas populações (LC 227/2026) |
| Mandato | **2 anos** + recondução |
| Presidência | Alternada (Estados / Municípios) |

## Instalação e estruturação (2026)

| | Conteúdo |
|---|---|
| **Instalação** | Primeira reunião extraordinária deliberativa do Conselho Superior em **19 e 23/02/2026** |
| **Resolução CSIBS 1/2026** | Aprovou a estrutura provisória e instituiu **6 Comissões de Trabalho** técnico-preparatórias, com coordenação paritária Estados/Municípios, até o regimento interno definitivo e as diretorias permanentes |
| **Regulamento do IBS** | Resolução CGIBS 6/2026 (30/04/2026), com disposições comuns ao Regulamento da CBS formalizadas na Portaria Conjunta MF/CGIBS 7/2026 |
| **Financiamento** | Até **0,2% da arrecadação do IBS**, com regra de transição 2026-2033 (LC 227/2026) |

## Funções (CF 156-A §3)

| | Conteúdo |
|---|---|
| **Normativa** | Editar regulamentos sobre alíquotas, escrituração, obrigações acessórias |
| **Arrecadação** | Receber o IBS, inclusive via split payment, com apuração e declarações unificadas |
| **Fiscalização** | Compartilhada com Estados e Municípios (não-exclusiva) |
| **Distribuição** | Repassar IBS ao Estado/Município de **destino** |
| **Contencioso** | Julgar impugnações e recursos administrativos |
| **Cobrança** | Inscrição em dívida ativa nacional unificada |

## Decisões + maiorias

| | Conteúdo |
|---|---|
| Regra | Aprovação **cumulativa**: (i) Estados/DF: **maioria absoluta** dos representantes E votos de representantes que correspondam a **mais de 50% da população do País**; (ii) Municípios/DF: **maioria absoluta** dos representantes |
| Presidência | Alternância entre o conjunto dos Estados/DF e o conjunto dos Municípios/DF a cada 2 anos |

## Contencioso administrativo (LC 227/2026)

| | Conteúdo |
|---|---|
| Estrutura | Câmaras de Julgamento + Câmaras Recursais (virtuais, colegiadas e paritárias) do CG-IBS |
| Composição | Servidores de carreira dos Estados e dos Municípios, em paridade; mandato dos julgadores de 2 anos, permitida a recondução |
| Procedimento | Contraditório + ampla defesa + recurso voluntário |
| Coexistência com PAF federal | **Específico do IBS** (≠ DL 70.235); a CBS segue contencioso federal (RFB/CARF) |
| Controle judicial | **PRESERVADO** (CF 5º XXXV) |

## Fiscalização compartilhada

| | Conteúdo |
|---|---|
| Estados + Municípios | Mantêm fiscalização própria (auditoria, RPA, ações coordenadas) |
| CG-IBS | Centraliza dados + edita protocolos + audita |
| Conflito de competência | **Resolve o CG-IBS** (1ª instância) + Judiciário (2ª) |

## Controle externo

| | Conteúdo |
|---|---|
| **TCU** | Controle externo (CF 156-B §3) |
| TCEs + TCMs | Acompanham distribuição local de IBS |
| Transparência | Portal próprio + Lei 12.527/11 + LC 131/09 |

## Distribuição do IBS (CF 156-A §5 V)

| | Conteúdo |
|---|---|
| Princípio | **DESTINO**: ente do consumo recebe |
| Operação interna | Estado + Município integrais |
| Interestadual | 100% no Estado de destino |
| Calculo | Via **NF-e + identificação do adquirente** |
| Auxílios | Fundo Nacional de Desenvolvimento Regional (FNDR, CF 159-A), escalonado até R$ 60 bi/ano |
| Conta-corrente | Repasse diário ao ente de destino |

## Fundo de Desenvolvimento Regional (CF 159-A)

| | Conteúdo |
|---|---|
| Origem | Recursos da União |
| Destino | Compensação a Estados/Regiões perdedores da Reforma |
| Valor | Aportes escalonados que alcançam **R$ 60 bilhões/ano em 2043** (EC 132) |
| Critérios | População + inverso PIB per capita + redução de desigualdades |

## Conflito federativo

| | Conteúdo |
|---|---|
| ADI/ADC | STF, controle constitucional |
| Conflito entre entes | CG-IBS 1ª instância + STF se afetar pacto federativo |
| Ações no STF | Há ADIs questionando aspectos da governança do IBS; **verificar status/numeração atual** antes de citar |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Empresa em SP vende para consumidor em RJ | IBS 100% **Estado do RJ** + Município do destino |
| Conflito de competência fiscal entre dois Municípios | **CG-IBS** decide |
| Contribuinte autuado | Impugna no **CG-IBS** + recurso voluntário |
| Decisão CG-IBS | **Controle judicial preservado** |
| Distribuição diária | Conta-corrente CG-IBS → ente |
| Estado perdedor com Reforma | **FNDR** compensa |

## Distinções essenciais

| | CARF (Federal) | CG-IBS contencioso |
|---|---|---|
| Competência | IRPJ/CSLL/PIS/COFINS/IPI | **IBS** |
| Lei | DL 70.235 | **LC 227/2026** |
| Composição | Paritária Fazenda/contribuinte | **Paritária Estados/Municípios** |

| | Confaz | CG-IBS |
|---|---|---|
| Modelo | Convênios unânimes | **Decisões por maioria** (qualificada em estratégicas) |
| Objeto | Incentivos ICMS | **IBS** integralmente |
| Permanência | Mantido para incentivos antigos (até 2032/extinção ICMS) | **Novo modelo** |

## Erros a evitar

- Tratar CG-IBS como **autarquia federal** (é entidade pública sui generis, com autonomia integral);
- O **controle judicial** das decisões do CG-IBS é assegurado (CF 5º XXXV preservado);
- Aplicar DL 70.235 ao contencioso do IBS (a disciplina é a **LC 227/2026**);
- Confundir CG-IBS com **Confaz** (modelos distintos: unânime × maioria);
- Aplicar **princípio da origem** na distribuição (é destino, CF 156-A §5 V);
- Tratar Fundo de Desenvolvimento Regional como facultativo (CF 159-A obriga);
- Ignorar **fiscalização compartilhada** com Estados/Municípios (não é exclusiva);
- Tratar deliberação do Conselho Superior como maioria simples (exige maioria absoluta nos dois conjuntos + representação de mais de 50% da população do País no conjunto dos Estados/DF);
- Esquecer mandato de **2 anos** com presidência alternada;
- Acreditar que CG-IBS afasta TCU (controle externo expresso, CF 156-B §3);
- Aplicar regulamento do **ICMS atual** a operações de IBS (sistemas distintos);
- Tratar contencioso CG-IBS como instância **dispensável** (impugnação administrativa pode ser opção, mas controle judicial é direito);
- Não considerar a **transição**: o CG-IBS opera com competência crescente a partir de 2026 (fase de teste) até 2033 (plena);
- Tratar o CG-IBS como órgão ainda não instalado: foi **instalado em fevereiro de 2026** (Resolução CSIBS 1/2026) e já editou o **Regulamento do IBS** (Resolução CGIBS 6/2026).

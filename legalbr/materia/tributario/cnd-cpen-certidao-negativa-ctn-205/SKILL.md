# Certidão Negativa de Débitos (CND) + CPD-EN

## Base legal

| | Conteúdo |
|---|---|
| **CTN 205** | CND: pode ser exigida como prova de quitação |
| **CTN 206** | **CPD-EN**: Certidão Positiva com Efeitos de Negativa |
| **CTN 207** | Dispensa em causas urgentes |
| **CTN 208** | Responsabilidade pessoal de servidor por falsa CND |
| **Lei 13.726/2018** | Desburocratização: vedação de exigências exorbitantes |
| **Portaria PGFN/RFB** | Procedimentos administrativos |

## Espécies

| | Conteúdo |
|---|---|
| **CND** | Sem débitos pendentes; situação regular |
| **CPD-EN** (CTN 206) | Há débitos, mas **suspensos** (CTN 151), **garantidos** em EF, ou **prescritos**/extintos; produz os mesmos efeitos da CND |
| **CPD** (positiva pura) | Há débitos sem garantia/suspensão; restritiva |

## CTN 206: CPD-EN

| | Conteúdo |
|---|---|
| Texto | "Tem os mesmos efeitos previstos no artigo anterior a certidão de que conste a existência de créditos **não vencidos, em curso de cobrança executiva em que tenha sido efetivada a penhora, ou cuja exigibilidade esteja suspensa**" |
| Pressupostos alternativos | (a) Não vencidos; (b) Em EF + penhora; (c) Exigibilidade suspensa (CTN 151) |

## CTN 207: dispensa em causas urgentes

| | Conteúdo |
|---|---|
| Texto | "Independentemente de disposição legal permissiva, será dispensada a prova de quitação de tributos, ou seu suprimento, quando se tratar de **prática de ato indispensável para evitar a caducidade de direito**" |
| Exemplos | Inscrição em concurso público + protocolização de pedido com prazo |
| Limite | Não é dispensa permanente; vale apenas para o ato urgente |

## CTN 208: responsabilidade do servidor

| | Conteúdo |
|---|---|
| Texto | "A certidão negativa expedida com **dolo ou fraude**, que contenha erro contra a Fazenda Pública, **responsabiliza pessoalmente** o funcionário que a expedir, pelo crédito tributário e juros de mora acrescidos" |
| Crime | Eventual responsabilidade penal (art. 304 CP + crimes de funcionário público) |

## Causas de suspensão da exigibilidade (CTN 151) → CPD-EN

| Inc. | Causa |
|---|---|
| **I** | Moratória |
| **II** | Depósito integral em dinheiro (Súm. 112 STJ) |
| **III** | Reclamações + recursos administrativos |
| **IV** | Liminar em MS |
| **V** | Tutela em outras ações |
| **VI** | Parcelamento |

## EF + garantia integral → CPD-EN

| | Conteúdo |
|---|---|
| Pressuposto | Penhora **válida + suficiente** |
| Garantia idônea | Dinheiro, seguro garantia, fiança bancária (LEF 7) |
| **Lei 13.043/2014** | Equiparou fiança bancária + seguro garantia a dinheiro |

## Aplicações práticas

| Hipótese | Solução |
|---|---|
| Licitação pública (Lei 14.133/21) | Exige CND/CPD-EN |
| Financiamento BNDES | Exige |
| Recuperação judicial (CTN 191-A + REsp 1.187.404/MT, Corte Especial, 2013) | Mitigado enquanto não havia lei de parcelamento específico; após a Lei 14.112/2020, a regularidade fiscal voltou a ser exigida (REsp 2.053.240/SP, 3ª Turma, 2023: sem as certidões, suspende-se o processo recuperacional; para tributos estaduais/municipais, a exigência depende de lei do ente) |
| Habilitação em concurso público | Exige (salvo CTN 207) |
| Falência | Em geral exige |
| Despachante junto à JUCESP | Exige para alguns atos |
| Recebimento de precatório/RPV | A ausência de CND não inviabiliza o pagamento devido pela Fazenda (jurisprudência) |

## STJ Súm. 446

| | Conteúdo |
|---|---|
| Tese | "Declarado e não pago o débito tributário pelo contribuinte, é **legítima a recusa** de expedição de certidão negativa ou positiva com efeitos de negativa" |
| Aplicação | Confissão em DCTF/GIA: o Fisco pode recusar CND sem garantia |

## Suspensão superveniente à execução fiscal (STJ)

| | Conteúdo |
|---|---|
| Tese | A suspensão da exigibilidade **superveniente** à propositura da execução fiscal **NÃO extingue** o feito; apenas o **suspende** enquanto persistir a causa (jurisprudência consolidada do STJ) |
| Aplicação | EF fica suspensa (não extinta) + CPD-EN possível durante a suspensão |

## Decadência/prescrição → CND

| | Conteúdo |
|---|---|
| Crédito **decaído** | Não constituído → CND |
| Crédito **prescrito** | Reconhecido formalmente → CND |
| Conta correntes da RFB | Pode haver demora; defensável pedir via processo |

## Lei 13.726/2018

| | Conteúdo |
|---|---|
| Conteúdo | Veda exigências exorbitantes; a administração deve aceitar **declaração de hipossuficiência** + autodeclaração + interoperabilidade |
| CND | Quando órgão A já tem dados de órgão B, não pode exigir nova CND |

## CND coletiva + individual

| | Conteúdo |
|---|---|
| **PJ** | CND da CNPJ + filiais (centralizada na matriz, regra geral) |
| **PF** | CND do CPF |
| Empresário individual + MEI | Pode haver alcance pessoal + empresarial |

## Cumulação de tributos

| | Conteúdo |
|---|---|
| Federal | RFB + PGFN: Certidão Conjunta de Débitos |
| Estadual | SEFAZ + PGE |
| Municipal | Secretarias |

## Síntese operacional

| Hipótese | Solução |
|---|---|
| Empresa quer participar de licitação | CND ou CPD-EN |
| EF com penhora integral | **CPD-EN** |
| Parcelamento ativo | CPD-EN |
| Liminar em MS suspendendo | CPD-EN |
| DCTF confessada não paga | Recusa legítima (Súm. 446) |
| Inscrição urgente em concurso | CTN 207: dispensa |
| RJ com aprovação | CND mitigada (REsp 1.187.404; reexigida após Lei 14.112/20) |
| CND falsa por servidor | CTN 208: responde |
| Crédito prescrito não reconhecido | Pedido administrativo + MS |

## Distinções essenciais

| | CND | CPD-EN |
|---|---|---|
| Débitos | Nenhum | Existem, mas suspensos/garantidos |
| Efeitos | Plena | **Equiparados à CND** |

| | CND | CPD pura |
|---|---|---|
| Efeito | Liberatório | **Restritivo** (não permite contratar) |

## Erros a evitar

- A CPD-EN é devida quando há causa **legítima** de suspensão (CTN 151 + CTN 206);
- A CND não alcança o contribuinte com **débito confessado** e não pago (Súm. 446);
- Exigir CND em caso de **urgência** (CTN 207);
- A CND é devida quando o crédito está **prescrito**, exigido o reconhecimento formal;
- Exigir CND para **recebimento de precatório/RPV** (a ausência de CND não impede o pagamento devido pela Fazenda);
- Exigir CND em RJ apesar de REsp 1.187.404 (mitigação), observado que a Lei 14.112/20 reintroduziu a exigência;
- Tratar CRF (FGTS) ou CNDT como CND tributária (regimes distintos);
- Permitir **falsa CND** ou de servidor sem responsabilidade (CTN 208);
- Não considerar **interoperabilidade** (Lei 13.726/18);
- Aceitar CPD-EN sem **penhora suficiente** em EF;
- Exigir nova CND quando órgão público **já tem** os dados;
- Aceitar CPD-EN com **liminar revogada** (perde efeito);
- Confundir CND com CRF/CNDT (sistemas independentes);
- Tratar CPD-EN como certidão **temporária frágil** (tem mesmos efeitos da CND);
- A CPD-EN é devida em parcelamento ativo (CTN 151 VI + 206).

# Substituição Tributária ICMS-ST

## CF 150 §7: fundamento

| | Conteúdo |
|---|---|
| Origem | **EC 3/1993** |
| Hipótese | Substituição tributária **PARA FRENTE** |
| Pressuposto | **LEI EXPRESSA** (não basta decreto/convênio) |
| Garantia | **Restituição IMEDIATA e PREFERENCIAL** se não ocorrer FG presumido |

## Espécies

| Espécie | Conteúdo | Exemplo |
|---|---|---|
| **PARA TRÁS** (regressiva/diferimento) | FG já ocorrido: substituto paga depois | Sucata + leite cru |
| **PARA FRENTE** (progressiva) | FG futuro presumido: antecipa toda a cadeia | **Combustíveis + bebidas + cigarros + autopeças** |
| **CONCOMITANTE** | Simultaneidade | Transporte por autônomo |

**Diferimento SEM crédito**: no diferimento (substituição para trás) não há crédito do imposto na etapa cujo pagamento foi diferido; o diferimento do ICMS na saída do AEAC das usinas/destilarias para o momento da saída da gasolina C das distribuidoras (Convênios ICMS 80/97 + 110/07) NÃO gera direito de crédito para as distribuidoras (STF, Plenário, RE 781.926, Tema 694 RG, j. 03/2023).

## LC 87/96: LEI KANDIR

| Art. | Conteúdo |
|---|---|
| **6** | Autoriza ICMS-ST |
| **8** | **BASE DE CÁLCULO PRESUMIDA** + **MVA (Margem de Valor Agregado)** |
| 9 | Operações interestaduais + convênio |
| **10** | **RESTITUIÇÃO** ao substituído |

## STF Tema 201 (RE 593.849, 19/10/2016)

| | Conteúdo |
|---|---|
| Tese | **DEVIDA RESTITUIÇÃO** quando **base efetiva < presumida** |
| Superou | **RE 195.852 (ADI 1.851)** que limitava restituição à NÃO ocorrência do FG |
| Natureza | Presunção do FG é **IURIS TANTUM** (fundamento: enriquecimento sem causa + capacidade contributiva) |
| BC efetiva **>** presumida | Estado **NÃO cobra a diferença** a mais |
| **Modulação** | Efeitos a partir de **19/10/2016** + casos pendentes |

## CONFAZ: MVA × PMPF

| | Conteúdo |
|---|---|
| **MVA** | Margem de Valor Agregado |
| **PMPF** | Preço Médio Ponderado a consumidor Final (base alternativa à MVA, fixada em convênio/protocolo) |
| Legitimidade na repetição do ICMS-ST | Substituído; na restituição da DIFERENÇA (base efetiva < presumida, Tema 201) é **INAPLICÁVEL o CTN 166** (Tema 1.191 STJ, 1ª Seção, REsp 2.034.975/MG, j. 08/2024) |
| **Lei 13.137/2015** | Alterou regras correlatas de ST |

## STF Tema 69 (RE 574.706): "TESE DO SÉCULO"

| | Conteúdo |
|---|---|
| Tese | **ICMS NÃO compõe base PIS/COFINS** |
| **Modulação** (13/05/2021) | Efeitos desde **15/03/2017**, ressalvadas ações ajuizadas antes |
| Extensão | **ISS na base do PIS/COFINS**: STF **Tema 118** (RE 592.616), julgamento **pendente** (não há tese fixada) + debates sobre outros tributos |

## STJ Tema 1.125 (REsp 1.896.678 + 1.958.265)

| | Conteúdo |
|---|---|
| Julgamento | **13/12/2023** (1ª Seção, rel. Min. Gurgel de Faria; acórdão publicado em 28/02/2024; trânsito em julgado) |
| Tese | "O ICMS-ST não compõe a base de cálculo da Contribuição ao PIS e da COFINS devidas pelo contribuinte substituído no regime de substituição tributária progressiva" |
| Simetria | **Tema 69 STF** |
| **Modulação** | ED acolhidos em parte (REsp 1.958.265, acórdão DJe 26/06/2024): marco da modulação é **15/03/2017** (data do julgamento do Tema 69 STF), **ressalvadas as ações judiciais e os procedimentos administrativos em curso** |

## Legitimidade do SUBSTITUÍDO

| | Conteúdo |
|---|---|
| Contribuinte de fato | **Consumidor final/substituído** |
| Legitimidade ativa para repetir indébito | **SIM** |
| Base | **LC 87/96 art. 10** |
| Diferença do Tema 201 (revenda por preço menor que a base presumida) | **CTN 166 INAPLICÁVEL**: restituição da diferença do ICMS-ST **sem** exigência de prova de não repasse (**Tema 1.191 STJ**, 1ª Seção, REsp 2.034.975/MG, j. 08/2024) |
| Demais repetições de tributo indireto | **CTN 166** + **Súm. 546 STF** (prova do não repasse ou autorização do contribuinte de fato) |
| **STJ Tema 537** (REsp 1.299.303) | Legitimidade do consumidor final em ICMS sobre **energia elétrica** (demanda contratada): peculiaridade do setor |

## EC 132/2023 + LC 214/2025: Reforma Tributária

| | Conteúdo |
|---|---|
| ICMS-ST | **EXTINÇÃO GRADUAL** no período de transição (2026-2032) |
| Modelo IBS + CBS | **Não-cumulatividade PLENA** + crédito amplo |
| Substituição tributária | **NÃO existe** no novo modelo |
| ICMS-ST | Sobrevive apenas para **estoques + operações da transição** |

## Distinções essenciais

| | §7 (FG não ocorrido) | Tema 201 (base inferior) |
|---|---|---|
| Hipótese | FG NÃO se realizou | FG ocorreu + base efetiva < presumida |
| Restituição | **Imediata e preferencial** | Devida (mas modulada) |
| Erro recorrente | Confundir | Confundir |

| | Substituto | Substituído |
|---|---|---|
| Quem recolhe | **SUBSTITUTO** | Quem paga embutido |
| Legitimidade repetir | Sim | **Sim** (diferença do Tema 201: **sem** condição do CTN 166, Tema 1.191 STJ; demais tributos indiretos: CTN 166 + Súm. 546 STF; energia: Tema 537 STJ) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Substituição sem lei expressa | **VEDADA** (CF 150 §7) |
| FG presumido não ocorre | **Restituição IMEDIATA** (§7) |
| Base efetiva < presumida | **Restituição** (Tema 201) |
| Aplicar ADI 1.851 (antiga) | **VEDADO** (superada por Tema 201) |
| ICMS na base PIS/COFINS | **VEDADO** (Tema 69), desde 15/03/2017 |
| ICMS-ST na base PIS/COFINS | **VEDADO** (Tema 1.125), desde 15/03/2017 |
| Contribuinte de fato | **Legitimado** para repetir nas hipóteses do CTN 166 + Súm. 546 STF (energia: Tema 537 STJ) |
| Restituição da diferença do ICMS-ST (Tema 201) | **Sem condição do CTN 166** (Tema 1.191 STJ) |
| Reforma Tributária | ICMS-ST extinto gradualmente |
| MVA fixado por convênio | LC 87/96 + CONFAZ |
| Aplicar Tema 1.125 pré-15/03/2017 sem ação | **VEDADO** (modulação) |

## Erros a evitar

- **Aplicar SUBSTITUIÇÃO SEM LEI EXPRESSA** (CF 150 §7: decreto/convênio insuficientes);
- Negar a **RESTITUIÇÃO** quando a base efetiva for inferior à presumida (Tema 201 STF supera ADI 1.851);
- **Incluir ICMS-ST em base PIS/COFINS** (Tema 1.125 STJ veda);
- **Aplicar Tema 1.125 ANTES de 15/03/2017** sem ação ajuizada (viola modulação);
- **Confundir restituição do §7 (FG não ocorrido) com restituição do Tema 201** (base inferior);
- Negar a legitimidade do **contribuinte de FATO** nas hipóteses do CTN 166 + Súm. 546 STF (energia elétrica: Tema 537 STJ);
- **Exigir do substituído prova de não repasse (CTN 166)** para restituir a diferença do Tema 201 (condição **inaplicável**: Tema 1.191 STJ, 1ª Seção, REsp 2.034.975/MG, j. 08/2024);
- Aceitar **ADI 1.851 como vigente** (superada em 2016);
- Aplicar **Lei Kandir a IBS/CBS** (são tributos distintos);
- Tratar **substituição para frente** como inconstitucional (CF 150 §7 admite);
- Não aplicar **CONFAZ 142/2018** na consolidação;
- Aplicar **modulação Tema 69 pré-15/03/2017** sem ação ajuizada antes.

# Súmula Vinculante 57, Imunidade de E-book e E-reader

## Texto integral

> "A imunidade tributária constante do art. **150, VI, d**, da CF/88 aplica-se à **importação e comercialização**, no mercado interno, do **livro eletrônico (e-book)** e dos **suportes exclusivamente utilizados para fixá-los**, como **leitores de livros eletrônicos (e-readers)**, ainda que possuam **funcionalidades acessórias**."

## Bases normativas

| | Conteúdo |
|---|---|
| **CF 150 VI d** | Imunidade tributária: **livros**, **jornais**, **periódicos** e o **papel destinado à sua impressão** |
| Princípio | **Liberdade de expressão** + **acesso à cultura/educação** (CF 5 IX + CF 215) |
| **PSV 117/DF** | Proposta de Súmula Vinculante que originou a SV 57 |
| **Aprovação** | Plenário Virtual, **11/04/2020** |
| **Publicação** | DJe de **24/04/2020** |

## Precedentes paradigma

| | Conteúdo |
|---|---|
| **RE 330.817 (Tema 593)** | Rel. Min. Dias Toffoli, Plenário, **08/03/2017** |
| **Tese 593** | "A imunidade tributária constante do art. 150, VI, d, da CF/88, aplica-se ao livro eletrônico (e-book), inclusive aos suportes exclusivamente utilizados para fixá-lo" |
| **RE 595.676 (Tema 259)** | Rel. Min. Marco Aurélio, imunidade alcança componentes eletrônicos que acompanham livro/fascículo didático |
| **Tese 259** | A imunidade da CF 150 VI d alcança componentes eletrônicos destinados, exclusivamente, a integrar **unidade didática** com fascículos |

## Núcleo

| | Conteúdo |
|---|---|
| **Interpretação evolutiva** | Imunidade cultural acompanha o **suporte tecnológico** |
| **E-book** | Imune (livro digital) |
| **E-reader** | Imune (suporte **exclusivo** para fixar livros eletrônicos) |
| **Funcionalidades acessórias** | Não descaracterizam (dicionário, marcador, anotação) |
| **Audiolivro** | Imune (mesma lógica) |
| **Importação + mercado interno** | Ambos alcançados |

## Aplicação prática

| Suporte | Imunidade |
|---|---|
| Livro físico | **SIM** (literal) |
| Periódico físico | SIM |
| Jornal físico | SIM |
| Papel destinado a impressão | SIM |
| **E-book** (arquivo digital) | **SIM** (SV 57) |
| **E-reader** (Kindle, Kobo etc.) | **SIM** (SV 57) |
| **Audiolivro** | SIM (interpretação evolutiva) |
| **CD-ROM com livro** | SIM (Tema 593) |
| **Componentes eletrônicos** integrantes de fascículo didático | SIM (Tema 259) |
| **Smartphone/tablet** com app de leitura | **NÃO** (suporte **não exclusivo**) |
| **Computador genérico** | NÃO |
| **Álbum de figurinhas** (com os cromos) | SIM (RE 221.239) |
| **Aplicativo de leitura** isolado | NÃO (não é suporte físico exclusivo) |
| **Tinta e cola** para impressão | Análise específica (RE 174.476 alcançou) |

## Imunidade objetiva

| | Conteúdo |
|---|---|
| **Natureza** | Imunidade **objetiva** (bem), não importa quem é o comerciante |
| **Tributos alcançados** | **Impostos** sobre o bem: IPI, ICMS, II, ISS (sobre serviço editorial gráfico, Súm. 156 STJ) |
| **NÃO alcança** | Contribuições sociais (PIS/COFINS sobre receita da editora, Tema 593 restrição) |
| **Conteúdo** | Independe do conteúdo (mesmo manuais técnicos, álbuns sem figurinhas etc.) |
| **Súm. 657 STF** | Imunidade alcança **filmes** e **papéis fotográficos** para a impressão |

## Casos correlatos

| | Conteúdo |

| **Tema 259** | RE 595.676, componentes eletrônicos + unidade didática |

## Distinguishing

| Hipótese | Saída |
|---|---|
| Editora vende livro físico | **Imune** ICMS/IPI/II |
| Comerciante revende e-reader | **Imune** (SV 57) |
| Vendedor importa Kindle | **Imune** (importação alcançada) |
| Loja vende smartphone com app de leitura | **NÃO** (suporte não exclusivo) |
| Vendedor importa **componente eletrônico** que acompanha fascículo didático | Imune (Tema 259) |
| Editora paga **PIS/COFINS** sobre faturamento | **NÃO imune** (contribuição não é imposto) |
| **ISS** sobre serviço gráfico para terceiros | Análise (Súm. 156 STJ, incide se for industrialização por encomenda) |
| Importação de **álbum de figurinhas** com cromos | Imune (RE 221.239) |

## Erros a evitar

- A imunidade alcança o **e-book**, sem leitura **literal** do CF 150 VI d (SV 57 + Tema 593);
- A imunidade alcança o **e-reader** com funcionalidades acessórias (a SV 57 a admite expressamente);
- Estender SV 57 a **smartphone/tablet** com app de leitura (suporte **não exclusivo**);
- Aplicar SV 57 a **PIS/COFINS** da editora (a imunidade é de impostos, não alcança contribuições);
- A imunidade alcança a **importação** de e-reader (SV 57);
- Confundir imunidade **objetiva** com **subjetiva**;
- A SV 57 alcança o audiolivro (mesma lógica evolutiva);
- Negar imunidade ao **álbum de figurinhas** com os cromos (alcança, RE 221.239);
- Aplicar SV 57 a **filme não didático** (apenas filmes para impressão, Súm. 657);
- Considerar ICMS **devido** sobre venda do e-reader (SV 57 expressa em sentido contrário);
- A imunidade alcança os **componentes eletrônicos** de fascículo didático (Tema 259);
- Exigir registro especial da editora para imunidade objetiva (basta o bem ser livro);
- Aplicar **regime de não cumulatividade** plena ignorando imunidade (livro imune não gera crédito ordinário, questão específica);
- Considerar **app de leitura** vendido isoladamente como suporte (não é);
- Ignorar a **interpretação evolutiva** do CF 150 VI d (núcleo da SV 57).

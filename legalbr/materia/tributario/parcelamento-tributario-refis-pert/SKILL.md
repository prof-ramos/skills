# Parcelamento Tributário

## Base legal

| | Conteúdo |
|---|---|
| **CTN 151 VI** | Suspensão da exigibilidade |
| **CTN 155-A** (LC 104/01) | Disciplina geral: exige lei específica + observa CTN 151 |
| **Lei 10.522/2002** | Parcelamento ordinário federal, até 60x |
| **Lei 11.941/2009** | REFIS da Crise |
| **Lei 12.996/2014** | Reabertura REFIS |
| **Lei 13.496/2017** | PERT (Programa Especial de Regularização Tributária) |
| **Lei 14.148/2021** | PERSE (Setor de Eventos) |
| **Lei 13.988/2020** | Transação tributária (outro instituto) |
| **PGDAU Editais PGFN** | Transação por adesão na dívida ativa: descontos + parcelamento (edital vigente: 6/2026) |
| **LC 123/06** | Parcelamento Simples Nacional |

## Efeitos

| | Conteúdo |
|---|---|
| Suspende exigibilidade (CTN 151 VI) | **SIM** |
| Suspende prescrição | **SIM** (causa de suspensão) |
| Constitui o crédito | **SIM**: adesão é **confissão** (REsp 1.133.027, Tema 375 STJ) |
| Suspende juros/multa? | NÃO; apenas não são cobrados durante o parcelamento |
| Permite CND/CPEN | **SIM**: emite CPD-EN (Certidão Positiva com Efeitos de Negativa, CTN 206) |
| Rescisão | Restabelece exigibilidade + retoma prescrição |
| **Tributação dos descontos** | Descontos e reduções de multas e juros obtidos na adesão a parcelamento especial (PERT e congêneres) constituem **acréscimo patrimonial**: compõem a base de cálculo do **IRPJ e da CSLL** (lucro real ou presumido) e do **PIS/COFINS** (receita bruta) (STJ, 1ª Turma, AgInt no AREsp 2.149.908/RS, j. 06/2024; entendimento pacificado nas duas Turmas da 1ª Seção) |

## Espécies

| | Conteúdo |
|---|---|
| **Ordinário** (Lei 10.522 + RFB) | Até 60x; sem desconto; juros SELIC |
| **Especial** (REFIS/PERT/PERSE) | Descontos significativos + prazo + parcelas |
| **Simples Nacional** | LC 123 art. 21 §15 a 25 |
| **Transação** (Lei 13.988) | Não é parcelamento clássico (concessões mútuas) |
| **PGDAU** (transação por adesão) | Edital PGFN |

## REFIS: histórico

| | Conteúdo |
|---|---|
| **REFIS I** (Lei 9.964/00) | 60 meses |
| **PAES** (Lei 10.684/03) | 180 meses |
| **PAEX** (MP 303/06) | 130 meses |
| **REFIS da Crise** (Lei 11.941/09) | 180 meses + descontos generosos |
| **PERT** (Lei 13.496/17) | 175 meses + descontos juros/multa |
| **PERSE** (Lei 14.148/21) | Setor de eventos: alíquota zero IRPJ/CSLL/PIS/COFINS; **encerrado**: a Lei 14.859/2024 fixou teto de R$ 15 bi e, atingido o limite (ADE RFB 2/2025), o benefício deixou de se aplicar a fatos geradores a partir de abril/2025 (há questionamentos judiciais em curso, inclusive ADIs no STF) |

## STJ Tema 375 (REsp 1.133.027)

| | Conteúdo |
|---|---|
| Tese | A confissão de dívida feita para obter parcelamento **não inibe o questionamento judicial** da obrigação tributária quanto aos seus **aspectos jurídicos** (legalidade/constitucionalidade); quanto aos aspectos **fáticos**, só se invalida por erro, dolo, simulação ou fraude |
| Efeito | A adesão **constitui o crédito** + **suspende a exigibilidade**, mas a confissão é irretratável apenas no plano fático regular |

## STJ Tema 101 (REsp 1.102.577/DF)

| | Conteúdo |
|---|---|
| Tese | Parcelamento **NÃO** é denúncia espontânea (CTN 138): não exclui multa |

## STJ Tema 1.317 (REsp 2.158.358, Primeira Seção, j. 12/11/2025)

| | Conteúdo |
|---|---|
| Tese | A extinção dos embargos à execução fiscal em face da desistência ou renúncia manifestada para adesão a programa de recuperação fiscal **em que já inserida a verba honorária** pela cobrança da dívida pública **não enseja nova condenação em honorários advocatícios** (vedado bis in idem; tese com modulação de efeitos) |

## Exclusão + notificação prévia

| | Conteúdo |
|---|---|
| Notificação prévia | A exclusão do parcelamento pela inadimplência pressupõe **notificação prévia** ao contribuinte (devido processo legal, CF 5 LIV/LV; quanto ao REFIS originário, STF Tema 668: é inconstitucional a supressão da notificação prévia à exclusão) |
| Rescisão por lei/edital | A rescisão por descumprimento, prevista em lei + edital do programa (PERT), é válida, observado o contraditório prévio |

## Confissão extra-tributária

| | Conteúdo |
|---|---|
| Adesão | Confissão **inequívoca** (CTN 174 § único IV: interrompe prescrição); o pedido de parcelamento, **ainda que indeferido**, interrompe a prescrição (Súm. 653 STJ) |
| Limites | Não impede discussão judicial sobre **inconstitucionalidade da norma** instituidora do tributo (REsp 1.133.027: confissão não alcança aspectos jurídicos) |

## Parcelamento + denúncia espontânea

| | Conteúdo |
|---|---|
| Tema 101 STJ | Parcelamento NÃO é denúncia espontânea |
| Pagamento à vista após parcelamento iniciado | Extingue o crédito com os descontos da lei do programa (CTN 156 I) |

## Simples Nacional (LC 123 art. 21 §15-25)

| | Conteúdo |
|---|---|
| Até 60x | Permitido para débitos do Simples |
| **Parcelamento especial 2018** (LC 162/18) | 180x para débitos do Simples |
| Optante em dívida ativa | Pode aderir transação PGDAU |

## PGDAU: editais recentes

| | Conteúdo |
|---|---|
| Edital 11/2025 | Prorrogado até 29/05/2026 (Edital 1/2026) |
| **Edital 6/2026** | Adesão de 01/06/2026 até **30/09/2026** (Portal Regularize) |
| Descontos | **Até 65%** (geral) + **70%** (PF/MEI/ME/EPP e entidades favorecidas) |
| Parcelas | Até **133 parcelas** (categorias favorecidas) |
| Entrada | Variável conforme modalidade (percentual do consolidado, parcelável) |
| Limite débito | Até **R$ 45 milhões** por sujeito passivo |

## CND/CPD-EN

| | Conteúdo |
|---|---|
| Parcelamento ativo | **CPD-EN** (Certidão Positiva com Efeitos de Negativa, CTN 206) |
| Permite contratar | Com a administração pública |
| Recurso | A CPD-EN viabiliza licitações + financiamentos |

## Vedações + restrições

| | Conteúdo |
|---|---|
| Débitos **não tributários** | Lei própria: só são parceláveis se previsto |
| FGTS | Parcelamento separado (Lei 8.036) |
| Débitos previdenciários | Lei específica (Lei 11.457) |
| Dívidas de **terceiros sem autorização** | Vedado |
| Débito em discussão judicial | Em regra **exige desistência** + renúncia |

## Rescisão

| | Conteúdo |
|---|---|
| Inadimplência | 3 parcelas consecutivas ou 6 alternadas (regra geral) |
| Devido processo | Notificação prévia (CF 5 LIV/LV; STF Tema 668 p/ REFIS) |
| Efeito | **Restabelece** exigibilidade, sem prazo de carência |
| Saldo | Inscreve em DA + cobrança imediata |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Adesão parcelamento ordinário | Suspende exigibilidade + emite CPD-EN |
| Adesão PGDAU 2026 | **Descontos 65-70%** + até 133 parcelas (edital vigente) |
| Inadimplência sem notificação | Rescisão **inválida** (devido processo, CF 5 LIV/LV; STF Tema 668 p/ REFIS) |
| Pagamento à vista após parcelamento iniciado | Extingue (CTN 156 I, na forma da lei do programa) |
| Parcelamento como denúncia espontânea | **NÃO** (Tema 101) |
| Confissão na adesão | **Constitui** o crédito (Tema 375) |
| Discussão de inconstitucionalidade | **Mantida** mesmo com adesão (Tema 375) |

## Distinções essenciais

| | Parcelamento | Transação |
|---|---|---|
| Norma | CTN 151 VI + 155-A | **Lei 13.988/20** |
| Desconto | Variável (especiais) | **Concessões mútuas** |
| Extingue? | NÃO (suspende) | **SIM** (com cumprimento integral) |

| | Confissão na adesão | Mérito constitucional |
|---|---|---|
| Atinge? | SIM | **NÃO** (Tema 375: pode discutir inconstitucionalidade) |

## Erros a evitar

- Tratar adesão como **extinção** (apenas suspende; só extingue com pagamento ou transação cumprida);
- Considerar que **confissão na adesão** impede discussão sobre **inconstitucionalidade** da norma (Tema 375: admite);
- Aplicar **denúncia espontânea** a parcelamento (Tema 101: não é);
- Rescindir **sem notificação prévia** (devido processo, CF 5 LIV/LV; STF Tema 668 p/ REFIS);
- Tratar parcelamento como **interrupção da decadência** (não: só interrompe/suspende prescrição);
- Aplicar prazo de até **60 meses** a programa especial (REFIS/PERT: 175+ meses);
- A CPD-EN não alcança o contribuinte com **parcelamento rescindido** (perde efeito);
- Ignorar exigência de **desistência judicial** (regra dos especiais);
- Aplicar PGDAU sem **limite de débito** quando previsto;
- Cobrar **multa de mora** sobre parcelamento ativo (suspende cobrança, não exclui multa devida);
- Tratar **transação** (Lei 13.988) como parcelamento (institutos distintos);
- Tratar os **descontos de multas e juros** da adesão como não tributáveis (compõem a base de IRPJ/CSLL e PIS/COFINS: STJ, 1ª Turma, AgInt no AREsp 2.149.908/RS, j. 06/2024);
- Considerar que reabertura de programa antigo (REFIS) reabre **todas** as condições anteriores (verificar edital);
- Rescindir por **uma única parcela** atrasada (regra geral exige 3 consecutivas);
- O parcelamento de **FGTS** não se cumula com o tributário (regimes separados);
- Cobrar do contribuinte em **parcelamento ativo** via execução fiscal (exigibilidade suspensa: suspende-se ou extingue-se a execução, conforme o momento da adesão).

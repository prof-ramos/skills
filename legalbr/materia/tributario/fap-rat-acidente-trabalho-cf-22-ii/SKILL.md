# RAT/SAT + FAP: Contribuição Acidente do Trabalho

## Base legal

| | Conteúdo |
|---|---|
| **CF 22 XXIII** | Acidente do trabalho: competência da União para legislar |
| **CF 7 XXVIII** | Seguro contra acidentes do trabalho, devido pelo empregador |
| **CF 201 §10** | Trabalhador rural |
| **Lei 8.212/1991 art. 22 II** | Contribuição patronal RAT (Riscos Ambientais do Trabalho), antes SAT (Seguro Acidente do Trabalho) |
| **Decreto 3.048/1999** (RPS) | Regulamento |
| **Decreto 6.042/2007** | FAP (multiplicador) |
| **Decreto 6.957/2009** | Atualização do enquadramento |
| **Decreto 10.410/2020** | Atualizações |

## Conceito

| | Conteúdo |
|---|---|
| RAT (ex-SAT) | Contribuição patronal específica para financiar **aposentadoria especial** + **benefícios por incapacidade** decorrentes de **risco ambiental** |
| Base de cálculo | **Folha de salários** dos empregados + avulsos |
| Alíquota | 1% (leve), 2% (médio), 3% (grave), conforme classificação CNAE |

## Enquadramento (Decreto 6.957/09)

| Risco | Alíquota | Exemplo CNAE |
|---|---|---|
| **Leve (1%)** | Atividades de baixo risco: escritórios, comércio em geral | 6920-6 (Contabilidade) |
| **Médio (2%)** | Risco intermediário: transporte, alguns serviços | 4923-0 (Táxi) |
| **Grave (3%)** | Alto risco: construção civil, mineração, indústria pesada | 4120-4 (Construção) |

## FAP: Fator Acidentário de Prevenção

| | Conteúdo |
|---|---|
| Definição | Multiplicador da alíquota RAT, entre **0,5 e 2,0** |
| Cálculo | Baseado em acidentes + óbitos + invalidez nos últimos **2 anos** |
| Atualização | Anual (Portaria MPS) |
| Efeito | Estímulo à prevenção: empresa segura reduz contribuição (até 50%) |
| Empresas sem trabalhadores expostos | FAP 1,0 (neutro) |

## RAT efetivo

| | Conteúdo |
|---|---|
| Fórmula | RAT × FAP |
| Mínimo | 0,5% (RAT 1% × FAP 0,5) |
| Máximo | 6,0% (RAT 3% × FAP 2,0) |

## STF Tema 554 (RE 677.725): SAT/RAT + FAP

| | Conteúdo |
|---|---|
| Tese | O **FAP**, previsto no art. 10 da Lei 10.666/2003, nos moldes do regulamento do Decreto 3.048/99 (RPS), **atende ao princípio da legalidade tributária** (CF 150, I) |
| Razão | Parâmetros essenciais previstos em lei + delegação a decreto de aspectos técnicos (alíquota SAT/RAT e multiplicador FAP) é admitida |
| Correlato | A constitucionalidade da definição do grau de risco (leve/médio/grave) por decreto já fora reconhecida no RE 343.446 (julgado pré-RG) |

## CNAE: escolha + alterações

| | Conteúdo |
|---|---|
| Cada CNPJ | Possui **CNAE preponderante** |
| Atividade preponderante | A que ocupa maior número de empregados |
| Mudança | Permitida com justificativa + impacta RAT |

## Adicionais para aposentadoria especial

| | Conteúdo |
|---|---|
| **Adicional RAT** | **6% / 9% / 12%** para empregados expostos a agentes nocivos com aposentadoria especial em **25 / 20 / 15 anos** (Lei 8.213 + Dec. 3.048) |
| Aplicação | Cumula com RAT comum |
| Comprovação | PPP (Perfil Profissiográfico Previdenciário) |

## Apuração + recolhimento

| | Conteúdo |
|---|---|
| Periodicidade | **Mensal** |
| Vencimento | Junto com demais previdenciárias (GFIP + EFD-Reinf + GPS/DARF) |
| Cobrança | RFB (após Lei 11.457/07) |

## Aplicação para entidades

| | Conteúdo |
|---|---|
| Empregadores rurais | Lei 8.212 art. 25 + análise específica |
| Cooperativa de trabalho | Lei 10.666/03 |
| Optantes do Simples (anexo IV) | RAT pago separadamente |
| Demais anexos do Simples | RAT incluso no DAS |
| Microempreendedor individual | Em regra dispensado |

## Tributação substitutiva (CPRB)

| | Conteúdo |
|---|---|
| Lei 12.546/2011 | CPRB substitutiva: empresa pode optar (setores específicos) |
| Efeito | Substitui a contribuição patronal (20% sobre folha); o RAT × FAP permanece devido |
| Atualmente | Reoneração gradual (Lei 14.973/2024) |

## Defesa do contribuinte

| | Conteúdo |
|---|---|
| Reclassificação CNAE | Possível com prova |
| Contestação FAP | Procedimento administrativo (Portaria MPS) |
| MS | Cabível para impugnar enquadramento ilegal |

## Temas relevantes

| | Conteúdo |
|---|---|
| **Súm. 351 STJ** | A alíquota do SAT é aferida pelo grau de risco desenvolvido em cada empresa, individualizada pelo seu CNPJ, ou pelo grau de risco da atividade preponderante |
| SV 8 STF | Decadência/prescrição em contribuições previdenciárias: 5 anos (CTN), inconstitucionais arts. 45/46 Lei 8.212 |
| Tema 478 STJ | Aviso prévio indenizado: **não incide** contribuição (verba indenizatória) |
| Tema 985 STF (RE 1.072.485) | Terço de férias **gozadas**: **INCIDE** a contribuição (julgado, modulado a partir de 15/09/2020) |

## Síntese operacional

| Hipótese | Solução |
|---|---|
| Empresa de contabilidade | RAT 1% × FAP |
| Construtora | RAT 3% × FAP |
| Empresa com baixo acidente | FAP < 1 (até 0,5) |
| Empresa com muitos acidentes | FAP até 2,0 |
| Empregado em condição insalubre 25 anos | Adicional 6% RAT |
| Reclassificação CNAE | Possível com prova |
| Optante Simples (anexo IV) | RAT separado |
| CPRB | Substitui patronal (não o RAT × FAP) |

## Distinções essenciais

| | RAT (Lei 8.212 art. 22 II) | Contribuição patronal (art. 22 I) |
|---|---|---|
| Base | Folha | Folha |
| Alíquota | 1%/2%/3% × FAP | 20% |
| Destinação | RAT específico | Geral previdenciária |

| | FAP | RAT |
|---|---|---|
| Função | Multiplicador (0,5-2,0) | Alíquota base |
| Cálculo | Acidentes anteriores | CNAE |

## Erros a evitar

- Tratar RAT/FAP como **inconstitucional** por decreto (Tema 554 STF + RE 343.446: confirmados);
- Aplicar RAT sem **FAP** (multiplicador obrigatório);
- Aceitar **CNAE preponderante errado** (impacta RAT);
- Confundir **RAT** (art. 22 II) com **patronal** (art. 22 I);
- Aplicar adicional **6%** sem comprovação por PPP;
- Esquecer cobrança via **EFD-Reinf** + DARF (após Lei 11.457);
- Aplicar CPRB sem opção formal + setor elegível;
- Não considerar a **reoneração gradual** da CPRB (Lei 14.973/2024);
- Tratar microempreendedor individual como **obrigado** (em regra dispensado);
- Aplicar RAT a cooperado da cooperativa de trabalho (Lei 10.666);
- Confundir RAT com Sistema S (CF art. 240: destinados a SESI/SESC etc.);
- Negar a contestação **administrativa** do FAP (procedimento próprio MPS);
- Aceitar FAP **automaticamente** sem revisão (pode ser questionado);
- Tratar a incidência sobre **terço de férias gozadas** como pendente (Tema 985 STF já julgado: **incide**, modulado a partir de 15/09/2020);
- Aplicar prescrição de **10 anos** (SV 8: 5 anos);
- Não considerar **aposentadoria especial** quando empregado exposto.

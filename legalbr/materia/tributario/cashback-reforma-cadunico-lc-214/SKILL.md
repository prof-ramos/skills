# Cashback Tributário

## Base constitucional + legal

| | Conteúdo |
|---|---|
| **CF 156-A §5 VIII** | Devolução do IBS/CBS a pessoas físicas (mecanismo de **personalização** / redução da regressividade) |
| **LC 214/2025 arts. 112-124** | Regulamentação detalhada (Devolução Personalizada do IBS e da CBS) |
| **Lei 12.212/2010** | Tarifa Social de Energia Elétrica, referência para "baixa renda" |
| **Decreto 5.209/2004** | Bolsa Família + cadastramento CadÚnico |

## Beneficiários (LC 214 art. 113)

| | Conteúdo |
|---|---|
| Família | Inscrita no **CadÚnico** |
| Renda per capita | ≤ **1/2 salário mínimo** (regra geral) |
| Responsável | Titular do CadÚnico (responsável familiar maior de 16 anos, preferencialmente mulher, Decreto 6.135/2007 art. 2) |
| Cadastro | Atualizado em até **24 meses** |

## Percentuais de devolução (LC 214 art. 118 + §)

| Item | CBS | IBS |
|---|---|---|
| **Itens essenciais**: energia elétrica + água + esgoto + gás canalizado + GLP (botijão até 13kg) + telecomunicações | **100%** | **20%** |
| **Demais** bens e serviços tributados | **20%** | **20%** |
| Bens **com alíquota zero** | Sem cashback (já zerado) | Sem cashback |

> União/Estados/Municípios podem **ampliar** (nunca reduzir) os percentuais. Os mínimos são os do art. 118 da LC 214/2025.

## Operação

| | Conteúdo |
|---|---|
| Crédito direto | Conta na instituição financeira indicada (preferência: Caixa) |
| Cashback em fatura | Energia + GLP: **estorno na própria conta** do consumidor |
| Apuração | Por documento fiscal, vinculada ao CPF do adquirente |
| Liquidação | Após confirmação do recolhimento (split payment) |
| Operacionalização | **CBS gerida pela RFB** (art. 114) + **IBS gerido pelo CG-IBS** (art. 115) |
| **Início** | Devoluções calculadas com base no consumo familiar realizado a partir de **janeiro/2027 para a CBS** e de **janeiro/2029 para o IBS** (LC 214 art. 123) |

## Natureza jurídica

| | Conteúdo |
|---|---|
| Espécie | **Devolução tributária** (≠ renda; ≠ transferência social) |
| Inclusão na BC IRPF? | **NÃO**: não é renda tributável (devolução de tributo) |
| Impenhorabilidade / cessão | A devolução tem natureza assistencial-tributária (LC 214, arts. 112-124); **verificar dispositivo específico** antes de afirmar impenhorabilidade/vedação de cessão |

## Fiscalização + integridade

| | Conteúdo |
|---|---|
| CG-IBS + RFB | Cruzamento de dados (CPF + CadÚnico + NF-e + cartões) |
| Fraude | Crime do **art. 171 §3 CP** (estelionato contra fazenda) + perda do benefício |
| Suspensão | Quando renda extrapolar o limite (verificação semestral) |

## Coexistência com tarifa social

| | Conteúdo |
|---|---|
| Tarifa Social (Lei 12.212/10) | **Desconto na tarifa** (subsídio ANEEL) |
| Cashback | **Devolução do tributo** |
| Compatibilidade | **CUMULATIVO**: beneficiário recebe desconto tarifário + cashback de IBS/CBS |

## Estados + Municípios: cashback estadual/municipal

| | Conteúdo |
|---|---|
| CF 156-A §5 VIII | Permite **complementação** local |
| Mínimos | Devem respeitar os percentuais mínimos da LC 214 |
| Adicionais | Estado/Município pode ampliar (cashback local) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Família CadÚnico com renda ≤ 1/2 SM | **Beneficiária** |
| Compra com NF-e + CPF na nota | Acumula cashback do IBS+CBS efetivamente recolhidos |
| Energia residencial baixa renda | **100% CBS + 20% IBS** |
| GLP (botijão até 13kg) | **100% CBS + 20% IBS** |
| Telecom + água + esgoto + gás canalizado | **100% CBS + 20% IBS** (essenciais) |
| Supermercado/demais em geral | **20% CBS + 20% IBS** |
| Cesta básica nacional | **Sem cashback** (já alíquota zero) |
| Renda extrapola 1/2 SM | **Suspende** na próxima atualização cadastral |
| IRPF | **NÃO tributa** (devolução de tributo, não é renda) |

## Distinções essenciais

| | Tarifa social | Cashback |
|---|---|---|
| Natureza | Desconto na tarifa | **Devolução de tributo** |
| Norma | Lei 12.212/10 + ANEEL | **CF 156-A §5 VIII + LC 214** |
| Coexistem? | **SIM** (cumulativos) | SIM |

| | Bolsa Família | Cashback |
|---|---|---|
| Natureza | Transferência de renda | Devolução tributária |
| Tributação | Isento IRPF | Não-renda (devolução de tributo) |
| Fonte | Tesouro | **IBS+CBS recolhidos** |

## Erros a evitar

- Tratar cashback como **renda** (é devolução de tributo, não tributável pelo IRPF);
- A cumulação com **tarifa social** é admitida (cumulativos);
- Aplicar à família **não inscrita no CadÚnico** (LC 214 art. 113 exige cadastro);
- O cashback não alcança a **cesta básica nacional** (alíquota zero, sem tributo a devolver);
- O cashback de **100% da CBS + 20% do IBS** alcança os itens essenciais (energia, água, esgoto, gás canalizado, GLP até 13kg, telecom);
- Aplicar o percentual de itens essenciais (100% CBS) aos **demais bens/serviços** (estes têm 20% CBS + 20% IBS);
- Tratar o IBS como devolvido a 100% (o IBS é **20%** mesmo nos itens essenciais; só a CBS é 100%);
- Considerar cashback como **renda para Bolsa Família** (não conta como renda);
- Confundir cashback com **subsídio** (não é benefício, é devolução constitucional);
- Reduzir cashback abaixo do **mínimo legal** (Estado/Município/União só pode ampliar);
- Aplicar cashback **antes do split payment** efetivo (só sobre tributo recolhido);
- Aplicar cashback ao consumo do **ano-teste de 2026**: a devolução considera o consumo a partir de **janeiro/2027 (CBS)** e **janeiro/2029 (IBS)** (LC 214 art. 123);
- Esquecer **CPF na nota** (sem identificação não acumula);
- O cashback não se afasta por **erro do estabelecimento** em destacar IBS/CBS (responsabilidade do contribuinte de direito, não do beneficiário).

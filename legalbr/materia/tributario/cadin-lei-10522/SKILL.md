# CADIN: Cadastro Informativo

## Base legal

| | Conteúdo |
|---|---|
| **Lei 10.522/2002** | Disciplina geral |
| **MP 1.973-27/2000** | Origem |
| **CF 5º LV** | Contraditório + ampla defesa |

## Conceito

| | Conteúdo |
|---|---|
| Definição | **Cadastro Informativo** federal de pessoas que possuem obrigações pecuniárias vencidas + não pagas perante órgãos e entidades da Administração Pública Federal |
| Natureza | **Administrativa/informativa** (≠ judicial) |
| Operador | Coordenado pela RFB/PGFN; alimentado por cada órgão credor |

## Inclusão (Lei 10.522 art. 2)

| | Conteúdo |
|---|---|
| Pressuposto | Débito **certo + líquido + exigível** vencido |
| Comunicação prévia | **75 dias** antes da inclusão; devedor notificado para regularizar |
| Sem regularização | Inclusão efetiva |

## Consulta obrigatória (Lei 10.522 art. 6)

| | Conteúdo |
|---|---|
| Obrigatória para | (a) Realização de operações de **crédito** com **recursos públicos**; (b) Concessão de **incentivos fiscais/financeiros**; (c) Celebração de **convênios + contratos** com órgãos federais; (d) Liberação de **benefícios** federais |
| **EXCEÇÕES** | (a) Operações com **recursos não-federais**; (b) Programas obrigatórios definidos em lei; (c) Saúde + educação + assistência social, em regra |

## Exclusão (Lei 10.522 art. 7)

| | Conteúdo |
|---|---|
| Pagamento integral | Exclui em até 5 dias |
| Suspensão da exigibilidade (CTN 151) | **Exclui automaticamente** (incluindo parcelamento ativo) |
| Decisão administrativa anulando | Exclui |
| Decisão judicial | Exclui |

## STJ + STF: controle

| | Conteúdo |
|---|---|
| **STF** | CADIN **NÃO é sanção política** desde que: (1) observado contraditório; (2) exclusão automática com suspensão; (3) não impeça atividade essencial |
| **Súm. 70, 323 e 547 STF** (referência) | Vedam interdição de estabelecimento, apreensão de mercadorias e proibição do exercício profissional como meios coercitivos de cobrança; não alcançam o CADIN se respeitadas as garantias |
| **STJ** | Inclusão sem notificação prévia (75 dias) é nula |

## MS para impugnar CADIN

| | Conteúdo |
|---|---|
| Cabimento | Quando inclusão indevida (sem notificação prévia, débito prescrito, suspensão da exigibilidade ignorada) |
| Tutela | Liminar para excluir |
| Causa | Suspensão (CTN 151) é causa automática |

## Inclusão + EF + Protesto CDA: coexistência

| | Conteúdo |
|---|---|
| Coexistem | CADIN + Protesto + EF: instrumentos distintos |
| Efeito | Restrição administrativa cumulativa |
| Garantia | Penhora idônea → exclusão do CADIN (via CTN 151) |

## Hipóteses de aplicação

| Hipótese | Solução |
|---|---|
| Empresa busca financiamento BNDES | Consulta CADIN; sem regularidade, sem crédito |
| Convênio com órgão federal | CADIN + CND + CPD-EN exigidos |
| Participação em licitação | CADIN + CND |
| Liberação Bolsa Família/programa social | Em regra **dispensado** |
| Atendimento médico SUS | Dispensado |
| Operação de crédito comercial privada | NÃO consulta CADIN (regra) |

## Lei 13.726/2018: desburocratização

| | Conteúdo |
|---|---|
| Vedação | Exigências exorbitantes vedadas; a Administração deve consultar diretamente o CADIN |
| Reflexo | Não pode exigir CND ao mesmo tempo que CADIN sem fundamento |

## Procedimento de impugnação

| | Conteúdo |
|---|---|
| 1 | Notificação prévia (75 dias) |
| 2 | Devedor pode pagar, parcelar ou impugnar |
| 3 | Sem resposta → inclusão |
| 4 | Recurso administrativo |
| 5 | MS judicial |

## Encerramento da relação tributária

| | Conteúdo |
|---|---|
| Pagamento integral | Exclui em até 5 dias úteis |
| Parcelamento (CTN 151 VI) | Exclui enquanto adimplente |
| Tutela (CTN 151 IV/V) | Exclui |
| Decadência/prescrição reconhecida | Exclui após reconhecimento administrativo/judicial |

## CADIN × CND × Protesto CDA

| | CADIN | CND | Protesto CDA |
|---|---|---|---|
| Natureza | Cadastro federal | Atestado de regularidade | Publicidade extrajudicial |
| Norma | Lei 10.522 | CTN 205-208 | Lei 9.492/97 |
| Efeito | Restringe relação federal | Permite contratar com poder público | Restritivo creditício amplo |
| Exclusão | Automática com CTN 151 | Concessão de CPD-EN | Após pagamento ou sustação |

## Síntese operacional

| Hipótese | Solução |
|---|---|
| Empresa quer convênio federal | CADIN regular + CND |
| Tutela suspendendo crédito | Exclusão automática |
| Parcelamento ativo | Exclusão automática |
| Inclusão sem notificação prévia | **NULA** + MS |
| Programa social essencial | Dispensa CADIN |
| Atividade essencial | STF protege |
| Multa pendente + tutela | Suspende → exclui |

## Erros a evitar

- Tratar CADIN como **sanção política** automática (STF: não é, se observado o contraditório);
- A exclusão é automática nas hipóteses de **CTN 151** (parcelamento, liminar);
- Aplicar inclusão sem **notificação 75 dias** (nula);
- Confundir CADIN com **SERASA/SPC** (institutos distintos, privados);
- Exigir CADIN para **atividades essenciais** (saúde/educação);
- Aplicar CADIN a operação com recursos **não-federais** (fora do art. 6);
- A CND não é devida quando o CADIN está limpo mas há débito ativo;
- Ignorar a **Lei 13.726/18**: a administração deve consultar diretamente;
- Considerar inclusão como **causa de exigibilidade** (não é; só cadastro);
- Aplicar CADIN como **substituto** de EF (não substitui);
- O MS é cabível para impugnar inclusão indevida;
- Excluir do CADIN sem **comunicação ao órgão credor** (procedimento);
- Tratar protesto CDA como excludente automático do CADIN (institutos diferentes);
- Aplicar CADIN a débito **prescrito** sem reconhecimento formal;
- Aplicar CADIN a **menor de idade** sem representação adequada.

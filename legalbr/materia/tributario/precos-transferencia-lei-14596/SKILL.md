# Preços de Transferência

## Base legal

| | Conteúdo |
|---|---|
| **Lei 14.596/2023** | Nova lei de preços de transferência (convertida da MP 1.152/22) |
| **Decreto 11.835/2023** | Regulamento |
| **IN RFB 2.161/2023** | Detalhamento operacional |
| **Lei 9.430/96 arts. 18-24** | **REVOGADOS** pela Lei 14.596 (antigo regime de margens fixas) |
| **OECD Transfer Pricing Guidelines 2022** | Modelo internacional adotado |

## Vigência

| | Conteúdo |
|---|---|
| **Aplicação obrigatória** | A partir de **01/01/2024** |
| **Aplicação opcional** | Para **2023** (contribuinte podia optar) |
| Regime antigo | Lei 9.430, vigente até 2023 (novo regime opcional em 2023) |

## Princípio fundamental: Arm's Length

| | Conteúdo |
|---|---|
| Definição | Operações entre **partes vinculadas** devem refletir os **termos** que seriam acordados entre **partes independentes** em condições comparáveis |
| Adoção | Padrão **OECD** integral (≠ regime antigo, com margens fixas) |
| Análise funcional | Funções desempenhadas + ativos utilizados + riscos assumidos (FAR) |

## Partes vinculadas (Lei 14.596 art. 4)

| | Conteúdo |
|---|---|
| Conceito | Inclui controladores + controladas + coligadas + irmãs + influência significativa + estabelecimentos permanentes (PEs) + entidades em relação contratual com efeitos econômicos similares |
| Conceito ampliado | Mais abrangente que regime antigo |

## Operações sujeitas (Lei 14.596 art. 3)

| | Conteúdo |
|---|---|
| Importação | Bens + serviços + intangíveis + direitos |
| Exportação | Idem |
| Royalties | Sujeitos (≠ regime antigo que excluía) |
| Operações financeiras | Empréstimos + garantias + cash pooling |
| Operações com paraísos | **Sempre** sujeitas |

## Métodos (Lei 14.596 art. 11)

| Método | Sigla | Aplicação |
|---|---|---|
| **Preço Independente Comparável** | **PIC** (CUP, Comparable Uncontrolled Price) | Preferencial quando há comparáveis |
| **Preço de Revenda menos Lucro** | **PRL** (RPM, Resale Price Method) | Bens distribuídos |
| **Custo mais Lucro** | **MCL** (CPM, Cost Plus Method) | Bens manufaturados |
| **Margem Líquida da Transação** | **MLT** (TNMM) | Quando outros impraticáveis |
| **Divisão do Lucro** | **MDL** (PSM, Profit Split) | Operações integradas |
| **Outros** | Quando comprovado mais adequado | (residual) |

## Diferença com regime antigo

| | Antigo (Lei 9.430) | Novo (Lei 14.596) |
|---|---|---|
| Princípio | Margens **fixas** | **Arm's length** com comparáveis |
| Métodos | PIC, PRL 20/30/40/60%, CPL com 20% | PIC, PRL, MCL, MLT, MDL (sem margens fixas) |
| Royalties | Excluídos | **Incluídos** |
| Análise funcional | Limitada | **Central** (FAR) |
| Comparáveis | Limitados | **Amplos** + benchmark |

## Ajustes

| Tipo | Conteúdo |
|---|---|
| **Espontâneo** | Contribuinte ajusta antes do prazo da declaração |
| **Compensatório** | No fim do exercício, corrige distorções |
| **Primário** | RFB autua a diferença |
| **Correspondente** | Outro país ajusta para evitar dupla tributação |
| **Secundário** | RFB pode requalificar como **dividendo ficto** |

## Documentação (3 níveis OECD)

| | Conteúdo |
|---|---|
| **Local File** | Detalha as operações controladas do contribuinte |
| **Master File** | Visão global do grupo multinacional |
| **CBC Report** (Country-by-Country) | Para grupos com receita > **R$ 2,26 bi** ou EUR 750 mi (IN 1.681/16 + 2.161/23) |
| Prazo entrega | Geralmente até último dia útil do **julho** do ano seguinte |

## Range interquartil + análise

| | Conteúdo |
|---|---|
| Range | Mediano dos comparáveis (P25 a P75) |
| Ponto correto | Em regra **mediana** se não houver justificativa |
| Ajuste | Para mediana se ficar fora do range |

## Aplicação a paraísos fiscais

| | Conteúdo |
|---|---|
| IN 1.037/10 | Lista de paraísos + regimes privilegiados |
| Regime privilegiado | Aplica preços de transferência mesmo sem vinculação |
| Sigilo + alíquota < 17% | Ativadores |

## Safe harbours

| | Conteúdo |
|---|---|
| Não há | Lei 14.596 **NÃO prevê** safe harbours fixos do regime antigo |
| Simplificação | Algumas opções para PMEs (IN 2.161 + atualizações) |

## Penalidades

| | Conteúdo |
|---|---|
| Documentação ausente/deficiente | Multas percentuais com teto de **R$ 5.000.000** (Lei 14.596 + IN 2.161) |
| Ajuste do IRPJ/CSLL | Selic + multa de **75%** (ofício) |
| Fraude/dolo | Qualificada **100%** (Lei 14.689) |

## STJ + interpretações

| | Conteúdo |
|---|---|
| STF Tema 537 | Correlato: tributação de lucros de controladas no exterior (art. 74 da MP 2.158-35, aplicável a países de tributação favorecida) |
| Tribunais administrativos (CARF) | Aplicam Lei 14.596 desde 2024 |

## Coexistência com tratados

| | Conteúdo |
|---|---|
| MAP (Mutual Agreement Procedure) | Procedimento de resolução de disputas |
| Brasil | Adotou o MAP em seus tratados e na regulamentação da RFB |
| **Pillar Two** | Lei 15.079/24, tributação mínima efetiva de 15% |

## Síntese operacional

| Hipótese | Solução |
|---|---|
| Subsidiária BR compra de matriz UK | Aplicar Lei 14.596: análise FAR + comparáveis |
| Royalties pagos à holandesa do grupo | Sujeitos (≠ regime antigo) |
| Operação com BVI | Sempre sujeita (paraíso) |
| Empresa com receita > R$ 2,26 bi | CBC report |
| Operação sem comparáveis | TNMM ou MDL |
| Ajuste espontâneo antes da declaração | Permitido |
| Sem documentação | Multa R$ 20k-5mi + autuação |
| Range OK | Sem ajuste |
| Fora do range | Ajusta para mediana |

## Distinções essenciais

| | Antigo | Novo (14.596) |
|---|---|---|
| Princípio | Margens fixas | **Arm's length** |
| Royalties | Excluídos | **Incluídos** |
| Análise | Mecânica | **Funcional + econômica** |
| Methods | Limitados | **OECD completo** |

## Erros a evitar

- Aplicar **margens fixas** do regime antigo a operações pós-2024 (revogadas);
- Excluir **royalties** do escopo (Lei 14.596 os inclui);
- Aplicar PIC quando não há **comparáveis válidos** (preferir TNMM/MDL);
- Ignorar **análise funcional FAR** (central no novo regime);
- Não preparar **Local File + Master File** (multas elevadas);
- Esquecer **CBC report** para grupos > R$ 2,26 bi;
- Aplicar safe harbour do regime antigo (não existe no novo);
- Não considerar **paraíso fiscal** (sempre sujeito);
- Aplicar range automaticamente sem análise (justificar P25/P75);
- Tratar transação financeira como fora (incluída);
- Considerar PMEs como dispensadas (apenas simplificações específicas);
- Aplicar ajustes **retroativamente** a 2023 sem opção (era opcional);
- Ignorar ajustes **secundários** (RFB pode requalificar);
- Esquecer **Pillar Two** (Lei 15.079);
- Considerar contracts **intercompany** como prova suficiente (precisa análise FAR + comparáveis);
- Não atualizar **lista IN 1.037** (paraísos podem mudar).

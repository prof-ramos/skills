# Regimes Diferenciados

## Base constitucional + legal

| | Conteúdo |
|---|---|
| **CF 156-A §6** | **Rol taxativo**: categorias com redução obrigatória |
| **LC 214/2025** | Detalha alíquotas + produtos + serviços |
| **EC 132 art. 9º §10** | Avaliação **quinquenal** de custo-benefício dos regimes diferenciados |
| **Decreto 12.955/2026 + Resolução CGIBS 6/2026** | Regulamentos da CBS (DOU 30/04/2026) e do IBS detalham a aplicação dos regimes diferenciados (disposições comuns na Portaria Conjunta MF/CGIBS 7/2026) |
| Anexos LC 214 | NCM por NCM dos bens/serviços beneficiados |

## Estrutura das alíquotas

| Nível | Aplicação |
|---|---|
| **Cheia** | Regra geral, alíquota plena IBS+CBS |
| **Redução 60%** | Aplicada à alíquota de referência |
| **Redução 30%** | Aplicada à alíquota de referência |
| **Zero** | Cesta básica nacional + medicamentos selecionados + Prouni |
| Especiais | Regime monofásico (combustíveis) e específicos |

## Setores com redução de 60% (CF 156-A §6 I + LC 214)

| Setor | Detalhamento |
|---|---|
| **Saúde** | Serviços médicos + odontológicos + psicológicos + fisioterapia + planos (regime próprio) + dispositivos médicos selecionados |
| **Educação** | Ensino infantil + fundamental + médio + superior + técnico + extensão |
| **Transporte coletivo** | Transporte público coletivo de passageiros rodoviário + metroviário + ferroviário + hidroviário, de caráter **urbano/semiurbano/metropolitano** |
| **Produtos agropecuários** in natura | Não inclusos na cesta básica nacional |
| **Insumos agrícolas** | Sementes + fertilizantes + defensivos + ração + corretivos |
| **Insumos para pesca + aquicultura** | Próprios |
| **Bens culturais** | Livros + jornais + periódicos (já imunes); espetáculos + serviços audiovisuais + arte |
| **Segurança e soberania nacional** | Bens e serviços de soberania e segurança nacional, segurança da informação e cibernética |
| **Atividade esportiva** | Federada/profissional |
| **Higiene/limpeza para baixa renda** | Selecionados |

## Setores com redução de 30% (CF 156-A §6 II)

| | Conteúdo |
|---|---|
| **Profissionais regulamentados** | Atividades das **profissões intelectuais, científicas, literárias ou artísticas** sujeitas a fiscalização por conselho profissional, desde que prestadas por sociedade que tenha sócio profissional habilitado |
| Exemplos | Medicina + advocacia + engenharia + arquitetura + contabilidade + odontologia + nutrição + psicologia + veterinária + administração |
| Forma | Sociedade simples + uniprofissional + LTDA com sócio profissional |
| Limite | Atividade-fim; não engloba atividades comerciais conexas |

## Alíquota zero (CF 156-A §6 + LC 214)

| Categoria | Conteúdo |
|---|---|
| **Cesta básica nacional** | Arroz + feijão + leite + carnes (bovina/suína/frango/peixe) + óleo + manteiga + açúcar + café + sal + farinha + mandioca + ovos + raízes/tubérculos + frutas + hortaliças (rol em LC) |
| **Medicamentos** | Lista específica (Anexos da LC 214): alíquota zero para certos medicamentos (ex.: câncer, doenças raras, retrovirais) e redução para os demais |
| **Prouni** | Mensalidades de bolsa integral |
| **PCDs** | Dispositivos de acessibilidade (selecionados) |
| **Automóveis (taxistas + PcD/TEA)** | Alíquota zero na aquisição por motoristas profissionais (táxi) e pessoas com deficiência ou TEA (LC 214 art. 149) |
| **Dispositivos médicos** específicos | Anexos |

## Cesta básica nacional × Cesta estendida

| | Conteúdo |
|---|---|
| **Nacional** (alíquota zero, CF 156-A §6) | Lista única + uniforme |
| **Estendida** | Estados/Municípios podem ampliar com cashback adicional |

## Outras especificidades

| | Conteúdo |
|---|---|
| **Hotelaria + parques + restauração + agências de viagem + aviação regional + SAF** | Regime específico/simplificado (LC 214, Título V) |
| **Bares + restaurantes** | Recolhimento simplificado sobre receita |
| **Aviação regional** | Regime específico (LC 214 arts. 284 e ss.) |

## Revisão quinquenal (CF 156-A §9)

| | Conteúdo |
|---|---|
| Periodicidade | A cada 5 anos |
| Quem propõe | Poder Executivo |
| Quem aprova | Congresso (LC) |
| Critério | Avaliação custo-benefício + aderência aos objetivos |

## Convivência com cashback (CF 156-A §5 VIII)

| | Conteúdo |
|---|---|
| Bem com alíquota zero | **Sem cashback** (não há tributo) |
| Bem com redução 60% | **Cashback sobre a fração tributada** |
| Bem com redução 30% | **Cashback sobre a fração tributada** |
| Energia residencial baixa renda | **Cashback 100%** (independentemente da redução) |

## STF: controle da taxatividade

| | Conteúdo |
|---|---|
| ADIs pendentes | Discussão sobre extensão por analogia (vedada: rol taxativo) |
| Princípio | **Taxatividade** + interpretação restritiva (CTN 111 III) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Consulta médica | **Redução 60%** |
| Sociedade médica com sócio profissional | **Redução 30%** (alternativa quando se enquadrar) |
| Mensalidade escolar | **Redução 60%** |
| Bilhete de ônibus urbano | **Redução 60%** |
| Sementes para plantio | **Redução 60%** |
| Honorário advocatício | **Redução 30%** |
| Arroz + feijão | **Zero** |
| Medicamento em lista de alíquota zero (anexos LC 214) | **Zero** |
| Mensalidade Prouni integral | **Zero** |
| Livros físicos/digitais | **Imunes** (CF 150 VI d) + regimes diferenciados a periódicos/cultura |
| Hotelaria | **Regime simplificado** |

## Distinções essenciais

| | Redução 60% | Redução 30% |
|---|---|---|
| Critério | Setor essencial (saúde/educação/agro/transporte) | Profissão regulamentada |
| Beneficiário | Bem/serviço | **Sociedade** profissional |
| Rol | LC 214 (objetivo) | Conselhos profissionais |

| | Cesta básica nacional | Cesta estendida |
|---|---|---|
| Alíquota | **Zero** (federal-uniforme) | Tributada + cashback |
| Quem amplia | (não se amplia) | Estado/Município |

## Erros a evitar

- Estender regime diferenciado **por analogia** (rol taxativo + CTN 111 III, interpretação restritiva);
- Aplicar redução 30% a **sociedade comercial sem sócio profissional regulamentado** (LC 214 + CF 156-A §6 II);
- Aplicar redução 60% a **transporte de carga** (regime é transporte coletivo de **passageiros**);
- Tratar **cesta estendida estadual** como alíquota zero federal (é cashback local);
- Aplicar **cashback** sobre item com **alíquota zero** (não há tributo a devolver);
- Aplicar IBS+CBS cheia a **medicamentos em lista de alíquota zero** dos anexos da LC 214;
- Aplicar redução a atividade-meio quando regime se aplica só à atividade-fim profissional;
- Esquecer a avaliação **quinquenal** de custo-benefício (EC 132 art. 9º §10, com risco de transição para a alíquota padrão);
- Aplicar alíquota cheia a **Prouni** integral (zero);
- Tratar regime simplificado de **bares/restaurantes** como redução constitucional (é específico LC 214);
- Confundir **profissional regulamentado** (redução 30%) com **autônomo** (regime padrão);
- Confundir a alíquota **zero na aquisição de automóveis por taxistas/PcD** (LC 214 art. 149) com redução no serviço de transporte individual (o regime de 60% é do transporte público **coletivo**);
- Aplicar redução de 60% a **insumos comerciais** (apenas insumos agrícolas/pesca/aquicultura);
- Aplicar imunidade ao **espetáculo cultural** quando seria regime diferenciado de 60% (não é imunidade);
- O cashback alcança a fração tributada de bem com redução 60% (incide sobre o que se tributa).

# IBS, Imposto sobre Bens e Serviços

## Base constitucional + legal

| | Conteúdo |
|---|---|
| **CF 156-A** (EC 132/2023) | Cria o IBS, competência **compartilhada** Estados+DF+Municípios |
| **CF ADCT 124-133** | Transição |
| **LC 214/2025** | Regulamenta IBS + CBS, sancionada 16/01/2025 |
| **LC 227/2026** (ex-PLP 108/2024) | Institui o **Comitê Gestor do IBS** (CG-IBS) + processo administrativo + normas gerais de ITCMD, sancionada 13/01/2026 |
| **Resolução CGIBS 6/2026** | **Regulamento do IBS** (30/04/2026) |
| **Decreto 12.955/2026 + Portaria Conjunta MF/CGIBS 7/2026** | Regulamento da CBS com Livro I de normas comuns CBS/IBS + formalização das disposições comuns entre os dois regulamentos |
| **Ato Conjunto RFB/CGIBS 4/2026 + Ato Técnico Conjunto 1/2026** | Cronograma dos DF-e e documentação técnica; suspensão de rejeições por ausência dos campos de IBS/CBS não elimina a obrigação jurídica aplicável |
| **Resolução do Senado** | Fixa a alíquota de referência (IBS a partir de 2029) |

## Natureza jurídica

| | Conteúdo |
|---|---|
| Espécie | **Imposto** (CF 156-A) |
| Ente | **Estados + DF + Municípios**, dual |
| Princípio | **DESTINO** (consumo); ≠ ICMS atual (origem em parte) |
| Não-cumulatividade | **PLENA** (CF 156-A §1 II) |
| Forma | **POR FORA** |
| Modelo | Inspirado em **IVA** (TVA francês + VAT europeu) |

## Cronograma

| Ano | Evento |
|---|---|
| **2026** | Teste: IBS **0,1%** + CBS 0,9% (compensáveis, art. 348 LC 214; **recolhimento dispensado** se cumpridas as obrigações acessórias) |
| **2027** | CBS plena; **ICMS/ISS mantidos** |
| **2029** | ICMS+ISS **90%** + IBS aumenta |
| **2030** | ICMS+ISS **80%** + IBS aumenta |
| **2031** | ICMS+ISS **70%** + IBS aumenta |
| **2032** | ICMS+ISS **60%** + IBS aumenta |
| **2033** | **Extinção total** ICMS/ISS; IBS pleno |

## Hipóteses (LC 214 art. 4)

| | Conteúdo |
|---|---|
| Regra | Operações **onerosas** com bens (materiais/imateriais/direitos) e serviços |
| Inclui | Locação + cessão + licenciamento + leasing + permuta |
| Importação | Sim, IBS-Importação (substitui parte do ICMS-Importação) |
| Exportação | **NÃO incide** (imunidade, com manutenção integral do crédito) |

## Não incidência (LC 214 art. 6)

| | Conteúdo |
|---|---|
| Exportações | **Imunes** |
| Transferências mesmo titular | NÃO incide (consolida Tema 1.099/RG STF + ADC 49) |
| Salários/rendimentos | NÃO |
| Doações sem contraprestação | NÃO |
| Dividendos + JCP | NÃO |

## Base de cálculo (LC 214 art. 12)

Valor da operação **POR FORA**. Não compõem: descontos incondicionais + IBS/CBS (não integram a própria base).

## Alíquotas (CF 156-A §1 IV + V)

| | Conteúdo |
|---|---|
| Estrutura | **Soma da alíquota estadual + municipal** |
| Fixação | Cada ente fixa **a sua** por lei própria (Estado/Município) |
| Alíquota **de referência** | **Senado Federal** + auxílio CG-IBS, para garantir a carga global |
| **Teste 2026** | **0,1%** (referência fixada pela União) |
| **Plena (estimada)** | ≈ **17-18%** (Estado + Município somados) |
| Reduzida 60% | Regimes diferenciados |
| Reduzida 30% | Profissionais regulamentados |
| Zero | Cesta básica nacional + medicamentos selecionados + Prouni |

## Crédito amplo

| | Conteúdo |
|---|---|
| Princípio | **Crédito = IBS efetivamente recolhido** na etapa anterior |
| Inclui | **Uso/consumo** + ativo + insumos + serviços |
| Vedação | Bens/serviços de uso pessoal + entrada isenta (regra) |
| Apropriação | **Condicionada ao pagamento** via split payment (CF 156-A §5 III) |
| Saldo credor | Ressarcimento com prazos acelerados na LC 214 (até **60 dias** em hipóteses qualificadas); saldos credores de **ICMS** ao final de 2032: **240 parcelas mensais** com IPCA (ADCT, EC 132) |

## Comitê Gestor do IBS (CF 156-A §3-§4)

| | Conteúdo |
|---|---|
| Natureza | **Entidade pública sob regime especial**, com autonomia técnica/administrativa/financeira |
| Composição | **Paritária**: 27 representantes dos Estados+DF e 27 dos Municípios (eleição em colegiados) |
| Função | Editar normas + arrecadar + fiscalizar + distribuir IBS + julgar contencioso administrativo |
| **Instalação** | Fevereiro/2026: primeira reunião extraordinária do Conselho Superior em 19 e 23/02/2026; Resolução CSIBS 1/2026 aprovou estrutura provisória e instituiu **6 Comissões de Trabalho** técnico-preparatórias, com coordenação paritária Estados/Municípios |
| **LC 227/2026** (ex-PLP 108/2024) | Disciplina governança + processo administrativo + contencioso |
| Decisões | Aprovação cumulativa: maioria absoluta dos representantes dos dois conjuntos, exigida no conjunto dos Estados/DF representação de mais de 50% da população do País (LC 227/2026) |

## Princípio do DESTINO

| | Conteúdo |
|---|---|
| Regra | IBS pertence ao **Estado + Município do consumo** (≠ ICMS atual, com origem em parcela) |
| Operação interestadual | Receita 100% no destino |
| Transferência mesmo titular | NÃO incide (cf. Tema 1.099/RG STF + ADC 49 + LC 204/23 + LC 214/25) |

## Split Payment (CF 156-A §5 II + LC 214 arts. 31-35)

| | Conteúdo |
|---|---|
| Mecânica | Adquirente paga **IBS direto ao CG-IBS** no instante da liquidação |
| Operador | Sistema do CG-IBS integrado a meios de pagamento |
| Efeito | Reduz inadimplência + acelera crédito do adquirente |
| **Crédito condicionado** | Adquirente só compensa o que foi **efetivamente recolhido** |

## Cashback (CF 156-A §5 VIII + LC 214 arts. 112-124)

| | Conteúdo |
|---|---|
| Beneficiários | Famílias **CadÚnico** com renda per capita ≤ 1/2 SM |
| Devolução do IBS | **20%** (regra geral **e** itens essenciais; diferente da CBS, que é 100% nos essenciais) |
| Itens essenciais | Energia + água + esgoto + gás canalizado + GLP até 13kg + telecom (CBS 100% / IBS 20%) |
| Operação | Crédito direto via instituição pagadora |

## Regimes diferenciados (CF 156-A §6)

| Setor | Redução |
|---|---|
| Saúde + educação + transporte coletivo + agropecuária + insumos agrícolas + bens culturais | **60%** |
| Profissionais regulamentados | **30%** |
| Cesta básica nacional + medicamentos selecionados + Prouni | **Zero** |

## Regimes específicos (CF 156-A §6 II)

| Setor | Regra |
|---|---|
| Combustíveis | **Monofásico ad rem** (cobrado uma única vez, recolhido pelo CG-IBS) |
| Serviços financeiros + seguros + planos de saúde | Receita líquida (margem) |
| Bens imóveis | **Redutor social** + cumulativo opcional |
| Cooperativas | Regime favorecido |
| Bares + hotelaria + restaurantes | Simplificado |
| **Combustíveis** | CG-IBS distribui ao destino |

## ZFM (CF 92-A ADCT)

| | Conteúdo |
|---|---|
| Manutenção | Até **2073** (incentivos preservados) |
| Mecânica | **Crédito presumido de IBS** + alíquotas do IPI reduzidas a zero a partir de 2027, exceto produtos com industrialização incentivada na ZFM (EC 132) |
| LC 214 | Cálculo + escrituração |

## Imunidades preservadas (LC 214 art. 8)

- CF 150 VI **todas** (recíproca + templos + entidades + livros + música BR);
- Exportações (CF 156-A §1 III);
- CF 195 §7 (beneficentes).

## Contencioso (LC 227/2026)

| | Conteúdo |
|---|---|
| Estrutura | Câmaras de Julgamento + Câmaras Recursais do CG-IBS (virtuais, colegiadas e paritárias) |
| Recurso | Próprio sistema do CG-IBS |
| Observação | O contencioso administrativo não afasta o Judiciário; controle judicial preservado (CF 5º XXXV) |

## Simples Nacional + IBS

| | Conteúdo |
|---|---|
| Optante mantém DAS | Alíquota efetiva única |
| Opção pelo **regime regular** de IBS/CBS | Possível; gera crédito ao adquirente |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Empresa em 2026 | Destacar **IBS 0,1% + CBS 0,9%** em NF (acessórias) |
| Empresa em 2029 | ICMS+ISS **90%** + IBS gradativo |
| Em 2033 | **Só IBS+CBS+IS**; ICMS/ISS extintos |
| Operação interestadual | IBS 100% **destino** |
| Cesta básica nacional | **Zero** |
| Energia residencial baixa renda | **Cashback: 100% da CBS + 20% do IBS** |
| Profissional regulamentado | **Redução 30%** |
| Saldo credor antigo (ICMS) | **240 meses** com IPCA a partir de 2033 |
| ZFM | Crédito presumido até 2073 |
| Transferência mesmo titular | **NÃO incide** |

## Distinções essenciais

| | ICMS atual | IBS |
|---|---|---|
| Ente | Estado | **Estado+Município** (dual) |
| Não-cumulatividade | Restrita (LC 87) | **PLENA** (uso/consumo + ativo) |
| Forma | Por dentro | **Por fora** |
| Destinação | Origem (parte) | **DESTINO** total |
| Substituição tributária | Para frente + ST | Centralizada/monofásica em casos pontuais |
| Crédito | Vedações setoriais | **Apenas pagamento efetivo** (split) |

| | IBS | CBS |
|---|---|---|
| Ente | Estado+Município | **União** |
| Substitui | ICMS+ISS | PIS+COFINS |
| Arrecadação | **CG-IBS** | **RFB** |
| Alíquota teste 2026 | **0,1%** | **0,9%** |

## Erros a evitar

- Tratar IBS como continuidade do **ICMS** (estrutura constitucional distinta, CF 156-A);
- Aplicar **princípio da origem** ao IBS (é **destino** integral);
- O crédito de **uso/consumo** é admitido no IBS (LC 214);
- Apurar IBS **por dentro** (é por fora);
- Ignorar o cronograma do Ato Conjunto RFB/CGIBS 4/2026: NF-e, NFC-e, CT-e, CT-e OS, BP-e não semiurbano/não aéreo, MDF-e, GTV-e, NF3e, DC-e e NFS-e Via desde **03/08/2026**; NFCom, DIR e NFS-e em hipóteses gerais da LC 116 desde **01/10/2026**; eventos periódicos mensais da DeRE D-1101, D-1106, D-1121, D-2101, D-1198 e D-1199 desde **15/11/2026**; NFGas, NFAg, NF-e ABI e demais hipóteses de NFS-e desde **01/12/2026**; Simples, operações monofásicas em NF-e, Duimp e eventos residuais da DeRE desde **01/01/2027**;
- Tratar a ausência de rejeição técnica dos campos de IBS/CBS no Ato Técnico Conjunto 1/2026 como dispensa da obrigação jurídica ou das condições do art. 348 da LC 214/2025;
- Confundir **0,1%** (teste) com plena (≈ 17-18% somatório);
- Atribuir a arrecadação do IBS à RFB ou a outro órgão (compete ao **CG-IBS**);
- Tratar o IBS como tributo da União (a gestão é federativa compartilhada, CF 156-A e 156-B);
- Aplicar IBS a **exportações** (imune);
- Tratar **transferência entre estabelecimentos** do mesmo titular como FG (Tema 1.099 STF + ADC 49 + LC 204/23 + LC 214: não incide);
- Ignorar **alíquota de referência** do Senado;
- Aplicar regime **cheio** a setor com redução 60% (saúde/educação/transporte coletivo);
- O crédito **sem pagamento** efetivo do fornecedor não é admitido (split condicionado);
- Tratar ICMS como extinto **em 2026** (extinção plena só em **2033**; 90/80/70/60% nos anos 2029-2032);
- Aplicar IBS sobre **cesta básica nacional** (alíquota zero);
- O **cashback** alcança a família elegível CadÚnico (IBS: 20% sempre; CBS: 20% geral e 100% nos itens essenciais: energia/água/esgoto/gás/GLP/telecom);
- Aplicar **ICMS-ST tradicional** ao IBS, cuja sistemática é diferente (centralização/monofásico pontual);
- Confundir contencioso CG-IBS com **exclusão do Judiciário** (CF 5º XXXV preservado).

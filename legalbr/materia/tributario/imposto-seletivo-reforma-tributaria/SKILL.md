# Imposto Seletivo (IS)

## Marco legal

- **EC 132/2023** (Reforma Tributária);
- **LC 214/2025** (regulamentação);
- **CF 153 VIII** (novo IS);
- Decreto regulamentar (em elaboração);
- Princípios constitucionais tributários (CF 150);
- **EC 132** + **EC 33/2001** (extrafiscalidade).

## Conceito + finalidade

| | Conteúdo |
|---|---|
| **Caráter** | **Extrafiscal** (não-arrecadatório) |
| **Função** | Desestimular consumo nocivo |
| **Sin tax** | Imposto do pecado |
| **Modelo internacional** | Inspirado em práticas europeias |
| **Base constitucional** | CF 153 VIII (incluído pela EC 132) |

## Vigência

| Período | Conteúdo |
|---|---|
| **2026** | Sistema atual |
| **2027** | **Início da cobrança do IS** |
| **2028-2033** | Transição IPI → IS + IBS + CBS |
| **2033** | Aplicação plena do novo modelo |

## Produtos abrangidos (LC 214 art. 409 §1)

| Categoria | Conteúdo |
|---|---|
| **Veículos automotores** | Carros, motos |
| **Embarcações** | Lanchas, iates |
| **Aeronaves** | Civis |
| **Produtos do tabaco** | Cigarros + cigarrilhas + charutos + tabaco |
| **Bebidas alcoólicas** | Cerveja, vinho, destilados |
| **Bebidas açucaradas** | Refrigerantes |
| **Minerais** | Ferro + outros |
| **Combustíveis fósseis** | Petróleo + gás natural + carvão |
| **Concursos de prognósticos** | Loterias + apostas + fantasy sports |

## Alíquotas projetadas (dependem de lei ordinária)

| Produto | Alíquota |
|---|---|
| **Cigarros + tabaco** | **250%** |
| **Bebidas alcoólicas** | 46-62% (varia por teor) |
| **Refrigerantes + açucaradas** | 32% |
| **Veículos** | Variável (caráter ambiental + segurança) |
| **Minerais + petróleo** | **0,25%** (teto constitucional de **1%** do valor de mercado na extração, CF 153 §6 VII) |
| **Fantasy sports + jogos** | A definir |

> **Alíquotas fixadas em lei ordinária (CF 153 §6 VI), específicas por unidade de medida ou ad valorem; os valores acima são projeções da tramitação legislativa.**

## Características

| | Conteúdo |
|---|---|
| **Monofásico** | Incide **uma única vez** (LC 214 art. 409) |
| **Não gera crédito** | Não há creditamento com operações anteriores nem posteriores (LC 214 art. 410); o IS **integra a base de cálculo do ICMS, do ISS, do IBS e da CBS** (CF 153 §6 IV) |
| **Federal** | Competência da União; administração e fiscalização pela **RFB** (LC 214 art. 411), contencioso administrativo pelo DL 70.235 |
| **Sem destinação específica** | Receita geral (em parte para vinculações) |
| **Princípio da seletividade** | Diferente do IPI (alíquotas conforme essencialidade) |

## Comparativo IPI × IS

| | IPI | IS |
|---|---|---|
| **Base constitucional** | CF 153 IV | CF 153 VIII |

## Regime constitucional (CF 153 §6 + CF 150 §1)

| | Conteúdo |
|---|---|
| **CF 153 §6 VI** | Alíquotas fixadas em **LEI ORDINÁRIA**, específicas (por unidade de medida) ou ad valorem |
| Anterioridade | Aplicáveis as regras gerais (CF 150 III b/c), sem exceção expressa própria para o IS |
| **CF 153 §6 VII** | Minerais: alíquota **máxima de 1%** na extração |
| Substituição do IPI | Substitui **parcialmente** o IPI extrafiscal; alíquotas do IPI zeradas a partir de 2027, salvo produtos com industrialização incentivada na **ZFM (até 2073)** |
| Destinação | **Compartilhada**: repartição a Estados/DF + Municípios via FPE/FPM (tributo federal) |
| 2026 | O IS ainda **não é cobrado**; cobrança a partir de **2027** |

## Relação com IBS/CBS

| | Conteúdo |
|---|---|
| **Monofásico** | Incide **uma única vez**, **sem creditamento interno** (LC 214 art. 410) |
| **INTEGRA a base de IBS + CBS** | O IS **compõe a base de cálculo** de ICMS, ISS, IBS e CBS (CF 153 §6 IV; IBS/CBS incidem "por fora", mas sobre valor que inclui o IS) |
| Não próprio | O IS **não integra a sua própria** base de cálculo |
| Não gera crédito de IBS/CBS | A incidência concentrada do IS não dá crédito ao adquirente |

## Erros a evitar

- Confundir IS com **IPI** (regimes próprios; IS monofásico);
- Achar que IS é **arrecadatório** (extrafiscal);
- Aplicar IS a **toda industrialização** (lista taxativa);
- Esquecer **monofasia** + única incidência;
- Calcular **alíquotas atuais** sem decreto regulamentar;
- Aplicar IS a **livros + entidades imunes** (imunidades aplicam);
- Confundir com **CIDE** (campos próprios);
- Esquecer **vigência 2027** (em transição até 2033);
- Esquecer que o IS **integra a base de cálculo do IBS e da CBS** (CF 153 §6 IV), mas **não** gera crédito (LC 214 art. 410) nem compõe a própria base (CF 153 §6 III);
- Não considerar **exportações imunes**;
- Aplicar alíquotas antes da **lei ordinária + regulamentação**;
- Subestimar **disputas constitucionais** sobre alíquotas.

# IGF, Imposto sobre Grandes Fortunas

## CF 153 VII

| | Conteúdo |
|---|---|
| Competência | **UNIÃO** |
| Status | **ÚNICO imposto federal JAMAIS INSTITUÍDO** desde 1988 |
| Veículo | **LEI COMPLEMENTAR** (CF 153 VII) |
| Vedação | **MP** vedada (CF 62 §1 III) |

## Princípios aplicáveis

| | Conteúdo |
|---|---|
| **CF 145 §1** | **CAPACIDADE CONTRIBUTIVA** |
| Sobreposição com IPTU/ITR/IR | Não há vedação constitucional expressa; a coordenação de bases é questão de desenho legislativo da futura LC |

## PROJETOS em tramitação

| Projeto | Conteúdo |
|---|---|
| **PLP 277/2008** (Luciana Genro) | Alíquotas **0,4% a 1,5%** |
| **PLP 183/2019** (Senador Plínio Valério) | Patrimônio líquido > **12.000× o limite mensal de isenção do IRPF**, alíquotas de **0,5% a 1%** |
| Pós-Lei 15.270/2025 (isenção mensal de R$ 5.000) | Pela fórmula do PLP 183/2019, o piso corresponderia a **~R$ 60 milhões** |
| Outros PLPs | Diversos projetos apensados/apresentados (PLS 315/2015, PLPs 38 e 50/2020 etc.); nenhum aprovado |

## EC 132/2023 (Reforma Tributária)

| | Conteúdo |
|---|---|
| Tratamento | **NÃO tratou** do IGF |
| Regulamentação | **EXCLUÍDA** do PLP 108/2024 |

## STF ADO 55: decisão paradigmática (06/11/2025)

| | Conteúdo |
|---|---|
| Resultado | **8x1** |
| Tese | **RECONHECEU OMISSÃO INCONSTITUCIONAL** do Congresso em regulamentar IGF após **37 anos** |
| **Prazo** | **NÃO FIXADO** (proposta isolada de fixação de 24 meses) |
| **Sanção** | **Sem sanção automática**; apenas **CIÊNCIA AO LEGISLATIVO** |

## Limites constitucionais

| | Conteúdo |
|---|---|
| **Princípio da LEGALIDADE TRIBUTÁRIA** (CF 150 I) | Omissão **NÃO autoriza cobrança imediata** |
| Necessário | **LC efetivamente promulgada** |

## Precedente da omissão (ADO 55)

| | Conteúdo |
|---|---|
| Origem | **ADO 55/DF**, ajuizada pelo **PSOL (2019)**, Rel. Min. Marco Aurélio |
| Núcleo | Ausência de **lei complementar** instituindo o IGF (CF 153 VII) por mais de 37 anos |

## Distinções essenciais

| | IGF | IR |
|---|---|---|
| Foco | **Patrimônio** (estoque) | **Renda** (fluxo) |
| Status | Não instituído | Há lei |

| | IGF | IPTU/ITR |
|---|---|---|
| Foco | Patrimônio total | Imóvel individual |
| Sobreposição | Sem vedação expressa | Não impede IGF |

| | LC (153 VII) | LO + MP |
|---|---|---|
| IGF | **EXIGE LC** | **VEDADO MP** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| União quer cobrar IGF | **EXIGE LC** (CF 153 VII) |
| MP institui IGF | **VEDADO** (CF 62 §1 III) |
| Cobrança imediata pós-ADO 55 | **VEDADA** (CF 150 I) |
| PLP 277/2008 | **0,4-1,5%** |
| PLP 5/2026 (Câmara) | Em tramitação inicial: propõe IGF sobre patrimônio a partir de R$ 10 milhões |
| Base | **PATRIMÔNIO LÍQUIDO** > R$ 60mi (estimativa) |
| Reforma EC 132 | **NÃO trata** IGF |
| ADO 55 STF | **Omissão reconhecida** (mas sem prazo/sanção) |

## Erros a evitar

- **Tratar IGF como instituído** (jamais foi);
- **Aceitar IGF por LO ou MP** (exige LC + CF 62 §1 III veda MP);
- **Cobrar IGF imediatamente pós-ADO 55** (legalidade tributária);
- Aplicar **alíquotas de PLP** como vigentes (são projetos);
- A **omissão** está reconhecida (ADO 55, 8x1);
- Tratar **prazo fixado** pelo STF (não foi);
- Confundir **IGF com IR** (patrimônio × renda);
- Invocar o CF 145 §2 contra o IGF (o dispositivo trata de base de cálculo de TAXAS, não de sobreposição de impostos);
- Tratar **EC 132 como tendo regulado** IGF (não regulou);
- Aplicar **PL 1.087/2025** ao IGF (é da reforma do IR);
- Tratar a **omissão** como autorizadora de cobrança imediata (exige LC promulgada, CF 150 I).

# ADIs 4357 + 4425 (EC 62 / Precatórios)

## Identificação

| | Conteúdo |
|---|---|
| Ações | **ADI 4357 + ADI 4425** |
| Autores | OAB + ANAMATRA + ASMEPRO + outros |
| Relator originário | Min. Ayres Britto |
| Redator | Min. **Luiz Fux** |
| Mérito | **14/03/2013** |
| Modulação | **25/03/2015** |

## Tese estruturante

| | Conteúdo |
|---|---|
| Resultado | EC 62/2009: **inconstitucionalidade PARCIAL** |
| Dispositivos derrubados | Leilões + compensação unilateral + TR como correção + parcelamento abusivo |
| Fundamento | CF 5 XXXVI (coisa julgada) + CF 100 + isonomia + razoabilidade |
| Modulação | **5 anos** de eficácia ultra-ativa do regime impugnado |

## Dispositivos atingidos

| | Conteúdo |
|---|---|
| Leilão de precatórios | **Inconstitucional**: deságio compulsório violava isonomia |
| Compensação compulsória com débitos tributários | **Inconstitucional**: sem participação do credor |
| Índice **TR** | Correção pela poupança/TR declarada **inconstitucional** (v. Tema 810 STF); consolidou-se o **IPCA-E** como índice de correção até a EC 113/2021 (SELIC unificada de 09/12/2021 a 09/09/2025; desde a EC 136/2025, IPCA + juros simples de 2% a.a. no requisitório) |
| Prazo de 15 anos | Excessivo |

## EC 113/2021 + ADPF 854

| | Conteúdo |
|---|---|
| **EC 113** | Tetos + parcelamento atualizado + acordo direto |
| **ADPF 854** | Processo estrutural: planos de pagamento + monitoramento |

## Tema 810 STF (RE 870.947)

| | Conteúdo |
|---|---|
| Correção monetária | É **inconstitucional** a atualização das condenações da Fazenda pela remuneração da **caderneta de poupança** (art. 1º-F da Lei 9.494/97, red. Lei 11.960/09): índice inidôneo para capturar a variação de preços |
| Juros de mora | Em débitos de natureza **tributária**, aplicam-se os mesmos juros com que a Fazenda remunera seu crédito (isonomia); em condenações **não tributárias**, o índice da poupança é constitucional |
| Regimes posteriores | **SELIC** unificada de 09/12/2021 a 09/09/2025 (EC 113/2021; Tema 1.419 STF); desde 10/09/2025, EC 136/2025: IPCA + juros simples de 2% a.a. no requisitório (objeto da ADI 7.873, sem liminar, em pleno vigor) |

## Tema 1.037 STF + SV 17 (juros no período de graça)

| | Conteúdo |
|---|---|
| **SV 17** | Não incidem juros de mora sobre os precatórios pagos dentro do período do art. 100 §5º da CF |
| **Tema 1.037 STF** | A SV 17 não foi afetada pela EC 62/2009; havendo inadimplemento, os juros fluem **após o período de graça** |

## Acordo direto

| | Conteúdo |
|---|---|
| **EC 94/2016 + Res. CNJ 303/2019** | Acordo direto com deságio (até 40%) |
| Voluntário | Credor decide |
| **Diferente de leilão** | (que era compulsório) |

## Distinções

| | EC 62/2009 (originária) | Pós-ADIs 4357/4425 |
|---|---|---|
| Leilão | Sim | **Vedado** |
| Compensação unilateral | Sim | **Vedada** |
| Correção | TR | **IPCA-E** (Tema 810) |
| Prazo | 15 anos | Encerrado em 2020 (EC 99) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Leilão de precatório | **Vedado** |
| Compensação unilateral | **Vedada** |
| Correção monetária | **IPCA-E** |
| Acordo direto | Voluntário (EC 94 + Res. 303) |
| Coisa julgada | Preservada |
| Regime ordinário | CF 100 |
| Regime especial | Encerrado em 2020 (EC 99/2017) |
| ADPF 854 | Plano estrutural |
| Modulação | 5 anos ultra-ativos |
| SV 17 | Sem juros de mora no período de graça do art. 100 §5º (Tema 1.037: fluem após o inadimplemento) |

## Erros a evitar

- Aplicar **TR/poupança** como índice de correção (Tema 810: inconstitucional);
- Compensar precatório com tributo unilateralmente;
- Tratar EC 62 integralmente vigente (parcialmente derrubada);
- Aplicar leilão compulsório;
- O acordo direto voluntário é admitido;
- Esquecer ADPF 854 (processo estrutural).

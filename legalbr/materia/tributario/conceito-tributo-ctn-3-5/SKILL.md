# Conceito de Tributo + Classificações

## CTN art. 3: DEFINIÇÃO

| | Conteúdo |
|---|---|
| Tese | "Tributo é toda prestação **PECUNIÁRIA COMPULSÓRIA**, em moeda ou cujo valor nela se possa exprimir, que **NÃO CONSTITUA SANÇÃO de ato ilícito**, instituída em lei e cobrada mediante **atividade administrativa plenamente VINCULADA**" |

## Elementos

| | Conteúdo |
|---|---|
| **(a) PECUNIARIEDADE** | Dação em pagamento de imóvel autorizada pela LC 104/2001 (CTN 156 XI) |
| **(b) COMPULSORIEDADE** | NÃO voluntária; distingue de preço público (**Súm. 545 STF**) |
| **(c) NÃO-SANÇÃO** | Distingue de multa, embora ***PECUNIA NON OLET*** (CTN 118) permita tributar atividade ilícita |
| **(d) LEGALIDADE estrita** | **CF 150 I** |
| **(e) VINCULAÇÃO administrativa** | Lançamento (CTN 142) |

## Súm. 545 STF

| | Conteúdo |
|---|---|
| Tese | "**Preços de serviços públicos e taxas NÃO se confundem**" |

## CTN art. 4

| | Conteúdo |
|---|---|
| Tese | Natureza jurídica é determinada pelo **FATO GERADOR** |
| Irrelevantes | **Denominação + destinação** |
| **Mitigado** | Pelo STF para **CONTRIBUIÇÕES ESPECIAIS** (destinação **É essencial**) |

## CTN art. 5: teoria TRIPARTITE

| | Conteúdo |
|---|---|
| Espécies | **IMPOSTOS + TAXAS + CONTRIBUIÇÕES DE MELHORIA** |

## CF 145: tripartição constitucional

| | Conteúdo |
|---|---|
| Tributos | Impostos + Taxas + Contribuições de melhoria |

## Teoria PENTAPARTIDA / QUINQUIPARTITE (STF dominante)

### Base
| | Conteúdo |
|---|---|
| **STF RE 146.733 + ADI 447** | Adota |

### As 5 espécies
| | Conteúdo |
|---|---|
| **I** | **IMPOSTOS** (CF 145 I + CF 153/155/156) |
| **II** | **TAXAS** (CF 145 II): vinculadas a serviço/poder de polícia |
| **III** | **CONTRIBUIÇÕES DE MELHORIA** (CF 145 III): obra pública com valorização |
| **IV** | **EMPRÉSTIMOS COMPULSÓRIOS** (CF 148): guerra/calamidade OU investimento público urgente + **sempre por LC** + **restituíveis** |
| **V** | **CONTRIBUIÇÕES ESPECIAIS** (CF 149): sociais + CIDE + interesse de categorias profissionais/econômicas |

## COSIP: CF 149-A (EC 39/2002)

| | Conteúdo |
|---|---|
| Tese | **Contribuição para iluminação pública** |
| **STF RE 573.675** | Reconheceu como espécie *sui generis* tributária; **afastou exigência de uti singuli das taxas** |

## CLASSIFICAÇÕES OPERACIONAIS

| Critério | Categorias |
|---|---|
| Hipótese | **Vinculados × NÃO-vinculados** |
| Destinação | De arrecadação **vinculada × não-vinculada** |
| Função | **FISCAL + EXTRAFISCAL + PARAFISCAL** |
| Competência | **PRIVATIVA + COMUM + RESIDUAL** (CF 154 I: sempre LC) + **EXTRAORDINÁRIA** (CF 154 II: guerra) |

## *PECUNIA NON OLET* (CTN 118)

| | Conteúdo |
|---|---|
| Tese | **TRIBUTAÇÃO de atividade ILÍCITA** é permitida |
| Razão | **Fato gerador irrelevante quanto à licitude** |
| Exemplo | Receita oriunda do tráfico → IR pode incidir |

## Distinções essenciais

| | Tributo | Preço público |
|---|---|---|
| Origem | Lei | **Contrato** |
| Compulsório | Sim | NÃO |
| Sanção | Não | Pode |
| **Súm. 545 STF** | Distingue | |

| | Tributo | Multa |
|---|---|---|
| Natureza | Não-sanção | **SANÇÃO** |

| | Tripartite (CTN) | Pentapartida (STF) |
|---|---|---|
| Espécies | 3 | **5** |
| Empréstimos compulsórios | NÃO inclui | **INCLUI** |
| Contribuições especiais | NÃO inclui | **INCLUI** |

## Síntese operacional

| Hipótese | Classificação |
|---|---|
| IPI | **Imposto** |
| Taxa de coleta de lixo | **Taxa** |
| Asfalto + valorização | **Contribuição de melhoria** |
| Guerra externa | **Empréstimo compulsório** (CF 148 I) |
| CIDE-combustíveis | **Contribuição especial** (CF 149) |
| Iluminação pública | **COSIP** (CF 149-A) |
| Atividade ilícita + receita | **Pecunia non olet**: tributa |
| Preço cobrado por concessionária | **Preço público** (não tributo) |

## Erros a evitar

- **Aplicar teoria TRIPARTITE** isoladamente (STF, pentapartida);
- Tratar **preço público como tributo** (Súm. 545 STF distingue);
- Considerar **destinação irrelevante** para contribuições (mitigação do CTN 4);
- **Afastar tributação de atividade ILÍCITA** (pecunia non olet, CTN 118);
- Tratar **empréstimo compulsório como definitivo** (CF 148, restituível);
- Admitir **empréstimo compulsório por LO** (exige LC);
- Confundir **COSIP com taxa** (RE 573.675, sui generis);
- Aplicar **multa como tributo** (não é);
- Tratar tributo **sem lançamento vinculado** (CTN 142);
- Aplicar **competência residual sem LC** (CF 154 I);
- Confundir **fiscal × extrafiscal × parafiscal** (funções).

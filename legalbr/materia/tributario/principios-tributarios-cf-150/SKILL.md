# Princípios Tributários

## CF 150 I: LEGALIDADE TRIBUTÁRIA

| | Conteúdo |
|---|---|
| Vedação | Exigir/aumentar tributo **SEM LEI** |
| **Exceções (alíquota por decreto)** | **II + IE + IPI + IOF** (CF 153 §1) |
| ICMS combustíveis monofásico | CF 155 §4 IV "c": só redução e restabelecimento |
| CIDE combustíveis | CF 177 §4 I "b": só redução e restabelecimento |
| **LC obrigatória** | Empréstimo compulsório (CF 148) + imposto residual (CF 154 I) + **IGF** (CF 153 VII, pendente) + **IBS/CBS/IS** (LC 214/2025) |

## CF 150 II + 145 §1: IGUALDADE + CAPACIDADE CONTRIBUTIVA

| | Conteúdo |
|---|---|
| CF 150 II | Vedação a distinção arbitrária |
| **CF 145 §1** | Tributos pessoais e **graduados conforme capacidade econômica** |
| **STF RE 562.045** (ITCMD-RS) | Capacidade contributiva alcança **TODOS os impostos** (reais ou pessoais): **ITCMD progressivo é válido** |
| **STF RE 736.090 / Tema 863** | Multa qualificada limitada a **100% do débito** (até 150% na reincidência do art. 44 §1º-A da Lei 9.430/96); conjuga capacidade contributiva + vedação ao confisco |

## CF 150 III: IRRETROATIVIDADE + ANTERIORIDADES

| Alínea | Conteúdo |
|---|---|
| **III caput** | Lei tributária NÃO atinge **fatos geradores anteriores** |
| **III "a"** | Igual |
| **III "b" (ANUAL)** | Vedado cobrar no **mesmo EXERCÍCIO** da publicação |
| **III "c" (NOVENTENA)** (EC 42/2003) | **90 dias** entre publicação e cobrança |

### CTN 144

Lançamento rege-se pela **lei do fato gerador**.

### STF Tema 1.383 (RE 1.473.645)
| | Conteúdo |
|---|---|
| Tese | A anterioridade (geral e nonagesimal) aplica-se à **redução ou supressão de benefícios/incentivos fiscais** que resulte em **majoração indireta** de tributos, observadas as exceções constitucionais de cada tributo |
| Caráter | Repercussão geral vinculante |

## CF 150 IV: VEDAÇÃO AO CONFISCO

| | Conteúdo |
|---|---|
| Conteúdo | Tributação confiscatória vedada |
| **Aplicação a MULTAS** | **Sim** |
| STF RE 833.106 + ADI 551/RJ + RE 582.461 | Multa **superior ao tributo** = inconstitucional |
| **Tema 863** | Qualificadas: **100%** (até 150% na reincidência) |

## CF 150 V: VEDAÇÃO INTERESTADUAL

Vedado tributo restringindo **livre tráfego**.

## Súmulas + Temas relevantes

| | Conteúdo |
|---|---|
| **Súm. 539 STF** | É constitucional lei municipal que reduz o IPTU sobre imóvel ocupado pela residência do proprietário que não possua outro |
| **STF Temas 881/885** | A coisa julgada em relações tributárias de TRATO SUCESSIVO **cessa automaticamente** com decisão contrária do STF em RG ou controle concentrado (respeitadas anterioridade anual + noventena) |
| **STJ Tema 1.125** | **ICMS-ST FORA da base PIS/COFINS** (RE 574.706 / Tema 69 STF é o paradigma do ICMS "próprio") |

## EC 132/2023 + LC 214/2025: Reforma Tributária

| | Conteúdo |
|---|---|
| **IBS + CBS** | Substituem ICMS + ISS + PIS/COFINS + IPI |
| **IS** (Imposto Seletivo) | Tabaco + álcool + bebidas açucaradas + agrotóxicos + veículos poluentes + loterias + minerais |
| **2026 (ANO TESTE)** | IBS 0,1% / CBS 0,9%, com **DISPENSA DE RECOLHIMENTO** para quem cumpre obrigações acessórias (art. 348 LC 214/2025) |
| Transição | **2027-2032** |
| Extinção ICMS/ISS | **2033** |
| Novos princípios | **Não-cumulatividade plena + neutralidade + cashback + split payment** |

## IGF (CF 153 VII)

| | Conteúdo |
|---|---|
| Status | **Pendente de LC** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Aumento de tributo por decreto | **Vedado** (salvo II/IE/IPI/IOF) |
| Aumento de IR no fim do ano | **Cobra ano seguinte** (só anual) |
| Aumento de IPI por decreto | Permitido + **noventena** (90d) |
| Aumento contribuição social | **Só noventena** |
| Multa de 200% do tributo | **Inconstitucional** (Tema 863: máx 150%) |
| Redução de benefício fiscal | **Anterioridade** (Tema 1.383) |
| ITCMD progressivo | **Válido** (RE 562.045) |
| Trânsito tributário contrário ao STF | **Cessa** (Temas 881/885) |
| 2026 IBS/CBS | **TESTE INFORMATIVO** (sem cobrança) |
| IGF | **Pendente** de LC |

## Erros a evitar

- **Aplicar anterioridade ao II/IE/IPI/IOF** (são exceções);
- **Exigir noventena para IR** (só anual);
- **Ignorar vedação ao confisco em MULTAS** (aplica-se: Tema 863);
- Tratar **CPMF/IPMF como tributos vigentes** (CPMF extinta em 2007; IPMF vigorou só em 1993-1994);
- Esquecer que **IGF segue PENDENTE** de LC;
- Supor que **IBS/CBS já oneram em 2026** (fase de teste, art. 348 LC 214);
- Aplicar **multa qualificada acima de 100%** sem reincidência (Tema 863: 150% só na reincidência);
- Não aplicar **anterioridade à redução de benefício** (Tema 1.383);
- Negar validade ao **ITCMD progressivo** (RE 562.045 o admite);
- Confundir a **fixação da base de cálculo de IPTU/IPVA** (exceção só à noventena) com majorações comuns (ambas anterioridades);
- Ignorar **Temas 881/885** em decisões transitadas tributárias de trato sucessivo.

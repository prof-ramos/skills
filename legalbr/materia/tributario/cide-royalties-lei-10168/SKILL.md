# CIDE-Tecnologia

## Marco legal

- **Lei 10.168/2000** (instituiu CIDE-Tecnologia);
- **Lei 10.332/2001** (ampliou incidência);
- **STF Tema 914** (RE 928.943: constitucionalidade);
- **CF 149** (CIDE: base constitucional);
- **CF 177 §4** (CIDE-combustíveis);
- **EC 33/2001** (constitucionalizou CIDEs);
- **Lei 11.452/2007** (alterações);
- **Decreto 4.195/2002** (regulamento);
- Atos Declaratórios e Soluções de Consulta RFB.

## Base constitucional (CF 149)

> "Compete exclusivamente à União instituir contribuições sociais, de **intervenção no domínio econômico** e de interesse das categorias profissionais ou econômicas (...)."

## Natureza jurídica

| | Conteúdo |
|---|---|
| **Espécie tributária** | Contribuição interventiva (CF 149) |
| **Não é IR + CSLL** | Independente |
| **Cumulativa** | Em regra (com IRRF) |
| **Não-restituível** | Tributo |
| **Vinculação** | FNDCT (Fundo Nacional de Desenvolvimento Científico e Tecnológico) |

## Hipóteses de incidência (Lei 10.168 + 10.332)

| Hipótese | Conteúdo |
|---|---|
| **I. Royalties** | Por contratos de uso/exploração de marcas + tecnologia |
| **II. Tecnologia** | Transferência |
| **III. Serviços técnicos** | Prestados por não-residente |
| **IV. Assistência administrativa + similares** | Após Lei 10.332 |
| **V. Direitos autorais** | Em alguns casos |
| **Beneficiário** | **Residente/domiciliado no exterior** |
| **Pagamento** + crédito + entrega + emprego + remessa | Fato gerador |

## Alíquota e base de cálculo

| | Conteúdo |
|---|---|
| **Alíquota** | **10%** |
| **Base** | Valor pago, creditado, entregue, empregado ou remetido |
| **Sem deduções** | Sobre o valor bruto |
| **Mensal** | Apuração |
| **Acréscimo** | Sobre o valor remetido (não retém da remessa) |

## Quem paga

| | Conteúdo |
|---|---|
| **Pessoa jurídica brasileira** | Pagadora |
| **Domiciliada/residente no Brasil** | Que pague para residente exterior |
| **PJ exterior** | Beneficiária (não paga, mas determina o fato gerador) |
| **PF brasileira** | Geralmente não (regra para empresas) |

## STF Tema 914 (RE 928.943)

| | Conteúdo |
|---|---|
| **Constitucionalidade** | Confirmada |
| **Inclusive alterações** | Leis 10.332/2001 e 11.452/2007 validadas |
| **Destinação** | Arrecadação integralmente aplicada em Ciência e Tecnologia |
| **Resultado** | Empresas que pleiteavam restituição perderam |

## Tema 914: tese fixada

> "I - É constitucional a contribuição de intervenção no domínio econômico (CIDE) destinada a financiar o Programa de Estímulo à Interação Universidade-Empresa para o Apoio à Inovação, instituída e disciplinada pela Lei nº 10.168/2000, com as alterações empreendidas pelas Leis nºs 10.332/2001 e 11.452/2007; II - A arrecadação da CIDE, instituída pela Lei nº 10.168/2000, com as alterações empreendidas pelas Leis nºs 10.332/2001 e 11.452/2007, deve ser integralmente aplicada na área de atuação Ciência e Tecnologia, nos termos da lei."

## Comparativo IRRF × CIDE

| | IRRF | CIDE |
|---|---|---|
| **Alíquota** | 15-25% (depende da relação) | **10%** |
| **Base** | Mesma | Mesma |
| **Beneficiário** | Não-residente | Não-residente |
| **Cumulação** | Possível | Possível |
| **Tratado (DTAA)** | Pode reduzir | Não afastada em regra |

## Acordos de bitributação (DTAA)

| | Conteúdo |
|---|---|
| **Tratados** | Reduzem IRRF |
| **CIDE** | Não atingida em regra (interpretação RFB) |
| **STJ** | Tratados de bitributação não afastam a CIDE em regra (alcance restrito) |
| **Discussão** | Extensão da imunidade dos tratados à CIDE permanece controvertida |

## FNDCT: destino

| | Conteúdo |
|---|---|
| **Fundo** | Nacional de Desenvolvimento Científico e Tecnológico |
| **Aplicação** | Programas de pesquisa + universidades + empresas |
| **Vinculação** | Lei 11.540/2007 |
| **CNPq + Finep** | Beneficiários |

## Operações tributadas

| | Conteúdo |
|---|---|
| **Licenciamento de software** | Sim (com discussões) |
| **Royalties de marca** | Sim |
| **Transferência de tecnologia** | Sim |
| **Patentes** | Sim |
| **Serviços técnicos** | Sim |
| **Cloud + SaaS** | Discussão |
| **Direitos autorais** | Caso a caso |

## Operações NÃO tributadas

| | Conteúdo |
|---|---|
| **Importação de mercadorias** | Não (apenas serviços/intangíveis) |
| **Remessa para serviços comuns** (não-técnicos) | Em geral não |
| **Pagamento a residente brasileiro** | Não cabe CIDE |
| **Capital intra-grupo** | Distinção complexa |

## Software: interfaces

| | Conteúdo |
|---|---|
| **STF ADI 5659** | ICMS × ISS em software (licenciamento = ISS) |
| **CIDE** | Incidência própria sobre a remessa ao exterior, independente do ISS/ICMS |
| **Cloud + SaaS** | Casos comuns de discussão |

## Cumulação com PIS/COFINS-Importação

| | Conteúdo |
|---|---|
| **Lei 10.865/2004** | Cumulação possível |
| **CIDE + IRRF + PIS/COFINS-Importação** | Cumuláveis |
| **Carga total** | Pode chegar a 40% |

| | Conteúdo |
|---|---|

| **Restituição** | Somente em caso de pagamento indevido |
| **Prazo** | 5 anos (CTN 168) |

## Aplicação prática

| Cenário | CIDE? |
|---|---|
| **Licença SaaS estrangeira** para PJ brasileira | Sim (licença + serviços técnicos) |
| **Royalty de marca** estrangeira | Sim |
| **Contrato de franquia** com franqueador exterior | Sim |
| **Assistência técnica** importada | Sim |
| **Importação de hardware** | Não |
| **Honorários jurídicos pagos no exterior** | Discussão (atividade pessoal) |

## Erros a evitar

- Aplicar **CIDE só a tecnologia stricto** (Lei 10.332 ampliou para royalties em geral);
- Ignorar **STF Tema 914** (constitucionalidade + destinação integral a C&T);
- Reduzir CIDE por **tratado de bitributação** (regra: não atinge);
- Confundir **CIDE-Tecnologia** com **CIDE-Combustíveis** (regimes próprios);
- Aplicar a **PF brasileira** (regra é PJ);
- Esquecer **cumulação com IRRF + PIS/COFINS-Importação**;
- Não recolher em **assistência administrativa + similares** (Lei 10.332);
- Aplicar **alíquota errada** (10%, fixa);
- Aceitar restituição **fora de hipóteses específicas** (CTN 168);
- Confundir com **ISS sobre serviços do exterior** (regimes próprios);
- Esquecer **FNDCT** como destino (vinculação).

# Moratória Tributária

## Base legal

| | Conteúdo |
|---|---|
| **CTN 151 I** | Moratória: causa de suspensão da exigibilidade |
| **CTN 152** | Espécies |
| **CTN 153** | Requisitos da lei concessiva |
| **CTN 154** | Casos de suspensão da concessão |
| **CTN 155** | Revogação por descumprimento ou fraude |
| **LC 24/75** | Convênio CONFAZ, necessário em alguns benefícios estaduais |

## Conceito

| | Conteúdo |
|---|---|
| Definição | **Dilação por lei** do prazo para pagamento de tributo vencido ou a vencer |
| Fonte | **Lei específica** do ente competente |
| Distintas | Moratória ≠ parcelamento ≠ isenção ≠ remissão |

## Espécies (CTN 152)

| Inciso | Conteúdo |
|---|---|
| **I "a"** | Em **caráter geral** pela própria pessoa jurídica de direito público competente (regra) |
| **I "b"** | Em caráter geral pela **União** quanto a **tributos estaduais ou municipais**, desde que simultaneamente concedida aos tributos federais (controvertida: heterônoma) |
| **II** | Em **caráter individual**: despacho administrativo, observados requisitos da lei |

## Requisitos da lei (CTN 153)

| | Conteúdo |
|---|---|
| **I** | Prazo de duração |
| **II** | Condições da concessão (caso individual) |
| **III** | Tributos a que se aplica |
| **IV** | Número de prestações + vencimentos (se for o caso) |
| **V** | Garantias eventuais |

## CTN 154: limites

| | Conteúdo |
|---|---|
| Caput | Salvo disposição em contrário, **só alcança créditos já constituídos** na data da lei (ou cujo lançamento já tenha sido iniciado) |
| § | **NÃO se aplica** aos casos de **DOLO, FRAUDE ou SIMULAÇÃO** |

## CTN 155: revogação

| | Conteúdo |
|---|---|
| Hipóteses | Beneficiário **não satisfaz** os requisitos OU **deixa de satisfazer** (descumprimento posterior) OU comete **dolo/fraude/simulação** |
| Efeito | Cobrança do crédito + **juros** + **eventual penalidade** (multa) |
| Inciso II | **Em caso de dolo/fraude**: pena + cobrança de juros sem direito ao tempo de moratória (suspensão não conta para prescrição) |
| Inciso I (sem dolo) | Tempo de moratória **CONTA** para prescrição (suspensão não retroage) |

## Efeitos

| | Conteúdo |
|---|---|
| Suspende exigibilidade | **SIM** (CTN 151 I) |
| Suspende prescrição? | **SIM** durante a moratória (regra) |
| Exclui multa? | Em regra **SIM** quando a lei concessiva dispensa a multa de mora |
| Exclui juros? | NÃO (juros mantidos) |
| Permite CPD-EN? | **SIM** (CTN 206) |

## Moratória **geral** × **individual**

| | Geral | Individual |
|---|---|---|
| Beneficiários | Todos os sujeitos passivos | Quem preenche requisitos + despacho |
| Norma | Lei (autoaplicável) | Lei + despacho administrativo |
| Comprovação | Não exige | Exige documentação |
| Revogação | Por lei superveniente | Por descumprimento (CTN 155) |

## Distinções essenciais

| | Moratória | Parcelamento (155-A) |
|---|---|---|
| Objetivo | Dilatar prazo único | **Pagamento em parcelas** |
| Norma | CTN 151 I + 152-155 | CTN 155-A |
| Multa | Em regra exclui | Mantida |

| | Moratória | Isenção (CTN 175 I) |
|---|---|---|
| Crédito | Existe, com exigibilidade suspensa | NÃO surge (ou já extinto) |
| Pagamento | Postergado | Não há |

| | Moratória | Anistia (CTN 180) |
|---|---|---|
| Atinge | Tributo | **Multa/infração** |
| Concessão | Lei | Lei |

## Moratória em casos concretos

| Hipótese | Aplicação |
|---|---|
| Calamidade pública (enchente/seca/Covid) | Lei dilatando vencimento → moratória |
| Reorganização administrativa | Lei adia prazo |
| Setor com dificuldades | Lei específica + critérios |
| Pandemia 2020 | RFB postergou DCTF/IRPJ (moratória parcial) |

## Moratória que dispensa multa (jurisprudência)

| | Conteúdo |
|---|---|
| Tese | Moratória que **dispensa multa** + concedida em programa específico institui benefício amplo; não cabe restrição administrativa adicional |
| Aplicação | Lei concessiva é lei especial; a administração não pode condicionar além dos termos legais |

## ADIs sobre moratória heterônoma (CTN 152 I "b")

| | Conteúdo |
|---|---|
| STF | Orientação contrária à moratória heterônoma (União sobre tributos estaduais/municipais), por violação da **autonomia federativa** (CF 18 + 145 + 151 III, que veda isenção heterônoma) |
| Status do CTN 152 I "b" | Leitura predominante é de **não-recepção** pela CF/88; União só pode conceder moratória sobre tributos próprios |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Lei concede moratória geral | Suspende exigibilidade + dispensa multa |
| Beneficiário com fraude | **Revogação** + cobrança + multa (CTN 155 II) |
| Empresa em moratória individual | Despacho deferindo + suspensão |
| Postergação por calamidade | Lei + automática |
| Moratória **heterônoma** (União sobre IPVA) | **Inconstitucional** |
| CPD-EN durante moratória | **SIM** |
| Após revogação | Cobrança imediata + prescrição retoma |

## Erros a evitar

- Confundir moratória com **parcelamento** (CTN 155-A: institutos diversos);
- Considerar moratória como **isenção** (não: só dilata prazo);
- Aplicar moratória **heterônoma** da União sobre tributo estadual/municipal (CTN 152 I "b": tida por não recepcionada);
- A exigibilidade fica suspensa durante a moratória (CTN 151 I);
- A **CPD-EN** é devida durante moratória ativa (CTN 206);
- Aplicar moratória a **dolo/fraude/simulação** (CTN 154 § + 155 II: vedada);
- Considerar que **suspensão da prescrição** durante moratória se aplica mesmo em fraude (CTN 155 II: o tempo não se computa);
- Excluir **juros** da moratória (apenas multa, em regra);
- Tratar moratória como **automática** sem lei concessiva;
- O benefício não subsiste após descumprimento de **condição** (CTN 155);
- Aplicar moratória **antes da constituição** do crédito (CTN 154, só créditos constituídos);
- Confundir moratória com **transação** (Lei 13.988/20, distinta);
- A moratória **individual** depende de despacho administrativo (CTN 152 II);
- A **multa** dispensada pela lei da moratória não é exigível (não cabe restrição administrativa além da lei).

# Imposto Seletivo

## CF 153 VIII (EC 132/2023)

| | Conteúdo |
|---|---|
| Competência | **FEDERAL** |
| Incidência | **PRODUÇÃO + EXTRAÇÃO + COMERCIALIZAÇÃO + IMPORTAÇÃO** de **BENS e SERVIÇOS PREJUDICIAIS** à **SAÚDE ou MEIO AMBIENTE** |

## Natureza

| | Conteúdo |
|---|---|
| Função | **EXTRAFISCAL** — desestimular consumo (**sin tax/pigouviano**) |
| **NÃO** | Arrecadar primariamente |

## Características constitucionais

| | Conteúdo |
|---|---|
| **CF 153 §6** | Alteração de alíquota **por DECRETO** (extrafiscalidade) |
| **CF 150 §1** | **EXCEÇÃO PARCIAL** à anterioridade anual — sujeito apenas à **NOVENTENA** |
| **Não-cumulativo na cadeia** | Incide **UMA ÚNICA VEZ** — **SEM CREDITAMENTO** (LC 214/2025) |
| Substituição | Substitui **PARCIALMENTE o IPI extrafiscal** — IPI sobrevive seletivamente apenas na **ZFM** (até 2073) |
| **CUMULA** | Com **CBS + IBS** — integra suas bases |

## HIPÓTESES — LC 214/2025 art. 409 (TAXATIVA)

| (n) | Conteúdo |
|---|---|
| **1** | **VEÍCULOS** poluentes |
| **2** | **Embarcações + aeronaves** |
| **3** | **Fumígenos** (cigarros + charutos) |
| **4** | **Bebidas alcoólicas** |
| **5** | **Bebidas açucaradas** |
| **6** | **Bens minerais** (extração — **alíq. máx 1%** — CF 153 §6 IV) |
| **7** | **Concursos de prognósticos + FANTASY SPORT** |

## Critério dúplice

| | Conteúdo |
|---|---|
| Tese | **SAÚDE OU MEIO AMBIENTE** |

## Vigência

| Ano | Conteúdo |
|---|---|
| **2026** | Ano-teste — **alíquota ZERO** |
| **2027** | **Incidência EFETIVA PLENA** |

## Federalismo

| | Conteúdo |
|---|---|
| Imposto | **FEDERAL** |
| Destinação | **COMPARTILHADA** (50% Estados/DF + Municípios via FPE/FPM) |

## ADIs pendentes

| | Conteúdo |
|---|---|
| **ADI 7.751 + 7.604 + 7.622** | Questionam Lei das Subvenções + correlatos |

## Pontos controvertidos (sob discussão judicial)

| | Conteúdo |
|---|---|
| Incidência sobre **veículos** | Tensão com isonomia e proporcionalidade — exige correlação entre nocividade e base de cálculo; segmento aguarda manifestação do STF em sede própria |

|---|---|---|

| Pós-2027 | **Pleno** | Só **ZFM concorrentes** |
| Anterioridade | Só nonagesimal | Só nonagesimal |
| Cumulativo | **SIM (única incidência)** | NÃO (cadeia) |

| | IS | CIDE-combustíveis |
|---|---|---|
| Foco | Saúde/ambiente amplo | Combustíveis |

| | Cumula com CBS/IBS | Integrava bases |
|---|---|---|

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Cigarros + bebidas | **IS** (LC 214 art. 409) |
| Veículo poluente | **IS** |
| Bebida açucarada | **IS** |
| Mineração | **IS** (máx 1%) |
| Fantasy sport | **IS** |
| Produto NÃO listado | **NÃO incide** (lista taxativa) |
| Alteração por decreto | **OK** (CF 153 §6) |
| Cobrança 2026 | **Alíquota zero** |
| Cobrança 2027 | **Pleno** |
| Anterioridade anual | **NÃO** se aplica |
| Anterioridade nonagesimal | **APLICA** |

## Erros a evitar

- Aplicar **anterioridade anual** ao IS (exceção CF 150 §1);
- Aceitar **alteração apenas por lei** (CF 153 §6 — decreto OK);
- Tributar **produto NÃO listado** (lista taxativa LC 214 art. 409);
- Aplicar IS sem **cumulação CBS/IBS** (integra base);
- Aplicar **creditamento** (incidência única);
- Aplicar **alíquota acima de 1%** a minerais (CF 153 §6 IV);
- Aplicar **IS antes de 2027** com alíquota efetiva (2026 — zero);
- Tratar **IS como arrecadatório principal** (é extrafiscal);
- Confundir **IS com IPI** (substitui parcialmente);
- Aplicar IS por **critério único** (é dúplice — saúde **OU** ambiente);
- A **destinação é compartilhada**: tributo federal, sujeito a repartição.

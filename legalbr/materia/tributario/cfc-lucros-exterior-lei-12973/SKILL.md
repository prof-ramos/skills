# Tributação de Lucros no Exterior (CFC Rules)

## Base legal

| | Conteúdo |
|---|---|
| **Lei 12.973/2014** | Disciplina principal, convertida da MP 627/13 |
| **Lei 9.430/96 art. 25 a 27** | Regras anteriores |
| **Lei 14.754/2023** | **Tributação anual** de **offshores PF** (controlled foreign company para PF) |
| **MP 2.158-35/2001 art. 74** | Disponibilização ficta (revogada pela 12.973) |
| **Decreto 9.580/2018 (RIR)** | Regulamento IR |
| **IN RFB 1.520/2014 + atualizações** | Operacional |

## Princípios

| | Conteúdo |
|---|---|
| **Tributação universal** | Brasileiros (PJ + PF) tributados por **renda mundial** (CF 153 III + CTN 43) |
| **Universalidade** | Não discrimina origem |
| **Anti-elisão** | CFC rules combatem postergação artificial |

## PJ: controladas + coligadas (Lei 12.973)

| Tipo | Tributação |
|---|---|
| **Controlada** (com controle direto/indireto) | Lucros **AUFERIDOS** tributados no encerramento do **exercício** da controlada |
| **Coligada** sem controle | Lucros **DISPONIBILIZADOS** (regime caixa), **salvo** se em país de tributação favorecida (paraíso) |
| **Coligada em paraíso** | Tributada como controlada (auferimento) |
| **Investida pelo método de equivalência patrimonial (MEP)** | Avaliação + tributação na consolidação |

## Conceitos básicos

| | Conteúdo |
|---|---|
| **Controlada no exterior** | PJ brasileira tem **controle direto/indireto** (mais de 50% capital votante OU influência majoritária) |
| **Coligada** | Influência significativa sem controle (presumida com 20% ou mais do capital votante, Lei 6.404 art. 243) |
| **Paraíso fiscal / país de tributação favorecida** | Lista RFB IN 1.037/10 + alíquota IR < **17%** OU sigilo |
| **Regime fiscal privilegiado** | Lei 11.727/08, privilégios específicos |

## Alíquotas e cálculo

| | Conteúdo |
|---|---|
| IRPJ + CSLL combinados | **34%** (15% IRPJ + 10% adicional + 9% CSLL) sobre os lucros do exterior |
| Crédito IR pago no exterior | **Compensável** (Lei 12.973 art. 87) até o limite do IR brasileiro |
| Diferimento | Permitido em alguns casos para lucros de **subcontroladas** + **prejuízos** |
| Subcapitalização | Lei 12.249/10, limites de juros entre vinculadas |

## Disponibilização ficta: histórico

| | Conteúdo |
|---|---|
| **MP 2.158-35 art. 74** (revogada) | Tributação ficta no auferimento, mesmo para coligadas |
| **STF ADI 2.588** (2014) | Inconstitucional para coligadas **não-paraíso**; **constitucional** para controladas + coligadas em paraíso |
| **Lei 12.973/14** | Substituiu o art. 74; manteve o auferimento para controladas |

## STF Tema 537 + ADI 2.588

| | Conteúdo |
|---|---|
| Tese (Tema 537) | O art. 74 da MP 2.158-35 **aplica-se** às empresas nacionais controladoras de PJs sediadas em **países de tributação favorecida** ou desprovidos de controles societários e fiscais adequados; **inconstitucional** o parágrafo único (que alcançava lucros apurados até 31/12/2001) |
| ADI 2.588 | Inconstitucional a tributação ficta para coligadas **fora** de paraíso (tributação só na disponibilização); constitucional para controladas em paraíso |

## Lei 14.754/2023: offshores PF + fundos exclusivos

| | Conteúdo |
|---|---|
| Aplicação | Pessoa Física brasileira residente |
| **Offshore (entidade controlada no exterior)** | Tributação **ANUAL** dos lucros (regime ficto), alíquota **15%** |
| **Fundos exclusivos** (PF) | Tributação anual pelo "come-cotas" (15%) |
| **Trusts** | Disciplinados; atribuem-se ao instituidor (em regra) |
| Vigência | A partir de **2024** |

## Tratados internacionais

| | Conteúdo |
|---|---|
| Brasil tem ~36 acordos | Bilaterais para evitar dupla tributação (DTAs) |
| **Pillar Two / IMG** | Lei 15.079/24, tributação mínima efetiva de 15% (Adicional de CSLL) |

## Países de tributação favorecida (IN RFB 1.037/10)

| | Conteúdo |
|---|---|
| Lista | Atualizada pela RFB; inclui jurisdições de baixa ou nula tributação |
| Critério | Alíquota IR < 17% + sigilo + regime privilegiado |
| Efeito | Aplica regime de auferimento para coligadas + restrições à dedução de pagamentos |

## Subcapitalização (Lei 12.249/10)

| | Conteúdo |
|---|---|
| Endividamento com vinculada | Juros dedutíveis até **2x** patrimônio líquido do mutuário |
| Paraíso fiscal | Limite reduzido a **30%** PL |
| Excesso | Não dedutível para IRPJ/CSLL |

## Jurisprudência: interpretações

| | Conteúdo |
|---|---|
| **STF Tema 537** | Art. 74 da MP 2.158-35 aplicável a controladoras de PJs em países de tributação favorecida; parágrafo único inconstitucional |
| REsp 1.325.709 | Precedente do STJ sobre a interação entre tratados de dupla tributação e o regime de lucros no exterior |

## Síntese operacional

| Hipótese | Solução |
|---|---|
| PJ brasileira com controlada nas Bahamas | **Tributação no auferimento** anual (Lei 12.973) |
| PJ brasileira com coligada em Portugal (não paraíso) | **Disponibilização** (regime caixa) |
| Coligada em país de tributação favorecida | Auferimento (ADI 2.588) |
| PF com offshore em BVI | **15% anual** (Lei 14.754) |
| PF com fundo exclusivo | **Come-cotas anual** (Lei 14.754) |
| Trust com instituidor BR | Atribui ao instituidor (Lei 14.754) |
| IR pago no exterior | Crédito até o limite brasileiro (Lei 12.973 art. 87) |

## Distinções essenciais

| | Controlada | Coligada |
|---|---|---|
| Tributação | Auferimento | Disponibilização (salvo paraíso) |
| ADI 2.588 + Tema 537 | Constitucional | Inconstitucional (não-paraíso) |

| | Lei 12.973 (PJ) | Lei 14.754 (PF) |
|---|---|---|
| Sujeito | PJ brasileira | **PF brasileira** |
| Aplicação | Universal | Offshore + fundo exclusivo |
| Alíquota | 34% (IRPJ+CSLL) | **15%** |

## Erros a evitar

- Aplicar regime de **disponibilização** a controlada (a Lei 12.973 impõe o auferimento);
- Tributar coligada **fora** de paraíso pelo auferimento (ADI 2.588: inconstitucional);
- Aplicar MP 2.158-35 art. 74 (revogada);
- O crédito de **IR pago no exterior** é admitido (Lei 12.973 art. 87);
- Ignorar **subcapitalização** (Lei 12.249);
- Aplicar regime PJ a **PF** (Lei 14.754 é específica);
- Tratar offshore PF como **regime caixa** (Lei 14.754: tributação anual);
- Não considerar **lista IN 1.037** ao classificar paraíso;
- Aplicar tratado de dupla tributação ignorando hierarquia (CTN 98);
- Esquecer o **Pillar Two** (Lei 15.079: 15% de tributação mínima efetiva);
- Considerar trust como **terceira pessoa** sem atribuir ao instituidor (Lei 14.754);
- Tratar **come-cotas** como facultativo (obrigatório para fundos exclusivos);
- Aplicar regra antiga (Lei 9.430 isolada) sem combinar com 12.973;
- O diferimento é permitido em **prejuízos** e **subcontroladas** (Lei 12.973);
- Aceitar pagamentos a paraíso sem **prova de causa real** (vedação de dedutibilidade, Lei 9.430 + 12.973).

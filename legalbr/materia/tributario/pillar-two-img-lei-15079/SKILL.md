# Pillar Two, Imposto Mínimo Global (IMG)

## Base legal

| | Conteúdo |
|---|---|
| **OECD/G20 BEPS 2.0** | Acordo internacional Pillar One + Pillar Two |
| **OECD GloBE Rules** (Dez/2021) | Texto modelo |
| **Lei 15.079/2024** | Brasil adotou via QDMTT (publicada 30/12/2024) |
| **MP 1.262/2024** | Convertida na Lei 15.079 |
| **IN RFB 2.228/2024** | Regulamentação operacional do adicional da CSLL |
| **Vigência** | **01/01/2025** (MP 1.262/2024 convertida; observada a noventena da CF 195 §6) |
| **Reconhecimento OCDE** | Adicional da CSLL reconhecido como **QDMTT e QDMTT Safe Harbour** (ago/2025) |

## Conceito

| | Conteúdo |
|---|---|
| Definição | Garantia de **alíquota efetiva mínima de 15%** sobre lucros de grupos multinacionais (MNE) em **cada jurisdição** |
| Finalidade | Garante arrecadação mínima; reduz a erosão da base tributável + transferência artificial de lucros |
| Fundo principal | **IIR** (Income Inclusion Rule) + **UTPR** (Undertaxed Payments Rule) + **QDMTT** |

## Aplicação: grupos atingidos

| | Conteúdo |
|---|---|
| Grupos multinacionais (MNE) | Com receita consolidada ≥ **EUR 750 milhões** em pelo menos 2 dos 4 anos anteriores |
| **Estimativa Brasil** | ~290 grupos multinacionais (BR + estrangeiros operando no Brasil) |
| Pequenas e médias | **Fora** do escopo (≠ Pillar Two) |
| Entidades excluídas | Fundos de investimento + fundos de pensão + entidades governamentais |

## Mecânica brasileira: QDMTT (Lei 15.079)

| | Conteúdo |
|---|---|
| QDMTT | **Qualified Domestic Minimum Top-up Tax**, adicional doméstico |
| Natureza | **Adicional da CSLL**, recolhido pela própria jurisdição (Brasil) |
| Cálculo | Diferença entre 15% e alíquota efetiva (ETR) brasileira da entidade |
| Vantagem | O Brasil arrecada o "top-up" e evita que outra jurisdição (via IIR) o faça |

## Alíquota efetiva (ETR)

| | Conteúdo |
|---|---|
| Cálculo | Imposto pago / Lucro GloBE da jurisdição |
| Numerador | Tributos abrangidos (IRPJ + CSLL) |
| Denominador | Lucro GloBE, partindo do lucro contábil ajustado |

## Top-up tax

| | Conteúdo |
|---|---|
| Fórmula | (15% − ETR) × (Lucro GloBE − carve-out) |
| Carve-out por substância | Exclusão de percentual da **folha de salários** + do **ativo tangível** (transição: folha a partir de 10% e ativos a partir de 8%, convergindo para 5% ao final) |

## Regras complementares

| Regra | Sigla | Conteúdo |
|---|---|---|
| **IIR** | Income Inclusion Rule | Holding tributa lucros não-tributados das subsidiárias |
| **UTPR** | Undertaxed Profits/Payments Rule | Backstop: outra jurisdição tributa se nem IIR nem QDMTT alcançarem |
| **QDMTT** | Qualified Domestic Minimum Top-up Tax | Adotado pelo Brasil; recolhimento doméstico |

## Cronograma

| Ano | Conteúdo |
|---|---|
| **2024** | Países pioneiros (UE + UK + Coreia + Japão) iniciam |
| **2025** | **Brasil** ingressa (Lei 15.079), via QDMTT |
| **2026** | Avaliação OECD + ajustes |
| 2027 | UTPR plenamente vigente nos países adotantes |

## Cálculo + complexidade

| Etapa | Conteúdo |
|---|---|
| 1 | Identificar entidades por jurisdição |
| 2 | Calcular **Lucro GloBE** (lucro contábil + ajustes OECD) |
| 3 | Calcular **tributos abrangidos** |
| 4 | Calcular **ETR** = tributos / GloBE |
| 5 | Comparar com 15% |
| 6 | Se ETR < 15% → calcular top-up |
| 7 | Aplicar carve-out por substância |
| 8 | Recolher no QDMTT (Brasil) ou IIR (holding) |

## Carve-out de substância

| | Conteúdo |
|---|---|
| Folha de salários | **5%** ao final da transição (percentuais transitórios decrescentes a partir de 10%) |
| Ativo tangível | **5%** ao final da transição (percentuais transitórios decrescentes a partir de 8%) |
| Razão | Incentiva substância econômica real (≠ "paper companies") |
| Reflexo | Reduz top-up para empresas com atividade real |

## STF + ADIs

| | Conteúdo |
|---|---|
| Discussão de constitucionalidade | Há controvérsia sobre o adicional da CSLL/QDMTT; **verificar numeração/status de ações no STF** antes de citar ADI específica |
| Argumentos contra | Aumento de carga + complexidade + adicional sem clara base constitucional + uso de standards OCDE (atos infralegais) |
| Argumentos a favor | Compromisso internacional + neutralidade competitiva + reconhecimento da OCDE |

## Tratados + MAP

| | Conteúdo |
|---|---|
| Pillar Two | Convive com tratados de dupla tributação (em regra) |
| MAP | Resolução de disputas (procedimento amigável dos tratados) |

## Aplicação prática

| Hipótese | Solução |
|---|---|
| Multinacional BR com receita > EUR 750 mi | Sujeita |
| Subsidiária no Brasil com ETR 12% | Top-up de 3% via QDMTT |
| Subsidiária no Brasil com ETR 18% | Sem top-up |
| Carve-out reduz | Beneficia indústrias com folha + ativo |
| Grupo familiar pequeno (< EUR 750 mi) | **Fora** |
| Empresa em ZFM com ETR baixa | Pode haver top-up (em discussão setorial) |
| Holding BR com subsidiárias em paraísos | IIR aplica (BR é IIR jurisdiction) |

## Distinções essenciais

| | Pillar One | Pillar Two |
|---|---|---|
| Foco | Realocação de lucros (economia digital) | **Imposto mínimo 15%** |
| Status | Em discussão | Adotado |

| | QDMTT | IIR |
|---|---|---|
| Quem aplica | **Jurisdição local** (BR) | **Jurisdição da holding** |
| Beneficiário | Arrecada local | Arrecada matriz |

## Erros a evitar

- Aplicar Pillar Two a grupos **abaixo** de EUR 750 mi (fora);
- Ignorar **carve-out de substância** (reduz top-up);
- Aplicar ETR sobre **lucro contábil** sem ajustes GloBE;
- Considerar QDMTT como **substituto** da CSLL/IRPJ (é **adicional**);
- Aplicar antes de **01/01/2025** (vigência);
- Tratar Pillar Two como dispensável com tratado de dupla tributação (em geral coexiste);
- Esquecer **transição** dos carve-outs (8%/7,8% → 5%/5%);
- Não considerar **MAP** para disputas;
- Aplicar Pillar Two a fundos de pensão (excluídos);
- Considerar **ZFM** automaticamente isenta (em discussão setorial);
- Tratar top-up como **devido** quando ETR está acima de 15%;
- Aplicar Pillar Two a grupo com receita >EUR 750 mi em **apenas 1 ano** (regra: 2 dos últimos 4);
- Considerar Pillar Two como Pillar One (escopos distintos);
- Ignorar a controvérsia de constitucionalidade do QDMTT/adicional da CSLL;
- Não preparar **GloBE Information Return** (declaração obrigatória anual).

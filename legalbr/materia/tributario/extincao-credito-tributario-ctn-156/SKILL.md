# Extinção do Crédito Tributário

## CTN 156: HIPÓTESES

| Inc. | Hipótese |
|---|---|
| **I** | **PAGAMENTO** |
| **II** | **COMPENSAÇÃO** |
| **III** | **TRANSAÇÃO** |
| **IV** | **REMISSÃO** |
| **V** | **PRESCRIÇÃO + DECADÊNCIA** |
| **VI** | **CONVERSÃO** de depósito em renda |
| **VII** | **Pagamento ANTECIPADO + HOMOLOGAÇÃO** (CTN 150 §4) |
| **VIII** | **Consignação em pagamento PROCEDENTE** (CTN 164 §2) |
| **IX** | **Decisão administrativa IRREFORMÁVEL** |
| **X** | **Decisão judicial transitada em julgado** |
| **XI** | **DAÇÃO em PAGAMENTO de IMÓVEIS** (LC 104/2001) |

## Decadência (CTN 173) × Prescrição (CTN 174)

| | Conteúdo |
|---|---|
| Prazo | **5 ANOS** ambos |
| **Decadência** | Atinge **direito de CONSTITUIR** o crédito (lançamento) |
| **Prescrição** | Atinge **pretensão de COBRANÇA** após constituição definitiva |

### STJ REsp 973.733 (recurso repetitivo)
| | Conteúdo |
|---|---|
| Tributos por homologação **COM pagamento antecipado** | Decadência conta da **ocorrência do FG** (CTN 150 §4) |
| **SEM pagamento** | Aplica-se **CTN 173 I** (1º dia exercício seguinte) |

## DAÇÃO EM PAGAMENTO (XI)

| | Conteúdo |
|---|---|
| **STJ 2ª Turma** | Reafirmou ser **NORMA DE EFICÁCIA LIMITADA** |
| Exige | **Regulamentação por lei do ente** competente |
| **Lei 13.259/2016** | Disciplinou no **âmbito FEDERAL** |
| Restrita a | **IMÓVEIS** + avaliação + anuência da PGFN + exclusão de débitos no Simples e FGTS |

|---|---|

### Modalidades
| | Conteúdo |
|---|---|
| **Adesão** | Edital |
| **Individual** | Negociação |
| **Pequeno valor** | Procedimento simplificado |

| | Conteúdo |
|---|---|
| STJ | Só extingue com **CUMPRIMENTO INTEGRAL** (Lei 13.988 art. 11) |

## PGDAU: editais de transação (conferir sempre o edital vigente)

| | Conteúdo |
|---|---|
| Edital vigente (julho/2026) | **PGDAU 6/2026**: adesão de 01/06/2026 até **30/09/2026**, pelo portal Regularize |
| Alcance | Débitos inscritos em dívida ativa da União de até **R$ 45 milhões** por sujeito passivo |
| Descontos | Até 100% de juros, multas e encargos, limitados a **65% (geral)** e **70% (MEI/ME/EPP/PF)** do valor total |
| Parcelas | Até **120 ou 145 parcelas**, conforme a modalidade; entrada de 5% a 6% do valor consolidado |
| Atenção | Os editais PGDAU se sucedem periodicamente; conferir as condições do edital vigente |

## Distinções essenciais

| | Decadência (173) | Prescrição (174) |
|---|---|---|
| Objeto | Constituir | Cobrar |
| Início | 1º dia exerc. seguinte (regra) | Constituição definitiva |
| Suspensão/interrupção | NÃO | **Admite** |

| | Dação genérica | Imóveis (XI + Lei 13.259) |
|---|---|---|
| Aplicação | Não regulamentada | **Específica federal** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Pagamento integral | **Extingue** (I) |
| Compensação | **CTN 170** (II) |
| Transação Lei 13.988 | **III**: só com cumprimento |
| Decurso 5 anos sem lançamento | **DECADÊNCIA** (V) |
| Decurso 5 anos após constituição | **PRESCRIÇÃO** (V) |
| Tributário por homologação + pagamento | **CTN 150 §4** (REsp 973.733) |
| Sem pagamento | **CTN 173 I** |
| Dação em imóvel federal | **Lei 13.259/2016** |
| Edital PGDAU vigente (6/2026) | **Adesão até 30/09/2026** (conferir o Regularize) |
| Refis Lei 11.941 com pagto à vista | **Extingue** (CTN 156 I, na forma da lei do programa) |

## Erros a evitar

- **Aceitar DAÇÃO em pagamento sem regulamentação** (CTN 156 XI: eficácia limitada);
- **Confundir decadência com prescrição** (objetos distintos);
- Aplicar **CTN 173 I** quando há pagamento antecipado (use 150 §4);
- Tratar **TRANSAÇÃO como CELEBRADA = extinção** (exige cumprimento);
- Tratar o rol do CTN 156 como fechado para os entes: o STF admite que lei local crie outras formas de extinção (ADI 2.405);
- Aplicar **prescrição interrompida indevidamente** (analisar interrupções);
- Aceitar **dação de móveis** no âmbito federal (Lei 13.259: só imóveis);
- Não considerar **descontos PGDAU** quando aplicáveis;
- Aplicar **decadência interrompida** (não admite);
- Permitir dação em pagamento de débitos vedados (Simples + FGTS, Lei 13.259);
- Confundir **REFIS com TRANSAÇÃO** (institutos distintos).

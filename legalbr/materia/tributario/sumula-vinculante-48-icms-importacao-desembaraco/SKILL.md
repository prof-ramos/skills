# Súmula Vinculante 48, ICMS Importação

## Texto integral

> "Na entrada de mercadoria importada do exterior, é legítima a cobrança do ICMS por ocasião do **desembaraço aduaneiro**."

## Bases normativas

| | Conteúdo |
|---|---|
| **CF 155 II** | Competência estadual para ICMS |
| **CF 155 §2 IX a** | Incide ICMS sobre **entrada de bem ou mercadoria importados do exterior** (redação dada pela **EC 33/2001**) |
| **CF 155 §2 IX a (parte final)** | Cabe ICMS **ainda que** o importador seja **pessoa física ou jurídica não habitualmente contribuinte** |
| **LC 87/1996 art. 12 IX** | Fato gerador no **desembaraço aduaneiro** de mercadoria ou bem importados |
| **LC 87/1996 art. 11 I d** | Local da operação: estabelecimento do destinatário (importador) |
| **Decreto 6.759/2009** | Regulamento Aduaneiro (despacho aduaneiro) |
| **PSV 94/DF** | Proposta que aprovou a SV 48 |

## Precedentes históricos

| | Conteúdo |
|---|---|
| **Súm. 661 STF** | Súmula anterior: "Na entrada de mercadoria importada do exterior, é legítima a cobrança do ICMS por ocasião do desembaraço aduaneiro." |
| **SV 48** | **Converteu** a Súm. 661 em vinculante (27/05/2015) |
| **EC 33/2001** | Estendeu incidência à **PF/PJ não habitualizada** |
| **Lei estadual posterior à EC 33** | Necessária para cobrança de PF/PJ não habitualizada |

## Núcleo

| | Conteúdo |
|---|---|
| **Aspecto temporal do FG** | Antecipado para o **momento do desembaraço aduaneiro** |
| **Razão prática** | A entrada da mercadoria ocorre em **porto/aeroporto fora do Estado de destino** |
| **Não é apreensão** | É **regra específica** de exigibilidade no ingresso ao território nacional |
| **Sujeito ativo** | Estado **de destino** (CF 155 §2 IX a) |
| **Não viola** | Princípio da legalidade nem livre iniciativa (RE 1.090.591) |

## Tema 1042 (RE 1.090.591)

| | Conteúdo |
|---|---|
| Relator | Min. Marco Aurélio |
| Julgamento | Sessão virtual encerrada em **14/09/2020** |
| **Tese** | "É **constitucional** vincular o despacho aduaneiro ao **recolhimento de diferença tributária** apurada mediante **arbitramento** da autoridade fiscal" |
| Contexto | Subfaturamento + retenção até pagamento |
| Reforço da SV 48 | Vinculação desembaraço x recolhimento confirmada |

## Aplicação prática

| Hipótese | Solução |
|---|---|
| Importação por PJ contribuinte habitual | **ICMS no desembaraço** (SV 48) |
| Importação por **PF** para uso próprio | **ICMS devido** (CF 155 §2 IX a com EC 33/2001) |
| Importação por **PJ não habitualizada** | **ICMS devido** (mesma base) |
| Importação anterior à EC 33/2001 (PF/PJ não habit.) | **NÃO incidia** (jurisprudência clássica) |
| Sujeito ativo | Estado **de destino** do importador |
| Base de cálculo | Valor da mercadoria + II + IPI + IOF + despesas aduaneiras + o **próprio ICMS** (cálculo por dentro, LC 87 art. 13 V) |

## Imunidade x SV 48

| Hipótese | Solução |
|---|---|
| Importação por **ente público** | **Imunidade recíproca** (CF 150 VI a), não há ICMS |
| Templo religioso | Imunidade CF 150 VI b |
| Partido + sindicato + entidade assistencial | CF 150 VI c |
| **Livro/jornal/periódico (papel + e-book)** | CF 150 VI d + SV 57 |
| Bem importado **para integrar ativo fixo** de PJ não contribuinte (antes EC 33) | Súm. 660 STF (não incidia) |

## Local da operação

| | Conteúdo |
|---|---|
| **CF 155 §2 IX a** | Estado de **destino físico** da mercadoria |
| LC 87 art. 11 I d | Estabelecimento onde ocorra a entrada |
| **Importação indireta** | Estado do real destinatário (combate à guerra fiscal) |
| Tema 520 STF (RE 665.134) | Sujeito ativo é o do **destinatário jurídico** quando há trading + destinatário final em outro Estado |

## Casos correlatos

| | Conteúdo |
|---|---|
| **Tema 1042** | RE 1.090.591, desembaraço x diferença tributária |
| **Tema 520** | RE 665.134, sujeito ativo na importação indireta |
| **Tema 297** | RE 540.829, leasing internacional sem opção de compra (não incide) |
| Súm. 660 STF | Pré-EC 33: não incidia sobre não contribuinte (superada para fatos posteriores) |
| ADI 1.600 | ICMS sobre transporte aéreo internacional (não incide) |

## Distinguishing

| Hipótese | Saída |
|---|---|
| Leasing internacional **sem opção de compra** | **NÃO incide** ICMS (Tema 297) |
| Comodato + importação | Análise da efetiva transferência |
| Bem para **ativo fixo** + PJ contribuinte | **Incide** (FG da importação) |
| Bem com **imunidade material** (livro, jornal) | Não incide |
| **Ente público** importador | Imunidade recíproca |
| Drawback regular | Suspensão (regime aduaneiro especial) |

## Erros a evitar

- O ICMS incide sobre **PF não habitualizada** após EC 33/2001;
- Aplicar Súm. 660 STF a fatos **posteriores à EC 33** (superada nesse ponto);
- Definir sujeito ativo pelo **porto de entrada** e não pelo **destino** (CF 155 §2 IX a);
- Considerar **apreensão** o condicionamento do desembaraço (RE 1.090.591);
- Aplicar SV 48 a **leasing sem opção de compra** (Tema 297);
- Esquecer o **cálculo por dentro** + II + IPI + IOF (LC 87 art. 13 V);
- A **importação indireta** com destinatário em outro Estado é tributável (Tema 520);
- Considerar o ICMS importação como **ICMS interestadual** comum (regra própria);
- Aplicar **DIFAL** à importação direta (não há operação interestadual prévia);
- Ignorar **imunidade material** (livro físico/e-book, SV 57);
- Confundir a exigência do ICMS no desembaraço (SV 48, lícita) com **sanção política** vedada (Súms. 70, 323 e 547 STF: interdição, apreensão de mercadorias e restrições de atividade como meio coercitivo de cobrança);
- Tratar trading como contribuinte quando o destinatário jurídico é outro;
- A lei estadual editada **após EC 33** é aplicável a PF/PJ não habit.;
- Aplicar incidência **antes do desembaraço** (a SV define o **momento exato**).

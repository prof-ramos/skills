# Norma Antielisão

## CTN 116 par. único (LC 104/2001)

| | Conteúdo |
|---|---|
| Tese | Autoridade administrativa pode **DESCONSIDERAR ATOS/NEGÓCIOS jurídicos** praticados com **FINALIDADE de DISSIMULAR** a ocorrência do FG ou a natureza dos elementos |
| Natureza | **Norma geral antielisiva** (também referida como **antielusiva**): visa coibir negócios formalmente lícitos mas com finalidade de dissimular o fato gerador |

## DISTINÇÕES clássicas

| | Conteúdo |
|---|---|
| **(a) ELISÃO** | Planejamento tributário **LÍCITO**, **anterior ao FG**, mediante forma jurídica menos onerosa |
| **(b) EVASÃO** | Sonegação **ILÍCITA** (omissão + falsificação) |
| **(c) ELUSÃO** | Utilização de formas jurídicas **ATÍPICAS + SIMULADAS + ABUSIVAS** que mascaram o FG; **ALVO NUCLEAR** do art. 116 par. único |

## STF ADI 2.446 (2022)

| | Conteúdo |
|---|---|
| Resultado | Ação julgada improcedente por maioria |
| Tese | CTN 116 par. único **CONSTITUCIONAL** |

### Fundamentos
| | Conteúdo |
|---|---|
| (i) | NÃO viola **legalidade nem separação de poderes**: a desconsideração restringe-se a **atos DISSIMULATÓRIOS** e não autoriza **tributação por analogia** |
| (ii) | Contribuinte mantém direito à **ECONOMIA FISCAL LEGÍTIMA** |
| (iii) | Eficácia plena depende de **LEI ORDINÁRIA regulamentadora** do procedimento administrativo |

| | Conteúdo |
|---|---|

## Contencioso administrativo: critérios usuais

| | Conteúdo |
|---|---|
| Critérios | Exame de **PROPÓSITO NEGOCIAL** + **SUBSTÂNCIA SOBRE FORMA** na análise de planejamentos tributários |

## Distinções essenciais

| | Elisão | Evasão | Elusão |
|---|---|---|---|
| Licitude | **Lícita** | **Ilícita** | Aparente lícita |
| Tempo | Antes do FG | Depois ou junto | Antes |
| Conteúdo | Forma alternativa | Sonegação | **Dissimulação** |
| CTN 116 par. único | NÃO atinge | Outras normas | **ATINGE** |

| | Dolo/fraude/simulação | Sem dolo |
|---|---|---|
| Decadência | **CTN 173 I** | CTN 150 §4 (homologação) |

| | Tributação por analogia | Desconsideração |
|---|---|---|
| Permitido | **NÃO** | **OK** (ADI 2.446) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Forma jurídica menos onerosa | **ELISÃO lícita** |
| Falsificação | **EVASÃO** + Lei 8.137 |
| Negócio simulado dissimulando FG | **ELUSÃO**: CTN 116 par. único |
| Dolo/fraude/simulação | **CTN 173 I** (Súm. 555) |
| Revisão por fraude | **CTN 149 VII** |
| Propósito negocial ausente | Risco de **desconsideração** no contencioso administrativo |
| Aplicação por analogia | **VEDADA** (ADI 2.446) |
| Sem LO regulamentadora | **Procedimento limitado** |
| Treaty shopping | Normas específicas |
| Preço de transferência | **Lei 9.430 + 14.596** |

## Erros a evitar

- **Tratar ELISÃO como evasão** (lícita × ilícita);
- Aplicar **CTN 116 par. único** para **tributação por analogia** (ADI 2.446: vedada);
- Aplicar **CTN 150 §4** quando há dolo/fraude (CTN 173 I + Súm. 555);
- A **economia fiscal legítima** é admitida (ADI 2.446);
- Aplicar **CTN 116** sem **LO regulamentadora** quanto ao procedimento detalhado;
- A revisão por fraude é cabível (**CTN 149 VII**);
- Tratar **CTN 116 como inconstitucional** (ADI 2.446: válido);
- Aplicar **CTN 116** a planejamento lícito sem dissimulação;
- Confundir **ELUSÃO** com elisão (distintas);
- Admitir como oponível ao fisco negócio praticado com dissimulação do fato gerador (CTN 116 par. único; ADI 2.446) ou com dolo, fraude ou simulação (CTN 149 VII); o exame de propósito negocial e substância econômica é critério usual do contencioso administrativo, sem previsão legal específica;
- Aplicar **norma geral** quando há **norma específica antielisiva**.

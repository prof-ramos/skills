# Sociedade em Comandita por Ações

## Marco legal

- **LSA 280-284** (Lei 6.404/76);
- **CC 1.090-1.092** (regras complementares);
- LSA aplicável **integralmente** no que não conflitar com CC 1.090-1.092 (LSA 280);
- Lei 8.934/94 (Junta Comercial).

## Características essenciais

| | Conteúdo |
|---|---|
| Capital | Dividido em **ações** (não quotas) |
| Espécies | ON + PN + classes |
| **Acionistas-diretores** | Somente **acionistas** administram (CC 1.091 + LSA 282); pessoa natural (LSA 146); responsabilidade ilimitada |
| **Demais acionistas** | Limitada ao **preço de emissão** das ações (LSA 1) |
| Nome | **Firma ou denominação** (CC 1.090), seguida de "Comandita por Ações", por extenso ou abreviadamente (LSA 281 par. único) |
| Natureza | **Empresária** (sociedade por ações sempre é empresária) |
| Registro | Junta Comercial |

## Diretores (CC 1.091 + LSA 282)

| | Conteúdo |
|---|---|
| **Quem pode** | **Apenas acionistas** (CC 1.091 caput); pessoa natural, por força do LSA 146 |
| **Vedação** | Não acionista: vedado |
| **Mandato** | Nomeação no ato constitutivo, **sem limitação de tempo** (CC 1.091 §2 + LSA 282) |
| **Destituição** | Acionistas representando **≥ 2/3 do capital** (CC 1.091 §2 + LSA 282) |
| Renúncia | Livre |
| Substituição | Por novo acionista, mediante assembleia |

## Responsabilidade dos diretores (CC 1.091 §§)

| | Conteúdo |
|---|---|
| **Subsidiária + ilimitada** | Pelas obrigações sociais, depois de esgotados os bens sociais (CC 1.091 caput + §1) |
| Vários diretores | **Solidariedade** entre eles, após esgotados os bens sociais (CC 1.091 §1) |
| **§3** | Diretor destituído ou exonerado continua responsável, **durante 2 anos**, pelas obrigações contraídas **sob sua administração** (CC 1.091 §3) |

## Restrições à AGE (CC 1.092 + LSA 283)

> AGE não pode, **sem consentimento dos diretores**, deliberar sobre:

| Matéria | Razão |
|---|---|
| **Mudança do objeto** essencial | Altera responsabilidade ilimitada |
| **Prorrogação do prazo** | Estende exposição |
| **Aumento ou diminuição do capital** | Altera responsabilidade |
| **Criação de debêntures** | Endividamento adicional |
| **Criação de partes beneficiárias** | Direitos econômicos diferenciados |

Forma de consentimento: **expresso** dos diretores em ata ou documento próprio.

## Demais acionistas

| | Conteúdo |
|---|---|
| Natureza | PF ou **PJ** |
| Responsabilidade | **Limitada ao preço de emissão** das ações subscritas/compradas (LSA 1) |
| Participação | Voto + dividendos + bonificações + retirada (LSA 137) |
| Conversão | Pode tornar-se diretor (se acionista e for eleito): assume responsabilidade ilimitada |

## Estrutura LSA aplicável (LSA 280)

| | Conteúdo |
|---|---|
| Capital social | Inteiramente subscrito antes do registro (LSA 80) |
| Ações | Nominativas (não há mais ações ao portador) |
| AGE/AGO | Aplicáveis (LSA 121-136) |
| Conselho fiscal | Aplicável (LSA 161) |
| **Conselho de administração** | **Vedado** (LSA 284): gestão direta dos diretores |
| **Capital autorizado + bônus de subscrição** | Também **vedados** (LSA 284) |
| Acordos de acionistas | Aplicáveis (LSA 118) |

## Diferenças com S.A. pura

| | S.A. (CC 1.088 + LSA) | **C/A** (CC 1.090 + LSA 280) |
|---|---|---|
| Capital | Ações | **Ações** |
| Resp. acionistas | Limitada | Limitada (exceto diretores) |
| Diretores | Limitada (BJR) | **Ilimitada + solidária** |
| Conselho de administração | Possível/obrigatório (cias. abertas) | **Vedado** |
| Mandato diretor | Até 3 anos (LSA 143) | **Indeterminado** |
| Destituição | Maioria | **2/3 capital** |

## Uso prático (raríssimo)

| Cenário | Aplicabilidade |
|---|---|
| Empresas familiares com gestão privativa | Possível mas LTDA + acordo é preferida |
| **Holdings de controle** | Inviável pelo regime |
| Em desuso desde anos 80 | Aparece em consultas históricas |
| Vantagem | Garantir blindagem do controle pela responsabilidade ilimitada dos diretores |

## Reorganização societária

- Transformação em S.A. ou LTDA segue o regime geral: consentimento unânime dos sócios, salvo previsão no estatuto, com recesso do dissidente (CC 1.114 + LSA 221);
- Fusão + cisão + incorporação seguem a LSA;
- Resolução parcial: aplicação subsidiária CC 1.028-1.032.

## Falência + dissolução

- Lei 11.101/2005 aplicável;
- Insolvência: diretores respondem pelo **saldo devedor**;
- Dissolução: causas comuns (CC 1.033 + LSA 206).

## Pontos operacionais consolidados

| | Conteúdo |
|---|---|
| Responsabilidade ilimitada diretor | Subsidiária: necessário esgotar os bens sociais antes (CC 1.091 §1) |
| **2/3 capital para destituir** | Quórum **inderrogável**: não pode ser reduzido por estatuto |
| Mandato indeterminado | Não pode ser limitado por estatuto (LSA 282) |
| Consentimento diretor (1.092) | Vício invalida deliberação |

## Vedações do LSA 284

O LSA 284 exclui a aplicação, à comandita por ações, das regras sobre **conselho de administração**, **autorização estatutária de aumento de capital** (capital autorizado) e **emissão de bônus de subscrição**. A gestão é exclusiva dos diretores-acionistas.

## Erros a evitar

- Aceitar **PJ como diretor** (vedado: administrador de sociedade por ações é pessoa natural, LSA 146);
- Eleger não acionista como diretor (vedado: CC 1.091 + LSA 282);
- Destituir diretor por maioria simples (necessário **2/3 do capital**, CC 1.091 §2);
- Aprovar alteração de capital, objeto ou prazo, criação de debêntures ou partes beneficiárias **sem consentimento dos diretores** (CC 1.092);
- Criar **conselho de administração**, capital autorizado ou bônus de subscrição (vedados, LSA 284);
- Esquecer a responsabilidade do diretor destituído/exonerado (CC 1.091 §3: 2 anos pelas obrigações contraídas sob sua administração);
- Tratar como S.A. comum para responsabilidade dos administradores;
- Aplicar **IDPJ** contra diretor: a responsabilidade é **direta**, após esgotados os bens sociais (CC 1.091).

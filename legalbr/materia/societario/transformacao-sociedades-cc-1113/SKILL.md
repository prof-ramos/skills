# Transformação de Sociedades

## Marco legal

- **CC 1.113-1.115** (Capítulo X);
- **LSA 220-222** (Lei 6.404/76, aplicável também a sociedades por ações);
- Lei 8.934/94 (Junta Comercial);
- Lei 14.451/2022 (quóruns LTDA, relevante para transformação contratada por maioria);
- IN DREI 81/2020, alterada pelas IN DREI 55/2021, 112/2022 e 88/2022 (procedimento registral).

## Conceito (CC 1.113)

> "O ato de transformação independe de dissolução ou liquidação da sociedade, e obedecerá aos preceitos reguladores da constituição e inscrição próprios do tipo em que vai converter-se."

| | Conteúdo |
|---|---|
| Natureza | **Continuidade** da pessoa jurídica |
| Personalidade | **Mantida** (mesmo CNPJ + mesmos contratos) |
| Patrimônio | **Inalterado** |
| Sócios | Mantidos (salvo recesso) |
| **Não** há | Dissolução, liquidação, nova subscrição, fato gerador tributário |

## Quórum (CC 1.114 + LSA 221)

| Cenário | Quórum |
|---|---|
| **Regra** | **Unanimidade** dos sócios |
| Previsão no contrato/estatuto | **Maioria** (capital social); a Lei 14.451/2022 reduziu para > 1/2 em LTDA |
| Companhia aberta (S.A. → outra) | Assembleia + comunicação CVM + OPA se aplicável |
| **Sócio dissidente** | Direito de **retirada/recesso** (LSA 221 + CC 1.077 análogo) |

### Direito de recesso

| | Conteúdo |
|---|---|
| Base | LSA 221 (retirada do dissidente quando a transformação for aprovada por previsão estatutária/contratual) + 137 (reembolso) |
| Prazo | **30 dias** da deliberação (LSA 137 IV, por analogia) |
| **Apuração de haveres** | Valor real a preços de mercado (STJ: não só contábil) |
| Reembolso | Nas sociedades regidas pelo CC, pagamento em dinheiro em **90 dias** da liquidação da quota (CC 1.031 §2 supletivo) |

## Procedimento

| Etapa | Conteúdo |
|---|---|
| 1. Convocação | Assembleia/reunião com pauta específica |
| 2. Deliberação | Quórum legal/contratual |
| 3. Novo contrato/estatuto | Adequado ao tipo de destino |
| 4. **Registro** | Junta Comercial (LSA 220 + CC 1.150): averbação no contrato anterior + arquivamento do novo |
| 5. Alvarás + inscrições | CNPJ mantém; atualização cadastral |
| 6. Publicação | Se exigida (S.A., LSA 289) |

## Garantia dos credores (CC 1.115 + LSA 222)

> "A transformação não modificará nem prejudicará, em qualquer caso, os direitos dos credores."

| | Conteúdo |
|---|---|
| Credores **anteriores** | Mantêm **as mesmas garantias** que o tipo anterior oferecia (CC 1.115 + LSA 222) |
| **Falência** posterior | Só produz efeitos em relação aos sócios que a ela estariam sujeitos no tipo anterior **se o pedirem credores anteriores** à transformação, e somente a estes beneficia (CC 1.115 par. único + LSA 222 par. único) |
| Sócio de responsabilidade ilimitada no tipo anterior | Mantém responsabilidade pelas obrigações **anteriores** à transformação |
| Dívidas novas | Regem-se pelo tipo de destino (responsabilidade limitada, se for o caso) |

## Tipos comuns de transformação

| De → Para | Razão |
|---|---|
| **LTDA → S.A.** | Acesso a mercado de capitais + emissão de debêntures + governança formal |
| **S.A. → LTDA** | Simplificação + redução de custos + flexibilidade contratual |
| **EIRELI → SLU** | **Automática** (Lei 14.382/22 art. 41), sem deliberação |
| **SLU → LTDA** | Entrada de novo sócio |
| **Empresário Individual → LTDA/SLU** | Limitação de responsabilidade |
| Sociedade Simples → LTDA | Adoção de natureza empresária |
| **Cooperativa → Sociedade** | **Vedada**: cooperativa exige dissolução |
| Comandita → S.A./LTDA | Eliminação da responsabilidade ilimitada (com manutenção das anteriores) |

## Aspectos tributários

| | Conteúdo |
|---|---|
| **IRPJ** | Sem fato gerador: não há realização |
| **ITBI** | **Não incide** sobre transferência de imóveis (mesma PJ) |
| ICMS/ISS | Sem fato gerador |
| Continuidade | Mesmo CNPJ + mesma escrituração |
| **Reorganização → S.A.** | Possível mudança de regime (LP → LR): atenção ao planejamento |

## Reforma tributária (LC 214/2025)

- Transformação **não é fato gerador** de IBS/CBS;
- Manutenção de créditos de IBS/CBS após a transformação;
- Regime do tipo de destino aplica-se a partir da averbação.

## Tributário trabalhista + previdenciário

- CTPS + INSS + FGTS continuam com **mesmo CNPJ**;
- Contratos de trabalho **mantidos** (CLT 10 + 448: continuidade);
- Sucessão automática.

## Casos especiais

| Cenário | Tratamento |
|---|---|
| **Cooperativa** | Não admite transformação (regime sui generis: exige dissolução) |
| **Fundação** | Não se aplica (não é sociedade) |
| **Comandita por Ações → S.A.** | Segue a regra geral: consentimento unânime, salvo previsão estatutária (CC 1.114 + LSA 221) |
| **Sociedade irregular/de fato** | Não cabe: precisa regularizar primeiro |
| Sociedade em conta de participação (SCP) | Sem PJ: não cabe transformação |

## Registro extemporâneo

| | Conteúdo |
|---|---|
| Regra | O ato sujeito a registro não pode ser oposto a terceiro antes do cumprimento das formalidades, salvo prova de que este o conhecia (CC 1.154) |
| Eficácia | Perante terceiros de boa-fé, apenas **ex nunc** |
| Aplicação | Transformações arquivadas tardiamente: efeitos perante terceiros só após o registro |

## Diferença de outras reorganizações

| | Conteúdo |
|---|---|
| **Transformação** | Mudança de tipo, **mesma PJ** |
| **Incorporação** | A incorpora B → B se extingue, patrimônio → A |
| **Fusão** | A + B → C (nova PJ; A e B se extinguem) |
| **Cisão** | A → B + C (parcial ou total) |
| **Conversão** | Termo coloquial: equivale a transformação |

## Contratos + autorizações

| | Conteúdo |
|---|---|
| Contratos com terceiros | **Mantidos** (CC 1.113: continuidade) |
| Licenças/alvarás | Geralmente mantidos (atualização cadastral) |
| Concessões públicas | Verificar contrato: pode exigir anuência |
| **Acordos de acionistas** | Adaptar para novo tipo |
| Contratos bancários com covenants | **Atenção**: change of control pode disparar |
| Empréstimos externos | Verificar cláusula de assignment |

## Erros a evitar

- Tratar transformação como **dissolução + nova sociedade** (CC 1.113: continuidade);
- Esquecer **direito de recesso** do dissidente (LSA 221);
- Achar que credor antigo perde garantia (CC 1.115 + LSA 222: mantém);
- Aplicar **ITBI** ou IRPJ sobre transformação (não há fato gerador);
- Transformar cooperativa em sociedade (vedado: exige dissolução);
- Esquecer que o sócio de responsabilidade ilimitada no tipo anterior **continua respondendo** pelas obrigações anteriores à transformação (CC 1.115 + LSA 222);
- Transformar S.A. aberta sem **comunicação CVM** (Resoluções aplicáveis);
- Esquecer atualização de **alvarás + licenças + cadastros** (mantém CNPJ mas pode exigir adequação);
- Esperar efeitos **retroativos** de registro tardio (CC 1.154: perante terceiros, só ex nunc);
- Aplicar quórum de **maioria** sem previsão contratual (regra é unanimidade, CC 1.114).

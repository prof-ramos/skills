# Marco Legal das Startups

## LC 182/2021

| | Conteúdo |
|---|---|
| Tese | **Marco Legal das Startups e do Empreendedorismo Inovador** |

## Conceito de STARTUP (art. 4)

| | Conteúdo |
|---|---|
| Definição | PJ **nascente ou em operação recente** com atuação caracterizada por **INOVAÇÃO aplicada a modelo de negócios ou produtos/serviços** |

### Requisitos cumulativos
| | Conteúdo |
|---|---|
| **Receita bruta** | Até **R$ 16 milhões** no ano anterior (proporcional) |
| **Tempo de CNPJ** | Até **10 ANOS** |
| Enquadramento | **Inova Simples** OU **declaração** de uso de modelos inovadores |

## Tipos admitidos

| | Conteúdo |
|---|---|
| **ME + EPP** | |
| EIRELI | (extinta pela Lei 14.382/2022; sucedida pela SLU) |
| **SLU** | Sociedade Limitada Unipessoal |
| **Sociedade empresária** | LTDA + outras |
| Cooperativa | |
| **S.A.** | |

## INVESTIMENTOS (art. 5)

| | Conteúdo |
|---|---|
| Tese | Aportes por **PF + PJ + fundos** que **NÃO integram capital social** + **sem assumir risco ilimitado** |

### Modalidades
| | Conteúdo |
|---|---|
| **Contrato de opção** | Subscrição/compra de ações ou quotas |
| **Debêntures conversíveis** | |
| **Mútuo CONVERSÍVEL** | Em participação societária |
| **SCP** | Sociedade em Conta de Participação |
| **Contrato de INVESTIMENTO-ANJO** | LC 155/2016, mantido (LC 123 art. 61-A, com redação da LC 182/2021) |

## INVESTIDOR-ANJO

| | Conteúdo |
|---|---|
| Status | **NÃO é sócio** |
| Gerência/voto | **NÃO TEM** direito |
| Responsabilidade por dívidas | **NÃO responde** (inclusive em recuperação judicial + desconsideração) |
| **Resgate** | Após **mínimo de 2 ANOS** |
| **Retorno MÁXIMO** | **7 ANOS** |

## SANDBOX REGULATÓRIO (art. 11)

| | Conteúdo |
|---|---|
| Conteúdo | Condições especiais simplificadas para PJ participantes |
| **Autorização TEMPORÁRIA** | Por órgãos reguladores setoriais (**CVM + BCB + Susep + ANS + Anatel** etc.) |
| Função | **TESTAR modelos e tecnologias INOVADORAS** com critérios pré-definidos |

## Programa INOVA SIMPLES

| | Conteúdo |
|---|---|
| Base | **LC 167/2019** |
| Função | Cadastro simplificado |

## Articulação com outras leis

| | Conteúdo |
|---|---|
| **Lei do Bem (Lei 11.196/2005)** | **Incentivos fiscais** a P&D |
| **Marco Legal CT&I (Lei 13.243/2016 + EC 85/2015)** | Cooperação com **ICTs + universidades + encomenda tecnológica + bônus tecnológico** |
| **CPSI** | **Contratação Pública de Soluções Inovadoras** por órgãos federais |

## Jurisprudência atual

| | Conteúdo |
|---|---|
| TST/TRTs | Respeitam **SEPARAÇÃO investidor-anjo × empresa**, afastando responsabilidade subsidiária |
| STJ | Aceita arranjos contratuais **ATÍPICOS** (mútuo conversível) como válidos |

## Debates atuais

| | Conteúdo |
|---|---|
| **Stock options** | **Natureza MERCANTIL**, não salarial (Tema 1.226 STJ): sem IRPF na aquisição das ações; IRPF só na revenda com ganho de capital |
| **Desconsideração** | Em startups com investimento-anjo: o anjo não responde, afastado o CC 50 (LC 123 art. 61-A §4 II) |

## Distinções essenciais

| | Investidor-anjo | Sócio |
|---|---|---|
| Capital social | **NÃO integra** | Integra |
| Risco | **Limitado** | Ilimitado |
| Voto | **NÃO** | Sim |
| Dívidas | NÃO responde | Responde |

| | Startup | ME comum |
|---|---|---|
| Inovação | **Característica essencial** | Opcional |
| Receita | Até R$ 16mi | Variável |
| Tempo CNPJ | Até 10a | Sem limite |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| PJ inovadora 5 anos receita R$ 8mi | **STARTUP** |
| > 10 anos CNPJ | **NÃO se aplica** Marco |
| Receita > R$ 16mi | NÃO |
| Investidor-anjo aporta | **NÃO é sócio** + **sem responsabilidade** |
| Mútuo conversível | Modalidade do art. 5 |
| Sandbox CVM | **Autorização temporária** |
| Inova Simples | Cadastro simplificado |
| Stock options | **Mercantil** (não salarial) |
| Desconsideração ataca anjo | **Vedada** |
| CPSI | Contratação pública específica |
| Cooperação ICT | Lei 13.243 |

## Erros a evitar

- **Tratar INVESTIDOR-ANJO como SÓCIO** (vedado: LC 182 + LC 123 art. 61-A §4 I);
- **Desconsiderar a personalidade contra o ANJO** (LC 182 + LC 155);
- Aplicar **vínculo trabalhista** ao stock option (STJ, Tema 1.226: mercantil);
- Aplicar **Lei 13.874 ignorando LC 182** em startups;
- **Aceitar startup com receita > R$ 16mi** (LC 182);
- Aplicar **Marco a empresa > 10a CNPJ** (LC 182);
- Negar **sandbox regulatório** (art. 11);
- Não articular **Lei do Bem** quando cabível;
- Tratar **mútuo conversível como mero empréstimo** (LC 182 art. 5);
- Negar **CPSI** quando aplicável;
- Aplicar **EIRELI** (extinta: usar SLU).

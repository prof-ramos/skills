# ADIs 2010 + 3105: Contribuição de Inativos

Antes de usar, ler o [protocolo LegalBR](../../../SKILL.md). Este arquivo não foi integralmente verificado; confirmar fundamentos em fontes oficiais.

## ADI 2010 (1999)

| | Conteúdo |
|---|---|
| Objeto | Lei 9.783/1999 (contribuição de inativos; lei posteriormente revogada) |
| Tese | **Inconstitucional** sem base na CF |
| Princípios | Direito adquirido + segurança jurídica |

## EC 41/2003 + ADI 3105

| | Conteúdo |
|---|---|
| EC 41 | Inseriu CF 40 §18 (contribuição de inativos) |
| ADI 3105 | **Constitucional** após EC |
| Alíquota | 11% sobre o que exceder o teto do RGPS |

## EC 103/2019 (Nova Previdência)

| | Conteúdo |
|---|---|
| Alíquotas | Progressivas |
| Inativos | Mantida contribuição |
| Aposentadoria por idade + tempo | Reforma |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Contribuição de inativos pré-EC 41 | **Vedada** (ADI 2010) |
| Pós-EC 41 | **Válida** (ADI 3105) |
| Base | Excedente ao teto do RGPS |
| Alíquota | EC 103: progressiva |
| Direito adquirido | Respeitado |
| Regime próprio | CF 40 |
| Regime geral | CF 201 |

## Erros a evitar

- Aplicar a Lei 9.783/99 como se vigente (contribuição vedada pela ADI 2010; lei revogada);
- Ignorar EC 41 + ADI 3105;
- Tratar contribuição como integral sem teto;
- Confundir RPPS com RGPS;
- Aplicar alíquota uniforme após EC 103 (são progressivas).

# Nome Empresarial

## Marco legal

- **CC 1.155-1.168** (Capítulo II, Nome Empresarial);
- **Lei 8.934/1994** (Registro Público de Empresas);
- **Lei 14.195/2021** (Ambiente de Negócios; IN DREI);
- **Lei 14.382/2022** (SERP, Sistema Eletrônico dos Registros Públicos);
- **IN DREI 81/2020** + atualizações;
- **Lei 9.279/96** (Propriedade Industrial: marca);
- **Provimentos CNJ** sobre registros.

## Conceito (CC 1.155)

> "**Nome empresarial** é a firma ou a denominação adotada, de conformidade com este Capítulo, para o exercício da atividade econômica."

| | Conteúdo |
|---|---|
| **Identifica** | Empresário/sociedade + atividade |
| **Componentes** | Firma + denominação |
| **Diferente de marca** | Marca = produto/serviço |
| **Diferente de título de estabelecimento** | Local físico |
| **Vinculado** | Ao tipo societário |

## Firma × Denominação

### Firma (CC 1.156-1.157)

| | Conteúdo |
|---|---|
| **Composição** | **Nome civil** do(s) sócio(s), completo ou abreviado |
| **Tipos que usam firma** | Empresário individual + sociedade em nome coletivo + comanditas |
| **Indicação** | Pode incluir gênero da atividade (ex. "Lima Restaurante") |
| **Assinatura** | Coincide com a firma |

### Denominação (CC 1.158-1.162)

| | Conteúdo |
|---|---|
| **Composição** | **Palavras**: núcleo + objeto |
| **Tipos que usam** | LTDA + S.A. + Cooperativa + SLU |
| **Núcleo** | Nome de fantasia (ex. "Magazine Luiza") |
| **Objeto** | Atividade (ex. "Comércio de Bebidas") |
| **Inclusão do tipo** | LTDA + S.A. obrigatório |

## Princípios (CC 1.163-1.165)

### Veracidade

| | Conteúdo |
|---|---|
| **Definição** | Nome deve refletir a realidade |
| **Composição** | Nome civil real + atividade correspondente |
| **Vedação** | Nome falso ou enganoso |
| **Sanção** | Anulação |

### Novidade

| | Conteúdo |
|---|---|
| **Definição** | Não pode haver outro nome empresarial idêntico ou semelhante |
| **Distinção** | De nomes já registrados |
| **Verificação** | Pela Junta Comercial antes do registro |
| **Colidência** | Pode levar à anulação |

## Proteção (CC 1.166)

> "A inscrição do empresário, ou dos atos constitutivos das pessoas jurídicas, ou as respectivas averbações, no registro próprio, **asseguram o uso exclusivo do nome nos limites do respectivo Estado**."

| | Conteúdo |
|---|---|
| **Âmbito** | **Estadual** (UF) |
| **Como ampliar** | Arquivamento em outras juntas + registro de marca no INPI |
| **Vigência** | A partir do registro |
| **Exclusividade** | Para mesmo ramo ou ramo concorrente |

## Proteção nacional via INPI

| | Conteúdo |
|---|---|
| **Lei 9.279/96** | Proteção de marca em todo o território nacional |
| **Marca + nome empresarial** | Podem coincidir ou divergir |
| **Marca** | Protege produto/serviço |
| **Nome empresarial** | Protege empresário/atividade |
| **Combinação** | Reforça proteção |

## Tipos por sociedade

| Tipo | Nome Empresarial |
|---|---|
| **Empresário Individual** | Firma (nome civil + atividade) |
| **EIRELI** | EXTINTA (Lei 14.382/2022): SLU substitui |
| **SLU** | Firma ou denominação + "Ltda." (Lei 14.382 art. 41) |
| **Sociedade em nome coletivo** | Firma com nome dos sócios |
| **Comandita simples** | Firma com nome dos comanditados |
| **LTDA** | Firma ou denominação + "Ltda." |
| **S.A.** | Denominação + "S.A." ou "Cia." |
| **Comandita por ações** | Firma ou denominação + "Comandita por Ações" (CC 1.161) |
| **Cooperativa** | Denominação + "Cooperativa" |

## Colidência de nomes

| | Conteúdo |
|---|---|
| **Identidade** | Nome igual a outro registrado |
| **Semelhança** | Capaz de causar confusão |
| **Verificação prévia** | Junta Comercial faz |
| **Procedimento** | Recurso administrativo |
| **STJ** | Anula registro posterior |
| **Prazo** | A ação de anulação cabe a qualquer tempo (CC 1.167) |

## Anulação de registro (CC 1.167)

| | Conteúdo |
|---|---|
| **Prazo** | A qualquer tempo (CC 1.167); não confundir com o prazo de 5 anos da ação de nulidade de registro de MARCA (LPI art. 174) |
| **Legitimidade** | Quem se sentir prejudicado |
| **Foro** | Justiça comum estadual |
| **Após decisão** | Junta cancela registro |
| **Indenização** | Possível (danos materiais + morais) |

## Alienação do nome empresarial (CC 1.164)

> "O nome empresarial **não pode ser objeto de alienação**."

| | Conteúdo |
|---|---|
| **Vedação** | Alienação isolada |
| **Junto com a empresa** | Possível (CC 1.144) |
| **Aliena-se o estabelecimento** + permite uso do nome |
| **Adquirente** | Sucessor + adendo "Sucessor de..." |

## Mudança de nome empresarial

| | Conteúdo |
|---|---|
| **Possível** | Mediante alteração contratual/estatutária |
| **Registro na Junta** | Necessário |
| **Cadastros** | Atualização (CNPJ + cadastros estaduais/municipais) |
| **Reflexo em contratos** | Notificação aos parceiros |
| **Reflexo em marca** | Atualização INPI se relacionada |

## Erros a evitar

- Confundir **nome empresarial** com **marca** ou **título do estabelecimento**;
- Aplicar **firma** em LTDA/S.A. (regra é denominação para essas);
- Esquecer o **princípio da veracidade**: nome falso é anulável;
- Não verificar **colidência prévia** na Junta;
- Tentar **alienar nome isoladamente** (CC 1.164: vedado);
- Inventar prazo decadencial para a anulatória do CC 1.167 (cabe **a qualquer tempo**; o prazo de 5 anos é da nulidade de marca, LPI 174);
- Não atualizar **CNPJ + cadastros** após mudança;
- Confundir **proteção estadual** com nacional (nome estadual; marca INPI);
- Aplicar EIRELI (extinta: SLU substitui);
- Não documentar **alteração contratual** + registro na Junta;
- Esquecer **adendo "Sucessor de..."** na sucessão.

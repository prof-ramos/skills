# Títulos de Crédito

## CC 887: conceito + princípios

| | Conteúdo |
|---|---|
| Conceito | "Documento necessário ao exercício do direito **literal e autônomo** nele contido" |
| Princípios | **CARTULARIDADE + LITERALIDADE + AUTONOMIA + ABSTRAÇÃO** |

### Princípios cambiários

| Princípio | Conteúdo |
|---|---|
| **CARTULARIDADE** | Incorporação ao documento físico, mitigada pela desmaterialização |
| **LITERALIDADE** | Só vale o que está escrito (CC 890: não escritas as cláusulas de juros não previstas em lei, dispensa de protesto, exclusão de responsabilidade) |
| **AUTONOMIA** | Obrigações independentes (CC 887 + 915) |
| **ABSTRAÇÃO** | Desvinculação da causa **APÓS CIRCULAÇÃO** por endosso |

## Disposições gerais (CC 887-926)

| Art. | Conteúdo |
|---|---|
| **890** | Reputa **não escritas** cláusulas excluídas (juros sem lei + dispensa de protesto + exclusão) |
| **893** | Incapacidade do emitente **NÃO invalida** obrigações dos demais |
| **894** | Pagamento mediante **entrega da cártula** |
| **896** | Perda: admite reivindicação |
| **897** | Aval como **garantia de pagamento**; o **parágrafo único VEDA o aval parcial** (a LU admite; prevalece a LU para letra/promissória/cheque) |
| **898** | **AVAL NO PRÓPRIO TÍTULO** (verso ou anverso); no anverso, basta a simples assinatura do avalista |
| **899** | Aval em **preto** (nome indicado) × em **branco** (equipara-se ao emitente ou devedor final) |
| **899 §1** | Avalista que paga tem **REGRESSO** contra avalizado e coobrigados anteriores |
| **900** | **Aval posterior ao vencimento** produz os mesmos efeitos do anteriormente dado |
| **903** | **Leis especiais PREVALECEM** sobre o CC |
| **914** | Endossante **NÃO responde** pelo pagamento, salvo cláusula expressa (derrogado por LU/Lei Cheque) |
| **917** | Endosso em branco ou em preto |
| **919** | Endosso **APÓS PROTESTO** → efeitos de **cessão civil** |
| **206 §3 VIII** | **PRESCRIÇÃO 3 ANOS** da pretensão de pagamento de título de crédito, ressalvada lei especial (o CC 925 trata de matéria diversa: desoneração do devedor de boa-fé na transferência de título nominativo) |

## CHEQUE: Lei 7.357/85

| | Conteúdo |
|---|---|
| Natureza | **Ordem de pagamento À VISTA** (art. 32) |
| Pré-datação | **Pacto extracartular** |
| **Apresentação** | **30 DIAS mesma praça / 60 DIAS praças distintas** (art. 33) |
| **Execução** | **6 MESES** após prazo de apresentação (art. 59) |

### Pós-prescrição
| | Prazo |
|---|---|
| Ação de **ENRIQUECIMENTO** | **2 anos** |
| **MONITÓRIA** | **5 anos** (Súm. 503 STJ: contados do **dia seguinte à emissão**) |

### Súmulas
| | Conteúdo |
|---|---|
| **Súm. 600 STF** | Cabe execução mesmo **sem apresentação tempestiva** (entre partes originárias) |
| **Súm. 388 STJ** | **Devolução indevida → dano moral** |
| **Súm. 476 STJ** | Endossatário por **endosso-mandato** só responde por protesto indevido se **extrapolar** os poderes de mandatário |
| **Súm. 503 STJ** | Monitória: 5 anos do dia seguinte à emissão |
| **Sustação por motivo relevante** | Lícita (jurisprudência STJ; não há súmula com esse enunciado) |

## DUPLICATA: Lei 5.474/68 + Lei 13.775/2018

| | Conteúdo |
|---|---|
| Natureza | **CAUSAL**: vinculada a compra/venda mercantil OU prestação de serviço |
| Emissão | Facultativa pelo vendedor |
| Aceite | **OBRIGATÓRIO** salvo recusa nas **3 hipóteses do art. 8**: avaria/não recebimento + vícios de qualidade/quantidade + divergência de prazos/preços |
| **DUPLICATA "FRIA"** | Sem causa → **crime de duplicata simulada (CP 172)** |

### Lei 13.775/2018: ESCRITURAL
| | Conteúdo |
|---|---|
| Sistema | **Eletrônico** registrado em sistema autorizado (CVM/BCB) |
| Aceite | **PRESUMIDO em 15 DIAS** por assinatura eletrônica |
| Extrato | **Título executivo** |
| **Jurisprudência STJ** (REsp 1.024.691/PR e precedentes da 2ª Seção) | Executividade da duplicata virtual com boleto + comprovante de entrega + protesto por indicação |

## NOTA PROMISSÓRIA + LETRA DE CÂMBIO: LU Genebra (Dec. 57.663/66)

| | Promissória | Letra |
|---|---|---|
| Natureza | **Promessa direta** de pagamento | **Ordem** de pagamento |
| Estrutura | Emitente | Saque + aceite + endosso + aval |
| Uso | Comum | Pouco usada |

### Prescrição
| Contra | Prazo |
|---|---|
| **Emitente/aceitante** | **3 anos** |
| **Endossantes** | **1 ano** (do protesto) |
| Regresso entre coobrigados | **6 meses** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Cheque devolvido | **30/60d apresentação + 6m execução** |
| Após 6 meses do prazo | Ação **enriquecimento (2a) ou monitória (5a)** (Súm. 503) |
| Devolução indevida | **Dano moral** (Súm. 388 STJ) |
| Sustação por motivo | **Lícita** (jurisprudência STJ) |
| Aval em separado | **Sem eficácia de aval no regime do CC** (CC 898: aval no próprio título); a LU admite em folha anexa (letra/promissória/cheque) |
| Duplicata fria | **CP 172** (crime) |
| Duplicata escritural | Lei 13.775 + aceite presumido 15d |
| Cheque pré-datado quebrado | Quebra do pacto extracartular |
| Prescrição entre coobrigados | **6 meses** |
| Endosso após protesto | **Cessão civil** (CC 919) |

## Erros a evitar

- **Aplicar Lei do Cheque a OUTROS títulos** (são leis distintas);
- **Ignorar protesto FACULTATIVO no cheque** para execução contra emitente (obrigatório só contra endossantes);
- **Admitir AVAL fora do próprio título** no regime do CC (CC 898: verso ou anverso);
- **Presumir abstração ANTES da circulação** (entre partes originárias cabe causa);
- Aplicar o prazo **trienal do CC 206 §3 VIII** quando há **lei especial** (LU/Lei Cheque prevalecem); não citar o CC 925 como regra de prescrição (trata da desoneração do devedor de boa-fé em título nominativo);
- Afastar **monitória dentro de 5 anos** (Súm. 503);
- **Tratar duplicata fria como ilícito civil apenas** (é CP 172);
- Tratar aceite da duplicata escritural como **expresso** (é presumido em 15d);
- Aplicar CC 914 (endossante não responde) **a cheque/letra/promissória** (LU contrário);
- Confundir os regimes do **aval parcial**: vedado pelo CC 897 par. único, mas admitido pela LU (que prevalece para letra/promissória/cheque);
- **Sustar cheque sem motivo relevante** (vedado; sustação lícita exige motivo relevante, jurisprudência STJ).

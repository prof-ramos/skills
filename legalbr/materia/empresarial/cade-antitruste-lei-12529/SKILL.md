# CADE: Antitruste

## Lei 12.529/2011 e o SBDC

| | Conteúdo |
|---|---|
| Base | **CF 170**: livre iniciativa + livre concorrência + função social + defesa do consumidor + repressão ao abuso |
| **SBDC** | Sistema Brasileiro de Defesa da Concorrência |
| Composição | **CADE** + órgão de advocacia da concorrência do **Min. Fazenda** (atribuições da antiga SEAE, hoje na Subsecretaria de Acompanhamento Econômico e Regulação) |

## Estrutura do CADE

| Órgão | Conteúdo |
|---|---|
| **Tribunal Administrativo** | **Presidente + 6 Conselheiros**, mandato **4 anos não renovável** + sabatina Senado |
| **Superintendência-Geral (SG)** | Instrução + julgamento de atos de concentração não complexos + instauração de processos administrativos |
| **DEE** | Departamento de Estudos Econômicos |
| **ProCADE** | Procuradoria Federal Especializada |

## Competências

| | Conteúdo |
|---|---|
| **(a)** | **REPRESSÃO** a infrações à ordem econômica (controle *a posteriori*) |
| **(b)** | Análise de **ATOS DE CONCENTRAÇÃO** (controle *a priori*: fusões + aquisições + JVs) |
| **(c)** | **Advocacy** concorrencial |
| **Art. 88 + Portaria Interministerial 994/2012** | Notificação obrigatória se um grupo tem faturamento **≥ R$ 750 mi** + outro **≥ R$ 75 mi** no Brasil (Resolução CADE 33/2022 disciplina a notificação e o rito sumário) |

## ACORDO DE LENIÊNCIA (arts. 86-87)

| | Conteúdo |
|---|---|
| Celebrado com | **SG do CADE** |
| Imunidade | Total ou **redução de 1/3 a 2/3** |
| Requisitos | **Confissão + colaboração efetiva + cessação da conduta** |

### Extensão à esfera criminal
| | Conteúdo |
|---|---|
| **Lei 8.137/90** | Crimes contra a ordem econômica |
| **Crimes licitatórios** | Hoje tipificados no Código Penal (arts. 337-E a 337-P, incluídos pela Lei 14.133/2021; a Lei 8.666/93, que os previa, foi revogada) |
| Efeito | **EXTINÇÃO da PUNIBILIDADE** dos crimes contra ordem econômica/licitações conexos |

## Lei 14.470/2022: enforcement privado

| | Conteúdo |
|---|---|
| **DOUBLE DAMAGES** | **Indenização em DOBRO** para vítimas de **CARTEL** (exceto contra signatários de Leniência/TCC) |
| Prescrição | **5 anos** do **trânsito em julgado ADMINISTRATIVO** |
| Decisão do Tribunal CADE | **Prova PRÉ-CONSTITUÍDA** para tutela de evidência |

## Jurisdição concorrente

| | Conteúdo |
|---|---|
| CADE | **Competência GERAL** |
| Atividades reguladas | Anatel (telecom) + ANS (saúde) + ANP (petróleo) + Aneel (energia), com atuação coordenada via convênios |
| **Prevalência** | CADE **sobre estruturas anticompetitivas** |
| Base | Jurisprudência do STJ sobre complementaridade entre regulação setorial e defesa da concorrência |

## Controle judicial

| | Conteúdo |
|---|---|
| Decisões do CADE | **Presunção de legitimidade** |
| Controle | **Restrito à LEGALIDADE**, não ao mérito técnico-econômico |

## TCC (Termo de Cessação de Conduta)

| | Conteúdo |
|---|---|
| Negociação | Com o CADE |
| Compromisso | Cessar conduta + pagar contribuição pecuniária |
| Caráter | Acordo administrativo |

## Distinções essenciais

| | CADE | Procon |
|---|---|---|
| Foco | **Concorrência** (mercado) | **Consumidor** (individual) |
| Bem jurídico | Ordem econômica | Vulnerável |

| | Cartel | Posição dominante |
|---|---|---|
| Conduta | Acordo anticompetitivo | Abuso unilateral |
| Sujeitos | Vários | Um (com poder de mercado) |

| | Atos de concentração | Condutas |
|---|---|---|
| Controle | **A priori** | **A posteriori** |
| Notificação | Obrigatória se faturamentos | Não há |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Fusão de grandes empresas | **Notificação ao CADE** (R$ 750mi + R$ 75mi) |
| Cartel | **Multa + leniência possível** |
| Posição dominante abusiva | **Sanção** + multa 0,1-20% |
| Leniência | Imunidade ou redução + extensão penal |
| Vítima de cartel | **Double damages** (Lei 14.470) |
| Reguladora vs CADE | **CADE prevalece** em concorrência |
| Decisão do CADE | **Controle só LEGALIDADE** |
| Crime contra ordem econômica + leniência | **Extingue punibilidade** |

## Erros a evitar

- **Aplicar controle JUDICIAL ao MÉRITO técnico-econômico** do CADE (só legalidade);
- **Cobrar dano simples** em cartel (Lei 14.470: double damages, exceto leniência);
- Negar **legitimidade do CADE** em setores regulados (prevalência);
- Aplicar **prescrição antes do trânsito ADMINISTRATIVO** (Lei 14.470);
- **Confundir cartel com posição dominante** (modalidades distintas);
- Permitir **fusão sem notificação** quando faturamentos atingem patamares;
- Aplicar **multa fora do parâmetro** 0,1-20% (art. 37);
- Negar **extensão criminal da leniência** (Lei 8.137 + licitações);
- Aplicar **CDC** em vez de Lei 12.529 a estrutura anticompetitiva;
- Tratar **TCC como prova de culpa criminal** (acordo administrativo);
- Aplicar **mandato renovável** aos conselheiros (é não renovável).

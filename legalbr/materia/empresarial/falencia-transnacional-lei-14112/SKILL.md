# Falência + Recuperação Transnacional

## Marco legal

- **Lei 11.101/2005** (LRF): arts. 167-A a 167-Y (incluídos pela Lei 14.112/2020);
- **Lei 14.112/2020** (Reforma da LRF);
- **UNCITRAL Model Law on Cross-Border Insolvency** (1997);
- **CPC** + **CTN** + **CC** (aplicação subsidiária);
- **LINDB art. 17** (ordem pública);
- **CF 105 I i** (homologação STJ: não se aplica diretamente);
- **DRCI/MJ** (cooperação).

## UNCITRAL Model Law

| | Conteúdo |
|---|---|
| **Adotada** | 1997 |
| **Países que aderiram** | 50+ |
| **Brasil** | Adotou em 2020 (Lei 14.112) |
| **Quatro pilares** | Acesso + reconhecimento + cooperação + medidas de apoio |
| **Não é tratado** | Modelo legislativo |

## Quatro pilares (Capítulo VI-A da LRF)

| Pilar | Conteúdo |
|---|---|
| **Acesso** | Representante estrangeiro tem legitimidade direta |
| **Reconhecimento** | Processo estrangeiro reconhecido em juízo |
| **Cooperação** | Comunicação direta entre juízes |
| **Medidas de apoio** | Tutela urgência + suspensão |

## Conceitos centrais

### Processo principal estrangeiro

| | Conteúdo |
|---|---|
| **COMI** (Centre of Main Interests) | Onde os interesses principais do devedor estão centralizados |
| **Presunção** | Domicílio (empresário individual) ou sede estatutária (sociedade) é o COMI, salvo prova em contrário (LRF 167-I III) |
| **Reconhecimento** | Como **principal** |
| **Efeitos** | Mais amplos |

### Processo estrangeiro não-principal

| | Conteúdo |
|---|---|
| **Estabelecimento** | Operação ou ativos em outro Estado |
| **Reconhecimento** | Como **não principal** |
| **Efeitos limitados** | Aos ativos locais |

### Representante estrangeiro

| | Conteúdo |
|---|---|
| **Definição** | Pessoa/órgão autorizado em processo estrangeiro |
| **Trustee + administrador + receiver** | Equivalentes |
| **Legitimidade ativa** | No Brasil, sem necessidade de homologação prévia |
| **Pode** | Requerer reconhecimento + medidas de apoio |

## Procedimento de reconhecimento (LRF 167-D)

### Competência

| | Conteúdo |
|---|---|
| **Juiz** do **principal estabelecimento** do devedor no Brasil |
| **Vara Empresarial** (em alguns Estados especializada) |
| **Não é STJ** | Diferente da homologação de sentenças |

### Pedido (LRF 167-H a 167-J)

| Etapa | Conteúdo |
|---|---|
| 1. **Petição** | Pelo representante estrangeiro (167-H) |
| 2. **Documentos** | Cópia apostilada da decisão de abertura + nomeação do representante (167-H §1) |
| 3. **Tradução** | Necessária para documentos em língua estrangeira |
| 4. **Apostila** | Conv. Haia 1961 |
| 5. **Requisitos do reconhecimento** | LRF 167-J (ressalvada a ordem pública, 167-A §4) |
| 6. **Reconhecimento como principal ou não** | Crucial |

## Efeitos do reconhecimento (LRF 167-M e 167-N)

### Como processo principal (167-M: efeitos automáticos)

| | Conteúdo |
|---|---|
| **Suspensão** | Execuções individuais |
| **Vedação a iniciar novas ações** | Salvo autorização |
| **Suspensão de outros processos** | Em curso no Brasil |
| **Stay** | Automático |

### Como processo não-principal

| | Conteúdo |
|---|---|

| **Efeitos limitados** | A ativos locais |
| **Discricionários** | Juiz analisa caso a caso |

## Erros a evitar

- O reconhecimento do processo estrangeiro de insolvência não passa pela **homologação no STJ** (Lei 14.112);
- O **COMI** (centro de interesses principais) é critério crítico;
- O processo **principal** e o **não principal** têm efeitos próprios;
- As **regras antigas** (pré-Lei 14.112) não se aplicam;
- A cláusula de **ordem pública** condiciona o reconhecimento (LRF 167-A §4);
- Os documentos exigem tradução e apostilamento (Conv. Haia 1961);
- A **insolvência transnacional** não se confunde com a **execução de sentença estrangeira** comum;
- O **CTN** e a ordem de pagamento brasileira são observados;
- O regime não alcança **estatais** ou **bancos** (regimes próprios);
- A comunicação direta com o juiz estrangeiro é permitida (LRF 167-P e 167-Q);
- O Regulamento **EU 2015/848** não se aplica literalmente: o Brasil tem regime próprio.

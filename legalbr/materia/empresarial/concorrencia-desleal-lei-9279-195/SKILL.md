# Concorrência Desleal

## Marco legal

- **Lei 9.279/1996** (LPI, Propriedade Industrial): arts. **195** (crime) + **209** (indenização);
- **CDC art. 36-37** (publicidade enganosa);
- **Lei 12.529/2011** (Antitruste, CADE);
- **CC 188 + 927** (responsabilidade civil);
- **CF 170 IV** (livre concorrência);
- **CP 138-140** (calúnia, difamação, injúria: interface);
- **Convenção de Paris** (1883): proteção internacional.

## Conceito

| | Conteúdo |
|---|---|
| **Definição** | Atos fraudulentos ou desleais que desviam clientela ou prejudicam concorrente |
| **Diferença de** antitruste (CADE) | Antitruste é coletivo; concorrência desleal é entre concorrentes |
| **Sujeitos** | Empresários + sociedades empresárias |
| **Bem jurídico** | Livre concorrência + boa-fé |
| **Aplicação** | Direito empresarial + civil + penal |

## Crimes (Lei 9.279 art. 195)

14 incisos, todos punidos com **detenção de 3 meses a 1 ano, ou multa**.

### Principais condutas

| Inciso | Conteúdo |
|---|---|
| **I** | Publicar **falsa afirmação** em detrimento de concorrente, para obter vantagem |
| **II** | **Prestar ou divulgar falsa informação** sobre concorrente, para obter vantagem |
| **III** | **Empregar meio fraudulento** para desviar clientela de outrem |
| **IV** | **Usar ou imitar expressão ou sinal de propaganda** alheios, criando confusão |
| **V** | **Usar indevidamente nome comercial, título de estabelecimento ou insígnia** alheios (ou vender/expor produto com essas referências) |
| **VI** | **Substituir, em produto de outrem, o nome ou razão social deste** pelo seu próprio, sem consentimento |
| **VII** | **Atribuir-se distinção/recompensa** não recebida, como meio de propaganda |
| **VIII** | **Vender/expor, em recipiente ou invólucro de outrem, produto adulterado ou falsificado** (ou usá-lo para negociar produto da mesma espécie) |
| **IX** | **Dar/prometer dinheiro/utilidade** a empregado de concorrente para que falte ao dever |
| **X** | **Receber dinheiro/utilidade como empregado** para proporcionar vantagem a concorrente do empregador |
| **XI** | **Divulgar/explorar, sem autorização, conhecimentos, informações ou dados confidenciais** obtidos por relação contratual ou de emprego (mesmo após o término) |
| **XII** | **Divulgar/explorar os mesmos dados confidenciais obtidos por meio ilícito ou fraude** |
| **XIII** | **Vender/anunciar produto declarando falsamente ser objeto de patente** (depositada/concedida) **ou de desenho industrial registrado** |
| **XIV** | **Divulgar/explorar, sem autorização, resultados de testes e dados não divulgados** apresentados a entidades governamentais para aprovação de comercialização |

## Conceitos centrais

### Desvio de clientela

| | Conteúdo |
|---|---|
| **Conduta fraudulenta** | Meio para atrair cliente |
| **STJ** | Aplica princípio amplo |
| **Provas robustas** | Necessárias |
| **Indenização** | Sem prova de prejuízo |

### Trade dress (conjunto-imagem)

| | Conteúdo |
|---|---|
| **Definição** | Conjunto visual + cromático + design do produto/serviço |
| **Proteção** | Lei 9.279 art. 195 III + 209 (analogia ao art. 124) |
| **Sem registro INPI específico** | Mas protegido |
| **STJ** | Confusão depende de prova pericial; requisitos: ausência de funcionalidade + distintividade + anterioridade de uso + risco de confusão (jurisprudência do STJ) |
| **Casos** | Garrafas + embalagens + decoração de lojas |

### Imitação parasitária

| | Conteúdo |
|---|---|
| **Conduta** | Aproveitar-se do prestígio alheio |
| **Caracteriza concorrência desleal** | Mesmo sem confusão completa |
| **Marca + trade dress + slogan** | Combinação imitada |
| **STJ** | Reconhece como ilícito |

### Keyword advertising (links patrocinados)

| | Conteúdo |
|---|---|
| **Conduta** | Compra, em serviço de anúncios de provedor de busca, de palavra-chave correspondente a marca registrada ou nome empresarial de concorrente, para obter posição privilegiada no resultado e desviar clientela para o próprio site |
| **Qualificação** | Concorrência desleal (LPI art. 195 III e V, c/c art. 10 bis da Convenção da União de Paris), quando titular e anunciante atuam no mesmo ramo e o uso é apto a desviar clientela e a violar as funções identificadora e de investimento do sinal (aproveitamento parasitário) |
| **STJ** | Entendimento das duas Turmas de direito privado (STJ, 4ª Turma, REsp 1.937.989/SP, rel. Min. Luis Felipe Salomão, j. 23/08/2022; STJ, 3ª Turma, REsp 2.032.932/SP, rel. Min. Ricardo Villas Bôas Cueva, j. 08/08/2023, DJe 24/08/2023) |

## Indenização (Lei 9.279 art. 209)

| | Conteúdo |
|---|---|
| **Dispensa prova de dano efetivo** | Presumido pela conduta |
| **Critérios** | Vantagens auferidas + lucros cessantes |
| **Aplicação ampla** | Não restrita aos 14 incisos do art. 195 |
| **Outras condutas desleais** | Cabem |
| **STJ + TJs** | Aplicam |

### Lei 9.279 art. 210 (apuração da indenização)

| | Conteúdo |
|---|---|
| **I** | Benefício obtido pelo autor da violação |
| **II** | Benefício que o titular teria obtido |
| **III** | Remuneração que o autor teria pago em licença |
| **Critério mais favorável** | Ao prejudicado |

## Erros a evitar

- Tratar a ação penal como **pública**: crimes do art. 195 são de **ação penal privada** (queixa), salvo art. 191 (LPI 199); prazo decadencial de 6 meses;
- Aplicar Lei 9.279 art. 195 sem **conduta fraudulenta** específica;
- Exigir **prova de dano** efetivo (art. 209 dispensa);
- Confundir com **violação marcária** (regimes próprios);
- Não pleitear **cessação** + indenização cumulativamente;
- Aplicar **CDC** sozinho quando há concorrência desleal (cumular);
- Esquecer **trade dress** como protegido (sem registro INPI específico);
- Aplicar **CADE** em conduta entre concorrentes (em geral, é Lei 9.279);
- Não buscar **cautelar** quando há risco de dano contínuo;
- Esquecer **Convenção de Paris** + proteção internacional;
- Aplicar regime sem ver **alta jurisprudência** do STJ;
- Tratar **imitação parasitária** como ilícito não-tipificado (Lei 9.279 protege).

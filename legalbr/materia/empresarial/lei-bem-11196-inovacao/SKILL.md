# Lei do Bem

## Lei 11.196/2005: Capítulo III (arts. 17-26)

| | Conteúdo |
|---|---|
| Função | Principal instrumento federal de fomento à **PD&I** |
| Conceito | **Pesquisa, Desenvolvimento e Inovação** |
| Base regulamentar | **Decreto 5.798/2006**: pesquisa básica + aplicada + desenvolvimento experimental |

## Requisitos para fruição

| | Conteúdo |
|---|---|
| **Tributação** | **EXCLUSIVAMENTE pelo LUCRO REAL** |
| Excluídos | **Lucro Presumido + SIMPLES** |
| Regularidade fiscal | **CND** |
| **Lucro FISCAL** | Demonstração no exercício |
| PD&I | Conforme conceitos do Dec. 5.798/2006 |

## BENEFÍCIOS FISCAIS (AUTOMÁTICOS)

### Exclusão adicional para IRPJ/CSLL
| Patamar | Hipótese |
|---|---|
| **60%** (padrão) | Sem aumento de pesquisadores |
| **70%** | Aumento de **até 5%** de pesquisadores |
| **80%** | Aumento de **MAIS de 5%** de pesquisadores |

### Adicionais
| | Conteúdo |
|---|---|
| **+ 20%** | Projetos com **PATENTE CONCEDIDA** ou cultivar registrada (Lei 11.196, art. 19, §3º) |
| **Exclusão 50%-250%** | Projetos executados por **ICT** (Instituição Científica, Tecnológica e de Inovação): exclusão de 50% a 250% dos dispêndios, mediante aprovação prévia (Lei 11.196, art. 19-A) |

### Outros benefícios
| | Conteúdo |
|---|---|
| **REDUÇÃO de 50% do IPI** | Equipamentos destinados a PD&I |
| **Depreciação/amortização ACELERADA INTEGRAL** | Bens para PD&I |
| **ISENÇÃO de IRRF** | Remessas ao exterior para registro de marcas/patentes |

## Marco Legal de CT&I

| | Conteúdo |
|---|---|
| **EC 85/2015** | Constitucionalizou CT&I (CF 218-219) |
| **Lei 13.243/2016** | Marco Legal de CT&I: alterou a **Lei 10.973/2004** (Lei de Inovação) |
| Articulação | Lei 9.279/1996 (PI) + Lei 9.609/1998 (Software) |

## Gestão + reporte

| | Conteúdo |
|---|---|
| **MCTI** | Ministério da Ciência, Tecnologia e Inovações |
| **FORMP&D** | Reporte ANUAL |

## Atualizações 2025-2026

| | Conteúdo |
|---|---|
| **Portaria MCTI 9.563/2025** (DOU 04/11/2025) | Novas normas de prestação de informações: FORMP&D eletrônico com prazo até **31 de agosto** do ano seguinte à fruição; análise por no mínimo 2 avaliadores; comunicação 100% eletrônica; compartilhamento dos resultados com a Receita Federal (revogou a Portaria MCTI 6.536/2022) |
| **MP 1.227/2024** | Incluiu Lei do Bem entre benefícios fiscais declarados na **DIRBI** (Declaração de Incentivos, Renúncias, Benefícios e Imunidades) |
| Adesão | Milhares de empresas beneficiárias por ano (3.878 em 2023, renúncia de ~R$ 9,8 bi, dados MCTI) |

## Jurisprudência STJ

| | Conteúdo |
|---|---|
| **STJ 1ª e 2ª Turmas** | **ILEGAL revogação ANTECIPADA** dos benefícios antes do prazo final (proteção da **boa-fé objetiva + segurança jurídica**) |
| **STJ 2ª Turma** | Admite **inclusão da PLR** paga a empregados dedicados à PD&I na base dos incentivos |

## Distinções essenciais

| | Lei do Bem | Lei de Inovação |
|---|---|---|
| Foco | **Incentivos fiscais** | Estímulos institucionais |
| Base | **Lei 11.196** | **Lei 10.973** |
| Conjugação | Cumulativa |

| | Lucro Real | Presumido/Simples |
|---|---|---|
| Lei do Bem | **CABÍVEL** | **VEDADO** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Empresa Lucro Real + PD&I | **Lei do Bem aplicável** |
| Empresa Lucro Presumido | **NÃO** |
| Aumento de pesquisadores > 5% | **80% exclusão** |
| Patente concedida | **+ 20%** |
| Projeto executado por ICT | **exclusão 50%-250%** (art. 19-A, com aprovação prévia) |
| IPI em equipamento PD&I | **-50%** |
| Reporte | **FORMP&D anual** (MCTI) |
| Revogação antecipada | **ILEGAL** (STJ) |
| Reporte na DIRBI | **MP 1.227/2024** |
| Sem lucro fiscal | **NÃO se aproveita** no ano |

## Erros a evitar

- **Aplicar Lei do Bem a Lucro Presumido/Simples** (só Lucro Real);
- **Concessão de benefício sem regularidade fiscal** (CND);
- Aplicar **exclusão sem comprovação de PD&I** (Dec. 5.798);
- **Cumular 80% sem aumento > 5% de pesquisadores** (parâmetro);
- Admitir **revogação antecipada** dos incentivos (STJ ilegal);
- Não respeitar **reporte FORMP&D**;
- Confundir **Lei do Bem com Lei de Inovação** (incentivos × institucionalização);
- Aplicar a **sem lucro fiscal** no exercício (sem aproveitamento);
- Afastar **inclusão de PLR de pesquisadores** (STJ 2ª T. admite);
- Não declarar **DIRBI** (MP 1.227);

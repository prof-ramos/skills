# Propriedade Intelectual + Tratados

## Bases legais

- **CF 5 XXVII XXVIII XXIX**;
- **Lei 9.279/1996** (LPI, propriedade industrial);
- **Lei 9.610/1998** (direito autoral);
- **Lei 9.609/1998** (software);
- **CUP** 1883; **TRIPS** (Dec. 1.355/1994);
- **PCT** (Dec. 81.742/1978);
- **Protocolo de Madri** (Dec. 10.033/2019);
- **Convenção de Berna** (Dec. 75.699/1975).

## Dualidade

| Eixo | Propriedade Industrial | Direito Autoral |
|---|---|---|
| Lei | **9.279/1996** | **9.610/1998** + **9.609/1998** |
| Objeto | Marcas, patentes, DI, IG | Obras literárias/artísticas; software |
| Órgão | **INPI** | Entidades coletivas / **ECAD** |
| Aquisição | Constitutiva (registro) | Declaratória (criação) |

## Patentes (LPI 8-93)

| Tipo | Prazo |
|---|---|
| **PI** (Invenção) | **20 anos** do depósito |
| **MU** (Modelo de utilidade) | **15 anos** do depósito |

### Requisitos
**Novidade + atividade inventiva + aplicação industrial** (8 + 13).

### Não patenteáveis (10 + 18)
Descobertas, teorias, métodos matemáticos, **software em si**, métodos cirúrgicos/terapêuticos, seres vivos naturais (exceto **microrganismos transgênicos**).

### STF ADI 5.529 (06/05/2021)

- **Inconstitucional** art. 40 par. único LPI (extensão);
- **Modulação**: **ex nunc** em geral; **ex tunc** para **fármacos, medicamentos, equipamentos de saúde**.

## Marcas (LPI 122-175)

| | Conteúdo |
|---|---|
| Conceito | Sinais distintivos **visualmente perceptíveis** |
| Vigência | **10 anos** + prorrogações **indefinidas** |
| Sistema | Atributivo (registro constitui) |
| **Notoriamente conhecida** (126) | Proteção mesmo sem registro |
| **Alto renome** (125) | Proteção em **todas as classes** |

### Protocolo de Madri (Dec. 10.033/2019)
- Registro internacional via **INPI → OMPI**;
- Designação múltipla;
- Exame médio **~12 meses** (2025);
- Independência após **5 anos**.

## Indicações Geográficas (176-182)

| | Conteúdo |
|---|---|
| **IP** | Centro de produção (Cachaça) |
| **DO** | Qualidades pelo meio (Vale dos Vinhedos) |

## Desenho Industrial (94-121)

- Forma plástica ornamental;
- **10 + 3 × 5 = 25 anos** (108);
- Exame formal.

## Direito Autoral (Lei 9.610/98)

### Direitos morais (24)
Paternidade, nominação, integridade, ineditismo. **Inalienáveis, irrenunciáveis, imprescritíveis, impenhoráveis**.

### Direitos patrimoniais (28-45)
- **Duração: 70 anos** a partir de 1º jan do ano seguinte ao **falecimento do autor**;
- Audiovisual/fotográficas: 70 anos do ano seguinte à divulgação;
- Após o prazo: **domínio público**;
- Cessão/licença: **escrito** + interpretação restritiva.

### Limitações (46)
Uso privado; citação; cópia de pequeno trecho; braile.

## Software (Lei 9.609/98)

- Regime de **direito autoral**;
- **50 anos** (a partir do ano seguinte ao lançamento);
- Registro INPI **facultativo**;
- Engenharia reversa para **interoperabilidade** (art. 6).

## Tratados internacionais

| | Conteúdo |
|---|---|
| **CUP** (1883) | Tratamento nacional + prioridade (12m patentes, 6m marcas/DI) |
| **TRIPS** (1994) | Padrões mínimos; 20 anos patentes |
| **PCT** | Depósito internacional unificado de patentes |
| **Protocolo de Madri** (2019) | Registro internacional de marcas |
| **Convenção de Berna** (1886) | Proteção autoral automática |

## Estado 2024-2026

- Pós-**ADI 5.529**: litígios sobre patentes farmacêuticas;
- **IA generativa e direito autoral** em debate;
- **PL 2.370/2019** atualiza Lei 9.610;
- CADE: pay-for-delay + sham litigation;
- INPI: Patentes Verdes; marca de posição registrável (Res. 232/2022); NFTs com diretrizes 2024.

## Quadro de prazos

| Direito | Prazo |
|---|---|
| **PI** | 20 anos do depósito |
| **MU** | 15 anos do depósito |
| **Marca** | 10 anos prorrogáveis indefinidamente |
| **DI** | 10 + 3×5 = 25 anos |
| **Direito autoral** (patrimonial) | **70 anos** pós-morte |
| **Software** | **50 anos** pós-lançamento |
| Conexos | 70 anos |

## Erros a evitar

- Pleitear extensão de patente (ADI 5.529: inconstitucional);
- Tratar software como **patenteável** (é direito autoral);
- Aplicar marca **sem registro** sem invocar notoriedade ou CUP 6 bis;
- Esquecer **alto renome** (proteção em todas as classes);
- Confundir IP (centro) com DO (qualidades pelo meio);
- Aplicar prazo de **25 anos** para marca (é 10 + indefinida; **25 é DI**);
- Considerar IA como **autora** (Lei 9.610 art. 11);
- Esquecer **interoperabilidade** em engenharia reversa de software (9.609 art. 6);
- Aplicar **direito de prioridade** errado (12m patentes, **6m marcas/DI**);
- Esquecer **moralidade** dos direitos autorais (inalienáveis).

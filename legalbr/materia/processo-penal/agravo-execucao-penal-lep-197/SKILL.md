# Agravo em Execução Penal

## Base + finalidade

| | Conteúdo |
|---|---|
| **LEP 197** | Único recurso cabível contra **todas** as decisões do juízo da execução penal |
| Função | Impugnar decisões: progressão, regressão, livramento condicional, indulto, sursis, remição, faltas disciplinares, etc. |
| Princípio | Unidade recursal, não cabe outro tipo (apelação, embargos, RESE, não) |

## Rito processual

| | Conteúdo |
|---|---|
| **Súm. 700 STF** | "É de cinco dias o prazo para interposição de agravo contra decisão do juízo da execução penal" |
| Rito | **Recurso em sentido estrito** (CPP 587-592), analogia |
| **Prazo** | **5 dias** (Súm. 700 + LEP omissa) |
| Razões | **2 dias** após interposição (no rito RESE) |
| Contrarrazões | 2 dias |
| Juízo de retratação | **Sim** (CPP 589, recebe ou retrata) |
| Efeito suspensivo | **NÃO** (em regra) |
| Efeito devolutivo | Sim, tribunal reaprecia |
| Competência | **TJ** (estadual) ou **TRF** (federal) |

## Decisões agraváveis

| Decisão | Cabe agravo? |
|---|---|
| Progressão/regressão de regime | **Sim** |
| Concessão/denegação livramento condicional | Sim |
| Remição da pena | Sim |
| Conversão de pena restritiva em privativa | Sim |
| Reconhecimento de falta grave (disciplinar) | Sim |
| Indulto + comutação (decisão de mérito) | Sim |
| Suspensão de pena (sursis) | Sim |
| Detração | Sim |
| Extinção da punibilidade | Sim |
| Saída temporária | Sim |
| Trabalho externo | Sim |
| Decisões de mero expediente | **NÃO** |
| Decisões irrecorríveis (LEP 197 fine) | Não |

## Efeito suspensivo

| Regra | Conteúdo |
|---|---|
| LEP omissa, RESE silente | **Sem** efeito suspensivo automático |
| **STJ** | Pode ser pleiteado via **mandado de segurança** ou **HC** se a decisão impuser/aliviar restrição grave |
| Decisão que **regride** regime | Imediatamente executável (apenado vai para regime mais gravoso) |
| Decisão que **liberta** | Imediatamente executável (apenado sai) |
| Recurso do MP contra libertação | Pode ser objeto de pedido de efeito suspensivo |

## Legitimidade

| Quem | Conteúdo |
|---|---|
| **MP** | Sim (LEP 67) |
| **Condenado** + defensor | Sim |
| **Defensoria Pública** | Sim |
| **Conselho da Comunidade** (LEP 80) | Sim (legitimidade subsidiária) |
| **Assistente** | Sim (em casos específicos) |
| Cônjuge/parentes | Por advogado |

## Procedimento detalhado

| Passo | Conteúdo |
|---|---|
| 1 | Decisão do juízo da execução |
| 2 | Interposição em **5 dias** (Súm. 700) |
| 3 | Razões em **2 dias** (rito RESE) |
| 4 | Contrarrazões da parte adversa em 2 dias |
| 5 | Juiz pode **retratar** OU manter decisão |
| 6 | Manutenção: remessa ao TJ/TRF |
| 7 | Acórdão do tribunal |
| 8 | Eventual recurso (REsp, RE), restritos |

## Súmulas + jurisprudência consolidada

| Súm. | Conteúdo |
|---|---|
| **Súm. 700 STF** | Prazo 5 dias |
| **Súm. 533 STJ** | Falta grave exige **PAD** (procedimento administrativo disciplinar) com contraditório, sem PAD = nula |
| **Súm. 534 STJ** | Falta grave **interrompe** prazo para progressão |
| **Súm. 535 STJ** | Falta grave **não interrompe** prazos de livramento condicional, indulto, comutação |
| **Súm. 715 STF** | Pena unificada para atender ao limite do CP 75 (30 anos à época; **40 anos** desde a Lei 13.964/2019) **não** é a considerada para a concessão de benefícios |
| **Súm. 716 STF** | Admite-se progressão de regime + outras benefícios mesmo antes do trânsito em julgado da condenação |
| **Súm. 717 STF** | Cumprimento provisório da pena (apelação solta) também enseja progressão |

## Falta grave (LEP 50-51)

| Hipótese | Conteúdo |
|---|---|
| **I-V (LEP 50)** | Inobservância das normas |
| **VI** | Tentativa ou consumação de **fuga** |
| **VII** | Cometimento de **crime doloso** |
| **VIII** | Posse de **aparelho celular** (Lei 11.466/2007) |
| **Inscrição** em organização criminosa | Acrescentado pela Lei 13.964 |

### Consequências da falta grave

| Efeito | Base |
|---|---|
| Interrompe prazo para **progressão** | Súm. 534 STJ |
| Regressão de regime | LEP 118 I |
| Suspensão/cancelamento de saída temporária | LEP 125 |
| Suspensão de visitas | LEP 41 |
| **Perda de até 1/3** dos dias remidos | LEP 127 (red. Lei 12.433/2011); SV 9 STF **cancelada em 25/09/2025**, Tema 477 RG: perda limitada a 1/3, a critério motivado do juiz |
| Não interrompe | Livramento + indulto + comutação (Súm. 535) |

## Progressão de regime, Lei 13.964/2019 (fatos até 24/03/2026)

| Crime | Percentual |
|---|---|
| **16%** | Primário, crime sem violência/grave ameaça |
| **20%** | Reincidente, crime sem violência/grave ameaça |
| **25%** | Primário, com violência/grave ameaça |
| **30%** | Reincidente, com violência/grave ameaça |
| **40%** | Primário em hediondo SEM morte |
| **50%** | Primário em hediondo COM morte |
| **60%** | Reincidente específico em hediondo SEM morte |
| **70%** | Reincidente específico em hediondo COM morte |

> **ATENÇÃO (alteração 2026).** Para **fatos a partir de 25/03/2026**, a **Lei 15.358/2026** (Antifacção) elevou os percentuais dos hediondos para **70% / 75% / 80% / 85%**. A **Lei 15.402/2026** (Dosimetria, de 08/05/2026) alterou dosimetria/execução (LEP 126 §9 + CP 359-M-A/359-M-B) e está **promulgada e vigente**: não há cautelar do Plenário nas ADIs 7.966/7.967, apenas decisão monocrática (09/05/2026) que suspendeu sua aplicação **somente nas execuções penais dos atos de 8 de janeiro em curso no STF**, até o julgamento das ADIs. Os novos percentuais **não retroagem** (CF 5 XL): para fatos anteriores aplica-se a tabela acima. Conferir a data do fato e o texto/vigência atual da LEP.

## Outras decisões executórias relevantes

| Instituto | Base |
|---|---|
| **Remição** (LEP 126) | 1 dia por 12h de estudo OU 1 dia por 3 dias de trabalho |
| **Saída temporária** (LEP 122-125) | Regime semiaberto, para visitar família, estudar |
| **Trabalho externo** (LEP 36) | Após 1/6 da pena cumprida |
| **Livramento condicional** (CP 83) | 1/3 (primário) / 1/2 (reincidente) / 2/3 (hediondo) |
| **Indulto + comutação** | Decreto presidencial anual |

## Erros a evitar

- Aceitar outro recurso (apelação, RESE) em vez de **agravo em execução**;
- Aplicar prazo de **10 dias**: é **5 dias** (Súm. 700);
- Conceder **efeito suspensivo** automático (regra é sem);
- Reconhecer falta grave **sem PAD** (Súm. 533 STJ, nulidade);
- Interromper prazo de **livramento** após falta grave (Súm. 535, não interrompe);
- Não interromper prazo de **progressão** (Súm. 534, sim, interrompe);
- Aplicar percentuais antigos (1/6) em hediondos: a Lei 13.964/2019 fixou 40-70% e, para fatos a partir de 25/03/2026, a Lei 15.358/2026 elevou para 70-85%;
- Negar **agravo** ao **conselho da comunidade** (LEP 80);
- Confundir decisão de mero expediente (não agraválel) com decisão de mérito;
- Não admitir agravo em decisão sobre **detração** ou **remição** (admite).

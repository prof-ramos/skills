# Investigação Criminal pelo Ministério Público (PIC)

## CF 129: competências constitucionais do MP

| Inc. | Conteúdo |
|---|---|
| **I** | Promover **PRIVATIVAMENTE** a ação penal pública |
| **II** | Zelar pelo respeito a CF + interesse público + serviços de relevância pública |
| **VI** | **EXPEDIR notificações** + requisitar informações + documentos |
| **VII** | **Controle externo** da atividade policial (CPP 14 e ss.) |
| **VIII** | **Requisitar diligências investigatórias** + **instauração de IP** |
| **IX** | Exercer **OUTRAS funções** compatíveis (atribuição residual) |
| **LC 75/1993** | LOMPU, disciplina o MP da União |
| **Lei 8.625/1993** | LONMP, disciplina os MPs estaduais |

## STF Tema 184 (RE 593.727, 14/05/2015, Pleno)

| | Conteúdo |
|---|---|
| Tese | "O **MP dispõe de competência** para promover, por autoridade própria + dentro de prazos razoáveis, **investigações de natureza penal**, **desde que** respeitados os **direitos e garantias** + as **hipóteses de reserva constitucional** + observada a **cláusula de reserva de jurisdição**" |
| Maioria | 7×4 (Plenário) |
| Marco | Constitucionalidade do **poder investigatório DIRETO do MP** |
| Limites | Não substitui IP + sujeição ao **controle JUDICIAL** + **paridade de armas** + transparência + reserva de jurisdição |

## Resolução CNMP 181/2017 (alterada por 183/2018)

| | Conteúdo |
|---|---|
| Núcleo | Disciplina o **PIC, Procedimento Investigatório Criminal** |
| **Art. 1** | PIC: instrumento de apuração de **infração penal**; as expressões "sumário" e "desburocratizado" foram declaradas **INCONSTITUCIONAIS**: a Constituição não autoriza investigação de natureza abreviada, flexível ou excepcional, e o PIC se submete aos **mesmos limites legais do inquérito policial** (STF, Plenário, ADI 5.793/DF, Rel. Min. Cristiano Zanin, j. 28/06/2024) |
| **Art. 2 V** | Interpretação conforme: o MP **NÃO pode presidir inquérito policial**, atribuição privativa da autoridade policial (STF, Plenário, ADI 5.793/DF, j. 28/06/2024) |
| **Art. 3** | Instaurado por **portaria** + autuação + numeração + comunicação ao núcleo |
| **Art. 4** | **Comunicação ao Conselho Superior** + sigilo quando necessário |
| **Art. 6** | Prazo: **mesmos prazos e regramentos** previstos para conclusão dos inquéritos policiais; prorrogações exigem **AUTORIZAÇÃO JUDICIAL**, vedadas renovações desproporcionais ou imotivadas (STF, Plenário, ADIs 2.943/DF, 3.309/DF e 3.318/MG, Rel. Min. Edson Fachin, j. 02/05/2024) |
| **Art. 13** | Procedimento + diligências + provas + perícias |
| **Art. 15** | Conclusão: **denúncia + arquivamento + remessa** |
| **Lei 13.964/2019** | Anticrime + arquivamento pelo MP (art. 28 alterado) |

### Parâmetros vinculantes do STF (ADIs de 2024)

| | Conteúdo |
|---|---|
| Comunicação ao juiz | Instauração e encerramento do PIC comunicados **IMEDIATAMENTE** ao juiz competente, com **registro e distribuição** |
| Prazos | Observância dos **mesmos prazos e regramentos** dos inquéritos policiais; prorrogação só com **AUTORIZAÇÃO JUDICIAL**, vedadas renovações desproporcionais ou imotivadas |
| Distribuição por dependência | Ao juízo que primeiro conhecer de PIC ou IP sobre o mesmo fato |
| CPP 18 | Aplicável ao PIC (desarquivamento diante de notícia de novas provas) |
| Motivação obrigatória | Da instauração (ou da não instauração mediante representação) quando houver suspeita de envolvimento de **agentes de segurança pública** ou morte/ferimento grave por arma de fogo desses agentes |
| Modulação (ADI 5.793) | Registro dos PICs em curso sem denúncia no prazo de **60 dias** da ata de julgamento |

(STF, Plenário, ADIs 2.943/DF, 3.309/DF e 3.318/MG, Rel. Min. Edson Fachin, j. 02/05/2024; ADI 5.793/DF, Rel. Min. Cristiano Zanin, j. 28/06/2024)

## Atribuições investigatórias do MP

| | Conteúdo |
|---|---|
| Requisição | Documentos + informações + perícias + dados (CF 129 VI + LOMP) |
| Tomada de **declarações** | Vítimas + testemunhas (NÃO interrogatório formal, segue regra própria) |
| **Inspeções** | Locais públicos + privados sob autorização |
| **Reserva de jurisdição** | **NÃO faz** sem ordem: busca domiciliar + interceptação + quebra de sigilo + prisão |
| **Coletiva** | Pode cooperar com polícia (operações) |
| Diligências | Como reforço/complementaridade ao IP |

## Distinção: IP × PIC × VPI

| | IP (CPP 4) | PIC (CNMP 181) | VPI |
|---|---|---|---|
| Conduzido por | **Autoridade policial** | **MP** | Cartório (preliminar) |
| Base | CPP 4 + Lei 12.830 | CF 129 + Tema 184 + Res. CNMP 181 | Apuração inicial |
| Sigilo | Súm. Vinculante 14 | Idem | Inicial |
| Prazo | 30/90/Lei especial | **Mesmos prazos do IP**; prorrogação só com autorização judicial (STF, ADIs 2.943/3.309/3.318, j. 02/05/2024) | Curto |
| Acesso advogado | SV 14 + Lei 13.245/16 | Idem | Restrito |
| Encerramento | Relatório à Justiça | **Denúncia** ou **arquivamento** | Decisão de instauração |

## Súm. Vinculante 14 STF + Lei 13.245/2016

| | Conteúdo |
|---|---|
| **SV 14** | Direito do **DEFENSOR**, no interesse do representado, de acesso amplo aos **ELEMENTOS de PROVA** já documentados em procedimento investigatório (inclui **PIC**) |
| Lei 13.245/16 | Garante prerrogativa do advogado **EM TODOS** os procedimentos investigatórios, IP + PIC + sindicâncias |
| Diligências em andamento | Pode ser restringido **temporariamente** + decisão fundamentada |
| Acessos | Cópias + reprodução + presença ao ato (CPP 7 XIV, Estatuto da OAB) |

## Limites do PIC

| | Conteúdo |
|---|---|
| **NÃO substitui** | IP, é **CONCORRENTE** e complementar |
| Reserva de jurisdição | **Busca em domicílio + interceptação + quebra de sigilo + prisão**: só por **ORDEM JUDICIAL** |
| Sujeito ativo | Investigado **NÃO é obrigado** a depor (princípio da **NÃO autoincriminação**: CF 5 LXIII) |
| Defesa técnica | **Assegurada** (CF 5 LV) + SV 14 + Lei 13.245 |
| Prazo razoável | CF 5 LXXVIII; **mesmos prazos e regramentos do IP**, prorrogação só com **autorização judicial** (STF, ADIs 2.943/3.309/3.318, j. 02/05/2024) |
| Comunicação ao juiz | Instauração e encerramento comunicados **imediatamente**, com registro e distribuição (STF, ADIs 2.943/3.309/3.318) |
| **Vedação** | Determinar **prisão** ou **medidas de força** (apenas pela polícia + ordem judicial); **presidir inquérito policial** (ADI 5.793) |
| Nulidade | Sem **portaria + autuação + numeração + ciência** = **vício formal** |

## Procedimento prático do PIC

### Instauração
| | Conteúdo |
|---|---|
| **Portaria** | Promotor instaura por portaria fundamentada (motivação obrigatória quando houver suspeita de envolvimento de agentes de segurança pública: STF, ADIs 2.943/3.309/3.318) |
| Comunicação | **Juiz competente** (imediata, com registro e distribuição) + **Conselho Superior** + Núcleo Criminal |
| Numeração | Registro próprio do MP |
| Sigilo | Quando necessário (semelhante a IP) |

### Diligências
| | Conteúdo |
|---|---|
| **Oitiva** de vítimas e testemunhas | Convocação por intimação |
| **Requisição** de documentos | A órgãos públicos + privados (CF 129 VI) |
| **Perícias** | Junto a institutos oficiais |
| **Reserva de jurisdição** | Quando necessária → **representação ao juiz** |

### Conclusão
| | Conteúdo |
|---|---|
| **Denúncia** | Se houver justa causa |
| **Arquivamento** | Promovido pelo MP, **CPP 28 (Anticrime, Lei 13.964/19)** |
| **Remessa** | Outro ramo MP quando atribuição diversa |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Notícia-crime sem IP | **PIC** + diligências direta MP |
| IP arquivado pela polícia | **PIC** complementar do MP |
| Acesso defesa ao PIC | **SV 14** + Lei 13.245, garantido |
| Quebra de sigilo no PIC | **REPRESENTAR** ao juiz (reserva jurisdição) |
| Interceptação no PIC | **Representar** ao juiz (Lei 9.296) |
| Investigado intimado por MP | **NÃO é obrigado a depor** (CF 5 LXIII) |
| MP determina prisão no PIC | **VEDADO** (apenas judicial, flagrante OU representação) |
| Prorrogação de prazo do PIC | **AUTORIZAÇÃO JUDICIAL**, vedadas renovações desproporcionais ou imotivadas (STF, ADIs 2.943/3.309/3.318, j. 02/05/2024) |
| Conclusão = arquivamento | **CPP 28** (Anticrime, MP promove + Conselho Superior revisa) |
| Conclusão = denúncia | **CPP 41** (denúncia + rito ordinário/sumário/sumaríssimo) |
| Vícios formais sem prejuízo | **NULIDADE relativa**: exige demonstração de prejuízo |

## Erros a evitar

- **Aceitar** prisão decretada pelo MP no PIC (vedado, reserva judicial);
- Realizar **busca em domicílio** sem ordem judicial (CF 5 XI + reserva);
- Realizar **interceptação telefônica** sem ordem judicial (Lei 9.296);
- Aplicar **quebra de sigilo bancário/fiscal** sem ordem (LC 105);
- **Negar acesso** da defesa ao PIC (SV 14 + Lei 13.245);
- Forçar o **investigado a depor** (CF 5 LXIII, não autoincriminação);
- Aplicar **CPP 28** sem submissão ao **Conselho Superior** (Anticrime + revisão);
- Substituir **IP** pelo PIC, **concorrência**, não substituição (Tema 184);
- Validar **prorrogação de PIC** autorizada apenas pelo próprio MP: exige **autorização judicial** (STF, Plenário, ADIs 2.943/DF, 3.309/DF e 3.318/MG, j. 02/05/2024);
- Caracterizar o PIC como procedimento "sumário" ou "desburocratizado" (expressões declaradas inconstitucionais) ou admitir que o MP **presida inquérito policial** (STF, Plenário, ADI 5.793/DF, j. 28/06/2024);
- **Desconsiderar duração razoável** (CF 5 LXXVIII);
- Tratar **PIC sem portaria** ou sem numeração como válido (vícios formais);
- Aplicar **competência federal** ao PIC quando atribuição estadual;
- Esquecer **comunicação ao Conselho Superior** (Res. CNMP 181 art. 4);
- Tratar PIC como **procedimento autônomo** desvinculado do processo penal, segue todos os princípios constitucionais.

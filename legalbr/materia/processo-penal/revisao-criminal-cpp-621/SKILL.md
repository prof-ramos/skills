# Revisão Criminal

## CPP 621: hipóteses

| Inc. | Hipótese |
|---|---|
| **I** | Sentença **contrária ao TEXTO EXPRESSO DA LEI PENAL** OU **contrária à evidência dos autos** |
| **II** | Sentença fundada em **DEPOIMENTOS, EXAMES OU DOCUMENTOS comprovadamente FALSOS** |
| **III** | **Após a sentença**, descobertas **NOVAS provas** de inocência OU **circunstância** que determine ou autorize diminuição especial da pena |

### Núcleo crítico
| | Conteúdo |
|---|---|
| Natureza | **AÇÃO AUTÔNOMA de impugnação** (não recurso) |
| Pressuposto | **Trânsito em julgado** da sentença condenatória |
| **Apenas pro reo** | Em favor do réu; **vedação à revisão pro societate** |
| Sentença absolutória | **NÃO** cabe revisão (não há gravame ao réu) |

## CPP 622-623: prazo + legitimidade

| | Conteúdo |
|---|---|
| Prazo (CPP 622) | **A QUALQUER TEMPO**, antes da extinção da pena OU após |
| Repetição (CPP 622 §u) | **Vedada** a reiteração do pedido, salvo se fundada em **provas novas** |
| Legitimidade (CPP 623) | **Condenado** OU **procurador legalmente habilitado** OU, no caso de morte, **cônjuge/ascendente/descendente/irmão** |
| Jurisprudência STJ/STF | Cabe **AINDA QUE EXTINTA a PUNIBILIDADE** ou cumprida a pena (interesse moral remanescente) |

## CPP 624: competência

| | Conteúdo |
|---|---|
| Regra | **TRIBUNAL** que proferiu a **última decisão** ou a que o juízo esteja vinculado |
| Condenação por **Tribunal Estadual** | **TJ** local (Câmaras Criminais Reunidas/Seção Criminal) |
| Condenação por **TRF** | **TRF** local |
| **STJ confirmou condenação** | **STJ** (3ª Seção): RvCr |
| **STF condenou ou confirmou** | **STF** |
| Originária Júri | **TJ** (devolutividade restrita à dosimetria/qualificadoras) |

## Causas típicas de cabimento

### CPP 621 I: contrária a TEXTO

| | Conteúdo |
|---|---|
| Aplicação | **Manifesta** contradição entre sentença e lei/prova |
| Erro material | Inclui erro grosseiro (ex.: aplicar pena revogada) |
| Limitação | NÃO se admite **reanálise de prova** que dependa de **interpretação subjetiva** (STJ) |
| Exemplo | Condenação por crime atípico + atribuição de qualificadora não pedida |

### CPP 621 II: prova FALSA

| | Conteúdo |
|---|---|
| Aplicação | Testemunho/laudo/documento **comprovadamente falsos** |
| Comprovação | Em processo próprio ou por prova produzida na própria revisão |
| Crime conexo | CP 342 (falso testemunho) + CP 297-299 (falsidade) |

### CPP 621 III: PROVA NOVA

| | Conteúdo |
|---|---|
| Conceito | Prova **superveniente** OU **conhecida** mas não apresentada (justificadamente) |
| **STJ RvCr 5.247/DF** (3ª Seção, j. 22/03/2023, Inf. 772) | NÃO cabe revisão da **DOSIMETRIA** sem **prova nova** |
| Exemplos | Confissão de outro autor + DNA superveniente + testemunha que só agora veio à tona |
| Anistia/abolição | **Não** é prova nova: extingue punibilidade |

## Procedimento (CPP 624-631)

| | Conteúdo |
|---|---|
| **Inicial** | Petição instruída com a **CERTIDÃO de TRÂNSITO** + **autos do processo** + provas |
| Defesa técnica | **OBRIGATÓRIA**: advogado OU defensoria |
| Relator | Sorteado |
| **Vista MP** | 10 dias |
| **Diligências** | Possíveis: produção de provas atípicas |
| **Julgamento** | Tribunal (Câmaras Reunidas/Pleno) |
| Não há | Audiência de instrução ampla |

## CPP 626: efeitos

| | Conteúdo |
|---|---|
| Provimentos possíveis | Alterar a classificação da infração, absolver o réu, modificar a pena ou anular o processo |
| **§u** | **VEDA reformatio in pejus**: não pode AGRAVAR a pena imposta pela decisão revista |

### Modalidades de decisão

| | Conteúdo |
|---|---|
| **Absolvição** | Anula condenação |
| **Modificação da capitulação** | Substitui o tipo penal |
| **Redução da pena** | Quantum |
| **Anulação processual** | Cinge-se à parte viciada |
| **Mudança da pena** | Sem agravar (CPP 626 §u) |

## CPP 630 + CF 5 LXXV: indenização por erro judiciário

| | Conteúdo |
|---|---|
| **CF 5 LXXV** | Estado **INDENIZA** o erro judiciário + quem fica preso além do tempo fixado |
| **CPP 630** | Tribunal **PODE** reconhecer direito a indenização **NA PRÓPRIA REVISÃO**, se requerida |
| Quantum | Liquidação no **juízo cível** (CPP 630 §1); ou via art. 37 §6 CF |
| Legitimação passiva | **União/Estado** conforme natureza do crime/justiça |
| Exclusões (CPP 630 §2) | Erro imputável ao próprio interessado (confissão, ocultação de prova) ou acusação meramente privada |
| **Anistia** + indenização | Não cabe: pressupõe ERRO judiciário (anistia é fato político) |

## Provas

| | Conteúdo |
|---|---|
| Documental | Regra |
| Testemunhal | Atípica: necessita motivação |
| Pericial | Possível (DNA) |
| Confissão de outro autor | Forte indicativo (STJ admite) |
| Retratação de delator | Caso a caso (STJ tem ressalvas) |

## Distinções essenciais

| | Revisão criminal | Habeas corpus |
|---|---|---|
| Natureza | **Ação autônoma** | Ação constitucional |
| Trânsito em julgado | **Exige** | Não exige |
| Provas novas | Admitidas | Excepcional |
| Cassação | Pode anular condenação | Trancar processo/anular ato específico |

| | Revisão | Apelação |
|---|---|---|
| Natureza | Ação autônoma | Recurso |
| Pressuposto | Trânsito | Sentença não transitada |
| Prazo | A qualquer tempo | 5 dias |

| | Revisão (621 III) | Habeas corpus + prova nova |
|---|---|---|
| Trânsito | Sim | Não exige |
| Prova nova | **Essencial** | Excepcional |

## STJ: pontos consolidados

| Tema | Conteúdo |
|---|---|
| Jurisprudência STJ/STF | Cabe ainda que extinta a punibilidade ou cumprida a pena |
| **RvCr 5.247/DF** (3ª Seção, j. 22/03/2023, Inf. 772) | Sem prova nova, não cabe revisão da DOSIMETRIA: vedada reapreciação |
| Jurisprudência STJ | Reconhecimento equivocado de reincidência autoriza revisão (e eventual indenização) |
| Não cabe | Quando o objeto seja **reapreciação de prova** dependente de interpretação subjetiva |

## Hipóteses recorrentes

| Hipótese | Saída |
|---|---|
| Erro material no tipo penal | **CPP 621 I** |
| Testemunha condenada por falso depoimento (CP 342) | **CPP 621 II** |
| DNA novo comprova outro autor | **CPP 621 III** |
| Confissão posterior de terceiro | **CPP 621 III** |
| Reapreciação de provas existentes | **NÃO cabe** (STJ) |
| Reapreciação da dosimetria sem prova nova | **NÃO cabe** (RvCr 5.247) |
| Crime já prescrito | **Cabe** (interesse moral, jurisprudência STJ/STF) |
| Após cumprimento total da pena | **Cabe** (interesse moral) |
| Pessoa morta | Cônjuge/parente entram (CPP 623) |
| Tribunal Estadual condenou | **TJ** (Seção/Câmaras Reunidas) |
| STJ confirmou condenação | **STJ** (3ª Seção) |

## Erros a evitar

- **Aplicar reformatio in pejus** em revisão (CPP 626 §u veda);
- Negar cabimento por **extinção da punibilidade** (jurisprudência STJ/STF admite, há interesse moral);
- Admitir revisão **pro societate** (vedada: revisão é apenas em favor do condenado);
- **Reapreciação de prova** já valorada (admitir apenas em **CPP 621 I "contrária à evidência"** se manifesto);
- Negar **indenização CF 5 LXXV** quando configurado erro;
- Aplicar revisão a **sentença ABSOLUTÓRIA** (não há gravame);
- **Confundir competência**: a revisão segue o **último Tribunal** (não o juízo de origem);
- Exigência de **advogado contratado** (defensoria pode atuar);
- Tratar **anistia/abolição** como **prova nova** (não é: extingue punibilidade);
- Admitir **revisão na DOSIMETRIA sem prova nova** (Inf. 772 STJ);
- Aplicar **prazo fixo** (não há: CPP 622 admite a qualquer tempo);
- Negar prova **TÉCNICA NOVA** (DNA, perícia) em CPP 621 III.

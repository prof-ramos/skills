# Princípios do Processo Penal

## 1. PRESUNÇÃO DE INOCÊNCIA (CF 5 LVII)

| | Conteúdo |
|---|---|
| Fórmula | "Ninguém será considerado culpado **até o trânsito em julgado** de sentença penal condenatória" |
| **STF ADCs 43, 44 e 54** (07/11/2019, por 6x5) | Declararam **CONSTITUCIONALIDADE do CPP 283** + **VEDARAM execução provisória** após 2º grau |
| Pacote Anticrime | Tentou flexibilizar; o STF **MANTEVE** a vedação |
| **EXCEÇÃO: Tema 1.068 STF** (RE 1.235.340) | **EXECUÇÃO IMEDIATA pós-JÚRI**, com base na soberania dos veredictos, independentemente do total da pena aplicada |

## 2. CONTRADITÓRIO + AMPLA DEFESA (CF 5 LV)

| | Conteúdo |
|---|---|
| Conteúdo | Direito de **ser ouvido e influir** |
| Engloba | **Defesa TÉCNICA** (advogado) + **AUTODEFESA** (interrogatório + presença) |
| Reforço | **Juiz das garantias** (ADIs 6.298-6.305, STF ago/2023): constitucional + implementação progressiva (CNJ) |

## 3. DEVIDO PROCESSO LEGAL (CF 5 LIV)

| | Conteúdo |
|---|---|
| Vertentes | **Formal** (procedimento) + **Substancial** (proporcionalidade + razoabilidade) |
| Função | Cláusula-mãe das demais garantias |

## 4. DUPLO GRAU

| | Conteúdo |
|---|---|
| Status | **NÃO expresso na CF**: implícito |
| Base internacional | **CADH 8.2 "h"** + PIDCP 14.5 |
| Ressalva | **Foro por prerrogativa** em única instância |
| **Tema 1.087 STF** | Cabível **apelação com base no CPP 593 III "d"** quando a decisão do Júri, amparada em **quesito genérico**, for considerada pela acusação manifestamente contrária à prova dos autos; o tribunal **não determina novo júri** quando houver **tese de clemência apresentada e constante em ata** |

## 5. INADMISSIBILIDADE DE PROVAS ILÍCITAS (CF 5 LVI + CPP 157)

| | Conteúdo |
|---|---|
| Inclui | **DERIVADAS** (fruits of the poisonous tree) |
| Exceções | **Descoberta inevitável + fonte independente + atenuação do vínculo** |
| Pacote Anticrime | **MANTEVE** o regime |
| Acesso da defesa | A inacessibilidade do material probatório à defesa compromete a validade do laudo correspondente (jurisprudência do STJ, 2025) |

## 6. JUIZ NATURAL (CF 5 LIII + XXXVII)

| | Conteúdo |
|---|---|
| Vedação | **Tribunal de exceção** |
| Conteúdo | Competência **prévia + abstrata** |

## 7. NEMO TENETUR SE DETEGERE (CF 5 LXIII)

| | Conteúdo |
|---|---|
| Direito | **AO SILÊNCIO** + não autoincriminação |
| **SV 11 STF** | **ALGEMAS só excepcionalmente**, sob justificativa fundamentada por escrito |

## 8. PUBLICIDADE (CF 5 LX + 93 IX)

| | Conteúdo |
|---|---|
| Regra | Pública |
| Mitigável | **Intimidade + interesse público** |

## 9. RAZOÁVEL DURAÇÃO (CF 5 LXXVIII)

| | Conteúdo |
|---|---|
| Inserção | **EC 45/2004** |
| Efeito | Excesso de prazo na **prisão** → **RELAXAMENTO** |

## 10. IDENTIDADE FÍSICA DO JUIZ (CPP 399 §2)

| | Conteúdo |
|---|---|
| Regra | Juiz que **PRESIDIU a INSTRUÇÃO julga** |
| Mitigação | **Transferência + promoção + aposentadoria** |

## 11. INSTRUMENTALIDADE: *pas de nullité sans grief* (CPP 563)

| | Conteúdo |
|---|---|
| Princípio | **Sem prejuízo demonstrado** = sem nulidade |
| Função | Convalidação |

## 12. ANPP (CPP 28-A, Lei 13.964/2019)

| | Conteúdo |
|---|---|
| Natureza | **Híbrida** (material + processual) |
| **STF HC 185.913/DF** (2024) | **RETROAGE até o TRÂNSITO em JULGADO** |
| **STJ Info 843** | Confissão prévia **NÃO é REQUISITO** |
| Inaplicável | **Racismo + injúria racial** (STF, RHC 222.599, 2ª Turma); o STJ estende a vedação às condutas homofóbicas equiparadas a racismo |

## Distinções essenciais

| | Pré-ADCs 43/44/54 | Pós (2019) |
|---|---|---|
| Execução pós-2º grau | Permitida (até 2019) | **VEDADA** (regra) |
| Júri | Aguardava trânsito | **Imediata** (Tema 1.068 STF) |

| | Devido processo formal | Substancial |
|---|---|---|
| Conteúdo | Procedimento | Proporcionalidade |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Condenação 2º grau pendente | **NÃO executa** (ADCs 43/44/54) |
| Condenação pelo Júri | **Executa IMEDIATAMENTE** (Tema 1.068 STF) |
| Algemas como regra | **Vedadas** (SV 11) |
| Réu cala | **Direito ao silêncio** (CF 5 LXIII) |
| Prova ilícita derivada | **Vedada**, salvo exceções |
| Excesso de prazo na preventiva | **Relaxa** |
| Inacessibilidade do material à defesa | Compromete a validade do laudo |
| ANPP retroativo | Cabível (HC 185.913) |
| Tribunal de exceção | **Vedado** |

## Erros a evitar

- **Aplicar EXECUÇÃO PROVISÓRIA pré-trânsito** em julgado (salvo Júri, Tema 1.068 STF);
- **Usar ALGEMAS como REGRA** (SV 11: excepcional);
- **Admitir prova ilícita DERIVADA sem exceção concreta**;
- Ignorar **cadeia de custódia em provas DIGITAIS**;
- Aplicar **Tema 1.068 a outros recursos** (é só pós-Júri);
- Negar **defesa técnica** (CF 5 LV);
- Aplicar **ANPP a racismo/injúria racial** (vedado);
- Não respeitar **revisão da preventiva a cada 90 dias** (CPP 316 par. único);
- Tratar **publicidade como absoluta** sem ponderar intimidade;
- Exigir **confissão prévia como requisito do ANPP** (STJ Info 843: não exige);
- Anular absolvição do Júri por **quesito genérico** quando houver **tese de clemência registrada em ata** compatível com a CF (Tema 1.087 STF: não cabe novo júri nessa hipótese).

# Prisão Domiciliar

## CPP 317: natureza

| | Conteúdo |
|---|---|
| Núcleo | **CUMPRIMENTO** da prisão preventiva na **RESIDÊNCIA** do investigado/acusado |
| Tipo | **Substitutiva** da preventiva; não é medida autônoma |
| Alterações legais | Hipóteses V e VI do CPP 318 incluídas pela **Lei 13.257/2016** (Marco Legal da Primeira Infância); CPP 318-A e 318-B pela **Lei 13.769/2018** |
| **Não confundir** | Com prisão domiciliar da **EXECUÇÃO penal** (LEP 117): outra hipótese |

## CPP 318: hipóteses (rol taxativo)

| Inc. | Hipótese |
|---|---|
| **I** | **Maior de 80 anos** |
| **II** | Extremamente **debilitado por doença grave** |
| **III** | **Imprescindível** aos cuidados especiais de pessoa **menor de 6 anos** OU **com deficiência** |
| **IV** | **GESTANTE** |
| **V** | **MULHER COM FILHO de até 12 anos** incompletos (Lei 13.257/2016) |
| **VI** | **HOMEM**, caso seja o **ÚNICO responsável** pelos cuidados de filho de até 12 anos incompletos (Lei 13.257/2016) |

### Lei 13.769/2018

| | Conteúdo |
|---|---|
| Vigência | **20/12/2018** |
| Inserção | **CPP 318-A** (substituição para gestante + mãe/responsável por criança ou PCD) + **CPP 318-B** (imposição concomitante de cautelares do 319) |
| Vedação | Crime **com VIOLÊNCIA/grave AMEAÇA** OU **CONTRA O PRÓPRIO FILHO OU DEPENDENTE** |
| Aplicação | Substituição **OBRIGATÓRIA** quando preenchidos os requisitos |

## STF HC 143.641 (HC Coletivo, 20/02/2018)

| | Conteúdo |
|---|---|
| Caso | HC coletivo impetrado em favor de **TODAS as MULHERES** presas preventivamente que sejam **gestantes, puérperas ou mães de crianças até 12 anos** OU de **PCD** |
| Decisão | Concedido **coletivamente**: substituição da preventiva por domiciliar |
| **Salvo** | Crime cometido **com violência/grave ameaça** OU **contra os próprios descendentes** OU situações excepcionalíssimas devidamente fundamentadas |
| Implementação | Lei 13.769/18 + aplicação reiterada pelo STJ |
| Alcance | Mesmo em **crimes equiparados a hediondos sem violência** (v.g. tráfico), respeitadas as exceções |

## CPP 318-A (Lei 13.769): substituição

| | Conteúdo |
|---|---|
| **Caput** | A prisão preventiva imposta a **MULHER GESTANTE** ou que for **MÃE/RESPONSÁVEL por CRIANÇA de até 12 anos** ou por PCD **SERÁ SUBSTITUÍDA** por prisão domiciliar |
| **Vedação 1** | Crime cometido **com violência ou grave ameaça a pessoa** |
| **Vedação 2** | Crime cometido **contra o próprio filho ou dependente** |
| Cautelares concomitantes | Possíveis (CPP 318-B) |

## Condições impostas

| | Conteúdo |
|---|---|
| Monitoração eletrônica | **Possível** (CPP 319 IX + Lei 12.258/10) |
| Recolhimento domiciliar | Integral OU parcial (saídas autorizadas) |
| Visitas restritas | Conforme decisão |
| **Saídas** | Apenas com **autorização judicial** específica (trabalho, saúde, escola) |

## Procedimento

| | Conteúdo |
|---|---|
| Iniciativa | **A pedido** da defesa; o exame das hipóteses do CPP 318 integra o controle de legalidade da prisão |
| Prova | Documentação: certidão de idade + atestado médico + certidão de nascimento + laudo PCD |
| Decisão | Fundamentada, com análise dos requisitos |
| Recurso do indeferimento | **HC** OU **RESE** (CPP 581 V) |

## STJ: pontos consolidados

| | Conteúdo |
|---|---|
| Aplicação ampla | A substituição da Lei 13.769 é a regra; as exceções (violência + crime contra descendente) têm interpretação **restritiva** |
| Tráfico sem violência | Substituição devida, salvo situação excepcionalíssima fundamentada |
| Negativa | Exige **fundamentação concreta e específica** (CPP 318 V), sob pena de constrangimento ilegal |
| Situação excepcionalíssima | O STJ admite a negativa **motivada** quando, por exemplo, a mulher comercializava drogas na casa onde a criança vivia (jurisprudência reiterada) |

## Distinções essenciais

| | Prisão domiciliar (CPP 317) | Prisão domiciliar (LEP 117) |
|---|---|---|
| Natureza | **Substitui a PREVENTIVA** | **Cumprimento** da pena |
| Fase | Investigação + processo | **Execução** |
| Hipóteses | CPP 318 I-VI | LEP 117 I-IV |
| Recurso | RESE/HC | Agravo em execução |

| | Prisão domiciliar | Recolhimento noturno (CPP 319 V) |
|---|---|---|
| Natureza | Substitutiva da preventiva | Cautelar alternativa |
| Restrição | **Integral** ou parcial | Apenas **noturno + folgas** |

| | Prisão domiciliar | Outras cautelares CPP 319 |
|---|---|---|
| Cabimento | Hipóteses específicas (CPP 318) | Genérico, por proporcionalidade |
| Base | CPP 317-318 | CPP 319 |

## LEP 117: prisão domiciliar na execução

| Inc. | Hipótese |
|---|---|
| **I** | Condenado **maior de 70 anos** |
| **II** | Condenado **acometido de doença grave** |
| **III** | Condenada com **filho menor ou deficiente** físico/mental |
| **IV** | Condenada **GESTANTE** |
| Aplicação | Regime **ABERTO** (regra); extensão quando falta vaga em regime adequado (SV 56) |

### SV 56 STF

| | Conteúdo |
|---|---|
| Tese | Falta de estabelecimento penal adequado **não autoriza** regime mais gravoso; observam-se os parâmetros do **RE 641.320** |
| Solução | Saída antecipada, monitoração ou **prisão domiciliar** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Mãe de criança de 8 anos + preventiva por tráfico | **CPP 318-A** + HC 143.641: substituição |
| Gestante + tráfico | **Domiciliar** |
| Gestante + crime com violência | NÃO substitui (vedação) |
| Pai único responsável + crime sem violência | **CPP 318 VI**: substituição |
| Maior de 80 anos | **CPP 318 I**: domiciliar |
| Mulher que vendia drogas em casa com o filho | Negativa **fundamentada** possível (situação excepcionalíssima, jurisprudência do STJ) |
| Mãe condenada definitivamente + criança | **LEP 117 IV** (execução, regime aberto) |
| Regime semiaberto sem vaga | **SV 56**: regime menos gravoso/domiciliar |
| Pai com filho de 14 anos | **NÃO se aplica** (limite: 12 anos incompletos) |
| PCD + cuidador imprescindível | **CPP 318 III**: domiciliar |
| Indeferimento sem fundamentação | **HC** + RESE: reformável |

## Erros a evitar

- **Negar prisão domiciliar** automaticamente em crime equiparado a hediondo sem violência (HC 143.641 estende);
- Aplicar as **VEDAÇÕES** (violência/crime contra descendente) sem fundamentação concreta;
- Confundir **CPP 318** (preventiva) com **LEP 117** (execução);
- **Exigir prova além do necessário** para gestante/mãe (basta documentação básica);
- Aplicar o CPP 318 VI a **PAI** que não seja o **único responsável**;
- Ignorar que a vedação por **VIOLÊNCIA** exige análise do caso concreto;
- Tratar a **idade do menor** como flexível (12 anos incompletos é o limite, CPP 318 V-VI);
- Negar domiciliar **sem motivação contemporânea**;
- Esquecer a **SV 56** quando há falta de vaga na execução;
- Impor **monitoração eletrônica** de forma automática (exige fundamentação, CPP 318-B + 319 IX);
- Conceder **saídas livres** sem autorização judicial específica;
- Aplicar o **HC coletivo** sem verificar a situação concreta da requerente.

# Correição Parcial Criminal

## Natureza

| | Conteúdo |
|---|---|
| Categoria | **Medida ATÍPICA** (não é recurso em sentido próprio) |
| Bem tutelado | Regularidade do **procedimento** |
| Hipótese | Ato/decisão do juiz que cause **TUMULTO PROCESSUAL** ou inversão tumultuária da ordem legal |
| Pressuposto | **AUSÊNCIA de recurso específico** (subsidiariedade absoluta) |
| Decisão | Administrativa-correicional (Corregedoria), com reflexos processuais |
| Cabimento atual | **Regimentos internos** dos tribunais + leis de organização judiciária |

## Fundamento normativo

| | Conteúdo |
|---|---|
| Justiça Federal | **Lei 5.010/66** (organização da JF de 1ª instância) prevê a reclamação correicional |
| **RITJ + RITRF** | Tribunais disciplinam em **regimento interno** |
| Observação histórica | A antiga referência à Lei 1.533/51 é apenas histórica: essa lei (mandado de segurança) foi **revogada pela Lei 12.016/2009** |
| **Súm. 267 STF** | "Não cabe mandado de segurança contra ato judicial passível de recurso ou **correição**" (reconhece o instituto) |

## Cabimento (regimental)

| Hipótese típica | Conteúdo |
|---|---|
| **Inversão tumultuária** da ordem processual | Juiz inverte fases do processo sem fundamento |
| Decisão sem **recurso específico** | Interlocutória fora do rol do RESE (CPP 581) |
| Irregularidade procedimental | Sem natureza de **constrangimento à liberdade** (caso contrário, HC) |
| **Omissão** reiterada sobre questão relevante | Quando não cabem ED |
| Indeferimento de **diligência essencial** sem fundamentação | Sem outra via |

## Cabimento prático

| Decisão | Saída |
|---|---|
| Indefere prova relevante sem motivação | **Correição** (se o RI prevê) OU MS criminal |
| Inverte a ordem da AIJ | **Correição** + arguição tempestiva da nulidade |
| Recebe denúncia inepta | **HC** (trancamento) conforme o caso |
| Decreta preventiva | **HC** (CF 5 LXVIII), não correição |
| Não decreta preventiva requerida | **RESE** (CPP 581 V), não correição |
| Rejeita denúncia | **RESE** (CPP 581 I), não correição |
| Indefere liberdade provisória | **HC** + RESE (CPP 581 V) |
| Não admite assistente de acusação | **MS criminal** (CPP 273 veda recurso) |
| Determinação extravagante fora do procedimento | **Correição** (extrapolação da função) |

## Distinções essenciais

| | Correição parcial | RESE (CPP 581) |
|---|---|---|
| Natureza | Medida ATÍPICA (regimental) | Recurso TÍPICO |
| Cabimento | **Subsidiário** | **Rol taxativo** |
| Prazo | RI (variável) | **5 dias** |

| | Correição parcial | HC |
|---|---|---|
| Bem tutelado | Procedimento | **LIBERDADE** |
| Cabimento | Tumulto + sem recurso | Constrangimento à liberdade |
| Base | RI + leis de organização | CF 5 LXVIII + CPP 647 |

| | Correição parcial | MS criminal |
|---|---|---|
| Natureza | Medida atípica | **Ação constitucional** (Lei 12.016) |
| Direito líquido e certo | Não exige | **Exige** (Lei 12.016 art. 1) |
| Limite comum | Vedada se há recurso típico | Vedado se há recurso ou correição (Súm. 267 STF) |

| | Correição parcial | Carta testemunhável |
|---|---|---|
| Hipótese | Tumulto procedimental | **Denegação** de recurso |
| Direcionamento | **Corregedoria** | **Escrivão** → tribunal (CPP 640) |
| Base | RI | **CPP 639** |

## Procedimento (regimento típico)

| Etapa | Conteúdo |
|---|---|
| **Inicial** | Petição à **Corregedoria-Geral** ou ao órgão indicado no RI |
| **Razões** | Tumulto + ausência de recurso típico + prejuízo |
| **Provas** | **Documentos** dos autos |
| **Informações** | Solicitadas ao juízo a quo |
| **Vista ao MP** | Conforme o RI |
| **Decisão** | Corregedoria OU órgão colegiado (conforme o RI) |
| **Efeito** | Anula/corrige o ato tumultuário OU determina a providência omitida |

## Pontos consolidados

| | Conteúdo |
|---|---|
| Subsidiariedade absoluta | Não cabe quando há **outro recurso** específico |
| **HC vs Correição** | Havendo ameaça à liberdade, o HC prevalece |
| **MS criminal vs Correição** | Havendo direito líquido e certo sem recurso, o MS é via constitucional própria |
| Aplicação | **Excepcional**: interpretação restritiva |
| Vedação | Não serve de **sucedâneo recursal** (Súm. 267 STF por paridade de razão) |

## Prazos comuns (regimentais; verificar o RI específico)

| Tribunal | Prazo típico |
|---|---|
| TJs estaduais | **5-10 dias** (RI) |
| TRFs | **5-15 dias** (RI) |
| STJ/STF | Não há correição parcial contra seus julgados (recursos próprios) |

## Conteúdo da peça

```
EXMO. SR. CORREGEDOR-GERAL DA JUSTIÇA [/PRESIDENTE DO TRIBUNAL]

[NOME], qualificado, vem, nos termos do art. [___] do Regimento
Interno do [Tribunal], oferecer CORREIÇÃO PARCIAL em face da
decisão de [data] proferida pelo Juízo [___] no processo [Nº],
pelas seguintes razões:

I – CABIMENTO (TUMULTO PROCESSUAL + AUSÊNCIA DE RECURSO ESPECÍFICO)
II – ATO/DECISÃO IMPUGNADO + descrição
III – ILEGALIDADE/IRREGULARIDADE
IV – PREJUÍZO PROCESSUAL CONCRETO
V – PEDIDO (correção + invalidação do ato)

[Local], [data]. [OAB]
```

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Juiz indefere prova sem fundamentar | **Correição** se o RI prevê OU **MS** com direito líquido |
| Juiz determina diligência fora do procedimento | **Correição** |
| Juiz não decide questão essencial reiteradamente | **Correição** + eventual ED |
| Juiz nega seguimento à apelação | **RESE** (CPP 581 XV), não correição |
| Juiz nega RESE | **Carta testemunhável** (CPP 639), não correição |
| Preventiva ilegal | **HC** (CF 5 LXVIII), não correição |
| Juiz cria fase processual sem previsão legal | **Correição** (tumulto evidente) |

## Erros a evitar

- **Usar correição parcial em lugar de RESE** (o recurso específico afasta a via);
- **Usar em lugar de HC** quando há ameaça à liberdade;
- Manejar **sem previsão no RI** do tribunal;
- Substituir o **MS criminal** quando há direito líquido e certo sem recurso;
- Confundir com **carta testemunhável** (denegação de recurso, CPP 639);
- Omitir a demonstração de **tumulto + prejuízo**;
- Ultrapassar o **prazo regimental**;
- Endereçar à **autoridade errada** (verificar Corregedoria × órgão colegiado no RI);
- Tratar como **recurso típico** com efeitos automáticos;
- Utilizá-la contra **decisões com via recursal específica** (apelação + ED + RESE);
- Citar a **Lei 1.533/51 como vigente** (revogada pela Lei 12.016/2009).

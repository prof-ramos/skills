# Poder de Investigação do MP

## Base normativa

| | Conteúdo |
|---|---|
| **CF 129 I** | Ação penal pública (privativa do MP) |
| **CF 129 VI** | Expedir notificações + requisitar informações e diligências |
| **CF 129 VII** | Controle externo da atividade policial |
| **CF 129 VIII** | Requisitar diligências investigatórias + instauração de IP |
| **CF 129 IX** | Outras funções compatíveis |
| **LC 75/93** | LOMPU |
| **Lei 8.625/93** | LONMP |
| **Resolução CNMP 181/2017** | PIC: Procedimento Investigatório Criminal |

## STF Tema 184 (RE 593.727)

| | Conteúdo |
|---|---|
| Fixada | **18/05/2015** |
| **Tese (essência)** | O **Ministério Público** dispõe de competência para promover, **por autoridade própria**, **INVESTIGAÇÕES de natureza penal**, desde que respeitadas as **garantias constitucionais** (legalidade + contraditório posterior + provas lícitas + reserva de jurisdição quando exigida) |

## Aplicação prática

| Hipótese | Saída |
|---|---|
| MP instaura PIC e colhe provas | **Cabível** (Tema 184) |
| MP investiga sem polícia | **Cabível** |
| MP requisita documentos a órgãos públicos | **Cabível** (CF 129 VIII) |
| MP convoca pessoas para depoimento | **Cabível** (poder requisitório) |
| MP requer dados bancários sem ordem judicial | **VEDADO** (reserva de jurisdição) |
| Interceptação telefônica pelo MP sem ordem | **VEDADO** (Lei 9.296) |
| MP investiga crime de corrupção | Cabível |
| MP investiga crime militar próprio | Análise (regime CPM) |
| Tutela coletiva: MP investiga improbidade | Cabível (ACP) |
| Resultado do PIC fundamenta denúncia | Cabível |

## Limites

| Limite | Conteúdo |
|---|---|
| **Reserva de jurisdição** | Interceptação + busca e apreensão + violação de domicílio |
| **Contraditório posterior** | Investigado pode contestar na ação penal |
| **Provas lícitas** | Vedação a prova ilícita (CF 5 LVI) |
| **Compartilhamento de dados** | Tema 990 (RFB/COAF) cabível; outros exigem ordem |
| **Identificação** do investigado | Cabível mediante requisitos legais |

## Erros a evitar

- Negar o poder investigatório do MP (Tema 184: cabível);
- Em PIC sem polícia, considerar **prova ilícita** automaticamente (Tema 184 valida);
- Em **interceptação telefônica** sem ordem judicial pelo MP: aceitar (vedada);
- Em **busca e apreensão** pelo MP sem ordem: aceitar (vedada);
- Em prova obtida por MP ferindo reserva de jurisdição: validar (cabe ilicitude);
- Em **contraditório** apenas na ação penal: aceitar como satisfatório (a tese exige);
- Em PIC de **crimes hediondos**, exigir polícia (cabe MP);
- Em **colaboração premiada** firmada por MP sem polícia: aceitar (cabível Lei 12.850).

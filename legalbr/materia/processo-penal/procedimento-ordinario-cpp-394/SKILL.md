# Procedimento Comum Ordinário

## CPP 394: classificação

| Procedimento | Critério |
|---|---|
| **ORDINÁRIO** | Pena máxima **≥ 4 anos** |
| **SUMÁRIO** | Pena máxima **< 4 anos** |
| **SUMARÍSSIMO** | Infrações de menor potencial ofensivo (Lei 9.099, JECrim) |

| | Conteúdo |
|---|---|
| Erro de rito | **Nulidade** quando suprime fases defensivas (demonstrado o prejuízo, CPP 563) |

## CPP 396 + 396-A: RESPOSTA À ACUSAÇÃO

| | Conteúdo |
|---|---|
| Prazo | **10 dias** após a citação |
| Conteúdo | **Preliminares** (incompetência + inépcia + litispendência) + **toda matéria de defesa** + documentos + **rol de até 8 TESTEMUNHAS** + justificações |
| STJ | Mérito reservado às alegações finais, mas **atipicidade flagrante** pode ser reconhecida desde logo |

## CPP 397: ABSOLVIÇÃO SUMÁRIA

| Inc. | Hipótese |
|---|---|
| **I** | **Excludente MANIFESTA de ILICITUDE** |
| **II** | **Excludente MANIFESTA de CULPABILIDADE** (salvo inimputabilidade → prossegue para eventual absolvição imprópria) |
| **III** | Fato **MANIFESTAMENTE ATÍPICO** |
| **IV** | **EXTINTA a PUNIBILIDADE** |

| | Conteúdo |
|---|---|
| Recurso | **Apelação** pelo MP |
| Tribunal | NÃO pode condenar diretamente: apenas determinar o prosseguimento (STJ) |

## CPP 400: AIJ, ORDEM RÍGIDA

| Ordem | Ato |
|---|---|
| 1 | **Ofendido** |
| 2 | **Testemunhas de acusação** |
| 3 | **Testemunhas de defesa** |
| 4 | **Esclarecimentos de peritos** |
| 5 | **Acareações** |
| 6 | **Reconhecimentos** |
| **7** | **INTERROGATÓRIO DO RÉU, POR ÚLTIMO** |

### STF HC 127.900/AM (Pleno, 03/03/2016)
| | Conteúdo |
|---|---|
| Tese | Interrogatório por último em **TODOS os procedimentos**, inclusive regidos por lei especial |
| Estende | **Lei de Drogas (Lei 11.343 art. 57)** + **militar** + demais especiais |

### STJ Tema 1.114 (REsp 1.933.759)
| | Conteúdo |
|---|---|
| Tese | O interrogatório é o **último ato** da instrução; a **inversão da oitiva de TESTEMUNHAS** gera nulidade **sujeita a preclusão** + demonstração de **PREJUÍZO** |

### STJ Tema 1.269
| | Conteúdo |
|---|---|
| Tese | Estende o interrogatório ao final ao **ADOLESCENTE** no procedimento do ECA (subsidiariedade do CPP 400) |

## CPP 401-402: testemunhas + diligências

| | Conteúdo |
|---|---|
| **401** | Máximo **8 por parte**; NÃO se computam ofendidos + peritos + informantes + referidas |
| **402** | Diligências adicionais só se a necessidade **surgir de circunstâncias reveladas** na instrução |

## CPP 403: ALEGAÇÕES FINAIS

### Regra: alegações ORAIS
| | Conteúdo |
|---|---|
| Tempo | **20 minutos** (prorrogáveis por 10) |
| Ordem | **Acusação → defesa** (defesa por último) |
| Sentença | Em audiência |

### Exceção (§3): MEMORIAIS ESCRITOS
| | Conteúdo |
|---|---|
| Hipótese | **COMPLEXIDADE da causa** ou **pluralidade de réus** |
| Prazo | **5 dias SUCESSIVOS** (acusação → defesa) |
| Sentença | **10 dias** |
| Defensoria Pública | **Prazo em dobro** (LC 80, arts. 44 I, 89 I e 128 I) |
| Ausência de alegações finais defensivas | **NULIDADE ABSOLUTA**: nomear defensor *ad hoc* |

## CPP 405: sentença

Em audiência ou em **10 dias**; registro dos depoimentos por meios audiovisuais.

## Marcos correlatos (Lei 13.964/2019)

| | Conteúdo |
|---|---|
| **CPP 158-A a 158-F** | **Cadeia de custódia**: observância sob pena de questionamento da prova |
| **CPP 28-A** | **ANPP**: precede o recebimento da denúncia |
| Juiz das garantias | ADIs 6.298-6.305 (ago/2023) + implementação CNJ |

## Procedimentos especiais

| | Conteúdo |
|---|---|
| **Sumário** (CPP 531-538) | Audiência única + pena < 4 anos |
| **Sumaríssimo** (Lei 9.099) | JECrim: composição civil + transação + suspensão condicional |
| **Drogas** (Lei 11.343 arts. 50-59) | Defesa preliminar 10d antes do recebimento + interrogatório por último (HC 127.900) |
| **Júri** (CPP 406-497) | Bifásico |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Crime pena máx ≥ 4 anos | **Ordinário** |
| Crime pena máx < 4 anos | **Sumário** |
| Menor potencial ofensivo | **Sumaríssimo** (Lei 9.099) |
| Após recebimento | **Citação + resposta em 10d** |
| Excludente manifesta | **Absolvição sumária** (397) |
| Interrogatório como 1º ato | **NULIDADE** (HC 127.900), observada a arguição tempestiva |
| Inversão de testemunhas | Nulidade sujeita a preclusão + prejuízo (Tema 1.114) |
| Causa complexa | **Memoriais escritos em 5d** (defesa por último) |
| Ausência de alegações finais | **Nulidade ABSOLUTA** |
| Adolescente ECA | Interrogatório por último (Tema 1.269) |

## Erros a evitar

- **Realizar o INTERROGATÓRIO como PRIMEIRO ATO** (HC 127.900: vale para todos os procedimentos);
- **Negar memoriais em causa complexa** (CPP 403 §3 admite);
- Converter alegações orais em memoriais **sem fundamentação concreta**;
- **Aplicar rito sumário onde cabe ordinário** com supressão de faculdades defensivas;
- Condenar **diretamente** no julgamento da apelação contra absolvição sumária (STJ veda);
- Omitir o **prazo em dobro da Defensoria** (LC 80);
- Sentenciar **sem alegações finais defensivas e sem nomear defensor ad hoc** (nulidade absoluta);
- Admitir mais de **8 testemunhas** por parte (CPP 401);
- Indeferir **diligências do art. 402** cuja necessidade surgiu na instrução, sem fundamentação;
- Aplicar a **antiga ordem da Lei 11.343** com interrogatório no início (HC 127.900 superou);
- Tratar a **inversão de oitivas como nulidade absoluta** (Tema 1.114: sujeita a preclusão + prejuízo).

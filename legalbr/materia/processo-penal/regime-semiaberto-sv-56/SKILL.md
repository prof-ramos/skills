# Regime Semiaberto e SV 56

## Súmula Vinculante 56

> "A **falta de estabelecimento penal adequado** **NÃO autoriza** a manutenção do condenado em regime prisional **mais gravoso**, devendo-se observar, nessa hipótese, os parâmetros fixados no RE 641.320/RS."

## Acórdão paradigma

| | Conteúdo |
|---|---|
| Caso | **RE 641.320/RS** |
| Relator | **Min. Gilmar Mendes** |
| Julgamento | **11/05/2016** |
| SV 56 | Aprovada **29/06/2016** |

| | Conteúdo |

## Núcleo

| | Conteúdo |
|---|---|
| Falta de vaga no semiaberto | **NÃO autoriza** fechado |
| Falta de vaga no aberto | **NÃO autoriza** semiaberto |
| Princípio | Vedação ao **excesso de execução** |
| Diálogo | **ADPF 347** (estado de coisas) + Tema 365 STF (RE 580.252, indenização) |

## Alternativas (RE 641.320)

| Ordem | Solução |
|---|---|
| **1** | Saída antecipada para o regime aberto |
| **2** | **Liberdade eletronicamente monitorada** |
| **3** | **Prisão domiciliar** se inviável tornozeleira |
| **4** | Cumprimento em **estabelecimento similar** (não destinado, mas com características semelhantes) |

## Casos relacionados

| | Conteúdo |
|---|---|
| **Tema 423 STF** | RE 641.320: parâmetros e avaliação dos estabelecimentos pelos juízes da execução |
| **ADPF 347** | Estado de coisas |
| **Tema 365 STF** | RE 580.252: indenização por condições degradantes |
| Súm. 491 STJ | Vedação à progressão per saltum |

## Distinguishing

| Hipótese | Saída |
|---|---|
| Vagas existentes mas indisponíveis temporariamente | Solução transitória |
| Cumprimento em **ala adequada** dentro de fechado | Aceitável apenas transitoriamente |
| Liberdade **monitorada** | Prioritária |
| Prisão **domiciliar** | Subsidiária |

## Erros a evitar

- Manter o condenado em **regime fechado** por falta de vaga no semiaberto;
- Manter no **semiaberto** por falta de vaga no aberto;
- Considerar a SV 56 como **mera recomendação**;
- Não esgotar a ordem das **alternativas** do RE 641.320;
- Aplicar prisão domiciliar **antes** da monitoração eletrônica;
- Ignorar diálogo com **ADPF 347** e **Tema 365 STF** (indenização);
- Negar reclamação ao STF por descumprimento da SV (cabível CF 102 I l).

# Quebra de Sigilo Bancário, Fiscal e Telemático

## Tipos de sigilo

| Sigilo | Base |
|---|---|
| **Bancário** | LC 105/2001 + CF 5 X e XII |
| **Fiscal** | CTN 198 + CF 5 X + LC 105 (compartilhamento) |
| **Telefônico** (em curso) | CF 5 XII + Lei 9.296/96 |
| **Telemático armazenado** | Marco Civil (Lei 12.965/2014) |
| **Dados cadastrais** | Sem sigilo absoluto, Lei 12.850 art. 15 |
| **Correspondência** | CF 5 XII (inviolável, só interpretação restritiva permite quebra judicial) |

## Sigilo bancário (LC 105/2001)

| | Conteúdo |
|---|---|
| Regra | **Inviolabilidade** das operações bancárias |
| **Exceções legais** (art. 3-6) | CPI + autoridade fiscal (procedimento administrativo) + ordem judicial |
| **Procedimento administrativo** RFB (LC 105 art. 6) | Permite acesso direto sem ordem judicial em **fiscalização tributária regular** |
| Critério | Necessidade demonstrada + procedimento administrativo formalizado |

## STF Tema 225 (RE 601.314, 2016)

**Constitucionalidade da LC 105 art. 6**: Receita Federal **pode acessar** diretamente dados bancários **sem ordem judicial** no exercício de **fiscalização tributária**.

| Requisitos cumulativos |
|---|
| Procedimento administrativo regular |
| Necessidade demonstrada |
| Garantia do sigilo (não-divulgação) |
| Garantia de defesa do contribuinte |

## STF Tema 990 (RE 1.055.941, 2019)

| | Conteúdo |
|---|---|
| Tese | **Compartilhamento** de dados bancários e fiscais entre **Receita Federal e Ministério Público** (e órgãos de persecução penal) **sem prévia autorização judicial** é **constitucional** |
| Condição | Procedimento administrativo regular + necessidade |
| Reflexo | MP pode usar dados encaminhados pela Receita em ações penais |
| Limitações | Não autoriza acesso indiscriminado, exige fundamentação concreta no procedimento administrativo |

## Quebra de sigilo bancário **judicial**

| Quando | Conteúdo |
|---|---|
| Investigação criminal | Por ordem judicial fundamentada |
| Processo penal | Idem |
| Requerente | MP + autoridade policial + parte autora |
| **CF 5 X + XII** | Reserva de jurisdição (em regra) |
| **Pacote anticrime + Lei 13.964** | Mantida regra geral |

## CPI: poder próprio (CF 58 §3)

| | Conteúdo |
|---|---|
| Texto | CPI tem **poderes de investigação próprios das autoridades judiciais** |
| **STF MS 23.452** | Pode quebrar sigilo **bancário, fiscal e telefônico** diretamente |
| **NÃO pode** | **Interceptar** comunicação telefônica em curso (reserva absoluta de jurisdição CF 5 XII), só **registros** de chamadas |
| Fundamentação | Decisão da maioria + ato motivado |

## Sigilo telemático (dados armazenados)

| | Conteúdo |
|---|---|
| Base | Marco Civil (Lei 12.965 art. 7 e 10) |
| Quebra | **Ordem judicial** fundamentada |
| Dados | E-mail, redes sociais, conversas armazenadas |
| **STJ RHC 51.531** (6ª Turma, 2016) | Acesso a conversas de WhatsApp em celular apreendido **exige** autorização judicial (ver condicionantes do Tema 977 STF) |
| **STJ RHC 99.735** (6ª Turma, 2018) | Espelhamento do WhatsApp Web pela polícia, sem conhecimento do dono do celular, é **prova ilícita** |

## Sigilo telefônico (em curso × registros)

| Tipo | Regra |
|---|---|
| **Interceptação em curso** | Lei 9.296, ordem judicial (CF 5 XII reserva) |
| **Registros telefônicos** (extrato de chamadas) | Quebra de sigilo por ordem judicial OU CPI |
| **Dados cadastrais** | **Sem** ordem judicial, Lei 12.850 art. 15 |

## Lei 12.850/2013 art. 15: dados cadastrais

| | Conteúdo |
|---|---|
| Texto | Delegado e MP têm **acesso direto** aos dados cadastrais (qualificação pessoal, filiação, endereço), **independe** de autorização judicial |
| Aplicação | Investigação criminal em geral (não só orcrim) |
| **Ratio** | Dados cadastrais não são sigilosos, visam identificação |
| Reflexo | Acelera diligências policiais |

## Procedimento de quebra judicial

| Passo | Conteúdo |
|---|---|
| 1 | Requerimento fundamentado (MP/polícia) |
| 2 | Indicação concreta dos elementos investigados |
| 3 | Especificação dos **bens/contas/períodos** |
| 4 | Decisão **fundamentada** do juízo competente |
| 5 | Oficiamento ao BACEN/RFB/instituição financeira |
| 6 | Autos em **sigilo** (apartados) |
| 7 | Análise + uso na investigação/ação |
| 8 | Compartilhamento controlado |

## Sigilo profissional (CP 154)

| | Conteúdo |
|---|---|
| Advogado-cliente | Inviolável (EOAB art. 7º XIX), quebra em casos excepcionais |
| Médico-paciente | LC 105 não atinge, sigilo médico (CP 154) |
| Contador | Sujeito ao sigilo + obrigação de comunicação ao **Coaf** (Lei 9.613) em operações suspeitas |

## Coaf + comunicações de operações suspeitas

| | Conteúdo |
|---|---|
| Lei 9.613 (lavagem) art. 11 | Obrigação de comunicar operações suspeitas |
| Sujeitos | Bancos, factoring, joalherias, cartórios, etc. |
| Encaminhamento ao Coaf | Anônimo (do cliente) |
| **STF Tema 990** | Compartilhamento **espontâneo** Coaf/RFB → MP **dispensa** ordem judicial |
| **STJ 3ª Seção (j. 14/05/2025)** | Polícia e MP **NÃO podem requisitar diretamente** RIF ao Coaf sem prévia autorização judicial (só o compartilhamento espontâneo do Coaf/RFB é livre); questão afetada ao STF no Tema 1.404 (RE 1.537.165), **pendente** |

## Cooperação internacional e sigilo

| | Conteúdo |
|---|---|
| Bloqueio de ativos no exterior | Via MLAT + DRCI |
| Quebra de sigilo bancário no exterior | Por cooperação direta (auxílio direto) + tratado |
| **Convenção de Mérida** | Cooperação ampla em corrupção |

## Dados protegidos pela LGPD (Lei 13.709)

| | Conteúdo |
|---|---|
| Aplicação | Dados pessoais em geral |
| Persecução penal | Excepcionada (art. 4 III a), atividade pública de segurança |
| Operações da Receita/MP | Sujeitas a finalidade e necessidade |
| Banco de perfis genéticos | Lei 12.654 + LGPD |

## Requisitos da decisão de quebra

| Item | Conteúdo |
|---|---|
| **Fundamentação concreta** | Indicação de indícios + necessidade |
| **Especificação** | Bens, contas, períodos, finalidade |
| **Proporcionalidade** | Quebra adequada ao crime investigado |
| **Sigilo dos autos** | Tramitação em apartado |
| **Defesa** | Acesso posterior assegurado |

## Erros a evitar

- Determinação de quebra de sigilo **bancário** sem **fundamentação concreta**;
- Admitir compartilhamento RFB-MP **sem procedimento administrativo regular** (Tema 990);
- Confundir **dados cadastrais** (sem ordem, Lei 12.850 art. 15) com sigilo bancário/fiscal;
- Admitir que CPI **intercepte** comunicações em curso (reserva absoluta de jurisdição);
- Não exigir **autorização judicial** para acesso a conversas em celular apreendido (RHC 51.531 + Tema 977 STF);
- Admitir espelhamento do WhatsApp Web sem conhecimento do dono (RHC 99.735);
- Quebra de sigilo de **advogado-cliente** sem indícios robustos + fundamentação (EOAB art. 7º);
- Não exigir **especificação** de período/contas/bens, quebra genérica é nula;
- Omitir decretação de sigilo dos autos da quebra;
- Tratar **LGPD** como afastada totalmente em persecução (exige proporcionalidade).

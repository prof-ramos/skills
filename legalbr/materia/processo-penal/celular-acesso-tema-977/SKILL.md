# Acesso a Celular sem Ordem Judicial

## Base normativa

| | Conteúdo |
|---|---|
| **CF 5 X** | Invioláveis a **intimidade + vida privada + honra + imagem** |
| **CF 5 XII** | Inviolabilidade do **sigilo das comunicações** (correspondência, telefônicas, dados): salvo, no último caso, ordem judicial para fins de investigação criminal/instrução processual |
| **Lei 9.296/96** | Interceptação telefônica: comunicações em **FLUXO** (exige ordem judicial) |
| **Lei 12.965/14** (MCI) art. 7 e 10 | Privacidade + proteção de dados em comunicações pela internet |
| **LGPD Lei 13.709/18** | Tratamento de dados pessoais |
| **CPP art. 6 II/III/VII** | Apreensão pela autoridade policial de objetos e instrumentos relacionados ao fato |
| **CPP art. 158-A a 158-F** | **Cadeia de custódia** (Lei 13.964/19: Pacote Anticrime) |

## STF Tema 977 (ARE 1.042.075)

| Tese | Conteúdo |
|---|---|
| **1** | Mera **apreensão** do aparelho (CPP 6 ou flagrante) **NÃO está sujeita à reserva de jurisdição** |
| **2** | **Encontro fortuito** de celular (sem dono identificado): **acesso** aos dados para esclarecer autoria do fato OU identificar proprietário **NÃO depende** de consentimento OU decisão judicial prévia, **justificada POSTERIORMENTE** |
| **3** | Em **apreensão** (CPP 6 ou flagrante) com titular identificado: **acesso aos dados depende** de **CONSENTIMENTO expresso e livre** do titular **OU** **prévia decisão judicial** |
| **4** | Autoridade policial pode adotar **providências de preservação** dos dados e metadados antes da autorização judicial, justificando posteriormente |
| **5** | **Efeitos prospectivos**, ressalvados pedidos formulados por defesas até o **encerramento do julgamento (25/06/2025)** |

## Distinção essencial

| Cenário | Regra |
|---|---|
| **Apreensão** do celular | **Não exige** ordem judicial (CPP 6) |
| **Acesso aos dados** (mensagens, fotos, contatos) | Exige **consentimento OU ordem judicial** |
| **Encontro fortuito** (celular sem dono) | Acesso permitido com **justificação posterior** |
| **Preservação dos dados** (cópia + lacração) | Permitida antes da ordem (justificada depois) |
| **Comunicações em fluxo** (interceptação ao vivo) | Exclusivamente sob **Lei 9.296/96** (ordem judicial) |

## Distinção com o espelhamento WhatsApp Web (STJ RHC 99.735)

| | Tema 977 STF | Espelhamento WhatsApp Web (STJ RHC 99.735, 6ª Turma) |
|---|---|---|
| Objeto | Dados **estáticos** armazenados no aparelho físico | **Espelhamento via WhatsApp Web** (acesso em tempo real ao conteúdo) |
| Reserva | Consentimento OU ordem judicial | 6ª Turma invalida (meio híbrido sem previsão legal: permite enviar/apagar mensagens sem vestígio); a 5ª Turma passou a admitir com ordem judicial quando único meio possível |
| Fundamento | CF 5 X + XII | Lei 9.296/96 (interceptação em fluxo) |
| Situação | Tese fixada (2025) | Divergência entre Turmas; afetada a recurso repetitivo em 2025 (REsp 2.052.194, 3ª Seção, sem suspensão nacional; sem tese fixada até julho/2026) |

## Cadeia de custódia (CPP 158-A a 158-F)

| Etapa | Conteúdo |
|---|---|
| **Reconhecimento** | Constatação do material |
| **Isolamento** | Evitar contato indevido |
| **Fixação** | Documentação pormenorizada |
| **Coleta** | Recolhimento técnico |
| **Acondicionamento** | Embalagem própria |
| **Transporte** | Com rastreabilidade |
| **Recebimento** | Pela perícia |
| **Processamento** | Análise técnica |
| **Armazenamento** | Local apropriado |
| **Descarte** | Após autorização judicial |
| **Quebra** | **Nulidade** se romper a cadeia (CPP 158-A §1) |

## Hipóteses

| Situação | Saída |
|---|---|
| Polícia apreende celular em flagrante e acessa mensagens sem consentimento/ordem | **Prova ilícita** (CPP 157) |
| Polícia apreende celular e o titular **consente** expressamente o acesso | Prova **lícita** (consentimento livre) |
| Encontro fortuito de celular em local de crime sem dono | Acesso permitido para identificar autoria, **justificado depois** |
| Apreensão e preservação imediata dos dados sem leitura, com ordem em 24h | **Lícita** (apenas preservação) |
| Espelhamento via WhatsApp Web sem ordem judicial | **Ilícito** (STJ RHC 99.735 + Lei 9.296/96) |
| Interceptação em fluxo de mensagens em tempo real | Apenas com ordem judicial (Lei 9.296/96) |
| Defesa pediu nulidade até **25/06/2025** | Tese aplicável aos casos anteriores (modulação ressalvada) |
| Coleta sem cadeia de custódia | **Nulidade** (CPP 158-A §1) |

## Casos correlatos

| | Conteúdo |
|---|---|
| **STJ RHC 99.735** (6ª Turma, 2018) | Espelhamento WhatsApp Web inválido; matéria afetada a repetitivo em 2025 (REsp 2.052.194) |
| **STJ RHC 51.531/RO** (Info 583) | Acesso direto pela polícia a conversas do celular apreendido em flagrante, sem ordem: ilícito (linha consolidada até o Tema 977) |
| **RE 583.937** | Gravação ambiental por interlocutor: lícita |
| **Lei 13.964/19** | Pacote Anticrime: cadeia de custódia |
| **Marco Civil (Lei 12.965/14)** | Provedor de aplicação: guarda de registros + acesso só com ordem |

## Erros a evitar

- **Confundir apreensão com acesso**: apreensão livre (CPP 6); acesso exige consentimento ou ordem;
- Aplicar a tese 2 (encontro fortuito) a celular **com titular identificado** (deve-se obter consentimento ou ordem);
- Considerar lícito o acesso **sem justificação posterior** documentada (tese 4);
- Aplicar Tema 977 **retroativamente** sem ressalva da modulação (defesas anteriores a 25/06/2025);
- **Romper a cadeia de custódia** (art. 158-A CPP: nulidade);
- Tratar acesso ao **WhatsApp Web** como acesso a dados estáticos (é espelhamento, assemelhado à interceptação, STJ RHC 99.735);
- **Interceptar comunicações em fluxo** sem ordem judicial sob a justificativa do Tema 977;
- Admitir consentimento obtido sob **coação/coação ambiental** (consentimento deve ser livre);
- Permitir acesso ao celular de **terceiro não investigado** sem ordem;
- Esquecer da **justificação posterior** quando se invoca tese 4 (preservação);
- Negar produção da prova quando o titular **consente expressamente** (consentimento dispensa ordem);
- Aplicar a tese a buscas digitais em computadores de pessoa jurídica sem distinguir o regime de empresas (LGPD + processo administrativo).

# Mandado de Soltura

## Natureza

| | Conteúdo |
|---|---|
| Categoria | **DOCUMENTO JUDICIAL** que ordena a soltura de pessoa presa |
| Origem | Decisão que **CESSA** a restrição à liberdade |
| Princípio | **EXECUÇÃO IMEDIATA** (CF 5 LXV + CPP 660 §§1-2) |
| Fundamento | Direito de **NÃO permanecer preso ilegalmente** |
| Sinônimo | Alvará de soltura (terminologia equivalente) |

## Hipóteses de emissão

| Hipótese | Decisão | Base |
|---|---|---|
| Concessão de **HC** | Tribunal/juiz | CF 5 LXVIII + CPP 660 |
| **Relaxamento** de prisão | Juiz | CPP 310 I |
| **LIBERDADE PROVISÓRIA** | Juiz | CPP 310 III + CPP 321 |
| Revogação da **PREVENTIVA** | Juiz | CPP 316 |
| **ABSOLVIÇÃO** | Sentença | CPP 386 + CPP 596 |
| **PRESCRIÇÃO** + outras extinções de punibilidade | Sentença | CP 107 |
| **CUMPRIMENTO INTEGRAL** da pena | Juiz da execução | LEP 109 |
| Conclusão do **livramento condicional** sem revogação | Juiz da execução declara extinta a pena | LEP 131-146 |
| Conversão da pena em PRD/multa | Juiz da execução | LEP 180 |
| Falta de vaga em regime adequado | SV 56 | STF |

## CPP 660: cumprimento imediato

| | Conteúdo |
|---|---|
| **§1** | Decisão favorável ao paciente no HC → **logo posto em liberdade**, salvo se por outro motivo deva ser mantido preso |
| **§2** | Evidenciada a ilegalidade da coação pelos documentos, o juiz ou tribunal ordena que **cesse imediatamente o constrangimento** |
| Princípio | **EXECUÇÃO IMEDIATA**, sem depender de nova provocação |
| **Súm. 691 STF** | NÃO cabe HC ao STF contra indeferimento de liminar em HC a tribunal superior (exceções restritas a flagrante ilegalidade) |
| Atraso | Ilegalidade: cabe **HC** + responsabilidade da autoridade |

## STJ: pontos consolidados

| | Conteúdo |
|---|---|
| Cumprimento imediato | O atraso injustificado no cumprimento do alvará configura constrangimento ilegal (jurisprudência do STJ) |
| Responsabilidade | A autoridade que retarda o cumprimento responde administrativa, civil e, conforme o caso, penalmente |
| Tribunal de origem | **EXPEDIR mandado/alvará** + comunicação à autoridade responsável |
| **STF SV 56** | Falta de vaga NÃO autoriza regime mais gravoso; observam-se os parâmetros do RE 641.320 (cumprimento em regime menos gravoso/domiciliar/monitoração) |

## Procedimento típico

| Etapa | Conteúdo |
|---|---|
| **Concessão** da soltura | Decisão judicial (HC + relaxamento + liberdade) |
| **Expedição** | Mandado/alvará pelo escrivão |
| **Encaminhamento** | À **autoridade policial** OU **diretor do estabelecimento** |
| **Cumprimento** | **IMEDIATO** + dispensa formalidades excessivas |
| **Cópias** | Para autoridade requisitante (juízo) + interessado |
| **Recibo** | Da soltura + documentação |

## Mandado de soltura × prisão

| | Soltura | Prisão (CPP 282-289) |
|---|---|---|
| Conteúdo | **Cessa** restrição | **Inicia** restrição |
| Documento | Alvará | Mandado de prisão |
| Princípio | Imediato + favorece liberdade | Devida fundamentação + execução conforme |
| **CPP 289 + 310** | Não se aplica | Cumprimento + audiência de custódia em 24h |

## CONTRAMANDADO

| | Conteúdo |
|---|---|
| Núcleo | Documento que **CESSA** a eficácia de **MANDADO ANTERIOR** (de prisão ou soltura) |
| Hipótese | Cessação da causa do mandado original (extinção, suspensão, anulação) |
| Cumprimento | Imediato, com comunicação a todas as autoridades que receberam o primeiro |
| Aplicação | Mandado de prisão expedido em duplicidade ou após indevida emissão |

## Cumprimento: entes responsáveis

| | Conteúdo |
|---|---|
| Estabelecimento prisional | Diretor: recebe via secretaria do juízo |
| **Polícia Judiciária** | Auxiliar quando necessário |
| **Polícia Militar** | Em casos de ostensiva captura/soltura |
| Oficial de Justiça | Comunica + entrega documentos |

## SV 56 STF: falta de vaga

| | Conteúdo |
|---|---|
| Tese | **Falta de estabelecimento penal adequado** NÃO autoriza manutenção em regime mais gravoso, observados os parâmetros do RE 641.320 |
| Solução | Saída antecipada, liberdade eletronicamente monitorada ou **PRISÃO DOMICILIAR**, conforme os parâmetros do RE 641.320 |
| Aplicação | Direito do executado de não cumprir pena em regime mais gravoso que o fixado |
| Vide | [[regime-semiaberto-sv-56]] |

## Documentos da peça

```
JUÍZO DA [VARA] DA COMARCA DE [...]
PROCESSO Nº [___]

ALVARÁ DE SOLTURA
================

O Juízo desta Vara, com fundamento na decisão de [data]
[absolvitória/de revogação da preventiva/de concessão de HC], que
[detalhar a decisão], MANDA expedir o presente ALVARÁ DE SOLTURA
em favor de [NOME], qualificado nos autos, para que seja IMEDIATA-
MENTE COLOCADO EM LIBERDADE.

Comunique-se à direção do estabelecimento prisional + Polícia
Civil + Polícia Militar.

[Local], [data]. [Juiz]
```

## Casos típicos

| Hipótese | Saída |
|---|---|
| HC concedido por tribunal | **Mandado de soltura** + comunicação imediata |
| Sentença absolutória | Alvará na sentença (CPP 596) |
| Revogação preventiva | Alvará imediato |
| Cumprimento integral da pena | Soltura ex officio + comunicação (LEP 109) |
| Falta de vaga regime semiaberto | Regime menos gravoso/**domiciliar** conforme RE 641.320 (SV 56) |
| Sentença + recurso em liberdade (Lei 11.343 art. 59) | Alvará de **manutenção em liberdade** |
| Atraso no cumprimento | **HC** + responsabilidade administrativa |
| Mandado de prisão indevidamente expedido | **CONTRAMANDADO** + recolhimento de outras vias |
| Liminar em HC durante audiência | Mandado imediato + comunicação |
| Prisão **já cumprida** (cumpriu pena) | Alvará automático ex officio |
| Erro material no mandado | Retificação + novo alvará |
| Pessoa custodiada em **outra comarca** | Carta precatória + cumprimento via deprecada |

## Distinções essenciais

| | Alvará/Mandado de soltura | Habeas Corpus |
|---|---|---|
| Natureza | **Documento executório** | **Ação constitucional** |
| Origem | **DECISÃO** que defere a soltura | Ação autônoma |
| Conteúdo | Ordem de soltar | Pedido de liberdade |

| | Mandado de soltura | Mandado de prisão |
|---|---|---|
| Conteúdo | **Soltar** | **Prender** |
| Base | CF 5 LXV + decisões | CPP 282-289 |

| | Contramandado | Alvará novo |
|---|---|---|
| Hipótese | **Cessar** anterior | Nova ordem |
| Função | Negativa | Positiva |

## Erros a evitar

- **Atrasar o cumprimento** do mandado/alvará (CF 5 LXV + CPP 660: imediato);
- Exigir **FORMALIDADES excessivas** para soltura (princípio da imediatidade);
- Negar **regime menos gravoso/domiciliar** em falta de vaga (SV 56 + RE 641.320);
- Confundir **alvará de soltura** com **mandado de prisão**;
- Esquecer **CONTRAMANDADO** quando mandado anterior se torna obsoleto;
- Não comunicar **autoridade policial** + diretor do estabelecimento;
- Tratar **alvará** como interlocutório recorrível (não é: é executório);
- Aplicar **rito ordinário** quando deveria ser **execução imediata**;
- Não emitir alvará ex officio em **extinção da punibilidade**;
- Esquecer a **responsabilidade administrativa** da autoridade que atrasa;
- Tratar **falta de vaga** como justificativa para regime mais gravoso (SV 56).

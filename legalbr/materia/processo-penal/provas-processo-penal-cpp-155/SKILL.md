# Provas no Processo Penal

|---|---|

| | Conteúdo |

## Espécies de prova (CPP 158-250)

| | Conteúdo |
|---|---|
| **PERICIAL** (158-184) | Corpo de delito + exames + cadeia de custódia |

| **CONFISSÃO** (197-200) | Isolada **NÃO basta** (CPP 197: apreciada com os demais elementos); atenuante CP 65 III "d" (Súm. 545 + Tema 1.194 STJ) |
| **OFENDIDO** (201) | Declarações + comunicações + proteção |

| **DOCUMENTOS** (231-238) | Produção em qualquer fase (regra) |
| **BUSCA E APREENSÃO** (240-250) | Medida sujeita aos requisitos constitucionais e legais, inclusive ordem judicial para busca domiciliar fora das exceções constitucionais |

## Confiabilidade racional e relatório com IA generativa

No **HC 1.059.475/SP**, a Quinta Turma do STJ afastou, no caso concreto, relatório de investigador produzido com IA generativa para interpretar vídeo e áudio. A perícia oficial não confirmara a expressão atribuída ao acusado, e o relatório não oferecia metodologia verificável, reprodução controlada ou validação humana apta a sustentar a divergência.

| Controle | Conteúdo |
|---|---|
| **Alcance** | Precedente da **Quinta Turma**, não vinculante; não estabelece proibição geral ao uso de IA na atividade probatória |
| **Admissibilidade racional** | Verifique aptidão da ferramenta para o dado, transparência metodológica, reprodutibilidade, validação humana e possibilidade de contraditório |
| **Material de origem** | Preserve e disponibilize o áudio, vídeo ou dado analisado para exame independente |
| **Categorias distintas** | O STJ não reconheceu ilicitude nem quebra de cadeia de custódia e não qualificou o relatório como perícia; faltou confiabilidade epistêmica mínima naquele caso |

## CPP 226: RECONHECIMENTO

### STJ HC 598.886-SC (2020)
| | Conteúdo |
|---|---|
| Tese | Procedimento do **CPP 226 OBRIGATÓRIO**, sob pena de invalidade |
| Razão | Reconhecimento viciado **NÃO se convalida** (efeito de reforço altera a memória) |

### STJ Tema 1.258 (repetitivo)
| | Conteúdo |
|---|---|
| Tese | As regras do CPP 226 são de **observância obrigatória** no inquérito e em juízo; o reconhecimento inválido **não pode lastrear condenação, preventiva, recebimento de denúncia nem pronúncia** |
| Detalhes | O reconhecimento inválido não pode servir de base para condenação, prisão preventiva, recebimento da denúncia ou pronúncia |

## Referências-chave

| | Conteúdo |
|---|---|
| **CPP 197** | Confissão **isolada** NÃO basta: apreciada com os demais elementos |
| **Súm. 545 STJ + Tema 1.194 STJ** | Confissão = atenuante CP 65 III "d", independentemente do uso no convencimento; retratação afasta, salvo se serviu à apuração |
| **HC 127.900 STF** | Interrogatório por último em TODOS os procedimentos |
| **HC 598.886 STJ + Tema 1.258 STJ** | CPP 226 obrigatório |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Condenação só com inquérito | **VEDADA** (CPP 155) |
| Cautelar/não repetível/antecipada | **Pode** fundamentar |
| Prova ilícita | **Desentranha** (157) |
| Prova ilícita derivada | **Vedada**, salvo fonte independente/descoberta inevitável/atenuação |
| Juiz que conheceu a ilícita | **Pode julgar** (ADI 6.298) |
| Interrogatório como 1º ato | Nulidade, observada a arguição (HC 127.900 + Tema 1.114) |
| Confissão isolada | NÃO basta (CPP 197) |
| Reconhecimento sem CPP 226 | **Inválido** (Tema 1.258 STJ) |
| Interceptação com motivação padronizada | **Ilegal** (Tema 661 STF) |
| Prorrogação fundamentada | **Lícita** (Tema 661 STF) |
| Quebra da cadeia de custódia | Exige **prejuízo concreto** |

## Erros a evitar

- **Condenar com base APENAS em INQUÉRITO** (CPP 155 veda);
- **Admitir prova ILÍCITA DERIVADA sem exceção concreta**;
- **Usar RECONHECIMENTO fora do CPP 226** (Tema 1.258);
- Aplicar o **CPP 157 §5** (declarado **inconstitucional**, ADI 6.298);
- **Realizar o INTERROGATÓRIO como PRIMEIRO ATO** (HC 127.900);
- Condenar com base em **confissão isolada** (CPP 197: exige corroboração);
- Tratar **motivação padronizada** como suficiente para interceptação (Tema 661 STF);
- **Omitir a atenuante da confissão** nos termos da Súm. 545 e do Tema 1.194 STJ;
- Admitir **reconhecimento informal**/por foto de aplicativo sem o CPP 226;
- Decretar prisão **com base em reconhecimento viciado** (Tema 1.258);
- Prorrogar interceptação **sem motivação concreta**.
- Generalizar o HC 1.059.475 como vedação a toda IA, ou atribuir ao julgado fundamento de ilicitude, quebra de cadeia de custódia ou perícia inexistente.

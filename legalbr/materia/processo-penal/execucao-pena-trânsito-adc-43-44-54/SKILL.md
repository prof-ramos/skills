# Execução Provisória da Pena (ADCs 43, 44 e 54 STF)

## Acórdãos paradigmas

| | Conteúdo |
|---|---|
| **ADC 43 + ADC 44 + ADC 54/DF** | Min. **Marco Aurélio** |
| Julgamento | **07/11/2019** (Pleno — **6x5**) |
| Publicação | 12/11/2020 |
| **HC 126.292** (2016) | **SUPERADO** |
| **HC 84.078** (2009) | Restaurado em essência |

## Tese fixada

> "O **art. 283 do CPP**, na redação dada pela Lei 12.403/2011, é **compatível com a CF**, sendo **VEDADA a execução provisória** da pena antes do trânsito em julgado da sentença penal condenatória."

## Bases normativas

| | Conteúdo |
|---|---|
| **CF 5 LVII** | Presunção de inocência **até o trânsito em julgado** |
| **CPP 283** (Lei 12.403/11) | Constitucional |
| **CPP 312** | Prisão preventiva |
| CPP 387 §1 | Execução |

## Hipóteses de prisão (taxativas)

| | Conteúdo |
|---|---|
| **Flagrante** | Sim |
| **Sentença condenatória transitada em julgado** | Sim |
| **Cautelar** (preventiva, temporária) | Sim, com requisitos do CPP 312 |
| Execução **provisória** | **VEDADA** |

## Modulação

Decisões anteriores baseadas no entendimento revogado devem ser revistas — **soltura imediata** mediante HC ou requerimento, caso a caso.

## Mantida prisão preventiva

| | Conteúdo |
|---|---|
| Após sentença | Cabível se presentes requisitos do **CPP 312** |
| Fundamentação | **Concreta** e atual |
| Risco | Garantia da ordem pública, instrução, aplicação da lei penal |

| | Conteúdo |
|---|---|
| Caso | **RE 1.235.340** |
| Julgamento | **12/09/2024** |
| Exceção | **Crimes dolosos contra a vida** — execução provisória após condenação **no Plenário do Júri** |
| Razão | Soberania dos vereditos |

## Distinguishing

| Hipótese | Saída |
|---|---|
| Condenação **2ª instância** + recursos pendentes | **Não cabe** execução provisória |
| Crime doloso contra a vida + plenário do Júri | **Tema 1.068** — execução cabível |
| Prisão **preventiva** com CPP 312 | Cabível mesmo após sentença |
| Pena **restritiva de direitos** | Veda execução provisória |
| Progressão de regime pró-réu | **Súm. 716** — admite |

## Erros a evitar

- Determinar **execução provisória** após acórdão condenatório em apelação (vedado);
- Confundir **execução provisória** com **prisão preventiva** (esta exige CPP 312);
- Aplicar exceção do **Júri (Tema 1.068)** a outros crimes;
- Tratar o **trânsito em julgado** como mera formalidade;
- Permitir início de cumprimento de **pena restritiva de direitos** sem trânsito;
- Negar HC para soltura de preso por execução provisória pré-2019;
- Equiparar a presunção de inocência a **mera regra de prova** sem regra de tratamento.

# Interrogatório do Réu

## CPP 185 + Lei 10.792/2003

| | Conteúdo |
|---|---|
| Natureza | **Meio de DEFESA (autodefesa)**, não meramente prova |
| Caráter | Ato **personalíssimo** do acusado |
| **Defensor obrigatório** | Constituído ou nomeado, sob **NULIDADE ABSOLUTA** (CPP 185 caput) |
| Entrevista prévia | Direito a **entrevista prévia e reservada** com o defensor antes do ato (CPP 185 §5), consectário da ampla defesa (CF 5 LV) |

## CPP 186: Direito ao silêncio (CF 5 LXIII)

| | Conteúdo |
|---|---|
| Redação | Lei 10.792/2003 |
| Cientificação | Antes do ato: direito de permanecer calado + de não responder perguntas |
| **Par. único** | Silêncio **NÃO importa confissão** + **NÃO pode ser interpretado em prejuízo** da defesa |
| Base | Não autoincriminação (***nemo tenetur se detegere***) |

## CPP 187: Duas partes

| | Conteúdo |
|---|---|
| **(i)** Sobre a pessoa | Qualificação + vida pregressa + condições pessoais |
| **(ii)** Sobre os fatos | Imputação + versão de defesa |
| Mentira | O réu pode mentir sobre os **fatos** (autodefesa, sem tipo penal correspondente); a falsa identidade é punível (CP 307) |

## CPP 188: Reperguntas

| | Conteúdo |
|---|---|
| Após o juiz | As partes (MP + defesa) podem formular reperguntas sobre pontos não esclarecidos |
| Sistema | Mitigação do modelo presidencialista |

## CPP 189-196

| | Conteúdo |
|---|---|
| Confissão parcial / negativa | Registradas com as razões do acusado (CPP 189-190) |
| Corréus | Interrogados **separadamente** (CPP 191) |
| Surdo/mudo/analfabeto | Regras próprias (CPP 192) |
| Intérprete | Para quem não fala português (CPP 193) |
| Curador ao menor de 21 | Regra **revogada** pela Lei 10.792/2003 (antigo CPP 194) |
| **CPP 196** | O juiz pode, **a todo tempo**, proceder a novo interrogatório, de ofício ou a pedido |

## CPP 400 (Lei 11.719/2008)

| | Conteúdo |
|---|---|
| Interrogatório | **ÚLTIMO ATO da instrução** no procedimento ordinário e sumário |
| Função | Garante a plenitude da autodefesa após o conhecimento de toda a prova acusatória |

## Procedimentos especiais

| | Conteúdo |
|---|---|
| **STF HC 127.900/AM** (Pleno) | A regra do CPP 400 (interrogatório como último ato) aplica-se a **TODOS os procedimentos**, inclusive especiais (drogas, Lei 11.343 art. 57; militar; eleitoral) |
| Fundamento | Sistema acusatório + ampla defesa |
| Marco temporal | Instruções encerradas a partir de **03/03/2016** |
| **STJ Tema 1.114** | O interrogatório é o **último ato da instrução**; a inversão da ordem quanto às testemunhas gera nulidade sujeita a **preclusão + prejuízo** |
| **STJ Tema 1.269** | Estendido ao **adolescente** (ato infracional: CPP 400 aplicado subsidiariamente ao ECA) |

## SV 14 + direito de presença

| | Conteúdo |
|---|---|
| **SV 14 STF** | Acesso amplo do defensor aos elementos de prova já documentados |
| Direito de presença | Do réu aos atos da instrução, salvo videoconferência fundamentada |

## Videoconferência (Lei 11.900/2009, CPP 185 §§2-9)

| | Conteúdo |
|---|---|
| Caráter | **Excepcional** + decisão **fundamentada** (CPP 185 §2) |
| Hipóteses (réu preso) | (i) Risco à segurança pública (fuga/organização criminosa); (ii) enfermidade ou dificuldade pessoal; (iii) influência sobre testemunha/vítima; (iv) gravíssima questão de ordem pública |
| Intimação | **10 dias** de antecedência (CPP 185 §3) |
| Entrevista reservada | **Garantida**, com canais telefônicos entre defensor no presídio e na sala de audiência (CPP 185 §5) |

## Lei 13.964/2019 (Anticrime)

| | Conteúdo |
|---|---|
| Sistema acusatório | Reforço (CPP 3-A) |
| Juiz das garantias | Inserido (implementação conforme ADIs 6.298-6.305 + CNJ) |
| Estrutura do interrogatório | Não alterada |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Réu sem defensor no ato | **NULIDADE ABSOLUTA** |
| Sem advertência do silêncio | Nulidade |
| Interrogatório antes das testemunhas | **Nulidade sujeita a preclusão + prejuízo** (Tema 1.114) |
| Procedimento especial (drogas) | **Interrogatório como último ato** (HC 127.900) |
| Adolescente | Último ato (Tema 1.269) |
| Videoconferência sem fundamentação | Nulidade |
| Réu silencia | **NÃO pode prejudicar** (CPP 186 par. único) |
| Réu mente sobre os fatos | **Não é crime** (autodefesa) |
| Sem entrevista prévia reservada | Nulidade (CPP 185 §5) |

## Erros a evitar

- Realizar o **interrogatório antes da oitiva das testemunhas** (Tema 1.114: nulidade que exige arguição tempestiva + prejuízo);
- **Não advertir do direito ao silêncio** (CPP 186);
- **Impedir a comunicação com o defensor** (CPP 185 §5);
- Determinar **videoconferência sem fundamentação concreta** nas hipóteses do §2;
- **Negar a entrevista prévia reservada** (CPP 185 §5);
- Interpretar o **silêncio em prejuízo** do réu (CPP 186 par. único veda);
- Tratar o interrogatório apenas como meio de **prova** (é sobretudo defesa);
- Aplicar o **CP 307** à mentira do réu sobre os fatos (a autodefesa não tipifica; a falsa identidade sim);
- Manter o interrogatório no início do rito da **Lei de Drogas** (HC 127.900 superou);
- Realizar novo interrogatório (CPP 196) **sem a presença de defensor**;
- Omitir a **antecedência de 10 dias** da intimação para a videoconferência (CPP 185 §3).

# Execução Provisória no Júri (Tema 1.068 STF)

## Acórdão paradigma

| | Conteúdo |
|---|---|
| Caso | **RE 1.235.340** |
| Julgamento | **12/09/2024** (Pleno) |

## Tese fixada

> "**Em crimes dolosos contra a vida**, admite-se a **execução provisória** da pena após a **condenação pelo Tribunal do Júri**, em razão da **soberania dos veredictos** (CF 5 XXXVIII c)."

## Bases normativas

| | Conteúdo |
|---|---|
| **CF 5 XXXVIII** | Instituição do Júri |
| CF 5 XXXVIII c | **Soberania dos veredictos** |
| **CF 5 LVII** | Presunção de inocência (regra geral) |
| **CPP 593 III** | Apelação no Júri (limitada) |
| **ADC 43/44/54** | Regra geral — execução só após trânsito |

## Núcleo

| | Conteúdo |
|---|---|
| Júri | **Exceção** à ADC 43/44/54 |
| Soberania dos veredictos | Justifica a execução imediata |
| Limites da apelação | CPP 593 III — manifesta contrariedade à prova, decisão contrária à lei expressa, nulidade |
| Alcance | **Apenas** crimes dolosos contra a vida |

## Aplicação

| Crime | Execução provisória |
|---|---|
| **Homicídio doloso** | **Cabível** após Júri |
| Latrocínio (não vai a Júri) | **Não cabível** |
| Demais crimes | ADC 43/44/54 (regra geral) |

## Modulação

**Sem modulação específica**.

## Casos relacionados

| | Conteúdo |
|---|---|

| HC 84.078 | Vedação histórica |

| Tema 925 | Anterior RG |
| **CF 5 XXXVIII** | Estrutura do Júri |

## Distinguishing

| Hipótese | Saída |
|---|---|
| Crime **doloso contra a vida** + condenação no Júri | **Execução provisória** |
| Demais crimes | **ADC 43/44/54** (regra geral) |
| Anulação do Júri pelo TJ | Suspende execução |
| Prisão **preventiva** após Júri | Cabível com CPP 312 |
| Crime tentado contra a vida | Aplica Tema 1.068 |

## Erros a evitar

- Estender **Tema 1.068** a outros crimes (só dolosos contra a vida);
- Confundir **execução provisória** com prisão **preventiva**;
- Manter execução após **anulação** do Júri pelo TJ;
- Aplicar a regra geral ADC 43/44/54 a Júri (Tema 1.068 é exceção);
- Negar HC para soltura em caso de **anulação** posterior;
- Ignorar a base da **soberania dos veredictos**;
- Confundir com a **execução provisória** em apelação penal comum (vedada).

# Prova Testemunhal

## Princípios

| | Conteúdo |
|---|---|
| **Imediação** | Juiz colhe diretamente |
| **Concentração** | Em audiência una |
| **Contraditório** | Partes inquirem |
| **Identidade física do juiz** (CPP 399 §2) | Juiz que presidiu a instrução sentencia (regra mitigada) |
| **Inquirição direta** (CPP 212, Lei 11.690/2008) | Partes perguntam **diretamente**; o juiz complementa |

## Quem deve depor (CPP 202-203)

**Toda pessoa** poderá ser testemunha (CPP 202). Dever de comparecer e de dizer a verdade (CPP 203 + 206).

## Compromisso (CPP 203) + dispensa (CPP 208)

| | Conteúdo |
|---|---|
| Forma | Promessa de dizer a verdade sobre o que souber e lhe for perguntado |
| Não prestam compromisso (CPP 208) | **Menores de 14 anos** + doentes e deficientes mentais + as pessoas do **CPP 206** (parentes) |
| Sem compromisso | Depõem como **informantes**: valor probatório relativo |
| **Réu como testemunha** | Não cabe (direito ao silêncio) |

## Recusa em razão de parentesco (CPP 206)

| | Conteúdo |
|---|---|
| Quem pode recusar | Ascendente + descendente + afim em linha reta + cônjuge (ainda que separado) + irmão + pai/mãe/filho adotivo |
| Exceção | **Quando não for possível, por outro modo, obter-se ou integrar-se a prova** |
| Nesse caso | Depõem sem compromisso (CPP 208) |

## Proibição de depor (CPP 207)

| | Conteúdo |
|---|---|
| Quem | Pessoas que devem **guardar segredo** em razão de função/ministério/ofício/profissão |
| Exemplos | Advogados, médicos, sacerdotes, psicólogos |
| Exceção | Se **desobrigadas pelo interessado** E quiserem depor |
| Advogado | Sigilo reforçado (EAOAB art. 7 XIX) |

## Número de testemunhas

| Procedimento | Por parte |
|---|---|
| **Comum ordinário** (CPP 401) | **8** (não computadas as que não prestam compromisso e as referidas) |
| **Comum sumário** (CPP 532) | **5** |
| **JECrim** | Praxe: até **3** (enunciados) |
| **Júri, 1ª fase** (CPP 406 §§2-3) | **8** |
| **Júri, Plenário** (CPP 422) | **5** |

## Momento de arrolar

| | Conteúdo |
|---|---|
| **Acusação** | Na denúncia/queixa (CPP 41 + 401) |
| **Defesa** | Na resposta à acusação (CPP 396-A) |
| Substituição | Admitida por analogia ao CPC nos casos de não localização/morte |
| Referidas + informantes | Não contam no limite |

## CPP 212 (Lei 11.690/2008): inquirição direta

| | Conteúdo |
|---|---|
| Ordem | (a) A parte pergunta **diretamente** à testemunha; (b) a parte contrária pergunta; (c) o **juiz complementa** sobre pontos não esclarecidos |
| Função do juiz | Indeferir perguntas que puderem **induzir a resposta**, sem relação com a causa ou repetidas |
| Inversão (juiz pergunta primeiro) | Nulidade **RELATIVA**: exige arguição oportuna + demonstração de prejuízo (jurisprudência do STJ) |

## Testemunhas referidas (CPP 209 §1)

Mencionadas por outra testemunha: o juiz **pode** ouvi-las **de ofício**; não contam no número legal.

## Contradita (CPP 214)

| | Conteúdo |
|---|---|
| **Contradita** | A parte alega circunstância que torne a testemunha suspeita ou indigna de fé (parentesco, inimizade, interesse) |
| Decisão | O juiz consigna a contradita e a resposta; exclui a testemunha proibida de depor (207) ou toma o depoimento sem compromisso (208) |
| Valor | O peso do depoimento é aferido na sentença |

## Acareação (CPP 229)

| | Conteúdo |
|---|---|
| Cabimento | Divergências relevantes entre testemunhas/acusado/ofendido |
| Procedimento | Confrontação sobre os pontos divergentes |
| Limite | O réu **não é obrigado** a participar (CF 5 LXIII) |
| Vide | [[confissao-acareacao-cpp-197-230]] |

## Proteção de testemunhas (Lei 9.807/99)

| | Conteúdo |
|---|---|
| Programa | **Provita**: proteção de vítimas e testemunhas ameaçadas |
| Requisitos | Coação ou grave ameaça + colaboração com a investigação/processo |
| Em audiência | Medidas de resguardo (CPP 217) + preservação de dados qualificativos em casos graves |

## CPP 217: retirada do réu / videoconferência

| | Conteúdo |
|---|---|
| Cabimento | Presença do réu pode causar **humilhação, temor ou sério constrangimento** à testemunha/ofendido, prejudicando a verdade |
| Procedimento | Inquirição por **videoconferência**; somente na impossibilidade, **retirada do réu** |
| Registro | Consignado em ata + presença do defensor obrigatória |
| Constitucionalidade | Reconhecida (não viola o contraditório) |

## Compromisso × valor probatório

| Depoente | Valor |
|---|---|
| **Compromissada** | Pleno (sob pena de CP 342) |
| **Informante** (sem compromisso) | Relativo: exige corroboração |
| Vítima (CPP 201) | Não é testemunha; a palavra da vítima tem **especial relevo** em crimes sexuais e de violência doméstica (jurisprudência consolidada), corroborada pelo conjunto |
| **Corréu** | Não é testemunha (direito ao silêncio) |
| Policial | Pode depor; o depoimento vale como o de qualquer testemunha, avaliado com o conjunto |
| Perito | Atua como **perito** (CPP 159), com esclarecimentos em audiência |

## Falso testemunho (CP 342)

| | Conteúdo |
|---|---|
| Crime | Fazer afirmação falsa, negar ou calar a verdade |
| Pena | **Reclusão 2-4 anos + multa** |
| Sujeito | Testemunha + perito + contador + tradutor + intérprete |
| **Retratação** (CP 342 §2) | Antes da **sentença no processo em que ocorreu o ilícito**: extingue a punibilidade |
| **Réu** | Não responde por CP 342 (autodefesa) |
| Informante | Controvertido; prevalece a atipicidade por ausência de compromisso |

## Inquirição de criança/adolescente

| | Conteúdo |
|---|---|
| **Lei 13.431/2017** | Escuta especializada + **depoimento especial** |
| Forma | Sala adequada + profissional capacitado + gravação |
| Vedação | Revitimização: evitar repetição do depoimento |
| Antecipação | Depoimento especial como prova antecipada em crimes sexuais (Lei 13.431 art. 11) |

## Erros a evitar

- Iniciar a inquirição pelo **juiz** (CPP 212: partes perguntam primeiro; nulidade relativa com prejuízo);
- Impedir a **inquirição direta** pelas partes (CPP 212);
- Compelir cônjuge/ascendente/descendente/irmão a depor **sob compromisso** (CPP 206 + 208);
- Aceitar depoimento de **advogado/médico** sobre fato sigiloso sem desobrigação do interessado (CPP 207);
- Computar **referidas e informantes** no limite legal (não contam);
- Não preservar testemunha sob ameaça (Lei 9.807 + CPP 217);
- Permitir que o **réu** deponha como testemunha;
- Aplicar o **CP 342** ao réu (autodefesa);
- Não realizar o **depoimento especial** de criança/adolescente (Lei 13.431);
- Compelir o réu à **acareação** (CF 5 LXIII);
- Retirar o réu da sala **sem tentar a videoconferência** e sem consignar os motivos (CPP 217).

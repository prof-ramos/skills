# Citação e Intimação no Processo Penal

## Citação: formas

| Forma | Quando |
|---|---|
| **Pessoal por mandado** (CPP 351) | Regra geral |
| **Carta precatória** (CPP 353) | Réu em outra comarca |
| **Carta rogatória** (CPP 368) | Réu no exterior em local conhecido |
| **Por edital** (CPP 361) | Réu não localizado |
| **Por hora certa** (CPP 362, Lei 11.719/2008) | Réu se oculta para não ser citado |
| **Réu preso** (CPP 360) | Pessoal, mandado cumprido no estabelecimento prisional |
| **Militar** (CPP 358) | Por intermédio do superior |

## CPP 366: réu citado por edital que não comparece nem constitui advogado

| | Conteúdo |
|---|---|
| Efeitos | **Suspende** o processo + **suspende** a prescrição |
| Marco | Citação por edital + não comparecimento + sem advogado |
| **Súm. 415 STJ** | Suspensão da prescrição **não pode** ser perpétua, limita-se ao tempo da prescrição pela **pena máxima** abstrata |
| Provas urgentes | Podem ser produzidas (CPP 366 §1), antecipação de prova |
| Preventiva | Cabível se preenchidos requisitos (CPP 312) |
| Retomada | Comparecimento ou constituição de defensor, processo prossegue |

### Distinção com CPP 367 (revelia)

| | CPP 366 | CPP 367 (revelia) |
|---|---|---|
| Citação | **Por edital** | Pessoal (qualquer forma) |
| Comparecimento | Não compareceu nem constituiu adv. | Compareceu inicialmente e depois não mais |
| Efeito | **Suspende** processo + prescrição | **Não suspende**: segue com defensor dativo |

## CPP 362: citação por hora certa

| | Conteúdo |
|---|---|
| Requisitos | Oficial verifica que réu se oculta + intima familiar/vizinho que receberá citação no dia útil seguinte em hora certa |
| **Subsidiária** ao edital | Esgota-se tentativa pessoal antes |
| Constitucionalidade | Reconhecida pelo STF (Tema 613, RE 635.145) |
| Efeitos | Processo **prossegue** (não suspende como no edital) |
| Defensor dativo | Nomeado se réu não constitui advogado |

## CPP 361: citação por edital

| | Conteúdo |
|---|---|
| Cabimento | Réu não localizado após esgotamento de meios |
| Prazo do edital | **15 dias** (CPP 361) |
| Publicação | Diário oficial + jornal de grande circulação (caso a caso) |
| **Após edital** | Se não comparece + não constitui defensor: **CPP 366** |

## CPP 360: citação de réu preso

| | Conteúdo |
|---|---|
| Regra | Citação **pessoal**: oficial vai ao estabelecimento prisional |
| Constitui defensor | Mesmo direito (defensor público se hipossuficiente) |
| Não comparecimento | Não há (está preso), processo prossegue |
| Não citação pessoal | **Nulidade absoluta** se houver cerceamento, STJ pacífico |

## Intimação (CPP 370-372)

| Quem | Forma |
|---|---|
| **Réu solto** | Pessoal (CPP 370 §1) OU correspondência com AR |
| **Réu preso** | Pessoal no estabelecimento (CPP 370 §4) |
| **Defensor constituído** | Por **publicação** na imprensa oficial (370 §1) |
| **Defensor público** + dativo | **Pessoal** (CPP 370 §4) |
| **MP** | Pessoal (370 §4) |
| **Querelante** | Por advogado |

### Sentença

| Quem | Necessidade |
|---|---|
| Réu **preso** | **Pessoal** (CPP 392 I), obrigatório para fluência do prazo |
| Réu **solto** | Pessoal OU edital |
| **Defensor** | Pessoal (público/dativo) OU publicação (constituído) |
| **Súm. 705 STF** | A renúncia do réu ao direito de apelação, manifestada **sem a assistência do defensor**, não impede o conhecimento da apelação por este interposta |

## Defensor dativo

| Quando | Conteúdo |
|---|---|
| Réu sem defensor após citação | Juiz nomeia |
| Defensor renuncia | Idem |
| **Honorários** | Pagos pela parte vencida ou pelo Estado |
| Intimação | **Pessoal** (CPP 370 §4) |

## Carta precatória + rogatória

| | Conteúdo |
|---|---|
| **Precatória** (CPP 353) | Réu em outra **comarca brasileira**: não suspende prazo |
| **Rogatória** (CPP 368) | Réu **no exterior**: **suspende** a prescrição até retorno cumprido |
| Réu **no exterior em local incerto** | Citação **por edital** (não rogatória) |

## Prazos

| Ato | Prazo (réu) |
|---|---|
| Resposta à acusação | **10 dias** (CPP 396) |
| Alegações finais | **5 dias** (CPP 403) |
| Recurso (apelação) | **5 dias** (CPP 593), razões em 8 dias |
| Recurso em sentido estrito | **5 dias** (CPP 586) |
| Habeas Corpus | Sem prazo |
| Revisão Criminal | Sem prazo |
| Embargos declaratórios | **2 dias** (CPP 619) |

## Citação eletrônica (Lei 11.419/2006 + CNJ Res. 354)

| | Conteúdo |
|---|---|
| Aplicabilidade | Processos digitais, partes cadastradas |
| Réu preso/civilmente solto | **Não substituível** por eletrônica salvo se cadastrada PJe Cidadão |
| Defensor com cadastro | Pode ser eletrônica |
| **Tendência** | Crescimento progressivo via CNJ + PJe |

## Anulações comuns

| Cenário | Saída |
|---|---|
| Sentença sem intimação pessoal do réu **preso** | **Nulidade absoluta** |
| Citação por edital sem esgotamento de pessoal | Nula |
| CPP 366 ignorado (continua processo sem comparecimento) | Nulidade |
| Intimação por publicação a **defensor público** | Nula (exige pessoal, 370 §4) |
| Defensor dativo não nomeado | Nula (cerceamento) |

## Erros a evitar

- Citar por edital sem **esgotar** tentativa pessoal + hora certa;
- Suspender prescrição **indefinidamente** no CPP 366, Súm. 415 STJ limita à prescrição pela pena máxima;
- Confundir CPP 366 (edital + ausência) com CPP 367 (revelia), efeitos opostos;
- Intimar defensor **público** ou dativo por **publicação** (exige pessoal, CPP 370 §4);
- Não intimar **pessoalmente** réu preso da sentença (CPP 392 I);
- Continuar processo ignorando CPP 366 quando há citação por edital + ausência;
- Aplicar **citação por hora certa** sem ocultação demonstrada;
- Confundir **carta precatória** (interestadual, não suspende) com **rogatória** (exterior, suspende);
- Não nomear defensor dativo após edital não respondido;
- Deixar de conhecer a apelação do defensor por renúncia do réu manifestada sem assistência técnica (Súm. 705 STF).

# Provas Ilícitas

## Base normativa

| | Conteúdo |
|---|---|
| **CF 5 LVI** | São **inadmissíveis** no processo as provas obtidas por meios ilícitos |
| **CPP 157** | Disciplina infralegal (Lei 11.690/2008) |
| Bem jurídico | Devido processo legal substancial + direitos fundamentais |

## CPP 157: definição

| | Conteúdo |
|---|---|
| **Caput** | "São inadmissíveis, devendo ser desentranhadas do processo, as provas ilícitas, assim entendidas as obtidas em **violação a normas constitucionais ou legais**" |
| Distinção operacional | **Ilícita** = viola norma material/substantiva; **Ilegítima** = viola norma processual |
| Tratamento atual | **Unificação**: ambas inadmissíveis |

## §1: Teoria dos frutos da árvore envenenada

| | Conteúdo |
|---|---|
| Texto | "São também inadmissíveis as provas **derivadas** das ilícitas, salvo quando não evidenciado o nexo de causalidade entre umas e outras OU quando as derivadas puderem ser obtidas por uma **fonte independente** das primeiras" |
| Origem | Construção jurisprudencial norte-americana (**Silverthorne Lumber Co. v. United States**, 1920), incorporada ao direito brasileiro via CPP 157 §1 |
| Princípio | Contaminação se propaga às provas derivadas |
| **Exceções** | (a) Ausência de nexo causal; (b) **fonte independente**; (c) **descoberta inevitável** (jurisprudência); (d) **prova lícita autônoma** |

## Exceções consagradas

### Fonte independente (§1 fine)

| | Conteúdo |
|---|---|
| Conceito | Prova obtida por **via paralela e legítima**, sem qualquer vínculo com a ilícita |
| **STF + STJ** | Reconhecem |
| Exigência | Demonstração concreta da via independente |

### Descoberta inevitável

| | Conteúdo |
|---|---|
| Conceito | Prova ilícita teria sido **inevitavelmente** descoberta por meios lícitos |
| Origem | **Nix v. Williams** (EUA, 1984) |
| Brasil | STJ admite com **cautela** (caso a caso) |
| Crítica | Risco de banalização |

### Prova ilícita PRO REO

| | Conteúdo |
|---|---|
| Princípio | **Admite-se** prova ilícita se necessária para **absolvição** (proporcionalidade) |
| **STF + STJ** | Pacífico |
| Fundamento | Dignidade + presunção de inocência prevalecem sobre a vedação |
| Caráter | Excepcional |

### Outras construções invocadas (não consolidadas)

| Construção | Conteúdo |
|---|---|
| **Boa-fé objetiva** | Invocada quando a polícia agiu com base em ordem judicial posteriormente declarada nula; **não adotada pelo STF/STJ**: o STJ mantém a inadmissibilidade mesmo reconhecendo boa-fé policial (REsp 1.574.681) |
| **Mera irregularidade** | Vício sanável que não atinge núcleo do direito |
| **Atenuação do nexo** | Tempo + intervenção da vontade do acusado (depoimento espontâneo) |

## §3: Desentranhamento

| | Conteúdo |
|---|---|
| **Obrigatório** | Após decisão sobre ilicitude |
| **Inutilização** | Prevista mas controvertida na prática |
| Preclusão | Decisão sobre desentranhamento pode ser preclusa para a parte que não recorreu |
| Recurso | Apelação ao final (não há recurso autônomo) |

## §5: Juiz que conhece a prova ilícita (declarado inconstitucional)

| | Conteúdo |
|---|---|
| Texto do §5 (Lei 13.964/2019) | "O juiz que conhecer do conteúdo da prova declarada inadmissível não poderá proferir a sentença ou acórdão" |
| **STF (ADI 6.298, j. 24/08/2023)** | Declarou o §5 do art. 157 **INCONSTITUCIONAL**: viola o princípio do juiz natural por ausência de critérios claros e objetivos de competência |
| Consequência | O juiz que conheceu da prova ilícita **PODE** proferir sentença ou acórdão |
| Imparcialidade | Eventual impedimento depende de análise concreta de parcialidade (não decorre automaticamente do §5) |
| **Juiz das Garantias (CPP 3-A, Lei 13.964/2019)** | Reforça, em outro plano, a separação entre quem atua na investigação e quem julga (declarado constitucional na ADI 6.298) |

## Casos paradigmáticos

| Cenário | Saída |
|---|---|
| Tortura para extrair confissão | **Ilícita** + frutos contaminados |
| Interceptação sem ordem judicial | **Ilícita** (CF 5 XII + Lei 9.296) |
| Acesso a celular sem consentimento ou ordem judicial | **Ilícita** (Tema 977 STF + RHC 51.531 STJ) |
| Confissão obtida por ameaça policial | Ilícita + descumprimento garantias |
| Busca domiciliar sem mandado/flagrante | Ilícita (Tema 280 STF se sem fundadas razões) |
| **WhatsApp Web** espelhamento sem ordem | Ilícita (RHC 99.735 STJ; matéria afetada a repetitivo) |
| Reconhecimento sem CPP 226 | **Inválido** (HC 598.886 STJ + Tema 1.258 STJ) |
| Filmagem em local público | **Lícita** (sem expectativa de privacidade) |
| Documento obtido por particular sem violação | Lícita (jurisprudência) |
| **Gravação por um interlocutor** | Lícita (STF Tema 237) |

## CPP 157 + nulidades

| | Conteúdo |
|---|---|
| Vício atinge **só a prova** | Inadmissibilidade + desentranhamento, preservados os atos independentes |
| A prova ilícita **embasou a condenação** | Anulação da sentença (fundamento essencial contaminado) |
| Recurso | Apelação + HC se preso |
| Revisão criminal | Cabe (CPP 621) |

## STJ HC 598.886 (2020): Reconhecimento de pessoas

| | Conteúdo |
|---|---|
| Tese | O **descumprimento das formalidades** do CPP 226 (alinhamento, semelhança, ausência de sugestão) gera **invalidade** do reconhecimento como prova |
| Reflexo | Reconhecimento isolado, viciado, não basta para condenar |
| Aplicação | Combate à condenação por reconhecimento fotográfico falho (vítimas de violência) |

## Inquérito × processo (extensão da regra)

| | Conteúdo |
|---|---|
| CPP 157 aplica-se em ambas as fases | Sim (CF 5 LVI: qualquer processo) |
| Prova ilícita no IP contamina denúncia? | Pode contaminar (depende do nexo) |
| Trancamento do IP/ação por HC | Cabível se base é prova ilícita |

## Erros a evitar

- Tratar como válida prova obtida por **interceptação clandestina** (CF 5 XII + Lei 9.296);
- Não aplicar a teoria dos **frutos da árvore envenenada** (CPP 157 §1): derivadas também são inadmissíveis;
- Admitir busca domiciliar sem **fundadas razões** registradas (Tema 280 STF);
- Admitir acesso a celular sem **consentimento ou ordem judicial** (Tema 977 STF);
- Rejeição de prova **pro reo** alegando ilicitude (princípio da proporcionalidade autoriza);
- Não aplicar **HC 598.886 STJ** em reconhecimento viciado;
- Omitir desentranhamento de prova após decisão de ilicitude (§3);
- Aplicar o §5 do art. 157 para afastar o juiz que conheceu da prova ilícita (declarado inconstitucional na ADI 6.298: o juiz pode julgar);
- Admitir **espelhamento WhatsApp Web** sem ordem (RHC 99.735 STJ);
- Aplicar **fonte independente/descoberta inevitável** sem demonstração concreta (banalização).

# Cooperação Jurídica Internacional em Matéria Penal

## Espécies

| Espécie | Finalidade |
|---|---|
| **Extradição** | Entrega de pessoa para responder/cumprir pena no Estado requerente |
| **Carta rogatória** | Atos de comunicação + diligências em outro Estado |
| **Homologação sentença estrangeira** | Reconhecer eficácia no Brasil |
| **Auxílio direto** | Atos diretos sem necessidade de exequatur (acordo bilateral/multilateral) |
| **Transferência de presos** | Cumprimento de pena em país de origem |
| **Repatriação de ativos** | Bloqueio + recuperação |

## Extradição

### Bases

| | Conteúdo |
|---|---|
| **CF 5 LI** | Brasileiro nato **nunca extraditado**; **naturalizado** só por crime comum cometido antes da naturalização OU comprovado envolvimento com tráfico |
| **CF 5 LII** | Estrangeiro nunca por crime **político** ou de **opinião** |
| **Lei 13.445/2017** (Migração) | Disciplina nova |
| **Competência** | **STF** (CF 102 I g) |
| Tratado vs reciprocidade | Brasil aplica via tratado ou compromisso de reciprocidade |

### Requisitos (Lei 13.445 art. 83-91)

- Existência de tratado ou promessa de reciprocidade;
- Crime previsto no ordenamento dos dois países (**dupla tipicidade**);
- Crime a que a lei brasileira comine pena de prisão não inferior a 2 anos (Lei 13.445/2017 art. 82 IV: veda-se a extradição quando a lei brasileira impuser ao crime pena de prisão inferior a 2 anos);
- Não-prescrição em ambos;
- Crime **comum** (não político);
- Não-extradição em razão de **raça, sexo, religião, opinião política**;
- **Compromisso de comutação** de pena de morte/prisão perpétua/corporal (CF + STF);
- Decisão final do STF.

### STF: pontos consolidados

| Tema | Conteúdo |
|---|---|
| **Cesare Battisti** (Ext 1.085) | Decisão presidencial sobre entrega, **discricionariedade vinculada** |
| Comutação | STF exige compromisso prévio do Estado requerente de observar o limite máximo de cumprimento no Brasil (CP 75: 40 anos desde a Lei 13.964/2019) |
| Detração | Período de prisão para extradição deve ser computado na pena |
| **Brasileiro nato** | **Vedada** em qualquer hipótese (cláusula pétrea) |
| **Crime político** | Conceito restritivo (jurisprudência do STF não equipara terrorismo a crime político para fins de extradição) |

## Carta rogatória (CPC 36 + Lei 13.445)

| | Conteúdo |
|---|---|
| **Função** | Solicitar diligência/atos a autoridade estrangeira |
| **Saída do Brasil** | Encaminhada via DRCI/MJ + canal diplomático |
| **Entrada no Brasil** | STJ, concessão de **exequatur** (CF 105 I i) |
| Conteúdo típico | Citação, intimação, oitiva, comunicação |
| Não admite | Atos de execução de sentença penal (caminho é homologação) |
| Prazos | Suspende prescrição (CPP 368 cita réu no exterior, durante rogatória) |

## Homologação de sentença estrangeira

| | Conteúdo |
|---|---|
| **Competência** | **STJ** (CF 105 I i) |
| **Procedimento** | CPC 960-965 + Reg. Int. STJ |
| Requisitos | Trânsito em julgado + autenticada/legalizada + tradução + observância da ordem pública/soberania |
| **Sentença penal estrangeira** | Pode ser homologada para efeitos civis (reparação dano, CP 9) ou de medida de segurança |
| **CP 9** | Sentença penal estrangeira pode ser executada no Brasil para obrigação de reparar dano + sujeição à medida de segurança |

## Auxílio direto

| | Conteúdo |
|---|---|
| Base | Tratados (MLAT) + Lei 13.445 art. 100 |
| Característica | **Dispensa exequatur**: execução direta pela autoridade brasileira |
| **DRCI/MJ** (Departamento de Recuperação de Ativos e Cooperação Internacional) | Autoridade central |
| **Vantagem** | Mais rápido + eficiente |
| Exemplos | Pedido de quebra de sigilo bancário, transferência de provas digitais, bloqueio de ativos |

## Validade da prova produzida no exterior (lex diligentiae)

| | Conteúdo |
|---|---|
| Parâmetro de validade | A **lei do Estado em que a prova foi produzida** (lex diligentiae, LINDB art. 13); a prova só é inadmitida no Brasil se o **meio de obtenção** violar a **ordem pública**, a **soberania nacional** ou os **bons costumes** |
| Presunção de legalidade | Material recebido por procedimento formal de cooperação (auxílio direto) presume-se legítimo; a Justiça brasileira **não controla os atos internos** do Estado requerido |
| Ônus da defesa | Indicar **base concreta de suspeita** contra a integridade ou a cadeia de custódia do material |
| Caso SKY ECC | Provas digitais do aplicativo transferidas pela França pelo Acordo promulgado pelo Decreto 3.324/1999 foram **validadas** (STJ, 6ª Turma, processo em segredo de justiça, Rel. Min. Rogerio Schietti Cruz, unânime, j. 06/05/2025, DJEN 19/05/2025) |

## MLAT: Mutual Legal Assistance Treaty

| | Conteúdo |
|---|---|
| Conceito | Tratado bilateral/multilateral de cooperação penal |
| Principais com Brasil | EUA (1997), Portugal, Itália, Espanha, França, China, México, Mercosul |
| **Convenção de Palermo** (ONU; ver Leis 12.694/2012 e 12.850/2013) | Crime organizado transnacional |
| **Convenção de Mérida** (UNCAC) | Corrupção |
| Convenção de Viena | Tráfico de drogas |
| Convenção de Budapeste (adesão do Brasil, vigência interna 2023) | Cibercrimes |

## Transferência de presos

| | Conteúdo |
|---|---|
| Base | Tratados bilaterais + Lei 13.445 |
| Objetivo | Permitir cumprimento de pena no país de nacionalidade |
| Requisitos | Acordo entre Estados + consentimento do preso + sentença transitada |
| Autoridade | **MJ + tribunal brasileiro** se preso vem para Brasil |

## Repatriação de ativos / bloqueio no exterior

| | Conteúdo |
|---|---|
| Base | Convenções (Mérida art. 31, 54) + tratados bilaterais |
| Solicitação | Brasil → STJ exequatur + auxílio direto |
| Recebimento | DRCI + MPF (atribuição) |
| **Lei 12.846** (anticorrupção) | Acordo de leniência pode envolver repatriação |
| **Lei 9.613** (lavagem) | Bloqueio de ativos no exterior via cooperação |

## Provider estrangeiro: entrega de dados

| | Conteúdo |
|---|---|
| **STF ADC 51** (Plenário, j. 23/02/2023) | Constitucional a **requisição direta** de dados a provedores com representação no Brasil, nas hipóteses do art. 11 do Marco Civil e do art. 18 da Convenção de Budapeste, sem necessidade de recorrer ao MLAT; empresas que operam no Brasil sujeitam-se à jurisdição nacional ainda que os dados estejam em servidores no exterior |
| Marco Civil + LGPD | Aplicam-se |
| **CLOUD Act** (EUA) | Compatibilidade com MLAT, auxílio direto facilitado |
| **Google + Microsoft + Meta** | Atendem ordens brasileiras via canais oficiais (controvérsia sobre alcance) |

## Convenção de Budapeste (adesão do Brasil, vigência interna 2023)

| | Conteúdo |
|---|---|
| Brasil aderiu | **Convenção de Budapeste sobre Cibercrime** vigência interna **2023** |
| Cooperação | Coleta expedita de dados + preservação + interceptação |
| Reflexo | Acelera cooperação em crimes cibernéticos |

## Erros a evitar

- Encaminhar atos para Estado estrangeiro **diretamente** sem DRCI/MJ ou exequatur do STJ;
- Confundir **carta rogatória** com **homologação**: uma é diligência, outra é eficácia;
- Aceitar extradição de **brasileiro nato** (vedada, CF 5 LI);
- Não exigir **comutação** de pena de morte/perpétua no compromisso de extradição;
- Aplicar **auxílio direto** sem base em tratado/MLAT, pode ser nulo;
- Não aplicar **CP 9** para homologação de sentença penal estrangeira (reparação + medida de segurança);
- Considerar **terrorismo** como crime político (jurisprudência do STF, não é, para fins de extradição);
- Confundir competência: extradição = STF; homologação = STJ; rogatória passiva = STJ (exequatur);
- Ignorar **Convenção de Budapeste** em crimes cibernéticos (vigência 2023);
- Tratar provedor estrangeiro como imune (STF ADC 51: requisição direta cabível a empresa com representação no Brasil).

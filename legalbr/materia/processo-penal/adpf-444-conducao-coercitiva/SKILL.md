# ADPF 444: Condução Coercitiva

## Identificação

| | Conteúdo |
|---|---|
| Ações | **ADPF 395 + ADPF 444** |
| Autores | PT (444) + Conselho Federal OAB (395) |
| Relator | Min. **Gilmar Mendes** |
| Julgamento | **14/06/2018** |
| Placar | **6×5** (procedente) |
| Vencidos | Mins. Edson Fachin, Luís Roberto Barroso, Luiz Fux, Cármen Lúcia, Alexandre de Moraes |

## Tese estruturante

| | Conteúdo |
|---|---|
| Resultado | **PROCEDENTES**: condução coercitiva para **INTERROGATÓRIO** do **INVESTIGADO/RÉU** é **INCONSTITUCIONAL** |
| Aplicação | A partir da decisão (não retroage para nulificar atos anteriores) |
| Cabimento residual | Testemunha **recusante** (CPP 218) |

## CPP 260

| | Conteúdo |
|---|---|
| Texto | "Se o **ACUSADO** não atender à intimação para o **INTERROGATÓRIO**, reconhecimento ou qualquer outro ato que, sem ele, não possa ser realizado, a autoridade poderá mandar conduzi-lo à sua presença" |
| Pós-ADPF | Aplicação **AFASTADA** quanto ao interrogatório do acusado |

## Distinções essenciais

| | Investigado/réu | Testemunha |
|---|---|---|
| Condução coercitiva | **VEDADA** (interrogatório) | **Cabível** se recusante (CPP 218) |
| Direito ao silêncio | **Sim** | Sim (parcial, em autoincriminação) |
| Compromisso | Não jura | Jura (CPP 203) |
| Mentira | **Direito** | **Falso testemunho** (CP 342) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Condução para interrogatório de investigado | **VEDADA** (ADPF 444) |
| Não comparecimento à intimação | Sem prejuízo, direito ao silêncio |
| Testemunha recusante | **Cabível condução** (CPP 218) |
| Reconhecimento pessoal | Cabível com cautelas |
| Acareação | Cabível |
| Identificação criminal | Cabível (Lei 12.037) |
| Coleta de DNA | Previsão legal (Lei 12.654); tese de RG pendente (Tema 905 STF) |
| Audiência de custódia | Compatível |
| Algemas | Excepcionais (SV 11) |
| Pena por não comparecer | Não há, direito ao silêncio |

## Erros a evitar

- A **condução coercitiva** de investigado para interrogatório é inconstitucional (ADPF 444);
- O **silêncio** não pode ser tratado como confissão tácita (CPP 186 § ún);
- O **investigado** não se confunde com a **testemunha** (regimes distintos);
- O CPP 260 não se aplica integralmente: sofre o filtro da ADPF 444;
- O **não comparecimento** à intimação não configura, por si só, obstrução à Justiça;
- A condução **disfarçada de reconhecimento** é vedada;
- O uso de **algemas** restringe-se às hipóteses da SV 11;
- Tratar a coleta de **DNA** como vedada: há previsão legal (Lei 12.654), com tese de RG ainda pendente (Tema 905 STF);
- O **falso testemunho** não alcança o investigado que mente (este não presta compromisso);
- A **audiência de custódia** não se confunde com condução coercitiva (institutos distintos).

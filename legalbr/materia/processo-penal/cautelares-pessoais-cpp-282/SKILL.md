# Medidas Cautelares Pessoais

## Marco normativo

| | Conteúdo |
|---|---|
| **Lei 12.403/2011** | Reescreveu CPP 282-300 + 319-350 |
| **Lei 13.964/2019** (Pacote Anticrime) | Sistema acusatório (CPP 3-A) + vedação de ofício |
| **Lei 15.272/2025** | Critérios objetivos de periculosidade (CPP 312 §3) + vedação expressa da gravidade abstrata (CPP 312 §4) + circunstâncias da conversão do flagrante (CPP 310 §§5-6) |
| **Lei 15.358/2026** (Antifacção) | Nova hipótese de preventiva: CPP 313 V (organização criminosa ultraviolenta, grupo paramilitar ou milícia privada) |

## CPP 282: REQUISITOS GERAIS

| | Conteúdo |
|---|---|
| **I** | **NECESSIDADE** para aplicação da lei penal + investigação + ordem pública/econômica |
| **II** | **ADEQUAÇÃO** à gravidade + circunstâncias do fato + condições pessoais |
| **§1** | **Substituibilidade** |
| **§2** | **VEDAÇÃO ao DECRETO de OFÍCIO** (Lei 13.964 + ADIs 6.298-6.305 STF) |
| **§3** | Legitimados: **MP + querelante + assistente + autoridade policial** (representação) |
| **§4** | Descumprimento → substituição + cumulação + preventiva |
| **§5** | Vedada **substituição AUTOMÁTICA** |
| **§6** | **CONTRADITÓRIO PRÉVIO** + preventiva como ***ULTIMA RATIO*** |

## CPP 311-313: PREVENTIVA

| | Conteúdo |
|---|---|
| Requisitos cumulativos | Prova de **materialidade** + indícios de **autoria** + **PERIGO CONCRETO + CONTEMPORANEIDADE** (fumus + periculum, CPP 312 caput e §2) |
| Cabimento (CPP 313) | Dolosos com **pena máxima > 4 anos** (I) + reincidente em crime doloso (II) + violência doméstica para garantir protetivas (III) + **integrante de organização criminosa ultraviolenta, grupo paramilitar ou milícia privada (V, Lei 15.358/2026)** + dúvida sobre identidade civil (§1) |
| Descumprimento de cautelar diversa | Autoriza preventiva (CPP 312 §1 c/c 282 §4) |
| Periculosidade (CPP 312 §3, Lei 15.272/2025) | Aferida por: *modus operandi* (violência reiterada/premeditação) + participação em organização criminosa + natureza/quantidade de drogas, armas ou munições + fundado receio de reiteração (outros inquéritos/ações em curso) |
| Gravidade abstrata (CPP 312 §4, Lei 15.272/2025) | **Incabível** preventiva com base em gravidade abstrata: exige demonstração concreta da periculosidade e do risco |
| Vedação (CPP 313 §2) | Preventiva não pode servir de **antecipação de pena** nem decorrer automaticamente da investigação ou da denúncia |

## CPP 316 par. único (Lei 13.964): REVISÃO 90 DIAS

| | Conteúdo |
|---|---|
| Regra | **Reanálise obrigatória a cada 90 DIAS** pelo **órgão emissor** |
| Sob pena | **Ilegitimidade** |
| **STF SL 1.395 MC-Ref (caso do HC 191.836) + ADIs 6.581/6.582** | Decurso do prazo **NÃO gera soltura automática**: o juízo competente deve ser instado a reavaliar a legalidade e a atualidade dos fundamentos |
| Alcance (ADIs 6.581/6.582) | A exigência vale **até o encerramento da cognição plena pelo tribunal de 2º grau** (inclusive na pendência de apelação) e alcança o **foro por prerrogativa**; não se aplica às prisões decorrentes de sentença condenatória de 2ª instância nem à fase de REsp/RE |
| **STJ HC 589.544** | Dever do **órgão que decretou** a prisão (leitura ajustada ao alcance definido pelo STF); a revisão nonagesimal **não se estende às cautelares diversas** (jurisprudência do STJ) |

## CPP 319: CAUTELARES DIVERSAS DA PRISÃO (9 incisos)

| Inc. | Cautelar |
|---|---|
| **I** | **Comparecimento periódico** |
| **II** | Proibição de acesso/frequência |
| **III** | Proibição de **manter contato** |
| **IV** | Proibição de **ausentar-se** da comarca |
| **V** | **Recolhimento DOMICILIAR NOTURNO** + finais de semana |
| **VI** | **Suspensão** do exercício de função pública/atividade econômica |
| **VII** | **INTERNAÇÃO PROVISÓRIA** (inimputável/semi) |
| **VIII** | **Fiança** |
| **IX** | **MONITORAÇÃO ELETRÔNICA** |

## CPP 320: passaporte

Entrega + **proibição de sair do país**.

## Proporcionalidade + subsidiariedade

| | Conteúdo |
|---|---|
| **Preventiva** | **EXCEÇÃO** (*ultima ratio*, CPP 282 §6) |
| Cautelares menos gravosas | **Preferidas** |
| **ADPF 347** | Audiência de custódia em **24h** (Res. CNJ 213) |
| **Tema 1.068 STF** (RE 1.235.340) | Execução imediata da condenação pelo Tribunal do Júri, **independentemente do total da pena** (soberania dos veredictos); afastado o limite mínimo de 15 anos do CPP 492 |

## Maria da Penha (Lei 11.340 arts. 22-24)

| | Conteúdo |
|---|---|
| Aplicação | **IMEDIATA**, sem oitiva prévia do agressor |

## Distinções essenciais

| | Preventiva | Cautelar diversa |
|---|---|---|
| Caráter | Excepcional | **Preferida** |
| Subsidiariedade | Sim | Não |

| | Pré-Lei 13.964 | Pós (2020) |
|---|---|---|
| De ofício | Permitido | **VEDADO** |
| Revisão 90d | Não | **Obrigatória** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Sem prova/indícios | **Liberdade** |
| Periculum concreto | Cautelar |
| Pena máx > 4a | **Preventiva possível** (CPP 313 I) |
| Organização criminosa ultraviolenta/milícia | Preventiva possível (CPP 313 V, Lei 15.358/2026) |
| Descumprimento de cautelar | Preventiva (CPP 312 §1) |
| Não revisada > 90d | Não solta automático (SL 1.395 + ADIs 6.581/6.582), mas exige revisão |
| Reanálise após condenação de 2ª instância ou em REsp/RE | Não exigida (ADIs 6.581/6.582) |
| VD imediata | Lei 11.340 + Lei 14.550 |
| Sem inquérito | Lei 14.550: protetivas autônomas |
| Decretação de ofício | **NULIDADE** (Lei 13.964) |
| Cautelares menos gravosas | Preferidas |
| Audiência de custódia | **24h** (ADPF 347) |

## Erros a evitar

- **Decretar PREVENTIVA de OFÍCIO** (Lei 13.964/2019 + ADIs 6.298-6.305 vedam);
- **Não revisar a cada 90 dias** (CPP 316 par. único);
- Aplicar cautelar **DESPROPORCIONAL** (gravidade abstrata insuficiente, CPP 312 §4);
- Aplicar fiança a **crime inafiançável** (CF 5 XLII-XLIV);
- Soltar **automaticamente** após 90d sem revisão (SL 1.395 + ADIs 6.581/6.582: não há soltura automática);
- Aplicar **revisão de 90d a cautelares diversas** (jurisprudência do STJ: só à preventiva);
- Tratar **preventiva como REGRA** (é exceção);
- Usar a preventiva como **antecipação de pena** (CPP 313 §2);
- **Substituir automaticamente** sem fundamentação (CPP 282 §5);
- Negar **contraditório prévio** (CPP 282 §6) fora das hipóteses de urgência;
- Não aplicar **Lei 14.550 (protetivas autônomas)**, vinculando-as indevidamente a inquérito;
- Decretar preventiva por descumprimento **sem demonstrar o descumprimento concreto** da cautelar diversa (CPP 312 §1);
- Ignorar os **critérios de periculosidade do CPP 312 §3** (Lei 15.272/2025) na fundamentação.

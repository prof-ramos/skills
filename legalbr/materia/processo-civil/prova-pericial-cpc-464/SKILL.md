# Prova Pericial

## CPC 464, CABIMENTO

| | Conteúdo |
|---|---|
| Hipótese | Quando a prova do fato depender de **conhecimento técnico ou científico** |
| Espécies | **Exame** (sobre coisas, pessoas); **Vistoria** (in loco); **Avaliação** (valor) |
| **§1** | Indeferida quando: I não depender de conhecimento especial; II desnecessária ante outras provas; III verificação impraticável |

## CPC 464 §§2-4, PERÍCIA SIMPLIFICADA (INFORMAL)

| | Conteúdo |
|---|---|
| **§2** | De ofício ou a requerimento, substituível por **prova técnica simplificada** quando o ponto controvertido for de **menor complexidade** |
| **§3** | Consiste na **inquirição de especialista pelo juiz** sobre o ponto controvertido |
| **§4** | Especialista com **formação acadêmica específica**; pode valer-se de recursos tecnológicos de som e imagem |
| Função | **Celeridade** + economia em causas de menor complexidade |

## CPC 471, PERÍCIA CONSENSUAL

| | Conteúdo |
|---|---|
| Hipótese | **Acordo** das partes (plenamente capazes + direitos disponíveis) |
| Forma | Termo nos autos + perito escolhido em comum |
| Efeito | **Substitui** a perícia oficial, laudo vincula |
| Vantagem | Reduz custos + acelera |

## CPC 465, NOMEAÇÃO DO PERITO

| | Conteúdo |
|---|---|
| Forma | Decisão judicial, perito **especialista** na matéria |
| **§1** | Em 15 dias as partes podem: I arguir impedimento/suspeição; II indicar **assistente técnico**; III apresentar **quesitos** |
| **§2** | Perito apresenta **em 5 dias**: proposta de honorários + currículo com especialização + contatos (endereço eletrônico) |
| **§3** | Partes manifestam-se em **5 dias** sobre a proposta; após, o juiz **arbitra** o valor |
| **§4** | Juiz pode autorizar pagamento de **até 50%** dos honorários no início; o restante, só após laudo + esclarecimentos |
| **§5** | Perícia **inconclusiva ou deficiente**: juiz pode **reduzir** a remuneração |

## CPC 466, IMPEDIMENTO E SUSPEIÇÃO DO PERITO

| | Conteúdo |
|---|---|
| Aplica-se | CPC 148 II |
| **Recusa motivada** | 5 dias (CPC 467) |
| Substituição | Em caso de impedimento, suspeição ou impossibilidade |

## CPC 467, DEVERES E RECUSA

| | Conteúdo |
|---|---|
| Perito **deve cumprir** o encargo no prazo, observando o conhecimento técnico |
| Recusa | Motivo: I impedimento; II falta de conhecimento técnico para a perícia; III motivo legítimo |

## CPC 468, SUBSTITUIÇÃO

| Hipótese | Conteúdo |
|---|---|
| I | Quando faltar conhecimento técnico ou científico |
| II | Sem motivo legítimo, deixar de cumprir o encargo no prazo |
| **§1** | No caso do inciso II: comunicação ao órgão profissional + possibilidade de **multa** (fixada conforme o valor da causa e o prejuízo) |
| **§2** | Perito substituído **restitui em 15 dias** os valores recebidos, sob pena de execução |

## CPC 469, QUESITOS COMPLEMENTARES

| | Conteúdo |
|---|---|
| Hipótese | Surgindo durante a perícia, partes podem apresentar |
| Prazo | Durante a diligência |

## CPC 470, DECISÃO SOBRE QUESITOS

| | Conteúdo |
|---|---|
| Juiz | Pode **indeferir** quesitos impertinentes, irrelevantes, repetitivos |
| Pode **formular** quesitos próprios |

## CPC 472, DISPENSA

| | Conteúdo |
|---|---|
| Hipótese | Prova suficientemente esclarecida por outros elementos OU pareceres técnicos juntados pelas partes |

## CPC 473, REQUISITOS DO LAUDO

| Inciso | Conteúdo |
|---|---|
| **I** | Exposição do objeto |
| **II** | Análise técnica ou científica |
| **III** | Indicação do método utilizado |
| **IV** | **Resposta conclusiva** a todos os quesitos |
| **§1** | Linguagem **simples** + coerência lógica |
| **§2** | Vedado ao perito **ultrapassar os limites de sua designação** e emitir opiniões pessoais que excedam o exame técnico |

## CPC 477, APRESENTAÇÃO + MANIFESTAÇÃO

| | Conteúdo |
|---|---|
| Prazo | **20 dias** antes da audiência (CPC 477) |
| **§1** | Partes têm **15 dias** para manifestar-se + **assistentes técnicos** para **parecer** |
| **§2** | Perito **deve esclarecer** se solicitado em 15 dias |
| **§3** | Em audiência, perito comparece se houver insuficiência |

## CPC 480, NOVA PERÍCIA

| | Conteúdo |
|---|---|
| Cabimento | Quando matéria **não esclarecida** OU **suspeita de erro** |
| Decisão | Judicial fundamentada |
| Não invalida primeira | Coexistirão para análise |

## HONORÁRIOS PERICIAIS

| | Conteúdo |
|---|---|
| **Quem paga** | Quem requereu a perícia; **rateio** quando determinada de ofício ou requerida por ambas as partes (CPC 95 caput) |
| **Beneficiário** da gratuidade | Honorários custeados na forma do **CPC 95 §3** (recursos do ente público ou tabela), admitido diferimento |
| **JEF** | Honorários periciais antecipados pelo Estado em ações previdenciárias (Lei 10.259/2001) |

## Falsidade do laudo

| | Conteúdo |
|---|---|
| Configurada | Pode ser impugnada via incidente (CPC 430) |
| Crime | Perícia falsa = **falso testemunho** (CP 342) |
| Sanção | Multa (CPC 468) + substituição |

## Convencimento motivado

| | Conteúdo |
|---|---|
| **CPC 479** | Juiz **não fica adstrito** ao laudo, pode formar livre convicção (motivada) |
| Discordância | Deve fundamentar (CPC 489 §1 V) |

## Assistente técnico

| | Conteúdo |
|---|---|
| Indicação | CPC 465 §1 II |
| Função | Acompanhar perícia + emitir parecer técnico |
| **NÃO substitui** perito | É auxiliar da parte (não juramentado) |
| Honorários | Pagos pela própria parte |

## Notas atuais

| | Conteúdo |
|---|---|
| **CPC 471** | Perícia consensual (partes capazes, direitos disponíveis) |
| **CPC 95 §3** | Custeio da perícia em favor do beneficiário da gratuidade |
| **CNJ Res. 233/2016** | Cadastro nacional de peritos |
| **CPC 479** | Juiz pode contrariar o laudo, com fundamentação (CPC 489 §1 V) |
| **CPC 469** | Quesitos suplementares válidos durante a diligência |

## Roteiro de análise

1. Aferição da **necessidade** da perícia (CPC 464);
2. Cabimento da perícia **simplificada** (§§ 2-4) ou **consensual** (CPC 471);
3. Nomeação do **perito** e abertura do prazo do CPC 465 §1 (impedimento, assistente, quesitos);
4. **Honorários** e responsabilidade pelo adiantamento (CPC 95);
5. **Laudo** apresentado 20 dias antes da audiência (CPC 477);
6. **Manifestação** das partes e parecer dos assistentes;
7. Audiência, quando necessária;
8. O laudo **não vincula** o julgamento (CPC 479), exigida fundamentação.

## Erros a evitar

- O prazo de **15 dias** para quesitos e assistente é obrigatório (CPC 465 §1);
- A **vista** do laudo às partes é devida (CPC 477 §1);
- A **discordância** do laudo exige fundamentação (CPC 489 §1 V);
- O indeferimento de perícia **necessária** gera cerceamento (a Súm. 7 STJ não obsta REsp);
- A perícia consensual cabe em **direitos disponíveis** com acordo das partes (CPC 471);
- A **multa do CPC 468** incide sobre o perito que descumpre o encargo;
- A **falta de capacitação** técnica do perito enseja substituição;
- O laudo **não é vinculante** (CPC 479);
- O pedido de esclarecimentos deve ser atendido (CPC 477 §2);
- O perito é auxiliar do juízo, não vinculado à parte (CPC 156).

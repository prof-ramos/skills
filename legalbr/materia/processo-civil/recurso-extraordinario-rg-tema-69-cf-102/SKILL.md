# Recurso Extraordinário (CF 102 III)

## Base normativa

| | Conteúdo |
|---|---|
| **CF 102 III "a"** | Contra decisão contrária a dispositivo da CF |
| **CF 102 III "b"** | Declarar inconstitucionalidade de tratado ou lei federal |
| **CF 102 III "c"** | Julgar válida lei/ato governo local contestada na CF |
| **CF 102 III "d"** | Lei local contestada em face de lei federal |
| **CF 102 §3** | **REPERCUSSÃO GERAL** como requisito |
| **CPC art. 1.029** | Procedimento do RE |
| **CPC art. 1.036+** | Repetitivos |
| **Lei 11.418/2006** | Regulamentou RG |
| **Súmula 282 STF** | Prequestionamento explícito |
| **Súmula 356 STF** | Embargos de declaração para prequestionar |

## Requisitos do RE

| Requisito | Conteúdo |
|---|---|
| **Cabimento** | CF 102 III + decisão de **última ou única instância** |
| **Prequestionamento** | Matéria constitucional debatida no acórdão recorrido (Súms. 282 e 356) |
| **Repercussão geral** | Demonstração de relevância econômica + política + social + jurídica |
| **Sucumbência recursal** | Cabível |
| **Tempestividade** | 15 dias úteis (CPC 1.003 §5) |
| **Capacidade postulatória** | Advogado |

## Repercussão Geral

| Aspecto | Conteúdo |
|---|---|
| **Conceito** | Relevância econômica + política + social + jurídica que ultrapasse interesses subjetivos |
| **Análise** | Pelo plenário virtual STF (Lei 11.418) |
| **Reconhecimento** | Necessário para conhecimento do RE |
| **Rejeição** | Decisão **irrecorrível** |
| **Casos repetitivos** | Sistema dos repetitivos (CPC 1.036+) |

## Aplicação prática

| Hipótese | Saída |
|---|---|
| RE sobre matéria de direito federal sem fundo constitucional | Inadmissível (cabe REsp) |
| RE com prequestionamento explícito | Cabível |
| RE sem demonstração de RG | **Inadmissível** |
| RE em JEC | Tema 800 STF: presunção de inexistência de RG |
| RE contra decisão estadual aplicando lei federal contrária à CF | **Cabível** (102 III "d") |
| RE contra decisão que aplicou lei contestada em ADC | Cabível |

## Casos correlatos

| | Conteúdo |
|---|---|
| **Lei 11.418/2006** | RG |
| **CPC 1.029-1.040** | Procedimento |
| **Tema 800 STF** | JEC + presunção |
| **Súms. 282 + 356 STF** | Prequestionamento |
| **CPC 988** | Reclamação |
| **CPC 927** | Precedentes vinculantes |

## Erros a evitar

- Admitir RE **sem prequestionamento** (Súm. 282);
- Admitir RE **sem demonstração de RG** (Tema 800 + CF 102 §3);
- Em JEC: aplicar regras gerais sem analisar Tema 800;
- Conhecer RE em matéria **infraconstitucional pura** (cabe REsp);
- Em RE com prequestionamento via embargos de declaração: aceitar (Súm. 356).

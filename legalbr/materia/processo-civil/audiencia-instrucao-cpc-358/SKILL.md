# Audiência de Instrução e Julgamento

## Marco normativo

| | Conteúdo |
|---|---|
| **CPC 358-368** | Disciplina da AIJ |
| **Posicionamento** | Posterior ao **saneamento** (CPC 357) |
| **Princípios** | Oralidade + concentração + imediação + publicidade (CPC 11) |
| Identidade física do juiz | **MITIGADA** pelo CPC/2015: sem vinculação obrigatória (jurisprudência do STJ) |

## Ordem das provas orais (CPC 361)

| Inc. | Ato |
|---|---|
| **I** | **Esclarecimentos do perito** + assistentes técnicos (quesitos do art. 477) |
| **II** | **Depoimento pessoal** das partes: autor + réu |
| **III** | **Inquirição de testemunhas**: autor + réu |

A ordem é **preferencial** (caput).

Inversão da ordem → **nulidade relativa** (dependente de prejuízo).

**Perito**: requerimento de comparecimento com quesitos (CPC 477 §3); intimação eletrônica com **10 dias** de antecedência (CPC 477 §4). Negar esclarecimentos tempestivos → **cerceamento de defesa**.

## Conciliação, alegações, encerramento

| Art. | Conteúdo |
|---|---|
| **359** | Tentativa de conciliação na abertura (omissão não anula por si) |
| **364** | **Alegações finais orais**: **20 min**, prorrogáveis por 10; litisconsortes dividem o prazo (§1) |
| **364 §2** | Causa complexa: **memoriais escritos** em prazos **sucessivos de 15 dias**, assegurada vista |
| **365** | Audiência **una e contínua**; cindida apenas em caráter excepcional e justificado |
| **366** | Encerrado o debate/razões finais: sentença **na audiência** OU em **30 dias** |

## Videoconferência

| | Conteúdo |
|---|---|
| **Res. CNJ 354/2020** + **481/2022** | Consolidou como **modalidade ordinária** |
| **CPC 236 §3** + **385 §3 + 453 §1** | Admitem expressamente |
| Jurisprudência | A videoconferência não viola, por si só, contraditório e imediação |
| Requisitos | Equipamento adequado + conexão estável + ambiente reservado |
| Recusa imotivada | Pode gerar **nulidade** quando a parte demonstra impossibilidade física de comparecer |

## Depoimentos

| | Conteúdo |
|---|---|
| **Depoimento pessoal** (CPC 385) | Ausência injustificada → **confissão ficta** (§1): exige intimação pessoal com **advertência expressa** |
| **Interrogatório livre** (CPC 139 VIII) | Sem risco de confissão tácita |

## Testemunhas (CPC 442-457)

| | Conteúdo |
|---|---|
| Limite | **10 por parte + 3 por fato** (CPC 357 §6) |
| Substituição | Vedada após o rol (salvo CPC 451) |
| **Contradita** (CPC 447) | Arguida **antes** do depoimento |

## Sistema presidencialista (CPC 459)

| | Conteúdo |
|---|---|
| Perguntas | Formuladas **DIRETAMENTE** pelas partes à testemunha |
| Juiz | Só intervém para **indeferir impertinentes/vexatórias** (CPC 458) |
| Sistema antigo (todas as perguntas pelo juiz) | Superado pelo modelo de perguntas diretas (CPC 459) |

## Lei 14.245/2021 (Lei Mariana Ferrer)

| | Conteúdo |
|---|---|
| Aplicação | Vedação de manifestações ofensivas à dignidade de vítimas/testemunhas |
| Subsidiária | Ao processo civil (origem no processo penal) |
| Dever do juiz | Coibir constrangimento |
| Omissão | Pode ensejar responsabilidade disciplinar e nulidade do ato |

## Poder de polícia (CPC 360) + registro

| | Conteúdo |
|---|---|
| Poderes (CPC 360) | Manter **ordem e decoro** + retirar quem se comportar inconvenientemente + requisitar força policial + urbanidade + registrar em ata os requerimentos |
| **CPC 368** | A audiência é **pública**, ressalvadas as exceções legais |
| Oitiva fora da sede | Carta precatória ou **videoconferência** (CPC 453 §1) |
| **Acareação** (CPC 461 II) | Possível na audiência |
| **Inspeção judicial** (CPC 481) | Possível |

## Síntese: fluxo

1. **Tentativa de conciliação** (CPC 359);
2. **Esclarecimentos do perito** (CPC 361 I);
3. **Depoimento pessoal das partes** (CPC 361 II: autor + réu);
4. **Inquirição de testemunhas** (CPC 361 III: autor + réu);
5. **Acareação/inspeção** se necessárias;
6. **Alegações finais orais** (CPC 364): 20 min + 10 prorrogáveis;
7. OU **memoriais escritos** (CPC 364 §2): prazos sucessivos de 15 dias;
8. **Sentença** na audiência OU em 30 dias (CPC 366).

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Causa com prova oral | **Designar AIJ** obrigatoriamente |
| Esclarecimentos do perito | Tempestivos → **cerceamento** se negados |
| Depoimento pessoal ausente | **Confissão ficta** se houve advertência |
| Testemunha proibida (CPC 447) | Contradita antes do depoimento |
| Perguntas pelo juiz | **Sistema presidencialista**: só impertinentes |
| Constrangimento da vítima | **Vedado** (Lei 14.245) |
| Videoconferência sem fundamentação para negar | **Nulidade** |
| Causa complexa | Memoriais (CPC 364 §2) |
| Identidade física do juiz | **Mitigada** (CPC/2015) |

## Erros a evitar

- **Julgar antecipadamente** causa com prova oral relevante requerida (cerceamento de defesa);
- **Inverter a ordem do CPC 361** sem justificativa, com prejuízo (nulidade relativa);
- **Rejeitar esclarecimentos periciais** tempestivos (cerceamento);
- **Admitir constrangimento** à vítima (Lei 14.245);
- **Recusar videoconferência** sem fundamentação concreta;
- Ausência de **advertência sobre confissão ficta** na intimação para depoimento pessoal;
- **Reassumir condução de perguntas** em sistema presidencialista (CPC 459);
- Encerramento da instrução **sem oportunizar memoriais** em causa complexa (CPC 364 §2);
- Inadmitir **substituição de testemunha** em hipóteses do CPC 451;
- Realização de audiência **sem 10 dias** de antecedência ao perito (CPC 477 §4);
- Omitir concessão de **20 min** de alegações orais (CPC 364).

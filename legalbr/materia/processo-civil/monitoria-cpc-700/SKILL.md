# Ação Monitória

## Cabimento (CPC 700)

| Inc. | Hipótese |
|---|---|
| I | Pagamento de **quantia em dinheiro** |
| II | Entrega de **coisa fungível/infungível** ou bem móvel/imóvel determinado |
| III | Adimplemento de obrigação de **fazer ou não fazer** |

**Base**: **prova escrita SEM eficácia de título executivo**.

| § | Conteúdo |
|---|---|
| §1 | Petição com valor devido + memória de cálculo |
| §2 | Autor pode **optar pelo procedimento comum** |
| §4 | Cabe **tutela provisória** em monitória |

## Prova escrita: espécies admitidas

| | Conteúdo |
|---|---|
| Contrato sem 2 testemunhas | Não é título extrajudicial (CPC 784 III a contrario) |
| **Cheque prescrito** | Súm. 299 STJ |
| **Nota promissória sem força executiva** | Súm. 504 STJ |
| Contrato de abertura de crédito + demonstrativo | **Súm. 247 STJ** |
| Contrato educacional + histórico escolar | Admitido na jurisprudência |
| **E-mails + documentos eletrônicos** | Admitidos pelo STJ quando não houver impugnação séria da autenticidade |
| Assinatura eletrônica | STJ: credenciamento ICP-Brasil **NÃO é indispensável** |
| WhatsApp/prints | Admitidos pela jurisprudência atual |

**STJ**: não se exigem certeza/liquidez/exigibilidade plenas; basta prova escrita que torne verossímil o direito alegado.

## Procedimento (CPC 701)

| Etapa | Conteúdo |
|---|---|
| Mandado | **15 dias** para pagar/entregar |
| **Paga em 15 dias** | **5% honorários** sobre o valor + **ISENÇÃO de custas** (§1) |
| **Inerte** | Constitui-se **título executivo judicial AUTOMATICAMENTE** (§2): segue cumprimento (CPC 523+) |
| **Embarga** | Suspende eficácia do mandado até julgamento |
| **Parcelamento** | Depósito de 30% + 5% honorários + 6 parcelas + juros 1%/mês |

## CPC 702: Embargos

| | Conteúdo |
|---|---|
| Prazo | **15 dias** |
| Garantia | **Independem** de prévia segurança do juízo |
| Matéria | **Ampla** (similar ao procedimento comum) |
| Rejeitados | Prossegue-se com o título executivo (701 §2); honorários conforme o CPC 85 |
| §4 | **Suspendem** eficácia do mandado |
| STJ | A impugnação deve ser **fundamentada e específica** |

## Fazenda Pública

| | Conteúdo |
|---|---|
| **Súm. 339 STJ** | **Cabível** monitória contra Fazenda |
| Procedimento adaptado | **Remessa necessária** (CPC 496) |
| Pagamento | Via **precatório/RPV** (CPC 534-535) |
| **Incompatível** | Juizado Especial da Fazenda |
| **STJ** | **NÃO há isenção** de honorários por pagamento em 15 dias (incompatível com regime do precatório) |

## Prescrição

| | Prazo |
|---|---|
| **Cheque sem força executiva** | **5 anos** do dia seguinte à emissão (**Súm. 503 STJ** + CC 206 §5 I) |
| **Nota promissória** | **5 anos** do dia seguinte ao vencimento (**Súm. 504 STJ**) |
| **Cheque executável** | 6 meses; após = 2 anos ação cambial; após = **5 anos monitória** |
| **Regra geral** | CC 206 §5 I: 5 anos para dívida líquida em instrumento |

## Correção + juros (STJ)

| | Conteúdo |
|---|---|
| Dívida líquida + termo certo | Correção + juros **do vencimento** |
| Cheque não apresentado | Juros do **primeiro ato para satisfação** (citação) |
| Fazenda | **Tema 905 STJ** rege |

## Natureza jurídica

| | Conteúdo |
|---|---|
| Tipo | Procedimento especial de **cognição sumária + plena eventual** (se houver embargos) |
| Híbrido | Conhecimento + execução |
| Constitucionalidade | STF admite: contraditório diferido válido |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Cheque prescrito | **Monitória** (Súm. 299 STJ) |
| Nota promissória prescrita | Monitória (Súm. 504) |
| Contrato sem 2 testemunhas | Monitória |
| E-mail/WhatsApp | Monitória (STJ) |
| Pago em 15 dias | **5% honorários + isenção custas** |
| Inerte | **Título executivo automático** |
| Embargos rejeitados | Honorários conforme CPC 85 |
| Contra Fazenda | **Cabível** (Súm. 339): sem isenção de honorários |

## Erros a evitar

- **Rejeitar liminarmente** sem oportunizar emenda (CPC 321), STJ exige emenda quando prova insuficiente;
- Confundir prazos: aplicar **3 anos** (CC 206 §3 VIII) quando é **5 anos** (Súms. 503-504);
- Não reduzir honorários a **5%** no pagamento tempestivo (CPC 701 §1);
- **Não constituir automaticamente** título executivo após inércia do réu (CPC 701 §2, *ope legis*);
- Admitir **embargos genéricos** sem fundamentação específica;
- Recusar **documentos eletrônicos** (e-mail + WhatsApp) por ausência de ICP-Brasil, contra STJ atual;
- Aplicar **procedimento comum à Fazenda** quando cabível monitória (Súm. 339);
- Afastar **tutela provisória** em monitória (CPC 700 §4 admite);
- Não suspender eficácia do mandado com **embargos** (CPC 702 §4);
- Concessão de **isenção de custas/honorários** à Fazenda (incompatível com precatório).

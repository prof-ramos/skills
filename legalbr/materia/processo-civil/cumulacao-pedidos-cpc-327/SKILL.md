# Cumulação de Pedidos

## CPC 327, REGRA GERAL

| | Conteúdo |
|---|---|
| Regra | É **lícita** a cumulação, num mesmo processo, contra o mesmo réu, de **vários pedidos** |
| Pressuposto | Mesmo réu (cumulação **objetiva**), para vários réus → **litisconsórcio** (CPC 113) |

## CPC 327 §1, REQUISITOS

| Inciso | Requisito |
|---|---|
| **I** | Pedidos **compatíveis** entre si |
| **II** | **Mesmo juízo** competente |
| **III** | Adequado **procedimento** comum (ou conversível) |

## CPC 327 §2, diversidade de procedimentos

| | Conteúdo |
|---|---|
| Pedidos exigem **procedimentos diversos** | Cumulação admitida se autor optar pelo **procedimento comum** |
| Exceção | Não se aplica quando a regra do procedimento especial **é incompatível** com o pedido cumulado |

## ESPÉCIES DE CUMULAÇÃO

### Cumulação SIMPLES (autônoma)

| | Conteúdo |
|---|---|
| Conceito | Pedidos **independentes** entre si |
| Acolhimento | Cada pedido é apreciado **separadamente** |
| Exemplo | Dano material + dano moral + dano estético em mesma ação |

### Cumulação SUCESSIVA

| | Conteúdo |
|---|---|
| Conceito | Segundo pedido depende do **acolhimento** do primeiro |
| Exemplo | Investigação de paternidade + alimentos |
| Acolhimento | Primeiro acolhido → análise do segundo |

> **CPC 327 §3**: o requisito da **compatibilidade** (§1 I) NÃO se aplica às cumulações do art. 326 (alternativa e subsidiária).

### Cumulação ALTERNATIVA

| | Conteúdo |
|---|---|
| Conceito | **Qualquer** dos pedidos satisfaz o autor |
| Base normativa | CPC 325 (obrigações alternativas) |
| Exemplo | Reparação OU restituição |

### Cumulação SUBSIDIÁRIA / EVENTUAL (CPC 326)

| | Conteúdo |
|---|---|
| Conceito | Segundo é **eventual**, apenas se primeiro **rejeitado** |
| Hierarquia | Autor estabelece ordem |
| Exemplo | Anulação do contrato (principal) OU revisão (subsidiário) |
| Valor da causa | Valor do **pedido principal** (CPC 292 VIII) |

## Cumulação irregular: emenda da inicial

| | Conteúdo |
|---|---|
| Cumulação defeituosa | Juiz determina **emenda** em 15 dias (CPC 321) |
| Falta de emenda | **Indeferimento** da inicial (CPC 321 par. único + 485 I) |

> **CPC 328** trata de tema diverso: na obrigação **indivisível** com pluralidade de credores, o credor que não participou do processo recebe sua parte, deduzidas as despesas na proporção de seu crédito.

## CPC 329, ADITAMENTO + ALTERAÇÃO

| Momento | Possibilidade |
|---|---|
| **Até a citação** | Alteração **livre** do pedido OU causa de pedir |
| **Até o saneamento** | Mediante **consentimento do réu** |
| **Após saneamento** | **Vedado** (preclusão) |
| **Reconvenção/contrarrazões** | NÃO se aplica (regimes próprios) |

### CPC 329 par. único, assegurar contraditório

| | Conteúdo |
|---|---|
| Aditamento → assegura **contraditório** + **prova** |

## Cumulação de demandas com **procedimentos especiais**

| Hipótese | Conteúdo |
|---|---|
| Possessória + outras pretensões | Possessória admite tutela específica (CPC 554) + cumulação |
| Inventário + outras | Vedada cumulação (procedimento especial inalterável) |
| Mandado de segurança + indenização | Vedada (MS não admite) |
| Reintegração + perdas e danos | **Admitida** (CPC 555) |

## Cumulação na petição inicial, exemplo

Forma típica:
1. **Pedido principal**: declaração de nulidade do contrato;
2. **Pedido subsidiário** (CPC 326): revisão do contrato em ponto específico;
3. **Pedido sucessivo** ao acolhimento: condenação à restituição de valores;
4. **Pedido simples cumulado**: condenação em danos morais.

## Cumulação por **conexão / continência**

| | Conteúdo |
|---|---|
| **Conexão** (CPC 55) | Comum **objeto ou causa de pedir** |
| **Continência** (CPC 56) | Conexão + identidade de **partes + causa**, **um pedido contém o outro** |
| Efeito | Reunião dos processos (CPC 55 §1), **competência absoluta** |

## Reconvenção (CPC 343)

| | Conteúdo |
|---|---|
| Natureza | Cumulação **objetiva inversa**, réu deduz pedido contra autor |
| Forma | Apresentada na contestação (mesma peça) |
| Requisitos | Conexão com ação principal OU fundamento na defesa |
| Independência | Autonomia processual, segue mesmo se ação principal extinta |

## Litisconsórcio + cumulação

| | Conteúdo |
|---|---|
| Cumulação **objetiva** | Vários pedidos contra mesmo réu (CPC 327) |
| Cumulação **subjetiva** (litisconsórcio CPC 113) | Vários réus ou autores |
| Cumulação **mista** | Múltiplos pedidos + múltiplas partes |

## Notas atuais

| | Conteúdo |
|---|---|
| **CPC 329** | Alteração até a citação é livre; até o saneamento, depende de anuência do réu |
| **CPC 327 §1** | Compatibilidade aferida na inicial; requisitos cumulativos (compatibilidade + mesmo juízo + procedimento) |
| **CPC 327 §2** | Procedimentos diversos: admite-se cumulação adotando o procedimento comum |

## Roteiro de análise

1. Espécie: simples, sucessiva, alternativa ou subsidiária;
2. Requisitos (CPC 327 §1): compatibilidade, mesmo juízo e procedimento;
3. Procedimentos diversos: adoção do procedimento **comum** (CPC 327 §2);
4. Valor: soma (simples), maior (alternativa), principal (subsidiária);
5. Alteração: livre até a citação, com anuência até o saneamento, preclusa após;
6. Reconvenção (CPC 343) inverte a cumulação;
7. Litisconsórcio quando há vários sujeitos.

## Erros a evitar

- Pedidos **incompatíveis** não se cumulam (CPC 327 §1 I; ex.: anulação e cumprimento sem subsidiariedade);
- Pedidos de juízos **diversos** não se cumulam (CPC 327 §1 II);
- O procedimento **especial incompatível** com o pedido cumulado obsta a cumulação (CPC 327 §2);
- A alteração do pedido **após o saneamento** é preclusa (CPC 329);
- Na cumulação alternativa, o valor da causa é o **maior**, não a soma (CPC 292 VII);
- A cumulação alternativa (qualquer pedido) não se confunde com a subsidiária (segundo se rejeitado o primeiro);
- O **inventário** é procedimento especial que veda a cumulação;
- A reconvenção é do réu, não cumulação do autor;
- O aditamento exige contraditório e oportunidade de prova (CPC 329 par. único);
- A conexão reúne processos (CPC 55 §1), não equivale a cumulação no **mesmo processo**.

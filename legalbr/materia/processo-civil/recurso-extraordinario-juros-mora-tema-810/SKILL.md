# Atualização das Condenações da Fazenda (pré-EC 113)

## Base normativa

| | Conteúdo |
|---|---|
| **Lei 9.494/97 art. 1-F** (redação Lei 11.960/09) | TR para correção + juros poupança em condenações da Fazenda |
| **EC 113/2021 art. 3** | SELIC única pós 09/12/2021 (Tema 1.419 STF) |
| **CF 5 XXXVI** | Direito adquirido + coisa julgada |
| **CTN art. 167** | Repetição indébito tributário |

## STF Tema 810 (RE 870.947, Min. Luiz Fux)

| | Conteúdo |
|---|---|
| Fixada | **20/09/2017** |
| **Tese 1** | É **inconstitucional** a aplicação da **TR** para correção monetária em condenações da Fazenda Pública (art. 1-F Lei 9.494/97, redação Lei 11.960/09) |
| **Tese 2** | Aplica-se **IPCA-E** para correção + **juros poupança** para juros (TR + 0,5% ao mês) |
| Aplicação | Período **até 08/12/2021** (pré-EC 113) |

## Aplicação prática

| Período | Regime |
|---|---|
| Antes da Lei 11.960/09 (até 29/06/2009) | Regime anterior (INPC + 0,5% a 1% juros conforme natureza) |
| **Lei 11.960/09 a 08/12/2021** | **IPCA-E correção + juros poupança** (Tema 810) |
| **Pós-EC 113 (09/12/2021)** | **SELIC ÚNICA** (Tema 1.419 STF) |
| **Pós EC 136/2025** | Verificar nova redação |

## Distinção com regime tributário

| | Não-tributário | Tributário |
|---|---|---|
| Pré-EC 113 | **Tema 810 STF**: IPCA-E + juros poupança | **Tema 905 STJ**: SELIC (quando há lei do ente) |
| Pós-EC 113 | **SELIC** (Tema 1.419 STF) | SELIC (Tema 1.419 STF) |

## Casos correlatos

| | Conteúdo |
|---|---|
| **Tema 810 STF** | IPCA-E correção (pré-EC 113) |
| **Tema 905 STJ** | Tributário: SELIC |
| **Tema 1.419 STF** | SELIC universal pós-EC 113 |
| **Tema 1.062 STF** | Estados/DF: limite SELIC |
| **Tema 1.217 STF** | Municípios: limite SELIC |
| **EC 113/2021** | SELIC universal |
| **Lei 9.494/97** | Norma alterada |

## Erros a evitar

- Aplicar **TR para correção** após Tema 810 (declarado inconstitucional);
- Aplicar Tema 810 a fatos **pós-EC 113** (cabe SELIC universal, Tema 1.419 STF);
- Em causa tributária, aplicar Tema 810 (cabe Tema 905 STJ pré-EC + SELIC pós);
- Cumular IPCA-E + juros poupança + outro índice (vedado);
- Aplicar Tema 810 a JT em causa privada (cabe ADC 58/59).

# Fracionamento de Honorários em ACP Coletiva

## Base normativa

| | Conteúdo |
|---|---|
| **CF 100** | Precatórios + RPV |
| **CF 100 §8** | **Vedado** fracionamento + repartição + quebra de valor da execução para fins de RPV |
| **CPC art. 85 §14** | Honorários: natureza alimentar |
| **Súm. 153 STJ** | Honorários: precatório separado, não como tributário |

## STF Tema 1.142 (RE 1.309.081)

| | Conteúdo |
|---|---|
| Fixada | **07/05/2021** |
| **Tese (essência)** | É **POSSÍVEL** o **fracionamento** dos honorários sucumbenciais decorrentes de **ação coletiva contra a Fazenda Pública** para pagamento via RPV. A vedação do CF 100 §8 NÃO se aplica entre o crédito **principal** (do exequente) e o **acessório** (honorários) |

## Distinção: principal × honorário

| Hipótese | Saída |
|---|---|
| Crédito principal R$ 100k + honorários R$ 30k | **Cabe fracionamento**: principal via precatório + honorários via RPV (se até 60 SM federal) |
| Crédito principal R$ 50k + honorários R$ 10k (ambos < RPV) | Ambos por RPV (sem fracionamento necessário) |
| Crédito principal R$ 300k + honorários R$ 60k | Principal por precatório + honorários por RPV se cabível |
| **Mesmo crédito** dividido para passar do limite RPV | **VEDADO** (CF 100 §8) |
| Crédito + honorário do mesmo advogado em vários processos | Cada um analisado |

## Quem se beneficia

| Hipótese | Conteúdo |
|---|---|
| Advogado em ação coletiva | Honorários por RPV cabível (Tema 1.142) |
| Vários advogados em ação coletiva | Cada um até o limite RPV |
| Cessão de honorário | Mantém natureza alimentar (Súm. 25 OAB) |
| Honorários contratuais | Mesma lógica |

## Casos correlatos

| | Conteúdo |
|---|---|
| **Tema 1.142 STF** | Fracionamento honorários ACP |
| **Tema 1.220 STF** | Honorários sobre crédito tributário |
| **Tema 1.190 STF** | Honorários cumprimento Fazenda |
| **Tema 1.156 STF** | Superpreferência via RPV |
| **Súm. 153 STJ** | Honorário em precatório próprio |
| **CF 100 §8** | Vedação ao fracionamento |

## Erros a evitar

- Vedar fracionamento honorário em ACP coletiva (Tema 1.142 permite);
- Aplicar CF 100 §8 ao acessório dos honorários (a vedação é para o **principal**);
- Em sucumbência da Fazenda, exigir precatório único para tudo (cabe fracionamento);
- Em **fracionamento entre litisconsortes**: análise específica (Tema 148 STF);
- Em causa privada sem Fazenda: aplicar Tema 1.142 (a tese é específica para Fazenda).

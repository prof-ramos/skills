# Petição Inicial + Emenda

## CPC 319: REQUISITOS (7 incisos)

| Inc. | Conteúdo |
|---|---|
| **I** | **Juízo** a que dirigida |
| **II** | **Qualificação COMPLETA** das partes (nome + estado civil + existência de união estável + profissão + CPF/CNPJ + endereço eletrônico + domicílio + residência) |
| **III** | **Fato e fundamentos jurídicos** do pedido |
| **IV** | **PEDIDO com especificações** |
| **V** | **VALOR da causa** |
| **VI** | **Provas** que pretende demonstrar |
| **VII** | **Opção** pela realização ou não de **audiência de conciliação/mediação** |

| § | Conteúdo |
|---|---|
| §§ 1-3 | **Dispensa de dados** quando autor não os possui e o acesso é dificultoso |

## CPC 320: DOCUMENTOS

| | Conteúdo |
|---|---|
| Conteúdo | **Indispensáveis à propositura** (substanciais e fundamentais) |

## CPC 321: EMENDA

| | Conteúdo |
|---|---|
| Hipótese | Verificada **irregularidade SANÁVEL** |
| Prazo | **15 DIAS** |
| Juiz | **Indica com PRECISÃO** o que corrigir |
| Descumprimento | **Indeferimento** (CPC 321 par. único) |
| STJ | **VEDADO indeferimento sem prévia oportunidade** de emenda quando vício sanável |

### Jurisprudência do STJ sobre a emenda
| | Conteúdo |
|---|---|
| Natureza do prazo | **DILATÓRIO**: pode ser **ampliado** pelo juiz |
| Indeferimento sem prévia emenda | **VIOLA o DEVIDO PROCESSO LEGAL** (CF 5 XXXV); o indeferimento pressupõe oportunidade de correção do vício sanável |

## CPC 322: PEDIDO

| | Conteúdo |
|---|---|
| Regra | **CERTO** |
| **§2** | Interpretação conforme **BOA-FÉ** |

## CPC 324-326: espécies de pedido

| Art. | Conteúdo |
|---|---|
| **324** | Pedido **DETERMINADO** (regra); genérico só nas hipóteses do §1 (ações universais; consequências indetermináveis; valor dependente de ato do réu) |
| **325** | Pedido **ALTERNATIVO**: quando a obrigação puder ser cumprida por mais de um modo |
| **326** | Pedidos em ordem **SUBSIDIÁRIA/SUCESSIVA**: o juiz examina o subsequente se NÃO acolhido o anterior; o par. único trata do pedido alternativo (acolhimento de um deles) |

## CPC 330: INDEFERIMENTO (4 hipóteses)

| Inc. | Hipótese |
|---|---|
| **I** | **INÉPCIA** (faltar pedido/causa de pedir + indeterminado + ilogicidade + incompatíveis) |
| **II** | Parte **MANIFESTAMENTE ILEGÍTIMA** |
| **III** | Falta de **INTERESSE PROCESSUAL** |
| **IV** | Não atendidas **prescrições dos arts. 106 e 321** |

| | Conteúdo |
|---|---|
| Efeito | **Sentença EXTINTIVA SEM MÉRITO** (CPC 485 I) |
| Recurso | **Apelação** com **RETRATAÇÃO em 5 dias** (CPC 331) |

## CPC 292 §3: VALOR DA CAUSA

| | Conteúdo |
|---|---|
| Correção **DE OFÍCIO** | Pelo juiz **até a sentença** |
| **STJ** | **NÃO em juízo de RETRATAÇÃO**: o valor da causa não pode ser alterado ao reexaminar recurso em retratação |

## Distinções essenciais

| | Inépcia | Ilegitimidade |
|---|---|---|
| Vício | Estrutural da petição | Subjetiva |
| Sanável | Por emenda | Conforme caso |

| | Indeferimento (CPC 330) | Improcedência liminar (CPC 332) |
|---|---|---|
| Hipóteses | Defeitos formais | **Mérito** contrário a precedente |
| Efeito | Sem mérito | **Com mérito** |

| | Subsidiários/sucessivos (326) | Alternativos (325) |
|---|---|---|
| Subordinação | Subsidiário (ordem) | Equivalentes |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Inicial sem CPF/CNPJ obtível | **Emenda 15 dias** (321) |
| Falta pedido | **Inépcia** (330 I) |
| Pedido indeterminado | Inépcia (salvo exceções) |
| Pedidos incompatíveis | Inépcia |
| Sem documentos indispensáveis | Emenda |
| Emenda em 15 dias descumprida | **Indeferimento** (CPC 321 par. único); prazo dilatório admite ampliação pelo juiz |
| Ilegitimidade manifesta | Indeferimento (330 II) |
| Apelação contra indeferimento | **Retratação 5 dias** (CPC 331) |
| Valor incorreto | **Correção de ofício** até sentença (292 §3) |
| Valor em retratação | **NÃO alterável** (STJ) |
| Pedido subsidiário/sucessivo | **326** |
| Pedido alternativo | **325** |

## Erros a evitar

- **Rejeitar SEM prévia emenda** (jurisprudência STJ, viola devido processo);
- Aplicar **preclusão automática** ao prazo de emenda (é dilatório);
- Admitir inicial **sem requisitos do CPC 319** sem oportunizar emenda;
- Tratar **inépcia como sanável SEM oportunidade** de correção;
- Aplicar **CPC 330 sem distinguir indeferimento de improcedência liminar** (CPC 332);
- Admitir **pedidos manifestamente incompatíveis** (inépcia);
- Cobrança de **emenda além do que indicado** (juiz deve precisar);
- Admitir **inicial sem documentos indispensáveis** (CPC 320);
- Confundir **valor da causa com valor do pedido**;
- **Alterar valor em retratação** (jurisprudência do STJ);
- Afastar **retratação 5 dias** após apelação (CPC 331).

# Ata Notarial

## CPC 384, conceito

| | Conteúdo |
|---|---|
| Definição | Tabelião, a requerimento do interessado, **atesta a existência e o modo de existir** de algum fato |
| Natureza | **Documento PÚBLICO**, fé pública notarial (CC 215 + Lei 8.935/1994) |

## CPC 384 par. único, DADOS DIGITAIS

| | Conteúdo |
|---|---|
| Inovação CPC/2015 | Pode-se atestar **dados representados por imagem ou som** **gravados em arquivos eletrônicos** |
| Aplicação | Conversas de **WhatsApp**, sites, redes sociais, e-mails, fotos, vídeos |
| Função | **Prova robusta** de conteúdo digital + cadeia de custódia preservada |

## Valor probatório

| | Conteúdo |
|---|---|
| **CPC 411 + 412** | Documento público, prova **PLENA** dos fatos atestados pelo tabelião |
| Limite | Tabelião atesta o que **VIU e OUVIU**, não atesta veracidade do conteúdo (apenas a existência) |
| Exemplo | Ata notarial de WhatsApp = atesta que **a conversa existe naquele dispositivo**, **não** que o teor é verdadeiro |

## Procedimento

| Etapa | Conteúdo |
|---|---|
| **1)** Interessado comparece ao **tabelionato de notas** |
| **2)** Apresenta requisição + dispositivo (celular, computador, URL) |
| **3)** Tabelião **observa** o fato + descreve com objetividade |
| **4)** Documenta hash, URL, IP, data/hora, para preservar autenticidade |
| **5)** Lavra a ata em **livro próprio** + entrega traslado autenticado |

## Aplicações típicas

| Hipótese | Uso |
|---|---|
| **WhatsApp** | Conversas, áudios, fotos enviadas |
| **Redes sociais** | Posts, comentários, perfis fake, ofensas |
| **Sites** | Conteúdo de página específica (vendas piratas, calúnia) |
| **E-mails** | Conversas, anexos |
| **Reuniões/eventos** | Cabeçalho, conteúdo de palestras |
| **Apuração de fatos** | Reunião de condomínio, assembleia (ata notarial concorrente com ata oficial) |
| **Acidente** | Estado de obras, vazamentos, intervenção urgente |
| **Insolvência** | Existência de bens, estado de patrimônio |

## Vantagens

| | Conteúdo |
|---|---|
| **Robustez** | Documento público com fé pública |
| **Cadeia de custódia** | Hash + dispositivo + horário registrados |
| **Ônus de quem impugna** | A parte que arguir a falsidade tem o ônus de prová-la (CPC 429 I) |
| **Prevenção de perda da prova** | Conteúdo digital pode desaparecer |

## Diferenciação com print

| | Print | Ata notarial |
|---|---|---|
| Forma | Fotografia da tela | Tabelião descreve em ata |
| Valor | Documento particular (admite contestação) | Documento **público** (prova plena) |
| Manipulação | Possível (edição de imagens) | Mais difícil (tabelião verifica origem) |
| Regime | Documento particular (CPC 422 §1), sujeito a impugnação (CPC 429) | Documento público com fé pública (CPC 384 + 405) |
| Lei | CPC 411 + Lei 14.063 | CPC 384 + Lei 8.935 + CC 215 |

## Custos

| | Conteúdo |
|---|---|
| Tabela | Emolumentos definidos por regulamentação cartorial estadual |

## Lei 8.935/1994, fé pública notarial

| Art. | Conteúdo |
|---|---|
| **7 III** | Compete com exclusividade ao tabelião de notas lavrar **atas notariais** (art. 6 III: aos notários compete autenticar fatos) |
| Caráter | **Fé pública**, equivale a documento oficial |
| Tabelião responde | Civil + administrativa + penal por dolo/culpa (Lei 8.935 art. 22) |

## CC 215, escritura pública

| | Conteúdo |
|---|---|
| Escritura pública | Documento mais robusto, para atos translativos de propriedade |
| Ata notarial | Específica para **atestar fatos** (não declarar vontade) |

## Provimento 100/2020 CNJ, atas eletrônicas

| | Conteúdo |
|---|---|
| **e-Notariado** | Permite ata notarial **inteiramente eletrônica** |
| Videoconferência | Tabelião acompanha por vídeo |
| Assinatura | ICP-Brasil |

## STJ, utilização

| | Conteúdo |
|---|---|
| Prova digital | Ata notarial de conversa de WhatsApp admitida como prova (STJ) |
| Obrigações | Ata notarial usada para constatar fatos relevantes ao cumprimento |
| Família | Ata notarial de constatação de relacionamento, uso crescente |
| Constatação de produtos piratas | Admitida |

## Limites

| | Conteúdo |
|---|---|
| Tabelião **NÃO atesta veracidade** do conteúdo (apenas existência) |
| Ata sobre **conversa interna** sem participação direta = sem prova robusta |
| Tabelião não pode **invadir privacidade** sem autorização |
| Senha do dispositivo = consentimento do titular |

## Ata notarial vs perícia digital

| | Ata notarial | Perícia |
|---|---|---|
| Quem faz | Tabelião | Perito |
| Foco | Constatação de fato | Análise técnica |
| Validade | Documento público | Laudo pericial (CPC 477) |
| Custo | Tabela cartorial | Honorários periciais (CPC 95) |
| Combinação | Possível, ata + perícia subsequente |

## Notas atuais

| | Conteúdo |
|---|---|
| **Provimento 100/2020 CNJ** | e-Notariado (ata notarial eletrônica) |
| **Jurisprudência STJ** | Ata notarial de conversa de WhatsApp/rede social admitida como prova |
| **Lei 14.063/2020** | Assinaturas eletrônicas em interações com entes públicos |
| **CC 215 + Lei 8.935/1994** | Fé pública notarial; ata atesta a existência do fato |

## Roteiro de análise

1. A prova digital ou de fato fugaz comporta ata notarial como meio idôneo;
2. A ata notarial é preferível ao print por sua robustez (documento público);
3. A lavratura pressupõe acompanhamento do tabelião com apresentação de dispositivo, URL ou conteúdo;
4. O traslado integra os autos como prova documental;
5. A contestação de autenticidade comporta perícia digital subsequente;
6. O valor probatório é de prova **plena** sobre a existência do fato (CPC 411-412);
7. A atestação eletrônica é admitida (Provimento 100/2020 CNJ).

## Erros a evitar

- Tratar ata notarial como prova **inferior** ao print;
- Achar que tabelião atesta **veracidade do conteúdo** (apenas existência);
- Acessar dispositivo de terceiro **sem autorização** (invasão de privacidade);
- Não preservar **hash** + cadeia de custódia na ata digital;
- Dispensar ata notarial em causa **relevante** quando conteúdo digital é central;
- Aplicar CPC 411-412 sem ata notarial em prova digital frágil;
- Esquecer **e-Notariado** (Provimento 100/2020 CNJ);
- Tratar ata como **dispensável** em fatos fugazes (pode perder conteúdo);
- Aplicar ata notarial como **prova testemunhal** (é documental);
- Negar ata notarial **sem contestação fundamentada** de falsidade.

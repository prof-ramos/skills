# Penhora, Avaliação e Expropriação

## CPC 831, PENHORA

| | Conteúdo |
|---|---|
| Definição | Ato pelo qual se **individualizam** bens do executado para satisfazer a execução |
| Função | Identificação + indisponibilidade + preservação |
| Quem realiza | **Oficial de justiça** ou via sistemas eletrônicos (Sisbajud, Renajud) |

## CPC 832, DESTINAÇÃO

| | Conteúdo |
|---|---|
| Bens **penhoráveis** | Sujeitos à execução |
| Limite | Valor suficiente para **integral satisfação** |

## CPC 833, IMPENHORABILIDADES (rol)

> Visto em [[execucao-titulo-extrajudicial-cpc-784]].

## CPC 835, ORDEM LEGAL

| Posição | Bem |
|---|---|
| **I** | Dinheiro (espécie, depósito, aplicação financeira) |
| **II** | Títulos da dívida pública com cotação em mercado |
| **III** | Títulos + valores mobiliários |
| **IV** | **Veículos automotores** |
| **V** | Bens imóveis |
| **VI** | Bens móveis em geral |
| **VII** | Semoventes |
| **VIII** | Navios + aeronaves |
| **IX** | Ações + quotas de sociedades simples + empresárias |
| **X** | Percentual do faturamento de empresa devedora |
| **XI** | Pedras + metais preciosos |
| **XII** | Direitos aquisitivos derivados de promessa de compra e venda + alienação fiduciária |
| **XIII** | Outros direitos |

> **§3**: Dinheiro tem **prioridade ABSOLUTA** sobre os demais.

## Penhora insuficiente + penhora no rosto dos autos

| | Conteúdo |
|---|---|
| Não havendo bens suficientes | Penhora **ampliada, substituída ou transferida** (CPC 874) |
| **Penhora "no rosto" dos autos** (CPC 860) | Cabível em créditos do executado em outros processos |

## CPC 840, DEPÓSITO

| Bem | Depositário |
|---|---|
| Dinheiro | Estabelecimento oficial **(Caixa, BB)** |
| Móveis | **Executado** (regra) ou outro depositário |
| Imóveis | Auto + registro CRI (averbação) |
| Veículos | Renajud + depósito particular ou Detran |

## Sistemas de pesquisa patrimonial e constrição

| | Conteúdo |
|---|---|
| Penhora **online (Sisbajud)** | CPC 854, bloqueio + intimação |
| Renajud (veículos) | Bloqueio circulação + transferência |
| **CCS-Bacen** | Cadastro de Clientes do SFN |
| **Infojud** | Receita Federal |
| **Bacenjud → Sisbajud** | Substituição em 2020 |

## CPC 854, SISBAJUD detalhado

| Etapa | Conteúdo |
|---|---|
| **Caput** | Indisponibilidade de ativos financeiros **sem prévia ciência** do executado |
| **§1** | Cancelamento da indisponibilidade **excessiva** em até 24h |
| **§2** | Intimação do executado após a indisponibilidade |
| **§3** | Executado tem **5 dias** para alegar impenhorabilidade ou excesso |
| **§5** | Rejeitada ou não apresentada a manifestação → **conversão em penhora**, sem termo |
| **Teimosinha** | Reiteração automática das ordens de bloqueio: legítima (STJ Tema 1.325); cabe ao executado demonstrar causa impeditiva ou meio igualmente eficaz menos gravoso; após a triangularização, o indeferimento exige fundamentação concreta |

## Criptoativos

| | Conteúdo |
|---|---|
| **STJ 3ª T (REsp 2.127.038/SP)** | Penhora de **criptoativos** admitida, exige cooperação com exchanges |
| Procedimento | Por meio de **ofício** à corretora, pelo **CriptoJud** (sistema do CNJ lançado em ago/2025, implantação gradual) ou via **Receita Federal** |

## CPC 870, AVALIAÇÃO

| | Conteúdo |
|---|---|
| Regra | Pelo **oficial de justiça** ou **perito** (CPC 870) |
| Pode dispensar avaliação | Quando bens com **cotação no mercado** (CPC 871) |
| Reavaliação | Cabível se alteração significativa de valor (CPC 873) |
| Recurso | Impugnação em **5 dias** + decisão = AI |

## EXPROPRIAÇÃO (CPC 875-903)

### Modalidades (CPC 825)

| Inciso | Modalidade |
|---|---|
| **I** | **Adjudicação** |
| **II** | **Alienação** por iniciativa particular ou em leilão |
| **III** | **Apropriação de frutos e rendimentos** de empresa ou de estabelecimentos e de outros bens |

### ADJUDICAÇÃO (CPC 876)

| | Conteúdo |
|---|---|
| Hipótese | Credor pede a **adjudicação** do bem penhorado pelo valor da avaliação |
| Quem pode | Credor + sócio + cônjuge + ascendente/descendente |
| Prazo | Após avaliação |
| Diferença | Paga ou recebe complemento |

### ALIENAÇÃO POR INICIATIVA DO PARTICULAR (CPC 879-881)

| | Conteúdo |
|---|---|
| Iniciativa | Próprio exequente + corretor habilitado |
| **Prazo** | Definido pelo juiz |
| Vantagem | Mais ágil que leilão |

### LEILÃO JUDICIAL (CPC 881-903)

| | Conteúdo |
|---|---|
| **CPC 882** | **Eletrônico** é a **REGRA** (CPC 882 §1 + Resolução 236/2016 CNJ) |
| Presencial | Apenas se impossível eletrônico (justificado) |
| **2 leilões** | I primeiro = lance mínimo = valor da avaliação; II segundo = qualquer lance, vedando preço vil (CPC 891) |
| **Preço vil** (CPC 891) | Inferior ao mínimo fixado (regra: 50% da avaliação) |
| Recurso | AI |

## CPC 891, PREÇO VIL

| | Conteúdo |
|---|---|
| Definição | Lance significativamente **inferior** ao valor da avaliação |
| Critério | Menos de **50%** (regra geral) |
| Decisão | Juiz **não homologa** + designa novo leilão |

## CPC 897, ARREMATAÇÃO

| | Conteúdo |
|---|---|
| Pagamento | À vista OU **parceladamente** (CPC 895, imóveis) |
| Auto de arrematação | Lavrado |

| | Conteúdo |
|---|---|
| Hipóteses (§1) | I não pagamento; II ônus omisso ao edital; III preço vil; IV requerimento (alienado) |

## Penhora no rosto dos autos

| | Conteúdo |
|---|---|
| Hipótese | Crédito do executado em outro processo |
| Forma | Ofício ao juízo do outro processo para inibir levantamento |
| Eficácia | Constringe o crédito quando reconhecido |

## Penhora de FATURAMENTO (CPC 866)

| | Conteúdo |
|---|---|
| Hipótese | Inexistência de outros bens penhoráveis, ou bens de difícil alienação/insuficientes (CPC 866 caput); Tema 769 STJ afastou a exigência de esgotamento de diligências |
| Percentual | Sem teto legal: fixado caso a caso pela dupla baliza do §1 (satisfação em tempo razoável x preservação da atividade empresarial) |
| Administrador | Nomeado pelo juízo (preferencialmente o executado) |
| Prestação de contas | Mensal (CPC 866 §2) |

## Substituição da penhora (CPC 847)

| | Conteúdo |
|---|---|
| Executado pode requerer | Substituir bem penhorado por outro |
| Requisitos | Aceitação do credor OU bem **mais líquido** + suficiente |

## Estado da arte 2024-2026

| | Conteúdo |
|---|---|
| **CPC 854** | Sisbajud + Teimosinha pacificado |
| **STJ 3ª T REsp 2.127.038/SP** | Criptoativos penhoráveis (via exchanges) |
| **CPC 882** | Leilão eletrônico = regra |
| **Lei 14.711/2023** | Marco Legal das Garantias: reforço da execução extrajudicial das garantias |
| **STJ Tema 1.325** | Teimosinha legítima; indeferimento pós-triangularização exige fundamentação concreta |

## Roteiro do rito

1. Localização de **bens** do executado (Infojud, Renajud, CCS-Bacen);
2. **Ordem legal** de preferência (CPC 835, dinheiro em primeiro lugar);
3. Sisbajud (CPC 854) com Teimosinha;
4. Penhora física quando necessária (CPC 845);
5. **Avaliação** (CPC 870);
6. **Expropriação**: adjudicação, alienação particular, leilão (CPC 825);
7. **Leilão eletrônico** (CPC 882); preço vil é o inferior a 50%;
8. Substituição e impugnações (CPC 847 + 854 §3).

## Erros a evitar

- O bem **impenhorável** não comporta penhora (CPC 833);
- A **ordem legal** do CPC 835 só pode ser afastada com fundamentação;
- O bloqueio via Sisbajud depende de **decisão** judicial (CPC 854);
- O lance **vil** (inferior a 50% da avaliação) é inadmissível (CPC 891);
- O leilão é eletrônico em regra (CPC 882), e o presencial é excepcional;
- Exigir esgotamento absoluto de diligências como pressuposto da penhora de faturamento (Tema 769 STJ afastou o requisito);
- O executado tem prazo de **5 dias** para alegar impenhorabilidade (CPC 854 §3);
- O **salário** é impenhorável até 50 sm fora de alimentos (CPC 833 §2);
- A **adjudicação** pelo credor é direito (CPC 876);
- A **Teimosinha** é automática, independente de novo pedido (CPC 854 §1).

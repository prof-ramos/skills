# Negócios Jurídicos Processuais

## CPC 190: CLÁUSULA GERAL de NEGOCIAÇÃO

| | Conteúdo |
|---|---|
| Requisitos | **Partes plenamente CAPAZES** + causas que admitam **AUTOCOMPOSIÇÃO** (direitos disponíveis) |
| Objeto | **Mudanças no PROCEDIMENTO** + convenções sobre **ÔNUS + PODERES + FACULDADES + DEVERES** processuais |
| Momento | **ANTES OU DURANTE** o processo |
| Natureza | **ATÍPICO** (cláusula geral) |

## CPC 190 par. único: CONTROLE JUDICIAL

| | Conteúdo |
|---|---|
| De ofício/requerimento | **APENAS** para: |
| (i) | **Nulidade** |
| (ii) | **Inserção ABUSIVA em CONTRATO DE ADESÃO** |
| (iii) | Parte em **MANIFESTA VULNERABILIDADE** |

## CPC 191: CALENDÁRIO PROCESSUAL

| | Conteúdo |
|---|---|
| Acordo | Entre **juiz e partes** |
| Vinculação | **A TODOS** |
| Dispensa | **INTIMAÇÕES** para atos previstos |
| Alteração | Apenas em **casos EXCEPCIONAIS** devidamente justificados |

### Balizas gerais
| | Conteúdo |
|---|---|
| Calendarização | Não pressupõe que a causa admita autocomposição (o CPC 191 não repete o requisito do 190) |
| Boa-fé e cooperação | O negócio **NÃO pode afastar** os deveres de boa-fé e cooperação (CPC 5-6, normas cogentes) |

## STJ: balizas do NJP atípico

| | Conteúdo |
|---|---|
| **REsp 1.810.444/SP** (4ª Turma) | Requisitos de validade: causa que admita **autocomposição** + partes **plenamente capazes** + limitação aos **ônus, poderes, faculdades e deveres processuais das partes** + situação jurídica **individualizada e concreta**. **Vedada** convenção sobre ato processual regido por **norma de ordem pública**. A convenção que transige sobre o **contraditório** ou sobre **atos de titularidade do juiz** só se aperfeiçoa com a **aquiescência do magistrado** (que não integra o negócio); o controle judicial é de **legalidade**, não de conveniência |
| Convenções típicas correlatas | Convenção sobre **ônus da prova** (CPC 373 §3) + **foro de eleição** (CPC 63) têm base legal expressa |

## LIMITES

| | Conteúdo |
|---|---|
| (i) | **Ordem pública processual** (juiz natural + contraditório + fundamentação + publicidade) |
| (ii) | **Direitos INDISPONÍVEIS** |
| (iii) | **Normas COGENTES** (competência absoluta + prazos do MP) |

## CPC 357 §2: saneamento + calendarização

NJP pode ocorrer também na **audiência de saneamento** (CPC 357 §2-3) com **homologação judicial**.

## Distinções essenciais

| | Atípicos (CPC 190) | Típicos |
|---|---|---|
| Base | Cláusula geral | Dispositivos específicos |
| Exemplos | Pacto de não recorrer | Convenção arbitral (Lei 9.307) |

| | NJP | Acordo material |
|---|---|---|
| Objeto | **Processo** | Direito material |
| Sede | CPC 190 | CC + leis especiais |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Direitos disponíveis + capazes | **NJP cabível** |
| Direitos indisponíveis | **Vedado** |
| Calendário processual | **CPC 191**: vincula |
| Contrato de adesão abusivo | **Controle judicial** (par. único) |
| Parte vulnerável | **Controle** (par. único) |
| Pacto de não recorrer | Convenção **atípica pactuável** em direitos disponíveis (CPC 190), sujeita ao controle de legalidade |
| Escolha de foro | **Admitida** (foro de eleição, CPC 63) |
| Convenção sobre ônus | **CPC 373 §3** |
| Mediação prévia | **Pactuável** |
| Redução prazo peremptório | **Pactuável** (CPC 190) |
| Acordo de instância única | **Pactuável** |

## Erros a evitar

- **Admitir NJP em direitos INDISPONÍVEIS** (vedado);
- Admitir **NJP de parte VULNERÁVEL** (controle judicial, par. único);
- Não respeitar **CALENDÁRIO** (CPC 191, vincula);
- Alterar calendário **sem justificativa concreta**;
- Afastar **deveres de BOA-FÉ E COOPERAÇÃO** via NJP (CPC 5-6, cogentes);
- Aplicar NJP a **competência ABSOLUTA** (vedado);
- Admitir NJP em **contrato de adesão abusivo** sem controle;
- Tratar **rol como TAXATIVO** (cláusula GERAL, atípica);
- Aplicar NJP em **direitos do MP** (cogentes);
- Admitir **Fazenda celebrar NJP em INDISPONÍVEIS**;
- Não admitir **NJP em saneamento** (CPC 357 §2-3 admite).

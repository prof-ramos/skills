# ADI 4277 + ADPF 132: União Homoafetiva

## Identificação

| | Conteúdo |
|---|---|
| Ações | **ADI 4277** + **ADPF 132** |
| Autores | PGR + Governador do RJ |
| Relator | Min. **Ayres Britto** |
| Julgamento | **05/05/2011** |
| Placar | **UNÂNIME** |
| Técnica | **Interpretação conforme** sem redução de texto |

## Tese estruturante

| | Conteúdo |
|---|---|
| Resultado | **PROCEDENTE**: união estável homoafetiva é entidade familiar |
| Técnica | **Interpretação conforme** do CC 1.723 |
| Base | CF 1 III + 3 IV + 5 caput + 226 |
| Efeito | **Erga omnes + vinculante** |

## CC 1.723

| | Conteúdo |
|---|---|
| Texto original | "É reconhecida como entidade familiar a união estável entre o **homem e a mulher**" |
| Pós-decisão | Interpretado conforme: **independe de sexo/gênero** |
| Família | Pluralidade de configurações |

## Erros a evitar

- É vedada a recusa de **habilitação ou casamento** entre pessoas do mesmo sexo (Res. CNJ 175);
- CC 1.723 aplica-se sem restrição à orientação sexual (ADI 4277, interpretação conforme);
- CC 1.790 (regime sucessório inferior do companheiro) é inconstitucional (RE 878.694);
- A **adoção homoparental** não pode ser negada com base em orientação sexual (REsp 1.281.093);
- **LGBTfobia** está equiparada a racismo (ADO 26), sem pena mais branda por esse fundamento;
- A alteração de gênero no registro independe de **cirurgia de redesignação** (ADI 4275);
- O imposto de **transmissão por morte** incide com regime idêntico entre companheiros homo e hetero;
- A pensão por morte não pode ser recusada com **fundamento na orientação sexual** (eficácia erga omnes);
- **União estável** e **concubinato** são institutos distintos;
- A decisão é de controle concentrado, com eficácia vinculante (não matéria meramente infraconstitucional).

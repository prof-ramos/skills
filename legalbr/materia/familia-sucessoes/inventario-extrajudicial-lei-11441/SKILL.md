# Inventário Extrajudicial

## Lei 11.441/2007

| | Conteúdo |
|---|---|
| Introdução | **Inventário + partilha + separação + divórcio** por **ESCRITURA PÚBLICA** |
| Local | **Tabelionato de Notas** |
| Regulamento | **Resolução CNJ 35/2007** |
| Função | **DESJUDICIALIZAÇÃO**: desafogar o Judiciário |

## Requisitos clássicos

| | Conteúdo |
|---|---|
| **(i)** | **INEXISTÊNCIA de testamento** (flexibilizada, ver abaixo) |
| **(ii)** | **CONSENSO entre herdeiros** |
| **(iii)** | **ASSISTÊNCIA por ADVOGADO** (comum ou de cada parte, Res. 35 art. 11) |
| **(iv)** | **CAPACIDADE civil** de todos (flexibilizada, Res. 571/2024) |

## TESTAMENTO: flexibilização (2022)

| | Conteúdo |
|---|---|
| **Lei 14.382/2022** + STJ **REsp 1.808.767/RJ** | Admitem **EXTRAJUDICIAL** quando: |
| (a) | Testamento **previamente registrado + aberto + cumprido** pela via judicial |
| (b) | Caduco OU revogado |

## Resolução CNJ 571/2024: INCAPAZES

| | Conteúdo |
|---|---|
| Tese | **ROMPEU vedação** ao admitir inventário extrajudicial **COM MENORES/INCAPAZES** |
| Condicionantes | (a) Pagamento do **quinhão em PARTE IDEAL** de cada bem (mantendo condomínio + sem partilha cômoda que importe alienação) |
| | (b) **Manifestação FAVORÁVEL do MP** (fiscal da lei) |
| Base normativa | **Art. 12-A** acrescido à Res. 35 |

| Fase | Conteúdo |
|---|---|
| 1 | **Recolhimento do ITCMD** (alíquota conforme lei estadual) |

## Distinções essenciais

| | Inventário JUDICIAL | EXTRAJUDICIAL |
|---|---|---|
| Foro | Vara de família/sucessões | **Tabelionato** |
| Testamento | Compatível | **Apenas se cumprido** |
| Incapazes | Compatível | **Após Res. 571/2024 com MP** |
| Litígio | Compatível | **Vedada (consenso)** |
| Celeridade | Menor | **Maior** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Todos maiores e capazes + consenso + sem testamento | **EXTRAJUDICIAL** |
| Testamento previamente cumprido | **EXTRAJUDICIAL admitido** |
| Incapaz + parte ideal + MP favorável | **EXTRAJUDICIAL** (Res. 571/2024) |
| Litígio | **JUDICIAL** |
| Bens esquecidos | **Sobrepartilha extrajudicial** |
| União estável | Hipótese sucessória extrajudicial (CNN) |
| Sem ITCMD | **Não procede** |
| Sem advogado | **Inviável** |
| Convocação por edital | Judicial |

## Erros a evitar

- O **inventário extrajudicial** é admitido havendo testamento previamente cumprido (Lei 14.382 e REsp 1.808.767);
- A vedação a **incapazes** não é absoluta (Res. 571/2024 admite com MP);
- A **sobrepartilha extrajudicial** é cabível após inventário judicial;
- A **lei pré-2022** comporta flexibilização (testamento e incapazes);
- A **partilha cômoda** com incapazes NÃO é admitida (Res. CNJ 571/2024 exige pagamento em parte ideal de cada bem, mantendo condomínio);
- O **inventário extrajudicial com litígio** é vedado, pois exige consenso;
- A **assistência por advogado** é exigida (CNJ 35);
- A escritura depende do **ITCMD recolhido**;
- A **convivência estável** é hipótese admitida (Prov. CNJ 149);
- As **custas judiciais** não incidem sobre o ato notarial;
- A presença do **MP** é exigida quando há incapaz.

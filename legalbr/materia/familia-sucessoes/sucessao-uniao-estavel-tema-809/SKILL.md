# Sucessão na União Estável (Tema 809 STF)

## Acórdão paradigma

| | Conteúdo |
|---|---|
| Casos | **RE 878.694/MG** + RE 646.721 (conjunto) |
| Relator | **Min. Luís Roberto Barroso** |
| Julgamento | **10/05/2017** |
| Acórdão | Publicado **06/02/2018** |

## Tese fixada

> "É **inconstitucional a distinção** de regimes sucessórios entre cônjuges e companheiros prevista no **art. 1.790 do CC/2002**, devendo ser aplicado, tanto nas hipóteses de **casamento** quanto nas de **união estável**, o **regime do art. 1.829** do CC."

## Bases normativas

| | Conteúdo |
|---|---|
| **CF 1 III** | Dignidade |
| **CF 5 caput** | Igualdade |
| **CF 226 §3** | União estável como entidade familiar |
| **CC 1.790** | **Declarado inconstitucional** |
| **CC 1.829** | Aplicável a todos |
| CC 1.830, 1.831, 1.832, 1.838, 1.845 | Sistematização |

## Modulação

| | Conteúdo |
|---|---|
| Inventários **sem trânsito da partilha** | **Aplica-se** o Tema 809 |
| Partilha **transitada** | Preservada (mantém CC 1.790) |

## Concorrência com descendentes (art. 1.829 I por analogia)

| Regime de bens | Concorre? |
|---|---|
| **Comunhão universal** | **NÃO** |
| **Separação obrigatória** | **NÃO** |
| **Separação convencional** | **SIM** |
| **Participação final aquestos** | **SIM** |
| **Comunhão parcial** + bens particulares | **SIM** (sobre os particulares) |
| Comunhão parcial **sem** bens particulares | NÃO |

## Companheiro herdeiro necessário?

| | Conteúdo |
|---|---|
| STF | **Silente** na tese |
| Orientação predominante pós-julgado | Sim (controvérsia subsistente) |
| STJ | Tem aplicado como necessário (controvérsia subsistente) |

## União homoafetiva

| | Conteúdo |
|---|---|
| Base | **ADI 4.277 + ADPF 132** (05/05/2011) |
| Aplicação do Tema 809 | **Plena** |
| Casamento homoafetivo | Resolução **175/2013 CNJ** |
| Reconhecimento póstumo da união | Possível, atraindo o regime do art. 1.829 (jurisprudência do STJ; o requisito da publicidade pode ser relativizado em contexto discriminatório) |

| | Conteúdo |
|---|---|

| STJ REsp 1.904.374 | Alcance temporal da modulação: antes da sentença de partilha, o juiz pode rever decisão que excluíra a companheira com base no CC 1.790 |

## Distinguishing

| Hipótese | Saída |
|---|---|
| União estável **putativa simultânea** ao casamento | **NÃO** atrai 1.829 (Tema 526/529) |
| **Testamento** válido sobre parte disponível | Prevalece sobre vocação |
| Partilha **transitada antes de 10/05/2017** | Preservada |
| Concubinato adulterino | Fora |

## Erros a evitar

- Acreditar que o STF **expressamente declarou** o companheiro herdeiro necessário (silente);
- Aplicar **CC 1.790** a inventários ainda pendentes;
- Confundir **meação** (regime de bens) com **herança** (vocação hereditária);
- Ignorar o **regime de bens** ao calcular a concorrência;
- Negar legitimidade à **união homoafetiva** (equiparada desde 2011);
- Tratar união estável **putativa concomitante** como apta a gerar herança plena.

# Sucessão Legítima

## CC 1.788: regra geral

| | Conteúdo |
|---|---|
| Hipóteses | **Inexistência de testamento** + caducidade + nulidade + bens não compreendidos |
| Caráter | Supletiva ao testamento |

## CC 1.845-1.847: herdeiros necessários + legítima

| | Conteúdo |
|---|---|
| **CC 1.845** | **Herdeiros necessários**: **descendentes + ascendentes + cônjuge** |
| **CC 1.846** | Legítima = **50%** dos bens |
| **CC 1.847** | Liberdade de testar limitada à **outra metade** |

## CC 1.798: legitimação a suceder

| | Conteúdo |
|---|---|
| Regra | Pessoa **existente** ao tempo da abertura |
| Exceção | **Prole eventual** + concebido (nascituro) |

## CC 1.829: ordem de vocação hereditária

| Inc. | Hipótese |
|---|---|
| **I** | **Descendentes** em concorrência com o cônjuge (regimes específicos) |
| **II** | **Ascendentes** em concorrência com o cônjuge (sempre) |
| **III** | **Cônjuge** sobrevivente (sozinho) |
| **IV** | **Colaterais** até **4º grau** (irmãos → sobrinhos → tios → primos/tios-avós/sobrinhos-netos) |

## CC 1.829 I: cônjuge × descendentes: regimes

| Regime | Concorrência |
|---|---|
| **Comunhão UNIVERSAL** | **NÃO concorre** (já tem meação) |
| **Separação OBRIGATÓRIA** | **NÃO concorre** |
| **Comunhão PARCIAL sem bens particulares** | **NÃO concorre** |
| **Comunhão PARCIAL COM bens particulares** | **CONCORRE só sobre os particulares** (STJ REsp 1.368.123) |
| **Separação CONVENCIONAL** | **CONCORRE em TUDO** |
| **Participação final aquestos** | Concorre sobre particulares |

## CC 1.832: cota mínima

| | Conteúdo |
|---|---|
| Concorrência com **filhos comuns** | **Cota mínima de 1/4** ao cônjuge |
| Filhos só do falecido | Não há cota mínima: divide-se proporcionalmente |

## CC 1.838: cônjuge sozinho (3ª ordem)

| | Conteúdo |
|---|---|
| Inexistindo descendentes/ascendentes | Cônjuge recolhe a **totalidade** |
| Independente do regime | Sim |
| Soma | + eventual meação |

## STF Tema 809 (RE 878.694: 2017)

| | Conteúdo |
|---|---|
| Tese | **INCONSTITUCIONAL CC 1.790** |
| Conclusão | União estável (hétero ou homoafetiva) **EQUIPARADA AO CASAMENTO** para sucessão |
| Aplicação | **CC 1.829 integral** ao companheiro |
| Companheiro | Herda segundo o CC 1.829 (regime do cônjuge). A qualificação como **herdeiro necessário** (CC 1.845) é **controvertida**: o STF foi silente na tese do Tema 809, havendo divergência na doutrina e na jurisprudência |
| Modulação | Alcança processos **sem trânsito** da partilha + partilhas extrajudiciais ainda não escrituradas |
| Base | ADPF 132 + ADI 4.277 (união homoafetiva) |

## STF Tema 622 (RE 898.060: 2016)

| | Conteúdo |
|---|---|
| Tese | **MULTIPARENTALIDADE**: paternidade socioafetiva + biológica **COEXISTEM** |
| Efeitos sucessórios | **PLENOS bilaterais**: filho herda de todos os pais; pais herdam do filho |
| Aplicação | Ordem CC 1.836-1.837 estendida |

## Distinção essencial: meação × herança

| | Meação | Herança |
|---|---|---|
| Natureza | **Direito patrimonial** (regime de bens) | **Direito sucessório** |
| Bens | Comuns do casamento/união | Particulares + comuns (parte do falecido) |
| Coexistência | Sim (comunhão universal: meação + exclusão da concorrência) |

## Síntese operacional

| Hipótese | Sucessão |
|---|---|
| Sem testamento | **CC 1.829** integral |
| Falecido + filhos + cônjuge (comunhão univ.) | Filhos integralmente + cônjuge só meação |
| Falecido + filhos + cônjuge (comunhão parcial + particulares) | Concorre sobre particulares (mín. 1/4 com comuns) |
| Falecido + filhos + cônjuge (separação convencional) | Concorre em **tudo** |
| Falecido + ascendentes + cônjuge | Concorrem (regime irrelevante) |
| Falecido + cônjuge só | **Cônjuge recebe totalidade** (CC 1.838) |
| Falecido + colaterais | Até **4º grau** |
| União estável | **= casamento** (Tema 809) |
| Companheiro homoafetivo | **= cônjuge** (ADPF 132) |
| Filho multiparental | Herda **de todos** os pais (Tema 622) |

## Erros a evitar

- **Aplicar CC 1.790** (inconstitucional, Tema 809);
- **Afastar concorrência do cônjuge** com descendentes em comunhão parcial COM particulares;
- **Aplicar concorrência em comunhão universal** (vedada);
- Não respeitar **cota mínima de 1/4** com filhos comuns (CC 1.832);
- Aplicar **ordem pré-CC/2002** (excluindo cônjuge);
- **Ignorar multiparentalidade** sucessória (Tema 622);
- Tratar **união homoafetiva** diferente (vedado, ADPF 132);
- **Confundir meação com herança** (institutos distintos);
- Tratar **companheiro como mero conviviente** sem direito sucessório (herda segundo o CC 1.829, como o cônjuge; o enquadramento como herdeiro necessário é controvertido);
- Excluir **prole eventual** da legitimação (CC 1.798);
- **Admitir testar mais de 50%** quando há herdeiros necessários (viola legítima);
- Aplicar **Tema 809 a partilha escriturada** (modulação afasta).

# Multiparentalidade

## STF Tema 622: RE 898.060 (Min. Luiz Fux, 21/09/2016)

| | Conteúdo |
|---|---|
| Tese | "A **paternidade SOCIOAFETIVA**, declarada ou não em registro público, **NÃO IMPEDE o reconhecimento do VÍNCULO de FILIAÇÃO CONCOMITANTE baseado na ORIGEM BIOLÓGICA**, com os efeitos jurídicos próprios" |
| Marco | **Multiparentalidade PLENA** |
| Efeitos | **Sucessórios + alimentares + previdenciários + nome + poder familiar** |

## Fundamento

| | Conteúdo |
|---|---|
| **CF 227** | Proteção integral |
| **CC 1.593** | Parentesco por **"outra origem"** |
| **ECA** | Convivência familiar |
| **CF 1 III** | **Dignidade da pessoa humana** |
| Critério decisivo | **MELHOR INTERESSE da CRIANÇA e ADOLESCENTE** |

## Provimento CNJ 63/2017 (consolidado pelo Provimento CNJ 149/2023, CNN)

| | Conteúdo |
|---|---|
| Autorizou | **Reconhecimento EXTRAJUDICIAL** da filiação socioafetiva perante o **registro civil** |
| Idade | A partir de **12 ANOS** com seu **consentimento** |

## Súm. 301 STJ

| | Conteúdo |
|---|---|
| Tese | **Presunção *juris tantum*** de paternidade pela **RECUSA AO DNA** |

## Reflexos sucessórios da multiparentalidade

| | Conteúdo |
|---|---|
| Conteúdo | O filho reconhecido em multiparentalidade herda de **todos os pais** (CC 1.829/1.846), como decorrência do Tema 622 |

## Aplicações pós-2020

| | Conteúdo |
|---|---|
| **Socioafetividade post mortem** | Sim |
| **Adoção à brasileira regularizada** | Sim |
| **Reprodução assistida heteróloga** | Não gera vínculo com o **doador** de material genético (CC 1.597 V): multiparentalidade inaplicável ao doador |

## LIMITES do Tema 622: adoção plena anterior

| | Conteúdo |
|---|---|
| Tese | O Tema 622 **NÃO se aplica** automaticamente a hipóteses de **ADOÇÃO PLENA ANTERIOR** |
| Razão | **ECA art. 41** + **CC 1.626** rompem juridicamente o vínculo com a família biológica |
| Discussão | Aferição para evitar busca patrimonial oportunista |

## Efeitos jurídicos da multiparentalidade

| | Conteúdo |
|---|---|
| **Sucessão** | Herda de **TODOS os pais** (CC 1.829 + Tema 622) |
| **Alimentos** | Concorrente entre todos os pais, com rateio conforme as possibilidades (CC 1.698) |
| **Pensão por morte** | Concorre |
| **Nome** | Pode constar de todos |
| **Poder familiar** | Compartilhado |
| **Plano de saúde** | Dependente |

## Distinções essenciais

| | Multiparentalidade | Adoção plena |
|---|---|---|
| Vínculo biológico | **Mantido** | **ROMPIDO** (ECA 41) |
| Efeitos | Plurais | Substitutivos |

| | Filiação biológica | Socioafetiva |
|---|---|---|
| Origem | Genética | **Convivência + afeto** |
| Reconhecimento | DNA | Extrajudicial Prov. CNJ 149 |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Pai biológico + pai socioafetivo | **Multiparentalidade** (Tema 622) |
| Reconhecimento extrajudicial > 12a | **Prov. CNJ 149** + consentimento |
| Adoção plena prévia | **ECA 41 LIMITA** Tema 622 (vínculo biológico rompido) |
| Reprodução heteróloga | Sem vínculo com o doador (CC 1.597 V) |
| Recusa ao DNA | **Súm. 301**: presunção *juris tantum* |
| Sucessão | Herda de **todos** |
| Alimentos | Concorrentes (vários pais, rateio CC 1.698) |
| Pensão por morte | Concorre |
| Filho > 12 anos | Consentimento obrigatório |
| Filho < 12 anos | Curador especial + interesse |

## Erros a evitar

- **Tratar filiação biológica e socioafetiva como EXCLUDENTES** (Tema 622);
- **Aplicar Tema 622 a ADOÇÃO PLENA prévia** (ECA 41 + CC 1.626 rompem o vínculo biológico);
- Admitir busca patrimonial **OPORTUNISTA** sem aferição;
- Não exigir **consentimento de > 12 anos** (Prov. CNJ 149);
- Afastar **efeitos sucessórios** plenos;
- Aplicar **Súm. 301 como presunção absoluta** (é *juris tantum*);
- Tratar **socioafetividade como vínculo inferior** (são equivalentes);
- Afastar **reconhecimento extrajudicial** (Prov. CNJ 149);
- Aplicar **pensão por morte** com exclusividade biológica;
- Não considerar **MELHOR INTERESSE** como critério prevalente;
- Ignorar os reflexos sucessórios plenos da multiparentalidade (CC 1.829/1.846 + Tema 622).

# Deserdação

## Marco legal

- **CC 1.961-1.965** (deserdação);
- **CC 1.814-1.818** (indignidade, comparativo);
- **CC 1.845-1.846** (herdeiros necessários + legítima);
- **CC 1.857-1.880** (testamento);
- Ação declaratória pelas vias ordinárias (prova da causa, CC 1.965).

## Conceito

| | Conteúdo |
|---|---|
| **Deserdação** | Privação **por ato do testador** dos direitos sucessórios de herdeiro necessário |
| **Apenas herdeiros necessários** | CC 1.845 |
| **Forma** | Testamento + causa expressa |
| **Confirmação** | Prova judicial pelos demais herdeiros/legatários |
| **Excepcionalidade** | Restrição à legítima (CC 1.846) |

## Herdeiros necessários (CC 1.845)

| | Conteúdo |
|---|---|
| **Descendentes** | Filhos + netos + bisnetos |
| **Ascendentes** | Pais + avós + bisavós |
| **Cônjuge** | Pós-Reforma 2002 (antes não era) |
| **Companheiro?** | CONTROVERTIDO: o Tema 809 STF aplicou o regime do CC 1.829 à união estável, mas foi silente quanto ao CC 1.845 |
| **Legítima** | 50% da herança (CC 1.846) |

## Causas para descendente (CC 1.962)

| | Conteúdo |
|---|---|
| **I** | Ofensa **física** |
| **II** | **Injúria grave** |
| **III** | Relações **ilícitas** com madrasta/padrasto |
| **IV** | **Desamparo** do ascendente em alienação mental ou grave enfermidade |

## Causas para ascendente (CC 1.963)

| | Conteúdo |
|---|---|
| **I** | Ofensa física |
| **II** | Injúria grave |
| **III** | Relações ilícitas com mulher/companheira do filho/neto ou com marido/companheiro da filha/neta |
| **IV** | Desamparo do filho/neto com deficiência mental ou grave enfermidade |

## Causas comuns (CC 1.961 + 1.814)

Aplicam-se também as causas de **indignidade** (CC 1.814):

| | Conteúdo |
|---|---|
| **I** | Autores, co-autores ou partícipes de homicídio doloso/tentativa contra o autor da herança, ascendente, descendente, cônjuge ou companheiro |
| **II** | Acusaram caluniosamente em juízo o autor da herança ou contra ele cometeram crime contra a honra |
| **III** | Por violência ou meios fraudulentos, inibiram ou obstaram o autor da herança de dispor livremente de seus bens |

## Procedimento

### 1. Testamento (CC 1.964)

> "Somente com expressa declaração de causa pode a deserdação ser ordenada em testamento."

| | Conteúdo |
|---|---|
| **Forma** | Testamento público + cerrado + particular |
| **Causa** | Específica + expressa |
| **Sem causa** | Inválida |
| **Genérica** | "Não merece": inválida |

### 2. Prova judicial (CC 1.965)

> "Ao herdeiro instituído, ou àquele a quem aproveite a deserdação, **incumbe provar a veracidade da causa alegada pelo testador**."

| | Conteúdo |
|---|---|
| **Não basta a declaração** | Prova é necessária |
| **Ônus** | Do interessado (não do deserdado) |
| **Ação própria** | Sob CC 1.965 |
| **Cognição plena** | Contraditório completo |

### 3. Prazo decadencial

| | Conteúdo |
|---|---|
| **Prazo** | **4 anos** (CC 1.965 par.) |
| **Início** | **Abertura do testamento** |
| **Decadencial** | Não se interrompe |
| **Perda** | Direito de comprovar caduca |

## Deserdação × Indignidade: comparativo

| | Deserdação | Indignidade |
|---|---|---|
| **Forma** | Testamento + causa | Sentença judicial |
| **Iniciativa** | Testador | Qualquer interessado |
| **Sujeito** | Apenas herdeiro necessário | Qualquer herdeiro |
| **Hipóteses** | CC 1.961-1.963 (mais amplas) | CC 1.814 (3 hipóteses) |
| **Momento** | Em vida (testamento) | Após a morte |
| **Prazo** | 4 anos (CC 1.965) | 4 anos (CC 1.815 par.) |
| **Efeito** | Exclusão da sucessão | Idem |

## Efeitos da deserdação

| | Conteúdo |
|---|---|
| **Perda** | Quinhão hereditário do deserdado |
| **Efeitos pessoais** | A exclusão atinge só o deserdado: os descendentes do deserdado herdam como se ele morto fosse (aplicação analógica do CC 1.816) |
| **Cônjuge supérstite** | Pode aplicar regras próprias |
| **Doações em vida** | Não afetadas (em regra) |

## Companheiro × cônjuge

| | Conteúdo |
|---|---|
| **CC 1.845** | Não menciona companheiro |
| **STF Tema 809** | Inconstitucionalidade do CC 1.790: aplica-se o regime sucessório do CC 1.829 também à união estável (silente quanto ao CC 1.845) |
| **Herdeiro necessário?** | CONTROVERTIDO: o STF foi silente no Tema 809 quanto ao CC 1.845; o STJ oscila (3ª T., REsp 1.357.117/2018, pela inclusão; 3ª T., 2022, em sentido contrário) |
| **Deserdação** | Aplicabilidade ao companheiro depende dessa qualificação (questão em aberto) |

## Ação de deserdação (vias ordinárias)

| Etapa | Conteúdo |
|---|---|
| 1. **Abertura do testamento** | Início do prazo |
| 2. **Ação declaratória** | Pelo interessado |
| 3. **Réu** | Deserdado |
| 4. **Provas** | Documental + testemunhal |
| 5. **Sentença** | Reconhece ou afasta a deserdação |
| 6. **Recurso** | Tribunal |
| 7. **Trânsito** | Define a partilha |

## Provas robustas

| | Conteúdo |
|---|---|
| **Boletim de ocorrência** | Lesão física |
| **Sentenças criminais** | Crimes |
| **Testemunhas** | Familiares + vizinhos |
| **Documentos** | Cartas, mensagens, e-mails |
| **Perícia** | Em alguns casos |
| **Histórico médico** | Para "desamparo + grave enfermidade" |

## Inalegabilidade

| | Conteúdo |
|---|---|
| **Após o prazo** | Deserdação caduca |
| **Sem testamento** | Herdeiro deserdado herda normalmente |
| **Sem causa expressa** | Idem |
| **Causa não comprovada** | Idem |

## Reabilitação?

| | Conteúdo |
|---|---|
| **CC 1.818** | Indignidade: reabilitação possível por ato expresso |
| **Deserdação** | **Sem previsão** específica: opera pela revogação do testamento (CC 1.969-1.972), inclusive tácita |

## Aspectos práticos

| | Conteúdo |
|---|---|
| **Cuidado com testamento** | Causa específica + provas pré-constituídas |
| **Inventário** | Não pode incluir o deserdado (com prova) |
| **Custas** | Para o vencido |
| **Honorários** | Sucumbência |

## STJ: orientações

| | Conteúdo |
|---|---|
| **Aplicação restritiva** | Atender literalidade |
| **Causa específica** | Necessária |
| **Provas robustas** | Exigidas |
| **Princípio do favor heredis** | Aplicação |
| **Tendência** | Garantir legítima |

## Erros a evitar

- A deserdação alcança apenas o **herdeiro necessário** (CC 1.961);
- A deserdação exige **causa expressa** no testamento (CC 1.964);
- A causa **genérica** (ex.: "não merece") é inválida;
- A deserdação depende de **ação e prova judicial** (CC 1.965);
- O **prazo de 4 anos** é decadencial;
- Deserdação (testamento) e **indignidade** (judicial) são institutos distintos;
- Os **fatos pretéritos** exigem prova robusta documentada;
- A **sub-rogação** dos descendentes do deserdado deve ser observada;
- A deserdação não alcança **legados**, restrita à herança da legítima;
- A deserdação difere da **renúncia** (ato do herdeiro);
- A qualificação do **companheiro** como herdeiro necessário (CC 1.845) é controvertida; o Tema 809 STF tratou apenas do regime sucessório do CC 1.829;
- A reabilitação não é **automática**: opera pela revogação do testamento.

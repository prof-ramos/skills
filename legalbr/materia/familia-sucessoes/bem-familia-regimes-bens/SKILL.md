# Bem de Família + Regimes + Adoção + Tutela/Curatela

## Bases legais

- **CF 226**;
- **CC 1.618-1.619 + 1.639-1.688 + 1.711-1.722 + 1.728-1.783** (arts. 1.620-1.629 revogados pela Lei 12.010/2009);
- **Lei 8.009/90** (bem família legal);
- **ECA + Lei 12.010/09 + Lei 13.509/17** (adoção);
- **Lei 13.146/2015** (LBI);
- **Lei 14.382/2022** + **Provimento CNJ 149/2023**.

## Bem de família

### Voluntário (1.711-1.722)
- Escritura/testamento + registro CRI;
- Até **1/3** do patrimônio líquido;
- Impenhorável + **inalienável**.

### Legal (Lei 8.009/90)
- Automaticamente impenhorável;
- **Súm. 364 STJ**: solteiro/separado/viúvo;
- **Súm. 486 STJ**: único imóvel locado para subsistência;
- **Súm. 449 STJ**: vaga garagem com matrícula própria **penhorável**.

### Exceções (art. 3)

| | Conteúdo |
|---|---|
| II | Financiamento do imóvel |
| III | Pensão alimentícia |
| IV | Impostos/condomínio (propter rem) |
| V | Hipoteca (garantia real pelo casal) |
| **VII** | **Fiança locatícia**: STF Tema 1.127 (RE 1.307.334) e STJ Tema 1.091 (REsp 1.836.371): penhora válida em locação **comercial e residencial** |

A impenhorabilidade do bem de família legal é matéria de ordem pública e pode ser **reconhecida de ofício** pelo juiz.

## Regimes de bens (1.639-1.688)

| | Conteúdo |
|---|---|
| **Comunhão parcial** | Regra (1.658-1.666) |
| Comunhão universal | 1.667-1.671 |
| Separação total | 1.687-1.688 |
| Participação final aquestos | 1.672-1.686 |

### Separação obrigatória (1.641)

| Hipótese | |
|---|---|
| I | Causas suspensivas (1.523) |
| **II** | Maiores de **70 anos** |
| III | Suprimento judicial |

### Súm. 377 STF + releitura STJ

Separação obrigatória admite **comunicação dos aquestos** onerosos, mas a releitura consolidada do STJ (EREsp 1.623.858/MG, 2ª Seção) **exige prova do esforço comum**: a comunicação **não é automática nem presumida**; o ônus é de quem pleiteia a partilha.

**STF Tema 1.236** (ARE 1.309.642, fixado em 01/02/2024): nos casamentos e uniões estáveis com pessoa maior de 70 anos, o regime de separação do CC 1.641 II **pode ser afastado** por manifestação expressa via escritura pública. Não declarou inconstitucional o art. 1.641 II (regra subsidiária mantida).

### Alteração de regime (1.639 §2 + Lei 14.382/22)

- Judicial **ou extrajudicial** (Provimento CNJ 149/2023);
- Pedido conjunto + motivado + ressalva a terceiros + edital;
- **Ex nunc**.

## Adoção (CC 1.618-1.619 + ECA 39-52)

### Características

- Ato **judicial**, **irrevogável**, igualdade plena (CF 227 §6);
- Desliga do biológico (ECA 41).

### Requisitos

| | Conteúdo |
|---|---|
| Adotante | ≥ 18 anos (ECA 42) |
| Diferença | **16 anos** (42 §3) |
| Consentimento | Pais biológicos ou destituição; adotando > 12 anos |
| Estágio convivência | Até **90 dias** prorrogáveis (Lei 13.509/17) |
| **SNA** | Habilitação prévia |

### Modalidades

- Unilateral (42 §1); conjunta (42 §2);
- **Homoafetiva** admitida (ADI 4.277 + Res. CNJ 175/2013);
- Póstuma (42 §6);
- Internacional (Convenção Haia 1993);
- **À brasileira** = crime CP 242 (mas STJ prevalece socioafetivo consolidado).

### Multiparentalidade: STF Tema 622

Socioafetiva **concomitante** com biológica; Provimento CNJ 149/2023 (registro extrajudicial).

## Tutela (1.728-1.766)

- Para menores (pais falecidos/destituídos/omissos);
- **Subsidiária**;
- Espécies: testamentária, **legítima** (1.731), dativa;
- Atos com autorização judicial (1.748): alienar imóveis, transigir, herança.

## Curatela (1.767-1.783): LBI

| | Conteúdo |
|---|---|
| **Reforma LBI** | Deficiência por si só **não** acarreta incapacidade (LBI 6) |
| **Excepcional** | Limitada a atos negociais/patrimoniais (LBI 85) |
| **Não afeta** | Corpo, sexualidade, matrimônio, voto |
| Sujeitos | Quem não pode exprimir vontade; ébrios/viciados; pródigos |
| **Termo** | "Curatela sob medida" (CPC 755) |
| **TDA** (1.783-A) | **Alternativa preferencial**, com 2 apoiadores |
| Compartilhada | 1.775-A LBI |

## Erros a evitar

- A penhora do bem de família do fiador **comercial** é constitucional (Tema 1.127 STF);
- A comunicação dos aquestos na **separação obrigatória** exige prova do esforço comum (releitura STJ da Súm. 377, EREsp 1.623.858), não se presume;
- A alteração do regime de bens opera com efeitos **ex nunc**, não ex tunc;
- A adoção é **irrevogável** (ECA art. 39, §1º);
- A **multiparentalidade** deve ser observada (STF Tema 622);
- A curatela é "sob medida", não **genérica** (LBI);
- A **TDA** é alternativa preferencial (LBI 1.783-A);
- A **deficiência** não gera incapacidade automática (LBI 6);
- A separação obrigatória aplica-se a partir dos **70 anos** (Lei 12.344/10), não dos 60;
- A habilitação prévia no **SNA** é obrigatória na adoção.

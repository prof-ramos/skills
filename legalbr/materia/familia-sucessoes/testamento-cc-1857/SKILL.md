# Testamento

## Fundamentos legais

| | Conteúdo |
|---|---|
| **CC 1.857** | Toda pessoa capaz dispõe; o §1 limita à **parte disponível (50%)** se houver herdeiros necessários (CC 1.789/1.845: descendentes + ascendentes + cônjuge) |
| **STJ 3ª T** (2023) | Admite que testamento **mencione** a legítima desde que não a reduza (princípio da conservação) |
| **CC 1.858-1.860** | Capacidade ativa: maiores de **16 anos**; vedado ao absolutamente incapaz; **decadência 5 anos** para anulação |

## Modalidades ordinárias

| Modalidade | Conteúdo |
|---|---|
| **Público** (1.864-1.867) | Tabelião + **2 testemunhas** |
| **Cerrado** (1.868-1.875) | Escrito pelo testador + auto de aprovação |
| **Particular** (1.876-1.880) | Escrito + leitura perante **3 testemunhas** + confirmação judicial |

## Modalidades especiais (CC 1.886-1.896)

| | Conteúdo |
|---|---|
| **Marítimo** | A bordo de navio |
| **Aeronáutico** (1.888) | A bordo de aeronave |
| **Militar** (1.893) | Militar em campanha/operação |

## Flexibilização STJ: testamento particular

| | Conteúdo |
|---|---|
| **REsp 1.633.254** + julgados posteriores (Inf. 2022/2024) | Princípio da **conservação da vontade do testador** permite confirmar testamento mesmo com **vícios formais não-essenciais** |
| **STJ 2024** | Falta de **1 testemunha** = vício puramente formal: NÃO anula se vontade inequívoca |
| **CC 1.879** | Testamento particular em **circunstâncias excepcionais SEM testemunhas**, com confirmação judicial |
| Distinção | **Vício essencial** (falta de assinatura + incapacidade) → nulidade; **vício acidental** → sanável |

## Codicilo (CC 1.881)

| | Conteúdo |
|---|---|
| Definição | Escrito particular **datado + assinado** para: enterro + esmolas + **móveis + roupas + joias** de pouco valor |
| Critério legal | "Bens de pouco valor" (CC 1.881), aferido caso a caso; sem percentual fixo em lei |
| Formalidade | O codicilo **dispensa as formalidades do testamento** (CC 1.881): basta escrito particular datado e assinado, sendo indevida a exigência dos requisitos do testamento |

## Deserdação (CC 1.961-1.965)

| | Conteúdo |
|---|---|
| Natureza | **Rol TAXATIVO** (1.962/1.963) |
| **STJ** | Interpretação **teleológica/sistemática** das causas (não meramente literal) |
| Causas | Atentado contra a vida + ofensa física + injúria grave + relações ilícitas + desamparo em enfermidade/deficiência |
| Exigências | **Testamento + ação judicial** + prova robusta |

## Revogação (CC 1.969-1.972)

| | Conteúdo |
|---|---|
| Forma | **Mesma do testamento** (expressa/tácita) |
| **STJ 3ª T** | Testamentos sucessivos têm relação de **complementaridade**: o posterior **NÃO revoga integralmente** o anterior, apenas no que for incompatível |
| **Casamento posterior** | **NÃO revoga** testamento (≠ common law) |

## Atualizações normativas

| | Conteúdo |
|---|---|
| **Lei 14.382/2022** (Marco dos Registros Públicos) | Desjudicialização |
| **Res. CNJ 571/2024** | Inventário/testamento **extrajudicial** mesmo com herdeiro incapaz/menor (frações ideais + parecer favorável do MP) e mesmo com testamento (exige autorização judicial em ação de abertura + trânsito em julgado + todos capazes/concordes) |
| **STF Tema 809** (RE 878.694) | União estável equiparada ao casamento na sucessão; companheiro tratado como o cônjuge para fins do CC 1.829 (o enquadramento como herdeiro necessário do CC 1.845 é controvertido) |

## Procedimento

| Etapa | Conteúdo |
|---|---|
| 1 | Abertura (CC 1.974+) + publicação |
| 2 | Cumprimento (CC 1.975+) |
| 3 | Testamenteiro (CC 1.976+) |
| 4 | Inventário + partilha |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Testador com herdeiros necessários | Dispõe **50%** (parte disponível) |
| Testador sem necessários | Dispõe **100%** |
| Particular com 3 testemunhas | Válido |
| Particular com vício formal não-essencial | **Validado** (STJ, conservação) |
| Pequeno valor (móveis/joias) | **Codicilo** (CC 1.881) |
| Deserdação por causa atípica | **Inválida** (rol taxativo) |
| Casamento posterior | **NÃO revoga** |
| Testamento posterior parcialmente conflitante | **Complementaridade** (STJ) |
| Inventário extrajudicial com testamento | Possível com autorização judicial (Res. CNJ 571) |

## Erros a evitar

- O **vício não-essencial** não acarreta anulação (STJ, conservação da vontade);
- As **3 testemunhas** comportam mitigação havendo vontade inequívoca (STJ);
- A **deserdação por causa atípica** não é admitida (rol taxativo);
- O **codicilo** deve ser considerado (CC 1.881);
- O **casamento posterior** não revoga o testamento (CC 1.969);
- O **inventário extrajudicial com incapaz** é autorizado com frações ideais e MP (Res. CNJ 571/2024);
- A menção válida no testamento não **reduz a legítima** (STJ);
- O **prazo decadencial** é de 5 anos (CC 1.859);
- O testador **incapaz** (menor de 16 ou absolutamente incapaz) não pode testar;
- O testamento particular depende de **confirmação judicial** (CC 1.876 e seguintes);
- A **mera incompatibilidade parcial** com testamento posterior não revoga o anterior (complementaridade, STJ).

# Família Recomposta + Multiparentalidade

## Marco legal

- **CC 1.595** (parentesco por afinidade);
- **CC 1.593** (parentesco de origem natural ou outra);
- **STF Tema 622, RE 898.060/2016** (multiparentalidade);
- **Lei 11.924/2009** (nome do enteado);
- **Provimento CNJ 63/2017** (paternidade socioafetiva extrajudicial);
- **ECA art. 27** (filiação);
- **CC 1.829** (sucessão);
- **CF 226** + 227 (entidade familiar + proteção integral).

## Conceito de família recomposta

| | Conteúdo |
|---|---|
| **Sinônimos** | Família mosaico, ensamblada, plural |
| **Composição** | Casal + filhos de relações anteriores |
| **Relações** | Padrasto + madrasta + enteado + irmãos consanguíneos/socioafetivos |
| **Reconhecimento** | CF 226 (família plural) |
| **Crescimento** | Pós-Lei do Divórcio (1977) + sociedade moderna |

## Parentesco por afinidade (CC 1.595)

> "Cada cônjuge ou companheiro é aliado aos parentes do outro pelo vínculo da afinidade."

| Tipo | Conteúdo |
|---|---|
| **Linha reta (sogros, enteados)** | Afinidade na linha reta **não se extingue** com a dissolução (CC 1.595 §2) |
| **Colateral (cunhados, 2º grau)** | Cessa com a dissolução |
| **Limite (CC 1.595 §1)** | Afinidade limita-se aos ascendentes, descendentes e irmãos do cônjuge/companheiro |
| **Padrasto/madrasta** | Afinidade em linha reta, perpétua |
| **Impedimento ao casamento** | Afins em linha reta, p. ex. sogros (CC 1.521 II) |

## STF Tema 622 (RE 898.060/2016)

### Tese

> "A paternidade socioafetiva, declarada ou não em registro público, **não impede o reconhecimento do vínculo de filiação concomitante baseado na origem biológica**, com efeitos jurídicos próprios."

| | Conteúdo |
|---|---|
| **Multiparentalidade** | Reconhecida |
| **Efeitos jurídicos próprios** | Para ambas filiações |
| **Igualdade entre filhos** (CF 227 §6) | Garantida |
| **Sem hierarquia** | Entre biológica + socioafetiva |

## Efeitos da multiparentalidade

| | Conteúdo |
|---|---|
| **Alimentos** | Dever concorrente entre todos os pais (rateio conforme possibilidades, CC 1.698) |
| **Guarda + visitas** | Reconhecida |
| **Sucessão** | Cada pai/mãe é fonte sucessória |
| **Nome civil** | Pode incluir todos |
| **Pensão por morte (INSS)** | Aplicação |
| **Plano de saúde + dependentes** | Aplicação |
| **Doação + tributário** | ITCMD por linha |

## Lei 11.924/2009: nome do enteado

> "Permite ao enteado ou enteada, havendo motivo ponderável e na forma dos §§ 2º e 7º do art. 57 da Lei 6.015/1973, **adotar o nome de família** do padrasto ou madrasta, mediante autorização."

| | Conteúdo |
|---|---|
| **Apenas acréscimo** | Não substitui nome do pai biológico |
| **Anuência** | Padrasto/madrasta + enteado |
| **Mediante autorização judicial** | Em alguns casos |
| **Em vida** | Não substitui adoção |

## Erros a evitar

- Achar que **padrasto** = pai legal (apenas afinidade, salvo socioafetividade);
- Aplicar **dever alimentar** automático ao padrasto (não há, salvo socioafetividade);
- Esquecer **STF Tema 622** (multiparentalidade);
- Confundir **adoção** com socioafetividade (adoção substitui; multiparentalidade soma);
- Aplicar **CC 1.595** (afinidade) sem ver linha reta vs. colateral;
- Negar **direitos sucessórios** na multiparentalidade (todos os pais geram sucessão);
- Esquecer **Provimento CNJ 63/2017** (paternidade socioafetiva extrajudicial);
- Tratar enteado sempre como dependente (depende de socioafetividade);
- Não documentar **posse de estado de filho**;
- Aplicar Lei 11.924 como adoção (apenas acréscimo de nome);
- Esquecer **CF 227 §6** (igualdade entre filhos);
- Aplicar ITCMD em **linha colateral** se houver socioafetividade reconhecida (linha reta).

# Fideicomisso

## Marco legal

- **CC 1.951-1.960** (Capítulo XVIII do Livro V);
- **CC 1.943-1.960** (substituições testamentárias);
- **CC 1.829 + 1.846** (sucessão legítima e legítima);
- **CC 1.857** (testamento);
- Lei 11.441/2007 (inventário extrajudicial);
- CC 1.911 (cláusulas restritivas);
- Lei estadual (ITCMD).

## Conceito (CC 1.951)

> "Pode o testador instituir herdeiros ou legatários, estabelecendo que, por ocasião de sua morte, a herança ou o legado se transmita ao fiduciário, resolvendo-se o direito deste, por sua morte, a certo tempo ou sob certa condição, em favor de outrem, que se qualifica de fideicomissário."

## Estrutura

| Pessoa | Função |
|---|---|
| **Testador** | Instituidor (de cujus) |
| **Fiduciário** | Recebe inicialmente: deve conservar + transmitir |
| **Fideicomissário** | Beneficiário final |
| **Termo, condição ou morte do fiduciário** | Dispara a transmissão |

## Pressupostos (CC 1.952)

| | Conteúdo |
|---|---|
| **Fideicomissário não concebido** | Ao tempo da morte do testador |
| **Razão** | Evitar a perpetuação de vínculos sobre o patrimônio |
| **Se já nascido** | Aplica-se o CC 1.952 par. (propriedade direta + usufruto do fiduciário) |

### Exceção (CC 1.952 par.)

> "Se, ao tempo da morte do testador, já houver nascido o fideicomissário, **adquirirá este a propriedade dos bens fideicometidos, convertendo-se em usufruto o direito do fiduciário**."

| | Conteúdo |
|---|---|
| **Já concebido + nascido** | Vira proprietário direto |
| **Fiduciário** | Vira usufrutuário |
| **Conversão** | Automática |

## Limite: 2º grau (CC 1.959)

> "**São nulos os fideicomissos além do segundo grau**."

| | Conteúdo |
|---|---|
| **Permitido** | Fiduciário → 1 fideicomissário |
| **Vedado** | Fideicomissário → 2º fideicomissário |
| **Razão** | Evitar perpetuação |
| **Em vida** | Permitido transmitir |

## Obrigações do fiduciário

| | Conteúdo |
|---|---|
| **Conservar os bens** | Não deteriorar (CC 1.953) |
| **Inventariar** | Lista dos bens fideicometidos |
| **Pagar ITCMD** | Sobre a herança/legado |
| **Caução** | Se fideicomissário exigir (CC 1.953 par.) |
| **Frutos** | Pertencem ao fiduciário |
| **Restituir** | No momento da transmissão |

## Direitos do fiduciário

| | Conteúdo |
|---|---|
| **Posse + uso** | Como dono |
| **Frutos + rendimentos** | Próprios |
| **Alienação** | Vedada (sem consentimento) |
| **Penhora** | Restrições |
| **Direito de propriedade resolúvel** | Tipo específico |

## Direitos do fideicomissário

| | Conteúdo |
|---|---|
| **Aquisição condicional** | Após condição/termo |
| **Cessão** do direito | Possível em alguns casos |
| **Renúncia** | Faz consolidar no fiduciário |
| **Conservação** | Pode exigir do fiduciário |
| **Inventário** | Direito de exigir |

## Caducidade (CC 1.958)

> "Caduca o fideicomisso se o fideicomissário **morrer antes** do fiduciário, ou antes de realizar-se a condição resolutória do direito deste último; nesse caso, a propriedade consolida-se no fiduciário."

| | Conteúdo |
|---|---|
| **Morte do fideicomissário** | Antes do fiduciário ou da condição |
| **Consolidação** | No fiduciário (vira proprietário pleno) |
| **Herdeiros do fideicomissário** | Não recebem (em regra) |
| **Exceção** | Se houver disposição em contrário |

## Distinção: fideicomisso × usufruto × substituição vulgar

| | Fideicomisso | Usufruto | Substituição vulgar |
|---|---|---|---|
| **Beneficiário** | Sucessor temporário | Usufrutuário |  Substituto |
| **Propriedade** | Resolúvel (fiduciário) | Nu-propriedade ao nu-proprietário | Definitiva |
| **Termo** | Sim | Sim | Caso de não-aceite |
| **Comum** | Raro | Comum | Comum |
| **CC** | 1.951 | 1.390 | 1.947 |

## Substituição vulgar (CC 1.947): comparativo

| | Conteúdo |
|---|---|
| **Definição** | Indica substituto **caso o primeiro não queira ou não possa** receber |
| **Hipóteses** | Premorte, renúncia, indignidade |
| **Diferença** | Não há sucessão em cadeia: só se o 1º falhar |

## Casos de aplicação

| | Conteúdo |
|---|---|
| **Neto não-concebido** | Fideicomissário (filho → fiduciário) |
| **Cônjuge + filho não-nascido** | Fideicomissário (cônjuge → fiduciário) |
| **Doação reversível** | Instituto distinto (CC 547), não é fideicomisso |
| **Trust** | Não se confunde: institutos distintos |
| **Doação com encargo** | Diferente |

## ITCMD

| | Conteúdo |
|---|---|
| **Tributa o fiduciário** | Sobre a herança/legado |
| **Tributa o fideicomissário** | Quando recebe (segunda incidência) |
| **Controvérsia** | Há discussão sobre dupla incidência (bis in idem) nas duas transmissões |
| **Estaduais** | Tabelas variam |
| **Reforma tributária** | Pode alterar |

## Direito sucessório do fideicomissário

| | Conteúdo |
|---|---|
| **Inalienável** durante o fideicomisso | Em regra |
| **Cessível** com cautela | Em alguns casos |
| **Penhora** | Restrita |
| **Herdeiros do fideicomissário** | Em geral não recebem (CC 1.958) |

## Renúncia + indignidade

| | Conteúdo |
|---|---|
| **Renúncia do fideicomissário** | Consolida no fiduciário |
| **Indignidade** | Excluída |
| **Cessão** | Mediante condições |
| **CC 1.955** | Renúncia do fideicomissário caduca o fideicomisso e consolida a propriedade no fiduciário, salvo disposição em contrário |

## Aspectos práticos

| | Conteúdo |
|---|---|
| **Testamento** | Forma necessária (público ou cerrado) |
| **Notário** | Lavratura cuidadosa |
| **Registro de Imóveis** | Averbar para imóveis |
| **Aplicação rara** | Em desuso na prática |

## Erros a evitar

- Permitir fideicomisso **além do 2º grau** (CC 1.959, nulo);
- Aplicar a **fideicomissário já concebido** sem ver CC 1.952 par. (vira proprietário direto);
- Confundir fideicomisso com **trust** (institutos distintos; a Lei 14.754/2023 trata do trust no plano tributário);
- Esquecer a questão da **dupla incidência do ITCMD** nas duas transmissões (controvertida);
- Confundir com **usufruto** (regimes próprios);
- Aplicar **fideicomisso entre vivos** (vedado: só testamentário no Brasil);
- Esquecer **caducidade** (CC 1.958) por premorte do fideicomissário;
- Não exigir **caução do fiduciário** se patrimônio relevante;
- Aplicar a **substituição vulgar** com regras de fideicomisso;
- Esquecer registro **em RI** para imóveis;
- Tratar herdeiros do fideicomissário como sucessores (em regra não recebem);
- Confundir com **doação reversível** (CC 547, diferente).

# Adoção Internacional

## Marco legal

| | Conteúdo |
|---|---|
| **Convenção da Haia** | Proteção das Crianças + Cooperação em Matéria de Adoção Internacional (1993) |
| **Dec. 3.087/1999** | Internalização |
| **ECA arts. 51-52** | Disciplina |
| **Lei 12.010/2009** | **Nova Lei da Adoção**: reformulou o ECA + idade mínima do adotante 18 anos (era 21) |

## ECA art. 51: definição

| | Conteúdo |
|---|---|
| Conceito | Pretendente com **residência habitual em PAÍS-PARTE** da Convenção deseja adotar criança em outro país-parte |

## PRINCÍPIO da SUBSIDIARIEDADE

| | Conteúdo |
|---|---|
| Regra | **APENAS após esgotadas TENTATIVAS NACIONAIS** (família substitutiva ou extensa) |
| Prévia consulta | **SNA** (Sistema Nacional de Adoção e Acolhimento) |
| **Res. CNJ 289/2019** | Unificou **CNA + CNCA** → **SNA** |

## PROCEDIMENTO

| Fase | Conteúdo |
|---|---|
| **(i)** | **Habilitação no PAÍS DE ORIGEM** perante autoridade central |
| **(ii)** | **Laudo de habilitação** pela autoridade central estrangeira |
| **(iii)** | Protocolo perante **ACAF/MJSP** (Autoridade Central Administrativa Federal) + **Autoridade Central ESTADUAL** (vinculada ao TJ) |
| **(iv)** | Análise pela **CEJAI/CEJA** (Comissões Estaduais Judiciárias de Adoção Internacional) |
| **(v)** | **Estudo PSICOSSOCIAL** |
| **(vi)** | **ESTÁGIO DE CONVIVÊNCIA SUPERVISIONADO OBRIGATÓRIO** **em território nacional** + **30 dias** (ECA art. 46 §3) + acompanhamento técnico |
| **(vii)** | **Sentença constitutiva** |

## Países NÃO signatários da Haia

| | Conteúdo |
|---|---|
| Exigência | **Homologação da sentença estrangeira pelo STJ** (CF 105 I "i") |

| | Conteúdo |
|---|---|

| **Diferença etária mínima** | **16 anos** entre adotante e adotando |
| Flexibilização | STJ admite **socioafetividade** como mitigação da diferença etária |

|---|---|

## Distinções essenciais

| | Adoção nacional | Internacional |
|---|---|---|
| Pretendentes | Brasileiros (residência BR) | **Residência no exterior** |
| Subsidiariedade | Não se aplica | **Esgotamento de tentativas nacionais** |
| Estágio | Variável | **30 dias mínimo no BR** |
| Autoridade | TJ local | **ACAF + CEJAI** |

| | Países-Parte Haia | Não signatários |
|---|---|---|
| Reconhecimento | Automático entre países-partes | **Homologação STJ** |

## Adoção homoafetiva

| | Conteúdo |
|---|---|
| **ADI 4.277 + ADPF 132** | União homoafetiva reconhecida |
| Adoção | Plenamente cabível (nacional + internacional) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Adotante BR + criança BR | **Adoção nacional** |
| Adotante exterior (país-parte) | **Adoção internacional** + procedimento Haia |
| Tentativas nacionais esgotadas | **Subsidiariedade atendida** |
| Estágio de convivência | **30 dias no BR** (ECA 46 §3) |
| País não signatário | **Homologação STJ** |
| Adotante < 18 anos | **VEDADA** (ECA 42, red. Lei 12.010/2009) |
| Diferença < 16 anos | Em regra vedada; STJ flexibiliza |
| Adoção homoafetiva | **CABE** (ADI 4.277) |
| Trânsito em julgado | **IRREVOGÁVEL** (ECA 39 §1) |

## Erros a evitar

- A adoção internacional exige **esgotamento das tentativas nacionais** (subsidiariedade);
- O **estágio de convivência** em território nacional não se suprime (ECA 46 §3, 30 dias);
- A adoção internacional depende de **ACAF e CEJAI** (autoridades centrais);
- O **adotante menor de 18 anos** não é admitido (ECA 42, red. Lei 12.010/2009);
- A **diferença de 16 anos** comporta flexibilização na socioafetividade (STJ);
- A adoção internacional para **país não signatário** exige **homologação no STJ**;
- A adoção **homoafetiva** é cabível (ADI 4.277);
- A adoção é **irrevogável** (ECA 39 §1);
- O **direito à origem** subsiste (ECA 48);
- A adoção depende de **prévia consulta ao SNA**;
- A **Lei 14.451/2022 não trata de adoção** (altera quóruns da sociedade limitada no CC): não citar como fundamento etário;
- As **regras da adoção pré-Lei 12.010** estão revogadas.

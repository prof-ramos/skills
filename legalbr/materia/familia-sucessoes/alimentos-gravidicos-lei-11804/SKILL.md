# Alimentos Gravídicos

## Lei 11.804/2008: disciplina

| | Conteúdo |
|---|---|
| Beneficiária | **GESTANTE** (titularidade da gestante, não do nascituro propriamente) |
| Devedor | **Suposto pai** |
| Cobertura | **Alimentação especial + assistência médica + psicológica + exames + internações + parto + medicamentos + saúde** + prescrições preventivas |
| Rateio | **Proporcional às possibilidades** do casal |

## Fundamentos constitucionais

| | Conteúdo |
|---|---|
| **CF 1 III** | Dignidade da pessoa humana |
| **CF 226 §7** | **Paternidade responsável + planejamento familiar** |
| **CF 227** | Proteção integral |

## Standard probatório

| | Conteúdo |
|---|---|
| Exigência | **INDÍCIOS de PATERNIDADE** |
| Standard | **ATENUADO**: não exige certeza |
| **NÃO se exige DNA prévio** | Standard probatório especial |

## Marco temporal

| Período | Pensão |
|---|---|
| **Da concepção até o PARTO** | **Alimentos gravídicos** (Lei 11.804) |
| **Após nascimento com VIDA** | **Conversão AUTOMÁTICA em alimentos comuns** ao recém-nascido (art. 6 par. único) |
| Independência | De pronunciamento judicial |
| Revisão | A pedido da parte |

## Execução e PRISÃO CIVIL

| | Conteúdo |
|---|---|
| **STJ** | **CABE prisão civil** pelo inadimplemento dos gravídicos |
| **Súm. 309 STJ** | Débito das **3 últimas prestações + vincendas** |
| Sistemática | **CPC 528** |
| **SV 25 STF** | **NÃO se aplica** (veda depositário infiel): prisão por alimentos tem assento constitucional próprio (**CF 5 LXVII**) |
| Tutela de urgência | Fixação liminar cabível |

## Distinções essenciais

| | Gravídicos | Provisionais | Provisórios | Compensatórios |
|---|---|---|---|---|
| Base | Lei 11.804 | **CC 1.706 + CPC** | **Lei 5.478 art. 4** | Jurisprudência |
| Natureza | Específicos da gestação | Cautelares | Liminares no rito especial | Equilíbrio econômico-financeiro |
| Standard | **INDÍCIOS** | Probabilidade | **Prova PRÉ-CONSTITUÍDA** | Pós-ruptura conjugal |
| Beneficiária | Gestante | Cônjuge/companheiro | Dependente | Ex-cônjuge |

## Procedimento

| | Conteúdo |
|---|---|
| Foro | Vara de Família |
| Tutela | **De URGÊNCIA** |
| Indícios | Mensagens + fotos + testemunhas + declarações |
| Trânsito | Conversão automática (art. 6 par. único) |
| Revisão | CC 1.695-1.699 |

## STJ + STF: jurisprudência consolidada

| | Conteúdo |
|---|---|
| STJ | Cabe prisão civil |
| STF | SV 25 não impede |
| **Súm. 309 STJ** | Débito = 3 últimas + vincendas |
| Defensoria/MP | Atuação em prol da gestante hipossuficiente |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Gestante sem recursos | **Lei 11.804** + tutela de urgência |
| Indícios de paternidade | **Suficiente** (não exige DNA) |
| Pós-parto com vida | **Conversão AUTOMÁTICA** em comuns |
| Pós-parto com nascido morto | Extingue |
| Inadimplemento | **PRISÃO CIVIL 1-3 meses** (CPC 528) |
| SV 25 alegada como impeditivo | **NÃO se aplica** (CF 5 LXVII) |
| Súm. 309 (débito) | **3 últimas + vincendas** |
| Revisão por possibilidade | Cabível |
| Conversão para alimentos definitivos | Por sentença autônoma |

## Erros a evitar

- Os gravídicos dispensam **DNA prévio**: o standard é de **indícios** (Lei 11.804);
- A **SV 25 STF** não impede a prisão civil alimentar (a hipótese da CF 5 LXVII subsiste);
- A **prisão civil** é cabível na inadimplência gravídica;
- A **Súm. 309** inclui as prestações **vincendas**;
- Os alimentos gravídicos são devidos à **gestante**, não ao nascituro;
- A **conversão** em alimentos comuns é automática pós-parto (art. 6 par. único);
- Gravídicos e **provisórios** (Lei 5.478, prova pré-constituída) são distintos;
- Gravídicos e **compensatórios** são institutos distintos;
- A **tutela de urgência** exige ao menos indícios;
- O **prazo de 1 a 3 meses** da prisão civil deve ser observado (CPC 528);
- Aplicam-se os **prazos próprios** dos alimentos gravídicos.

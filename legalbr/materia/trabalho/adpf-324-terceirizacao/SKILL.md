# ADPF 324 + RE 958.252 — Terceirização

## Identificação

| | Conteúdo |
|---|---|
| Ações | **ADPF 324 + RE 958.252** (Tema 725) |
| Autores | ABAG + diversos |
| Relator | Min. **Luís Roberto Barroso** |
| Julgamento | **30/08/2018** |

## Tese estruturante

| | Conteúdo |
|---|---|
| Resultado | Terceirização **LÍCITA em qualquer atividade** |
| Tema 725 | "É lícita a terceirização ou qualquer outra forma de divisão do trabalho entre pessoas jurídicas distintas, independentemente do objeto social das empresas envolvidas" |
| Súm. 331 TST | Parcialmente superada |
| Base | CF 1 IV + 170 (livre iniciativa) |

## Leis articuladas

| | Conteúdo |
|---|---|
| **Lei 13.429/2017** | Trabalho temporário + terceirização |
| **Lei 13.467/2017** | Reforma trabalhista |
| **Lei 6.019/1974** | Trabalho temporário (atualizada) |

## Responsabilidade

| | Conteúdo |
|---|---|
| **Subsidiária** | Por culpa in vigilando (ADC 16 + Tema 246) |
| **Solidária** | Trabalho temporário (Lei 6.019) |
| **Sucessão** | CLT 448 |
| **Grupo econômico** | CLT 2 §2 |

## Limites

| | Conteúdo |
|---|---|
| **Boa-fé** | Vedado uso fraudulento |
| **Pejotização** | Combatida quando fraude |
| **CLT 9** | Nulidade de atos para fraudar |
| **Vínculo empregatício** | CLT 3 — pessoalidade + subordinação |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Terceirização meio ou fim | **Lícita** (Tema 725) |
| Súm. 331 TST | Parcialmente superada |
| Pejotização fraudulenta | Vínculo reconhecido |
| Resp. subsidiária | Por culpa |
| Resp. solidária | Trab. temporário |
| Ônus prova culpa | Reclamante (Tema 246) |
| Adm. Pública | ADC 16 + Lei 14.133 |

## Erros a evitar

- Tratar terceirização da atividade-fim como ilícita;
- Aplicar Súm. 331 TST integralmente após ADPF 324;
- Considerar pejotização sempre fraudulenta (caso a caso);
- Inverter ônus da prova de culpa;
- Confundir terceirização com pejotização.

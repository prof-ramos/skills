# Justiça do Trabalho

## Estrutura (CF 111)

| | Conteúdo |
|---|---|
| Órgãos | **TST + TRTs + Varas do Trabalho** |
| Varas | Substituíram **JUNTAS** após **EC 24/1999** (extinguiu **REPRESENTAÇÃO CLASSISTA**) |

## CF 111-A: TST (EC 45/2004)

| | Conteúdo |
|---|---|
| Composição | **27 ministros** |
| Idade | **> 35 e < 70 anos** |
| Nomeação | PR + aprovação por **maioria absoluta do Senado** |
| **Quinto constitucional** | **1/5 OAB + MPT** |
| Demais | Entre juízes dos TRTs |

## CF 112-116

| Art. | Conteúdo |
|---|---|
| **112** | Lei criará Varas; nas comarcas sem Vara, a lei pode atribuir jurisdição trabalhista ao juiz de direito |
| 113 | Lei disciplina jurisdição + competência |
| **115** | TRTs: **mínimo 7 juízes** (quinto constitucional aplicável) |
| 116 | **Varas**: jurisdição exercida por juiz singular |
| **117** | **REVOGADO** pela EC 24/1999 |

## CF 114: COMPETÊNCIA (EC 45/2004)

| Inc. | Conteúdo |
|---|---|
| **I** | Ações da **RELAÇÃO DE TRABALHO**, incl. entes de DIREITO PÚBLICO EXTERNO + Adm direta/indireta |
| II | **DIREITO de GREVE** |
| III | **REPRESENTAÇÃO SINDICAL** |
| IV | **MS + HC + HD** quando o ato envolver matéria sujeita à JT |
| V | **Conflitos de COMPETÊNCIA** entre órgãos com jurisdição trabalhista |
| **VI** | **INDENIZAÇÕES por dano MORAL/PATRIMONIAL** decorrentes da relação |
| VII | Ações sobre **PENALIDADES ADMINISTRATIVAS** impostas pelos órgãos de fiscalização |
| **VIII** | **EXECUÇÃO DE OFÍCIO de CONTRIBUIÇÕES SOCIAIS** (CF 195 I "a" + II + acréscimos) decorrentes das sentenças |
| IX | Outras controvérsias, na forma da lei |

| | Conteúdo |
|---|---|
| **§2** | **DISSÍDIO COLETIVO**: pressuposto **"COMUM ACORDO"** (EC 45/2004) |
| §3 | Legitimidade do MPT para o dissídio coletivo em caso de greve em atividade essencial |

## STF ADI 3.395 (Min. Cezar Peluso)

| | Conteúdo |
|---|---|
| Tese | **EXCLUI da JT** causas envolvendo **SERVIDORES ESTATUTÁRIOS** |
| Justificativa | Vínculo **jurídico-administrativo** permanece na **Justiça Comum/Federal** |
| Ressalva | A exclusão **não alcança** ações fundadas em normas de **segurança, higiene e saúde do trabalho**: ACP do MPT voltada exclusivamente ao meio ambiente do trabalho permanece na **JT**, mesmo quando o órgão conta com estatutários, pois não se discute o vínculo jurídico-administrativo nem há servidor como parte (Súm. 736 STF; STF, 1ª Turma, RE 1.566.015 AgR, j. 05/2026) |

## STF Tema 1.046 (ARE 1.121.633, j. 02/06/2022)

| | Conteúdo |
|---|---|
| Tese | **CONSTITUCIONAIS acordos/convenções coletivas** que limitam/afastam direitos trabalhistas |
| Limite | **Direitos absolutamente INDISPONÍVEIS** |

## STF Tema 725 (RE 958.252)

| | Conteúdo |
|---|---|
| Tese | **TERCEIRIZAÇÃO LÍCITA em TODAS as atividades** (inclusive **atividade-fim**), independentemente do objeto social das empresas, **mantida a responsabilidade subsidiária** da contratante |

## Distinções essenciais

| | Servidor estatutário | Empregado público |
|---|---|---|
| Vínculo | Jurídico-administrativo | **CLT** |
| Foro | **Justiça Comum** | **JT** |

| | Pré-EC 45/2004 | Pós (2004) |
|---|---|---|
| Competência | Restrita | **Ampliada** |
| Comum acordo | NÃO | **SIM** (§2) |

| | TST | TRTs |
|---|---|---|
| Composição | **27 ministros** | Mínimo 7 |
| Função | Cúpula | 2ª instância |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Reclamação trabalhista | **JT** |
| Servidor estatutário | **Justiça Comum** (ADI 3.395) |
| Empregado público (CLT) | **JT** |
| Dano moral relação de trabalho | **JT** (CF 114 VI) |
| Direito de greve | **JT** (CF 114 II) |
| Servidor + greve | **Comum** (ADI 3.395) |
| ACP do MPT sobre meio ambiente do trabalho (ainda que o órgão tenha estatutários) | **JT** (Súm. 736 STF; RE 1.566.015 AgR) |
| Negociado prevalece | **Tema 1.046**, em direitos disponíveis |
| Terceirização atividade-fim | **Lícita** (Tema 725), com responsabilidade subsidiária |
| Dissídio coletivo | **Comum acordo** (§2) |

## Erros a evitar

- Submeter o **servidor estatutário** à JT (ADI 3.395 exclui);
- Deslocar para a Justiça Comum o dano moral decorrente da relação de trabalho (é **competência da JT**, CF 114 VI);
- Estender o **Tema 1.046** a direitos **absolutamente indisponíveis**;
- Tratar como ilícita a **terceirização da atividade-fim** (Tema 725), esquecendo a responsabilidade subsidiária da tomadora;
- Ajuizar dissídio coletivo sem **comum acordo** (§2 CF 114);
- Aplicar a **EC 45/2004** retroativamente sem ressalvas;
- Deslocar MS/HC/HD de matéria sujeita à JT para outro ramo (CF 114 IV);
- Tratar a **execução de contribuições sociais** como dependente de iniciativa da União (opera de ofício, CF 114 VIII);
- Confundir as funções de TST, TRT e Vara;
- Ignorar que a **representação classista** foi extinta (EC 24/1999);
- Desrespeitar a proporção do **quinto constitucional** entre OAB e MPT.

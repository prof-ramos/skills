# ADI 4650: Doações de Pessoas Jurídicas

## Identificação

| | Conteúdo |
|---|---|
| Ação | **ADI 4650** |
| Autor | **Conselho Federal da OAB** |
| Relator | Min. **Luiz Fux** |
| Julgamento | **17/09/2015** |
| Placar | **8×3** (procedente) |

## Tese estruturante

| | Conteúdo |
|---|---|
| Resultado | **PROCEDENTE**: doações de **PJ** a campanhas e partidos são **INCONSTITUCIONAIS** |
| Base | CF 1 V + CF 14 + CF 17 |
| Razão | Pluralismo + igualdade do voto + autonomia partidária |

## Dispositivos atingidos

| Lei | Conteúdo |
|---|---|
| **Lei 9.504/1997** art. 81 | Doações de PJ a campanhas: declarado inconstitucional |
| **Lei 9.096/1995** arts. 31, 38 e 39 (na parte relativa a PJ) | Doações e contribuições de PJ a partidos: vedadas |
| **Doações de PF** | Pedido de invalidação dos limites **rejeitado** (limites legais mantidos) |

## Fundamentos constitucionais

| Art. | Conteúdo |
|---|---|
| **CF 1 V** | Pluralismo político |
| **CF 14** | Soberania popular + voto direto + secreto + universal + periódico |
| **CF 17** | Liberdade partidária + autonomia |
| **CF 5 caput** | Igualdade |
| **CF 37** | Moralidade + impessoalidade |

## Argumentos do STF

| | Conteúdo |
|---|---|
| **Distorção econômica** | PJs com alto poder econômico desequilibram a disputa |
| **Sufrágio + soberania popular** | Devem se basear na pessoa natural (cidadão) |
| **Captura regulatória** | Risco de financiadores cobrarem favorecimento |
| **Igualdade do voto** | Comprometida pela influência econômica |
| **Lex specialis** | Direito eleitoral admite restrições próprias |

## Reforma Eleitoral 2015 (Lei 13.165)

| | Conteúdo |
|---|---|
| Origem | Pós ADI 4650 |
| **Vedação confirmada** | Doação de PJ não foi reintroduzida |
| **PF: limite** | 10% dos rendimentos brutos do ano anterior (Lei 9.504 art. 23 §1º) |
| Limites de gastos | Fixados em lei (arts. 18 e seguintes) |

## FEFC: Fundo Especial de Financiamento de Campanha

| | Conteúdo |
|---|---|
| Lei | **13.487/2017** |
| Função | **Financiamento PÚBLICO** das campanhas |
| Composição | Recursos do Orçamento da União |
| Distribuição | Lei 9.504 art. 16-D (parcela igualitária + votos + bancadas) |
| Cotas | Mínimo de 30% a candidaturas femininas, proporcional ao número de candidatas (ADI 5617 + **EC 117/2022, CF 17 §8**) e proporcionalidade racial (ADPF 738) |
| **Eleições 2026** | Res. TSE 23.752/2026 (alterando a Res. 23.607/2019): mínimo de **30% do FEFC** também para candidaturas de **pessoas negras** e distribuição proporcional para candidaturas **indígenas** |
| **EC 111/2021** | Voto a candidata mulher ou a candidato negro para a Câmara contado em dobro na distribuição de FEFC/FP (eleições de 2022 a 2030) |
| **EC 117/2022** | CF 17 §7: mínimo de 5% do fundo partidário em programas de participação política das mulheres |

|---|---|

| **Limite de gastos** | Definido em lei, por cargo |
| **Crowdfunding** | Permitido (financiamento coletivo, Lei 13.488/2017) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Doação de **PJ** a campanha ou partido | **VEDADA** (ADI 4650) |
| Doação de **PF** | Até **10% dos rendimentos brutos** do ano anterior |
| **FEFC** | Recurso público (Lei 13.487) |
| **Crowdfunding** | Permitido (Lei 13.488) |
| Autofinanciamento | Até 10% do limite de gastos do cargo |
| Caixa dois / doação irregular | Multa + inelegibilidade + crime (CE art. 350) |
| Cotas de campanha para mulheres | Mínimo 30%, proporcional às candidatas (EC 117/2022 + ADI 5617) |
| Cotas raciais | Proporcionalidade (ADPF 738); em 2026, piso de 30% do FEFC para pessoas negras (Res. TSE 23.752/2026) |
| Doações **de origem estrangeira** | **VEDADAS** (Lei 9.504 art. 24) |
| Doações de **órgãos públicos e concessionárias** | **VEDADAS** (Lei 9.504 art. 24) |

## Distinções

| | Pré-ADI 4650 | Pós (2015) |
|---|---|---|
| Doação PJ | Permitida com limites (art. 81) | **VEDADA** |
| Financiamento | Misto com forte peso empresarial | **Público + privado de PF** |
| Caixa dois | Comum | Continua **criminoso** |
| FEFC | Inexistente | **Criado em 2017** |

## Princípios

| | Conteúdo |
|---|---|
| **Igualdade do voto** | Cada cidadão = um voto |
| **Pluralismo** | Diversidade ideológica |
| **Lisura eleitoral** | Moralidade |
| **Autonomia partidária** | CF 17 |
| **Transparência** | Lei 9.096 + 9.504 |

## Erros a evitar

- A **doação de PJ** é vedada, ainda que de valor reduzido (ADI 4650);
- Os limites do art. 81 da Lei 9.504 estão superados (dispositivo invalidado);
- **Fundo partidário** (Lei 9.096) e FEFC (Lei 13.487) são fundos distintos;
- O **crowdfunding** é permitido (Lei 13.488);
- A doação **de origem estrangeira** ou de **entes públicos** é vedada (Lei 9.504 art. 24);
- O **caixa dois** é crime (CE art. 350) e admite cumulação com improbidade (Tema 1260 STF), não mera irregularidade administrativa;
- O autofinanciamento segue o teto de **10% do limite de gastos do cargo** (Lei 13.878/2019), não os rendimentos do candidato;
- As cotas de **mulheres** (mínimo 30%, EC 117/2022) e a proporcionalidade **racial** (ADPF 738) são de observância obrigatória;
- A reserva mínima feminina é **proporcional ao número de candidatas** (CF 17 §8);
- A vedação a PJ é tese constitucional (ADI 4650), não regra meramente infralegal.

# Fidelidade Partidária

## Marco legal

- **CF arts. 14 + 17** (partidos);
- **Lei 9.096/1995** (Lei dos Partidos Políticos);
- **TSE Resolução 22.610/2007** (procedimento desfiliação);
- **STF MS 26.602, 26.603, 26.604** (2007 — fidelidade no proporcional);
- **STF ADI 5.081** (2015 — não-aplicação ao majoritário);
- **TSE Súm. 67** (consolida);
- **EC 91/2016** (janela partidária);
- **Lei 13.165/2015 + Lei 13.488/2017** (atualizações);
- **EC 111/2021** (reforma).

## Evolução jurisprudencial

| Marco | Conteúdo |
|---|---|
| **STF MS 26.602/26.603/26.604 (2007)** | Fidelidade partidária — mandato do **partido** (proporcional) |
| **TSE Resolução 22.610/2007** | Procedimento aplicável |
| **Lei 13.165/2015** | Codificou em Lei 9.096 art. 22-A |
| **STF ADI 5.081 (2015)** | **Não se aplica** ao sistema **majoritário** |
| **TSE Súm. 67** | Consolida |
| **EC 91/2016** | Janela partidária (30 dias) |

## Aplicação por sistema

### Sistema PROPORCIONAL (fidelidade aplicada)

| Cargo | Aplicação |
|---|---|
| **Vereador** | Sim — desfiliação sem justa causa = perda do mandato |
| **Deputado Estadual** | Sim |
| **Deputado Distrital** | Sim |
| **Deputado Federal** | Sim |

### Sistema MAJORITÁRIO (não aplica — ADI 5081 + Súm. 67)

| Cargo | Aplicação |
|---|---|
| **Presidente da República** | **Não** |
| **Senador** | **Não** |
| **Governador** | **Não** |
| **Prefeito** | **Não** |

### Razão (STF ADI 5.081)

| | Conteúdo |
|---|---|
| **Majoritário** | Vontade do eleitor é **personalíssima** (vinculada ao candidato) |
| **Proporcional** | Voto pode beneficiar **toda a chapa** — vinculação ao partido |
| **Soberania popular** | Sistema majoritário privilegia escolha pessoal |

## Justa causa para desfiliação (Lei 9.096 art. 22-A § + Reso 22.610)

| Hipótese | Conteúdo |
|---|---|
| **Mudança substancial do programa partidário** | Devidamente formalizada |
| **Desvio reiterado do programa** | Pelo partido |
| **Grave discriminação política pessoal** | Comprovada |
| **Mudança de partido por nova legenda** | Quando criada nova agremiação |
| **Fusão + incorporação** | Automática |
| **Janela partidária** (EC 91/2016) | 30 dias a cada legislatura |

### Janela partidária (EC 91/2016)

| | Conteúdo |
|---|---|
| **Prazo** | **30 dias** a cada legislatura |
| **Quando** | A cada 4 anos |
| **Justa causa automática** | Não há perda de mandato |
| **Próxima janela** | A cada novo mandato |

## TSE Resolução 22.610/2007 — procedimento

| Etapa | Conteúdo |
|---|---|
| 1. **Pedido** | Partido + qualquer interessado + MP |
| 2. **Notificação** do parlamentar | 30 dias para defender |
| 3. **Justificativa** | Justa causa ou habilitar exceções |
| 4. **Decisão** | Pelo TRE/TSE |
| 5. **Recurso** | TSE → STF (RE) |
| 6. **Posse do suplente** | Se cassado |

## Suplência (sistema proporcional)

| | Conteúdo |
|---|---|
| **Mandato vacante** | Suplente do **mesmo partido/coligação** assume |
| **Não pode** suplente alheio | Mantém vontade do eleitor |
| **Coligação** | Ordenação pela coligação |
| **EC 97/2017** | Reduziu papel das coligações em proporcionais (vedou para Câmara/Estaduais) |

## EC 97/2017 — fim das coligações no proporcional

| | Conteúdo |
|---|---|
| **Vigência** | Eleições 2020 (proporcionais) |
| **Coligações** | Vedadas em proporcionais |
| **Federação partidária** | Substitui (Lei 9.096 art. 11-A) |
| **Cláusula de barreira** | Federação atende em conjunto |

## Cláusula de barreira (EC 97/2017)

| | Conteúdo |
|---|---|
| **Vedação acesso ao fundo + tempo TV** | Partidos abaixo do limite |
| **Limite progressivo** (votos válidos p/ Câmara em ≥ 9 UFs) | 2018: 1,5%; 2022: 2%; 2026: 2,5%; 2030: 3% |
| **OU** (alternativa por deputados eleitos em ≥ 9 UFs) | 2018: 9; 2022: 11; 2026: 13; 2030: 15 |

## EC 111/2021 — reforma adicional

| | Conteúdo |
|---|---|
| **Janela** | Mantida |
| **Federação** | Disciplinada |
| **Voto distrital misto** | Não aprovado |
| **Cláusula** | Aprofundada |

## Súmula 67 TSE

> "A perda do mandato em razão da desfiliação partidária **não se aplica aos candidatos eleitos pelo sistema majoritário**."

## Efeitos da perda do mandato

| | Conteúdo |
|---|---|
| **Vacância** | Imediata após trânsito |
| **Suplente** | Mesmo partido/federação |
| **Não há** restituição mesmo em recurso | Suplente assume |
| **Inelegibilidade** | Não automática (depende de outros fatores) |

## Cassação × renúncia

| | Conteúdo |
|---|---|
| **Renúncia antes da cassação** | Inelegibilidade 8 anos (Lei 9.096 + LC 64 art. 1 I k) |
| **Cassação por desfiliação** | Sem inelegibilidade automática |
| **Suplente** | Em ambos os casos |

## Federação partidária (Lei 9.096 art. 11-A)

| | Conteúdo |
|---|---|
| **Conceito** | União de partidos por 4 anos (legislatura) |
| **Atuação conjunta** | Bancada + tempo TV + fundo |
| **Fidelidade** | Aplica-se à federação |
| **Sair da federação** | Caracteriza desfiliação |

## STJ + STF — orientações específicas

| | Conteúdo |
|---|---|

| **Mandato vacante** | Suplente |

## Erros a evitar

- Aplicar fidelidade ao **majoritário** (vedado — ADI 5081 + Súm. 67);
- Esquecer **janela partidária** (EC 91/2016 — 30 dias);
- Aceitar **justa causa genérica** sem fundamentação;
- Confundir **desfiliação** com **expulsão** (regimes próximos mas distintos);
- Esquecer **federação** (Lei 9.096 art. 11-A);
- Aplicar **EC 97** retroativamente;
- Esquecer **suplente** do mesmo partido;
- Aplicar **inelegibilidade automática** após cassação por fidelidade;
- Confundir **coligação** (vedada no proporcional) com **federação** (permitida);
- Aplicar regras antigas após **EC 91 + 97 + 111**;
- Não usar Resolução **22.610 procedimento**;
- Esquecer Súm. **67 TSE**.

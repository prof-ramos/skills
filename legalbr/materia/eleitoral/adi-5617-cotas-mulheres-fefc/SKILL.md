# ADI 5617 — Cotas Mulheres no FEFC

## Identificação

| | Conteúdo |
|---|---|
| Ação | **ADI 5617** |
| Autor | **PGR** |
| Relator | Min. **Edson Fachin** |
| Julgamento | **15/03/2018** |
| Placar | **9×2** (procedente) |

## Tese estruturante

| | Conteúdo |
|---|---|
| Resultado | **PROCEDENTE** |
| Tese | Reserva de **30% candidaturas femininas** **EXIGE** distribuição **PROPORCIONAL** do FEFC + tempo de propaganda |
| Razão | Cota formal sem recursos é vazia — igualdade material |
| Base | CF 5 caput + CF 14 + Lei 9.504/97 art. 10 §3 |

## Cota de candidaturas

| | Conteúdo |
|---|---|
| **Lei 9.504/97 art. 10 §3** | Cada partido **DEVE preencher 30%-70%** das candidaturas por gênero |
| Aplicação | Eleições proporcionais (vereador + deputado) |
| Sanção | **Cassação de chapa** se descumprir (TSE) |

## ADI 5617 — comandos

| | Conteúdo |
|---|---|
| **FEFC** | Distribuição proporcional — mínimo **30%** para campanhas femininas |
| **Tempo de TV/Rádio** | Distribuição proporcional |
| **Fundo Partidário** | Mínimo proporcional (Lei 9.096) |
| **Reserva específica** | Diferenciada por candidata |

## Res. TSE 23.605/2019

| | Conteúdo |
|---|---|
| Função | Disciplina o uso do FEFC |
| **Cotas mulheres** | Implementou ADI 5617 |
| **Cotas negras** | Posterior — após ADI 6738 |
| **Prestação de contas** | Detalhamento por gênero/raça |

## Erros a evitar

- A cota **formal de candidaturas** não basta sem distribuição proporcional de **FEFC e propaganda** (ADI 5617);
- As cotas não são obrigatórias na **eleição majoritária** (Lei 9.504 só obriga a proporcional);
- As **candidaturas-laranja** configuram fraude e levam à cassação;
- A cota de mulheres não é **opcional**;
- A lógica das cotas estende-se às **cotas raciais** (ADI 6738);
- O tempo de propaganda não pode ser reduzido **abaixo do proporcional**;
- A cota é proporcional ao quantitativo de candidaturas, não **percentual fixo** desvinculado;
- A **Lei 14.291** não autoriza a redução das cotas;
- A tese alcança o fundo partidário (Lei 9.096 também observa);
- A **prestação de contas** por gênero e raça é fiscalizada (Res. TSE 23.605).

# Direito de Vizinhança

## Marco legal

| | Conteúdo |
|---|---|
| **CC 1.277-1.313** | Disciplina geral |
| **CPC 554-568** | Possessórias ([[possessorias-cc-1210-cpc-554]]) |
| **CC 186 + 187** | Responsabilidade civil + abuso |
| **Lei 6.766/79** | Parcelamento ([[loteamento-parcelamento-solo-lei-6766]]) |
| **Estatuto da Cidade** ([[estatuto-cidade]]) | |

## USO ANORMAL DA PROPRIEDADE (art. 1.277)

| | Conteúdo |
|---|---|
| Bem tutelado | **SEGURANÇA + SOSSEGO + SAÚDE** |
| Vizinhos | Próximos OU não próximos (basta nexo) |
| Critério | Uso **NORMAL** + tolerabilidade + finalidade |
| Limite | Pré-ocupação + interesse social mitigam (não eliminam) |

### Reação possível

| | Conteúdo |
|---|---|
| **Fazer cessar** | Ação cominatória + tutela específica |
| **Indenizar** | Dano material + moral |
| **Cumular** | Cessação + perdas e danos |

## Tolerabilidade (art. 1.279)

| | Conteúdo |
|---|---|
| Quando tolerar | Atividade autorizada com interesse público |
| Direito | Indenização cabível mesmo havendo tolerância |
| Limite | **Excesso** ainda enseja cessação |

## ÁRVORES LIMÍTROFES (arts. 1.282-1.284)

| | Conteúdo |
|---|---|
| **CC 1.282** | Tronco na **linha divisória** → árvore **COMUM** |
| **CC 1.283** | Raízes/ramos invadem o vizinho → **CORTE permitido** até o plano vertical do limite |
| **CC 1.284** | **Frutos caídos** no terreno do vizinho → propriedade do **dono do TERRENO** (salvo no público) |

## ÁGUAS (arts. 1.288-1.296)

| | Conteúdo |
|---|---|
| **1.288** | Inferior **recebe** as águas naturais do superior |
| **1.289** | Imóvel inferior **recebe** sobras quando o superior tem direito ao uso |
| **1.290** | Águas pluviais: uso conforme a função social |
| **1.291** | Vedado **poluir** águas indispensáveis às primeiras necessidades |
| **1.293** | **AQUEDUTO**: mediante indenização para todas as necessidades + atravessa prédios alheios |

## PASSAGEM FORÇADA (art. 1.285)

| | Conteúdo |
|---|---|
| Hipótese | Prédio **ENCRAVADO** sem saída para via pública |
| Direito | Vizinho **deve permitir** passagem mediante **INDENIZAÇÃO** |
| Vizinho obrigado | O **mais natural e menos oneroso** |
| Distinção | **≠ SERVIDÃO** ([[servidao-cc-1378]]): passagem forçada é **direito legal** (não convencional) |

### Quando deixa de ser encravado

| | Conteúdo |
|---|---|
| Acesso obtido posteriormente | Cessa direito à passagem |
| Acesso difícil mas existente | Sem direito (não há encravamento) |
| **Encravamento absoluto** | Necessário (não basta inconveniente) |

## CABOS + TUBULAÇÕES (art. 1.286)

| | Conteúdo |
|---|---|
| Direito | Atravessar prédio vizinho **com cabos, tubulações e dutos** subterrâneos ou aéreos |
| Indenização | Devida |
| **Vedação ao vizinho** | Não pode opor-se quando **único modo técnico** |

## LIMITES ENTRE PRÉDIOS (arts. 1.297-1.298)

| | Conteúdo |
|---|---|
| **Ação demarcatória** | CPC 569: fixação dos limites |
| **Tapumes** | Construção comum + custeio rateado |
| **Presunção** | Tapumes existentes pertencem em **comum** aos vizinhos |
| Linhas confusas | Em partes iguais (art. 1.298), salvo prova |

## DIREITO DE CONSTRUIR (arts. 1.299-1.313)

### Princípio geral (art. 1.299)

> Pode levantar construção desde que respeite **direitos dos vizinhos** + regulamentos administrativos.

### JANELAS, EIRADO, TERRAÇO, VARANDA (art. 1.301)

| | Conteúdo |
|---|---|
| Janela / sacada **VOLTADA** ao vizinho | Distância **mínima 1,5 metros** |
| Janela perpendicular (não voltada) | Distância **mínima 75 cm** |
| Janela perpendicular **lateral** | Sem distância (não invade visão) |
| Natureza da regra | **Objetiva e cogente**: presunção de devassamento independe de prova de prejuízo (STJ) |
| CC 1.302 + STJ | Decurso do prazo **decadencial de ano e dia** impede exigir o desfazimento de janela, sacada, terraço ou goteira; escoado o prazo, resta ao vizinho contraconstruir; o STJ (REsp 1.531.094/SP, 3ª T.) trata a vedação do art. 1.301 (1,5 m) como norma **objetiva e cogente**, não relativizável |

### Decadência do art. 1.302 (ano e dia)

| | Conteúdo |
|---|---|
| Prazo | **1 ano e 1 dia** da construção em desacordo |
| **Não correu** | Vizinho pode exigir desfazimento a qualquer tempo |
| Correu | Vizinho **deve tolerar** + pode levantar contraconstrução a 1,5m (parede + muro) |

### CONSTRUÇÕES PERIGOSAS (art. 1.311)

> Vedadas obras que ponham em risco **estabilidade** ou **segurança** do imóvel vizinho.

| | Conteúdo |
|---|---|
| Cabe | Ação de **DANO INFECTO** (caução para reparação eventual) |
| Constatado o risco | **Embargo** + reparos + indenização |

## PAREDE MEEIRA (arts. 1.305-1.307)

| | Conteúdo |
|---|---|
| **1.305** | Vizinho **pode edificar** sobre/encostar na parede divisória |
| Construir sobre meeira | Mediante **rateio de despesas** |
| **1.306** | **Meeiro** pode **embutir vigas** até a metade da espessura |
| **1.307** | Quem alça a meeira mais alto **rateia** com o vizinho na proporção do uso |

## ÁGUAS PLUVIAIS + GOTEIRAS (art. 1.300)

> Proibido construir de modo a despejar **goteiras** ou águas pluviais sobre o prédio vizinho.

## CHAMINÉS + EXALAÇÕES (art. 1.308)

> Vedadas construções que **infiltrem ou exalem** materiais nocivos ao prédio vizinho.

## Ações cabíveis

| Ação | Conteúdo |
|---|---|
| **Nunciação de obra nova** | Hoje sob procedimento comum (CPC 2015 extinguiu o rito próprio), para **embargar** obra |
| **Demarcatória / divisória** | CPC 569 ([[possessorias-cc-1210-cpc-554]] item correlato) |
| **Dano infecto** | Caução prévia + tutela de urgência (CC 1.280) |
| **Demolitória** | Para desfazer construção em desacordo |
| Cominatória + perdas | Para fazer cessar uso anormal |

## OBRIGAÇÕES PROPTER REM

Direitos de vizinhança **acompanham a coisa**: o adquirente assume.

## Função social + abuso (CC 187)

| | Conteúdo |
|---|---|
| Limite | Mesmo uso autorizado pode ser **abusivo** |
| Reação | Cessação + indenização + ressalva da boa-fé do vizinho |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Bar com ruído excessivo | **Uso anormal** (art. 1.277) → cominatória + cessar + indenizar |
| Prédio encravado | **Passagem forçada** (1.285) + indenização |
| Já há acesso ruim por outro lado | **Sem encravamento**: não cabe passagem forçada |
| Janela voltada a < 1,5 m | **Desfazimento** salvo decadência (1 ano + 1 dia, art. 1.302) |
| Janela há **5 anos** sem reclamar | **Decadência consumada**: resta ao vizinho contraconstruir |
| Raízes invadem o terreno | **Corte permitido** (1.283) |
| Tronco na divisa | **Árvore COMUM** (1.282) |
| Frutos caídos no vizinho | Do **vizinho do terreno** (1.284) |
| Construção que ameaça ruína | **Dano infecto** + caução + reparo |
| Despejo de goteiras | **Vedado** (1.300): cessação + indenização |
| Vizinho recusa parede meeira | Permitida + rateio (1.305-1.307) |
| Cabos sem outra rota técnica | **Direito de passagem** (1.286) + indenização |

## Erros a evitar

- Tratar **passagem forçada** como servidão (a primeira é **legal**, a segunda **convencional**; [[servidao-cc-1378]]);
- Aplicar prazo **comum** ao desfazimento de janela (decadência de **ano e dia**, CC 1.302) ou **relativizar** a distância mínima de 1,5 m (norma cogente: STJ, REsp 1.531.094/SP);
- Conceder passagem forçada por **mera comodidade** (exige-se ausência de saída para a via pública; acesso apenas difícil não basta);
- Negar **uso anormal** sob argumento de pré-ocupação (mitiga, não afasta);
- Esquecer a **decadência** após ano e dia para desfazimento de janela (vizinho perde a demolitória);
- Tratar tapumes como **propriedade exclusiva** do vizinho que ergueu (presunção de **comum** + rateio);
- Cobrar **integral** da meeira (rateio proporcional ao uso);
- Confundir **frutos caídos** (1.284) com furto/apropriação indébita (a propriedade muda automaticamente);
- Permitir **construção perigosa** sem caução (CC 1.280);
- Negar **dano infecto** alegando ausência de dano efetivo (basta o **risco**).

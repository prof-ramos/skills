# Servidão

## CC 1.378: conceito

| | Conteúdo |
|---|---|
| Conceito | **Direito real de GOZO** sobre **prédio alheio** |
| Estrutura | **Prédio DOMINANTE** × **prédio SERVIENTE** |
| Modos | **CONTRATO** ou **TESTAMENTO** |
| Forma | **REGISTRO no RI** (efeito constitutivo; Lei 14.382/2022, SERP) |

## Espécies

| Critério | Espécies |
|---|---|
| Conduta | **POSITIVA** (fazer/tolerar) × **NEGATIVA** (*non facere*) |
| Frequência | **CONTÍNUA** × **DESCONTÍNUA** |
| Visibilidade | **APARENTE** × **NÃO APARENTE** |

| | Conteúdo |
|---|---|
| Aparente | **Visível** externamente |
| Não aparente | **Não visível** |
| Jurisprudência | Apenas a servidão **aparente** tem proteção possessória e habilita usucapião |

## CC 1.379: USUCAPIÃO de servidão

| | Conteúdo |
|---|---|
| Servidão **APARENTE** | **ADMITE** usucapião |
| Prazo geral | **10 ANOS** (c/c CC 1.242) |
| **Justo título + boa-fé** | **5 ANOS** (par. único) |
| Servidão **NÃO APARENTE** | **NÃO ADMITE** usucapião (CC 1.213 c/c 1.379) |
| Enunciado 251 CJF | Confirma |
| STJ | Exige exercício **incontestado + contínuo + APARENTE** (cumulativos) |

## CC 1.380-1.388: regime dinâmico

| Art. | Conteúdo |
|---|---|
| **1.380** | **INDIVISIBILIDADE**: subsiste em divisão dos prédios |
| **1.381** | Desapropriação preserva **sub-rogação no preço** |
| **1.382** | Extensão **limitada às necessidades** do dominante |
| 1.383 | Sub-rogação do local |
| **1.384** | Exercício restritivo: *in dubio pro servientis* |
| **1.385** | Deveres de **CONSERVAÇÃO pelo DOMINANTE** |
| **1.386** | Dever de **NÃO AGRAVAMENTO** pelo serviente |
| 1.387-1.388 | Obras |
| **Enunciado 89 CJF** | Serviente pode exigir **REMOÇÃO às suas custas** se a obra inutilizada o prejudicar |

## CC 1.389: EXTINÇÃO

| Inc. | Hipótese |
|---|---|
| **I** | **Desapropriação** |
| **II** | **Renúncia** |
| **III** | **NÃO USO** por **10 ANOS** (STJ exige inércia qualificada) |
| **IV** | **CONFUSÃO** (reunião na mesma pessoa) |
| **V** | Resgate |
| **VI** | Perecimento |

| | Conteúdo |
|---|---|
| Cancelamento RI | Depende de **prova robusta**; a Lei 14.382/2022 simplificou averbações |

## SERVIDÃO ADMINISTRATIVA: DL 3.365/41 art. 40

| | Conteúdo |
|---|---|
| Natureza | **DIREITO REAL PÚBLICO** |
| Finalidade | **Utilidade pública** |
| Indenização | **Proporcional ao dano** |
| **Súm. 56 STJ** | **Juros compensatórios** |
| **Servidão de linhas de transmissão** | Indenização **proporcional à intensidade** da limitação: coeficiente de servidão apurado por perícia (grau de restrição + risco + incômodo) |

### Súmulas e teses relevantes
| | Conteúdo |
|---|---|
| **Súm. 56 STJ** | Juros compensatórios na desapropriação/servidão administrativa |
| Desapropriação indireta: prescrição | **10 ANOS** após o CC/2002 (presunção de obra/serviço público); 15 anos se comprovada ausência de obra; Súm. 119 STJ (20 anos) só para ações anteriores ao CC/2002 |
| **DL 3.365 art. 27 §1** | Honorários em **desistência** da desapropriação |

## Servidão × passagem forçada (CC 1.285)

| | Servidão (1.378) | Passagem forçada (1.285) |
|---|---|---|
| Natureza | **Direito real voluntário** | **Direito de vizinhança** |
| Encravamento | **NÃO exige** | **EXIGE** encravamento efetivo/funcional |
| Característica | **Facultativa** | **Compulsória** *ex lege* |
| Indenização | Conforme pacto | **Cabal** |
| Registro | **EXIGE** | **DISPENSA** |

## Distinção essencial: civil × administrativa

| | Civil (CC 1.378) | Administrativa (DL 3.365 art. 40) |
|---|---|---|
| Sujeitos | Particulares | Poder Público |
| Finalidade | Privada | **Utilidade pública** |
| Constituição | Contrato/testamento/usucapião | Decreto + acordo/judicial |
| Indenização | Pactuada | **Proporcional ao dano** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Direito de gozo entre prédios | **Servidão** |
| Prédio encravado sem acesso | **Passagem forçada** (CC 1.285) |
| Servidão aparente + 10 anos | **Usucapião** |
| Servidão aparente + justo título + 5 anos | Usucapião |
| Servidão **NÃO APARENTE** | **NÃO admite** usucapião |
| Linhas de transmissão | **Servidão administrativa** + indenização proporcional (coeficiente por perícia) |
| Não uso por 10 anos | **Extingue** (CC 1.389 III) |
| Confusão | Extingue (IV) |
| Desapropriação | Sub-rogação no preço (1.381) |
| Obra do serviente prejudica | **Enunciado 89 CJF**: remoção |
| Honorários em desistência | **DL 3.365 art. 27 §1** |

## Erros a evitar

- **Confundir SERVIDÃO ADMINISTRATIVA com CIVIL**;
- **Admitir usucapião de servidão NÃO APARENTE** (CC 1.379 veda);
- **Tratar passagem forçada como servidão** (CC 1.285, vizinhança × CC 1.378, real);
- **Ignorar REGISTRO como elemento constitutivo** da servidão civil;
- Aplicar **prazo diverso de 10 anos** ao não-uso (CC 1.389 III);
- Afastar **indivisibilidade** após divisão dos prédios (1.380);
- Cobrar **conservação do serviente** (é do dominante, CC 1.385);
- Admitir **agravamento pelo serviente** (CC 1.386 veda);
- Aplicar **5 anos sem justo título + boa-fé** (são cumulativos, 1.379 par. único);
- Tratar **servidão administrativa como desapropriação** (institutos distintos).

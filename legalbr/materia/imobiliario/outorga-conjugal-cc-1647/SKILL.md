# Outorga Conjugal (Uxória/Marital)

## Marco legal

| | Conteúdo |
|---|---|
| **CC 1.647** | Atos que exigem outorga do outro cônjuge |
| **CC 1.648** | Autorização **JUDICIAL** supletiva |
| **CC 1.649** | **ANULABILIDADE** + prazo 2 anos |
| **CC 1.650** | Legitimados: cônjuge OU herdeiros |
| **CF 226 §3** | União estável |
| **Lei 6.515/77** + **EC 66/2010** | Casamento + divórcio |

## ATOS sujeitos à outorga (art. 1.647)

| Inciso | Conteúdo |
|---|---|
| **(I)** | **Alienar** ou **gravar de ônus real** bens imóveis |
| **(II)** | Pleitear (autor ou réu) **direitos sobre imóveis** |
| **(III)** | Prestar **FIANÇA ou AVAL** |
| **(IV)** | Fazer **DOAÇÃO** **não remuneratória** de bens **comuns** ou que possam integrar futuro pagamento |

## EXCEÇÃO: Regime de **SEPARAÇÃO ABSOLUTA**

| | Conteúdo |
|---|---|
| **Separação CONVENCIONAL** (pacto antenupcial) | **DISPENSA** outorga (art. 1.647 caput parte final) |
| **Separação LEGAL/OBRIGATÓRIA** | (art. 1.641) Súm. 377 STF: **NÃO** dispensa outorga, pois comunicam-se os aquestos |
| Comunhão universal | **EXIGE** outorga |
| Comunhão parcial | **EXIGE** outorga (mesmo para bens particulares, pois há aquestos) |
| Participação final nos aquestos | **EXIGE**, salvo dispensa expressa no pacto (art. 1.656) |

## OUTORGA × REGIME

| Regime | Outorga em alienação de imóvel? |
|---|---|
| Comunhão parcial | **SIM** |
| Comunhão universal | **SIM** |
| **Separação convencional absoluta** | **NÃO** (dispensa) |
| Separação obrigatória (Súm. 377) | **SIM** |
| Participação final nos aquestos | **SIM**, salvo pacto |
| Fora do casamento (solteiro) | Não há |

## AUTORIZAÇÃO JUDICIAL SUPLETIVA (art. 1.648)

| | Conteúdo |
|---|---|
| Hipótese | **Negativa injusta** do outro cônjuge ou **impossibilidade** de manifestação |
| Competência | Juiz da família |
| Cabe | Demonstrar **interesse manifesto** + ausência de prejuízo |
| Decisão | **Substitui** a outorga (atua em nome do cônjuge ausente/recusante) |

## ANULABILIDADE (art. 1.649)

| | Conteúdo |
|---|---|
| Efeito da falta | **Ato ANULÁVEL** (não nulo) |
| **Legitimidade** | **Cônjuge prejudicado** ou seus herdeiros |
| **Prazo** | **2 ANOS** contados da **dissolução** da sociedade conjugal (separação/divórcio/morte) |
| Confirmação | Pode ser **CONFIRMADA** pelo outro cônjuge antes do prazo |
| Terceiro de boa-fé | Pode ser **indenizado** (CC 1.649 parágrafo único) |

## SÚMULA 332 STJ: FIANÇA sem outorga

> **A fiança prestada sem autorização de um dos cônjuges implica a INEFICÁCIA TOTAL da garantia.**

| | Conteúdo |
|---|---|
| Efeito | **Toda a fiança** cai (não apenas a meação) |
| Mesmo a quota do fiador | É afetada (proteção integral) |
| Aplica | Mesmo em locação ([[lei-inquilinato-lei-8245]]) |
| Aval (cambiário) | Súmula **não** se aplica diretamente ao aval; o aval **sem outorga** segue regra do CC 1.647 III + 1.649 (anulabilidade da quota) |

## UNIÃO ESTÁVEL e outorga

| | Conteúdo |
|---|---|
| **STJ (jurisprudência)** | A vênia do companheiro é exigida quando há **publicidade** da união estável: contrato/registro no cartório de imóveis ou **conhecimento** do terceiro adquirente |
| Sem registro/conhecimento | Boa-fé do terceiro **prepondera**: alienação válida |
| Companheiro pode pleitear | Meação + indenização contra o ex-companheiro alienante |
| **EC 66** + ADI 4277 + RE 646.721 | Equiparação a casamento para vários efeitos, mas não automática para outorga |

## ATOS QUE NÃO precisam de outorga

| | Conteúdo |
|---|---|
| Alienação de **bens MÓVEIS** | Dispensada |
| Aval **em cambial isolada** (com regime favorável) | Cuidado: CC 1.647 III continua exigindo |
| Atos administrativos de comércio do cônjuge empresário | Dispensados na atividade empresarial regular |
| Defesa em processos judiciais (não como autor) | Dispensa quando não envolve direitos reais sobre imóveis |
| Imóveis exclusivamente do cônjuge **em separação convencional** | Dispensa |
| **Locação simples** (não onera) | Dispensada |

## Ordem prática: escritura de venda

| Fase | Conteúdo |
|---|---|
| (1) | Verificar **estado civil** + regime de bens |
| (2) | Verificar se há união estável (declaração + registro civil) |
| (3) | Se exige → obter **assinatura do cônjuge** (mesma escritura) |
| (4) | Não conseguir? → **autorização judicial** (1.648) |
| (5) | Ato sem outorga → **anulável** (1.649) |

## Doação não remuneratória (1.647 IV)

| | Conteúdo |
|---|---|
| **Não remuneratória** | Liberalidade pura |
| **Remuneratória** | Recompensa por serviço (dispensa) |
| Bens **comuns** | EXIGE outorga |
| **Doação em vida** + **adiantamento da legítima** | EXIGE outorga + colação na sucessão |
| Cônjuge | **NÃO pode** dispor por **doação universal** sem anuência |

## Litisconsórcio NECESSÁRIO (CPC 73)

| | Conteúdo |
|---|---|
| Hipótese | **Ações que versam sobre direitos reais** imobiliários |
| Citação | **AMBOS os cônjuges** |
| Efeito | Sem citação → **nulidade absoluta** processual (não confundir com anulabilidade material) |
| Mesma exigência | Possessórias (de proteção de imóvel, CPC 73 §1) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Casado em comunhão parcial vendendo imóvel | **EXIGE outorga** (1.647 I) |
| Casado em separação convencional vendendo imóvel | **DISPENSA** outorga (parte final do caput) |
| Casado em separação **obrigatória** (Súm. 377) | **EXIGE outorga** (há comunhão aquestos) |
| Fiança sem outorga | **INEFICAZ na totalidade** (Súm. 332) |
| Aval sem outorga | **Anulável** quanto à meação (CC 1.649) |
| Outorga ausente + 1 ano da venda | Anulável (cônjuge prejudicado tem 2a) |
| Cônjuge nega injustamente | **Autorização judicial** (1.648) |
| União estável **registrada** | **EXIGE** outorga do companheiro (STJ: publicidade/conhecimento) |
| Compatibilidade com bem de família | Outorga + ([[impenhorabilidade-bem-familia]]) |
| Ação possessória em imóvel matrimonial | **Litisconsórcio necessário** (CPC 73) |
| Falecimento de cônjuge prejudicado | **Herdeiros** podem anular (1.650) |
| Doação remuneratória ao filho | **Dispensa** outorga (não é liberalidade pura) |

## Erros a evitar

- Dispensar outorga em **separação obrigatória** (Súm. 377: comunicam-se os aquestos);
- Tratar separação **convencional** como impeditiva (esta **DISPENSA** outorga);
- Aplicar nulidade absoluta (é **ANULABILIDADE**, 1.649);
- Contar prazo de anulabilidade **da venda** (é da **dissolução** da sociedade conjugal);
- Considerar fiança **parcial** quando não há outorga (Súm. 332: ineficácia **integral**);
- Ignorar **autorização judicial** quando há **negativa injusta** (1.648);
- Tratar união estável sem registro como exigência automática (STJ exige **publicidade** ou conhecimento do terceiro);
- Esquecer de citar AMBOS os cônjuges em ações sobre imóveis (CPC 73);
- Aceitar venda de imóvel em comunhão parcial **sem outorga** mesmo que o imóvel seja particular (a comunhão aquestos justifica);
- Aplicar a Súm. 332 ao **aval cambiário** (a regra é CC 1.647 III + 1.649).

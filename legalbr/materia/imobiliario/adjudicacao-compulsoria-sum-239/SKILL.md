# Adjudicação Compulsória + Compromisso de C&V

## Fundamento legal

| | Conteúdo |
|---|---|
| **CC 1.225 VII** | Direito **REAL** do **promitente comprador** (instrumento sem registro pode ter eficácia inter partes) |
| **CC 1.417-1.418** | **DIREITO REAL à aquisição** quando irrevogável |
| **CC 463-466** | Contrato preliminar: base obrigacional |
| Lei 6.766/79 art. 26 + §6 | Loteamento + irrevogabilidade |

## Lei 6.766/79: LOTEAMENTOS

| | Conteúdo |
|---|---|
| **Art. 26** | Promessa de compra e venda |
| **§6** | **IRREVOGÁVEL e IRRETRATÁVEL** quando NÃO houver previsão expressa de **arrependimento** |
| Alcance | Aplicação **RESTRITIVA** do art. 26 §6: alcança a transmissão primária **loteador → adquirente** |

## Requisitos da adjudicação compulsória (STJ)

| Req. | Conteúdo |
|---|---|
| (i) | **Contrato preliminar VÁLIDO**, irrevogável e irretratável |
| (ii) | **ADIMPLEMENTO INTEGRAL** do preço |
| (iii) | **RECUSA INJUSTIFICADA** do promitente vendedor |

| | Conteúdo |
|---|---|
| Imprescritibilidade | Sim (salvo aquisição por 3º via usucapião) |

## Súmulas STJ

| | Conteúdo |
|---|---|
| **Súm. 239** | "O direito à adjudicação compulsória **não se condiciona ao registro** do compromisso de compra e venda no cartório de imóveis" |
| **Súm. 84** | Admite **EMBARGOS DE TERCEIRO** fundados em alegação de posse advinda de compromisso de compra e venda, **ainda que desprovido do registro** |
| Cessionários/sucessores | Legitimados a postular a adjudicação (CC 1.418: o cessionário do promitente comprador exerce os mesmos direitos) |

## Lei 14.382/2022: ADJUDICAÇÃO COMPULSÓRIA EXTRAJUDICIAL

| | Conteúdo |
|---|---|
| Novo dispositivo | **Art. 216-B da LRP** |
| Função | **Desjudicialização integral** perante o **OFICIAL DO RI competente** |
| Cabimento | Inadimplemento da obrigação de outorga + óbito + ausência + incapacidade + paradeiro incerto + extinção da PJ do promitente vendedor |

### Procedimento extrajudicial
1. **Requerimento** por advogado/defensor com **poderes específicos**;
2. **Instrução documental**: contrato + prova de quitação + **ata notarial** + certidões + ITBI;
3. **NOTIFICAÇÃO** do promitente vendedor (**prazo 15 dias**);
4. **Sem impugnação ou impugnação infundada** → decisão registral pelo oficial;
5. **Suscitação de dúvida** se óbice.

| | Conteúdo |
|---|---|
| **Provimento CNJ 150/2023** | Uniformizou nacionalmente o rito |
| Eletrônico | Via **SERP** (Sistema Eletrônico Registros Públicos) |

## Adjudicação JUDICIAL × EXTRAJUDICIAL

| | Judicial | Extrajudicial |
|---|---|---|
| Base | **CPC 501** (sentença produz os efeitos da declaração de vontade não emitida) | **Art. 216-B LRP** (Lei 14.382) |
| Foro | Vara cível | **Cartório de RI** |
| Notificação | Citação | **15 dias** ao promitente vendedor |
| Impugnação | Contestação | Impugnação registral |
| Decisão | Sentença | Decisão registral do oficial |

| | Conteúdo |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Compromisso quitado + recusa do vendedor | **Adjudicação compulsória** |
| Compromisso NÃO registrado | **Cabe igualmente** (Súm. 239) |
| Embargos de terceiro com compromisso desregistrado | **Cabíveis** (Súm. 84) |
| Cessionário do promitente comprador | **Legitimado** (CC 1.418) |
| Vendedor desaparecido | **Extrajudicial** (Lei 14.382) |
| Vendedor extinto (PJ) | Extrajudicial |
| Loteamento sem cláusula de arrependimento | **Irrevogável** (Lei 6.766 art. 26 §6) |
| Incorporação | Lei 4.591 |
| Distrato | Lei 13.786 |
| Notificação 15 dias sem impugnação | Decisão registral |

## Erros a evitar

- **Exigir REGISTRO do compromisso como pressuposto** (Súm. 239, não é);
- **Confundir adjudicação JUDICIAL × EXTRAJUDICIAL** (Lei 14.382);
- **Aplicar Lei 6.766 sem analisar IRREVOGABILIDADE** (art. 26 §6);
- Afastar **embargos de terceiro** por falta de registro (Súm. 84 admite);
- Desconsiderar **cessionário** como legitimado (CC 1.418);
- Aplicar a Lei 6.766 art. 26 §6 a **transmissões POSTERIORES** (interpretação restritiva: alcança a transmissão primária);
- Tratar adjudicação compulsória como **prescritível** (regra é imprescritível);
- Exigir **escritura pública prévia** (Súm. 239 dispensa);
- Aplicar **CC 463 sem requisitos da adjudicação** (preliminar exige adimplemento + recusa);
- Ausência de admissão da **notificação extrajudicial** quando cabível (Lei 14.382);
- Tratar **promessa registrada** como simples promessa (é direito real, CC 1.225 VII).

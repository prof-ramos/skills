# Direito Real de Laje

## Marco legal

| | Conteúdo |
|---|---|
| **CC 1.225 XIII** | Direito real **autônomo** (incluído pela Lei 13.465) |
| **CC 1.510-A a 1.510-E** | Disciplina |
| **Lei 13.465/2017** | Origem ([[reurb-lei-13465]]) |
| **Lei 14.382/2022** | Registro eletrônico + SERP ([[registros-publicos-lei-6015]]) |
| **MP 759/2016** | Texto original, convertida na 13.465 |

## Conceito (art. 1.510-A)

| | Conteúdo |
|---|---|
| Natureza | **Direito real** autônomo |
| Objeto | **Superfície superior OU inferior** de construção-base |
| Estrutura | Unidades **autônomas distintas** com **matrículas próprias** |
| Acessão | Suprime a regra **superficies solo cedit** (CC 1.255) |

## Estrutura jurídica

| | Conteúdo |
|---|---|
| **Construção-base** | Imóvel original com matrícula primária |
| **Laje** | Unidade autônoma sobre ou sob a construção-base; matrícula nova |
| **Cessão** | Onerosa ou gratuita: escritura pública (≥ 30 sal-mín) + registro |
| **Acesso** | Independente OU compartilhado (regulado em ato) |

## DIFERENÇA: direito de laje × outros institutos

| | Direito de laje | Outros |
|---|---|---|
| Superfície ([[direito-superficie-cc-1369]]) | Construir/plantar **NO solo** alheio | Laje é **OUTRA EDIFICAÇÃO** sobreposta/subposta |
| Condomínio edilício | **Convenção** + áreas comuns | Laje é **autônoma** sem convenção condominial (salvo coexistência) |
| Servidão ([[servidao-cc-1378]]) | Ônus sobre prédio | Laje é **propriedade plena** |
| Usufruto ([[usufruto-uso-habitacao-cc-1390]]) | Uso e fruição alheios | Laje é **titularidade própria** |

## Faculdades do titular da laje (art. 1.510-A §§)

| | Conteúdo |
|---|---|
| **§3** | Manter unidade isolada com **acesso independente** + uso e fruição |
| **§4** | Não abrange áreas comuns que sirvam à construção-base |
| **§5** | Estrutura + telhado + áreas comuns são **rateadas em despesas proporcionais** |

## LAJES SUCESSIVAS (art. 1.510-A §6)

| | Conteúdo |
|---|---|
| Permitidas | Sobre/sob laje anterior, **sucessivamente** |
| Requisito | **Autorização EXPRESSA** do titular da construção-base + lajes anteriores |
| Cada laje | Matrícula própria |

## DIREITO DE PREFERÊNCIA (art. 1.510-D)

| | Conteúdo |
|---|---|
| Alienação | Tanto da construção-base quanto da laje |
| **Preferência** | **Recíproca** entre titulares (base + laje + sucessivas) |
| Prazo | **30 dias** da notificação para exercer (CC 504, aplicado analogicamente; ver [[direito-preferencia-imobiliaria-cc-504]]) |
| Não exercido | Alienação livre |
| **Sanção** | Adjudicação ao preterido (analogia ao CC 504) |

## OBRIGAÇÕES propter rem (art. 1.510-C)

| | Conteúdo |
|---|---|
| Despesas de uso comum | Rateio **proporcional à fração** |
| Tributos (IPTU) | **Individualizados** pela matrícula |
| Solidariedade | **Vedada** salvo previsão (cada titular responde pelo seu) |

## EXTINÇÃO (art. 1.510-E)

| Hipótese | Conteúdo |
|---|---|
| **Ruína da construção-base** | Extingue a laje **se** não houver reconstrução em **5 ANOS** |
| Reconstrução tempestiva | Laje **mantida** + matrícula original |
| **Renúncia ao direito** | Reverte à construção-base |
| Confusão | Mesmo titular em todas as unidades |

## REGISTRO (art. 1.510-A §1 + LRP)

| | Conteúdo |
|---|---|
| Forma | **Escritura pública** (≥ 30 sal-mín) OU instrumento particular em REURB |
| Local | **CRI** da circunscrição |
| Matrícula | **NOVA matrícula** para a laje + averbação na matrícula-base |
| **CNJ Prov. 149/2023** | Procedimento eletrônico via SERP |

## REURB e direito de laje

| | Conteúdo |
|---|---|
| Aplicação | Núcleos urbanos informais consolidados com **construções sobrepostas** |
| Modalidade | **REURB-S** ou **REURB-E** ([[reurb-lei-13465]]) |
| Instrumento | Legitimação fundiária + CRF com **matrículas separadas** para cada laje |
| Forma simplificada | Aceita em REURB-S sem escritura pública |

## Tributação

| Tributo | Quem paga |
|---|---|
| **IPTU** | Cada titular pela respectiva matrícula |
| **ITBI** | Devido na cessão onerosa ou aquisição |
| **ITCMD** | Devido em sucessão/doação |
| Despesas comuns | Rateadas conforme a fração proporcional (CC 1.510-A §5 / 1.510-C) |

## Limites

| | Conteúdo |
|---|---|
| **§4** | Não pode comprometer a **segurança da construção-base** |
| **§6** | Sucessivas lajes requerem **autorização escrita** |
| Veda | Uso que **interfira** com função da construção subjacente (luminosidade, ventilação) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Casa térrea + 2 pavimentos sobrepostos | **Direito de laje** sucessiva (com autorização escrita) |
| Construção-base desaba sem reconstrução em 5 anos | **Laje extinta** (1.510-E) |
| Titular da base quer vender o terreno | **Preferência** ao titular da laje (1.510-D) |
| Inadimplência de IPTU pela laje | Cobrança **só do titular da laje** (não do dono da base) |
| Reformas estruturais que afetam laje superior | **Vedadas** sem anuência (§4) |
| Cessão onerosa por R$ 50 mil | **Escritura pública** + registro CRI |
| Construção em REURB-S | Forma **simplificada** + CRF |
| Confusão (mesmo titular base + laje) | **Extinção** + unificação |
| Laje sobre laje sem autorização | **Inadmissível** (§6) |
| Despesas de telhado comum | **Rateio proporcional** (1.510-A §5) |

## Erros a evitar

- Tratar laje como **mera servidão** ou condomínio (é **direito real autônomo**);
- Aplicar **superficies solo cedit** (CC 1.255): a Lei 13.465 afastou expressamente;
- Negar **matrícula própria** à laje (cada unidade tem a sua);
- Permitir laje sucessiva **sem autorização escrita** (§6);
- Cobrar dívida de IPTU do dono da base por **dívida da laje** (responsabilidade individual);
- Estender extinção automática a **TODA** ruína (só após **5 anos** sem reconstrução);
- Confundir com **direito de superfície** ([[direito-superficie-cc-1369]]): superfície cede **o solo**; laje é **outra edificação**;
- Esquecer **preferência recíproca** (1.510-D): aplica analogia ao CC 504 + indenização ao preterido;
- Tratar acesso da laje como **obrigatoriamente compartilhado** (pode ser **independente**, §3);
- Ignorar registro: laje **só existe** após averbação + matrícula nova.

# FIIs: Fundos de Investimento Imobiliário

## Marco legal

- **Lei 8.668/1993** (criação dos FIIs);
- **Lei 9.779/1999** (regime tributário);
- **Lei 11.033/2004** (isenção IR PF);
- **Lei 14.754/2023** (Lei dos Investimentos no Exterior + FII; mantém isenção);
- **Lei 14.130/2021** (FIAGRO);
- **CVM Resolução 175/2022** (substitui IN 472/2008);
- **Lei 8.245** (locação; relação com FII tijolo);
- **CC** + Lei 6.404 (estrutura societária);
- **CTN** + Lei 10.931 (CRI + CCI).

## Conceito

| | Conteúdo |
|---|---|
| **Definição** | Comunhão de recursos para investimento em ativos imobiliários |
| **Natureza** | **Condomínio fechado** (sem PJ) |
| **Resgate** | **Vedado** (cotas negociadas em bolsa) |
| **Cotistas** | PF ou PJ |
| **Administrador** | Instituição financeira autorizada CVM |

## Tipos de FII

| Tipo | Conteúdo |
|---|---|
| **Tijolo** | Imóveis físicos (shoppings, lajes, hospitais, escolas) |
| **Papel** | CRI + LCI + outros títulos imobiliários |
| **Híbrido** | Combinação |
| **Fundos de fundos** | Investem em outros FIIs |
| **Desenvolvimento** | Imobiliário em construção |

## Estrutura

| | Conteúdo |
|---|---|
| **Patrimônio** | Imóveis + títulos + caixa |
| **Cotas** | Negociadas em bolsa (B3) |
| **Liquidez** | Via secundário (não resgate) |
| **Distribuição** | **Mensal** (em geral); mínimo de 95% do lucro (Lei 8.668 art. 10 par. único) |
| **Política de investimento** | Definida em estatuto |

## Tributação

### Isenção PF (Lei 11.033 art. 3 III + Lei 14.754)

| Condições | Conteúdo |
|---|---|
| **1) FII tem ≥ 100 cotistas** | Mínimo elevado de 50 para 100 pela Lei 14.754/2023 (art. 41), desde 01/01/2024 |
| **2) Cotas negociadas exclusivamente em bolsa ou balcão organizado** | Liquidez |
| **3) PF cotista com menos de 10% das cotas** | Sem isenção para titular de 10% ou mais das cotas ou com direito a mais de 10% dos rendimentos |
| **Renda mensal** | **Isenta** de IR |
| **Lei 14.754/2023** | **Manteve a isenção**, elevando o mínimo de cotistas de 50 para 100 |

### Tributação se PF não atender

| | Conteúdo |
|---|---|
| **Rendimentos** | **20%** IR retido na fonte |
| **Ganho de capital (cotas)** | 20% (sempre) |
| **Tabela progressiva** | Não aplica |

### Tributação PJ

| | Conteúdo |
|---|---|
| **Rendimentos** | IR 20% retido |
| **Ganho de capital** | 20% |
| **Lucro real/presumido** | Adiciona à base |
| **Sem isenção** | Para PJ |

## Erros a evitar

- Aplicar **isenção PF** sem verificar 3 requisitos cumulativos (Lei 11.033);
- Usar o piso antigo de **50 cotistas**: desde 01/01/2024 a isenção exige **100 cotistas** (Lei 11.033 art. 3 III c/c §1º I, redação do art. 41 da Lei 14.754/2023);
- Esquecer **CVM Resolução 175/2022** (substituiu IN 472);
- Tratar FII como **PJ** (é condomínio sem personalidade);
- Confundir FII **tijolo** com **papel** (estruturas próprias);
- Aplicar **resgate** de cotas (vedado: só negociação secundária);
- Esquecer **20% IR** sobre ganho de capital de cotas (sempre);
- Aplicar isenção a **PJ** cotista (apenas PF);
- Não atualizar para **CVM 175** + **Lei 14.754**;
- Confundir FII com **FIAGRO** (regimes próximos, Lei 14.130);
- Esquecer **CRI/LCI** como ativos comuns de FII papel;
- Aplicar **alíquota tabela progressiva** em rendimentos (é 20% retido);
- Tratar **B3** como local de resgate (apenas negociação secundária).

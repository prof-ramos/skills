# Títulos de Crédito Imobiliário

## Marco legal

| | Conteúdo |
|---|---|
| **Lei 9.514/1997** | SFI + CRI + companhia securitizadora |
| **Lei 10.931/2004** | CCI + LCI + patrimônio de afetação |
| **Lei 13.097/2015** | LIG (Letra Imobiliária Garantida): regime integral, arts. 63-97 |
| **Lei 14.430/2022** | Marco Legal da Securitização (CR/LRS); não alterou o regime da LIG, que permanece na Lei 13.097/2015 |
| **Lei 14.711/2023 (LACE)** | Ampliação das garantias |
| **CMN + CVM + BACEN** | Normativos operacionais |

## Quadro comparativo

| | **CCI** | **CRI** | **LCI** | **LIG** |
|---|---|---|---|---|
| Emissor | Credor (banco) | **Securitizadora** | **Banco** | **Banco** |
| Natureza | **Cédula** (CC + lei) | **Valor mobiliário** (CVM) | **Título de crédito** | **Valor mobiliário** + título de crédito |
| Lastro | 1 crédito imobiliário | **Recebíveis** + CRI | Crédito imobiliário | **Carteira segregada** (covered bond) |
| Regime fiduciário | Sim (1 crédito) | **Sim** (segregação) | Não (responsabilidade do banco) | **Sim** (carteira garantidora apartada) |
| IR PF | n/a | **Isento** | **Isento** | **Isento** |
| Investidor | n/a | Qualificado (em geral) | Qualquer | Profissional/qualificado |

## CCI: Cédula de Crédito Imobiliário (Lei 10.931 arts. 18-25)

| | Conteúdo |
|---|---|
| Natureza | **Título de crédito** representativo de **um único** crédito imobiliário |
| **Cartular ou escritural** | (com sistema autorizado) |
| Garantia | Pode ser **com** ou **sem** garantia real |
| Endosso | **Em PRETO** + **transmissão SIMPLIFICADA** sem necessidade de averbação na matrícula |
| Execução | **Título executivo extrajudicial** (CPC 784) |
| Função | Mobiliza créditos imobiliários (refazer caixa) |

### Vantagens da CCI

| | Conteúdo |
|---|---|
| Circulação | Sem nova averbação no CRI |
| Garantia imobiliária | Acompanha **automaticamente** o título |
| Eficácia | Independe de notificação ao devedor |
| Base | Para emissão de **CRI** (lastro) |

## CRI: Certificado de Recebíveis Imobiliários (Lei 9.514 arts. 6-8)

| | Conteúdo |
|---|---|
| Natureza | **VALOR MOBILIÁRIO** + **CVM** |
| Emissor | **COMPANHIA SECURITIZADORA** (S.A.) |
| Lastro | **Créditos imobiliários** (incluindo CCI) |
| **Regime fiduciário** | Patrimônio **segregado**: não atinge o da securitizadora |
| Investidor | Geralmente **qualificado/profissional** |
| Distribuição | Pública (oferta) + restrita (CVM 160) |

### TERMO DE SECURITIZAÇÃO (Lei 9.514 art. 8)

| | Conteúdo |
|---|---|
| Conteúdo | Identificação dos recebíveis + lastros + condições + agente fiduciário |
| **Regime fiduciário** | Constituído por declaração no termo + averbação |
| Custodiante | Custódia dos lastros |
| Agente fiduciário | Representa os titulares de CRI |

### Tributação

| | Conteúdo |
|---|---|
| **PF** | **Isenção** de IR (Lei 11.033 art. 3 II) |
| **PJ** | IR ordinário sobre rendimentos |
| **IOF** | Reduzido |

## LCI: Letra de Crédito Imobiliário (Lei 10.931 arts. 12-17)

| | Conteúdo |
|---|---|
| Natureza | **Título de crédito** + título nominativo |
| Emissor | **INSTITUIÇÃO FINANCEIRA** com carteira imobiliária |
| Lastro | **Crédito imobiliário** com garantia real (hipoteca ou AF) |
| Valor da emissão | Limitado ao **valor dos créditos** lastreados |
| Liquidez | **Resgate/recompra vedados antes do prazo mínimo** do CMN (Res. 4.410/2015 art. 4): **6 meses** na LCI sem atualização por índice de preços (Res. CMN 5.215/2025) e **36 meses** quando atualizada mensalmente por índice de preços (Res. CMN 5.119/2024) |
| FGC | **Garantido** pelo Fundo Garantidor de Crédito (até R$ 250 mil por instituição) |
| **Isenção IR PF** | Sim |

### CARACTERÍSTICAS

| | Conteúdo |
|---|---|
| Forma | **Cartular ou escritural** |
| Circulação | **Endosso em preto** |
| Vencimento | Conforme contrato, observado o prazo mínimo do CMN |
| Remuneração | Pré-fixada + pós-fixada (CDI, IPCA) |

## LIG: Letra Imobiliária Garantida (Lei 13.097/2015, arts. 63-97)

| | Conteúdo |
|---|---|
| Natureza | **VALOR MOBILIÁRIO** + título de crédito imobiliário |
| Conceito | Similar ao **covered bond** internacional |
| Emissor | **Banco** com carteira imobiliária autorizada |
| Lastro | **CARTEIRA GARANTIDORA APARTADA** (cover pool) |
| Recurso | Dupla garantia: banco emitente + carteira segregada |
| **Isenção IR PF** | Sim |
| Investidor | Profissional/qualificado em regra |

### Carteira garantidora (cover pool)

| | Conteúdo |
|---|---|
| Composição | **Créditos imobiliários** + ativos elegíveis |
| Segregação | **Apartada** do patrimônio do banco emitente |
| **Sobre-colateralização** | Mínima exigida por norma (geralmente 5% acima do valor das LIGs) |
| Agente fiduciário | Fiscaliza o cover pool |
| Falência do emitente | **Cover pool** isolado e direcionado aos titulares de LIG (não entra na massa) |

## FUNDING do crédito imobiliário: novo modelo CMN (2025-2027)

| | Conteúdo |
|---|---|
| **Res. CMN 5.254 e 5.255/2025** | Novo modelo de direcionamento dos recursos da poupança (SBPE): percentual destinado ao crédito imobiliário sobe **gradualmente de 65% para 100%** (2026 = transição; modelo pleno em jan/2027); criados os depósitos interfinanceiros imobiliários |
| **Teto do SFH** | Valor do imóvel financiável no SFH elevado de R$ 1,5 milhão para **R$ 2,25 milhões**, com uso de FGTS até esse valor |
| **Res. BCB 512/2025** | Dedução do compulsório de até 5% dos saldos de poupança aplicados em crédito imobiliário |

## Patrimônio de AFETAÇÃO + Regime FIDUCIÁRIO

| Patrimônio | Aplicação | Característica |
|---|---|---|
| **Afetação na incorporação** | [[incorporacao-imobiliaria-lei-4591]] | Patrimônio próprio da obra |
| **Regime fiduciário do CRI** | Lei 9.514 art. 9 | Recebíveis lastros segregados |
| **Cover pool LIG** | Lei 13.097/2015 | Carteira do banco segregada |
| **AF imóvel** | [[direitos-reais-garantia-alienacao-fiduciaria]] | Garantia real |

## OPERAÇÃO típica de securitização

| Fase | Conteúdo |
|---|---|
| (1) | **Originação** dos créditos imobiliários (banco + incorporadora) |
| (2) | **Emissão da CCI** representativa |
| (3) | **Cessão à securitizadora** |
| (4) | Securitizadora institui **regime fiduciário** + emite **CRI** |
| (5) | CRI **distribuído ao mercado** (CVM 160: oferta pública ou restrita) |
| (6) | **Pagamento** dos CRI pelo fluxo dos créditos imobiliários |
| (7) | Custodiante guarda lastros + agente fiduciário fiscaliza |

## SUBORDINAÇÃO entre séries

| Série | Conteúdo |
|---|---|
| **Sênior** | Recebimento prioritário |
| **Mezanino** | Intermediária |
| **Subordinada (júnior)** | Última a receber (absorve primeiras perdas) |
| Função | Estruturar risco + reforço de crédito |

## IOF + outros tributos

| | Conteúdo |
|---|---|
| **IOF** | Alíquota decrescente conforme prazo (zero após 30 dias para PF, regra geral) |
| **ITBI/ITCMD** | Não incidem (são valores mobiliários) |
| **ISS** | Não incide sobre cessão de crédito imobiliário |

## RECUPERAÇÃO judicial / FALÊNCIA

| | Conteúdo |
|---|---|
| Crédito **com garantia real** (CCI + AF) | **Extraconcursal** (Lei 11.101 art. 49 §3), se AF do imóvel |
| **CRI + regime fiduciário** | Lastros **isolados**, fora da massa |
| **LIG + cover pool** | Carteira garantidora **fora** da massa do emitente |
| Sobra | Eventual saldo positivo retorna ao patrimônio da emissora/securitizadora |

| **Inadimplência histórica** | Carteira |

## ALTERNATIVAS: FII (Fundos Imobiliários)

| | Conteúdo |
|---|---|
| Natureza | **Fundo de Investimento** (CVM) |
| Pode investir em | CRI + LCI + LIG + imóveis físicos |
| Cotas | Negociadas em bolsa (B3) |
| **Isenção IR PF** | Sim (rendimentos distribuídos por FII com 100+ cotistas, mínimo da Lei 14.754/2023 desde 01/01/2024, e cotas negociadas exclusivamente em bolsa ou balcão organizado) |
| Estrutura | **Condomínio** especial fechado |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Banco vendendo carteira de hipotecas | Emite **CCI** + cede a **securitizadora** + CRI |
| Investidor PF em CRI | **Isento IR** |
| Securitizadora falir | **Regime fiduciário** isola lastros |
| Banco emissor de LIG falir | **Cover pool** fica com investidores |
| CCI em garantia ou cessão | **Sem averbação** no CRI (lei) |
| LCI antes da carência mínima do CMN | Resgate **vedado** |
| Subordinada absorve perdas | **Sênior** protegida |
| Lastro AF imóvel | Crédito **extraconcursal** ([[direitos-reais-garantia-alienacao-fiduciaria]]) |
| FII com CRI + LIG + imóveis | Diversificação **dentro do mesmo veículo** |
| Sobre-colateralização baixa | Reduz proteção dos LIG |

## Erros a evitar

- Confundir **CCI** (cédula, emitida pelo credor) com **CRI** (securitização, emitido pela securitizadora);
- Tributar **IR PF** sobre CRI ou LCI ou LIG (são **isentos**);
- Tratar o regime fiduciário como ineficaz em **recuperação judicial** (é extraconcursal + segregado);
- Permitir LCI **sem lastro suficiente** (vedado);
- Emitir LIG sem **sobre-colateralização** mínima;
- Considerar o **emissor** responsável quando há regime fiduciário ou cover pool (responsabilidade circunscrita aos lastros);
- Aplicar prescrição comum (10 anos) à cobrança da CCI (é **3 anos** para títulos de crédito por força do CC 206 §3 VIII);
- Esquecer **CVM 160** (oferta pública) para CRI/LIG (distribuição irregular);
- Cobrar **ITBI** ou **ISS** na cessão de crédito imobiliário (não incidem);
- Tratar FII como **PJ tributável** sobre rendimentos distribuídos (isenção PF condicionada; desde 01/01/2024 exige **100 cotistas**: Lei 14.754/2023);
- Confundir **patrimônio de afetação** ([[incorporacao-imobiliaria-lei-4591]]) com **regime fiduciário do CRI** (são instrumentos distintos).

# Alienação Fiduciária de Imóvel

## Marco legal

| | Conteúdo |
|---|---|
| **Lei 9.514/1997** | Sistema Financeiro Imobiliário (SFI) + AF de imóvel |
| **Lei 10.931/2004** | CCI + LCI + reforço da AF |
| **Lei 13.465/2017** | Ajustes em leilão + purga |
| **Lei 14.711/2023** (LACE) | Marco das garantias — concessão sucessiva, extensão fiduciária |
| **CC 1.367-1.368-B** | Aplicação subsidiária dos direitos reais |

## Conceito (art. 22)

Negócio jurídico pelo qual o **devedor (fiduciante)** transfere ao **credor (fiduciário)** a **propriedade RESOLÚVEL** do imóvel **em garantia** de dívida, com **desdobramento da posse** (direta com o fiduciante).

## REQUISITOS do contrato (art. 24)

| | Conteúdo |
|---|---|
| (i) | **Valor do principal** + prazo + condições de reposição |
| (ii) | **Taxa de juros** + encargos |
| (iii) | **Cláusula constituindo a propriedade fiduciária** |
| (iv) | **Indicação do imóvel** |
| (v) | **Valor para LEILÃO** (avaliação) — art. 24 VI |
| (vi) | Cláusula penal + procedimento em caso de inadimplemento |

## REGISTRO no CRI (art. 23)

| | Conteúdo |
|---|---|
| Constituição | **Pelo REGISTRO** na matrícula |
| Efeito | Transferência da **propriedade resolúvel** ao credor fiduciário |
| Posse | Fiduciante mantém **posse direta** (uso) |
| Credor | Adquire **posse indireta** |

## INADIMPLEMENTO + CONSOLIDAÇÃO (arts. 26-26-A)

| Fase | Conteúdo |
|---|---|
| (1) | **Mora ex re** — vencimento das prestações |
| (2) | **Notificação** ao fiduciante pelo **oficial do RGI** |
| (3) | **15 dias** para purga (a partir da intimação) |
| (4) | Não purgada → **averbação da consolidação** mediante recolhimento do **ITBI** + laudêmio (se houver) |
| (5) | Propriedade plena ao credor (vez resolvida a condição resolutiva) |

### Notificação (art. 26 §§)

| | Conteúdo |
|---|---|
| Forma | **Pessoal** ou por **edital** se não localizado (com hora certa após 3 tentativas) |
| Carta com AR | Permitida pela Lei 13.465/2017 + Lei 14.382/22 |
| Endereço | Indicado no contrato (presunção de validade) |
| Mora purgada | **Pagamento integral** + encargos + custas + emolumentos do RGI |

## LEILÃO PÚBLICO EXTRAJUDICIAL (art. 27)

| Leilão | Conteúdo |
|---|---|
| **1º leilão** (art. 27 §1) | **30 dias** da consolidação — lance mínimo = **VALOR DE AVALIAÇÃO** (contrato) |
| **2º leilão** (art. 27 §2) | **15 dias** após o 1º — lance mínimo = **DÍVIDA + encargos + tributos + leilão** |
| Não arrematado | Dívida considerada **EXTINTA** (art. 27 §5) — credor fica com o imóvel |

## Sobra/saldo (art. 27 §4)

| | Conteúdo |
|---|---|
| Lance > dívida | **Saldo restituído** ao fiduciante (em até 5 dias) |
| Lance ≤ dívida (no 2º) | Dívida extinta automaticamente |
| Lance < dívida (no 2º) | Vedado — não pode adjudicar abaixo da dívida |

## Tema 982 STJ (purga até a arrematação)

> Pode o devedor fiduciante **purgar a mora** mesmo **APÓS a consolidação** da propriedade no nome do credor, até a **assinatura do auto de arrematação** no leilão extrajudicial. Após o segundo leilão, somente eventual sobra é restituível.

## STJ Tema 1.095

> **Entrega das chaves** = início da exigibilidade de **juros remuneratórios** quando há AF + financiamento imobiliário em incorporação ([[incorporacao-imobiliaria-lei-4591]]).

## STJ Tema 1.158

> A **alienação fiduciária de imóvel** sujeita o credor à **prévia consolidação extrajudicial** + leilão — **não cabe** execução comum por título extrajudicial ignorando a Lei 9.514.

## Reintegração de posse (art. 30)

| | Conteúdo |
|---|---|
| Após consolidação + leilão (ou não arrematação) | Credor/arrematante tem direito à **REINTEGRAÇÃO** |
| Liminar | **60 dias** (art. 30) — desocupação compulsória |
| Procedimento | Sumário com base na consolidação averbada |

## AF SUPERVENIENTE + LACE (Lei 14.711/2023)

| Inovação | Conteúdo |
|---|---|
| **Garantia sucessiva** | Mesmo imóvel pode garantir **vários financiamentos** sucessivos (art. 9 §1 LACE) |
| **Extensão da AF** | AF pode garantir **dívidas futuras** entre as mesmas partes |
| Excussão concorrente | Sucessivos credores observam **ordem cronológica** do registro |
| **AF inversa** | Permite uso da AF mesmo quando o **credor** é pessoa física |
| **Recompra** | Direito do devedor + cessão para terceiros + facilidade no SERP ([[registros-publicos-lei-6015]]) |

## Vedações + cuidados

| | Conteúdo |
|---|---|
| Bem **público** | Inalienável → vedada AF |
| Bem **família** legal | NÃO afasta AF (a garantia consentida supera a impenhorabilidade — ver [[impenhorabilidade-bem-familia]]) |
| Lance vil | **Não se aplica** ao 2º leilão (lance mínimo é a dívida) |
| Cláusula comissória | **VEDADA** — disciplina é a do art. 27 (leilão) |

## RECUPERAÇÃO judicial e AF (art. 49 §3 LRF + Lei 14.112)

| | Conteúdo |
|---|---|
| AF de imóvel | **Crédito EXTRACONCURSAL** — não sujeito à RJ (Lei 11.101 art. 49 §3) |
| Stay period | Aplica-se mas **NÃO impede** consolidação após o período |
| Bem essencial | Pode ser preservado se essencial à atividade (Tema 1.051 STJ — controle de essencialidade) |

## Hipoteca × AF — quadro comparativo

| | Hipoteca ([[hipoteca-cc-1473]]) | AF Imóvel |
|---|---|---|
| Propriedade | Permanece com devedor | Transfere **resolúvel** ao credor |
| Execução | **Judicial** (CPC 824) | **Extrajudicial** (art. 26-27) |
| Prazo | Extensa (anos) | **45-60 dias** da mora |
| Cláusula comissória | Vedada (CC 1.428) | Substituída por **leilão** |
| Súm. 308 STJ | Aplica (vide [[incorporacao-imobiliaria-lei-4591]]) | Inaplicável (estrutura diversa) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Mora + notificação 15d sem pagamento | **Consolidação** averbada + ITBI |
| Purga após consolidação mas antes do leilão | **Admitida** (Tema 982) |
| 1º leilão sem arrematante | Vai ao 2º (15 dias) |
| 2º leilão sem arrematante | **Dívida EXTINTA** (art. 27 §5) |
| Lance > dívida no 2º leilão | **Sobra devolvida** ao fiduciante |
| Devedor recusa desocupação após leilão | **Reintegração** com **liminar 60d** (art. 30) |
| Bem de família + AF | Garantia **PREVALECE** (consentimento) |
| AF + RJ do devedor | Crédito **extraconcursal** + controle de essencialidade |
| 2º contrato sobre o mesmo imóvel | **LACE** — admite **AF sucessiva** |
| Execução comum em vez do procedimento | **Inadmissível** (Tema 1.158) |

## Erros a evitar

- Executar AF de imóvel por **rito comum** (Tema 1.158 — só pelo art. 26-27);
- Aceitar **cláusula comissória** disfarçada;
- Permitir **lance vil** no 2º leilão (lance mínimo = dívida);
- Negar **purga até a arrematação** (Tema 982);
- Confundir AF com hipoteca (rito + propriedade são distintos);
- Considerar **bem de família** como impedimento (a AF consentida afasta a impenhorabilidade — Lei 8.009 art. 3 V);
- Negar consolidação por **notificação por AR** (Lei 13.465 + 14.382 admitem);
- Ignorar **devolução de saldo** quando o lance supera a dívida;
- Permitir AF sobre **bens públicos**;
- Considerar AF concursal em RJ (é **extraconcursal** — art. 49 §3 LRF).

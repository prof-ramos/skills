# REURB: Regularização Fundiária Urbana

## Marco legal

| | Conteúdo |
|---|---|
| **Lei 13.465/2017** | Revogou a Lei 11.977 em parte; instituiu a REURB |
| **Decreto 9.310/2018** | Regulamento |
| **CF 5 XXII + XXIII + 182-183** | Função social + moradia |
| **Lei 14.382/2022** | SERP + integração registral ([[registros-publicos-lei-6015]]) |
| **Lei 6.766/1979** | Parcelamento ([[loteamento-parcelamento-solo-lei-6766]]) |
| **Prov. CNJ 149/2023 (CNN, Foro Extrajudicial)** | Atos extrajudiciais (consolidou as normas antes dispersas em provimentos anteriores da Corregedoria Nacional) |

## Conceito (art. 9)

Conjunto de medidas **jurídicas, urbanísticas, ambientais e sociais** destinadas à **incorporação ao ordenamento urbano** de **núcleos urbanos informais**, com regularização do título de propriedade aos ocupantes.

## NÚCLEO URBANO INFORMAL CONSOLIDADO (art. 11 III)

| | Conteúdo |
|---|---|
| Definição | Núcleo urbano informal **DIFÍCIL REVERSÃO** |
| Critérios | Tempo de ocupação + natureza das edificações + localização + características da população |
| Áreas | Públicas ou privadas (regimes específicos) |

## MODALIDADES

### REURB-S: Interesse Social (art. 13 I)

| | Conteúdo |
|---|---|
| Público-alvo | População de **baixa renda** (declarada pelo município) |
| **Custas** | **Gratuita**: atos registrais e cartoriais (art. 13 §1) |
| **ITBI** | Isento (art. 24 §1) |
| Instrumentos | Todos disponíveis (legitimação fundiária + posse) |
| Prioridade | Concessão de uso especial para fins de moradia (CUEM) |

### REURB-E: Interesse Específico (art. 13 II)

| | Conteúdo |
|---|---|
| Público-alvo | **Demais** ocupantes |
| Custas | **Onerosa**: emolumentos + ITBI |
| Instrumentos | Compra + venda + permuta + legitimação **somente em hipóteses específicas** |

## LEGITIMAÇÃO FUNDIÁRIA (art. 23)

| | Conteúdo |
|---|---|
| Natureza | **AQUISIÇÃO ORIGINÁRIA** do direito real de propriedade |
| Forma | Reconhecimento pelo município/DF + averbação no CRI |
| Cabimento | **REURB-S** prioritariamente |
| **Efeito** | **Livre de ônus** anteriores (em REURB-S, art. 23 §2) |
| Vedação | Quem é titular de outro imóvel urbano/rural (REURB-S) |

## Legitimação de POSSE (arts. 25-26)

| | Conteúdo |
|---|---|
| Natureza | Ato administrativo: **posse com presunção de titularidade** |
| Conversão | Em **PROPRIEDADE** após 5 anos (usucapião administrativa, art. 26) |
| Prazo de conversão imediata | **Quando coincidir com prazo de usucapião especial** ([[usucapiao-cc-1238]]) |
| Não confunde com legitimação fundiária | Esta é originária e instantânea |

## DEMARCAÇÃO URBANÍSTICA (arts. 19-22)

| | Conteúdo |
|---|---|
| Função | **Identificar** o núcleo + limites + ocupantes |
| Executor | **Poder público** ou legitimado (art. 14) |
| Procedimento | Auto de demarcação → averbação no CRI → notificação dos confrontantes |
| Impugnação | **30 dias**; havendo conflito vai a juízo |
| Efeito | Premissa para a regularização |

## LEGITIMADOS para REURB (art. 14)

| | Conteúdo |
|---|---|
| União, Estados, DF, Municípios | |
| Beneficiários | Coletiva ou individualmente |
| **Cooperativas** habitacionais | Associações + sociedades de propósito específico |
| Proprietário | Do imóvel ocupado |
| **MP + Defensoria + Loteador** | Em situações específicas |

## FASES (art. 28)

| Fase | Conteúdo |
|---|---|
| (1) | **Requerimento** da REURB |
| (2) | **Processamento** administrativo |
| (3) | **Elaboração do projeto** de regularização |
| (4) | **Saneamento** do processo |
| (5) | **DECISÃO** da autoridade competente |
| (6) | Expedição da **CRF (Certidão de Regularização Fundiária)** |
| (7) | **Registro** da CRF + projeto no CRI |

## CRF: CERTIDÃO DE REGULARIZAÇÃO FUNDIÁRIA (art. 41)

| | Conteúdo |
|---|---|
| Função | Documento ÚNICO que ingressa no CRI |
| Conteúdo | Identificação do núcleo + ocupantes + projeto + listagem das unidades |
| Efeito | **Registra** o parcelamento + abertura de matrículas + titularidade |
| **Lista de ocupantes** | Vincula o município ao reconhecimento (não cabe revisão posterior do CRI) |

| | Conteúdo |
|---|---|
| Mapa do núcleo + perímetro | |
| **Memorial descritivo** + planta com lotes | |
| Cronograma físico de obras | |
| Compromisso do **município** quanto a infraestrutura mínima | |
| **Estudo técnico ambiental** quando exigido | |

## APP/APRM em REURB (art. 11 + Lei 12.651/12)

| | Conteúdo |
|---|---|
| Núcleos consolidados pré-22/12/2016 | **Regularizáveis** mesmo em APP (com estudo + medidas mitigadoras) |
| REURB-S | Tratamento mais flexível |
| REURB-E | Estudos técnicos rigorosos |

## CONDOMÍNIO URBANO SIMPLES (arts. 61-62)

| | Conteúdo |
|---|---|
| Hipótese | Lote único com **mais de uma edificação** + áreas de uso comum |
| Constituição | Pela averbação na matrícula (sem incorporação) |
| Regulamento | Substitui convenção (admite forma simplificada) |
| Útil | Para regularizar habitações coletivas em pequenos lotes |

## CONJUNTO HABITACIONAL (art. 63)

Habitação **multifamiliar** com unidades autônomas + áreas comuns + registro mediante **convenção simplificada**. Aplicação subsidiária do regime do condomínio edilício ([[condominio-edilicio-multipropriedade]]).

## Bens PÚBLICOS em REURB (arts. 16-18)

| | Conteúdo |
|---|---|
| Imóveis públicos urbanos ocupados | Sujeitos à REURB |
| Instrumentos | **Legitimação fundiária** (REURB-S) ou **alienação** (REURB-E) |
| União | Aplica-se Lei 11.481/2007 e Lei 13.240: destinação para regularização |
| Concessão de Direito Real de Uso (CDRU) | Alternativa à propriedade |
| CUEM | Concessão de Uso Especial para Moradia, para REURB-S |

## REURB × OUTROS institutos

| | Diferença |
|---|---|
| Usucapião ([[usucapiao-cc-1238]]) | Individual + judicial/extrajudicial; **REURB** é coletiva e administrativa |
| **Adjudicação** ([[adjudicacao-compulsoria-sum-239]]) | Pressupõe contrato; **REURB** independe |
| Loteamento ([[loteamento-parcelamento-solo-lei-6766]]) | Parcelamento **regular**; REURB regulariza o **irregular** |
| Concessão administrativa | Não transfere domínio; REURB transfere |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Núcleo informal consolidado de baixa renda | **REURB-S** + legitimação fundiária + gratuita |
| Núcleo informal classe média/alta | **REURB-E** + oneroso |
| Ocupante de **bem PÚBLICO** (REURB-S) | **Legitimação fundiária** ou CDRU/CUEM |
| Ocupante de **bem PRIVADO** | Acordo + legitimação ou demarcação urbanística |
| Núcleo em **APP** | Regularizável se consolidado pré-22/12/2016 |
| Múltiplas casas em um lote | **Condomínio urbano simples** (art. 61) |
| Já titular de outro imóvel | **VEDADA** legitimação fundiária em REURB-S |
| Após aprovação | **CRF** → averbação CRI + matrículas individuais |
| Conflito sobre área | **Demarcação urbanística** + impugnação 30d |
| Posse há 5 anos + legitimação de posse | **Conversão automática** em propriedade (art. 26) |

## Erros a evitar

- Tratar legitimação **fundiária** como derivada (é **originária**, art. 23);
- Cobrar emolumentos em **REURB-S** (gratuita);
- Negar regularização em **APP** consolidada pré-22/12/2016;
- Exigir **registro do contrato** anterior em REURB (não há contrato; é ato administrativo);
- Confundir **legitimação fundiária** com **legitimação de posse** (uma é título, outra é posse com presunção);
- Pedir **anuência do antigo proprietário** em REURB-S de núcleo privado consolidado (não é exigida, art. 23 §2);
- Aplicar **ITBI** em REURB-S (isento, art. 24 §1);
- Tratar **CRF** como mera certidão (é o **título** que ingressa no CRI);
- Usar REURB para regularizar parcelamento **novo** (REURB é para núcleos **consolidados**);
- Ignorar **legitimados** distintos do município (cooperativas + MP + defensoria também podem).

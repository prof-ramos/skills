# Usufruto + Uso + Habitação

## CC 1.390: USUFRUTO

| | Conteúdo |
|---|---|
| Conceito | Direito **REAL** sobre coisa alheia |
| Caracteres | **Temporário + personalíssimo + INALIENÁVEL** |
| Cessão | **Apenas exercício** (CC 1.393); o direito em si NÃO se transfere |
| Desmembramento | **Nua-propriedade** (titularidade) + **usufruto** (uso + fruição) |

## CC 1.391: modos de constituição

| Modo | Conteúdo |
|---|---|
| **Lei** | Ex.: usufruto dos pais sobre bens dos filhos (CC 1.689) |
| **Contrato** | Oneroso/gratuito + **REGISTRO no RGI** (sob pena de não constituir direito real) |
| **Testamento** | Sim |
| **Usucapião** | Sim |

| | Conteúdo |
|---|---|
| Imóveis | Exigem **REGISTRO** |
| Móveis | **Tradição** |

## CC 1.392-1.394: extensão + direitos

| Art. | Conteúdo |
|---|---|
| **1.392** | Abrange **frutos** (naturais + industriais + civis) + **acessões** |
| **1.394** | **Posse + uso + administração + percepção de frutos** |

## Vedações estruturais

| | Conteúdo |
|---|---|
| **CC 1.393** | **VEDADO USUFRUTO SUCESSIVO**: sem cláusula transmitindo a 3º após a morte do primeiro (a qualificação registral nega ingresso) |
| Permitido | **Usufruto SIMULTÂNEO** com **direito de acrescer** (CC 1.411) |
| **CC 1.397** | Cousufruto **proporcional**: extingue-se parte a parte (salvo cláusula de acrescer) |
| **CC 1.410 III** | **PJ: máx 30 ANOS** |
| CC 1.410 I | **PF: VITALÍCIO** (morte do usufrutuário) |

## CC 1.400-1.409: DEVERES

| Art. | Conteúdo |
|---|---|
| 1.400 | **Inventariar bens** + **caução** (se exigida) |
| 1.401 | Conservar a coisa |
| 1.402-1.403 | **Despesas ordinárias + tributos sobre rendimentos** |
| **1.404** | **Reparos EXTRAORDINÁRIOS** cabem ao **nu-proprietário** |
| 1.409 | Restituir ao fim |

## CC 1.410: EXTINÇÃO

| Inc. | Hipótese |
|---|---|
| **I** | **Morte do usufrutuário** |
| II | Termo |
| III | Cessação da causa |
| IV | **Não-uso/não-fruição** |

| VI | Consolidação (reunião na pessoa do nu-proprietário) |

| | Conteúdo |

## CC 1.412: USO

| | Conteúdo |
|---|---|
| Conceito | Direito **REAL menor** que usufruto |
| Limites | Apenas **NECESSIDADES PESSOAIS** do usuário e família |
| Frutos | Só **OS NECESSÁRIOS** |

## CC 1.413: disciplina supletiva

Aplicação subsidiária das regras do usufruto ao uso.

## CC 1.414-1.416: HABITAÇÃO

| Art. | Conteúdo |
|---|---|

| Vedação | **USO COMERCIAL** ou **locação** |
| 1.415-1.416 | Caráter pessoal + indivisibilidade |

## CC 1.831: HABITAÇÃO ao CÔNJUGE

| | Conteúdo |
|---|---|
| Beneficiário | **Cônjuge SOBREVIVENTE** |
| Objeto | **ÚNICO IMÓVEL RESIDENCIAL** a inventariar |
| Natureza | **VITALÍCIA + PERSONALÍSSIMA + EX LEGE** |
| Registro | **DISPENSA** |

## Lei 9.278/96 art. 7: COMPANHEIRO

| | Conteúdo |
|---|---|
| Tese | **Companheiro em união estável** tem o **MESMO direito real de habitação** (Lei 9.278/96 art. 7 + STJ, REsp 1.220.838; ver [[direito-real-habitacao-cc-1831]]) |
| Concorrência | Reconhecido mesmo concorrendo com **descendentes exclusivos** do falecido (jurisprudência do STJ) |
| Alienação judicial | Jurisprudência do STJ **impede** a extinção de condomínio com alienação judicial do imóvel gravado pela habitação |

## Distinções essenciais

| | Usufruto | Uso | Habitação |
|---|---|---|---|
| Frutos | **TODOS** | **NECESSÁRIOS** | n/a |
| Uso | Amplo | Limitado | **Apenas morar** |
| Cessão exercício | Possível | Geralmente não | **Não** |
| Comercial | OK | Pessoal | **VEDADO** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Doação com reserva de usufruto | Comum |
| Usufruto a PJ | **Máx 30 anos** (1.410 III) |
| Usufruto vitalício PF | **Sem prazo determinado** |
| Cláusula de usufruto sucessivo | **NULA** (CC 1.393) |
| Usufruto simultâneo com acrescer | **Admitido** (CC 1.411) |
| Não-uso prolongado | **EXTINGUE** (STJ REsp 1.179.259) |
| Cônjuge sobrevivente em único imóvel | **Habitação ex lege** (CC 1.831) |
| Companheiro sobrevivente | **MESMO direito** (Lei 9.278/96 art. 7 + STJ) |
| Concorrência habitação × condomínio | **Habitação prevalece** (jurisprudência do STJ) |
| Reparos extraordinários | **Nu-proprietário** (CC 1.404) |
| Reparos ordinários | **Usufrutuário** (CC 1.402) |

## Erros a evitar

- **Aceitar USUFRUTO SUCESSIVO** (CC 1.393: vedado);
- **Aplicar 30 anos a PF** (é vitalício, CC 1.410 I);
- **Negar HABITAÇÃO ao COMPANHEIRO** (Lei 9.278/96 art. 7 + STJ, REsp 1.220.838);
- **Cobrar aluguel do titular de habitação** (CC 1.414: gratuidade);
- **Ignorar Súm. 364 STJ** na proteção do bem de família;
- Exigir prazo legal específico para extinção por **não-uso** (STJ dispensa);
- Cobrar **reparos extraordinários do usufrutuário** (são do nu-proprietário);
- Permitir **uso comercial no direito de habitação** (CC 1.414 veda);
- Permitir **cessão do usufruto** (só o exercício, CC 1.393);
- Tratar **usufruto como alienável** (é inalienável);
- Permitir **alienação judicial do imóvel** com habitação ativa (jurisprudência do STJ veda).

# Enriquecimento sem Causa

## CC 884, conceito

| | Conteúdo |
|---|---|
| Definição | Quem se enriquecer **à custa de outrem sem justa causa**, restitui o indevidamente auferido + correção monetária |
| Natureza | **Fonte autônoma** de obrigação (ao lado de contrato, ato ilícito, lei) |
| Cláusula geral | Permite restituição em hipóteses **atípicas** |

## Elementos cumulativos

| Elemento | Conteúdo |
|---|---|
| **Enriquecimento** | Aumento patrimonial (positivo) OU economia de despesa OU evitar perda |
| **Empobrecimento** | Diminuição patrimonial correlativa |
| **Nexo de causalidade** | Conexão entre enriquecimento e empobrecimento |
| **Ausência de justa causa** | Sem fundamento jurídico (contrato, lei, decisão judicial) |

## CC 885, perdurando a causa

| | Conteúdo |
|---|---|
| Hipótese | A causa **deixa de existir** após a transferência |
| Efeito | Cabe restituição (hipótese tipica: condição superveniente) |

## CC 886, SUBSIDIARIEDADE

| | Conteúdo |
|---|---|
| **Regra crítica** | Ação **NÃO cabe** se a lei conferir ao lesado **outros meios** para se ressarcir |
| Aplicação | Existindo ação contratual, indenizatória, possessória etc., usar essas primeiro |
| **Subsidiariedade** (CC 886) | Enriquecimento sem causa é fonte **autônoma**, mas subsidiária aos demais meios |

## CC 882, vedação implícita

| | Conteúdo |
|---|---|
| Pagamento de dívida **prescrita** ou cumprimento de obrigação **moral** | **Não autoriza repetição** (irrepetibilidade) |

## Hipóteses típicas

| Caso | Solução |
|---|---|
| Pagamento indevido | **CC 876** (regime específico), não usar CC 884 |
| Acessão de boa-fé em terreno alheio | CC 1.255 (regime próprio), não usar CC 884 |
| Investimento em imóvel locado | CC 96 (benfeitorias), não usar CC 884 |
| Trabalho prestado sem contrato | **CC 884**, admite (subsidiária) |
| Servidor irregularmente contratado | **Súm. 363 TST** + STF Tema 191 (RE 596.478), apenas saldo de salários + FGTS (não enriquecimento integral) |
| Acordo extrajudicial não cumprido | Execução do acordo, não CC 884 |
| Restituição tributária | **CTN 168** (5 anos), regime próprio, não usar CC 884 |

## Ação in rem verso

| | Conteúdo |
|---|---|
| Procedimento | **Comum** (CPC 318) |
| Foro | Domicílio do réu (CPC 46) |
| Prazo | **3 anos** (CC 206 §3 IV), conforme jurisprudência do STJ |
| **Termo inicial** | Conhecimento do enriquecimento + ausência de causa |
| Liquidação | Valor do **enriquecimento** OU **empobrecimento** (o **menor**), princípio da justiça |

## Diferença com institutos correlatos

| Instituto | Diferença |
|---|---|
| **Pagamento indevido** (CC 876) | Pagamento equivocado, regime próprio (CC 876-883); prescrição: 3 anos (CC 206 §3 IV; STJ Tema 919) ou 10 anos (CC 205) na linha das repetições fundadas em relação contratual/tarifas (STJ Tema 932; EAREsp 738.991/RS, Corte Especial) |
| **Gestão de negócios** (CC 861) | Atuação espontânea, pode haver indenização ao gestor |
| **Responsabilidade civil** | Exige **ato ilícito** + culpa (CC 186) |
| **Tutela específica** (CPC 497) | Cumprimento in natura |

## Aplicação tributária

| | Conteúdo |
|---|---|
| **CTN 168** | Repetição de indébito **tributário** prescreve em **5 anos** |
| **Súm. 412 STJ** | Repetição de indébito de **tarifas de água e esgoto** (natureza não tributária) sujeita-se ao prazo prescricional do **Código Civil** |
| Restituição administrativa | Vedada para indébito reconhecido na via judicial; regime de **precatório** obrigatório (STF Tema 1.262, RE 1.420.691) |
| **Lei 14.385/2022** | Disciplina a devolução, aos consumidores de energia elétrica, de valores de tributos recolhidos indevidamente (altera a Lei 9.427/96) |
| **CC 884** | **NÃO se aplica** a tributos, regime CTN |

## Empobrecimento + enriquecimento mensuráveis

| Princípio | Conteúdo |
|---|---|
| Indenização = **MENOR** entre enriquecimento e empobrecimento (princípio do **maior favorecimento ao enriquecido**) |
| Salvo má-fé do enriquecido, então integralidade |

## Estado da arte 2024-2026

| | Conteúdo |
|---|---|
| Prescrição | Ação de enriquecimento = **3 anos** (CC 206 §3 IV), conforme STJ |
| **Subsidiariedade** (CC 886) | Não cabe quando existe via específica de ressarcimento |
| Repetição tributária | CTN 168 (5 anos); tarifas de água/esgoto = prazo do CC (Súm. 412 STJ) |
| Acumulação | Vedada com indenização contratual pelo mesmo fato (CC 886) |

## Roteiro de análise

1. Identificar os **4 elementos** (enriquecimento + empobrecimento + nexo + ausência de causa);
2. Verificar **subsidiariedade** (CC 886), há ação específica disponível?
3. Liquidar pelo **menor** (enriquecimento ou empobrecimento);
4. **Prescrição 3 anos** (CC 206 §3 IV);
5. Foro do **réu** (CPC 46);
6. Em tributário → não usar; **CTN 168** (5 anos);
7. Excluir hipóteses do CC 882 (dívida prescrita, obrigação natural).

## Erros a evitar

- Usar CC 884 quando existe **ação específica** (CC 886, subsidiariedade);
- Aplicar prescrição de 10 anos (STJ aplica **3 anos**, CC 206 §3 IV);
- Cobrar **integral** do enriquecimento (regra é o **menor** entre enriquecimento e empobrecimento);
- Repetir pagamento de **dívida prescrita** (CC 882 veda);
- Cobrar trabalho prestado em **vínculo CLT** via enriquecimento sem causa (deve usar verbas trabalhistas);
- Aplicar CC 884 em **tributário** (regime próprio do CTN 168);
- Acumular com **indenização contratual** pelo mesmo fato (CC 886);
- Tratar enriquecimento como **dano moral autônomo** (são institutos diversos);
- Ignorar **ausência de causa** como elemento, confundir com inadimplemento (este tem causa: o contrato);
- Aplicar em contratos **anuláveis ainda não anulados** (causa subsiste até desconstituição).

# ADI 4815: Biografias Não Autorizadas

## Identificação

| | Conteúdo |
|---|---|
| Ação | **ADI 4815** |
| Autor | **ANEL (Associação Nacional dos Editores de Livros)** |
| Relatora | Min. **Cármen Lúcia** |
| Julgamento | **10/06/2015** |
| Placar | **UNÂNIME** |

## Tese estruturante

| | Conteúdo |
|---|---|
| Resultado | **Procedente**: biografias **DISPENSAM autorização prévia** |
| Técnica | **Interpretação conforme** dos arts. 20 e 21 CC |
| Prevalência | Liberdade de **EXPRESSÃO + INFORMAÇÃO + ARTE + CIÊNCIA** |
| Responsabilização | **A POSTERIORI**: civil/criminal por excessos |

## CC 20 e CC 21

| | Conteúdo |
|---|---|
| **CC 20** | "Salvo se autorizadas, ou se necessárias à administração da justiça ou à manutenção da ordem pública, a divulgação de escritos, a transmissão da palavra, ou a publicação, a exposição ou a utilização da imagem de uma pessoa poderão ser proibidas, a seu requerimento e sem prejuízo da indenização que couber, se lhe atingirem a honra, a boa fama ou a respeitabilidade" |
| **CC 21** | "A vida privada da pessoa natural é inviolável, e o juiz, a requerimento do interessado, adotará as providências necessárias para impedir ou fazer cessar ato contrário a esta norma" |
| Pós-ADI 4815 | Interpretados **CONFORME** a CF: não exigem **autorização prévia** para biografias |

## Fundamento constitucional

| Art. | Conteúdo |
|---|---|
| **CF 5 IV** | Liberdade de manifestação do pensamento |
| **CF 5 IX** | Liberdade de **EXPRESSÃO**: atividade intelectual + artística + científica |
| **CF 5 XIV** | Acesso à informação |
| **CF 220** | Manifestação do pensamento **PLENAMENTE LIVRE**: vedada censura |
| **CF 5 V** | Direito de **RESPOSTA** proporcional |
| **CF 5 X** | Inviolabilidade: honra + intimidade + imagem |

## Ponderação aplicada

| | Conteúdo |
|---|---|
| Liberdade de expressão | **Posição preferencial** no debate público |
| Direitos da personalidade | Tutelados **A POSTERIORI** (indenização + retratação) |
| **Pessoa pública** | **Esfera de proteção REDUZIDA** quanto a atos públicos |
| **Pessoa privada** | **Esfera de proteção AMPLIADA** quanto à intimidade |

## Distinções importantes

| | Vida pública | Vida privada |
|---|---|---|
| Biografia | Compatível | Restrita (intimidade) |
| Imagem | Tolerância maior | Proteção robusta |
| Excesso | Indenização menor | Indenização maior |

| | Antes ADI 4815 | Pós (2015) |
|---|---|---|
| Autorização prévia | Exigida pelo CC 20 | **DISPENSADA** |
| Censura por liminar | Cabível em hipóteses | **Vedada** como regra |
| Responsabilização | A priori (autorização) | **A posteriori** (indenização) |

## Direito de resposta

| | Conteúdo |
|---|---|
| Base | **CF 5 V** + **Lei 13.188/2015** |
| Função | Resposta proporcional + retratação |
| Cabimento | Conteúdo ofensivo |
| Prazo | 60 dias |

## Responsabilização posterior

| | Conteúdo |
|---|---|
| Civil | Indenização por dano moral + material (CC 186 + 927) |
| **Penal** | Calúnia + difamação + injúria (CP 138-140) |
| Quantum | Critérios: extensão + repercussão + condição econômica |
| Retratação | Cabível |

## Liberdade artística + biográfica

| | Conteúdo |
|---|---|
| **Artistas** | Direito a relatar a vida |
| **Pesquisadores** | Liberdade científica |
| **Editores** | Direito a publicar |
| **Familiares** | Apenas legitimados a indenizar (não a censurar) |

## Pessoa pública

| | Conteúdo |
|---|---|
| Político | Atos no exercício do mandato: relatáveis |
| Artista | Vida pública/artística: relatável |
| **Atos privados** | Esfera de intimidade: tutelada |

## Tutela inibitória

| | Conteúdo |
|---|---|
| Liminar para impedir publicação | **EXCEPCIONAL** após ADI 4815 |
| Critério | Demonstração de **dano irreparável** + ofensa **clara** + sem alternativa |
| Censura genérica | **Vedada** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Biografia de pessoa pública | **Não exige autorização** |
| Biografia de privada | Limitada por intimidade, com responsabilização |
| Liminar para impedir | **Excepcional** + alta exigência probatória |
| Excesso/erro | **Indenização + retratação + direito de resposta** |
| Falecido | Cônjuge/parente: legitimidade indenizatória (não veto) |
| Pesquisa científica | **Ampla liberdade** |
| Documentário | **Mesma proteção** que biografia escrita |
| Filme/ficção | Tolerância maior + cláusulas (ressalva) |

## Cônjuge e família do biografado

| | Conteúdo |
|---|---|
| Legitimidade | **CC 12 § ún + CC 20 § ún**: indenizatória |
| **NÃO podem** | **VETAR** publicação |
| Legitimidade | Apenas **indenizatória** (indenização + retratação), não impeditiva |

## Erros a evitar

- A **autorização prévia** para biografias é vedada (ADI 4815);
- A **liminar de proibição** sem dano irreparável e ofensa clara configura censura prévia, vedada;
- O CC 20 e o CC 21 reclamam interpretação conforme, não aplicação **literal** (transformados pela ADI 4815);
- A **biografia de pessoa pública** submete-se a medida distinta da privada (esferas distintas);
- A ADI 4815 não afasta a **indenização**; a responsabilização **posterior** é cabível;
- A **censura prévia** fundada em direitos da personalidade é vedada;
- A **biografia (fatos)** não se confunde com a **ficção** (regimes e responsabilidade distintos);
- O veto familiar tem efeito apenas indenizatório, não impeditivo;
- As pesquisas históricas não dependem de autorização (liberdade científica, CF 5 IX);
- A **proibição perpétua** de obras já publicadas é incabível; a regra é a responsabilização individualizada.

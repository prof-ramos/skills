# Direitos da Personalidade

## Base normativa (CC 11-21)

| Art. | Conteúdo |
|---|---|
| **11** | **Intransmissíveis e irrenunciáveis**, sem limitação voluntária, salvo lei |
| **12** | Cessação de ameaça/lesão + perdas e danos, com **tutela específica CPC 497** |
| 12 par. único | **Morto**: cônjuge + ascendente + descendente + colateral até **4º grau** |
| **13** | Vedada disposição do próprio corpo se diminuição permanente, **salvo exigência médica** |
| **14** | Disposição **gratuita** do corpo pós-morte para fins científicos/altruísticos (revogável) |
| **15** | **Ninguém pode ser constrangido** a tratamento médico/intervenção com risco de vida |
| **16-19** | Direito ao **nome + pseudônimo**; cabível a **supressão do sobrenome paterno por abandono afetivo** (LRP art. 57, IV; STJ, 3ª Turma, REsp 2.169.650/GO, j. 03/03/2026) |
| **20** | **Direito à imagem**: uso autorizado; exceções: adm. justiça + ordem pública + pessoa pública (interesse jornalístico/histórico) |
| **21** | **Vida privada**: juiz adotará providências para impedir/cessar violação |

## LGPD (Lei 13.709/2018) complementa

Art. 18, direitos dos titulares:
- Confirmação de tratamento;
- **Acesso + correção + anonimização/bloqueio/eliminação**;
- Portabilidade;
- Informação sobre compartilhamento;
- Revogação do consentimento;
- Oposição.

## Jurisprudência crítica

| | Conteúdo |
|---|---|
| **STF Tema 786** (RE 1.010.606, 2021) | "É **INCOMPATÍVEL** com a CF a ideia de direito ao esquecimento" como direito autônomo. Não afasta responsabilização, caso a caso, por excesso ou abuso (honra + imagem + privacidade) |
| **STF ADI 4.815** (2015) | Biografias não autorizadas são **lícitas**: inconstitucional exigir autorização prévia do biografado |
| **STF Tema 761** (RE 670.422, 2018) | Pessoa **trans** tem direito subjetivo a alterar nome e gênero no registro civil **SEM cirurgia** + diretamente em cartório (Prov. CNJ 73/2018) |
| **STF Tema 622** (RE 898.060) | **Multiparentalidade**: paternidade socioafetiva NÃO impede reconhecimento concomitante do vínculo biológico, com efeitos jurídicos próprios |
| **STJ Súm. 403** | Indenização pelo uso não autorizado de imagem com fins econômicos/comerciais **independe de prova de prejuízo** (dano *in re ipsa*); **MITIGADA**: não se aplica a fatos históricos de repercussão social |
| **STJ Súm. 387** | Cumulação **dano moral + estético** |
| **STJ REsp 1.152.541** | **Critério BIFÁSICO** para arbitramento de dano moral: (1) valor-base por precedentes análogos; (2) ajuste pelas circunstâncias (gravidade + culpabilidade + condição econômica) |

## Lei 14.382/2022, modernização dos Registros Públicos

| | Conteúdo |
|---|---|
| Alteração de **prenome** após maioridade | **Uma vez** + **sem motivação** + diretamente em cartório |
| Sobrenome | Também alterável extrajudicialmente |
| **Supressão de sobrenome paterno por abandono afetivo** | Possível com fundamento no **art. 57, IV, da Lei 6.015/1973** (redação da Lei 14.382/2022), direito extensível aos descendentes (STJ, 3ª Turma, REsp 2.169.650/GO, Rel. ## Direito à própria imagem: exceções (CC 20)

| Hipótese | Conteúdo |
|---|---|
| Administração da justiça | Autorizado |
| Manutenção da ordem pública | Autorizado |
| Pessoa pública/figura célebre | Interesse jornalístico/histórico |

| | Conteúdo |
|---|---|
| Como **direito autônomo** | **REJEITADO** (Tema 786 STF) |

| Fase | Conteúdo |
|---|---|

| **2ª** | Ajuste pelas circunstâncias concretas: gravidade + culpabilidade + condição econômica |

## Tutela específica (CPC 497)

Inibitória + específica: não basta indenizar; deve-se **cessar a lesão** (CC 12 + CPC 497).

## Disposição do corpo + tratamento (CC 13-15)

| | Conteúdo |
|---|---|
| Disposição com risco de vida | **VEDADA** |
| Disposição gratuita pós-morte (científico) | Admitida (CC 14) |
| Tratamento com risco | **Não pode ser constrangido** (CC 15) |
| Consentimento informado | Essencial |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Uso indevido de imagem | **Dano moral** (Súm. 403) + tutela específica |
| Biografia não autorizada | **Lícita** (ADI 4.815) |
| Direito ao esquecimento autônomo | **REJEITADO** (Tema 786 STF) |
| Alteração de gênero sem cirurgia | **Admitida** (Tema 761) |
| Multiparentalidade | **Reconhecida** com efeitos plenos (Tema 622) |
| Dano moral, quantum | **Bifásico** (REsp 1.152.541) |
| Disposição do corpo com risco | **Vedada** (CC 13) |
| Tratamento médico imposto | **Vedado** (CC 15) |
| Dano moral + estético | **Cumuláveis** (Súm. 387) |
| Morto, legitimidade para tutela | Cônjuge + ascendente + descendente + colateral até 4º grau |

## Erros a evitar

- **Aplicar direito ao esquecimento** como direito autônomo (Tema 786 STF rejeita);
- **Não aplicar bifásico** para dano moral (REsp 1.152.541, recomendado pelo STJ);
- **Exigir autorização para biografias** (ADI 4.815 veda);
- Admitir **disposição do próprio corpo** com risco de vida (CC 13);
- Afastar **alteração de gênero sem cirurgia** (Tema 761);
- **Tratar Súm. 403 como absoluta**, fatos históricos + mero coadjuvante mitigam;
- Confundir prazo do par. único do CC 12, legitimação até **colateral 4º grau**;
- **Ignorar LGPD** como prolongamento dos direitos da personalidade (art. 18);
- Afastar **multiparentalidade** quando coexistem socioafetividade e biologia (Tema 622);
- Esquecer **tutela inibitória/específica do CPC 497** (não basta indenizar, cessar a lesão);
- Constranger paciente a **tratamento com risco** (CC 15).

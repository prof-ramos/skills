# Mandato

## CC 653: conceito

| | Conteúdo |
|---|---|
| Conceito | Alguém recebe poderes para **PRATICAR ATOS** ou **ADMINISTRAR INTERESSES** em nome de outrem |
| Procuração | **INSTRUMENTO** (forma) |
| Mandato | **Negócio jurídico** (substância) |

## CC 654: forma

| | Conteúdo |
|---|---|
| Regra | Instrumento **PARTICULAR ou PÚBLICO** |
| **§1** | **ESCRITURA PÚBLICA** para alienação de imóveis **> 30 SM** |
| **Lei 14.382/2022 (SERP)** | Sistema Eletrônico dos Registros Públicos: **procurações eletrônicas** com **assinatura digital ICP-Brasil** equiparadas à pública |
| Procuração **ad judicia** (CPC 105) | Habilita o advogado a praticar todos os atos do processo, **salvo poderes especiais expressos** (receber citação, confessar, reconhecer a procedência do pedido, transigir, desistir, renunciar, receber, dar quitação, firmar compromisso, assinar declaração de hipossuficiência) |

## CC 655-660: disposições

| Art. | Conteúdo |
|---|---|
| **655** | Ainda que o mandato seja por instrumento público, pode **substabelecer-se por instrumento particular** |
| **656** | Mandato pode ser **expresso ou tácito, verbal ou escrito** |
| **658** | **GRATUIDADE PRESUMIDA**: onerosidade só se estipulada ou inerente ao ofício (advogado/corretor) |
| **659** | Aceitação pode ser **TÁCITA** (resulta do começo de execução) |
| 660 | Mandato **especial** (negócios determinados) ou **geral** (todos os do mandante) |

## CC 663-668: responsabilidade

| Art. | Conteúdo |
|---|---|
| **663** | Atos do mandatário |
| **665** | Mandatário que excede poderes = **gestor de negócios** enquanto não ratificado |
| **667** | Mandatário responde por **CULPA** + prejuízos causados; agir contra interesses do mandante gera dever de indenizar |
| 668 | Prestação de contas |

### Anulação de ato doloso do procurador
| | Conteúdo |
|---|---|
| Prazo | **4 ANOS**, decadencial (CC 178 II, dolo) |
| Termo a quo | **Realização do negócio** (NÃO o conhecimento pelo mandante), conforme a literalidade do CC 178 II, aplicada pelo STJ |

## CC 685: MANDATO IN REM SUAM

| | Conteúdo |
|---|---|
| Conceito | Mandato **em causa própria** |
| **Irrevogável** | Sim (CC 685) |
| Morte | **NÃO extingue** |
| Prestação de contas | **DISPENSA** |
| Faculdade | Mandatário pode **transferir o bem para si** |
| Forma | Se imóvel > 30 SM → **escritura pública** |

## Substabelecimento (CC 655 + 667)

| Modalidade | Efeito |
|---|---|
| **COM reserva** | Mandatário **MANTÉM poderes** (atuação conjunta possível) |
| **SEM reserva** | **PERDE poderes** (translativo pleno) |
| **Sem autorização** (CC 667 §1) | Mandatário responde pelos danos causados pelo substabelecido, **ainda que provenientes de caso fortuito** (salvo prova de que o dano ocorreria mesmo sem o substabelecimento, CC 667 §1 in fine) |
| **Com autorização** (CC 667 §2) | Responde só por **culpa na escolha** do substabelecido ou **nas instruções** dadas |
| **Proibição descumprida** (CC 667 §3) | Atos do substabelecido **não obrigam o mandante**, salvo ratificação |
| **Procuração omissa** (CC 667 §4) | Mandatário responde **se o substabelecido proceder culposamente** |
| Forma | Pode ser por **instrumento particular**, ainda que o mandato seja público (CC 655) |

## CC 682: EXTINÇÃO

| Modalidade | Conteúdo |
|---|---|
| **Revogação** | Pelo mandante |
| **Renúncia** | Pelo mandatário |
| **Morte ou interdição** | De mandante OU mandatário: extinção **ipso iure** (não suspende) |
| Mudança de estado | Que inabilite a conferir poderes ou o mandatário para exercê-los |
| Término do prazo ou conclusão do negócio | Sim |

## Irrevogabilidade (CC 683-685)

| Art. | Conteúdo |
|---|---|
| **683** | Cláusula de irrevogabilidade: revogação é eficaz, mas obriga o mandante a **perdas e danos** |
| **684** | Irrevogabilidade como **condição de negócio bilateral** ou no **interesse exclusivo do mandatário**: revogação **INEFICAZ** |
| **685** | **IN REM SUAM**: revogação ineficaz + não se extingue pela morte + dispensa prestação de contas |

## Súm. 115 STJ

| | Conteúdo |
|---|---|
| Tese | "**Na instância especial** é inexistente recurso interposto por advogado sem procuração nos autos" |
| Alcance | Restrita à instância especial; nas instâncias ordinárias aplica-se o saneamento do vício de representação (CPC 76) |

## Distinções essenciais

| | Mandato comum | In rem suam |
|---|---|---|
| Revogabilidade | **REVOGÁVEL** | **IRREVOGÁVEL** |
| Morte | Extingue | **NÃO extingue** |
| Prestação de contas | EXIGE | **Dispensa** |

| | COM reserva | SEM reserva |
|---|---|---|
| Mandatário | Mantém poderes | Perde |
| Atuação conjunta | Possível | Não |

## Aplicações típicas

| Hipótese | Saída |
|---|---|
| Procuração para alienar imóvel > 30 SM | **Escritura pública** (CC 654 §1) |
| Procuração eletrônica ICP-Brasil | **Equiparada à pública** (Lei 14.382) |
| Advogado em juízo | **Ad judicia** (CPC 105) |
| Sem onerosidade estipulada | **Gratuita** (presunção CC 658) |
| Procurador age contra mandante | Indeniza os prejuízos (CC 667) |
| Anular ato doloso | **4 anos** da realização (CC 178 II) |
| Mandante morre | **EXTINGUE** (salvo *in rem suam*) |
| Recurso na instância especial sem procuração | **Inexistente** (Súm. 115 STJ) |
| Substabelecimento com procuração omissa | Mandatário responde por culpa do substabelecido (CC 667 §4) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Alienação > 30 SM | Escritura pública |
| Aceitação | Expressa ou tácita |
| Procurador atua contra mandante | Indeniza (CC 667) |
| Mandatário transfere a si | **In rem suam** (CC 685) |
| Morte | Extingue (regra) |
| Substabelecimento s/ reserva | Perde poderes |
| Procuração eletrônica | ICP-Brasil → pública (Lei 14.382) |

## Erros a evitar

- **Confundir gratuidade × onerosidade** (CC 658, gratuidade presumida);
- Aplicar o regime errado de responsabilidade no **substabelecimento** (sem autorização: responde até por fortuito, CC 667 §1; com autorização: só culpa in eligendo, §2; procuração omissa: culpa do substabelecido, §4);
- **Tratar morte como suspensão** (é extinção *ipso iure*);
- Admitir procuração **particular para alienar imóvel > 30 SM** (vedado, escritura pública);
- Tratar ***in rem suam*** como revogável (é irrevogável + não extingue por morte);
- **Computar o prazo de anulação do conhecimento** (CC 178 II: conta-se da realização do negócio);
- Conhecer **recurso na instância especial sem procuração** (Súm. 115 STJ, inexistente);
- Afastar **procuração eletrônica** ICP-Brasil (Lei 14.382 equipara);
- Aplicar **regras de mandato a outros negócios representativos** (sem mandato);
- Confundir **procuração (instrumento) com mandato (NJ)**;
- Dispensar **vênia conjugal** quando aplicável (CC 1.647).

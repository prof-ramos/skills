# Pessoa Jurídica

## CC 40, classificação

| Modalidade | Conteúdo |
|---|---|
| **Direito público externo** | Estados estrangeiros; organismos internacionais |
| **Direito público interno** | União, Estados, DF, Municípios, autarquias, **associações públicas** (CC 41 IV) + fundações públicas |
| **Direito privado** | CC 44 |

## CC 44, PJ DE DIREITO PRIVADO

| Inciso | Modalidade |
|---|---|
| **I** | **Associações** (sem fim econômico, CC 53) |
| **II** | **Sociedades** (com fim econômico, CC 981) |
| **III** | **Fundações** (CC 62-69) |
| **IV** | **Organizações religiosas** (Lei 10.825/2003) |
| **V** | **Partidos políticos** (Lei 9.096/1995) |
| **VI** | **EIRELI**, **EXTINTA** pela Lei 14.195/2021 (convertidas em SLU) |

## SLU, Sociedade Limitada Unipessoal (Lei 13.874/2019)

| | Conteúdo |
|---|---|
| Origem | Lei 13.874/2019; substitui a EIRELI desde a Lei 14.195/2021 |
| Regência | CC 1.052 §1 e §2 |
| **Vantagem** | Capital social sem mínimo + autonomia patrimonial |
| Conversão automática | EIRELIs convertidas em SLU pela Lei 14.195 |

## CC 45, INÍCIO DA EXISTÊNCIA

| | Conteúdo |
|---|---|
| Regra | **Inscrição** do ato constitutivo no respectivo **registro** + autorização legal quando necessário |
| Cartório civil PJ | Associações, fundações, organizações religiosas |
| Junta Comercial | Sociedades empresárias |
| Decadência | **3 anos** para invalidação dos atos constitutivos (CC 45 par. único) |

## CC 49-A, AUTONOMIA PATRIMONIAL (Lei 13.874/2019)

| | Conteúdo |
|---|---|
| **Par. único** | "A autonomia patrimonial das pessoas jurídicas é um instrumento lícito de **alocação e segregação de riscos**, estabelecido pela lei com a finalidade de **estimular empreendimentos**" |
| Função | Reforça princípio + obstaculiza desconsideração abusiva |

## ASSOCIAÇÕES (CC 53-61)

| Art. | Conteúdo |
|---|---|
| **53** | União de pessoas para fins **NÃO econômicos** |
| **54** | Estatuto obrigatório com: I denominação; II fins; III sede; IV requisitos para admissão; V direitos/deveres associados; VI fontes de recurso; VII modo constituição/funcionamento órgãos; VIII condições para alteração do estatuto + dissolução; IX forma gestão administrativa |
| **55** | Direitos **iguais** entre associados, salvo distinção previsão estatutária |
| **56** | Qualidade de associado é **intransmissível**, salvo previsão expressa |
| **57** | Exclusão admite **defesa** + recurso à assembleia |
| **59** | Competência privativa da **assembleia geral**: I destituir administradores; II alterar o estatuto. Exige assembleia **especialmente convocada**, com **quórum fixado no estatuto** (CC 59 par. único, redação da Lei 11.127/2005) |
| **61** | Dissolução → ativos destinados à entidade similar de fins não econômicos |

## FUNDAÇÕES (CC 62-69)

| Art. | Conteúdo |
|---|---|
| **62** | Criada por **dotação de bens** (escritura/testamento) + designação de fim **NÃO econômico** |
| **62 par. único** (red. Lei 13.151/2015) | Fins taxativos (incisos I-IX): I **assistência social**; II cultura, defesa e conservação do patrimônio histórico e artístico; III **educação**; IV **saúde**; V segurança alimentar e nutricional; VI **defesa, preservação e conservação do meio ambiente** e desenvolvimento sustentável; VII pesquisa científica, tecnologias alternativas, modernização de gestão e divulgação de conhecimentos técnicos; VIII promoção da ética, cidadania, democracia e direitos humanos; IX **atividades religiosas** |
| **64** | Insuficiência da dotação → incorpora-se a outra fundação similar |
| **65** | Estatuto submetido ao **MP** (velamento), alterações requerem aprovação |
| **66** | **MP** vela pelas fundações (federal/estadual conforme âmbito) |
| **67** | Alteração de estatuto: I 2/3 dos competentes para gerir; II vinculação ao fim original; III aprovação do MP |
| **69** | Dissolução → patrimônio destinado a outra fundação **similar** (preferência) |

## SOCIEDADES (CC 981-1.195)

| | Conteúdo |
|---|---|
| Conceito | **Pessoas que se obrigam reciprocamente** + contribuir para o exercício de atividade econômica + partilhar resultados |
| Tipos | Simples, Limitada, Anônima, Em Comandita, Em Nome Coletivo |
| **Simples** | Atividade intelectual, científica, literária ou artística (CC 982) |
| **Empresária** | Atividade empresarial (CC 982 + 966) |
| **Limitada** | Mais usada (CC 1.052-1.087) |
| **S/A** | Lei 6.404/1976 + 14.195/2021 |

## Estado da arte 2024-2026

| | Conteúdo |
|---|---|
| **Lei 13.874/2019** | Liberdade Econômica, autonomia patrimonial reforçada |
| **Lei 14.195/2021** | Extinção da EIRELI + Modernização do Ambiente de Negócios |
| **Lei 14.451/2022** | Redução do quórum para sociedades limitadas |

## Roteiro de análise

1. Classificar (público × privado);
2. Modalidade (associação, sociedade, fundação, organização religiosa, partido);
3. Verificar **registro** (Cartório PJ × Junta Comercial);
4. Aferir **autonomia patrimonial** (CC 49-A);
5. Em fundações → controle do **MP** (CC 65-66);
6. Sociedade limitada → SLU (sem mínimo de capital);
7. Desconsideração: CC 50 + IDPJ (CPC 133).

## Erros a evitar

- Criar EIRELI nova (extinta, Lei 14.195/2021);
- Tratar **associação** com finalidade econômica como válida (CC 53, sem fim econômico);
- Constituir fundação para **fim não previsto** no CC 62 par. único (taxativo);
- Ignorar **velamento do MP** em fundações (CC 65-66);
- Atribuir **personalidade** sem registro (CC 45);
- Confundir SLU com **EIRELI** (institutos diversos pós-2021);
- Tratar sociedades como pessoa jurídica de **direito público**;
- Desconsiderar PJ por mero **inadimplemento** (CC 50 exige abuso da personalidade; na seara tributária, Súm. 430 STJ: inadimplemento não gera, por si só, responsabilidade do sócio-gerente);
- Domicílio fixo único, múltiplas sedes geram múltiplos domicílios (CC 75 §1);
- Aplicar requisitos de fundação (MP) a **organização religiosa** (CC 44 §1).

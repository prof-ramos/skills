# Cadastro Positivo

## Lei 12.414/2011

| | Conteúdo |
|---|---|
| Função | Banco de dados de **ADIMPLEMENTO** (histórico de pagamentos) |
| Distinção | Diferente dos **cadastros RESTRITIVOS** (SCPC + Serasa: CDC 43) |

## LC 166/2019: INVERSÃO PARADIGMÁTICA

| | Conteúdo |
|---|---|
| **Pré** | Regime **OPT-IN** (consentimento prévio expresso) |
| **Pós** | **OPT-OUT**: **abertura AUTOMÁTICA** pelos gestores |
| Gestores | **Serasa + SPC + Boa Vista + Quod** |
| Exclusão | **2 dias úteis** após solicitação |
| Função | Ampliar base + reduzir **spread bancário** |

## ANPD + LGPD

| | Conteúdo |
|---|---|
| **ANPD** | Disciplina tratamento de dados |
| **LGPD** (Lei 13.709/2018) | Dados cadastrais e financeiros são **dados pessoais comuns** (não integram o rol de dados sensíveis do art. 5º II); o tratamento para **proteção do crédito** tem base legal própria (art. 7º X), nos limites da Lei 12.414 |

## Regime opt-out: salvaguardas

| | Conteúdo |
|---|---|
| Vigência | O regime **opt-out** da LC 166/2019 está em vigor e aplicável desde 2019 |
| Contrapesos | **Transparência + finalidade + direito à exclusão** (Lei 12.414 + LGPD) |
| Limites | Tratamento de dados sujeito à Lei 12.414, ao CDC e à LGPD (Lei 13.709/2018), sob fiscalização da ANPD |

## STJ: Súmulas

| | Conteúdo |
|---|---|
| **Súm. 550** | **CREDIT SCORING legítimo**: método estatístico de avaliação de risco que **não constitui banco de dados**; dispensa consentimento, mas assegura ao consumidor esclarecimentos sobre as informações valoradas e as fontes dos dados |
| **Súm. 359** | Cabe ao **órgão mantenedor** do cadastro de proteção ao crédito a **NOTIFICAÇÃO PRÉVIA** do devedor antes da inscrição |
| **Súm. 404** | É **dispensável o AR** na carta de comunicação ao consumidor sobre a negativação (também Tema 59 STJ) |
| **Súm. 385** | **PREEXISTÊNCIA** de inscrição legítima **AFASTA dano moral *in re ipsa***, ressalvado o direito ao cancelamento |

## STJ Tema 710 (credit scoring)

| | Conteúdo |
|---|---|
| Tese | O sistema **credit scoring** é método estatístico de avaliação de risco, prática comercial **LÍCITA** (Lei 12.414 arts. 5º IV e 7º I); dispensa consentimento do consultado, mas exige respeito à privacidade e à máxima transparência (CDC + Lei 12.414), com esclarecimentos, se solicitados, sobre fontes e dados considerados |
| Violação | Desrespeito aos limites de privacidade/transparência pode ensejar responsabilização |

## Notificação prévia (cadastro negativo, correlato)

| | Conteúdo |
|---|---|
| Dever | **NOTIFICAÇÃO PRÉVIA** do CDC 43 §2º é obrigação do **órgão mantenedor / arquivista** (não do credor): Súm. 359 |
| AR | Dispensável (Súm. 404 + Tema 59 STJ) |
| Legitimidade passiva | Órgãos mantenedores respondem pelos danos decorrentes de inscrição **sem prévia notificação**, inclusive quando os dados vêm de fontes públicas (Temas 37/38 STJ) |
| Ausência | Gera **direito à EXCLUSÃO + INDENIZAÇÃO** pelo mantenedor |
| **Salvo** | Súm. 385 (preexistência) |

## STJ Tema 922 (preexistência de anotação)

| | Conteúdo |
|---|---|
| Tese | A inscrição indevida **comandada pelo credor**, quando **preexistente legítima anotação**, **não enseja dano moral**, ressalvado o direito ao cancelamento (inteligência da Súm. 385) |
| Alcance | Estende a lógica da Súm. 385 às ações movidas **contra o credor** que efetivou a inscrição indevida |

## Lei 14.181/2021: Superendividamento

| | Conteúdo |
|---|---|
| Dialoga | Repactuação global considerando capacidade pelo histórico positivo |

## STJ 2026: dano moral em compartilhamento indevido

| | Conteúdo |
|---|---|
| **STJ (4ª Turma, 2026)** | Disponibilização não autorizada de **dados pessoais não sensíveis** em cadastro positivo, por si só, **NÃO gera dano moral presumido** |
| Requisito | Titular deve **demonstrar** a disponibilização/comercialização indevida + **abalo significativo** aos direitos de personalidade |
| Divergência interna | 3ª Turma (2025) reconhecia dano moral **presumido** na disponibilização em desacordo com a lei; a questão foi **afetada ao rito dos repetitivos**, com suspensão dos recursos sobre o tema |

## Distinções essenciais

| | Cadastro POSITIVO | Cadastro NEGATIVO |
|---|---|---|
| Conteúdo | **Adimplemento** | Inadimplência |
| Base | Lei 12.414 | CDC 43 + Lei 9.507 |
| Regime atual | **Opt-out (LC 166)** | Inscrição mediante notificação |

| | Credit scoring | Cadastro positivo |
|---|---|---|
| Natureza | Método estatístico | **Banco de dados** |
| Súm. 550 | Lícito | Lícito (LC 166) |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Inscrição automática | **OPT-OUT** (LC 166/2019) |
| Consumidor pede exclusão | **2 dias úteis** |
| Sem notificação prévia (negativo) | **EXCLUSÃO + indenização** pelo mantenedor (Súm. 359 + Temas 37/38 STJ) |
| Pré-existência de inscrição legítima | **Sem dano moral** (Súm. 385 + Tema 922) |
| Credit scoring | **Lícito** (Súm. 550 + Tema 710) |
| Superendividamento | **Repactuação** (Lei 14.181) |
| Acesso aos dados | **ANPD + LGPD** |

## Erros a evitar

- **Exigir CONSENTIMENTO PRÉVIO** para cadastro positivo (LC 166, opt-out);
- **Atribuir a notificação prévia ao CREDOR** (Súm. 359: é do órgão mantenedor/arquivista);
- Aplicar **dano moral automático** ignorando Súm. 385 e Tema 922;
- Tratar **credit scoring como banco de dados** (Súm. 550 + Tema 710: método estatístico);
- Afastar **direito de exclusão em 2 dias úteis**;
- Confundir **Lei 12.414 (positivo) com CDC 43 (negativo)**;
- Aplicar **regime pré-LC 166** após maio/2019;
- Tratar dados cadastrais/financeiros como **dados sensíveis** da LGPD (são dados pessoais comuns; a proteção do crédito é base legal do art. 7º X);
- Aplicar Súm. 385 quando **NÃO há preexistência** (gera dano);
- Tratar inscrição como **sempre indevida** (cabe se positiva);
- Exigir **AR** na comunicação de negativação (Súm. 404 + Tema 59: dispensável).

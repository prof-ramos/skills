# Portabilidade de Crédito

## Marco legal

- **Res. CMN 5.057/2022**: portabilidade de operações de crédito e de arrendamento mercantil (vigente desde 01/03/2023; sucedeu a Res. CMN 4.292/2013; alterada pela Res. CMN 5.112/2023: cheque especial e saldo de fatura de cartão desde 01/07/2024);
- **Res. CMN 3.402/2006 + Res. CMN 4.639/2018**: portabilidade de salário (solicitável na instituição destinatária); regras atualizadas pela Res. CMN 5.058/2022 + Res. BCB 284/2023;
- **Lei 10.820/2003**: consignado;
- **CDC** Lei 8.078/1990;
- **Circulares BCB**: operacionalização.

## Portabilidade de crédito

| | Conteúdo |
|---|---|
| Definição | Transferência de operação de crédito ativa de uma instituição (originária) para outra (proponente) |
| Direito | **Sem custo** ao consumidor |
| Vedações | Tarifas, taxas administrativas, comissão de transferência |
| Cobertura | Crédito pessoal, consignado, imobiliário, veículos, cartão |

## Modalidades abrangidas

| Operação | Portabilidade |
|---|---|
| Crédito pessoal | Sim |
| **Consignado** | Sim |
| Financiamento imobiliário | Sim (com regras específicas) |
| Financiamento de veículo | Sim |
| Cartão de crédito (dívida) | Sim |
| Cheque especial | Sim |
| Crédito rural | Sim (com regras) |

## Procedimento (Res. CMN 5.057)

| Etapa | Conteúdo |
|---|---|
| **1. Solicitação** ao banco originário | Pedido formal: saldo devedor + tabela de evolução |
| **2. Banco originário** | Fornece em até **2 dias úteis** |
| **3. Proposta** do banco proponente | Avaliação |
| **4. Aceitação** do consumidor | Manifestação livre |
| **5. Liquidação** | Banco proponente paga ao originário |
| **6. Transferência** | Em até **5 dias úteis** |
| **7. Quitação** | Originário emite termo |

## Tarifas e custos

| | Conteúdo |
|---|---|
| Ao consumidor | **Zero**: vedada cobrança |
| Tarifa interbancária | Por conta dos bancos |
| **Quitação antecipada** | Sem multa em consignado (Lei 10.820); análise nos demais |
| IOF | Não há novo IOF (mesma operação) |

## Banco originário: vedações

- Recusar fornecimento de saldo;
- Cobrar tarifa de quitação;
- Atrasar liquidação;
- **Reter dívida com proposta concorrente** sem comunicação clara;
- Aliciamento com mesma taxa (sem efetivo benefício).

## Aliciamento: limite

| | Conteúdo |
|---|---|
| Banco originário pode contraproposta | Sim |
| Em até | **5 dias úteis** após o pedido |
| Tem que ser **melhor** | Caso contrário, consumidor migra |
| Recusa imotivada após proposta concorrente | Indevida |

## Portabilidade de salário (Res. CMN 3.402/06 + 4.639/18)

| | Conteúdo |
|---|---|
| Direito | Receber salário em banco de escolha |
| Solicitação | Diretamente ao banco proponente |
| Prazo | Próximo crédito (1 mês) |
| Sem custo | Vedada cobrança |
| Sem motivação | Direito potestativo |
| Empregador não pode recusar | Apenas confirmar com o banco |

## Dano moral

- Não decorre automaticamente da recusa ou demora: depende da demonstração de abalo concreto que ultrapasse o mero dissabor (frustração da contratação, perda de oportunidade, descontos indevidos prolongados).

| Caso | Cabível |
|---|---|
| Recusa indevida | Conforme a repercussão concreta sobre o consumidor |
| Demora além do prazo | Caso a caso |
| Aliciamento com falsa proposta | Caso a caso |
| Cobrança de tarifa | Devolução em dobro (CDC 42 par. único; para cobranças posteriores a 30/03/2021, independe de má-fé, bastando a violação da boa-fé objetiva: EAREsp 676.608, Corte Especial) + eventual dano moral |
| Quantum | Referenciais usuais conforme a gravidade |

## Tutela antecipada

- Liberação imediata;
- Quitação retroativa;
- Astreintes;
- Inversão CDC 6 VIII.

## Crédito imobiliário: portabilidade

| | Conteúdo |
|---|---|
| Regras Res. CMN 5.057 | Aplicam-se |
| ITBI / cartório | Não incide novo |
| Garantia | Transferência da alienação fiduciária / hipoteca |
| Avaliação | Banco proponente pode reavaliar |
| Tempo médio | 30-60 dias (mais complexo) |

## Veículo

- Mesma sistemática;
- Alienação fiduciária transfere;
- DETRAN: atualizar gravame;
- Banco proponente cuida.

## Consignado

- Portabilidade ampla (Lei 10.820);
- Sem nova autorização do empregador (em regra);
- Cessação dos descontos no originário + início no proponente;
- Margem consignável: limite global de 40% (RGPS) / 35% (BPC) para contratos novos desde a MP 1.355/2026 (45% no regime anterior da Lei 14.431).

## Quitação antecipada

| | Conteúdo |
|---|---|
| **Sem multa** consignado | Lei 10.820 |
| Crédito pessoal | Conforme contrato (Res. CMN admite desconto proporcional) |
| Financiamento veículo | Desconto proporcional dos juros |
| Imobiliário (SFH) | Lei 10.150/2000: sem multa |
| Critério | **Desconto proporcional** dos juros futuros (CDC 52 §2) |

## Acumulação com revisão

- Possível: portabilidade + revisão judicial de cláusulas abusivas;
- Banco proponente assume com base no saldo revisado.

## Cláusulas inválidas

- "Multa por portabilidade";
- "Tarifa de transferência";
- "Renúncia ao direito de portabilidade";
- "Carência mínima de X meses para portar";
- Foro de eleição prejudicial.

## ANS: portabilidade de planos de saúde (referência)

Não confundir: a ANS regula portabilidade de planos de saúde (RN 438/2018); esta skill é sobre **crédito**.

## Erros a evitar

- Admitir **multa** ou tarifa em portabilidade (vedada);
- Validar **recusa** sem fundamento (Res. CMN 5.057);
- Admitir atraso > **5 dias úteis** sem responsabilidade;
- Admitir **carência mínima** para portar (vedada);
- Afastar quitação **antecipada** sem desconto proporcional (CDC 52 §2);
- Admitir aliciamento **sem efetivo benefício** ao consumidor;
- Afastar portabilidade em **consignado** (admitida);
- Omitir tutela em **demora prolongada**;
- Aplicar prescrição **trienal** à reparação (CDC 27, 5 anos);
- Admitir **dependência de autorização do empregador** em portabilidade de salário;
- Não aplicar a dobra do **CDC 42** a tarifas indevidas;
- Confundir portabilidade de crédito com portabilidade telefônica/saúde.

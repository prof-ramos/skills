# Letra Financeira (LF)

## Base legal

| Norma | Conteúdo |
|---|---|
| **Lei 12.249/10 arts. 37-43** | Criação e regime jurídico da LF |
| **Lei 14.430/22** | Atualização: flexibilizou prazo mínimo e formas |
| **Res. CMN 4.123/12 e 4.733/19** | Regulamentos anteriores, sucedidos pelo regime vigente |
| **Res. CMN 5.007/22** | Regulamento vigente (revogou a Res. 4.733/19 a partir de 02/05/2022): prazos, valores mínimos e modalidades |
| **Res. CMN 4.955/21** | Capital regulatório (sucedeu a Res. 4.192/13): LF subordinada elegível a Capital Nível 2 (Tier 2) |
| **Res. BCB 196/22** | Características operacionais |
| **CVM** | Distribuição pública sob Res. CVM 160/22 |
| **Lei 9.250/95** | **Sem isenção IR PF**, diferentemente de LCI/LCA/CRI |

## Conceito

| | Conteúdo |
|---|---|
| Definição | **Título de crédito** emitido por **IF** consistente em **promessa de pagamento** referente ao valor + remuneração |
| Emitentes habilitados | Bancos múltiplos, comerciais, de investimento, de desenvolvimento, sociedades de crédito, financiamento e investimento (SCFI), cooperativas de crédito, BNDES e CEF |
| **Não emite** | Corretoras, distribuidoras, administradoras de consórcio, instituições de pagamento |
| Finalidade | **Alongamento do passivo** da IF: captação de prazo médio/longo |
| Forma | **Escritural**, registrada em depositária autorizada (B3/Cetip) |
| Cláusula à ordem | Sim, circulável |
| **Sem FGC** | Não há cobertura: assumir risco da IF emissora |
| **Sem isenção IR PF** | Tributação normal (IR regressivo 22,5% → 15%) |

## Modalidades

| Tipo | Conteúdo |
|---|---|
| **LF Simples (Sênior)** | Dívida ordinária da IF; preferência sobre subordinada na liquidação |
| **LF Subordinada** | Pagamento subordinado a credores comuns; **elegível a Capital Nível 2** (Res. CMN 4.955/21); resgate antecipado restrito às hipóteses regulamentares (Res. CMN 5.007/22 e 4.955/21) |
| **LF Perpétua** | Sem prazo de vencimento; elegível a **Capital Nível 1** quando atende requisitos (cláusulas de absorção de perdas) |
| **LF com Cláusula de Recompra** | Permite recompra pela emissora após prazo mínimo |
| **LF com Cláusula de Subordinação** | Mais arriscada; remunera com prêmio |
| **LF Verde/Social/Sustentável** | Lastreio ESG: Res. CMN 5.115/23 (incentivos para emissões verdes) |

## Prazo mínimo

| Modalidade | Prazo |
|---|---|
| LF Simples (não-subordinada) | **24 meses** (Res. CMN 5.007/22) |
| LF Subordinada | **5 anos**: atende exigência regulatória de capital |
| LF Perpétua | Sem prazo de vencimento |
| Resgate antecipado | Em regra **vedado** antes do prazo; exceções: subordinada com autorização BCB, recompra pactuada |

## Valor mínimo

| | Conteúdo |
|---|---|
| **LF não-subordinada** | Valor nominal unitário mínimo de **R$ 50.000** (Res. CMN 5.007/22) |
| **LF subordinada** | Valor nominal unitário mínimo de **R$ 300.000** (Res. CMN 5.007/22) |
| LF para investidor qualificado | Conforme Res. CVM 30/21, valores próprios |
| Distribuição pública restrita | Res. CVM 160/22: até 75 investidores profissionais |

## Requisitos formais (Lei 12.249 art. 38)

| Inc. | Requisito |
|---|---|
| I | Denominação **"Letra Financeira"** |
| II | Nome da IF emissora |
| III | Valor nominal |
| IV | Data de emissão e vencimento |
| V | Taxa de juros + atualização monetária |
| VI | Local de emissão |
| VII | Cláusula de subordinação, se houver |
| VIII | Nome do beneficiário (título escritural e nominativo; emissão ao portador incompatível com o registro em depositária) |
| IX | Cláusula à ordem |
| X | Local de pagamento |

## Executividade e cobrança

| | Conteúdo |
|---|---|
| Executividade | **Título executivo extrajudicial** (Lei 12.249 art. 41 + CPC 784 I/III) |
| Liquidez | Apurada pelo valor nominal + remuneração contratada |
| Inadimplemento | Cobrança pelo titular contra a IF emissora |
| Prescrição | **5 anos** (CC 206 §5 I) |

## Tributação

| | Conteúdo |
|---|---|
| IR PF/PJ | Regressivo: 22,5% (até 180 dias), 20% (181-360), 17,5% (361-720), **15%** (acima 720 dias) |
| IOF | Resgate antes de 30 dias: tabela regressiva (≠ aplicação de longo prazo) |
| **Sem isenção IR PF** | Diferente de LCI/LCA/CRI/CRA/Debênture Incentivada: desvantagem competitiva |
| Lei 14.754/23 | "Lei dos Fundos": não impacta LF diretamente |

## Mercado e finalidade regulatória

| | Conteúdo |
|---|---|
| Função | **Alongamento do passivo bancário**: reduz dependência de captação de curto prazo (CDB, depósitos) |
| LCR/NSFR | LF longa contribui para indicadores regulatórios de liquidez (Basileia III) |
| Capital Nível 2 | LF Subordinada compõe Tier 2: fortalece índice de Basileia |
| Capital Nível 1 | LF Perpétua + cláusulas de absorção (CET1 só com ações) |
| Cliente alvo | Investidor qualificado/profissional + institucional + private |
| Liquidez secundária | Negociação em mercado de balcão (B3), geralmente baixa |

## Erros a evitar

- Tratar **LF** como **CDB de prazo longo**: não há FGC, risco distinto;
- Aceitar **resgate antecipado** sem cláusula expressa ou autorização BCB (subordinadas);
- Aplicar **isenção IR PF** à LF: não há (≠ LCI/LCA);
- Contratar **LF Subordinada** sem informar ao cliente o **risco de absorção** em caso de resolução bancária (Lei 13.506/17);
- Emitir LF não-subordinada com **valor nominal inferior a R$ 50 mil** (Res. CMN 5.007/22);
- Confundir **LF Perpétua** com **dívida sem obrigação**: IF deve cumprir cláusulas de cupom até intervenção/liquidação;
- Esquecer **escrituração eletrônica em depositária** (B3/Cetip): característica obrigatória;
- Emitir LF por instituição não habilitada (corretora, distribuidora, IP): nulidade;
- Considerar LF um produto **de baixo risco** apenas porque emitido por IF: sem FGC;
- Tratar LF subordinada como elegível **automaticamente** a Capital Nível 2: depende de validação BCB (Res. CMN 4.955/21);
- Não observar o **valor nominal mínimo de R$ 300 mil** para a LF subordinada;
- Confundir LF com **CCB**: CCB representa crédito; LF é captação;
- Aplicar **prescrição de 6 meses** (cheque) ou **3 anos** (CC) à LF: o prazo é 5 anos (CC 206 §5 I).

# Crimes contra o Sistema Financeiro Nacional

## Lei 7.492/1986 — "Lei do Colarinho Branco"

| | Conteúdo |
|---|---|
| Tutela | **Higidez do Sistema Financeiro Nacional (SFN)** |
| Articulação | Lei 4.595/64 (LRBSF) + Lei 6.385/76 (CVM) + atuação **BACEN/CVM** |

## Art. 1 — INSTITUIÇÃO FINANCEIRA

| | Conteúdo |
|---|---|
| Conceito | **AMPLO** — PJ que **capte + intermedeie + aplique** recursos próprios/3º |
| Inclui | Equiparadas |
| **Lei 14.478/2022** | **ATIVOS VIRTUAIS** — exchanges de cripto + custodiantes + plataformas DeFi com intermediação |
| **Lei 14.286/2021** | Novo Marco Cambial — redesenhou art. 22 sem descriminalizar |

## Art. 4 — GESTÃO FRAUDULENTA × TEMERÁRIA

| | Caput (fraudulenta) | Par. único (temerária) |
|---|---|---|
| Pena | **Recl. 3-12 anos + multa** | **Recl. 2-8 anos + multa** |
| Elemento subjetivo | **Dolo de FRAUDE** | **Assunção de RISCO PROIBIDO** |
| Habitualidade | **Crime habitual IMPRÓPRIO** (reiteração não multiplica) — exige sequência | **Habitualidade PRÓPRIA** — sucessão de atos, não fato isolado |

## Art. 22 — EVASÃO DE DIVISAS

| | Conteúdo |
|---|---|
| Pena | **Recl. 2-6 anos + multa** |
| Caput | Câmbio **NÃO AUTORIZADO** para evasão |
| Par. único 1ª parte | Saída de moeda |
| **Par. único 2ª parte** | **Manter DEPÓSITOS NÃO DECLARADOS** ao BACEN (Declaração **CBE/Anexo**) |

### STJ — interpretação AMPLA de "depósito"
| | Conteúdo |

| Insignificância | **REJEITADA** em regra |

## Prescrição

| | Conteúdo |
|---|---|
| Regida pela | **Pena máxima** (CP 109) |
| Art. 4 caput | **16 anos** (8-12 anos) |
| Art. 22 | **12 anos** (4-8 anos) |

## Distinções essenciais

| | Gestão fraudulenta | Gestão temerária |
|---|---|---|
| Dolo | Fraude | Risco proibido |
| Pena | 3-12a | 2-8a |
| Habitualidade | Imprópria | **Própria** |

| | Lei 7.492 | Lei 8.137 (tributários) |
|---|---|---|
| Bem jurídico | SFN | Erário |
| Competência | JF | JF (alguns) ou JE |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Banco com gestão de risco | **Art. 4 caput** se fraude / par. único se temerária |
| Conta no exterior > U$$ 100k não declarada | **Art. 22 par. único** (CBE) |
| Bitcoin no exterior sem CBE | **Art. 22** (HC 711.555) |
| IF clandestina (factoring) | **Art. 9-10** |
| Caixa 2 bancário | **Art. 11** |
| Financiamento obtido por fraude | **Art. 19** |
| Desvio de crédito oficial | **Art. 20** |
| Conexão com lavagem | **Lei 9.613** cumulada |
| Pena mínima < 4a | **ANPP** cabível |
| Competência | **JF** sempre (CF 109 VI) |
| Prescrição art. 4 | **16 anos** (pena máx > 12) |

## Erros a evitar

- **Aplicar COMPETÊNCIA ESTADUAL** (Tema 1.124 + art. 26, sempre JF);
- **Confundir gestão FRAUDULENTA com TEMERÁRIA** (art. 4 caput × par. único);
- **Aplicar Lei 7.492 FORA de IF** (art. 1, exige conceito amplo);
- **Ignorar EQUIPARAÇÃO de ativos virtuais** (Lei 14.478/2022);
- **Desconsiderar Declaração CBE como ELEMENTAR** do art. 22 par. único;
- Aplicar **insignificância em evasão de divisas** (STJ rejeita);
- Não aplicar **ANPP** em tipos com pena mínima < 4a (cabível);
- Aplicar **Súm. 522 STF apenas a moeda falsa** (atrai sistema bancário em geral);
- Tratar **gestão fraudulenta como habitual próprio** (é imprópria);
- Aplicar **revogação de art. 22** pela Lei 14.286 (manteve);
- Não cumular com **Lei 9.613** (lavagem, quando cabível).

# Conta-Corrente Bancária e Depósito

## Base normativa

| Norma | Conteúdo |
|---|---|
| **CC 627-652** | Contrato de depósito (regular e irregular) |
| **CC 645** | Depósito de coisas fungíveis = depósito irregular = empréstimo (regido por regras do mútuo) |
| **Lei 4.595/64** | SFN, atividade privativa de instituição financeira |
| **Res. CMN 4.753/19** | Abertura, manutenção e **encerramento** de contas de depósito |
| **Res. CMN 4.949/21** | Princípios e procedimentos de relacionamento com clientes |
| **Res. CMN 3.919/10** | **Tarifas** bancárias e segmentação por pacotes |
| **Res. CMN 3.402/06** | **Conta-salário**, isenção de tarifas |
| **Res. CMN 4.765/19** | Cheque especial: limite, juros, MEC |
| **Lei 7.357/85** | Cheque + CCF (Cadastro de Emitentes de Cheques sem Fundos) |
| **Res. CMN 4.571/17** | SCR, Sistema de Informações de Crédito do BCB |
| **CDC arts. 14, 39, 42, 51** | Tarifas abusivas + cobrança vexatória + cláusulas nulas |
| **Súm. 297 STJ** | CDC aplicável às IFs |

## Natureza jurídica

| | Conteúdo |
|---|---|
| Tipologia | **Depósito irregular** (CC 645): IF assume propriedade do dinheiro e obriga-se a restituir quantidade equivalente |
| Característica adicional | Contrato **plurifuncional**: depósito + mandato (pagamentos) + abertura de crédito (cheque especial) |
| Onerosidade | Onerosa quando tarifada; gratuita em pacotes essenciais (Res. CMN 3.919/10 art. 2) |
| Forma | Por adesão, sujeita ao CDC + CC 423 (interpretação favorável ao aderente) |
| Conta-corrente × Poupança | Conta-corrente = movimentação livre; Poupança = remuneração legal (Lei 8.177/91 + Res. CMN 4.819/20) |

## Abertura

| Requisito | Conteúdo |
|---|---|
| **Identificação** | RG + CPF (PF) ou CNPJ + atos constitutivos (PJ), Res. CMN 4.753 art. 3 |
| **Comprovação de endereço** | Documento de até 90 dias |
| **PEP** | Diligência reforçada se Pessoa Exposta Politicamente (Circ. BCB 3.978/20, PLD/FT) |
| **Cadastro Único Bancário** | Compartilhado entre IFs do mesmo conglomerado |
| **CCS-BCB** | Cadastro de Clientes do Sistema Financeiro, registro centralizado de relacionamento |
| **Adesão** | Contrato + ficha cadastral + autorização SCR (LC 105/01 ressalvada, sigilo bancário) |
| **Restrição** | IF pode recusar abertura, exceto contas-salário (são por designação do empregador) |

## Encerramento

| Hipótese | Conteúdo |
|---|---|
| **Pelo titular** | Imediato: pagamento de saldo devedor + devolução de cheques |
| **Pela IF** | **Aviso prévio de 30 dias** (Res. CMN 4.753/19 art. 12) + comunicação formal |
| **Saldo positivo** | Direito do titular a recebê-lo a qualquer tempo |
| **Saldo negativo** | Cobrança ordinária (CCB ou contrato de abertura de crédito) |
| **Inatividade** | 6 meses sem movimentação + saldo zero: IF pode encerrar |
| **CCF** | Inscrição por devolução nos motivos regulamentares (2ª apresentação sem fundos, conta encerrada, conta inativa), Res. CMN 1.682/90 |
| **Súm. 572 STJ** | O BB, na condição de gestor do CCF, **não tem** o dever de notificar previamente o devedor sobre a inscrição, tampouco legitimidade passiva nas ações fundadas na ausência de prévia comunicação |

## Tarifas (Res. CMN 3.919/10)

| Categoria | Cobrança |
|---|---|
| **Pacote essencial** | **Gratuito**, limita serviços (saques, transferências, extratos mensais) |
| Pacote padronizado | Tabela do BCB, comparável entre IFs |
| Pacote diferenciado | Livre, desde que detalhado no contrato |
| **Serviços essenciais isolados** | Gratuitos: cartão de débito, 2º via cartão por defeito, 1º cheque mensal, 2 extratos/mês, 4 saques/mês, transferências entre contas do mesmo banco |
| Manutenção mensal | Permitida apenas no pacote contratado; não pode haver cobrança paralela |

## Cheque especial (Res. CMN 4.765/19)

| | Conteúdo |
|---|---|
| Natureza | **Abertura de crédito rotativo** vinculada à conta de depósitos à vista; não é título executivo (Súm. 233 STJ) |
| Alcance | Contas de PF e de **MEI** (Res. 4.765 art. 1º) |
| Juros máximos | **8% ao mês** sobre o valor utilizado (Res. CMN 4.765/19 art. 3º), teto regulatório vigente desde 06/01/2020 |
| Tarifa de disponibilização | **Vedada**: o art. 2º da Res. 4.765 (tarifa de até 0,25% sobre o limite acima de R$ 500) foi revogado pela Res. CMN 4.962/21 e declarado inconstitucional pelo STF (ADI 6.407) |
| Limites | Compatíveis com o perfil de risco; vedado impor limite superior a R$ 500 se o cliente optar por limite menor; **majoração** exige autorização prévia do cliente (art. 4º) |
| Redução do limite | Comunicação prévia de **30 dias**, dispensada em caso de deterioração do risco de crédito (art. 4º §§ 2º-3º) |
| Capitalização | Permitida com pactuação expressa (Súm. 539 STJ) |

## Conta-salário (Res. CMN 3.402/06)

| | Conteúdo |
|---|---|
| Finalidade | Recebimento exclusivo de salários/proventos |
| Tarifas | **Vedada** cobrança de manutenção, saques, transferências |
| Portabilidade | **Imediata e gratuita**: direito do trabalhador escolher conta-receptora |
| Conversão | Pode ser transformada em conta-corrente comum a pedido do titular |
| Impenhorabilidade | Salário é impenhorável (CPC 833 IV); reserva de até 40 SM protegida (CPC 833 X, estendida pela jurisprudência a outras contas) |

## SCR (Sistema de Informações de Crédito)

| | Conteúdo |
|---|---|
| Base normativa | Res. CMN 4.571/17 + Circular BCB 3.870/17 |
| Captura | Operações a partir de R$ 200 reportadas mensalmente |
| Acesso ao cliente | Gratuito via Registrato BCB |
| Inclusão em SCR | Não é inscrição em órgão restritivo (≠ SPC/Serasa): não autoriza dano moral por si |
| Correção | Pelo Registrato BCB ou ouvidoria da IF |

## STJ: jurisprudência relevante

| | Conteúdo |
|---|---|
| **Súm. 322 STJ** | "Para a repetição de indébito, nos contratos de abertura de crédito em conta-corrente, **não se exige a prova do erro**" |
| **Súm. 297 STJ** | CDC aplicável a IFs |
| **Súm. 233 STJ** | Contrato de abertura de crédito **não é título executivo**: cobrança por ação de cobrança ou monitória (CPC 700) |
| **Súm. 247 STJ** | Contrato de abertura de crédito em conta-corrente + demonstrativo de débito = documento hábil para **ação monitória** |
| Repetição de indébito em conta-corrente | Prescrição **decenal** (CC 205), orientação do STJ (não sumulada) |
| **Súm. 379 STJ** | Nos contratos bancários não regidos por legislação específica, os juros **moratórios** podem ser convencionados até 1% a.m. |
| Orientação do STJ | Inscrição no SCR, por si só, não gera dano moral |
| Tema 27 STJ | Revisão de juros remuneratórios admitida só em situações excepcionais, comprovada abusividade ante a taxa média de mercado |
| Súm. 539 STJ | Capitalização em cheque especial válida se expressamente pactuada (pós 31.03.2000) |
| Tema 411 STJ | Cabível a inversão do ônus da prova em favor do consumidor para determinar à IF a exibição de extratos bancários, obrigação legal e de integração contratual compulsória, cabendo ao correntista indicar indícios da contratação e especificar os períodos |

## Erros a evitar

- Tratar **conta-corrente** como depósito regular (CC 627): é irregular (CC 645);
- Confundir **conta-salário** com conta-corrente: vedação de tarifas + impenhorabilidade próprias;
- Cobrar **manutenção** em pacote essencial (Res. CMN 3.919/10);
- Encerrar conta unilateralmente **sem aviso de 30 dias** (Res. CMN 4.753 art. 12);
- Aplicar a cheque especial os **juros remuneratórios livres**: há **teto regulatório de 8% a.m.** (Res. CMN 4.765/19);
- Cobrar **tarifa pela disponibilização** do cheque especial: vedada (art. 2º da Res. 4.765 revogado e declarado inconstitucional, ADI 6.407 STF);
- Considerar **execução direta** do saldo devedor em conta-corrente: Súm. 233 STJ veda;
- Negar **portabilidade** de conta-salário: direito subjetivo do trabalhador;
- Inscrever no **CCF** fora dos motivos regulamentares (Res. CMN 1.682/90);
- Penhorar **conta-salário**: impenhorabilidade reforçada (CPC 833 IV);
- Tratar **SCR** como SPC/Serasa: registro neutro, sem dano moral automático;
- Esquecer **prescrição decenal** para repetição de indébito em conta (CC 205);
- Não pedir **exibição de extratos completos** com inversão do ônus quando a operação é controvertida (Tema 411 STJ).

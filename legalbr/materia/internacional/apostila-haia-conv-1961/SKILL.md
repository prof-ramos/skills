# Apostila da Haia

## Marco legal

- **Convenção da Haia de 5/10/1961** (Convenção sobre a Eliminação da Exigência de Legalização de Documentos Públicos Estrangeiros);
- **Decreto 8.660/2016** (promulgação no Brasil);
- **CNJ Resolução 228/2016** (regulamentação interna + autoridades competentes);
- **CNJ Provimento 62/2017** + atualizações;
- Lei 6.015/73 (registros públicos);
- HCCH (Hague Conference on Private International Law).

## Conceito

Apostila = **certificado** emitido por autoridade competente do Estado de origem que atesta:
- **Autenticidade da assinatura** do signatário;
- **Qualidade** em que ele atuou (cargo, função);
- **Identidade do selo ou carimbo**.

Não atesta o conteúdo do documento.

## Vigência no Brasil

| Data | Evento |
|---|---|
| 5/10/1961 | Convenção em Haia |
| 2/12/2015 | Adesão pelo Brasil (instrumento depositado) |
| **14/08/2016** | **Entrada em vigor no Brasil** |
| Aplicação | Cerca de **120 Estados-parte** (verificar lista HCCH atualizada) |

## Documentos abrangidos (art. 1 Conv.)

| Categoria | Exemplos |
|---|---|
| **Documentos administrativos** | Certidões, atestados, declarações de órgãos públicos |
| **Documentos notariais** | Escrituras, procurações, autenticações |
| **Documentos judiciais** | Sentenças, mandados, certidões de cartório judicial |
| **Documentos com declaração oficial** | Reconhecimento de firma + autenticação em particulares |
| **Certificações oficiais** | Diplomas, históricos, certidões civis |

## NÃO abrangidos

| | Conteúdo |
|---|---|
| **Documentos diplomáticos/consulares** | Excluídos pela própria Convenção |
| **Documentos comerciais e alfandegários** | Manifestos, fatura comercial, certificado de origem |
| Documentos **particulares puros** | Sem reconhecimento de firma não se apostilam diretamente; precisam ser **autenticados** primeiro |
| Países **não-parte** | Continua **legalização consular** tradicional |

## Apostila × legalização consular tradicional

| | Apostila | Legalização consular |
|---|---|---|
| Estados-parte | Convenção da Haia | Demais países |
| Fluxo | **Único ato** no país de origem | Múltiplos passos: cartório + Itamaraty + Consulado do país de destino |
| Tempo | Dias | Semanas/meses |
| Custo | Reduzido | Maior |
| Validade | Aceita pelos países parte | Conforme acordos bilaterais |

## Autoridades competentes no Brasil (CNJ 228)

| Documento | Apostiladora |
|---|---|
| **Notarial** | Tabelionato de Notas |
| **RCPN** (certidões civis) | RCPN ou Tabelionato (autoridade designada) |
| **RTD/PJ** | Cartório de Registro de Títulos e Documentos / Registro de PJ |
| **Judicial** | **Foro Judicial** (CGJ de cada Tribunal) ou tabelionatos credenciados |
| **Administrativo federal** (MEC, INSS, RFB) | Tabelionato, após autenticação |
| **Documento militar** | Ministério da Defesa, autoridades específicas |

## Sistema eletrônico

| | Conteúdo |
|---|---|
| Sistema CNJ | **SEI Apostila** (portal eletrônico do CNJ) |
| Selo eletrônico | Verificação pelo QR code + número da apostila |
| Validação | Disponível no portal do CNJ e na rede HCCH |
| Banco de dados | Manuseado pelos tabeliães credenciados |

## Procedimento para apostilar (documento brasileiro)

1. **Autenticar** ou reconhecer firma em cartório (se necessário);
2. Levar a tabelionato/órgão competente para apostilamento;
3. Pagar emolumentos (estaduais, valor variável);
4. Receber **apostila** anexa ao documento + verificável no QR code;
5. (Quando exigido) **Tradução juramentada** + apostilamento da tradução.

## Tradução juramentada (Decreto 13.609/1943 + Lei 14.195/2021)

| | Conteúdo |
|---|---|
| **Obrigatória** | Quando documento estrangeiro for produzir efeitos no Brasil em **idioma estrangeiro** |
| Tradutor Público | Habilitado em Junta Comercial (concurso) |
| Lei 14.195/2021 | Novo regime dos tradutores públicos (inclusive certificação) |
| Apostilamento | A **tradução juramentada** também precisa ser apostilada quando for circular para outro país |

## Reconhecimento no exterior

| | Conteúdo |
|---|---|
| Apostila brasileira válida | Em **qualquer Estado-parte** |
| Reservas | Alguns países exigem requisitos adicionais |
| Tradução | Geralmente exigida pelo país de destino |
| Banco de dados | Países parte mantêm registros verificáveis |

## Documento estrangeiro apostilado no Brasil

| | Conteúdo |
|---|---|
| Aceitação | **Direta**, sem novo trâmite consular |
| **Tradução juramentada** | Necessária se em idioma estrangeiro |
| **Registro** | RTD (CC 129) se a lei brasileira exigir |
| Produzir efeitos | Cartório + RCPN + STJ (sentença estrangeira) |

## Sentenças estrangeiras (relação com homologação)

| | Conteúdo |
|---|---|
| **Sentença estrangeira para homologação** | STJ (RISTJ + CPC 960-965) |
| Apostila | **Substitui** a legalização consular do documento |
| Tradução | Mantida |
| Procedimento | RISTJ arts. 216-A ss. |

## Documentos consulares e seus limites

- Atos do Itamaraty no exterior **não** se apostilam; são considerados consulares (excluídos pela Convenção);
- Procurações consulares têm regime próprio (CC 215);
- Em alguns países, autoridades consulares brasileiras emitem **apostila** para documentos lavrados em terreno brasileiro (consulado);
- **Atenção a dupla apostila** quando documento circula entre 3+ jurisdições.

## Casos especiais

| Cenário | Tratamento |
|---|---|
| **Diploma escolar/universitário** | Apostilar; necessário para revalidação no exterior |
| Certidão de nascimento para casamento | Apostilar + traduzir |
| Procuração para ato no exterior | Lavrar + apostilar |
| Documentos para visto | Apostilar conforme exigência consular |
| **Documento sem autoridade conhecida** | Reconhecer firma primeiro, depois apostilar |

## Países não signatários (lista varia)

- Verificar lista atualizada no HCCH;
- Estados ainda não parte: alguns países asiáticos e africanos;
- Para estes: legalização consular tradicional (cartório + Itamaraty + consulado do país de destino).

## Erros a evitar

- Tentar apostilar **documento comercial alfandegário** (excluído);
- Aplicar apostila para **país não-parte** (precisa legalização consular);
- Esquecer **tradução juramentada** + apostilamento da tradução;
- Tentar legalizar consularmente documento para país **parte** (a apostila substitui);
- Não verificar via **QR code** (autenticidade);
- Achar que apostila valida **conteúdo** (só autentica assinatura + cargo + selo);
- Apostilar documento **particular puro** sem autenticação prévia;
- Esquecer registro em RTD quando lei exige (CC 129);
- Levar documento **diplomático/consular** para apostilar (excluído pela Convenção);
- Confundir com **homologação de sentença** (essa exige procedimento no STJ; a apostila apenas autentica a origem).

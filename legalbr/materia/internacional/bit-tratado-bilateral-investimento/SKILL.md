# BIT, ACFI e Proteção Internacional de Investimentos

## Marco legal

- **Convenção ICSID 1965 (Washington)**: **Brasil NÃO é parte**;
- **Convenção MIGA 1985**: Brasil é parte (garantia política);
- **Modelo BIT clássico** (não vigente no Brasil);
- **Modelo ACFI** brasileiro (desde 2015): MDIC + Itamaraty;
- Lei 4.131/1962 (Capital Estrangeiro) + Lei 11.371/2006;
- BACEN Resolução 4.373/2014 (investimento estrangeiro);
- Tratados específicos assinados (ACFIs);
- OCDE Diretrizes para Empresas Multinacionais (RBC).

## Posição histórica brasileira

| | Conteúdo |
|---|---|
| **BITs anos 90** | 14 assinados (com Alemanha, Bélgica, Chile, Coreia do Sul, Cuba, Dinamarca, EUA, França, Itália, Países Baixos, Portugal, Suíça, Reino Unido, Venezuela) |
| **Ratificação** | **NENHUM** ratificado pelo Congresso Nacional |
| Razões | Receio com ISDS + soberania regulatória + preocupações ambientais |
| **ICSID** | Brasil não é parte |
| **MIGA** | Brasil é parte (proteção contra riscos políticos) |
| **2015** | Início do modelo ACFI |

## Modelo ACFI (brasileiro)

| Continente | Países |
|---|---|
| **África** | Moçambique, Angola, Malawi, Etiópia, Marrocos, São Tomé e Príncipe |
| **Américas** | México, Colômbia, Chile, Peru, Suriname, Guiana, Equador |
| **Ásia/Oriente Médio** | Índia (em vigor desde 2025), EAU |

## Diferenças BIT × ACFI

| | **BIT tradicional** | **ACFI brasileiro** |
|---|---|---|
| **Soluções de controvérsias** | **ISDS**, Investor-State Dispute Settlement (arbitragem direta) | **State-State Dispute Settlement** + Joint Committee |
| **Ombudsmen** | Não há | **Sim**: pontos focais nacionais |
| **Joint Committee** | Não há | **Sim**: gerencia investimentos + previne litígios |
| **Foco** | Proteção pós-investimento | **Cooperação + facilitação** desde antes |
| **Indenização expropriação** | Compensação ampla (Hull formula) | Adequada, efetiva e em moeda conversível, mais restritiva |
| **MFN + tratamento nacional** | Amplo | **Restrito** a investimentos similares + setores específicos |
| Cláusulas guarda-chuva | Comuns | Geralmente excluídas |
| Standstill | Comuns | Restritos |
| **RBC + ESG** | Pouco | Cláusulas RBC (Responsible Business Conduct) |

## Estrutura típica do ACFI

| Capítulo | Conteúdo |
|---|---|
| Definições | Investimento + investidor + território + moeda |
| Tratamento | MFN, NT, FET (Fair and Equitable Treatment) |
| **Expropriação** | Direta + indireta, com indenização |
| Transferências | Liberdade de remessas |
| **Ombudsman** | Ponto focal nacional + apoio ao investidor |
| **Joint Committee** | Reuniões anuais + agenda + casos |
| **Solução de controvérsias** | Diálogo → mediação → State-State |
| **Não-aplicação ISDS** | Característica central |

## ICSID e Brasil

| | Conteúdo |
|---|---|
| Convenção 1965 | Brasil **não é parte** (não ratificou) |
| Razão | Vinculação a ISDS (investor-State) |
| **Acesso indireto** | Estruturação via **país parte**, conforme tratados aplicáveis |
| MIGA | Brasil é parte: proteção contra riscos políticos (não comerciais) |
| **Brasileiros no ICSID** | Empresas brasileiras podem litigar como investidores por meio de veículos constituídos em países parte |

## Erros a evitar

- Assumir que Brasil é parte do **ICSID** (não é: a Convenção de Washington não foi ratificada);
- Esperar **ISDS direto** sob ACFIs brasileiros (não há: State-State);
- Confundir **BIT** com **ACFI** (modelos distintos);
- Esquecer que **nenhum BIT** brasileiro foi ratificado (não vigora);
- Investir sem mapear **setores restritos** (mineração + telecom + imprensa);
- Esquecer **MIGA** como proteção contra riscos políticos;
- Achar que ACFI substitui completamente proteção: é instrumento de cooperação + prevenção;
- Esquecer **Joint Committee + ombudsman** como vias de solução amigável;
- Aplicar **MFN ampla** quando ACFI prevê restrições setoriais;
- Esquecer **registro BACEN** (RDE-IED): sem registro, remessas comprometidas;
- Confundir **proteção contratual** (FET) com **proteção constitucional** local;
- Aplicar diretamente **UNCITRAL** ou **ICC** para disputas Estado-investidor brasileiro (sem BIT/ACFI específico, não há foro internacional).

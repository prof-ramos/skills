# Cooperação Internacional

## Bases constitucionais: extradição

| | Conteúdo |
|---|---|
| **CF 5 LI** | Brasileiro **NÃO será extraditado**, salvo **naturalizado** em (i) crime comum antes da naturalização OU (ii) **tráfico ilícito de entorpecentes** (a qualquer tempo) |
| **CF 5 LII** | Vedada extradição por **crime POLÍTICO ou de OPINIÃO** |
| **CF 102 I "g"** | Competência originária do **STF** para extradição **passiva** |
| **CF 105 I "i"** | Competência do **STJ** para homologação de sentença estrangeira + exequatur de carta rogatória |

## Brasileiro nato: inextraditável em absoluto

**STF**: MS 33.864/DF + Ext 1.462 (caso Cláudia Hoerig): única hipótese real foi **perda de nacionalidade prévia** (CF 12 §4 II).

## Lei 13.445/2017 (Lei de Migração)

Substituiu o Estatuto do Estrangeiro (Lei 6.815/80, revogada).

| | Conteúdo |
|---|---|
| **Arts. 81-99** | Extradição passiva |
| **Arts. 100-104** | Extradição ativa |
| **Decreto 9.199/2017** | Regulamentação |

## Requisitos (Lei 13.445 art. 82)

| Inc. | Conteúdo |
|---|---|
| I | **Dupla incriminação** |
| II | Crime com pena de prisão cominada **não inferior a 2 anos** |
| III | **Não prescrição** em ambos os países |
| IV | NÃO ser crime político (§4: terrorismo + genocídio + crimes contra humanidade **NÃO** são políticos) |
| V | Jurisdição do Estado requerente |
| VI | **Compromisso de COMUTAÇÃO** de pena de morte/perpétua/corporal (art. 96 III + CF 5 XLVII) |

**STF Ext 1.201**: comutação de perpétua/morte em pena de **até 30 anos** (Lei 13.445 art. 96 III). Para crimes posteriores à Lei 13.964/2019, a 1ª Turma admitiu o limite de **40 anos** (Ext 1.652, CP art. 75), vedada a retroação do limite maior.

## Princípio da especialidade (art. 96 I)

Extraditado só pode ser julgado/preso pelos fatos da extradição. Extensão requer **pedido suplementar** (Ext 571-Extensão).

## Procedimento

| Etapa | Conteúdo |
|---|---|
| 1 | Pedido por via diplomática |
| 2 | **MJSP**: triagem |
| 3 | **STF** (relator + defesa + MPF + julgamento colegiado) |
| 4 | **PR decide entrega**, mesmo se STF deferiu (ato discricionário-vinculado) |
| Caso Battisti (Ext 1.085) | STF deferiu (2009); PR negou a entrega (2010) |
| Caso Hoerig (Ext 1.462) | STF deferiu (2017, após perda da nacionalidade no MS 33.864); extraditanda entregue aos EUA |
| Caso Pizzolato (2015) | Extradição **ativa**: Itália deferiu (Corte de Cassação) e entregou ao Brasil (1ª extradição de nacional italiano ao Brasil) |
| STF | **NÃO julga mérito penal**, apenas legalidade extrínseca/formal |

## Súmulas STF

| | Conteúdo |
|---|---|
| **Súm. 421** | "Não impede a extradição a circunstância de ser o extraditando casado com brasileira ou ter filho brasileiro." |
| **Súm. 692** | "Não se conhece de habeas corpus contra omissão de relator de extradição, se fundado em fato ou direito estrangeiro cuja prova não constava dos autos, nem foi ele provocado a respeito." |

## Refúgio e asilo (Lei 9.474/1997)

| | Conteúdo |
|---|---|
| Refúgio | Reconhecido pelo **CONARE** suspende/extingue extradição se motivada pelos mesmos fatos (arts. 33-34) |
| Asilo político | Afasta extradição (*non-refoulement*) |
| Caso paradigma | Ext 1.085 (Battisti) discutiu interferência política |

## CPC 26-41: Cooperação Internacional

### Auxílio Direto (CPC 28-29)
| | Conteúdo |
|---|---|
| Aplicação | Atos **NÃO decisórios** (citação + intimação + oitiva + prova) |
| **Dispensa exequatur** | |
| Autoridade Central | **MJSP/DRCI** |
| Base | Tratados (Las Leñas/Mercosul Dec. 2.067/96 + Haia + ONU) ou **reciprocidade** |

### Carta Rogatória (CPC 36)
| | Conteúdo |
|---|---|
| Aplicação | Atos **decisórios** OU citações/intimações via tradicional |
| **Exequatur** | **STJ** (CF 105 I "i" + RISTJ arts. 216-O+) |
| Controle | Ordem pública + soberania + dignidade |

## Homologação de Sentença Estrangeira (CPC 960-965 + CF 105 I "i")

**STJ** homologa.

| Requisito | Conteúdo |
|---|---|
| (i) | **Trânsito em julgado** |
| (ii) | Competência da autoridade prolatora |
| (iii) | Citação válida ou revelia regular |
| (iv) | Sem ofensa à **ordem pública + soberania + coisa julgada nacional** |
| (v) | **Tradução juramentada** + chancela consular OU **apostila** (Convenção Haia 1961, Dec. 8.660/2016) |

## Sequestro internacional de crianças (Convenção de Haia 1980: Dec. 3.413/2000)

| | Conteúdo |
|---|---|
| Autoridade Central | **MJSP/DRCI** (a **AGU** ajuíza a ação de restituição) |
| Ação | Busca/restituição na **JF** (CF 109 III) |
| Regra | **Retorno imediato** ao país de residência habitual |
| Exceções art. 13 | Interpretação restritiva, mas o **STF (ADIs 4.245 + 7.686, 2025)** firmou que o art. 13(1)(b) deve ser lido com perspectiva de gênero: indícios objetivos de violência doméstica (ainda que dirigida só à mãe) autorizam a recusa do retorno |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Estado estrangeiro requer brasileiro nato | **NEGADA** (CF 5 LI) |
| Naturalizado + crime pré-naturalização | **Admite** |
| Naturalizado + tráfico (a qualquer tempo) | **Admite** |
| Crime político | **NEGADA** (CF 5 LII) |
| Terrorismo + genocídio + crimes contra humanidade | NÃO são políticos: admite |
| Ato não decisório no exterior | **Auxílio direto** |
| Ato decisório no exterior | **Carta rogatória** + exequatur STJ |
| Sentença estrangeira | **Homologação STJ** |
| Sequestro de criança | Autoridade Central **MJSP/DRCI** + ação pela **AGU** na **JF** + Haia 1980 |

## Erros a evitar

- Pedir/admitir **extradição de brasileiro nato** (vedação absoluta CF 5 LI);
- **Confundir naturalizado** em tráfico (qualquer tempo) com crime comum (só antes da naturalização);
- Não exigir **compromisso de comutação** de perpétua/morte;
- Tratar **crime político como comum** (ou vice-versa: terrorismo NÃO é político);
- Esquecer princípio da **especialidade**;
- Usar **carta rogatória** para ato não decisório (cabe auxílio direto, mais célere);
- Pedir **exequatur ao STF** (é **STJ** desde EC 45/2004);
- Homologar sentença **sem trânsito em julgado** ou com citação ficta irregular;
- **Extraditar refugiado** reconhecido pelo CONARE pelos mesmos fatos;
- Achar que **STF julga o mérito** do crime na extradição passiva (só legalidade);
- Esquecer que o **PR tem palavra final** mesmo após STF deferir;
- Aplicar **Estatuto do Estrangeiro** (revogado pela Lei 13.445/2017).

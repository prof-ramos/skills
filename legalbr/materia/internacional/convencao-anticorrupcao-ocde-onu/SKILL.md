# Convenções Internacionais Anticorrupção

## Marco legal

- **OCDE 1997** (Paris), Convenção sobre o Combate ao Suborno de Funcionários Públicos Estrangeiros: **Dec. 3.678/2000**;
- **OEA 1996** (Caracas), Convenção Interamericana contra a Corrupção: **Dec. 4.410/2002**;
- **ONU 2003** (Mérida), UNCAC: **Dec. 5.687/2006**;
- **Lei 10.467/2002** (CP arts. 337-B/C/D, suborno transnacional);
- **Lei 12.846/2013** (Lei Anticorrupção empresarial);
- **Lei 9.613/1998** (Lavagem de Dinheiro, alterada pela Lei 12.683/2012);
- **Lei 12.850/2013** (organização criminosa; revogou a Lei 9.034/95);
- Dec. 11.129/2022 (regulamento da Lei 12.846; substituiu o Dec. 8.420/2015).

## Três convenções principais

| Convenção | Foco | Tipo |
|---|---|---|
| **OCDE 1997** | Suborno **transnacional** (PJ corrompendo agente público **estrangeiro**) | Específica |
| **OEA 1996** | Combate à corrupção **regional** (Américas) | Regional ampla |
| **ONU 2003 (UNCAC)** | Combate **global** + recuperação de ativos | Universal mais ampla |

## Convenção OCDE 1997: Dec. 3.678/2000

| | Conteúdo |
|---|---|
| **Foco** | Combate ao suborno **ativo** de funcionário público estrangeiro |
| **Sujeito** | **PJ** (responsabilidade da empresa) + PF |
| **Crime tipificado** | "Promessa, oferta ou pagamento de vantagem indevida" |
| **Brasil, CP** | Arts. 337-B (corrupção ativa em transação comercial internacional); 337-C (tráfico de influência); 337-D (definição de funcionário público estrangeiro) |
| **Pena** | 1-8 anos + multa |
| Monitoramento | **Working Group on Bribery** (peer review) |
| Aspectos avaliados | Legislação + enforcement + estatísticas |

## Convenção OEA 1996: Dec. 4.410/2002

| | Conteúdo |
|---|---|
| **Foco** | Corrupção em geral (nacional + transnacional) na região |
| **Reserva brasileira** | Art. XI §1 c (extradição) |
| Crimes alvo | Suborno ativo/passivo + enriquecimento ilícito + suborno transnacional |
| Cooperação | Assistência jurídica + extradição |
| Aplicação | OEA + MESICIC (Mecanismo de Acompanhamento) |

## UNCAC: ONU 2003 (Dec. 5.687/2006)

| Cap | Conteúdo |
|---|---|
| **II, Prevenção** | Órgãos preventivos + integridade no serviço público + setor privado + participação social |
| **III, Criminalização** | Suborno + apropriação indébita + tráfico de influência + abuso de função + enriquecimento ilícito + lavagem |
| **IV, Cooperação internacional** | Extradição + assistência mútua |
| **V, Recuperação de ativos** | Mecanismo inovador para devolução |
| **VI, Assistência técnica** | Capacitação + intercâmbio |

### Recuperação de ativos (UNCAC V)

| | Conteúdo |
|---|---|
| **Princípio fundamental** | Ativos devem ser **devolvidos** ao Estado de origem |
| Procedimentos | Cooperação internacional + auxílio direto + carta rogatória |
| **Mecanismos** | Confisco direto + retorno + restituição |
| **Brasil** | DRCI/MJ é Autoridade Central |
| **Casos** | Lava Jato: repatriação de bens em Suíça, EUA e outras jurisdições |

## Direito interno brasileiro decorrente

### CP arts. 337-B a 337-D (Lei 10.467/02)

| Art | Crime |
|---|---|
| **337-B** | Corrupção ativa em **transação comercial internacional**, pena 1-8 anos + multa |
| **337-C** | Tráfico de influência em transação comercial internacional |
| **337-D** | Definição de **funcionário público estrangeiro** |

### Lei 12.846/2013: anticorrupção empresarial

| | Conteúdo |
|---|---|
| **Responsabilidade objetiva** | Da PJ por atos contra a administração pública nacional **ou estrangeira** |
| **Extraterritorialidade** | PJ brasileira **fora do Brasil** + PJ estrangeira **no Brasil** (art. 28) |
| **Sanções administrativas** | Multa (0,1-20% do faturamento) + publicidade adversa |
| **Sanções judiciais** | Perdimento + dissolução compulsória + interdição de contratar com a Administração |
| **Acordo de leniência** | Lei 12.846 art. 16 + Dec. 11.129/22 + Lei 14.230/21 (improbidade) |
| **Programa de integridade** | Mitigação (Dec. 11.129/22) |

## Comparativo legislações extraterritoriais

| | **FCPA (EUA)** | **UK Bribery Act 2010** | **Lei 12.846 BR** | **Sapin II (FR)** |
|---|---|---|---|---|
| **Sujeito** | PJ + PF | PJ + PF | **PJ apenas** | PJ + PF |
| **Responsabilidade** | Strict liability (limited) | Strict + due diligence defense | **Objetiva** | Objetiva + compliance defense |
| **Suborno passivo** | Não cobre | Sim | Não cobre | Sim |
| **Pagamentos facilitadores** | Permitidos | Vedados | Vedados | Vedados |
| **Compliance defense** | Mitiga | **Defesa completa** ("adequate procedures") | **Mitiga** (Dec. 11.129/22) | Mitiga |
| Extraterritorialidade | Ampla (US issuers, foreign branches) | Ampla | **Ampla** (art. 28) | Ampla (PJ FR + atos em FR) |

## Lavagem de dinheiro (Lei 9.613 + 12.683)

| | Conteúdo |
|---|---|
| **Crime base** | Antes restrito; após Lei 12.683, **qualquer infração penal** |
| **Tipos** | Ocultar + dissimular + integrar |
| **Pena** | 3-10 anos + multa |
| **COAF** | Comunica operações suspeitas |
| **PEP** (Pessoa Politicamente Exposta) | KYC reforçado |
| GAFI/FATF | Recomendações internacionais |

## Programa de integridade (Dec. 11.129/22)

Elementos essenciais:
- Comprometimento da alta direção;
- Padrões de conduta + Código de Ética;
- Treinamentos + comunicação;
- Análise periódica de riscos;
- Registros contábeis confiáveis;
- Controles internos;
- **Due diligence** com terceiros + parceiros + cadeia;
- **Canal de denúncias** + investigação interna;
- **Sanções disciplinares**;
- Procedimentos para acordos de leniência.

## Erros a evitar

- Confundir Lei 12.846 (PJ, administrativa/civil) com **CP 337-B** (penal);
- Esquecer **extraterritorialidade** da Lei 12.846 (PJ brasileira no exterior + PJ estrangeira no Brasil, art. 28);
- Aplicar **pagamentos facilitadores** (permitidos pelo FCPA mas vedados pela Lei 12.846 + UK Bribery Act);
- Aceitar **compliance defense** total brasileira: o programa de integridade (Dec. 11.129/22) é **mitigante**, não excludente;
- Esquecer **acordo de leniência** (Lei 12.846 art. 16 + Lei 14.230/21);
- Não verificar **PEPs** + **due diligence** com terceiros;
- Aplicar UNCAC sem internalizar via CP + Lei 12.846 (sem self-executing);
- Confundir **OCDE** (suborno transnacional) com **OEA/UNCAC** (corrupção em geral);
- Ignorar **MLAT** + DRCI para cooperação em casos transfronteiriços;
- Esquecer **lavagem de dinheiro** como crime adicional (Lei 9.613);
- Esquecer **sanções OFAC + UE** que podem aplicar mesmo sem nexo direto;
- Não atualizar **programa de integridade** após reforma da LIA (Lei 14.230/21);
- Citar a Lei 9.034/95 como vigente (revogada pela Lei 12.850/2013).

# Lei de Migração + Refúgio

## Lei 13.445/2017: ESTATUTO DA MIGRAÇÃO

| | Conteúdo |
|---|---|
| **Revogou** | **Estatuto do Estrangeiro** (Lei 6.815/1980, editada sob o paradigma da segurança nacional) |
| Paradigma | **DIREITOS HUMANOS** |
| Regulamento | **Dec. 9.199/2017** |

## Princípios (art. 3)

| | Conteúdo |
|---|---|
| Universalidade + indivisibilidade + interdependência | **DH** |
| Repúdio | Xenofobia + racismo + discriminação |
| **Não criminalização** | Da migração |
| **Acolhida humanitária** | Princípio expresso |
| **Reunião familiar** | Princípio expresso |
| Igualdade + inclusão | Acesso a serviços públicos |

## Categorias migratórias

| | Conteúdo |
|---|---|
| **VISITANTE** | Até **90 dias** |
| **RESIDENTE** | Autorização de residência |
| **Especiais** | Asilado + refugiado + apátrida |

## VISTO de RESIDÊNCIA HUMANITÁRIA (art. 14 §3)

| | Conteúdo |
|---|---|
| Concedido a | **Apátridas** + nacionais de país em situação de **grave/iminente instabilidade institucional + conflito armado + calamidade + grave violação de DH** |
| Aplicação prática | **Haitianos + venezuelanos** (Operação Acolhida) + **afegãos + ucranianos** |

## NON-REFOULEMENT (art. 7)

| | Conteúdo |
|---|---|
| Veda | **Devolução** para país onde haja **risco à vida/integridade** |

## EXTRADIÇÃO

| | Conteúdo |
|---|---|
| Vedada | Crime **POLÍTICO ou de OPINIÃO** (CF 5 LII) |
| **Brasileiro NATO** | **JAMAIS extraditado** (CF 5 LI) |
| Brasileiro naturalizado | Pode em crimes anteriores à naturalização ou tráfico de drogas |

## ASILO × REFÚGIO

| | Asilo POLÍTICO | Refúgio |
|---|---|---|
| Natureza | **Ato DISCRICIONÁRIO** | **Ato VINCULADO** |
| Perseguição | **Individualizada por OPINIÃO POLÍTICA** | Diversos motivos |
| Tradição | Latino-americana | **Convenção de 1951** |

## Lei 9.474/1997: ESTATUTO DO REFUGIADO

| | Conteúdo |
|---|---|
| Internaliza | **Convenção de 1951 + Protocolo de 1967** |
| Conceito ampliado | **DECLARAÇÃO DE CARTAGENA 1984** |

### Definição de refugiado
| | Conteúdo |
|---|---|
| **(a)** | **FUNDADO TEMOR de perseguição** por **RAÇA + RELIGIÃO + NACIONALIDADE + GRUPO SOCIAL + OPINIÃO POLÍTICA** |
| **(b)** | Saiu por **GRAVE E GENERALIZADA VIOLAÇÃO de DH** em seu país (Cartagena 1984, definição ampliada) |

## CONARE: Comitê Nacional para Refugiados

| | Conteúdo |
|---|---|
| Composição | Ministérios (Justiça, Relações Exteriores, Trabalho, Saúde, Educação) + **Polícia Federal** + sociedade civil + **ACNUR** (voz, sem voto) |
| Função | Delibera sobre solicitações |
| **Reconhecimento** | **DECLARATÓRIO** (não constitutivo) |

## Proteção do solicitante

| | Conteúdo |
|---|---|
| Desde o protocolo | **Não pode ser deportado/extraditado** enquanto pendente |
| Trabalho | Permitido |
| Educação | Acesso |

## Naturalização

| Modalidade | Conteúdo |
|---|---|
| **Ordinária** | Após **4 anos** de residência (Lei 13.445 art. 65) |
| **Redução do prazo (art. 66)** | **1 ano** nas hipóteses legais: filho brasileiro, cônjuge brasileiro, serviço relevante ao país, capacidade profissional/científica/artística |

## Procedimento de solicitação de refúgio

| Fase | Conteúdo |
|---|---|
| 1 | Solicitação à Polícia Federal |
| 2 | Protocolo + documento provisório |
| 3 | Entrevista + instrução perante o CONARE |
| 4 | Decisão |
| 5 | Recurso ao MJ |

## Distinções essenciais

| | Estatuto do Estrangeiro (Lei 6.815, revogada) | Lei 13.445/2017 |
|---|---|---|
| Paradigma | **Segurança nacional** | **DH** |
| Criminalização | Possível | **VEDADA** |
| Reunião familiar | Restrita | **Princípio** |

| | Convenção 1951 | Cartagena 1984 |
|---|---|---|
| Definição | Perseguição individual | **Grave e generalizada VIOLAÇÃO DE DH** |
| Aplicação | Universal | **Ampliada** |

## Síntese operacional

| Hipótese | Saída |
|---|---|
| Pessoa em situação humanitária | **Visto humanitário** (Lei 13.445 art. 14 §3) |
| Perseguição individual | **Refúgio** (Lei 9.474 + Convenção 1951) |
| Grave violação DH | **Refúgio** (Cartagena 1984) |
| Devolução com risco | **VEDADA** (non-refoulement) |
| Brasileiro nato + crime | **JAMAIS** extradita (CF 5 LI) |
| Naturalizado + crime anterior | **Pode extraditar** |
| Crime político/opinião | **Vedada extradição** (CF 5 LII) |
| Sem documentos | NÃO impede solicitação |
| CONARE pendente | **Proteção provisória** |
| Asilo + opinião política | Discricionário |
| Pena de morte/perpétua no exterior | **Vedada extradição** sem comutação |

## Erros a evitar

- **Aplicar Estatuto do Estrangeiro REVOGADO** (vigora a Lei 13.445);
- **Devolver pessoa em risco** (viola non-refoulement);
- **Extraditar brasileiro NATO** (CF 5 LI: JAMAIS);
- **Negar PROTEÇÃO provisória** ao solicitante de refúgio;
- **Confundir ASILO com REFÚGIO** (discricionário × vinculado);
- Aplicar **Convenção 1951 sem Cartagena 1984** (definição ampliada);
- Aplicar **caráter constitutivo** ao reconhecimento (é declaratório);
- Ignorar as **hipóteses de redução do prazo de naturalização** (Lei 13.445 art. 66: 1 ano);
- Permitir **criminalização da migração** (Lei 13.445 veda);
- Permitir **extradição em crime POLÍTICO** (CF 5 LII);
- Negar **reunião familiar** como princípio (Lei 13.445).

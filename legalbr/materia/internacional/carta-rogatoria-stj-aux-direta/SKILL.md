# Carta Rogatória + Auxílio Direto

## Marco legal

- **CPC 26-41** (Capítulo II do Livro I, Cooperação Internacional);
- **CF 105 I i** (competência STJ, exequatur);
- **RISTJ 216 e ss.** (procedimento + delibação; arts. 216-A a 216-X sucederam a Res. STJ 9/2005);
- Manual de Cooperação Jurídica Internacional (DRCI/MJSP);
- Tratados: **Mercosul Las Leñas** (Dec. 2.067/96), Haia (1965 + 1970), bilaterais;
- LINDB art. 17 (limites: ordem pública + soberania + bons costumes).

## Espécies de cooperação (CPC 27)

| Espécie | Conteúdo |
|---|---|
| **I**: Citação, intimação, notificação | Comunicação processual |
| **II**: Colheita de provas + informações | Oitiva, perícia, exibição |
| **III**: Homologação | Decisões estrangeiras (CPC 960-965) |
| **IV**: Concessão de medida judicial de urgência | Cautelar internacional |
| **V**: Assistência jurídica internacional | Defensoria + advocacia |
| **VI**: Outras | Hipóteses não vedadas |

## Carta rogatória × Auxílio direto

| | **Carta Rogatória** | **Auxílio Direto** |
|---|---|---|
| **Origem** | Autoridade **jurisdicional** estrangeira | Autoridade **administrativa** ou jurisdicional |
| **Natureza** | Cumprimento de ato **jurisdicional** | Pedido de **ajuda** ao Brasil, sem caráter jurisdicional |
| **Exequatur STJ** | **Obrigatório** | **NÃO** passa pelo STJ |
| **Delibação** | Sim | Não: Justiça Federal decide diretamente |
| Base | CPC 36 + RISTJ 216 | CPC 28-34 |
| Autoridade Central | DRCI/MJ | DRCI/MJ |

## Carta rogatória (CPC 36 + RISTJ)

### Fluxo (Brasil rogado)

1. Autoridade estrangeira → Autoridade Central (DRCI);
2. DRCI encaminha ao **STJ** (Presidência);
3. **Delibação** pelo Presidente do STJ:
   - Requisitos formais;
   - **Não ofensa à soberania, ordem pública** (LINDB 17);
   - **Contraditório**;
4. **Exequatur** (concedido) → Justiça Federal cumpre (CF 109 X);
5. Justiça Federal cumpre o ato (citação, oitiva, etc.);
6. Devolução da carta com cumprimento à autoridade rogante via DRCI.

### Defesa (CPC 36 §2)

| | Conteúdo |
|---|---|
| Restrita | Atendimento dos requisitos para produção de efeitos |
| **Não cabe** | Discussão de mérito |
| Prazo | 15 dias (RISTJ) |
| Recurso | Agravo regimental ao STJ |

### Requisitos (CPC 26 + RISTJ 216-O)

| | Conteúdo |
|---|---|
| **Autenticidade** | Tradução + apostila/legalização |
| Especificidade | Pedido claro + objeto + finalidade |
| **Contraditório** | Garantido no procedimento brasileiro |
| **Ordem pública** | Respeito a princípios fundamentais |
| Reciprocidade | Salvo em tratados |
| Sentença estrangeira | Via homologação, **não rogatória** |

## Auxílio direto (CPC 28-34)

### Cabimento (CPC 28)

> "Cabe auxílio direto quando a medida não decorrer diretamente de decisão de autoridade jurisdicional estrangeira a ser submetida a juízo de delibação no Brasil."

| | Conteúdo |
|---|---|
| Aplicação | Atos sem conteúdo jurisdicional |
| Exemplos | Inquérito + obtenção de documentos + comunicações + perícias administrativas |
| **Procedimento** | DRCI ou MP recebe → encaminha a **Justiça Federal** (CPC 33) |

### Fluxo do auxílio direto

1. Pedido externo → Autoridade Central (DRCI/MJ);
2. DRCI ↔ AGU/MPF (provoca);
3. Justiça Federal aprecia diretamente (CPC 33);
4. Cumprimento + devolução das informações.

### Auxílio penal

| | Conteúdo |
|---|---|
| Base | MLAT (Mutual Legal Assistance Treaty) + bilaterais |
| **Autoridade Central penal** | DRCI/MJ + Secretaria Nacional de Justiça |
| Exemplos | Quebra de sigilo bancário, sequestro de bens, oitiva |
| **Não** se confunde com extradição | Procedimento próprio (CPP + Lei 13.445) |

## Autoridade Central (CPC 26 §4)

| | Conteúdo |
|---|---|
| **Padrão** | Ministério da Justiça e Segurança Pública, **DRCI/SNJ** |
| Tratados específicos | Podem nomear autoridade central diversa |
| MPF | Conduz cooperação penal e em matéria de improbidade |
| AGU | Sucessórias + civil em alguns casos |

## Princípios da cooperação (CPC 26)

| | Conteúdo |
|---|---|
| **Devido processo legal** | Respeito a garantias no Estado requerente |
| **Reciprocidade** | Salvo nos tratados |
| **Igualdade de tratamento** | Entre nacionais e estrangeiros |
| **Espontaneidade** | Na transmissão de informações |
| **Publicidade** | Dos atos processuais |

## Limites (CPC 39 + LINDB 17)

| | Conteúdo |
|---|---|
| **Manifesta ofensa à ordem pública** | Veda cooperação |
| **Soberania** | Não autoriza atos atentatórios |
| **Crimes políticos** | Exceções históricas |
| **Discriminação** | Caso a caso (gênero, raça, religião) |

## Tratados aplicáveis

| Tratado | Conteúdo |
|---|---|
| **Mercosul, Protocolo de Las Leñas** (Dec. 2.067/96) | Cooperação jurisdicional + reconhecimento de decisões |
| **Haia 1965** | Notificação de atos no exterior |
| **Haia 1970** | Obtenção de provas no exterior (Dec. 9.039/2017) |
| **Haia 1980** | Sequestro internacional de crianças |
| Convenção Interamericana sobre Cartas Rogatórias (1975) | Aplicação OEA |
| **Tratados bilaterais** | Brasil-França, Brasil-Espanha, Brasil-Itália, Brasil-EUA (penal), etc. |

## Sentença estrangeira (vs. carta rogatória)

| | Sentença Estrangeira (Homologação) | Carta Rogatória |
|---|---|---|
| O que se busca | Eficácia da decisão no Brasil | Cumprimento de ato processual |
| Procedimento | RISTJ 216-A + CPC 960-965 | RISTJ 216 + CPC 36 |
| Trânsito em julgado | Necessário | Não exigido |
| Tutela urgência | Possível mediante medida cautelar | Exequatur de urgência possível |
| Execução | Após homologação → JF | Diretamente JF após exequatur |

## Sequestro de crianças (Haia 1980)

| | Conteúdo |
|---|---|
| Tratamento | Auxílio direto via AGU |
| Competência | Justiça Federal (CF 109 III) |
| Princípio | Retorno do menor ao país de residência habitual |
| Limites | Risco grave à criança (art. 13 da Convenção) |

## Cooperação em arbitragem internacional

| | Conteúdo |
|---|---|
| Sentenças arbitrais estrangeiras | Homologação STJ (Lei 9.307/96 + Conv. NY 1958) |
| **Apoio jurisdicional** (medidas urgentes) | Carta rogatória ou auxílio direto |
| Lei 9.307 art. 22-A | Tutela judicial em apoio à arbitragem |

## Erros a evitar

- Pedir **homologação de sentença** via carta rogatória (não: é via própria, RISTJ 216-A);
- Achar que carta rogatória passa pela **Justiça Federal direto** (passa **antes** pelo STJ, exequatur);
- Esquecer **autoridade central** (DRCI) no fluxo;
- Discutir **mérito** na rogatória (defesa restrita, CPC 36 §2);
- Aplicar carta rogatória a pedido **não jurisdicional** (cabe auxílio direto, CPC 28);
- Esquecer **tradução + apostila/legalização** (CPC 26 + Dec. 8.660/16);
- Negar cooperação por **ordem pública** sem motivação concreta (LINDB 17);
- Confundir cooperação **penal** com extradição (procedimentos distintos);
- Ignorar **tratados bilaterais** que podem dispensar requisitos;
- Não invocar **Las Leñas** em cooperação com Mercosul (procedimento simplificado);
- Esquecer **CPC 33** (auxílio direto vai à JF): não passa pelo STJ;
- Aplicar **decadência/prescrição** brasileira aos prazos estrangeiros: atenção à lei aplicável.

# Acordos para Evitar a Bitributação

## Marco legal

- **Tratados bilaterais** (DTAAs): Brasil tem ~37 em vigor;
- **Lei 9.430/1996** (crédito + alíquotas);
- **CTN 98** (tratados prevalecem sobre lei interna);
- **Lei 14.596/2023** (preços de transferência, alinhada à OCDE);
- **IN RFB 208/2002** (residência fiscal);
- **IN RFB 1.037/2010** (paraísos fiscais + regimes privilegiados; lista atualizada pela IN RFB 2.265/2025);
- **OCDE Convention** (Modelo + Comentários);
- **UN Model Convention** (versão para países em desenvolvimento);
- **MLI** (BEPS Multilateral Instrument): Brasil **não ratificou**.

## Posição brasileira

| | Conteúdo |
|---|---|
| **Tratados em vigor** | ~37 (lista atualizada Receita Federal) |
| **EUA** | **Sem tratado**: bitributação fática (créditos via legislação interna) |
| **OCDE** | Brasil **em adesão** (processo em curso; não é membro pleno) |
| Modelo | **Híbrido OCDE + ONU**, preserva tributação na fonte |
| **MLI/BEPS** | Brasil **não ratificou** o instrumento multilateral |

## Países com tratado (lista resumida)

| Continente | Países |
|---|---|
| **Américas** | Argentina, Canadá, Chile, Colômbia, Equador, México, Peru, Trinidad e Tobago, Uruguai, Venezuela |
| **Europa** | Áustria, Bélgica, Dinamarca, Espanha, Finlândia, França, Holanda, Hungria, Itália, Luxemburgo, Noruega, Portugal, Rússia, Suécia, Suíça, Turquia, Ucrânia (**Reino Unido**: assinado 29/11/2022, **não em vigor**, sem ratificação brasileira) |
| **Ásia/Oceania** | China, Cingapura, Coreia do Sul, Emirados Árabes Unidos, Filipinas, Índia, Israel, Japão |

> Lista pode mudar: verificar **Receita Federal** atualizada.

## Métodos para eliminar bitributação

| Método | Conteúdo |
|---|---|
| **Crédito** (creditamento) | **Brasil adota** (Lei 9.430 art. 26): tributos pagos no exterior compensam IRPJ/CSLL no Brasil até limite da tributação brasileira |
| **Isenção** | Mais raro nos tratados brasileiros; alguns rendimentos isentos |
| **Match credit** | Tratado pode prever crédito superior ao efetivamente pago (incentivo) |
| **Tax sparing** | Crédito presumido, preserva incentivos do país-fonte |

## Conceitos centrais

### Residência fiscal (art. 4 OCDE)

| Critério | Conteúdo |
|---|---|
| **PF** | (i) Local de habitação permanente; (ii) Centro de interesses vitais; (iii) Permanência habitual; (iv) Nacionalidade; (v) Procedimento amigável |
| **PJ** | Local da **direção efetiva** (POEM, Place of Effective Management) |
| Brasileiro no exterior | IN RFB 208/2002: saída definitiva → mudança de residência |
| **Tax tie-breaker** | Resolve dupla residência |

### Estabelecimento permanente (PE: art. 5)

| | Conteúdo |
|---|---|
| **Físico** | Instalação fixa (escritório, fábrica, loja, mina) |
| **Construção** | Canteiro > 6/12 meses (varia) |
| **Agente dependente** | Atua habitualmente com poderes |
| **Não é PE** | Depósito + exposição + atividade preparatória/auxiliar |
| **PE digital** | OCDE Pillar One, em discussão |
| **Brasil + UN Model** | Conceito mais amplo de PE (inclui serviços + agente) |

## Distribuição da competência tributária

| Renda | Quem tributa |
|---|---|
| **Juros** | País-fonte (com limites de 10-15%) + país-residência (crédito) |
| **Dividendos** | Variável (5-15% no fonte + residência); Brasil isenta dividendos por lei interna |
| **Royalties** | País-fonte (10-15%) + país-residência |
| **Serviços técnicos** | Posição da RFB (ADI RFB 5/2014): enquadramento conforme o tratado/protocolo (royalties, serviços independentes ou lucros) |
| **Imóveis** | País da situação |
| **Trabalho dependente** | País onde se exerce (com exceções) |
| **Trabalho independente** | País de residência ou da base fixa |

## Serviços técnicos: controvérsia STJ

| | Conteúdo |
|---|---|
| **STJ REsp 1.161.467** | Caso Copesul (2012): serviços técnicos sem transferência de tecnologia e sem PE enquadram-se no art. 7 (lucros das empresas) dos tratados Brasil-Alemanha e Brasil-Canadá; sem IRRF na fonte (CTN 98) |
| **STJ REsp 1.272.897** | Reafirmou o enquadramento no art. 7 (tratado Brasil-Espanha, 2015): sem IRRF em serviços sem transferência de tecnologia |
| **Posição da RFB** | ADI RFB 5/2014 (substituiu o ADN Cosit 1/2000): royalties quando o protocolo equiparar serviços técnicos a royalties; serviços profissionais independentes quando couber; lucros nos demais casos |
| **Divergência recente** | Decisões posteriores do STJ aplicaram o art. 12 (royalties) quando o protocolo equipara; matéria ainda não pacificada, verificar o tratado concreto |

## Preços de transferência (Lei 14.596/2023)

| | Conteúdo |
|---|---|
| **Reforma** | Alinhamento ao **arm's length OECD** |
| Métodos | CUP, RPM, CPM, TNMM, profit split (substituiu PIC, PRL, CPL antigos) |
| Vigência | Janeiro 2024 (obrigatória) ou 2023 (opcional) |
| **Documentação** | Local file + Master file + CbC report |
| **APA** | Permitido (advance pricing agreements) |
| **MLI** | Não ratificado pelo Brasil; sem aplicação direta |

## Procedimento amigável (MAP): art. 25 OCDE

| | Conteúdo |
|---|---|
| Função | Resolver controvérsias entre administrações fiscais |
| Autoridade competente | **RFB** no Brasil |
| **IN RFB 1.846/2018 + IN 1.669/2016** | Procedimento |
| Prazo | Tratado-dependente (geralmente 3 anos) |
| **Decisão** | Vinculante para fisco brasileiro se acordada |

## Arbitragem em DTAAs

| | Conteúdo |
|---|---|
| **Cláusula opcional OECD/MLI** | Arbitragem se MAP falhar em 2 anos |
| **Brasil** | Não aceita arbitragem em DTAAs (em regra) |

## BEPS + MLI

| Ação BEPS | Conteúdo |
|---|---|
| **Action 1** | Economia digital (Pillar One + Two) |
| **Action 5** | Práticas tributárias prejudiciais |
| **Action 6** | Abuso de tratados (PPT, Principal Purpose Test) |
| **Action 7** | PE artificial |
| **Action 14** | MAP eficaz |
| **Pillar Two: global minimum tax 15%** | **Lei 15.079/2024** (Brasil internalizou via adicional de CSLL) |

## Pillar Two: IIR/UTPR/QDMTT no Brasil

| | Conteúdo |
|---|---|
| **Lei 15.079/2024** | Implementa Pillar Two (Adicional da CSLL) |
| **Alíquota mínima global** | 15% para multinacionais com receita > €750M |
| **Adicional de CSLL** | Aplicado para garantir 15% efetivo |
| **Vigência** | 2025 (regulamentação RFB) |

## Paraísos fiscais: IN RFB 1.037/2010

| | Conteúdo |
|---|---|
| **Lista** | ~65 países/dependências |
| **Critério** | Tributação < 17% sobre renda + opacidade |
| Consequências | Preços de transferência aplicáveis + alíquotas mais altas |
| **Regime fiscal privilegiado** | Categoria adicional |
| Limitações | DTAA com paraíso prevalece sobre IN |

## CFC rules: Lei 12.973/2014

| | Conteúdo |
|---|---|
| **Controladas no exterior** | Tributação dos lucros no Brasil, mesmo sem distribuição |
| Princípio | "Lucros disponibilizados" |
| **Aplicação** | Controladas + coligadas em paraísos |
| **STF + STJ** | Discussões sobre compatibilidade com DTAAs |

## Transferência de residência

| | Conteúdo |
|---|---|
| **Saída definitiva** | Comunicação à RFB + Declaração de Saída Definitiva |
| **Após** | Não residente: tributação na fonte apenas |
| **Paraíso fiscal** | Não basta sair; RFB exige reconhecimento de residência em outro país |
| **PF estrangeira** | Tributada por rendimentos de fonte brasileira |

## Erros a evitar

- Assumir tratado entre **Brasil e EUA** (não existe; apenas troca de informações);
- Confundir **residência fiscal** com **nacionalidade** (residência é critério tributário);
- Aplicar regra interna brasileira sobre o **tratado** (CTN 98: tratado prevalece);
- Esquecer a jurisprudência do **STJ sobre serviços técnicos**: sem PE pode não ser tributável (caso a caso);
- Ignorar **Atos Declaratórios RFB**, que limitam aplicação de tratados a serviços técnicos;
- Subutilizar **MAP** quando há dupla tributação efetiva;
- Esquecer **Pillar Two** (Lei 15.079): global minimum tax 15%;
- Aplicar regras antigas de **preços de transferência** após 2024 (Lei 14.596);
- Esquecer **paraísos fiscais (IN 1.037)**: consequências severas;
- Não documentar **Master file + Local file + CbC** (Lei 14.596);
- Ignorar **POEM** (lugar de direção efetiva), chave para residência PJ;
- Aplicar **tributação sobre dividendos** ignorando tratado (Brasil isenta por lei interna desde 1996);
- Esquecer que **dividendos brasileiros** podem voltar a ser tributados por alteração legislativa (verificar regime vigente).

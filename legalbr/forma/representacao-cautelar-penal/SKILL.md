# Representação por Medida Cautelar Penal

## Base normativa comum

| | Conteúdo |
|---|---|
| **CPP 282** | Pressupostos comuns: necessidade + adequação + **proporcionalidade** + fumus + periculum |
| Legitimação | **MP** + **autoridade policial** (CPP 282 §2): em fase investigativa pode ser pelo delegado |
| Cláusula constitucional | **Reserva de jurisdição**: só **JUIZ** decreta (CF 5 XI, XII, LXI) |
| Lei 13.964/19 (Anticrime) | Sistema acusatório + juiz de garantias (CPP 3-B); cautelar de ofício **VEDADA** |
| Princípio | **Lex stricta** + interpretação restritiva |

## Tipos de medidas cautelares

### A: PRISÃO PREVENTIVA (CPP 311-316)

| Requisito | Conteúdo |
|---|---|
| **CPP 311** | Decretação por juiz **A REQUERIMENTO** do MP/querelante/assistente OU representação policial |
| **CPP 312** | **PROVA da existência do crime + INDÍCIOS SUFICIENTES de autoria** + **PERICULUM** |
| **Periculum libertatis** | Garantia da **ordem pública/econômica** + conveniência **instrução criminal** + **aplicação da lei penal** |
| **CPP 313** | Cabimento: crime DOLOSO com pena máxima **> 4 anos** OU reincidência em crime doloso (CPP 313 II) OU **VD** |
| **Anticrime** | **Não cabe** decretação **de ofício** (CPP 282 §2) |
| **CPP 312 §2** | Fundamentação **contemporânea** + **mínima legalidade** |
| **CPP 316** | **REVISÃO 90 DIAS** (p.ú.); STF (ADIs 6.581/6.582): o descumprimento do prazo **não** gera soltura automática |

### B: BUSCA E APREENSÃO (CPP 240-250)

| Requisito | Conteúdo |
|---|---|
| **CPP 240** | Fundamento: **prender criminoso** + **apreender objetos do crime** + **descobrir provas** |
| **CPP 241** | Domiciliar EXIGE **ordem judicial** (CF 5 XI) |
| Cláusula | **Reserva de jurisdição** + execução **DIURNA** (regra) |
| Pessoal | CPP 244: flagrante OU fundada suspeita |
| **CPP 244 + STJ (RHC 158.580/BA)** | Busca pessoal exige **fundada suspeita CONCRETA**, não bastam atitude/aparência suspeitas |
| **Tema 280 STF** | Sem mandado em casa só em **flagrante** + **fundadas razões** |

### C: INTERCEPTAÇÃO TELEFÔNICA (Lei 9.296/96)

| Requisito | Conteúdo |
|---|---|
| **Lei 9.296 art. 1-2** | Crimes **PUNIDOS COM RECLUSÃO** + outras provas insuficientes |
| **Prazo** | **15 dias prorrogáveis sucessivamente** (mas STF/STJ exigem **fundamentação fundada** para prorrogação) |
| **STF Tema 661** | Prorrogações sucessivas: **fundamentação concreta** + sucessiva renovação dos motivos |
| Imprescindibilidade | Demonstrar que **OUTRA prova não basta** |
| Decisão | **Sigilosa** + fundamentada (Lei 9.296 art. 4 §2: 24h para decidir; art. 5: fundamentação) |
| Vedação | Crime punido com **detenção** (regra) |

### D: QUEBRA DE SIGILO BANCÁRIO/FISCAL

| Requisito | Conteúdo |
|---|---|
| **LC 105/2001** | Quebra de sigilo bancário só por **ORDEM JUDICIAL** (regra) |
| **Tema 225 STF** (RE 601.314) | Receita Federal **PODE** acessar dados bancários sem ordem judicial **para fins TRIBUTÁRIOS** (mas não criminais) |
| Sigilo fiscal | Idêntico: só com ordem |
| **Tema 990 STF** | Compartilhamento de relatórios da UIF e do procedimento fiscalizatório da RFB com a persecução penal **dispensa** autorização judicial prévia (comunicações formais + sigilo) |
| MP | Requer a quebra **ao juízo** (reserva de jurisdição); acesso direto é vedado |
| **Necessidade** | Provar **imprescindibilidade** + crime grave |
| Decisão | Sigilosa + fundamentada |

## Estrutura da representação

### Cabeçalho
```
EXMO. SR. DR. JUIZ DA [VARA CRIMINAL/CENTRAL DE INQUÉRITOS] DA COMARCA DE [...]

[Promotor de Justiça / Procurador da República / Delegado de Polícia]
[atribuição funcional + CPP/Lei 9.296/etc.]
```

### Núcleo
```
vem, com fundamento no [art. 311 CPP] [/art. 240 CPP] [/Lei 9.296/96]
[/LC 105/2001], REPRESENTAR pela [decretação da prisão preventiva /
expedição de mandado de busca e apreensão / interceptação telefônica /
quebra de sigilo] em face de [investigado], pelas razões fáticas e
jurídicas que passa a expor:

I: DOS FATOS (com narrativa CRONOLÓGICA + provas)
II: DOS REQUISITOS LEGAIS (CPP 282 + específicos)
III: DO FUMUS COMMISSI DELICTI (materialidade + indícios autoria)
IV: DO PERICULUM IN MORA (ordem pública/instrução/lei penal)
V: DA PROPORCIONALIDADE + INSUFICIÊNCIA DE CAUTELARES MENORES (CPP 319)
VI: DO PEDIDO (sigilo + execução + prazo)
```

## Fundamentos por medida: checklist

### Prisão preventiva

| | Demonstrar |
|---|---|
| **A** | **Prova da MATERIALIDADE** (laudo + boletins + apreensões) |
| **B** | **INDÍCIOS SUFICIENTES de autoria** (testemunho + imagens + interceptação) |
| **C** | **Periculum** concreto: **fundamentado** (reiteração delitiva + risco à instrução + fuga concreta) |
| **D** | **Insuficiência** de cautelares menos gravosas (CPP 319) |
| **E** | **Contemporaneidade** dos fatos (CPP 312 §2: fatos antigos comprometem o cabimento) |
| **F** | **Cláusula CPP 313**: pena máx > 4 OU reincidência em crime doloso OU VD |
| **G** | **Vedação na violência doméstica**: CPP 313 III sem necessidade de pena específica |

### Busca e apreensão

| | Demonstrar |
|---|---|
| **A** | **CRIME** já configurado OU em via de elucidação |
| **B** | **NEXO** entre o local + bem buscado + investigação |
| **C** | **NECESSIDADE** + impossibilidade de obtenção por outro meio |
| **D** | Indicação **PRECISA do local** + horário (regra diurna) |
| **E** | **PROPORCIONALIDADE**: não pode ser **diligência genérica** ("fishing expedition") |

### Interceptação telefônica

| | Demonstrar |
|---|---|
| **A** | **Crime apenado com RECLUSÃO** |
| **B** | **Indícios** razoáveis de autoria |
| **C** | **IMPRESCINDIBILIDADE**: outras provas inviáveis |
| **D** | Linhas específicas + alvo + período (15 dias renovável fundamentadamente) |
| **E** | Cooperação com **operadora**: comando + sigilo |

### Quebra de sigilo

| | Demonstrar |
|---|---|
| **A** | Crime **GRAVE** + investigação em curso |
| **B** | Necessidade + adequação |
| **C** | Período + instituição + dados específicos |
| **D** | Limites temporais + objetivos do exame |

## Cláusulas obrigatórias

| | Conteúdo |
|---|---|
| Pedido subsidiário | **Caso indeferida** preventiva, requerer **cautelares CPP 319** |
| Sigilo | Solicitar **distribuição sigilosa** + segredo de justiça |
| Mandado | Pedir **expedição + prazo + autoridade executora** |
| **Anpp prévia** | Em crime sem violência + pena mín < 4: analisar **antes** ANPP (CPP 28-A) |
| Cooperação | Solicitar autoridade policial para diligências |

## Anticrime: efeitos práticos

| | Conteúdo |
|---|---|
| **Sistema acusatório** | MP/representação **necessária**: juiz não decreta de ofício |
| **Juiz de garantias** (CPP 3-B) | Em comarcas implementadas: análise pela fase investigativa |
| **Revisão 90 dias** (CPP 316 §u) | Cabe ao requerente provocar nova representação |
| **Audiência de custódia** | Pós-flagrante: pode converter em preventiva |
| Cabe medida atípica? | CPP 282 V: possível mas com cautela |

## Distinções essenciais

| | Preventiva | Temporária |
|---|---|---|
| Base | CPP 311 + 312 | Lei 7.960/89 |
| Crime | Doloso pena > 4 OU reincidente em doloso/VD | Rol taxativo (Lei 7.960 art. 1 III) |
| Prazo | Indeterminado (revisão 90d) | **5 dias** prorrogáveis 5d (hediondos: 30+30) |
| Representação | MP/Delegado | Delegado/MP |

| | Preventiva | Cautelar CPP 319 |
|---|---|---|
| Restrição | Liberdade | Outras medidas (monitoramento, fiança, comparecimento) |
| Subsidiariedade | Última ratio | Primeira opção |

| | Busca/apreensão | Mandado de prisão |
|---|---|---|
| Objetivo | Provas/bens | Pessoa |
| Base | CPP 240 | CPP 282-289 |

| | Interceptação | Quebra sigilo |
|---|---|---|
| Lei | 9.296/96 | LC 105/01 + CPP |
| Conteúdo | **Comunicações em tempo real** | **Dados pretéritos** (registros) |
| Prazo | 15d + renovação | Período histórico |

## Princípios + jurisprudência (síntese)

| | Conteúdo |
|---|---|
| **STF: fundamentação concreta** | Repugna fundamentação genérica em preventiva |
| **CPP 315 §2** | Gravidade abstrata do crime e fórmulas genéricas NÃO fundamentam |
| **STF: contemporaneidade** | Fatos antigos com nova preventiva exigem **motivação contemporânea** (CPP 312 §2) |
| **CPP 244 / STJ RHC 158.580** | Busca pessoal exige fundada suspeita CONCRETA |
| **Tema 280 STF (RE 603.616)** | Domicílio só sem mandado em flagrante real + fundadas razões |
| **STJ Tema 1.155** | Recolhimento domiciliar noturno e dias de folga: período **detraído** da pena (horas convertidas em dias; monitoramento eletrônico não é condição) |
| **STF: sigilo** | Quebra deve ser fundamentada + ônus argumentativo do requerente |

## Síntese operacional

| Hipótese | Regime |
|---|---|
| Preventiva sem materialidade | Fumus ausente: cabimento não configurado |
| Periculum sem fundamentação concreta | Cabimento não configurado |
| Crime doloso com pena máx ≤ 4 + sem reincidência dolosa/VD | **Cabimento vedado** (CPP 313) |
| VD contra mulher + ameaça séria | **Cabe preventiva** (CPP 313 III): sem exigir pena específica |
| Busca em domicílio sem mandado | **Apenas em flagrante real + fundadas razões** (Tema 280 STF) |
| Interceptação para crime de detenção | **VEDADA** (Lei 9.296 art. 2 III) |
| Quebra sigilo bancário sem ordem judicial | Apenas tributária + LC 105 |
| Pedido + cautelares menos gravosas | Recomendado: proporcionalidade |
| Sem ANPP examinado | **Vício**: fundamentar inviabilidade |
| Pena mín < 4 + sem violência | **ANPP antes** (CPP 28-A) |

# Nota Técnica Jurídica

## Marco normativo

| | Conteúdo |
|---|---|
| **Lei 9.784/1999** | Processo administrativo federal: art. 42 (parecer obrigatório, vinculante ou não) |
| **Lei 13.655/2018** | Incluiu na LINDB arts. 20-30 |
| **LINDB art. 22** | Considerar dificuldades + obstáculos reais |
| **LINDB art. 28** | Responsabilidade por **dolo ou erro grosseiro** |
| **Lei 14.133/2021 art. 53** | Parecer jurídico em licitações + contratos |
| **STF MS 24.631** | Parecer vinculante x opinativo |
| **LC 73/1993** | LOAGU: atos consultivos (art. 4 X) |
| **CF 131-132** | Advocacia Pública |

## Natureza + finalidade

| | Conteúdo |
|---|---|
| **Manifestação consultiva interna** | Da advocacia pública à administração |
| **Caráter opinativo** | Não vinculante, salvo lei |
| **Mais ágil que parecer** | Documento de assessoria + orientação técnica |
| **Direcionada a gestor** | Auxilia decisão administrativa |
| **Sigilo** | Em regra, interna: mas atos administrativos finais são públicos (LAI Lei 12.527) |

## Diferenças entre instrumentos

| Instrumento | Característica |
|---|---|
| **Parecer jurídico** | Formal, completo, com fundamentação extensa, conclusão fechada |
| **Parecer normativo** (LC 73 art. 40, no plano federal) | Vinculante após aprovação superior e publicação |
| **Nota técnica** | Curta, focada, opinativa, orientação prática |
| **Manifestação** | Em processo administrativo específico, sem caráter consultivo amplo |
| **Cota** | Em autos judiciais: opinião pontual do procurador |
| **Memorando** | Comunicação interna, sem caráter consultivo |
| **Despacho interlocutório** | Decisório administrativo: não consultivo |
| **Informação** | Resposta administrativa simples a consulta interna |

## Estrutura

1. **Identificação**:
   - Cabeçalho: NOTA TÉCNICA Nº [número/ano]: [órgão].
   - Consulente (órgão demandante).
   - Subscritor (procurador + cargo + OAB se houver).
   - Data.
2. **Síntese da consulta**: pergunta concreta + escopo.
3. **Fatos / premissas**: ordem cronológica + documentos analisados.
4. **Análise jurídica**:
   - Legislação aplicável (lei + decreto + ato normativo).
   - Jurisprudência relevante (STF/STJ/TCU + súmulas + temas).
   - Atos normativos internos pertinentes.
   - Análise dos cenários alternativos.
5. **Conclusão**:
   - Resposta direta à consulta.
   - Recomendação prática + riscos (baixo/médio/alto).
6. **Pontos abertos**: o que **não** foi analisado + premissas frágeis.
7. **Encerramento**: assinatura + cargo + matrícula.

## Pertinência (quando usar)

| Caso | Documento adequado |
|---|---|
| **Consulta complexa + decisão central + base legal** | Parecer |
| **Consulta pontual com necessidade de orientação prática** | Nota técnica |
| **Questão recorrente que merecerá pacificação interna** | Parecer normativo (LC 73 art. 40, no plano federal) |
| **Análise de minuta** (contrato, edital) | Nota técnica ou parecer (a depender da complexidade) |
| **Resposta a TCU/CGU** | Manifestação ou memorial |
| **Avaliação preliminar de risco** | Nota técnica |
| **Subsídio para tomada de decisão urgente** | Nota técnica |

## Responsabilidade do subscritor (LINDB art. 28)

| | Conteúdo |
|---|---|
| **Regra** | Agente público responde **apenas por dolo ou erro grosseiro** (LINDB 28) |
| **STF MS 24.631** | Parecer **opinativo**: sem responsabilidade salvo dolo ou culpa grave |
| **Parecer/NT vinculante** | Responsabilidade **solidária** com o gestor |
| **TCU Acórdãos diversos** | Aplicam o critério LINDB |
| **CF 37 §6 + ação regressiva** | Cabe se dolo ou culpa grave |
| **Penal** | Prevaricação (CP 319) + advocacia administrativa (CP 321) se configurado |

## Erro grosseiro x dolo (CGU + TCU)

| | Conteúdo |
|---|---|
| **Erro grosseiro** | Desvio manifesto de diligência razoável, conhecimento técnico ou cuidado básico |
| **Dolo** | Intenção desonesta + conhecimento da ilicitude |
| **Erro técnico simples** | **Não** acarreta responsabilidade |
| **Decisão fundamentada em parecer/NT defensável** | Não enseja responsabilidade |

## Análise sob a LINDB (arts. 20-30)

| Artigo | Conteúdo |
|---|---|
| **Art. 20** | Considerar **consequências práticas** |
| **Art. 21** | Decisão que invalida ato deve indicar **consequências jurídicas e administrativas** e, se for o caso, regime de transição |
| **Art. 22** | Considerar **obstáculos + dificuldades reais** |
| **Art. 23** | Compromissos transitórios + regime de transição |
| **Art. 24** | Revisão de validade considerando contexto da época |
| **Art. 26** | Compromissos consensuais |
| **Art. 27** | Compensação por benefícios indevidos ou prejuízos anormais resultantes do processo ou da conduta dos envolvidos |
| **Art. 28** | Dolo ou erro grosseiro |
| **Art. 29** | Consulta pública opcional na alteração regulamentar |
| **Art. 30** | Atos com pretensão normativa devem ter critérios objetivos |

## Estrutura abreviada

Para questões objetivas:

1. **Consulta** (1 parágrafo);
2. **Resposta objetiva** (1 parágrafo destacado);
3. **Análise** (3-5 parágrafos);
4. **Riscos + ressalvas** (1 parágrafo);
5. **Recomendação**.

## Análise de minuta (contratos + editais)

- Pertinência do objeto;
- Conformidade legal (Lei 14.133 + lei local);
- Cláusulas obrigatórias (Lei 14.133 art. 92 + 124);
- Cláusulas leoninas + desproporcionais;
- Foro + arbitragem (Lei 9.307 + Lei 13.129);
- Reajuste + repactuação;
- Sanções + extinção;
- Pareceres anteriores aplicáveis.

## Análise de processo administrativo

- Regularidade formal (Lei 9.784);
- Competência do agente decisório;
- Motivação adequada (Lei 9.784 art. 50);
- Contraditório + ampla defesa;
- Prazos + decadência (Lei 9.784 art. 54: 5 anos);
- Sanções proporcionais;
- Recurso administrativo cabível.

## Análise de tese jurídica

- Marco normativo;
- Jurisprudência vinculante (STF/STJ);
- Súmulas pertinentes;
- Posição da PGFN/AGU/PGE (atos administrativos internos);
- Aplicação concreta + cenários.

## Conclusão típica

- **"Em conclusão, a presente Nota Técnica entende que [tese central], com base em [dispositivos legais] e [jurisprudência vinculante]. Recomenda-se [providência], observados os riscos [enumerar]. Submete-se à apreciação superior."**

## Sigilo + publicidade (LAI Lei 12.527)

- Em regra, **internas**.
- Quando juntadas a procedimento decisório, tornam-se **acessíveis** após decisão final.
- Sigilo (LAI art. 23): se houver informação sensível, hipóteses do art. 23.
- LGPD: tratar dados pessoais conforme Lei 13.709.

## Pontos abertos + ressalvas

Sempre indicar:

- Documentos **não analisados** (por ausência ou irrelevância);
- Premissas **frágeis** ou supostas;
- Necessidade de **complementação** + diligências sugeridas.

## Erros a evitar

- **Conclusão vaga** ou sem recomendação clara;
- **Confundir com parecer**: NT é mais ágil + objetiva;
- **Omitir riscos** e cenários alternativos;
- **Esquecer LINDB 22**: considerar dificuldades + obstáculos reais;
- **Tratar opinativo como vinculante** (responsabilidade): distinguir;
- **Não documentar dispositivos legais analisados** + relação com a consulta;
- **Confundir NT com despacho** ou cota: instrumentos diferentes;
- **Ignorar pareceres anteriores** sobre matéria conexa;
- **Concluir sem responder à pergunta**: finalidade da NT é a recomendação;
- **Não delimitar escopo**: pontos abertos + premissas devem aparecer;
- **Sugerir transação ilegal**: observar lei autorizativa + limites do gestor;
- **Tratar todos os agentes como responsáveis** sem distinguir dolo + erro grosseiro (LINDB 28);
- **Confundir parecer normativo** (vinculante após aprovação) com NT (opinativa);
- **Esquecer LAI** ao tratar de sigilo das informações analisadas;
- **Recomendar ato** sem indicar competência do agente decisório.

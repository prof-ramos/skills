# Reclamação Disciplinar ao CNJ e CNMP

## Base normativa

| Diploma | Conteúdo |
|---|---|
| **CF art. 103-B** (EC 45/04) | Cria o CNJ |
| **CF art. 130-A** (EC 45/04) | Cria o CNMP |
| **Lei 11.364/2006** | Organiza o CNJ |
| **LC 75/1993** + LC 35/79 (LOMAN) | Organização MP e Magistratura |
| **Resolução CNJ 135/2011** | Uniformiza o processo administrativo disciplinar contra magistrados |
| **Resolução CNJ 67/2009** | Regimento Interno do CNJ (atualizado) |
| **Regimento Interno do CNMP** + resoluções disciplinares do CNMP | Procedimentos no CNMP |
| **LOMAN art. 42** | Penas disciplinares aos magistrados |
| **Lei 8.625/93** + leis orgânicas estaduais | Sanções disciplinares aos membros do MP |

## Distinção crítica: jurisdicional vs. administrativo

| Controle | Conteúdo |
|---|---|
| **Jurisdicional** | Recurso, MS, HC, embargos: controle de **decisão** |
| **Administrativo** (CNJ/CNMP) | Controle de **conduta** + ato administrativo do juiz/membro MP |
| **Não confundir**: CNJ **não reforma** decisão judicial |  |
| **Súmula Vinculante**: matéria reservada ao STF |  |

## Estrutura institucional

### CNJ (CF 103-B)
| Composição | 15 membros |
|---|---|
| **Presidente** | Presidente do STF |
| **STJ** | 1 ministro (Corregedor Nacional de Justiça) |
| **TST** | 1 ministro |
| **Justiça estadual** | 1 desembargador de TJ + 1 juiz estadual |
| **Justiça federal** | 1 juiz de TRF + 1 juiz federal |
| **Justiça do trabalho** | 1 juiz de TRT + 1 juiz do trabalho |
| **Ministério Público** | 1 membro do MPU + 1 membro de MP estadual |
| **Advocacia** | 2 advogados indicados pelo Conselho Federal da OAB |
| **Cidadãos** | 2 (indicados pela Câmara dos Deputados e pelo Senado) |
| **Mandato** | 2 anos + 1 recondução |

### CNMP (CF 130-A)
| Composição | 14 membros |
|---|---|
| **Presidente** | PGR |
| **MPU** | 4 membros (asseguradas as carreiras: MPF, MPT, MPM, MPDFT) |
| **MP estaduais** | 3 membros |
| **Magistrados** | 2 juízes (indicados um pelo STF e outro pelo STJ) |
| **Advocacia** | 2 advogados (indicados pelo Conselho Federal da OAB) |
| **Cidadãos** | 2 (CD + Senado) |
| **Mandato** | 2 anos + 1 recondução |
| **Corregedor Nacional do MP** | Função própria |

## Atribuições do CNJ (CF 103-B §4)

| Inciso | Atribuição |
|---|---|
| **I** | Zelar pela autonomia do Poder Judiciário |
| **II** | Zelar pela observância do art. 37 |
| **III** | Receber e conhecer das reclamações contra membros do Judiciário |
| **IV** | Representar ao MP, no caso de crime contra a administração pública ou abuso de autoridade |
| **V** | Rever, de ofício ou mediante provocação, processos disciplinares julgados há menos de 1 ano |
| **VI** | Elaborar relatório estatístico semestral sobre processos e sentenças |
| **VII** | Elaborar relatório anual propondo providências (integra a mensagem ao Congresso) |

## Tipos de procedimentos

| Procedimento | Conteúdo | Sigla |
|---|---|---|
| **Procedimento de Controle Administrativo** | Controle de atos administrativos de tribunais ou órgãos do Judiciário/MP | **PCA** |
| **Pedido de Providências** | Solicitação de medida administrativa | **PP** |
| **Reclamação Disciplinar** | Apuração de conduta funcional de magistrado/membro MP | **RD** |
| **Sindicância** | Apuração preliminar | (sem sigla) |
| **Processo Administrativo Disciplinar** | Apuração formal com defesa | **PAD** |
| **Representação por Excesso de Prazo** | Atraso processual | **REP** |
| **Consulta** | Esclarecimento normativo | (sem sigla) |
| **Avocação** | CNJ assume processo de corregedoria local | (sem sigla) |
| **Revisão Disciplinar** | Revisão de processo já concluído | **RDC** |

## Hipóteses de Reclamação Disciplinar (Lei CNJ + LOMAN)

| Conduta | Conteúdo |
|---|---|
| **Desídia** | Acúmulo injustificado de feitos; descumprimento de prazos |
| **Inadequação funcional** | Comportamento inadequado em audiência ou despacho |
| **Quebra de imparcialidade** | Ato que comprometa neutralidade |
| **Recebimento de vantagem indevida** | Corrupção (também criminal) |
| **Decisão em conflito de interesse** | Não-impedimento |
| **Inadequação na conduta privada** | Quando reflete sobre função |
| **Descumprimento de orientação** do CNJ |  |
| **Excesso de prazo** | Após advertência |
| **Trato inadequado a partes** | Discriminação, hostilidade |
| **Uso indevido de prerrogativas** | Trânsito, prerrogativa em condução |
| **Violação de sigilo** | Funcional |
| **Manifestações públicas** inadequadas | Em redes sociais, mídia |

## Sanções (LOMAN art. 42 + Resoluções)

| Sanção | Conteúdo |
|---|---|
| **Advertência** | Aplicada pelo presidente do tribunal ou corregedor |
| **Censura** | Em hipóteses específicas |
| **Remoção compulsória** | Mudança forçada de vara |
| **Disponibilidade** | Afastamento com vencimentos |
| **Aposentadoria compulsória** | Com vencimentos proporcionais |
| **Demissão** | Apenas para **não-vitalício** (no início da carreira) |
| **Cassação de aposentadoria** | Em hipóteses |

**Vitaliciedade** (CF 95 I): magistrado vitalício só pode ser destituído por sentença judicial transitada em julgado. CNJ aplica até a aposentadoria compulsória (e remoção); demissão exige ação no MS ou ação ordinária.

## Sanções para membros do MP (Lei 8.625 + LC 75)

| Sanção | Aplicação |
|---|---|
| **Advertência** | Pelo corregedor ou PGE/PGR |
| **Censura** |  |
| **Remoção compulsória** | Por necessidade |
| **Suspensão** | Em casos específicos |
| **Disponibilidade** |  |
| **Demissão** | Apenas membros não-vitalícios |
| **Cassação de aposentadoria** |  |

## Procedimento de RD (Res. CNJ 135 + RICNJ)

1. **Petição inicial** ao CNJ (ou CNMP);
2. **Análise** de admissibilidade pelo conselheiro ou corregedor;
3. **Notificação** ao magistrado/membro MP para manifestação;
4. **Instrução** + diligências;
5. **Parecer** da Procuradoria do CNJ;
6. **Decisão** monocrática (em hipóteses) ou colegiada;
7. **Recurso administrativo** interno;
8. **Mandado de segurança** ao STF (CF 102 I r: competência originária) contra ato do CNJ.

## Estrutura da reclamação

1. **Endereçamento** ao CNJ ou CNMP.
2. **Qualificação** do reclamante + procuração.
3. **Identificação** do reclamado (juiz, desembargador, ministro, promotor, procurador) com cargo e tribunal/MP.
4. **Síntese fática** detalhada da conduta.
5. **Cronologia** com datas + atos + documentos.
6. **Caracterização da conduta**: dispositivo legal infringido (LOMAN, Lei 8.625, Res. CNJ 135 ou CNMP).
7. **Documentação anexa**: cópia dos autos, certidões, depoimentos, áudios, vídeos, mensagens.
8. **Tutela**: medidas urgentes (afastamento cautelar, em hipóteses extremas);
9. **Pedido**: instauração + apuração + sanção compatível;
10. **Encaminhamento ao MP** se houver crime correlato.

## Reclamação disciplinar ao CNJ (CF 103-B §4 III) vs. Reclamação constitucional (CPC 988)

| | Reclamação ao CNJ | Reclamação constitucional |
|---|---|---|
| **Base** | CF 103-B + Res. CNJ 135 | CPC 988 |
| **Função** | Controle administrativo | Preservação de competência ou autoridade de decisão |
| **Veículo** | Não é recurso | Espécie de ação |
| **Cabimento** | Conduta administrativa | Usurpação de competência; descumprimento de SV, RG, repetitivo, controle concentrado |
| **Decisão** | Sanção administrativa | Cassação ou anulação |
| **Recurso** | Interno + MS ao STF | Embargos + agravo |

Não confundir!

## Avocação (CF 103-B §4 III + RICNJ)

- CNJ pode **assumir** processo disciplinar em curso em corregedoria local;
- Hipóteses: gravidade, demora, suspeição;
- Decisão fundamentada;
- Procedimento integral perante CNJ.

## Revisão Disciplinar (CF 103-B §4 V)

- CNJ pode **rever** processo disciplinar em até **1 ano** do trânsito em julgado da decisão local;
- De ofício ou por provocação;
- Pode agravar ou abrandar.

## Coordenação com criminal

- **Reclamação** = administrativa;
- **Criminal**: encaminhamento ao MP (CF 103-B §4 IV);
- **Coordenação**: independentes mas relacionados;
- **Em corrupção, abuso de autoridade**: dupla via.

## MS ao STF contra ato do CNJ/CNMP (CF 102 I r)

- Competência originária do STF;
- Cabimento: ato administrativo do CNJ/CNMP que viole direito líquido e certo;
- Litisconsórcio: CNJ/CNMP + autoridade requerente;
- Prazo: 120 dias (Súmula 632 STF);
- Defesa do CNJ/CNMP pela AGU.

## Coordenação com OAB

- OAB tem assento no CNJ + CNMP (2 cada);
- **Representação OAB** (Lei 8.906 art. 49): pode ser feita em paralelo;
- Procedimento próprio na OAB para questões com advogados.

## Coordenação com corregedorias locais

- Corregedoria do tribunal/MP: atuação disciplinar local;
- CNJ/CNMP: competência disciplinar originária e concorrente com as corregedorias locais (STF, ADI 4.638), além de avocação e revisão;
- O esgotamento prévio da via local não é requisito de admissibilidade, embora o CNJ possa remeter o caso à corregedoria local por conveniência.

## Diferenças entre CNJ e CNMP

| | CNJ | CNMP |
|---|---|---|
| **Composição** | 15 membros (1 STF presidente) | 14 membros (PGR presidente) |
| **Atuação** | Judiciário | Ministério Público (federal + estaduais) |
| **Casos típicos** | Excesso de prazo, decisões reprováveis, conduta inadequada | Atuação ministerial, decisões de arquivamento, conduta |
| **Estatuto disciplinar** | LOMAN + Res. CNJ 135 | Lei 8.625 + LC 75 + Res. CNMP |
| **Recurso** | MS STF | MS STF |

## Erros a evitar

- **Confundir reclamação disciplinar com recurso**: CNJ não reforma decisão judicial.
- **Confundir reclamação CNJ com reclamação constitucional** (CPC 988): regimes distintos.
- **Falta de documentação**: peça frágil.
- **Reclamar contra decisão** sem identificar conduta administrativa ou disciplinar distinta.
- **Atrasos processuais** sem advertência prévia ao tribunal: requisito subjetivo de cabimento.
- **Em magistrado vitalício**: pedir demissão (não cabe; só sentença judicial).
- **Em revisão disciplinar**: ultrapassar 1 ano do trânsito local.
- **Em MS contra CNJ**: perder prazo de 120 dias (Súm. 632 STF).
- **Em coordenação OAB**: duplicar via sem articular bem.
- **Em apuração penal**: confundir com administrativa.
- **Em avocação**: pleitear sem demonstrar gravidade + ineficiência local.
- **Em SV ou jurisprudência**: pleitear cumprimento pelo CNJ: não é via (é STF via reclamação constitucional).
- **Em afastamento cautelar**: pleitear sem indícios robustos.
- **Em correição CNJ a um tribunal**: confundir com competência jurisdicional.
- **Em manifestação pública**: invocar como conduta sem ofensa funcional clara.
- **Em LGPD**: tratar dados sensíveis da reclamação sem cuidado.
- **Em sigilo**: pedir sigilo sem necessidade demonstrada (CNJ Resolução específica).
- **Em ato administrativo do tribunal**: confundir com decisão judicial recorrível.
- **Em conselheiro suspeito**: não pedir impedimento.
- **Em recurso interno do CNJ**: descumprir prazo.

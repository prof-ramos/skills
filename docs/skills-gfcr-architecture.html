Skills GFCR Architecture Overview

Repository for custom Claude skills and MCP servers. Focused on structured skill packaging, reusable scripts, and operational tooling for GitHub automation.

Business Context

Objectives

Centralize curated Claude skills and MCP tooling with consistent packaging.

Primary Users

Developers and operators who manage skills and GitHub automation workflows.

Value

Repeatable skill onboarding, faster reuse, and safer repo operations.

Success Metrics

Installed skills, automation run time, and GitHub API task completion.

Data Flow

Sources to Outcomes

Skills and documentation are loaded into the agent runtime, which drives tooling and outputs.

Processing Pipeline

System Architecture

Data Layer skills/, docs/, reference templates, skill zip artifacts
Processing Layer skill scripts, validation, packaging, local helpers
Service Layer MCP server (supergithub) for GitHub API operations
Output Layer CLI actions, repo updates, packaged skill distributions
Key Modules skills/ (ui-ux-pro-max, brazilian-official-docs, social-ads-creator)
Automation gh_cli.py and github_repo_manager.py for repo lifecycle tasks
Documentation README.md, implementation_plan.md, and official skill references

Features

Functional

Skill authoring, validation, and packaging for local Claude usage.

Functional

GitHub repository lifecycle actions: list, archive, delete, topics, create.

Functional

Brazilian official document templates and validation scripts.

Non-Functional

Security-conscious CLI with confirmations and token validation.

Non-Functional

Portability via documented structure and asset bundling.

Non-Functional

Extensible skill catalog aligned with Anthropic conventions.

Deployment

Local Setup

Clone repo, install dependencies for servers, and set GH_TOKEN.

Run CLI tools from servers/supergithub or load skills/ into Claude.

Workflow

Author or update skills, validate scripts, then package into dist/ for reuse.

Use MCP server to automate GitHub maintenance at scale.
